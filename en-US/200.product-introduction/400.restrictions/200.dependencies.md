# Dependencies

This topic lists the database versions that OCP depends on.

## Database version requirements

OCP supports the following OceanBase Database versions:

* OceanBase V2.2.76 and OceanBase V2.2.77

* OceanBase V3.1.x

* OceanBase V3.2.x

* OceanBase V4.0.x

* OceanBase V4.1.x

* OceanBase V4.2.x

* OceanBase V4.3.x
