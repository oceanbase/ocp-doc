# What is OceanBase Cloud Platform

OceanBase Cloud Platform (OCP) is an enterprise-level database management platform centered around OceanBase Database, supporting all mainstream versions of OceanBase Database from V2.2.76 to V4.x.

OCP offers full lifecycle management services for OceanBase components such as clusters and tenants, as well as management services for OceanBase-related resources like hosts, networks, and software packages. This allows you to efficiently manage OceanBase clusters and reduce enterprise IT operation and maintenance costs.

As an enterprise-level database management platform centered around OceanBase, OCP offers a rich set of features:

* Efficient OceanBase cluster management

  * Supports high availability.

  * Response speed can reach seconds.

* Clear information framework

  * The new object-oriented architecture provides immersive management perspectives for individual clusters and tenants, aligning with user expectations.

  * Immersive navigation modules are designed based on the work scenarios of DBAs, making the functional entry points clearer.

* Smooth and efficient user path

  * Core job tasks are sequentially connected, ensuring a clear and uninterrupted process.

  * Provides quick access to maintenance tasks on all pages, allowing for easy switching to the task.

* Visual experience

  * Task details include flowcharts and flexible canvas interactions, making it easier and more intuitive to manage task progress.

  * New cluster and tenant topology diagrams reveal distributed business logic, displaying operational status and key data.

* Professional features

  * Provides full lifecycle management for OceanBase clusters.

  * Management features specifically designed for OceanBase Database.

  * Progressive management features from clusters to sessions.

  * Thoughtfully designed topology diagram functionality.
