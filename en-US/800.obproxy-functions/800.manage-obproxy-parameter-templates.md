# Manage OBProxy parameter templates

An OBProxy parameter template contains predefined OBProxy parameters. You can use a parameter template to create a series of OBProxies that have similar configurations without repeatedly configuring OBProxy parameters.

## Prerequisites

* Make sure that you have the following permissions:

  * Resource permissions: **OBProxy maintenance** permission.
  * Menu permissions: Permission on the **Overview** menu of OBProxies.

* You cannot modify or delete built-in parameter templates of the system.

## Procedure

1. Log in to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, click **OBProxy** to go to the **OBProxies** tab.

3. Click the **Parameter Template** tab. In the **OBProxy Parameter Templates** list, you can perform management operations on OBProxy parameter templates. For example, you can create, edit, copy, delete, and search for a template.

### Create a parameter template

You can configure frequently used parameters in a parameter template to avoid repeated configurations.

1. Click **Create Parameter Template** in the upper-right corner of the **OBProxy Parameter Templates** list.

   You can also go to the **Create OBProxy Cluster** page, and click **Create OBProxy Parameter Template** in the **Parameter Settings** section.

2. In the **Create Parameter Template** panel, specify the template name and remarks, and set the template parameters.

   You can click **+Add Parameter** to add a parameter and set its value. For more information, see [OBProxy parameters descpription](900.obproxy-parameters-description.md).

3. Click **Create**.

### Edit a parameter template

You can modify a parameter template as needed.

1. In the **OBProxy Parameter Templates** list, find the parameter template that you want to modify, and click **Edit** in the **Actions** column.

2. In the **Edit OBProxy Parameter Template** panel, modify the template name, remarks, or parameters.

3. Click **Create**.

### Copy a parameter template

You can copy a complex template named A, and rename the template to B. This way, you can use template B after making simple modifications as needed.

1. In the **OBProxy Parameter Templates** list, find the parameter template that you want to copy, and click **Copy** in the **Actions** column.

2. In the **Copy OBProxy Parameter Template** panel, modify the template name, remarks, or parameters.

3. Click **Create**.

### Delete a parameter template

You can delete a parameter template that will not be used.

1. In the **OBProxy Parameter Templates** list, find the parameter template that you want to delete.

2. Click **Delete** in the **Actions** column.

3. Click **OK**.

### Search for a parameter template

You can enter a template name for fuzzy search of OBProxy parameter templates.

1. Specify the template name in the search box above the **OBProxy Parameter Templates** list.

2. Click ![1](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5829950461/p377279.png), and view the search results in the **OBProxy Parameter Templates** list.
