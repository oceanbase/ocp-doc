# Refresh OBProxy configurations

This topic describes how to refresh OBProxy configurations. You can refresh the OBProxy configurations to synchronize the parameter settings of an OBProxy with those of the OBProxy cluster.

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **OBProxy Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** menu of **OBProxy**

* In the OBProxies list on the Overview page of the OBProxy cluster, if the **<UI-TERM key="ocp-v2.Plan.Component.PlanExecuteTable.Status">Status</UI-TERM>** of an OBProxy is **<UI-TERM key="ocp-v2.page.Overview.Content.NormalOperation">Running</UI-TERM>** , and an exclamation point ( **!** ) is displayed in its **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.ParameterVersion">Parameter Version</UI-TERM>** column, it means that the parameter version of this OBProxy is different from that of the OBProxy cluster. In this case, you need to refresh the configurations of this OBProxy.

## Procedure

1. Log on to the OCP console.

2. In the left-side navigation pane, click **OBProxy** .

3. In the OBProxy cluster list, click the target OBProxy cluster to go to the **<UI-TERM key="ocp-v2.page.Overview.Overview">Overview</UI-TERM>** page of that OBProxy cluster.

4. Find the target OBProxy in the OBProxies list. Click **More > Refresh Configurations** in the **<UI-TERM key="ocp-v2.page.Credential.Binlog.Operation">Actions</UI-TERM>** column.

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422-en/%E5%88%B7%E6%96%B0%E9%85%8D%E7%BD%AE1.png)

   If you want to refresh the configurations of multiple OBProxies, select target OBProxies and click **More > Batch Refresh** .

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422-en/%E6%89%B9%E9%87%8F%E5%88%B7%E6%96%B0%E9%85%8D%E7%BD%AE1.png)

5. In the dialog box that appears, click **<UI-TERM key="ocp-v2.component.FilterDropdown.Determine">OK</UI-TERM>** .

   In the dialog box, you can click **<UI-TERM key="ocp-v2.Detail.Report.ViewTasks">View Task</UI-TERM>** to view the progress.

   When the task status is **<UI-TERM key="ocp-v2.src.constant.task.Completed">Completed</UI-TERM>** , and the **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.ParameterVersion">Parameter Version</UI-TERM>** column of the **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.ObproxyList">OBProxies</UI-TERM>** list on the **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** page does not contain an exclamation point ( **!** ), the OBProxy configurations are refreshed.
