# Stop or start an OBProxy

This topic describes how to stop or start an OBProxy. Stopping an OBProxy causes business interruptions. Proceed with caution.

After you stop an OBProxy, you can click **<UI-TERM key="ocp-v2.src.constant.oceanbase.Start">Start</UI-TERM>** to restart it.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **OBProxy Maintenance** permission
* **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** menu of **OBProxy**

## Procedure

1. Log on to the OCP console.

2. In the left-side navigation pane, click **OBProxy**.

3. In the **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** list, select the target OBProxy cluster to go to its **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** page.

4. Find the OBProxy that you want to stop, and choose **More > Stop** in the **<UI-TERM key="ocp-v2.page.Package.UploadPackageTaskDrawer.Operation">Actions</UI-TERM>** column.

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422-en/%E5%81%9C%E6%AD%A2obproxy1.png)

   You can also select multiple OBProxies and click **<UI-TERM key="ocp-v2.src.constant.obproxy.BatchStop">Batch Stop</UI-TERM>**.

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422-en/%E6%89%B9%E9%87%8F%E5%81%9C%E6%AD%A2obproxy1.png)

   To stop all OBProxies in an OBProxy cluster, you can directly stop the cluster. For more information, see [Stop or start an OBProxy cluster](../300.manage-a-obproxy-cluster/700.restarts-all-obproxy-nodes-in-the-obproxy-cluster.md).

5. In the dialog box that appears, click **<UI-TERM key="ocp-v2.Component.ZoneList.EditZoneModal.Ok">OK</UI-TERM>**.

6. In the dialog box that appears, click **<UI-TERM key="ocp-v2.Detail.Report.ViewTasks">View Task</UI-TERM>** to view the progress.

   When the task enters the **<UI-TERM key="ocp-v2.Compaction.Detail.Completed">Completed</UI-TERM>** state, and the status of the OBProxy is displayed as **<UI-TERM key="ocp-v2.src.constant.backup.Stopped">Stopped</UI-TERM>** in the **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.ObproxyList">OBProxies</UI-TERM>** list on the **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">Overview</UI-TERM>** page, the task is successfully executed.

7. Start the OBProxy.

   If you want to use the stopped OBProxy again, find the OBProxy in the **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.ObproxyList">OBProxies</UI-TERM>** list, and choose **More > Start** in the **<UI-TERM key="ocp-v2.page.Host.Operation">Actions</UI-TERM>** column. You can also select multiple OBProxies and click **<UI-TERM key="ocp-v2.src.constant.obproxy.BatchStart">Batch Start</UI-TERM>**.

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422-en/%E5%90%AF%E5%8A%A8obproxy1.png)
