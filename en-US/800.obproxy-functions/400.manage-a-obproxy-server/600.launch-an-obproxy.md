# Launch an OBProxy

This topic describes how to launch an OBProxy. After you launch an OBProxy, the load balancing weight of the node is resumed. The node is used as a traffic entry for new connections based on the load balancing rules. Business requests are sent to this OBProxy, and the business pressure on the system is reduced.

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **OBProxy Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** menu of **OBProxy**

* The target OBProxy is in the pending takeover or deletion state.
* The target OBProxy is removed.
* The OBProxy cluster contains at least one load balancer instance.

## Procedure

1. Log on to the OCP console.

2. In the left-side navigation pane, click **OBProxy**.

3. In the OBProxy cluster list, click the target OBProxy cluster. Then, the **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** page of the OBProxy cluster appears.

4. In the OBProxy list, select the target OBProxy, move the pointer over the **<UI-TERM key="ocp-v2.Cluster.Component.MachineResource.SeeMore">More</UI-TERM>** icon, and then click **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.Online">Launch</UI-TERM>** in the drop-down list.

5. In the dialog box that appears, click **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.Online">Launch</UI-TERM>**.
