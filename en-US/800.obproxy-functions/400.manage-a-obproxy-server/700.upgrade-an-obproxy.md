# Upgrade an OBProxy

This topic describes how to upgrade an OBProxy.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **OBProxy Maintenance** permission
* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.page.Overview.Overview">Overview</UI-TERM>** menu of **OBProxy**

## Procedure

1. Log on to the OCP console.

2. In the left-side navigation pane, click **OBProxy** .

3. In the OBProxy cluster list, click the target OBProxy cluster to go to its overview page.

4. In the OBProxy list, select the OBProxy to upgrade, and click **<UI-TERM key="ocp-v2.src.constant.obproxy.Upgrade">Upgrade</UI-TERM>** in the **<UI-TERM key="ocp-v2.Settings.Credential.Host.Operation">Actions</UI-TERM>** column.

   ![10291419](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422-en/%E5%8D%87%E7%BA%A7obproxy1.png)

5. In the dialog box that appears, select **<UI-TERM key="ocp-v2.Cluster.Detail.UpgradedVersion">Upgrade Version</UI-TERM>** .

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422-en/%E5%8D%87%E7%BA%A7obproxy2.png)

   <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>You can only upgrade the OBProxy to a higher version. The hardware architecture of the target version must match that of the host.</p>
   </main>

6. Click **<UI-TERM key="ocp-v2.MultiCluster.Detail.SwitchoverModal.Determine">OK</UI-TERM>** .
