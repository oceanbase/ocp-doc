# Manage load balancing

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OceanBase Cloud Platform (OCP) Enterprise Edition. OCP Community Edition does not support this feature. </p>
</main>

OceanBase Load Balancer (OBLB) is a software load balancing tool that is based on iptables. You can configure OBLB for an OBProxy cluster to improve its load balancing capability.

* If the OBLB service is not configured for an OBProxy cluster, you can click **Add Load Balancer** to add the OBLB service for it.
* If the OBLB service is already configured for an OBProxy cluster, you can click **Modify Load Balancer** to update the related OBLB information.

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **OBProxy Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** menu of **OBProxy**

* OBLB has been deployed in OceanBase Admin Toolkit (OAT) before you add the OBLB service. For more information, see [Install and uninstall OBLB](https://en.oceanbase.com/docs/common-oat-10000000001923206).

## Add an OBLB service

  1. Log in to the OCP console.

  2. In the left-side navigation pane, click **OBProxy** to go to the OBProxy page.

3. In the OBProxy cluster list, click the target OBProxy cluster. Then, the **<UI-TERM key="ocp-v2.page.Overview.Overview">Overview</UI-TERM>** page of the OBProxy cluster appears.

4. Move the pointer over **<UI-TERM key="ocp-v2.Session.LockAnalysis.Operation">Operation</UI-TERM>** on the right side of **<UI-TERM key="ocp-v2.Detail.Overview.Endpoint">Access URL</UI-TERM>**. Then, select **Add Load Balancing** from the drop-down list.

        ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/402-en/%E6%96%B0%E5%A2%9E%E8%B4%9F%E8%BD%BD%E5%9D%87%E8%A1%A11.png)

  5. In the right-side pane, enter related information of the OBLB service.

   * OBLB Service Address: the OBLB service address. You can select the OBLB service configured when the OCP is deployed, or click **<UI-TERM key="ocp-v2.Detail.Component.OBLBServerSelect.AddOblbService">Add OBLB Service</UI-TERM>** and then add the OBLB service in the right-side pane.

        * **OBLB Service Address**: the virtual IP address of the OBLB service.
        * **OBLB Service Port**: the port of the OBLB service. The default service port is 9090. You can change the port as needed.
        * **Username** and **Password**: the username and password of the OBLB service, which are used to get the authentication information about the OBLB interface.

     * **VIP**: the virtual IP address of the OBLB service.
     * **Access Port**: the access port of the OBLB service. The default access port is 2883. You can change the access port.
     * **Domain Name Configuration (Optional)**: the configuration that points to the VIP and port. OCP does not provide the mappings between VIPs and domain names. You must configure the domain name resolution service.
     * **Remarks (Optional)**: additional information about the OBLB service.

        <main id="notice" type='explain'>
        <h4>Note</h4>
        <p>The Alibaba Cloud Server Load Balancer (SLB) service applies only to the Apsara Stack environment. We recommend that you contact Technical Support for assistance. </p>
        </main>

## Modify the OBLB service

  1. Log in to the OCP console.

  2. In the left-side navigation pane, click **OBProxy** to go to the OBProxy page.

3. In the OBProxy cluster list, click the target OBProxy cluster. Then, the **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** page of the OBProxy cluster appears.

4. Move the pointer over **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.Operation">Actions</UI-TERM>** on the right side of **<UI-TERM key="ocp-v2.Component.LBLoadBalanceConditon.LoadBalancer">Load Balancer</UI-TERM>**. Then, select **<UI-TERM key="ocp-v2.Detail.Overview.ModifyLoadBalancing">Modify Load Balancer</UI-TERM>** from the drop-down list.

  5. In the right-side pane, click the ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/402-cn/%E7%BC%96%E8%BE%91%E6%8C%89%E9%92%AE.png) icon to edit the domain name configuration information.
    You can click **Delete** in the **Actions** column to delete the VIP configured for the OBProxy cluster.

5. In the right-side pane, click ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/402-cn/%E7%BC%96%E8%BE%91%E6%8C%89%E9%92%AE.png) to edit the domain name configuration information.

   You can click **<UI-TERM key="ocp-v2.Auth.User.Delete">Delete</UI-TERM>** in the Actions column to delete the VIP configured for the OBProxy cluster.

    <main id="notice" type='alert'>
    <h4>Notice</h4>
    <p>After the VIP is deleted, you cannot connect to the OBProxy cluster by using this VIP. Proceed with caution. </p>
    </main>
