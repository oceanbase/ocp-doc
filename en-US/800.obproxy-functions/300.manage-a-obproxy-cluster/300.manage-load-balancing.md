# Manage load balancing

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OCP Enterprise Edition. OCP Community Edition does not support this feature. </p>
</main>

OBLB is an iptables-based software load balancing tool. You can configure OBLB for an OBProxy cluster to improve the load balancing capability of the cluster.

* If no OBLB service is configured for the OBProxy cluster, you can use the **<UI-TERM key="ocp-v2.TakeOver.Component.LoadBalancer.AddLoadBalancing">Add Load Balancer</UI-TERM>** feature to add an OBLB service.
* If an OBLB service is configured for the OBProxy cluster, you can use the **<UI-TERM key="ocp-v2.Detail.Overview.ModifyLoadBalancing">Modify Load Balancer</UI-TERM>** feature to update the load balancing information.

## Prerequisites

* Make sure that the user who logs in to the OCP console has the following permissions:

  * **OBS Proxy Maintenance** resource permissions.
  * **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** menu permissions.

* Before you add an OBLB service, you must deploy the OBLB tool in OAT. For more information, see [Deploy OBLB](https://www.oceanbase.com/docs/enterprise-oat-doc-cn-10000000001092549).

## Procedure

  1. Log in to the OCP console.

  2. Click **OBS Proxy** to go to the OBProxy page.

  3. In the cluster list, click the name of the OBProxy cluster that you want to operate to go to the **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** page of the cluster.

  4. Hover the pointer over **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.Operation">Actions</UI-TERM>** in the right-side column of the **<UI-TERM key="ocp-v2.Detail.LoadBalance.LoadBalancing">Load Balancer</UI-TERM>** section, and click **<UI-TERM key="ocp-v2.Detail.Overview.AddLoadBalancing">Add Load Balancer</UI-TERM>** in the menu that appears.

        ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/402-cn/%E6%B7%BB%E5%8A%A0%E8%B4%9F%E8%BD%BD%E5%9D%87%E8%A1%A1%E6%8C%89%E9%92%AE.png)

  5. In the right-side panel, specify the information about the OBLB service.

     * OBLB Service Endpoint: You can select an OBLB service that is configured during the deployment of OCP, or click **<UI-TERM key="ocp-v2.Component.LBLoadBalanceConditon.AddOblbService">Add OBLB Service</UI-TERM>** to create an OBLB service in the right-side panel.

        * OBLB Service Endpoint: the VIP address of the OBLB service.
        * OBLB Service Port: the port of the OBLB service. The default value is 9090.
        * Username and Password: the username and password of the OBLB service, which are used for authentication when you call the OBLB interface.

     * VIP: the specific VIP address of the OBLB service.
     * Access Port: the access port of the OBLB service. The default value is 2883.
     * Port Type: the type of the access port. Valid values: RPC and SQL.
     * Domain Name Configuration (Optional): the configuration information for mapping the VIP and port. The platform does not provide a mapping between the VIP and domain name. You must prepare a domain name resolution service.
     * Remarks (Optional): the supplementary description of the load balancing.

        <main id="notice" type='explain'>
        <h4>Note</h4>
        <p> SLB is applicable only in Apsara Stack. We recommend that you contact technical support for assistance. </p>
        </main>

## Modify load balancing

  1. Log in to the OCP console.

  2. Click **OBProxy** to go to the OBProxy page.

  3. In the cluster list, click the name of the OBProxy cluster that you want to modify, and go to the **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** page of the cluster.

  4. Hover the pointer over **<UI-TERM key="ocp-v2.Alarm.LogFilter.Operation">Actions</UI-TERM>** next to **<UI-TERM key="ocp-v2.Detail.LoadBalance.LoadBalancing">Load Balancer</UI-TERM>**, and click **<UI-TERM key="ocp-v2.Detail.Overview.ModifyLoadBalancing">Modify Load Balancer</UI-TERM>** in the menu that appears.

     ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/402-cn/%E4%BF%AE%E6%94%B9%E8%B4%9F%E8%BD%BD%E5%9D%87%E8%A1%A1%E6%8C%89%E9%92%AE.png)

  5. In the right-side panel, click ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/402-cn/%E7%BC%96%E8%BE%91%E6%8C%89%E9%92%AE.png) to edit the information about the domain name configuration.
    You can also click **<UI-TERM key="ocp-v2.page.Tags.TagList.Delete">Delete</UI-TERM>** in the Actions column to delete the configured VIP in the cluster.

     ![4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/402-cn/%E4%BF%AE%E6%94%B9%E8%B4%9F%E8%BD%BD%E5%9D%87%E8%A1%A1.png)

     	<main id="notice" type='notice'>
      <h4>Notice</h4>
      <p>After the VIP is deleted, it cannot be used to connect to the current OBProxy cluster. Proceed with caution. </p>
      </main>
