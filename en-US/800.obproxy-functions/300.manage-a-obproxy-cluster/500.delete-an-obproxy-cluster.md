# Delete an OBProxy cluster

This topic describes how to delete an OceanBase Proxy (OBProxy) cluster. After an OBProxy cluster is deleted, the OBProxies in the cluster are uninstalled from each host, and the resources occupied by the OBProxies on each host are released. Settings of the OBProxy cluster and related OceanBase Load Balancer (OBLB) are also deleted.

<main id="notice" type='notice'>
<h4>Notice</h4>
<p>If a host in the OBProxy cluster is offline, the system cannot clean up the host environment and will skip this step during the deletion of the OBProxy cluster. In this case, we recommend that you manually clean up the host environment. </p>
</main>

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **OBProxy Management** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** menu of **OBProxy**

* Make sure that the current OBProxy cluster no longer provides the reverse proxy service.

   The **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.ConnectableObCluster">Connectable OceanBase Clusters</UI-TERM>** list of the OBProxy cluster is empty, or the listed OceanBase clusters are deprecated.

## Procedure

You can delete an OBProxy cluster by using the following two methods:

* **Method 1**: Go to the **OBProxy** page, find the OBProxy cluster that you want to delete, and choose **More > Delete** in the **<UI-TERM key="ocp-v2.Inspection.Rule.Operation">Actions</UI-TERM>** column.
* **Method 2**: Go to the **<UI-TERM key="ocp-v2.page.Overview.Overview">Overview</UI-TERM>** page of the OBProxy cluster that you want to delete, move the pointer over the **<UI-TERM key="ocp-v2.page.Welcome.SeeMore">More</UI-TERM>** icon, and click **<UI-TERM key="ocp-v2.Detail.Component.DeleteModal.DeleteACluster">Delete Cluster</UI-TERM>**.

The following procedure takes **Method 2** as an example.

1. Log on to the OCP console.

2. In the left-side navigation pane, click **OBProxy**.

3. In the **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** list, click the target OBProxy cluster to go to its **<UI-TERM key="ocp-v2.page.Overview.Overview">Overview</UI-TERM>** page.

4. Move the pointer over the **<UI-TERM key="ocp-v2.Component.AddBackupStrategy.ViewMore">More</UI-TERM>** icon and click **<UI-TERM key="ocp-v2.Cluster.Detail.DeleteACluster">Delete Cluster</UI-TERM>**.

   ![09162145](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422-en/%E5%88%A0%E9%99%A4%E9%9B%86%E7%BE%A41.png)

5. In the dialog box that appears, click **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.Delete">Delete</UI-TERM>**.

6. In the dialog box that appears, click **<UI-TERM key="ocp-v2.Cluster.Import.ImportClusterResults.ViewTasks">View Task</UI-TERM>** to view the progress.

   When the task enters the **<UI-TERM key="ocp-v2.Compaction.Detail.Completed">Completed</UI-TERM>** state, and the deleted OBProxy cluster does not exist in the **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** list on the **OBProxy** page, the cluster is successfully deleted.
