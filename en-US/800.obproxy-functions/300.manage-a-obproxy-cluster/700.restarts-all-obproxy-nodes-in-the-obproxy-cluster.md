# Restart an ODP cluster

This topic describes how to restart an OceanBase Database Proxy (ODP) cluster. If you restart an ODP cluster, all ODPs in the cluster are restarted.

To restart an ODP cluster that provides services, we recommend that you restart ODPs in the cluster in batches based on your load-balancing strategy. For more information, see [Restart an ODP](../400.manage-a-obproxy-server/400.restart-an-obproxy.md).

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **OBProxy Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** menu of **OBProxy**

* In ODP earlier than V3.2.1, only the **<UI-TERM key="ocp-v2.Detail.Component.RestartModal.ForceRestart">Force Restart</UI-TERM>** mode is supported. In ODP V3.2.1 and later, the **<UI-TERM key="ocp-v2.Component.CgroupEditModal.ForceRestart">Force Restart</UI-TERM>** and **<UI-TERM key="ocp-v2.Detail.Component.RestartObproxyModal.Restart">Restart</UI-TERM>** modes are supported.

* The **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.Restart">Restart</UI-TERM>** mode is supported only when all ODPs in the ODP cluster are in the **<UI-TERM key="ocp-v2.src.constant.backup.NormalOperation">Running</UI-TERM>** state. Otherwise, only **<UI-TERM key="ocp-v2.Component.CgroupEditModal.ForceRestart">Force Restart</UI-TERM>** is supported.

* A force restart will first stop all ODPs in the ODP cluster. We recommend that you perform the operation when the business traffic is low.

## Procedure

You can restart an ODP cluster by using the following two methods:

* **Method 1**: Go to the **OBProxy** page, find the ODP cluster that you want to restart, and choose **More > Restart All** in the **<UI-TERM key="ocp-v2.Alarm.Shield.Operation">Actions</UI-TERM>** column.
* **Method 2**: Go to the **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">Overview</UI-TERM>** page of the ODP cluster that you want to restart, and click **<UI-TERM key="ocp-v2.Detail.Overview.RestartAll">Restart All</UI-TERM>**.

The following procedure demonstrates how to use **Method 2**.

1. Log on to the OCP console.

2. In the left-side navigation pane, click **OBProxy**.

3. In the **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>** list, select the target ODP cluster to go to its **<UI-TERM key="ocp-v2.page.Overview.Overview">Overview</UI-TERM>** page.

4. Click **<UI-TERM key="ocp-v2.Detail.Overview.RestartAll">Restart All</UI-TERM>**.

   ![09162146](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422-en/%E5%85%A8%E9%83%A8%E9%87%8D%E5%90%AF1.png)

5. In the dialog box that appears, select **<UI-TERM key="ocp-v2.src.constant.obproxy.Restart">Restart</UI-TERM>** or **<UI-TERM key="ocp-v2.Component.CgroupEditModal.ForceRestart">Force Restart</UI-TERM>**.

   * **<UI-TERM key="ocp-v2.Detail.Component.RestartModal.Restart">Restart</UI-TERM>** (recommended): By default, business access to the database is not interrupted during a restart. If your business involves long-running transactions, we recommend that you set the `hot_upgrade_exit_timeout` parameter to an appropriate value or ensure that application connections can be retried.
   * **<UI-TERM key="ocp-v2.Component.CgroupEditModal.ForceRestart">Force Restart</UI-TERM>**: The client that connects to the ODP cluster is disconnected, which results in business interruptions.

6. In the dialog box that appears, click **<UI-TERM key="ocp-v2.Detail.Report.ViewTasks">View Task</UI-TERM>** to view the progress.

   When the task enters the **<UI-TERM key="ocp-v2.src.constant.backup.Completed">Completed</UI-TERM>** state, and the status of all ODPs is displayed as **<UI-TERM key="ocp-v2.src.constant.compute.NormalOperation">Running</UI-TERM>** in the **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.ObproxyList">OBProxies</UI-TERM>** list on the **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** page, the ODP cluster is restarted.
