# CPU Utilization

This topic describes performance metrics related to the **<UI-TERM key="ocp-v2.Compaction.Detail.CpuAndMemoryChart.CpuUsage">CPU Utilization</UI-TERM>** of a host.

## Definition

The CPU utilization of a host.

## Description

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.IndicatorItem">Metric</UI-TERM>** | **Metric field name** | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.Unit">Unit</UI-TERM>** |
|---------|-------------|--------|
| - | cpu_percent | %      |

## Calculation expression

100 * (1 - sum(rate(node_cpu_seconds_total{mode=~"idle|iowait|steal",@LABELS}[@INTERVAL])) by (@GBLABELS) / sum(cpu_count{@LABELS}) by (@GBLABELS))
