# Network throughput

This topic describes performance metrics related to the **network throughput** of a host.

## receive

### Definition

The amount of data received per second.

### Description

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.IndicatorItem">Metric</UI-TERM>** | **Metric field name** | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.Unit">Unit</UI-TERM>**  |
|------------|-----------------------|-----------|
| receive    | net_recv              | Byte |

### Calculation expression

avg(rate(node_network_receive_bytes_total{@LABELS}[@INTERVAL])) by (@GBLABELS) / 1048576
