# RPC delivery failure

This topic describes the **RPC delivery failure** metric of an OceanBase tenant. You can specify the statistics scope and query the **RPC delivery failure** metric of a tenant in a single zone or on a specific OBServer node.

## Metric introduction

The number of RPC transmission failures during the sampling period.

## Metric parameter description

| Metric item | Metric name | Unit |
|---------|-------------------|--------|
| rpc_deliver_fail_count    | delta_rpc_packet_deliver_fail_count |   -   |

## Calculation expression

sum(delta(ob_sysstat{stat_id="10004",@LABELS}[@INTERVAL])) by (@GBLABELS)

## Collection SQL

* OceanBase Database V2.2.70 and later, but earlier than V4.0:

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (10004) and (con_id > 1000 or con_id = 1) and class < 1000
  ```

* OceanBase Database V4.0 and later:

  ```sql
  select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (10004) and (con_id > 1000 or con_id = 1) and class < 1000
  ```
