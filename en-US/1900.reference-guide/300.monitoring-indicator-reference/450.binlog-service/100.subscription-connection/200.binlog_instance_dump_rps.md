# Associate RPS

This topic describes the subscription connection monitoring metric **<UI-TERM key="ocp-v2.Instance.Overview.SendRps">Associate RPS</UI-TERM>** of a binlog instance. You can specify a statistical range to query the  sending RPS data of a binlog instance.

## Definition

The number of binlogs sent per second by a binlog instance.

## Description

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.IndicatorItem">Metric</UI-TERM>** |   **Metric field name**    | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.Unit">Unit</UI-TERM>** |
|---------|---------------|--------|
| all     | binlog_instance_dump_rps | -      |

## Calculation expression

sum(binlog_instance_dump_rps{@LABELS}) by (@GBLABELS)
