# Query tenant backup strategy

## Description

This interface is used to query the backup strategy of a tenant.

## Remarks

### Interface constraints

The caller must authenticate with OCP Application Service.

### Request path

`GET /api/v2/ob/clusters/{id}/tenants/{tenantId}/backup/config/backupStrategy`

### Request parameters

**Path parameters**

|  Parameter      |  Type     |  Required  |  Example value  |  Description   |
|------------|-----------|--------|---------|----------|
|  id        |  Integer  |  Yes    |  1002   |  The cluster ID.  |
|  tenantId  |  Integer  |  Yes    |  108    |  The tenant ID.  |

### Return results

**Basic data structure**

|  Parameter        |  Type      |  Description                               |
|--------------|------------|----------------------------------|
|  data        |  Object    | Backup strategy details, for more information, see **`OcpBackupStrategy` data structure**. |
|  successful  |  Boolean   | Specifies whether the request is successful.                          |
|  timestamp   |  Datetime  | The timestamp when the server processed the request.                     |
|  duration    |  Integer   | The time in ms that the server spent on processing the request.                  |
|  status      |  Integer   | The HTTP status code.            |
|  traceId     |  String    | The Trace ID of the request, which is used for troubleshooting.             |
|  server      |  String    | The address of the application service that responded to the request.                    |

**`ObBackupServiceStorageConfig` data structure**

|  Parameter                             |  Type     |  Description  |
|-----------------------------------|-----------|------------------|
|  configName                       |  String   |  The storage configuration name.  |
|  obBackupStorageBaseInfo          |  ObBackupStorageBaseInfo  |  The backup storage information, for more information, see **`ObBackupStorageBaseInfo` data structure**.  |
|  alarmStoragePercentageThreshold  |  Integer  |  The backup storage capacity alarm threshold. Please configure it as a percentage.  |
|  storageId                        |  Integer  |  The storage configuration ID.  |
|  serviceType                      |  String   |  The service type. Valid values: <li>BACKUP_RESTORE_SERVICE: backup and restore service (logical backup restore).</li><li>OB_CLUSTER: OceanBase cluster (physical backup restore).</li><li>OTHERS: Others.</li>  |
|  serviceId                        |  Integer  |  The service ID. When the service type is BACKUP_RESTORE_SERVICE, it represents the backup restore service ID; when the service type is OB_CLUSTER, it represents the cluster ID.  |
|  serviceName                      |  String   |  The service name. When the service type is BACKUP_RESTORE_SERVICE, it represents the backup restore service name; when the service type is OB_CLUSTER, it represents the cluster name.  |
|  hostIdList                       |  Array    |  The list of host IDs, which is used to parse the host list for global restore. When the service type is BACKUP_RESTORE_SERVICE, it represents the list of host IDs for the backup restore service; when the service type is OB_CLUSTER, it represents the list of host IDs for the cluster.     |

**`ObBackupStorageBaseInfo` data structure**

|  Parameter               |  Type          |  Description  |
|---------------------|----------------|----|
|  backupStorageType  |  String        |  The storage type. Valid values: `BACKUP_STORAGE_FILE`, `BACKUP_STORAGE_OSS`, `BACKUP_STORAGE_COS`, and `BACKUP_STORAGE_S3`.  |
|  storageUrl         |  String        |  The storage directory. Please configure it as a directory without a protocol, such as `/obbackup/` or `osstest/backup`.  |
|  ossAccessKey       |  OssAccessKey  |  The OSS information. This field is effective only when `backupStorageType=BACKUP_STORAGE_OSS`. For more information, see **`OssAccessKey` data structure**.  |
|  cosAccessKey       |  CosAccessKey  |  The OCS information. This field is effective only when `backupStorageType=BACKUP_STORAGE_COS`. For more information, see **`CosAccessKey` data structure**.  |
|  s3AccessKey       |  S3AccessKey  |  The S3 information. This field is effective only when `backupStorageType=BACKUP_STORAGE_S3`. For more information, see **`S3AccessKey` data structure**.  |
|  customBackupRangeList       |  Array  |  The custom backup range. Supported OBServer versions: [4.2.5.2, 4.3.0) and [4.2.1.11, 4.2.2). For more information, see **`customBackupRange` data structure**.  |

**`customBackupRange` data structure**

|  Parameter             |  Type    |  Description         |
|-------------------|----------|---------------|
|  backupType      |  Enum  |  The backup type. Valid values: DATA and LOG.  |
|  nodeType  |  Enum  |  The backup node type. Valid values: ZONE, REGION, and IDC.  |
|  nodeList           |  Array  | The backup node set. Required. The priority of nodes at the same index is the same. Separate multiple nodes at the same index with commas. Example: ["zone1,zone2", "zone3"].  |

**`ObBackupScheduleConfig` data structure**

|  Parameter                      |  Type     |  Description         |
|----------------------------|-----------|------------------|
|  backupScheduleMode        |  String   |  The backup schedule period. Valid values: <li>WEEK: week.</li><li>MONTH: month.</li>  |
|  backupScheduleEnabled     |  Boolean  |  The backup switch.  |
|  backupScheduleTime        |  Object   |  The backup schedule time, such as "02:00:00.000+08:00".  |
|  dayAndDataBackupModelMap  |  Object   |  The mapping between the schedule day and the data backup mode. Example: { "2": "FULL_BACKUP", "4": "FULL_BACKUP", "6": "INCREMENTAL_BACKUP" } indicates that full data backup is performed on Tuesday, Thursday, and Saturday, and incremental data backup is performed on Saturday.  |
|  startLogBackup            |  Boolean  |  Specifies whether to start log backup simultaneously. Generally, this parameter is set to `true`.  |
|  cleanEnabled              |  Boolean  |  The expired data cleanup switch.  |
|  backupDataRetentionDays   |  Integer  |  The backup data retention period in days. For example, 7 indicates that the backup data of the last 7 days is retained. This parameter takes effect only when `cleanEnabled=true`.  |
|  cleanScheduleTime         |  Object   |  The schedule time for expired data cleanup.  |

**`ObBackupThresholdConfig` data structure**

|               Parameter              |  Type  |   Description              |
|---------------------------------|--------|-----------------------------|
| dataBackupTimeoutMinutes        | Long | The data backup schedule timeout period in minutes.           |
| noSuccessfulDataBackupAlarmDays | Long | The maximum number of days without triggering a data backup success alert.           |
| libObLogExpireDays              | Long | The retention period of liboblog. This parameter is effective only in logical backup mode. |
| logBackupDelaySeconds           | Long | The log backup delay alert threshold in seconds.            |
