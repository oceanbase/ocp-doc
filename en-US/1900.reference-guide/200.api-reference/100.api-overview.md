# Manage resources of an OceanBase cluster

OCP provides RESTful APIs for you to manage resources of an OceanBase cluster and develop your own applications. This topic describes the APIs, syntax, and examples. It is intended for developers. Before you call an API, make sure that you understand the related concepts of OCP.
