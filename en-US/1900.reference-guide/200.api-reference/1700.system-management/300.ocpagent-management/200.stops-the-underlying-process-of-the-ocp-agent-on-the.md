Stop the OCP Agent process on a host 
=============================================================

## Description

Stops the OCP Agent process of the specified host.

## Call note

### Interface constraints

The caller must have the corresponding host management permissions.

### Request path

`POST /compute/hosts/{hostId}/agent/stop`

### Request parameters

**path:**

|   Parameter   |  Type  | Required | Example value |  Description   |
|--------|------|----|-----|-------|
| hostId | Long | Yes  | 100 | The ID of the host. |

### Return result

|     Parameter     |    Type    |          Description           |
|------------|----------|-----------------------|
| data       | Object   | The information about the asynchronous DAG task.          |
| successful | Boolean  | Specifies whether the request is successful.               |
| timestamp  | Datetime | The timestamp when the server finishes the request.          |
| duration   | Integer  | The time taken by the server to process the request in milliseconds. |
| status     | Integer  | The HTTP status code that conforms to the HTTP standard. |
| traceId    | String   | The Trace ID of the request, which is used to troubleshoot problems.  |
| server     | String   | The address of the application service that responds to the request.         |
