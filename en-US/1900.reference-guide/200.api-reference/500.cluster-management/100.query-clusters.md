# Query the list of OceanBase clusters

## Feature description

This API is used to query information about OceanBase clusters managed by OCP.

You can specify conditions such as the cluster name and status to narrow down the query scope. In primary-standby deployment mode, the response includes both primary and standby clusters. You can identify the role of each cluster based on its attributes.

## Call instructions

### Interface constraints

* The caller must be at least the CLUSTER_VIEWER role.

* The caller must be authenticated by OCP application services.

### Request path

`GET /api/v2/ob/clusters`

### Request parameters

|     Parameter      |     Type      | Required |       Example Value        |  Description     |
|-------------|-------------|----|------------------|-------------|
| page        | Integer     | No  | 1                | The page number of the requested data. The value starts from 1. Default value: 1.    |
| size        | Integer     | No  | 10               | The size of the requested data. Default value: 10, maximum value: 2000.     |
| sort        | String      | No  | name,asc         | The sorting rule for the requested data.    |
| name        | String      | No  | foo              | The keyword for the cluster name, which is case-insensitive.    |
| status      | StringArray | No  | CREATING,RUNNING | The status of the cluster. Valid values: <li>RUNNING: running. </li><li>CREATING: being created. </li><li>DELETING: being deleted. </li><li>STARTING: starting. </li><li>RESTARTING: restarting. </li><li>STOPPING: stopping. </li><li>STOPPED: stopped. </li><li>TAKINGOVER: takeover. </li><li>MOVINGOUT: moving out. </li><li>SWITCHOVER: standby cluster switchover. </li><li>FAILOVER: standby cluster failover. </li><li>OPERATING: under maintenance. </li>    |
| withRemote  | Enum        | No  | NONE             | Specifies whether to include OceanBase clusters in remote OCP instances. Valid values: <li>NONE: not to obtain. </li><li>ALL: obtain all. </li><li>RELATED: obtain those in the primary-standby relationship with the current OCP instance. </li>    |
| foldStandby | -           | -   | -                | This parameter is deprecated and will be removed in later versions.   |

|------------------|----------|--------------------------|

| ├─ totalElements | Integer  | Total number of records.                    |
| ├─ totalPages    | Integer  | Total number of pages.                     |
| ├─ number        | Integer  | Current page number.                    |
| ├─ size          | Integer  | The size of the current page.                   |
| successful       | Boolean  | Indicates whether the request is successful.                  |
| timestamp        | Datetime | The server timestamp when the request is completed.             |
| duration         | Integer  | The time taken by the server to process the request, in milliseconds.          |
| status           | Integer  | An HTTP status code that conforms to the HTTP status specification.    |
| traceId          | String   | The trace ID of the request, which is used to troubleshoot issues.     |
