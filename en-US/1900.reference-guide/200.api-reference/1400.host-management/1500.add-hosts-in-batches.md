# Add multiple hosts

## Overview

You can call this API to add host information in batches.

## API details

### Constraints

The caller must have the HOST_MANAGER permission.

### Request path

`POST /api/v2/compute/hosts/batchCreate`

### Request parameters

**body:**

|    Parameter         |     Type      | Required |            Example value             |         Description        |
|-----------------|-------------|------|----------------|---------------|
| hostBasicDataList | ObjectArray | Yes  | --                         | HostBasicData array. For more information, see **HostBasicData**.   |
| sshPort           | Integer     | Yes  | 22                         | The SSH port of the host.      |
| kind              | String      | Yes  | DEDICATED_PHYSICAL_MACHINE | The type of the host. Valid values: <li>DEDICATED_PHYSICAL_MACHINE: physical host.</li><li>DEDICATED_ECS: ECS.</li>    |
| idcId             | Long        | Yes  | 100                        | The ID of the IDC. |
| typeId            | Long        | Yes  | 1001                       | The ID of the host type.   |
| credentialId      | Long        | Yes  | 1001                       | The ID of the credential. A credential is the information used by SSH to access a host.   |
| alias             | String      | No  | Machine1                      | The alias of the host. You can set an alias only when you add a single host.  |
| description       | String      | No  | Test machine                   | The description of the host.  |

**HostBasicData**

|       Parameter       |   Type   | Required |     Example value     |    Description    |
|----------------|--------|----|-------------|----------|
| innerIpAddress | String | Yes  | xxx.xxx.xxx.xxx | The IP address of the host. |
| serialNumber   | String | No  | 6CU4120W67  | The serial number of the host.    |

### Response parameters

**Basic data structure**

|     Parameter      |    Type    |             Description             |
|-------------|----------|----------------------------|
| data        | Object   | The returned data.                      |
| ├─ contents | Array    | The array of TaskInstance objects. For more information, see **TaskInstance data structure**. |
| successful  | Boolean  | Indicates whether the request was successful.                     |
| timestamp   | Datetime | The timestamp when the server completed the request.                |
| duration    | Integer  | The time taken by the server to process the request, in milliseconds.             |
| status      | Integer  | The HTTP status code.       |
| traceId     | String   | The trace ID of the request. This trace ID is used for troubleshooting.        |
| server      | String   | The address of the application server that responded to the request.               |

**TaskInstance data structure**

|        Parameter        |     Type      |    Description       |
|------------------|-------------|-------------|
| id               | Long        | The ID of the software package.     |
| name             | String      | The name of the software package.     |
| clusterId        | Long        | The ID of the cluster.       |
| tenantId         | Long        | The ID of the tenant。。   |
| hostId           | Long        | The ID of the host.     |
| type             | String      | The type of the task. Valid values: <li>MANUAL: a manually initiated O&M task.</li><li>SYS_ONECE: a one-time task executed by the system.</li><li>SCHEDULED: a non-built-in scheduled task.</li><li>SYS_SCHEDULED: a built-in scheduled task executed by the system.</li>               |
| status           | Integer     | The status of the task. Valid values: <li>RUNNING: the task is being executed.</li><li>FAILED: the task failed.</li><li>SUCCESSFUL: the task was executed successfully.</li>    |
| creator          | String      | The username of the task creator.     |
| operation        | String      | The operation to be performed on the task. Valid values: <li>EXECUTE: execute the task normally.</li><li>RETRY: retry the task.</li><li>ROLLBACK: roll back the task.</li><li>SKIP: skip the task.</li><li>CANCEL: cancel the task.</li>    |
| executor         | String      | The address of the node that executes the task.    |
| createTime       | String      | The time when the task was created.    |
| startTime        | String      | The time when the task started.     |
| finishTime       | String      | The time when the task ended.   |
| prohibitRollback | Boolean     | Specifies whether to prohibit rollback.     |
| subtasks         | ObjectArray | The array of SubtaskInstance objects. For more information, see **SubtaskInstance data structure**.   |

**SubtaskInstance data structure**

|     Parameter         |    Type     |      Description     |
|------------------|-----------|----------|
| id               | Long      | The ID of the subtask instance.   |
| name             | String    | The name of the subtask.   |
| seriesId         | Long      | The ID of the subtask sequence.          |
| description      | String    | The description of the subtask.  |
| timeout          | Integer   | The timeout period of the subtask, in seconds.    |
| status           | String    | The status of the subtask. Valid values: <li>PENDING: the initial state. The subtask is waiting for the upstream nodes to complete.</li><li>READY: the subtask is being prepared. The upstream nodes have completed, and the subtask is waiting to be executed.</li><li>RUNNING: the subtask is being executed.</li><li>CANCELING: the subtask is being canceled.</li><li>FAILED: the final state. The subtask failed.</li><li>SUCCESSFUL: the final state. The subtask was executed successfully.</li>   |
| operation        | String    | The operation to be performed on the subtask. Valid values: <li>EXECUTE: execute the subtask normally.</li><li>RETRY: retry the subtask.</li><li>ROLLBACK: roll back the subtask.</li><li>SKIP: skip the subtask.</li><li>CANCEL: cancel the subtask.</li>    |
| executor         | String    | The address of the node that executes the subtask.         |
| runTime          | Integer   | The number of times the subtask was executed.        |
| createTime       | String    | The time when the subtask was created.      |
| startTime        | String    | The time when the subtask started.      |
| finishTime       | String    | The time when the subtask ended.         |
| nodeType         | String    | The type of the node, for example, JAVA_TASK.      |
| paralleIdx       | Integer   | The index of the subtask in the parallel subtask group. -1 indicates that the subtask is not in a parallel subtask group.    |
| upstreams        | LongArray | The IDs of the upstream subtasks.     |
| downstream       | LongArray | The IDs of the downstream subtasks.      |
| prohibitRollback | Boolean   | Specifies whether to prohibit rollback for the subtask.         |
