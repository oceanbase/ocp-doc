Add multiple hosts at a time 
=================================================

## Feature description

Add host information in batches.

## Call instructions

### Interface constraints

The caller must have the HOST_MANAGER privilege.

### Request path

`POST /api/v2/compute/hosts/batchCreate`

### Request parameters

**body:**

|        Parameter         |     Type      | Required |            Example Value             |      Description       |
|-------------------|-------------|------|----------------------------|----------------|
| hostBasicDataList | ObjectArray | Yes  | --                         | Array of HostBasicData objects, containing basic host information. For details, see the **HostBasicData data structure**.    |
| sshPort           | Integer     | Yes  | 22                         | SSH port of the host.    |
| kind              | String      | Yes  | DEDICATED_PHYSICAL_MACHINE | Host type. Valid values: <li>DEDICATED_PHYSICAL_MACHINE: physical host</li><li>DEDICATED_CONTAINER: container</li><li>DEDICATED_ECS: ECS</li>    |
| publishPorts      | StringArray | No   | 8080:8080,8090,8090        | Port mapping. When the host type is a container, you must specify the port mapping between the container and the physical host.  |
| idcId             | Long        | Yes  | 100                        | IDC ID.  |
| typeId            | Long        | Yes  | 1001                       | Host type ID.   |
| credentialId      | Long        | Yes  | 1001                       | Credential ID. The credential is used for SSH access to the host.   |
| alias             | String      | No   | Machine 1                      | Host alias. You can set an alias only when you add a single host.    |
| description       | String      | No   | Test machine                   | Host description.     |

**HostBasicData data structure**

|       Parameter       |   Type   | Required |     Example Value     |    Description    |
|----------------|--------|----|-------------|----------|
| innerIpAddress | String | Yes  | xxx.xxx.xxx.xxx | Host IP address. |
| serialNumber   | String | No   | 6CU4120W67  | Host serial number.    |

**TaskInstance data structure**

|        Parameter        |     Type      |    Description    |
|------------------|-------------|---------|
| id               | Long        | The ID of the software package.    |
| name             | String      | The name of the software package.   |

| status           | Integer     | The task execution status. Valid values: <li>RUNNING: the task is running</li><li>FAILED: the task failed</li><li>SUCCESSFUL: the task succeeded</li>     |
| creator          | String      | The username of the task creator.   |
| operation        | String      | The task operation. Valid values: <li>EXECUTE: normal execution</li><li>RETRY: retry</li><li>ROLLBACK: rollback</li><li>SKIP: skip</li><li>CANCEL: cancel</li>    |
| executor         | String      | The address of the task execution node.   |
| createTime       | String      | The task creation time.   |
| startTime        | String      | The task start time.     |
| finishTime       | String      | The task end time.   |
| prohibitRollback | Boolean     | Indicates whether to allow rollback.   |
| subtasks         | ObjectArray | An array of SubtaskInstance objects. For more information, see **SubtaskInstance data structure**.  |

**SubtaskInstance data structure**

|        Parameter        |    Type     |      Description     |
|------------------|-----------|----------|
| id               | Long      | The ID of the subtask instance.  |
| name             | String    | The name of the subtask.  |
| seriesId         | Long      | The ID of the subtask series. |
| description      | String    | The description of the subtask.  |
| timeout          | Integer   | The timeout period of the subtask, in seconds.     |
| status           | String    | The status of the subtask. Valid values: <li>PENDING: the initial state, waiting for the upstream node to complete execution</li><li>READY: the ready state, where the dependency node has completed execution and is waiting to be executed</li><li>RUNNING: the running state</li><li>CANCELING: the canceling state</li><li>FAILED: the failed state, where the subtask failed</li><li>SUCCESSFUL: the successful state, where the subtask succeeded</li>    |
| operation        | String    | The operation of the subtask. Valid values: <li>EXECUTE: normal execution</li><li>RETRY: retry</li><li>ROLLBACK: rollback</li><li>SKIP: skip</li><li>CANCEL: cancel</li>              |
| executor         | String    | The information of the subtask execution node. |
| runTime          | Integer   | The number of times the subtask is executed.   |
| createTime       | String    | The creation time of the subtask.  |
| startTime        | String    | The start time of the subtask.  |
| finishTime       | String    | The end time of the subtask. |
| nodeType         | String    | The node type, for example, JAVA_TASK. |
| paralleIdx       | Integer   | The parallel subtask index value. -1 indicates that the subtask is not parallel.   |
| upstreams        | LongArray | The list of upstream subtask IDs.   |
| downstream       | LongArray | The list of downstream subtask IDs.     |
| prohibitRollback | Boolean   | Indicates whether to allow rollback for the subtask.      |
