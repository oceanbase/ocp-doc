# Performance statistics of SQL queries

## **Features**

Queries the SQL performance statistics of a tenant and performs SQL performance statistics in the specified time interval. The performance statistics include clusters, tenants, servers, databases, users, SQL_ID, response time, CPU time, execution times, and error counts. You can select **Yes** or **No** to

You can query the performance metrics of a specific SQL by using conditions such as internal SQL, keywords in the SQL text, and advanced search.
**Note**

This API call is time-consuming. If the response is slow, try reducing the query frequency, the time range, or the number of concurrent requests. You can also check the resource usage of the OCP server and monitor database and modify the specifications accordingly.

## **Call instructions**

**Interface constraints**

The caller must have the read permission for the specified tenant.

**Request path**

`GET /api/v2/ob/clusters/{id}/tenants/{tenantId}/topSql`

**Request parameters**

|     Parameter     |    Type    | Required |            Example Value            |      Description     |
|------------|----------|-------|---------------------------|-------|
| id         | Integer  | Yes  | 1                         | The ID of the cluster.    |
| tenantId   | Integer  | Yes  | 1001                      | The ID of the tenant.     |
| startTime  | Datetime | Yes  | 2020-02-16T05:32:16+08:00 | The start time.    |
| endTime    | Datetime | Yes  | 2020-02-16T07:32:16+08:00 | The end time.           |
| serverId   | Integer  | No   | 300                       | The ID of the OceanBase server. If not specified, the SQL is executed on all OceanBase servers.   |
| inner      | Boolean  | No   | false                     | Specifies whether to include internal SQL. Internal SQL is initiated by OceanBase. The default value is false, indicating that internal SQL is not included.     |
| sqlText    | String   | No   | hello                     | The keyword of the SQL. The keyword is case-insensitive.     |
| searchAttr | String   | No   | executions                | The name of the metric for advanced search. The parameters searchOp and searchVal must be specified for the parameter to take effect.  |
| searchOp   | String   | No   | GT                        | The operator for advanced search. The parameters searchAttr and searchVal must be specified for the parameter to take effect. Valid values: <li>EQ: equal to</li><li>NE: not equal to</li><li>GT: greater than</li><li>GE: greater than or equal to</li><li>LT: less than</li><li>LE: less than or equal to</li>    |
| searchVal  | String   | No   | 1543                      | The value for advanced search. The parameters searchAttr and searchOp must be specified for the parameter to take effect. |

  | server      | String   | The address of the server that responds to the request.          |

## **Example**

**Request example**

Query the SQL performance of the cluster with Id 1 and tenant with Id 1001. The time range is from 2020-11-03T19:00:00+08:00 to 2020-11-03T20:00. The advanced search condition is that the number of executions is greater than or equal to 500.

```code
GET /api/v2/ob/clusters/1/tenants/1001/topSql?searchAttr=executions&searchOp=GE&searchVal=500&startTime=2020-11-03T19%3A00%3A00%2B08%3A00&endTime=2020-11-03T20%3A00%3A00%2B08%3A00
```
