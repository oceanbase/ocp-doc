# Query the server list of a zone

## Feature description

This API is used to query the server information in a specified zone of the target OceanBase cluster.

## Call instructions

### Interface constraints

* The caller must have at least read-only permissions on the target OceanBase cluster.

  For more information about the caller's permissions, see [Overview of roles](../../../1600.system-management-features/400.manage-roles/100.roles-overview.md) and [Overview of users](../../../1600.system-management-features/500.manage-users/100.users-overview.md).

* The caller must be authenticated through the OCP application service.

### Request path

`GET /api/v2/clusters/{id}/zones/{zoneName}/servers`

### Request parameters

**path:**

|    Parameter     |   Type    | Required |  Example value  |    Description     |
|-----------|---------|----|-------|-----------|
| id        | Integer | Yes  | 1     | The ID of the target OceanBase cluster. |
| zoneName  | String  | Yes  | zone1 | The name of the zone. |

### Return result

**Basic data structure**

|     Parameter      |    Type    |          Description           |
|-------------|----------|-----------------------|
| data        | Object   | The requested data.                |
| ├─ contents | Array    | The array of server information. The data structure is described in the following table.     |
| successful  | Boolean  | Indicates whether the request is successful.               |
| timestamp   | Datetime | The timestamp when the server finishes the request.          |
| duration    | Integer  | The time taken by the server to process the request, in milliseconds.       |
| status      | Integer  | The HTTP status code that conforms to the HTTP status specification. |
| traceId     | String   | The Trace ID of the request, which is used to troubleshoot issues.  |
| server      | String   | The address of the application service that responds to the request.         |

**Data structure of server information**

|         Parameter          |     Type      |     Description   |
|---------------------|-------------|-------------|
| id                  | Integer     | The ID of the server.   |
| ip                  | String      | The IP address of the server.    |
| port                | Integer     | The RPC port of the server.    |
| sqlPort             | Integer     | The SQL port of the server.   |
| version             | String      | The OceanBase version of the server.      |
| withRootServer      | Boolean     | Indicates whether the server is equipped with a Root Service.     |
| status              | String      | The status of the server. Valid values: <li>CREATING: The server is being created.</li><li>RUNNING: The server is running.</li><li>STOPPING: The server is being stopped.</li><li>STOPPED: The server is stopped.</li><li>STARTING: The server is being started.</li><li>RESTARTING: The server is being restarted.</li><li>DELETING: The server is being deleted.</li><li>UNAVAILABLE: The server is unavailable.</li><li>OPERATING: The server is under maintenance.</li><li>DELETED: The server is deleted. </li>    |
| updateTime          | Datetime    | The last update time of the server.     |
| clusterId           | Integer     | The ID of the cluster to which the server belongs.   |
| zoneName            | String      | The name of the zone to which the server belongs.       |
| regionName          | String      | The name of the region to which the server belongs.       |
| idcName             | String      | The name of the IDC to which the server belongs.    |
| hostId              | Integer     | The ID of the server's host.    |
| hostTypeName        | String      | The type of the server's host.    |
| startTime           | Datetime    | The start time of the server.     |
| stopTime            | Datetime    | The stop time of the server.      |
| availableOperations | StringArray | The list of available operations for the server.   |

### Request example

Obtain the list of all servers in the zone1 zone of cluster 1.

`GET /api/v2/ob/clusters/1/zones/zone1/servers`
