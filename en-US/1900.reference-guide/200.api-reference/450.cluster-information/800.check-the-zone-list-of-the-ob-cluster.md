# View the zone list of an OceanBase cluster

## Feature description

This interface is used to query the zone list of an OceanBase cluster.

## Call instructions

### Interface constraints

* The caller must have the permission to view OceanBase clusters.

  For more information about the permissions of the caller, see [Overview of roles](../../../1600.system-management-features/400.manage-roles/100.roles-overview.md) and [Overview of users](../../../1600.system-management-features/500.manage-users/100.users-overview.md).

* The caller must be authenticated through OCP application services.

### Request path

`GET /api/v2/ob/clusters/{id}/zones`

### Request parameters

**path:**

| Parameter |   Type    | Required | Example value |               Description               |
|----|---------|----|-----|--------------------------------|
| id | Integer | Yes  | 100 | The ID of the OceanBase cluster whose zones are to be queried. |

### Return result

**Basic data structure**

|        Parameter        |    Type    |          Description           |
|------------------|----------|-----------------------|
| data             | Object   | The requested data.                |
| ├─ contents      | Array    | An array of zones. For more information, see the following table.   |
| ├─ page          | Object   | Paging information.                 |
| ├─ totalElements | Integer  | The total number of records.                 |
| ├─ totalPage     | Integer  | The total number of pages.                  |
| ├─ number        | Integer  | The current page number.                 |
| ├─ size          | Integer  | The size of the current page.                |
| successful       | Boolean  | Indicates whether the request is successful.               |
| timestamp        | Datetime | The timestamp when the server finishes the request.          |
| duration         | Integer  | The time taken by the server to process the request, in milliseconds. |
| status           | Integer  | An HTTP status code that conforms to the HTTP status specification. |
| traceId          | String   | The trace ID of the request, which is used to troubleshoot problems.  |
| server           | String   | The address of the application service that responds to the request.         |

**Zone data structure**

|     Parameter      |   Type    |        Description        |
|-------------|---------|------------------|
| name        | String  | The name of the zone.           |
| idcName     | String  | The name of the IDC to which the zone belongs.            |
| regionName  | String  | The region to which the zone belongs.             |
| servers     | Array   | The list of servers. For more information, see the following table.        |
| clusterId   | Long    | The ID of the cluster in OCP.            |
| obClusterId | Long    | The ID of the cluster in OceanBase. |
| serverCount | Integer | The number of servers.         |
| hostCount   | Integer | The number of hosts.              |

**Server data structure**

|       Parameter       |    Type    |       Description        |
|----------------|----------|-----------------|
| id             | String   | The OBServer ID.    |
| ip             | String   | The OBServer IP.    |
| port           | Integer  | The port.              |
| sqlPort        | Integer  | The SQL port.           |
| version        | String   | The version.              |
| withRootserver | Boolean  | Indicates whether the RootService is included. |
| status         | String   | The status.              |
| clusterId      | Long     | The ID of the cluster in OCP.          |
| zoneName       | String   | The name of the zone to which the server belongs.        |
| regionName     | String   | The region to which the server belongs.            |
| idcName        | String   | The IDC to which the server belongs.            |
| hostId         | Long     | The ID of the host corresponding to the server.          |
| hostTypeName   | String   | The host type.            |
| startTime      | DateTime | The start time.            |
| stopTime       | DateTime | The stop time.            |
