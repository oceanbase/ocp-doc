# Delete a zone from an OceanBase cluster

## Description

This topic describes how to delete a zone from an OceanBase cluster.

## Considerations

### Limitations

* The user must have the management permissions on the target OceanBase cluster.

  For more information about the permissions of the user, see [Overview of roles](../../../1600.system-management-features/400.manage-roles/100.roles-overview.md) and [Overview of users](../../../1600.system-management-features/500.manage-users/100.users-overview.md).

* The user must be authenticated by using OCP application services.

### Request path

`DELETE /api/v2/ob/clusters/{id}/zones/{zoneName}`

### Request parameters

**path:**

|    Parameter    |   Type    | Required | Example value |             Description              |
|----------|---------|----|-----|-----------------------------|
| id       | Integer | Yes  | 1   | The ID of the OceanBase cluster that contains the zone to be deleted. |
| zoneName | String  | Yes  | 1   | The name of the zone to be deleted.                |

### Response

**Basic data structure**

|     Parameter     |    Type    |                                Description                                |
|------------|----------|------------------------------------------------------------------|
| data       | Object   | The asynchronous task information. For more information, see [Task information](../400.task-return-structure.md). |
| successful | Boolean  | Indicates whether the request is successful.                                                          |
| timestamp  | Datetime | The timestamp when the server finishes processing the request.                                                     |
| duration   | Integer  | The time taken by the server to process the request, in milliseconds.                                                  |
| status     | Integer  | The HTTP status code that conforms to the HTTP status code specification.                                            |
| traceId    | String   | The Trace ID of the request, which is used to troubleshoot issues.                                             |
| server     | String   | The address of the application service that responds to the request.                                                    |
