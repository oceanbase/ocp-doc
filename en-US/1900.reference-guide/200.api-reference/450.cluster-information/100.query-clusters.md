# Query cluster list

## Feature description

This interface is used to query the information of OceanBase clusters managed by OCP.

You can specify the query scope based on conditions such as the cluster name and status. In the primary/standby deployment mode, the response contains both the primary and standby clusters. You can identify the role of each cluster based on its attributes.

## Call instructions

### Interface constraints

* The caller must be at least the CLUSTER_VIEWER role.

* The caller must be authenticated through OCP application services.

### Request path

`GET /api/v2/ob/clusters`

### Request parameters

**body:**

|     Parameter      |     Type      | Required |       Example Value        |  Description     |
|-------------|-------------|------|------------------|-------------|
| page        | Integer     | No  | 1                | The page number of the requested data. The value starts from 1. Default value: 1.    |
| size        | Integer     | No  | 10               | The size of the requested data. Default value: 10, maximum value: 2000.     |
| sort        | String      | No  | name,asc         | The sorting rules for the requested data.    |
| name        | String      | No  | foo              | The keyword for the cluster name, which is case-insensitive.    |
| status      | StringArray | No  | CREATING,RUNNING | The status of the cluster. Valid values: <li>RUNNING: running. </li><li>CREATING: being created. </li><li>DELETING: being deleted. </li><li>STARTING: starting. </li><li>RESTARTING: restarting. </li><li> STOPPING: stopping. </li><li>STOPPED: stopped. </li><li>TAKINGOVER: takeover. </li><li>MOVINGOUT: migrating out. </li><li>SWITCHOVER: primary-standby cluster switchover. </li><li>FAILOVER: standby cluster fault recovery. </li><li> OPERATING: under maintenance. </li>    |
| withStandby | -     | -  | -             | This parameter is deprecated and will be removed from the environment.    |

### Response

|        Parameter        |    Type    |            Description            |
|------------------|----------|--------------------------|
| data             | Object   | The data structure of an ObCluster. For more information, see the following table. |
| ├─ contents      | Array    | An array of cluster information (including primary and standby clusters). For more information, see the following table. |
| ├─ page          | Object   | The pagination information.                    |
| ├─ totalElements | Integer  | The total number of records.                    |
| ├─ totalPage     | Integer  | The total number of pages.                     |
| ├─ number        | Integer  | The current page number.                    |
| ├─ size          | Integer  | The size of the current page.                   |
| successful       | Boolean  | Indicates whether the request is successful.                  |
| timestamp        | Datetime | The timestamp when the server completes the request.             |
| duration         | Integer  | The time taken by the server to process the request, in milliseconds.          |
| status           | Integer  | The HTTP status code that conforms to the HTTP status specification.    |
| traceId          | String   | The Trace ID of the request, which is used to troubleshoot problems.     |
| server           | String   | The address of the application service that responds to the request.            |

**Data structure of an ObCluster**

|           Parameter            |    Type    |      Description     |
|-------------------------|----------|---------------|
| primaryCluster          | Object   | The primary cluster of the current cluster.     |
| standbyClusters         | Array    | The array of standby clusters of the current cluster.       |
| id                      | Integer  | The ID of the cluster in OCP.        |
| name                    | String   | The name of the cluster.       |
| obClusterId             | Integer  | The ID of the cluster in OceanBase.         |
| obVersion               | String   | The version of the cluster.      |
| status                  | String   | The status of the cluster. Valid values: <li>RUNNING: The cluster is running. </li><li>CREATING: The cluster is being created. </li><li>DELETING: The cluster is being deleted. </li><li>STARTING: The cluster is being started. </li><li>RESTARTING: The cluster is being restarted. </li><li> STOPPING: The cluster is being stopped. </li><li>STOPPED: The cluster is stopped. </li><li> TAKINGOVER: The cluster is being taken over. </li><li>MOVINGOUT: The cluster is being migrated out. </li><li>SWITCHOVER: The primary and standby clusters are being switched. </li><li>FAILOVER: The standby cluster is being restored. </li><li>OPERATING: The cluster is under maintenance. </li>   |
| regionCount             | Integer  | The number of regions.     |
| rootServers             | Array    | The information about the root servers.    |
| ├─ address              | String   | The address of the root server, in the `IP:Port` format.       |
| ├─ role                 | String   | The role of the root server. Valid values: <li>LEADER: Leader </li><li>FOLLOWER: Follower </li>    |
| ├─ sql_port             | Integer  | The SQL port.    |
| type                    | String   | The cluster type. Valid values: <li>PRIMARY: Primary cluster </li><li>STANDBY: Standby cluster </li>      |
| regionCount             | Integer  | The number of regions.          |
| tenantCount             | Integer  | The number of tenants.    |
| partitionCount          | Integer  | The number of partitions.      |
| serverCount             | Integer  | The number of OBServer nodes.      |
| delayTime               | Float    | The lag of the standby cluster, in seconds.    |
| syncStatus              | String   | The primary-standby synchronization status. Valid values: <li>VALID: Valid status </li><li>DISABLED: Synchronization is disabled. </li><li>SYNCHRONIZING: Synchronization is in progress. </li>    |
| zones                   | Array    | The list of zones.        |
| createTime              | DateTime | The creation time.      |
| updateTime              | DateTime | The update time.       |
| creator                 | String   | The creator.        |
| deadLockDetectionEnabled | Boolean | Indicates whether to enable automatic deadlock detection. |
| failToQueryFromObReason | String   | The additional failure reason when the cluster cannot be accessed.      |

**Data structure of a zone**

|     Parameter      |   Type    |      Description       |
|-------------|---------|---------------|
| name        | String  | The name of the zone.       |
| idcName     | String  | The name of the IDC where the zone is located.        |
| regionName  | String  | The region where the zone is located.         |
| servers     | Array   | The list of servers.    |
| clusterId   | Long    | The ID of the cluster in OCP.        |
| obClusterId | Long    | The ID of the cluster in OceanBase. |
| serverCount | Integer | The number of servers.     |
| hostCount   | Integer | The number of hosts.          |
