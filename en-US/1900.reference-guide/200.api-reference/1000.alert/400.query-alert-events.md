# Query alert events
## **Feature description**

Query detailed information about a specified alert event.
## **API details**

### Constraints

The caller must have read permission for the alert feature.
### Request path

`GET /api/v2/alarm/alarms/{id}`

### Request parameters

**path:**

### Response parameters

**Basic data structures**

| Name | Type | Example value | Description |

| ---- | ------- | ------ | ------------- |
| id | Integer | 1023 | The ID of the alert event. |
**Alert Event Data Structure**

| Parameter | Type | Description |

| ---------------- | -------- | ------------------------------------------ |

| data | Object | List of alert events. For more information, see **Alert event data structure**. |
| successful | Boolean | Whether the request was successful. |
| timestamp | Datetime | The timestamp when the server completed the request. |
| duration | Integer | The time taken by the server to process the request, in milliseconds. |
| status | Integer | An encoding that complies with the HTTP Status specification. |
| traceId | String | The trace ID of the request, used for troubleshooting. |
| server | String | The address of the server that responded to the request. |
### Request example
| Parameter | Type | Description |

| ----------- | -------- | ------------ |

| id | Integer | The ID of the alert event. |
| appType | String | Application category (alert source). Valid values: <li>OceanBase</li><li>OCP</li><li>OMS</li><li>OBProxy</li><li>Log</li> |
| alarmType | String | Alert type. |
| scope | String | Alert scope. Valid values: <li>Cluster</li><li>Tenant</li><li>Host</li><li>Service</li><li>Arbitration</li><li>Backup</li><li>OceanBaseLog</li><li>OBProxyLog</li><li>HostLog</li> |
| level | Integer | The alert levels \[1\~5\] correspond to: Down, Critical, Alert, Caution, and Info. |
| status | String | Alert status. Valid values: <li>Active</li><li>Inactive</li><li>Silenced</li><li>Inhibited</li> |
| target | String | The target object of an alert event, generated based on the target template specified in the alert rule. |
| summary | String | An overview of the alert event, generated based on the overview template of the alert rule. |
| description | String | The details of an alert event are generated based on the details template of the alert rule. |
| activeAt | Datetime | The time when the alert event was generated. |
| resolvedAt | Datetime | The time when the alert event was cleared. |
| updatedAt | Datetime | The update time of the alert event. |
| labels | Object | The tag and value of the alert event. |
