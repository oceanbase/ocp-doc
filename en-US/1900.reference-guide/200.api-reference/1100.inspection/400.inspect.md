# Initiate an inspection

## Overview

You can call this API to initiate an inspection for a specified object.

## API details

### Constraints

You have passed the authentication for the OCP application service.

### Request path

`POST /api/v2/inspection/run`

### Request parameters

**query:**

|  Parameter  |  Type  |  Required  |  Example value  |  Description  |
|--------|--------|--------|----------|--------|
|  inspectionObjectType  |  String  |  No  |  OB_CLUSTER  |  The type of the inspection object. Valid values: <li>OB_CLUSTER: cluster.</li><li>OB_TENANT: tenant.</li><li>HOST: host.</li><li>OB_PROXY: OBProxy.</li> |
|  objectIds  |  Array   |  No  |  1002  |  The ID of the inspection object in OCP, such as the ID of a cluster or tenant. Separate multiple IDs with commas (,). |
|  tag        |  Integer |  Yes  |  1  |  The ID of the inspection scenario. Valid values: <li>1: basic inspection.</li><li>2: performance inspection.</li><li>3: deep inspection.</li><li>4: installation inspection.</li> |

### Response parameters

**Basic data structure**

|  Parameter  |  Type  |  Description  |
|--------|--------|--------|
|  data  |  Object  |  The data returned from the API.  |
|  ├─ contents |  Array    | The information about the asynchronous task. For more information, see [Task information](../400.task-return-structure.md).    |
|  successful  |  Boolean |  Indicates whether the request was successful. |
|  timestamp |  Datetime  |  The timestamp when the server completed the request.  |
|  duration |  Integer  |  The time taken by the server to process the request, in milliseconds.  |
|  status |  Integer  |  The HTTP status code.  |
|  traceId |  String  |  The trace ID of the request. This trace ID is used for troubleshooting.  |
|  server  |  String  |  The address of the application server that responded to the request.  |

### Request example

```json
POST /api/v2/inspection/run?inspectionObjectType=OB_CLUSTER&tag=1
```
