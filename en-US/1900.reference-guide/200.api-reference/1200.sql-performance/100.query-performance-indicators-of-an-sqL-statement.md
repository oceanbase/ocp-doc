# Performance statistics of SQL queries

## **<UI-TERM key="ocp-v2.Tenant.New.ServiceName.Description">Function Description</UI-TERM>**

Queries the SQL performance statistics of a tenant within a specified time interval. The performance statistics include the cluster, tenant, server, database, user, SQL ID, response time, CPU time, execution count, and error count. You can query the performance metrics of a specific SQL statement based on conditions such as **whether the SQL statement is internal, keywords in the SQL text, or advanced search**.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>This API call is time-consuming. If the response time is long, you can reduce the query frequency, query time range, or number of concurrent requests. You can also check the resource usage of the OCP server and Monitor DB and adjust the specifications as needed.</p>
  </main>

## **Call instructions**

**Interface constraints**

The caller must have the read privilege on the specified tenant.

**Request path**

`GET /api/v2/ob/clusters/{clusterId}/tenants/{tenantId}/topSql`

**Request parameters**

|     Parameter     |    Type    | Required |            Example Value            |                                                                                                                                                                                      Description                                                                                                                                                                                       |
|------------|----------|----|---------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| clusterId  | Integer  | Yes  | 1                         | The ID of the cluster                                                                                                                                                                                                                                                                                                                                                                        |
| tenantId   | Integer  | Yes  | 1001                      | The ID of the tenant                                                                                                                                                                                                                                                                                                                                                                        |
| startTime  | Datetime | Yes  | 2020-02-16T05:32:16+08:00 | The start time                                                                                                                                                                                                                                                                                                                                                                          |
| endTime    | Datetime | Yes  | 2020-02-16T07:32:16+08:00 | The end time                                                                                                                                                                                                                                                                                                                                                                          |
| serverId   | Integer  | No   | 300                       | The ID of the OceanBase server on which the SQL statement is executed. If this parameter is not specified, the SQL statements are executed on all OceanBase servers.                                                                                                                                                                                                                                                                                                                               |
| inner      | Boolean  | No   | false                     | Specifies whether to include internal SQL statements. Internal SQL statements are initiated by OceanBase Database. The default value is false, which specifies not to include internal SQL statements.                                                                                                                                                                                                                                                   |
| sqlText    | String   | No   | hello                     | The keywords of the SQL statement. The keywords are case-insensitive.                                                                                                                                                                                                                                                                                    |
| searchAttr | String   | No   | executions                | The name of the metric for advanced search. This parameter takes effect only when both searchOp and searchVal are specified.                                                                                                                                                                                                                                                                                                                                     |

Valid values: <li>EQ: equals</li><li>NE: not equal</li><li>GT: greater than</li><li>GE: greater than or equal to</li><li>LT: less than</li><li>LE: less than or equal to</li>    |
| searchVal  | String   | No   | 1543                      | The value for advanced search. This parameter takes effect only when both searchAttr and searchOp are specified.                                                                                                                                                                                                                                                                                                                                     |

## **Examples**

**Request example**

Query the SQL performance of the cluster with ID 1 and tenant ID 1001. The time range is from 2020-11-03T19:00:00+08:00 to 2020-11-03T20:00. Specify the advanced search condition: the number of executions is greater than or equal to 500.

```code
GET /api/v2/ob/clusters/1/tenants/1001/topSql?searchAttr=executions&searchOp=GE&searchVal=500&startTime=2020-11-03T19%3A00%3A00%2B08%3A00&endTime=2020-11-03T20%3A00%3A00%2B08%3A00
```
