# Query SQL performance statistics
## **<UI-TERM key="ocp-v2.Tenant.New.ServiceName.Description">Description</UI-TERM>**



Query the SQL performance statistics of a tenant, which are aggregated over a specified time interval. The performance data includes information such as cluster, tenant, server, database, user, SQL_ID, response time, CPU time, execution count, and error count. You can filter specific SQL performance metrics by conditions such as **Internal SQL or Not**, **Keywords in the SQL Text**, and **Advanced Search**.
<main id="notice" type='explain'>

<h4>Note</h4>


  <p>This API is time-consuming for queries. If the response time is long, appropriately reduce the query frequency, the time range of the query, or the number of concurrent requests. You can also monitor the resource usage of OCP Server and MonitorDB, and adjust their specifications as needed.</p>
    </main>
    ## **API details**
  **Constraints**

You must have read permission for the specified tenant.
**Request path**

`GET /api/v2/ob/clusters/{clusterId}/tenants/{tenantId}/topSql`

