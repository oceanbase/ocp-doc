Query the operator structure of an execution plan 
======================================================================

## **<UI-TERM key="ocp-v2.Tenant.New.ServiceName.Description">Function Description</UI-TERM>**

Queries the operator structure of an execution plan. The result set contains ordered operator information in a tree structure.

## **Call instructions**

**Interface constraints**

The caller must have the read permission on the specified tenant.

**Request path**

`GET /api/v2/cluters/{id}/tenants/{tenantId}/plans/{uid}/explain`

**Request parameters**

|    Parameter     |    Type    | Required |               Example Value                |   Description    |
|-----------|----------|----|----------------------------------|---------|
| id        | Integer  | Yes  | 1                                | Cluster ID.  |
| tenantId  | Integer  | Yes  | 1001                             | Tenant ID.  |
| uid       | String   | Yes  | AAAAAAAAAAEAAAAAAAKOvgAFs1_j8s3i | Plan UID. |
| startTime | Datetime | Yes  | 2020-02-16T05:32:16+08:00        | Start time.    |
| endTime   | Datetime | Yes  | 2020-02-16T07:32:16+08:00        | End time.    |

**Return result**

Basic data structure

|        Parameter         |    Type    |          Description           |
|-------------------|----------|-----------------------|
| data              | Object   | The requested data.                |
| ├─ data | Array    | An array of execution plan operators. The data structure of an execution plan operator is described in Table 1. |
| ├─ notEmpty | Boolean    | Plan Explain. |
| ├─ planOperationSummery | Array    | An array of operation lists. The data structure of an operation list is described in Table 2. |
| ├─ rootOperations | Array    | An array of operation operators. The data structure of an operation operator is described in Table 3. |
| successful        | Boolean  | Indicates whether the request is successful.               |
| timestamp         | Datetime | The timestamp indicating the time when the server finishes processing the request.          |
| duration          | Integer  | The time taken by the server to process the request, in milliseconds.       |
| status            | Integer  | An HTTP status code that conforms to the HTTP standard. |
| traceId           | String   | The Trace ID of the request, which is used to troubleshoot problems.  |
| server            | String   | The address of the application service that responds to the request.         |

Data structure of an execution plan operator

|        Parameter         |    Type    |          Description           |
|-------------------|----------|-----------------------|
| ClusterName     | String | The name of the cluster.                  |
| CollectTimeUs   | Long   | The time when the plan is collected, in microseconds.  |
| Cost            | Integer    | The cost of the operator.         |
| CreateTime      | String | The creation time.                |
| FirstLoadTimeUs | Long   | The time when the plan is first loaded, in microseconds.  |
| Id              | Long   | The operator ID.  |
| ObClusterId     | Long   | The OceanBase cluster ID.  |
| ObServerId      | Long   | The server ID of the OceanBase endpoint.  |
| ObTenantId      | Long   | The OceanBase tenant ID.  |
| ObjectName      | String | The name of the operation target.  |
| Operator        | String | The logical operator.  |
| PlanId          | Long   | The execution plan ID.  |
| PlanUnionHash   | String | The unique identifier of the plan, which is calculated based on the operations and targets of the plan.  |
| Property        | String | The output and filtering of the operation.  |
| Rows            | Long   | The estimated number of rows.  |

Data structure of an operation list

|     Parameter     |   Type    |      Description      |
|------------|---------|--------------|
| operator   | String  | The logical operator.       |
| objectName | String  | The operation target. |

Data structure of an operation operator

|     Parameter     |   Type    |      Description      |
|------------|---------|--------------|
| operator   | String  | The name of the operator.       |
| objectName | String  | The operation target, which is generally the name of a table. |
| rows       | Integer | The number of rows operated.      |
| cost       | Integer | The cost of the operation.       |
| property   | String  | The output and filtering of the operation.    |
| children   | Array   | An array of child operators.      |
