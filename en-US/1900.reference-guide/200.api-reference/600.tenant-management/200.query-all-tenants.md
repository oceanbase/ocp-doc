# Query all tenants

## Description

You can call this operation to query all tenants.

## Call description

### Prerequisites

* You have passed the authentication for the OceanBase Cloud Platform (OCP) application service.

* Only the tenants in the clusters that you have the read permission are returned.

### Request path

`GET /api/v2/ob/tenants`

### Request parameters

| Parameter | Type | Required | Example value | Description |
|----------|-------------|------|----------|------------------|
| page     | Integer     | No | 1 | The number of the page to return. The value starts from 1. Default value: 1.      |
| size | Integer | No | 10 | The number of records to return on each page. Default value: 10. Maximum value: 2000.      |
| sort | String | No | name,asc | The rule for sorting the requested data.        |
| name     | String      | No   | foo      | The keyword in the names of the tenants to query, which is case-insensitive.      |
| mode     | StringArray | No   | ORACLE   | The mode of the tenants to query. Valid values: <li>ORACLE </li><li>MYSQL </li>     |
| locked   | Boolean     | No   | false    | Specifies whether to query only locked tenants. Valid values: <li>If you do not specify this parameter, all tenants are queried. </li><li>If you set the value to `true`, only locked tenants are queried. </li><li>If you set the value to `false`, only unlocked tenants are queried. </li> |
| clusterName  | String   | No   | cluster1   | The name of the cluster.   |
| readonly | Boolean     | No   | false    | Specifies whether to query only tenants in the read-only state. Valid values: <li>If you do not specify this parameter, all tenants are queried. </li><li>If you set the value to `true`, only tenants in the read-only state are queried. </li><li>If you set the value to `false`, only tenants not in the read-only state are queried. </li> |
| status   | StringArray | No   | NORMAL   | The status of the tenants to query. Valid values: <li>NORMAL </li><li>CREATING </li><li>MODIFYING </li><li>DELETING </li> |
| withRemote | Enum | No | NONE | Specifies whether to query OceanBase Database tenants managed by remote OCP clusters. This parameter takes effect only if you have deployed OCP in multi-cluster mode. Valid values: <li>NONE: Query none of them. </li><li>ALL: Query all of them. </li><li>RELATED: Query local tenants and the remote tenants that are in a primary/standby relationship with local tenants. </li>   |
| tagId    | Array       | No   | -         | The IDs of the tags.   |

## Examples

### Sample request

Query tenants that are running or being created, and whose names contain the keyword "foo". Return only the second page, with a page size of 10.

```json
GET /api/v2/ob/tenants?name=foo&status=NORMAL,CREATING&page=2&size=10
```
