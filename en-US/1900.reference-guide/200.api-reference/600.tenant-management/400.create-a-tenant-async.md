# Create a tenant

## Feature description

The interface used to create a single tenant under the specified cluster.

## Call instructions

### Interface constraints

The caller needs to be authenticated through the OCP application service.

### Request path

`POST /api/v2/ob/clusters/{id}/tenants/createTenant`

### Request parameters

**path:**

| Parameter |   Type    | Required | Example value |  Description   |
|------|---------|------|------|-------|
| id | Integer | Yes  | 2000017   | The cluster ID in OCP. |
