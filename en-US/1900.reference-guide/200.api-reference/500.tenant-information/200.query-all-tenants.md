# Query all tenant list

## Feature description

Queries the list of all tenants.

## Call instructions

### Interface constraints

* The caller must be authenticated through the OCP application service.

* Only tenants with cluster read permissions are returned.

### Request path

`GET /api/v2/ob/tenants`

### Request parameters

**body:**

|    Parameter    |     Type      | Required |   Example Value    |        Description         |
|----------|-------------|-------|----------|------------------------|
| page     | Integer     | No  | 1        | The page number of the requested data. The value starts from 1. Default value: 1.        |
| size     | Integer     | No  | 10       | The size of the requested data. Default value: 10, maximum value: 2000.     |
| sort     | String      | No  | name,asc | The sorting rule for the requested data.    |
| name     | String      | No  | foo      | The name of the tenant to query, which is case-insensitive.       |
| mode     | StringArray | No  | ORACLE   | The mode of the tenant to query.<li>ORACLE: Oracle mode</li><li>MYSQL: MySQL mode</li>     |
| locked   | Boolean     | No  | false    | The lock status of the tenant to query.<li>If not specified, all tenants are queried.</li><li>If the value is `true`, only tenants in the locked state are queried.</li><li>If the value is `false`, only tenants not in the locked state are queried.</li>     |
| readonly | Boolean     | No  | false    | The read-only status of the tenant to query.<li>If not specified, all tenants are queried.</li><li>If the value is `true`, only tenants in the read-only state are queried.</li><li>If the value is `false`, only tenants not in the read-only state are queried.</li>   |
| status   | StringArray | No  | NORMAL   | The status of the tenant to query.<li>NORMAL: Running</li><li>CREATING: Creating</li><li>MODIFYING: Modifying</li><li>DELETING: Deleting</li>    |

### Return result

**Basic data structure**

|        Parameter        |    Type    |          Description          |
|------------------|----------|----------------------|
| data             | Object   | The business data requested.              |
| ├─ contents      | Array    | A list of tenant information. Details are provided in **Tenant data structure**.   |
| ├─ page          | Object   | The pagination information.                 |
| ├─ totalElements | Integer  | The total number of records.                 |
| ├─ totalPage     | Integer  | The total number of pages.                  |
| ├─ number        | Integer  | The current page number.                 |
| ├─ size          | Integer  | The size of the current page.                |
| successful       | Boolean  | Indicates whether the request succeeded.               |
| timestamp        | Datetime | The timestamp when the server completes the request.          |
| duration         | Integer  | The time taken by the server to process the request, in milliseconds.       |
| status           | Integer  | The HTTP status code that conforms to the HTTP status specification. |
| traceId          | String   | The Trace ID of the request, which is used to troubleshoot issues.  |
| server           | String   | The address of the server that responds to the request.          |

**Tenant data structure**

|     Parameter      |    Type    |       Description    |
|-------------|----------|--------------|
| id          | Integer  | The ID of the tenant.    |
| name        | String   | The name of the tenant.      |
| clusterName | String   | The name of the cluster to which the tenant belongs.     |
| clusterId   | Integer  | The ID of the cluster to which the tenant belongs in OCP.       |
| obClusterId | Integer  | The ID of the cluster to which the tenant belongs in OceanBase.    |
| clusterType | String   | The type of the cluster to which the tenant belongs. Valid values: <li>PRIMARY: the primary cluster</li><li>STANDBY: the standby cluster</li>     |
| syncStatus  | Enum     | The primary/standby synchronization status. Valid values: <li>VALID: valid</li><li>DISABLED: data synchronization is disabled</li><li>DISABLED_WITH_READ_ONLY: read-only</li><li>SYNCHRONIZING: synchronizing (OceanBase does not support this status)</li><li>UNKNOWN: unknown</li>  |
| mode        | String   | The mode of the tenant. Valid values: <li>ORACLE: Oracle mode</li><li>MYSQL: MySQL mode</li>    |
| createTime  | Datetime | The creation time of the tenant.   |
| primaryZone | String   | The zone priority of the tenant.     |
| zoneList    | String   | The zone list of the tenant.      |
| locality    | String   | The replica distribution of the tenant.     |
| status      | String   | The status of the tenant. Valid values: <li>NORMAL: running</li><li>CREATING: being created</li><li>MODIFYING: being modified</li><li>DELETING: being deleted</li>    |
| locked      | Boolean  | Indicates whether the tenant is locked.     |
| readonly    | Boolean  | Indicates whether the tenant is in read-only mode.     |
| obVersion   | String   | The OceanBase version of the cluster to which the tenant belongs.      |
| description | String   | The description of the tenant.     |

## Examples

### Request example

Query the list of tenants whose names contain the keyword "foo" and whose status is either "Running" or "Creating". When the request is paginated with a page size of 10, the data of the second page.

```json
GET /api/v2/ob/tenants?name=foo&status=NORMAL,CREATING&page=2&size=10
```
