# Create a tenant (deprecated)

## Description

The interface for creating a single tenant under the specified cluster.

## Call instructions

### Interface constraints

The caller needs to be authenticated through the OCP application service.

### Request path

`POST /api/v2/ob/clusters/{id}/tenants`

### Request parameters

**path:**

| Parameter |   Type    | Required | Example value |  Description   |
|----|---------|----|-----|-------|
| id | Integer | Yes  | 1   | The ID of the cluster to which the target tenant belongs. |

**body:**

|        Parameter        |   Type    | Required |        Example value         |         Description      |
|------------------|---------|-------|--------------------|--------------|
| name             | String  | Yes  | foo                | The tenant name, which must be unique in the cluster.    |
| mode             | String  | No  | MYSQL              | The tenant compatibility mode. Valid values: <li>ORACLE</li><li>MYSQL</li>    |
| primaryZone      | String  | No  | zone1,zone2;zone3  | The zone priority.  |
| charset          | String  | No  | utf8mb4            | The character set. Valid values: <ul><li>ORACLE mode: <ul><li>utf8mb4</li><li>gbk</li><li>gb18030 </li></ul></li><li> MYSQL mode: <ul><li>binary</li><li>utf8mb4</li><li>gbk</li><li>gb18030</li></ul></li></ul> Default value: utf8mb4     |
| collation        | String  | No  | utf8mb4_general_ci | The collation. Valid values: <ul><li>binary</li><li>utf8mb4</li><li>gbk</li><li>gb18030</li></ul> Default value: utf8mb4_general_ci.<blockquote>**<UI-TERM key="ocp-v2.component.RecentCompaction.Description">Description</UI-TERM>**</br>ORACLE tenants do not support this parameter. </blockquote>   |
| description      | String  | No  | bar                | The tenant description.   |
| whitelist        | String  | No  | %                  | Valid formats: <li>IP address, for example, xxx.xxx.xxx.1,xxx.xxx.xxx.2</li><li>Subnet mask, for example, xxx.xxx.xxx.3/24 </li><li>Wildcard match, for example, xxx.xxx.xxx.% or xxx.xxx.xxx.\_</li><li>Mixed formats, for example, xxx.xxx.xxx.1,xxx.xxx.xxx.2,xxx.xxx.xxx.%,xxx.xxx.xxx._,xxx.xxx.xxx.3/24 </li><blockquote>**<UI-TERM key="ocp-v2.Alarm.Template.Description">Description</UI-TERM>**</br>% indicates that all clients can connect. The default value is %. </blockquote>|
| rootPassword     | String  | Yes  |                    | The administrator password. <li>ORACLE tenant: SYS user </li><li>MYSQL tenant: root user </li><li>Password requirements: 8 to 32 characters long, and must contain at least three of the following four types: numbers (0-9), uppercase letters (A-Z), lowercase letters (a-z), and special characters. | zones            | Array   | Yes  | --                 | --  |
| ├─name           | String  | Yes  | zone1              | The zone name in the cluster.   |
| ├─replicaType    | String  | Yes  | FULL               | Valid values: <li>FULL</li><li>LOGONLY</li><li>READONLY</li>  |
| ├─resourcePool   | Object  | Yes  |                    | The resource pool.  |
| ├─unitSpecName   | String  | Yes  | S1                 | View the specification list on the "Unit Specification Management" page.   |
| ├─unitCount      | Integer | Yes  | 1                  | The number of units.  |

### Return result

**Basic data structure**

|     Parameter     |    Type    |          Description           |
|------------|----------|-----------------------|
| data       | Object   | The information of the created tenant. For more information, see **Tenant data structure**.            |
| successful | Boolean  | Indicates whether the request is successful.               |
| timestamp  | Datetime | The timestamp when the server finishes the request.          |
| duration   | Integer  | The time taken by the server to process the request, in milliseconds.       |
| status     | Integer  | The HTTP status code that conforms to the HTTP status specification. |
| traceId    | String   | The Trace ID of the request, which is used to troubleshoot issues.  |
| server     | String   | The address of the application service that responds to the request.         |

**Tenant data structure**

|     Parameter      |    Type    |     Description       |
|-------------|----------|----------|
| id          | Long     | The ID of the tenant.  |
| name        | String   | The name of the tenant.  |
| clusterName | String   | The name of the cluster to which the tenant belongs.    |
| clusterId   | Integer  | The ID of the cluster to which the tenant belongs in OCP.       |
| obClusterId | Integer  | The ID of the cluster to which the tenant belongs in OceanBase.    |
| clusterType | String   | The type of the cluster to which the tenant belongs. Valid values: <li>PRIMARY: a primary cluster</li><li>STANDBY: a standby cluster</li>     |
| mode        | String   | The mode of the tenant. Valid values: <li>ORACLE: Oracle mode</li><li>MYSQL: MySQL mode</li>    |
| createTime  | Datetime | The creation time of the tenant.   |
| primaryZone | String   | The zone priority of the tenant.     |
| zoneList    | String   | The zone list of the tenant.      |
| locality    | String   | The distribution of the tenant's replicas.     |
| status      | String   | The status of the tenant. Valid values: <li>NORMAL: running</li><li>CREATING: being created</li><li>MODIFYING: being modified</li><li>DELETING: being deleted</li>    |
| locked      | Boolean  | Indicates whether the tenant is locked.    |
| readonly    | Boolean  | Indicates whether the tenant is in read-only mode.    |
| obVersion   | String   | The OceanBase version of the cluster to which the tenant belongs.     |
| description | String   | The description of the tenant.   |
