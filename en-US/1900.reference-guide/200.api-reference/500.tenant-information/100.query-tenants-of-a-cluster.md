# Query tenants of a cluster

## Description
------------------------------------

You can call this operation to query tenants of a cluster.
## Call description
**Call description** 
### Prerequisites

**Prerequisite** 

### Request path

`GET /api/v2/ob/clusters/{id}/tenants`

### Request parameters

**path:**
**Request parameters** 
|    Parameter |     Type | Required | Example value |        Description |
|-----------|---------|----------|---------------|-------------|
| id | Integer | Yes | 1 | The ID of the target cluster. |
| readonly  | Boolean     | No       | Boolean       | Specifies whether to set the tenant to read-only.                                                                                                                                                                                                  |
**body:**
| status    | StringArray | No       | CREATING      | The status of the tenant. * NORMAL   * CREATING   * MODIFYING   * DELETING    |
| Parameter |     Type | Required | Example value |        Description |
| page | Integer | No | 0 | The number of the page to return. Pages start from page 1. Default value: 1. |
| size | Integer | No | 10 | The number of entries to return on each page. Default value: 10, maximum value: 2000. |
| sort | String | No | asc,name | The rule of sorting the tenants. |
| name | String | No | foo | The keyword in the cluster name. The value is not case-sensitive. |
| mode | String | No | MYSQL | The mode of the tenant. Valid values: ORACLE and MYSQL. |
| locked | Boolean | No | true | Specifies whether to lock the tenant. |
| readonly | Boolean | No | Boolean | Specifies whether to set the tenant to read-only. |
| status | StringArray | No | CREATING | The status of the tenant. Valid values: NORMAL, CREATING, MODIFYING, and DELETING. |

Query all tenants in the cluster whose ID is 8.

```json
GET /api/v2/ob/clusters/8/tenants
```
