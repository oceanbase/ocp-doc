# Modify tenant parameters

## Description

This interface is used to modify parameters of a tenant.

## Call instructions

### Interface constraints

* The caller must have the permission to update the target tenant.

  For more information about the permissions of the caller, see [Overview of roles](../../../1600.system-management-features/400.manage-roles/100.roles-overview.md) and [Overview of users](../../../1600.system-management-features/500.manage-users/100.users-overview.md).

* The caller must be authenticated by OCP.

### Request path

`PUT /api/v2/ob/clusters/{id}/tenants/{tenantId}/parameters`

### Request parameters

**path:**

|    Parameter    |  Type  | Required | Example value |      Description       |
|----------|------|----|-----|---------------|
| id       | Long | Yes  | 1   | The ID of the cluster to which the target tenant belongs. |
| tenantId | Long | Yes  | 10  | The ID of the target tenant.     |

**body:**

|          Parameter          |  Type   | Required | Example value |            Description            |
|----------------------|-------|----|-----|--------------------------|
| TenantParameterParam | Array | Yes  | NA  | The list of TenantParameterParam objects. For more information, see **TenantParameterParam data structure**. |

**TenantParameterParam data structure**

|  Parameter   |   Type   | Required |          Example value           |       Description        |
|-------|--------|----|------------------------|-----------------|
| name  | String | Yes  | ob_default_replica_num | The parameter name. This parameter specifies the default number of OceanBase replicas. |
| value | String | Yes  | 2                      | The parameter value.            |
| parameterType | String | Yes  | OB_SYSTEM_VARIABLE  | The parameter type. Valid values: OB_SYSTEM_VARIABLE (variable) and OB_TENANT_PARAMETER (parameter).  |

### Return result

**Basic data structure**

|     Parameter     |    Type    |          Description           |
|------------|----------|-----------------------|
| successful | Boolean  | Indicates whether the request is successful.               |
| timestamp  | Datetime | The timestamp when the server finishes processing the request.          |
| duration   | Integer  | The time taken by the server to process the request, in milliseconds.       |
| status     | Integer  | The HTTP status code that conforms to the HTTP status code standard. |
| traceId    | String   | The Trace ID of the request, which is used for troubleshooting.  |
| server     | String   | The address of the application service that responds to the request.         |

## Examples

### Request example

`PUT /api/v2/ob/clusters/1/tenants/12/parameters`

```json
[
  {
    "name": "ob_default_replica_num",
    "value": 2
  }
]
```
