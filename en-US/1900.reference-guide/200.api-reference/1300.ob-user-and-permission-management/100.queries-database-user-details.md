# Get database user details list

## Feature description

Obtains the details list of database users.

## Call instructions

### Interface constraints

* The caller needs to be authenticated through the OCP application service.

* The caller must have the read permission on the specified tenant.

### Request path

`GET /api/v2/ob/clusters/{id}/tenants/{tenantId}/users`

### Request parameters

**path:**

|    Parameter    |   Type    | Required | Example Value |  Description   |
|----------|---------|----|-----|-------|
| id       | Integer | Yes  | 1   | The ID of the cluster. |
| tenantId | Integer | Yes  | 5   | The ID of the tenant. |

### Returned result

|     Parameter      |    Type    |           Description           |
|-------------|----------|------------------------|
| data        | Object   | The list of database users. For more information, see **Database user data structure**.          |
| successful  | Boolean  | Indicates whether the request is successful.                |
| timestamp   | Datetime | The timestamp when the server finishes the request.           |
| duration    | Integer  | The time taken by the server to process the request, in milliseconds.        |
| status      | Integer  | The HTTP status code that conforms to the HTTP status specification.   |
| traceId     | String   | The Trace ID of the request, which is used to troubleshoot issues.   |
| server      | String   | The address of the server that responds to the request.           |

**Database user data structure**

|           Parameter            |     Type      |   Description        |
|-------------------------|-------------|-----------|
| username                | String      | The username.    |
| globalPrivileges        | StringArray | The global privilege list: <li>For MySQL tenants, this field specifies the global privileges. </li><li>For Oracle tenants, this field specifies the system privileges. </li>    |
| dbPrivileges            | Array       | The database privilege list, which exists only in the response for a MySQL tenant and does not exist in the response for an Oracle tenant.    |
| ├─ dbName               | String      | The database name.     |
| ├─ privileges           | StringArray | The database privileges.   |
| objectPrivileges        | Array       | The object privilege list, which exists only in the response for an Oracle tenant and does not exist in the response for a MySQL tenant.      |
| ├─ dbObject             | Object      | The database object. For more information, see **dbObject parameter description**.     |
| ├─ privileges           | StringArray | The object privileges.     |
| grantedRoles            | StringArray | The roles granted to the user, which exists only in the response for an Oracle tenant and does not exist in the response for a MySQL tenant.  |
| isLocked                | Bool        | Indicates whether the user is locked.      |
| createTime              | Datetime    | The user creation time.  |
| connectionStrings       | Array       | The list of connection strings.  |
| ├─ connectionStringType | String      | The connection string type. Valid values: <li>OBPROXY</li><li>DIRECT</li>                            |
| ├─ obProxyAddress       | String      | The OBProxy address, which is valid only when the connection string type is OBPROXY.      |
| ├─ obProxyPort          | Integer     | The OBProxy port, which is valid only when the connection string type is OBPROXY.    |
| ├─ connectionString     | String      | The connection string.   |
| accessibleDatabases     | StringArray | The accessible databases, which exist only in the response for a MySQL tenant and do not exist in the response for an Oracle tenant.   |

**dbObject parameter description**

|     Parameter     |   Type   |      Description      |
|------------|--------|------------|
| objectType | String | The database object type. Valid values: <li>TABLE</li><li>VIEW</li><li>STORED_PROCEDURE</li>    |
| objectName | String | The database object name, which is the table name, view name, or stored procedure name.      |
| schemaName | String | The schema name, which is usually the same as the username.     |
