# ob_cluster_operation_info

## Alert description

This alert is triggered when a cluster-level operation is executed in OCP.

List of operations:

* Create cluster
* Enable/Disable SQL collection
* Stop/Start cluster
* Restart cluster
* Migrate cluster
* Delete cluster
* Upgrade version
* Create standby cluster
* Switch to daily/standby cluster
* Decouple cluster
* Convert cluster to read-only
* Generate performance report
* Backup and restore cluster
  * Immediate backup
  * Automatic backup scheduling
  * Initiate restore
  * Secondary backup scheduling
* Zone operations
  * Add zone
  * Stop zone
  * Start zone
  * Restart zone
  * Delete zone

## Alert principle

None.

## Alert template

* **Alert overview**

  * Template: \${alarm_target} \${operation_name} \${operation_result}
  * Example: alarm_template_id=0:ob_cluster=obcluster-1 Create cluster SUCCESS

* **Alert details**

  * Template: Cluster: \${ob_cluster_name}, Alert: \${operation_name} \${operation_result}, Operator: \${operator}, Result: \${operation_result}.
  * Example: Cluster: obcluster-1, Alert: Create cluster SUCCESS, Operator: admin, Result: success.

Where:

* ${alarm_target}: the object that generates the alert. The value is in the format of ob_cluster=xxxxxxx. ob_cluster indicates the name of the cluster that generates the alert.

* ${operation_name}: the operation executed.

* ${operation_result}: the result of the operation. Valid values: SUCCESS (the operation is successful) and FAILED (the operation failed).

* ${operator}: the name of the user who executed the operation.

## Impact on the system

If the result is SUCCESS, no impact is caused. If the result is FAILED, the corresponding operation failed.

## Possible causes

This alert is triggered when you perform cluster-level O&M operations in OCP, such as adding or deleting an OBServer node.

## Solution

This is a reminder. You do not need to handle it.

If the result in the alert is FAILED, you can view the task log in the **<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">Task Center</UI-TERM>** page of OCP to analyze the cause of the failure.
