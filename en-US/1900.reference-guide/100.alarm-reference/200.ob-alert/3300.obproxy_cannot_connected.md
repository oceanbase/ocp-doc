# obproxy_cannot_connected

## Alert description

This alert is triggered when OBProxy cannot be connected.

## Alert principle

The following table describes the key parameters involved in the monitoring logic of this alert.

| Parameter | Value |
|-----------|--------------|
| Metric | obproxy_connectable. This metric indicates whether OBProxy can be connected. A value of `1` indicates that OBProxy can be connected. A value of `0` indicates that OBProxy cannot be connected, and the alert is triggered.    |
| Metric expression | ```min(obproxysys_connectable{@LABELS}) by (@GBLABELS)```     |
| Collected metric | obproxy_connectable          |
| Metric source | The metric source of this alert is special. OCP-Agent checks whether the local OBProxy can be connected by establishing a socket connection with `localhost:2883`, and then returns the result to the collected metric. The port number 2883 is obtained from the configuration file `/home/admin/ocp_agent/config.conf`. |
| Collection cycle  | 5 seconds      |

## Rule information

|     Metric        | Default threshold | Duration | Detection cycle | Time before clearance |
|---------------------|------|------|------|------|
| obproxy_connectable | 0    | 60 seconds  | 10 seconds | 5 minutes |

## Alert information

|   Trigger method   | Alert level | Scope  |
|------------------|----------|-------|
| Based on the metric expression | Downtime   | Host |

## Alert template

* **Alert overview**

  * Template: \${alarm_target} \${alarm_name}
  * Example: alarm_template_id=0:obproxy_cluster=obproxy_02-1:host=xxx.xxx.xxx.xxx OBProxy cannot be connected

* **Alert details**

  * Template: OBProxy cluster: ${obproxy_cluster}, Host: ${host}, Alert: ${alarm_name}. Reason for disconnection: ${failed_reason}.
  * Example: OBProxy cluster: obproxy_02, Host: xxx.xxx.xxx.xxx, Alert: OBProxy cannot be connected. Reason for disconnection: OBPROXY_CONNECTION_ERROR.

* **Alert recovery**

  * Template: Alert: ${alarm_name}, OBProxy connection status: \${recover_value}
  * Example: Alert: OBProxy cannot be connected, OBProxy connection status: 1

Here, ${alarm_target} indicates the object that generated the alert. The format is obproxy_template_id=xx:obproxy_cluster=xx:host=xx. obproxy_cluster_id indicates the ID of the OBProxy cluster that generated the alert. ob_cluster indicates the name of the OBProxy cluster that generated the alert. svr_ip indicates the IP address of the OBProxy server that generated the alert.

## Impact on the system

OBProxy serves as the proxy layer of an OceanBase cluster, providing access to OBServer nodes. If OBProxy cannot be connected, the application cannot connect to the database.

## Possible causes

The following are the common causes:

* Network communication failure

* OBProxy process unexpectedly stops

## Solution

Check the reason why OBProxy cannot be connected and restore OBProxy.

* If the server is damaged, replace OBProxy.

* If the OBProxy is no longer needed, delete it.

* If the process is abnormal, refer to [ob_cannot_connected OB server cannot be connected](100.ob_cannot_connected.md).
