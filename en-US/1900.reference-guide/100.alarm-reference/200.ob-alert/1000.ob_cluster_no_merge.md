# ob_cluster_no_merge

## Alert description

This alert is triggered when an OceanBase cluster in the OCP has not triggered a major compaction for a long time. The alert is triggered when the time since the last major compaction exceeds the default threshold of 108000 seconds.

## Alert principle

The following table describes the key parameters involved in the monitoring logic of this alert.

|    Parameter      |      Value       |
|-------------|-----------|
| Monitoring metric     | no_merge_time, which indicates the time since the last major compaction. The alert is triggered when the value of this metric exceeds the threshold.     |
| Monitoring expression   | ```(max(ob_zone_current_timestamp{name="merge_start_time",@LABELS}) by (@GBLABELS) - max(ob_zone_stat{name="merge_start_time",@LABELS}) by (@GBLABELS)) / 1000000```      |
| Collected metric     | ob_zone      |
| Metric source     | Collected from internal views. The SQL statement for collection is: ```select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ zone, name, value, time_to_usec(now()) as current from __all_zone```   |
| Collection cycle     | 5 seconds       |

## Rule information

|        Monitoring metric             | Default threshold (unit: seconds) | Duration | Detection cycle | Elimination cycle |
|-----------------------------|------------|------|------|------|
| no_merge_time | 108000     | 0 seconds  | 10 seconds | 5 minutes |

## Alert information

|   Alert trigger method   | Alert level | Scope |
|------------|------|--------|
| Based on the monitoring metric expression | Critical   | Cluster |

## Alert template

* **Alert overview**

  * Template: \${alarm_target} \${alarm_name}
  * Example: alarm_template_id=0:ob_cluster=obcluster-1 OceanBase cluster has not triggered a major compaction for a long time

* **Alert details**

  * Template: Cluster: \${ob_cluster_name}, Alert: \${alarm_name}. The time since the last major compaction is \${value_shown} seconds, which exceeds \${alarm_threshold} seconds.
  * Example: Cluster: obcluster-1, Alert: OceanBase cluster has not triggered a major compaction for a long time. The time since the last major compaction is 1 hour, 17 minutes, and 49.496 seconds, which exceeds 59 seconds.

* **Alert recovery**

  * Template: Alert: ${alarm_name}, OceanBase cluster has not triggered a major compaction for \${value_shown} seconds.
  * Example: Alert: OceanBase cluster has not triggered a major compaction for 70000.0 seconds.

## Impact on the system

The Root Service of an OceanBase cluster periodically initiates major compactions. If major compactions are not initiated for a long time, the disk space will increase, leading to disk space exhaustion and affecting business write operations.

## Possible causes

This issue commonly occurs when the Root Service is abnormally paused, such as due to lack of a leader or process anomalies.
