# refresh_location_cache_failed

## Alert description

The OBServer node fails to refresh the location cache. This may cause SQL statements of the tenant to time out and affect business operations.

## Alert principle

OCP-Agent (ocp_monagent) monitors the running logs of the OBServer node. This alert is triggered in the following two scenarios:

1. When the following keywords appear in the logs for 1 minute:

   ```SQL
   LOCATION_STATISTIC
   SYS_CORE
   suc_cnt=0
   sql_suc_cnt=0
   ```

   The above keywords can be described by the following regular expression: `.\*LOCATION_STATISTIC.\*SYS_CORE.\*suc_cnt=0.\*sql_suc_cnt=0.\*` .

2. When the following keywords appear:

   ```SQL
   init_batch_rpc_renew_struct.*fail to check is local server.*ret=-4018
   ```

## Impact on the system

Due to incorrect location information, the system may be affected in the following ways:

1. Business SQL statements may time out.
2. The sys tenant queue may be backed up. You can use the `dump tenant info` keyword to check the `req_queue:total_size` value to see whether the queue is backed up.

## Possible causes

A known system failure.

## Solution

1. Directly connect to the OBServer node as the sys tenant.

2. When an OBServer node fails, run the following statement to refresh the location cache:

   ```SQL
   select count(*) from oceanbase.__all_virtual_proxy_schema where tenant_name = "sys" and database_name = "oceanbase" and table_name = "all_core_table" and partition_id = 0;
   ```

3. If **Step 2** fails, restart the server.

4. An uncommon scenario may also cause this issue: If a tenant in the cluster has been removed from the locality and the replicas of the removed R are deleted from the observer or zone, and the primary node is switched (triggered by O&M operations or a failure), the logs may continuously report the error "init_batch_rpc_renew_struct.*fail to check is local server.*ret=-4018". In this case, you can directly connect to all OBServer nodes in the cluster and run the `alter system flush location cache` statement to refresh the location cache.
