# ob_license_expired

## Alert description

<main id="notice" type='explain'>
<h4>Note</h4>
This alert is only triggered for standalone instances.
</main>

The alert is triggered when the license of an OceanBase standalone instance managed by OCP expires.

## Alert principle

| Parameter | Value |
|------------|-------|
| Metric | ob_license_expired_second_duration. This metric indicates the expiration time of the OceanBase license. Different metric values trigger alerts of different levels. |
| Metric expression | ```min(ob_license_expired_second_duration{@LABELS}) by (@GBLABELS)``` |
| Collected metric | ob_license_expired_second_duration |
| Source | The expiration time of the standalone instance license is detected. |
| Collection cycle | 5 seconds |

## Rule information

| Metric expression | Default threshold | Duration | Detection cycle | Elimination cycle |
|------------|---------|----------|----------|----------|
| ob_license_expired_second_duration | The metric has three default thresholds:<li>ob_license_expired_second_duration == 0</li><li>ob_license_expired_second_duration > 0 and ob_license_expired_second_duration < 2592000</li><li>ob_license_expired_second_duration >= 2592000 and ob_license_expired_second_duration < 5184000</li> | 0 seconds | 60 seconds | 7200 seconds |

## Alert information

| Trigger method | Alert level | Scope |
|--------------|---------|----------|
| Metric expression | <li>ob_license_expired_second_duration == 0: Down</li><li>ob_license_expired_second_duration > 0 and ob_license_expired_second_duration < 2592000: Critical</li><li>ob_license_expired_second_duration >= 2592000 and ob_license_expired_second_duration < 5184000: Warning</li> | Service |

## Alert template

* **Overview**

  * Template: ${alarm_target} ${alarm_name}
  * Example: expired_time=2025-10-10 OB License expiration time

* **Details**

  * Template: The license of the OceanBase standalone instance cluster ID ${ob_cluster_id} has expired or will expire at ${expired_time}. Please update the license of the standalone instance to avoid service interruption.
  * Example: The license of the OceanBase standalone instance cluster ID 10003 has expired or will expire at 2025-10-10. Please update the license of the standalone instance to avoid service interruption.

## Impact on the system

When the license of a standalone instance expires, the cluster will be in a down state and cannot provide normal services.

## Possible causes

The license of the standalone instance has expired or will expire within 60 days.

## Solution

Apply for a new license and import it again by using the [Import a license](../../../600.cluster-functions/300.manage-a-cluster/1400.import-license.md) method. OCP automatically updates the expiration time of the license.
