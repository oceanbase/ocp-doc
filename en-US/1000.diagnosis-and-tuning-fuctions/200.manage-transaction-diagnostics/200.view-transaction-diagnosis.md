# Diagnose transactions

OceanBase Cloud Platform (OCP) allows you to view basic information and associated SQL statements of large transactions. You can use the transaction diagnostics feature to identify and analyze large transactions.

You can diagnose transactions by using one of the following methods:

* **Method 1**: Log in to the OCP console. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Diagnosis.AutonomousService">OceanBase Autonomy Service</UI-TERM>**. On the page that appears, find the target cluster and click its name to go to the **<UI-TERM key="ocp-v2.Detail.Realtime.RealTimeDiagnosis">Real-time Diagnostics</UI-TERM>** page. Then, click the **<UI-TERM key="ocp-v2.SQLDiagnosis.TraceDetail.TransactionDiagnosis">Transaction Diagnostics</UI-TERM>** tab.

* **Method 2**: Log in to the OCP console. On the **<UI-TERM key="ocp-v2.page.Overview.Overview">Overview</UI-TERM>** page of a tenant, click **<UI-TERM key="ocp-v2.Transaction.Detail.TransactionDiagnosis">Transaction Diagnostics</UI-TERM>** in the left-side navigation pane.

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>OCP Community Edition does not support OceanBase Autonomy Service. To use this service, go to the relevant page by using <b>Method 2</b>. </p>
</main>

## Prerequisites

* To diagnose transactions by using **Method 1**, make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.Realtime.RealTimeDiagnosis">Real-time Diagnostics</UI-TERM>** menu of **<UI-TERM key="ocp-v2.page.Diagnosis.AutonomousService">OceanBase Autonomy Service</UI-TERM>**

* To diagnose transactions by using **Method 2**, make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.page.Overview.TransactionDiagnosis">Transaction Diagnostics</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.util.menu.Tenant">Tenants</UI-TERM>**

* The version of OceanBase Database is V3.2.x or later so that the **Log Volume of Single Participant** field is available.
* You have enabled parameters in the **<UI-TERM key="ocp-v2.src.constant.parameter.TransactionDiagnosticCollection">Transaction Diagnostics Collection</UI-TERM>** section by referring to [Manage parameters](../../600.cluster-functions/300.manage-a-cluster/1200.manage-om-configuration/200.manage-om-configuration-parameters.md).

## Procedure

The procedure of **Method 1** is described as follows:

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.hook.useMenu.AutonomousService">OceanBase Autonomy Service</UI-TERM>**.

3. In the **<UI-TERM key="ocp-v2.page.Diagnosis.ClusterDetails">Cluster Details</UI-TERM>** section, click the name of the cluster that you want to view.

4. On the **<UI-TERM key="ocp-v2.Transaction.Detail.TransactionDiagnosis">Transaction Diagnostics</UI-TERM>** tab of the **<UI-TERM key="ocp-v2.Detail.Realtime.RealTimeDiagnosis">Real-time Diagnostics</UI-TERM>** page, filter the transactions.

      * By default, the system displays the transactions whose execution time is greater than 500 ms or transactions whose log volume of a single participant exceeds 0.5 MB. You can specify another execution time or log volume range to query transactions.

      * Turn on **<UI-TERM key="ocp-v2.Component.overview.AutomaticRefresh">Auto Refresh</UI-TERM>**. The transaction list on the page will be automatically refreshed based on the refresh frequency. You can set the refresh frequency to 5s, 10s, or 30s. The default refresh frequency is 10s.

    ![Image 56](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/9334633561/p440487.png)
  
* View transactions.

  You can view transactions by transaction status. Transactions are divided into long-running transactions, suspended transactions, and other transactions by status. The transaction list displays information of the running large transactions. The list contains the following columns: **<UI-TERM key="ocp-v2.Alarm.Event.Detail.TransactionHash">Transaction Hash</UI-TERM>**, **<UI-TERM key="ocp-v2.Detail.Transaction.SessionId">Session ID</UI-TERM>**, **<UI-TERM key="ocp-v2.Transaction.Detail.TransactionType">Transaction Type</UI-TERM>**, **<UI-TERM key="ocp-v2.Transaction.Detail.AffectedRows">Affected Rows</UI-TERM>**, **<UI-TERM key="ocp-v2.Transaction.Detail.Executed">Execution Time Elapsed</UI-TERM>**, and **Maximum Log Volume of Single Participant**. The following table describes the columns of the transaction list.
  
  |    Column    |                                   Description                                    |
  |-----------|-------------------------------------------------------------------------|
  | Transaction Hash   | The unique ID of the transaction.                                                                |
  | Session ID     | The unique ID of the session. For more information, see [Manage the sessions of a tenant](../300.manage-session/100.manage-tenant-sessions.md). |
  | Transaction Type      | The transaction type. Valid values: **XA Transaction**, **Distributed Transaction**, and **Ordinary Transaction**. <blockquote>**<UI-TERM key="ocp-v2.src.component.AddBinlogCredentialModal.Description">Note</UI-TERM>**</br>eXtended Architecture (XA) transactions are not supported in OceanBase Database V4.0 and later. </blockquote>                                                |
  | Affected Rows     | The number of rows affected in the execution of all SQL statements in the transaction.                                             |
  | Execution Time Elapsed (ms) | The amount of time for which the transaction has been executed.                                                              |

  ![Image 109](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/0434633561/p440488.png)
  
* View the details of a transaction.

  Click the hash value of a specific transaction. The **<UI-TERM key="ocp-v2.Component.SQLDetail.TransactionDetails">Transaction Details</UI-TERM>** page appears. You can view the basic information, execution information, and details of executed SQL statements of the transaction on the page.
  * Click **<UI-TERM key="ocp-v2.Transaction.Detail.CloseATransaction">Close Transaction</UI-TERM>** in the upper-right corner to close the session of the transaction. Only regular transactions and distributed transactions in the **<UI-TERM key="ocp-v2.src.constant.transaction.LongTransaction">Long Transactions</UI-TERM>** list can be closed.

  * Click the SQL text in the **<UI-TERM key="ocp-v2.Transaction.Detail.SqlStatementWithTheLongest">SQL Statement with Longest Execution Time</UI-TERM>**, **<UI-TERM key="ocp-v2.Transaction.Detail.SqlStatementThatAffectsThe">SQL Statement with Most Affected Rows</UI-TERM>**, or **<UI-TERM key="ocp-v2.Transaction.Detail.SqlExecutionDetails">Details About Executed SQL Statements</UI-TERM>** field to view the details of the SQL statement.

* Close transactions.

  On the **<UI-TERM key="ocp-v2.Detail.Transaction.TransactionList">Transactions</UI-TERM>** page, select the transaction to be closed and click **<UI-TERM key="ocp-v2.Transaction.Detail.CloseATransaction">Close Transaction</UI-TERM>** in the corresponding **<UI-TERM key="ocp-v2.User.MySQL.Operation">Actions</UI-TERM>** column. You can also select multiple transactions and click **<UI-TERM key="ocp-v2.Detail.Transaction.CloseTransactionsInBatches">Batch Close Transactions</UI-TERM>**. In the dialog box that appears, click **<UI-TERM key="ocp-v2.Component.AddOBServerDrawer.Ok">OK</UI-TERM>** to close the session of the selected one or more transactions. After the session of a transaction is closed, the transaction is rolled back and the session connection is also terminated.
  
   <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>Only regular transactions and distributed transactions in the <strong>Long Transactions</strong> list can be closed. </p>
   </main>
