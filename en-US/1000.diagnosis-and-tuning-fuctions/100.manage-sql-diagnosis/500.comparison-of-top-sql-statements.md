# View Comparison of Top SQL Statements

This topic describes how to view comparison of Top SQL statements.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">Real-time Diagnostics</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.hook.useMenu.AutonomousService">OceanBase Autonomy Service</UI-TERM>**

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, click **Autonomous service**.

3. In the **<UI-TERM key="ocp-v2.page.Diagnosis.ClusterDetails">Cluster Details</UI-TERM>** section, click the name of the target cluster.

4. By default, the **<UI-TERM key="ocp-v2.page.Iframe.SqlDiagnosis">SQL Diagnostics</UI-TERM>** tab of the **<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">Real-time Diagnostics</UI-TERM>** page appears.

5. In the list on the **TopSQL** tab, click **<UI-TERM key="ocp-v2.Realtime.SQLDiagnosis.TopsqlComparison">Comparison of Top SQL Statements</UI-TERM>** and choose **<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.ComparisonOfDifferentPeriods">Comparison by Period</UI-TERM>** or **<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.ComparisonOfDifferentNodes">Comparison on Different Nodes</UI-TERM>** in the panel that appears to compare and analyze the top SQL statements in different dimensions.

    * **View the comparison details of top SQL statements in different time periods**

        On the **<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.ComparisonOfDifferentPeriods">Comparison by Period</UI-TERM>** tab, the system displays the SQL statements that meet the following rules within the specified **Period for Comparison** in comparison against the specified **<UI-TERM key="ocp-v2.ComparisonSqlDrawer.DetailedTable.BasePeriod">Baseline Period</UI-TERM>**:

        * The SQL statement is ranked top N for the first time. The value of N is specified by the `perf.sql.top-sql-comparison.new-in-top-n-limit` parameter in OCP. The default value of the parameter is `100`.
        * An increase in the number of executions of the SQL statement exceeds the specified threshold. The threshold is specified by the `perf.sql.top-sql-comparison.executions-increase-limit` parameter in OCP. The default value of the parameter is `20%`.
        * An increase in the average response time for the SQL statement exceeds the specified threshold. The threshold is specified by the `perf.sql.top-sql-comparison.elapsed-time-increase-limit` parameter in OCP. The default value of the parameter is `20%`.
        * An increase in the average number of returned rows for the SQL statement exceeds the specified threshold. The threshold is specified by the `perf.sql.top-sql-comparison.return-rows-increase-limit` parameter in OCP. The default value of the parameter is `20%`.
        * An increase in the error rate of the SQL statement exceeds the specified threshold. The threshold is specified by the `perf.sql.top-sql-comparison.error-percentage-increase-limit` parameter in OCP. The default value of the parameter is `10%`.
        * An increase in the percentage of remote plans for the SQL statement exceeds the specified threshold. The threshold is specified by the `perf.sql.top-sql-comparison.remote-plan-percentage-increase-limit` parameter in OCP. The default value of the parameter is `20%`.
        * An increase in the number of executions of the SQL statement exceeds the specified threshold. The threshold is specified by the `perf.sql.top-sql-comparison.executions-increase-limit` parameter in OCP. The default value of the parameter is `10%`.

        Procedure:

        1. Specify **<UI-TERM key="ocp-v2.src.hook.sqlDiagnosis.BasePeriod">Baseline Period</UI-TERM>** and **Period for Comparison**.

            * Select a period of time for **<UI-TERM key="ocp-v2.ComparisonSqlDrawer.DetailedTable.BasePeriod">Baseline Period</UI-TERM>**.
            * Set **Comparison Period** to **<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.PreviousPeriod">Previous Period</UI-TERM>**, **<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.SamePeriodOfThePreviousDay">Same Period of Previous Day</UI-TERM>**, **<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.TheSamePeriodLastWeek">Same Period Last Week</UI-TERM>**, or a custom period.

        2. Click **<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.ServerComparison.ComparativeAnalysis">Comparative Analysis</UI-TERM>** and view the details on the **<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.ServerComparison.DetailedDataComparison">Comparison of Details</UI-TERM>** and **<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.PerformanceTrendComparison">Comparison of Performance Trends</UI-TERM>** tabs.

            * **<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.DetailedDataComparison">Comparison of Details</UI-TERM>**: On this tab, you can view details about SQL statements.

                You can click the SQL text of an SQL statement to view its details and click the trend chart icon on the right to view the metric trend comparison chart.

                ![11](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E4%B8%8D%E5%90%8C%E6%97%B6%E6%AE%B5%E6%98%8E%E7%BB%86%E6%95%B0%E6%8D%AE%E5%AF%B9%E6%AF%94-1.png)

            * **<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.PerformanceTrendComparison">Comparison of Performance Trends</UI-TERM>**: On this tab, you can view the performance trend comparison charts of SQL statements, including the read/write response time, number of read/write requests, and CPU utilization.

                ![22](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E4%B8%8D%E5%90%8C%E6%97%B6%E6%AE%B5%E6%80%A7%E8%83%BD%E5%AF%B9%E6%AF%94-1.png)

    * **View the comparison details of top SQL statements on different nodes**

        You can compare the execution performance of the same SQL statement on different nodes.

        1. Select the baseline node and the node for comparison.

        2. Select an analysis period.

            You can view the comparison details of the last five minutes, last half hour, last hour, last six hours, or a custom time range.

        3. Click **<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.ServerComparison.ComparativeAnalysis">Comparative Analysis</UI-TERM>** to view the data comparison details and response time trend details.

            * **<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.DetailedDataComparison">Comparison of Details</UI-TERM>**: On this tab, you can view details about SQL statements.

                You can click the SQL text of an SQL statement to view its details and click **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.ColumnManager.ColumnManagement">Column Management</UI-TERM>** in the upper-right corner to configure the column expression and column name of a custom column in the dialog box that appears.

                ![11](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E4%B8%8D%E5%90%8C%E8%8A%82%E7%82%B9%E6%98%8E%E7%BB%86%E6%95%B0%E6%8D%AE%E5%AF%B9%E6%AF%94-1.png)

            * **<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.ServerComparison.ComparisonOfResponseTimeTrends">Response Time Trend Comparison</UI-TERM>**: This tab shows the execution duration ratio trends of the baseline node and the node for comparison.

                Click **<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.ServerMonitor.AllSqlTypes">All SQL Types</UI-TERM>** in the upper-right corner to select the type of SQL statements that you want to view.

                ![11](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E4%B8%8D%E5%90%8C%E8%8A%82%E7%82%B9%E5%93%8D%E5%BA%94%E6%97%B6%E9%97%B4%E8%B6%8B%E5%8A%BF%E5%AF%B9%E6%AF%94-1.png)
