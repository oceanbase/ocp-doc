# View the SQL collection enabling/disabling history

This topic describes how to view the SQL collection enabling/disabling history.

You can view the SQL collection enabling/disabling history by using the following methods:

* **Method 1**: Log in to the OceanBase Cloud Platform (OCP) console. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.hook.useMenu.AutonomousService">OceanBase Autonomy Service</UI-TERM>**. On the page that appears, find the target cluster and click its name to go to the **<UI-TERM key="ocp-v2.Detail.Realtime.RealTimeDiagnosis">Real-time Diagnostics</UI-TERM>** page.

* **Method 2**: Log in to the OCP console. On the **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** page of a tenant, click **<UI-TERM key="ocp-v2.SQLDiagnosis.Digest.SqlDiagnosis">SQL Diagnostics</UI-TERM>** in the left-side navigation pane.

<main id="notice" type='notice'>
   <h4>Applicability</h4>
   <p>OCP Community Edition does not support OceanBase Autonomy Service. To use this service, go to the relevant page by using <b>Method 2</b>. </p>
</main>

## Prerequisites

* To view the SQL collection enabling/disabling history by using **Method 1**, make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.Realtime.RealTimeDiagnosis">Real-time Diagnostics</UI-TERM>** menu of **<UI-TERM key="ocp-v2.page.Diagnosis.AutonomousService">OceanBase Autonomy Service</UI-TERM>**

* To view the SQL collection enabling/disabling history by using **Method 2**, make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Component.SQLDetail.SqlDiagnosis">SQL Diagnostics</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Tenant.New.Tenant">Tenants</UI-TERM>**

## Procedure

The procedure of **Method 1** is described as follows:

1. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.hook.useMenu.AutonomousService">OceanBase Autonomy Service</UI-TERM>**. On the **<UI-TERM key="ocp-v2.page.Diagnosis.ClusterDetails">Cluster Details</UI-TERM>** page, click the name of the target cluster to go to its **<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">Real-time Diagnostics</UI-TERM>** page.

2. By default, the **<UI-TERM key="ocp-v2.page.Iframe.SqlDiagnosis">SQL Diagnostics</UI-TERM>** tab appears.

3. Click **<UI-TERM key="ocp-v2.Detail.SQLDiagnosis.ViewCollectionSwitchHistory">View SQL Collection History</UI-TERM>**.

   ![Image 161](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/3924633561/p440557.png)

4. In the **<UI-TERM key="ocp-v2.component.TraceTimelineDrawer.SqlCollectionSwitchHistory">SQL Collection History</UI-TERM>** panel on the right, view the time and actions of SQL collection enabling/disabling operations.

   * You can sort the operations by time.

   * You can sort the operations by action (enable or disable).
