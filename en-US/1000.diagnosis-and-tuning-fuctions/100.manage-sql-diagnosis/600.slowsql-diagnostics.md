# Diagnose slow SQL statements

Slow SQL statements are statements whose execution time exceeds the specified threshold, which is 100 ms by default. You can use the slow SQL diagnostics feature to identify risky statements and avoid risks.

You can diagnose slow SQL statements by using one of the following methods:

* **Method 1**: Log in to the OceanBase Cloud Platform (OCP) console. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.hook.useMenu.AutonomousService">OceanBase Autonomy Service</UI-TERM>**. On the page that appears, find the target cluster and click its name to go to the **<UI-TERM key="ocp-v2.Detail.Realtime.RealTimeDiagnosis">Real-time Diagnostics</UI-TERM>** page.

* **Method 2**: Log in to the OCP console. On the **<UI-TERM key="ocp-v2.page.Overview.Overview">Overview</UI-TERM>** page of a tenant, click **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.SqlDiagnosis">SQL Diagnostics</UI-TERM>** in the left-side navigation pane.

<main id="notice" type='notice'>
   <h4>Applicability</h4>
   <p>OCP Community Edition does not support OceanBase Autonomy Service. To use this service, go to the relevant page by using <b>Method 2</b>. </p>
</main>

## Prerequisites

* To diagnose slow SQL statements by using **Method 1**, make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.Realtime.RealTimeDiagnosis">Real-time Diagnostics</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.hook.useMenu.AutonomousService">OceanBase Autonomy Service</UI-TERM>**

* To diagnose slow SQL statements by using **Method 2**, make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.ParallelSQL.TraceDetail.SqlDiagnosis">SQL Diagnostics</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.constant.auditEvent.Tenant">Tenants</UI-TERM>**

* You have enabled parameters in the **<UI-TERM key="ocp-v2.component.OperationConfig.List.SqlDiagnosticCollection">SQL Diagnostics Collection</UI-TERM>** section by referring to [Manage parameters](../../600.cluster-functions/300.manage-a-cluster/1200.manage-om-configuration/200.manage-om-configuration-parameters.md).

* By default, an SQL statement whose execution time exceeds 100 ms is considered a slow SQL statement. You can choose **<UI-TERM key="ocp-v2.page.Information.Cluster">Cluster</UI-TERM>** > **<UI-TERM key="ocp-v2.component.OperationConfig.OMConfiguration">O&M Configuration</UI-TERM>** > **<UI-TERM key="ocp-v2.component.OperationConfig.List.SqlDiagnosticCollection">SQL Diagnostics Collection</UI-TERM>**, find the **monagent.ob.slow.sql.threshold** parameter, and change its value to modify the default threshold that defines a slow SQL statement. For more information, see [Manage parameters](../../600.cluster-functions/300.manage-a-cluster/1200.manage-om-configuration/200.manage-om-configuration-parameters.md).

## Procedure

The procedure of **Method 1** is described as follows:

1. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Diagnosis.AutonomousService">OceanBase Autonomy Service</UI-TERM>**. On the **<UI-TERM key="ocp-v2.page.Diagnosis.ClusterDetails">Cluster Details</UI-TERM>** page, click the name of the target cluster to go to its **<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">Real-time Diagnostics</UI-TERM>** page.

2. By default, the **<UI-TERM key="ocp-v2.SQLDiagnosis.Digest.SqlDiagnosis">SQL Diagnostics</UI-TERM>** tab appears.

   The SQL diagnostic data is not displayed on the **<UI-TERM key="ocp-v2.ParallelSQL.TraceDetail.SqlDiagnosis">SQL Diagnostics</UI-TERM>** tab if you do not set the values of both the cluster parameter `enable_sql_audit` and the tenant parameter `ob_enable_sql_audit` to `True`. You can click **<UI-TERM key="ocp-v2.Detail.SQLDiagnosis.ModifyClusterParameters">Change Cluster Parameters</UI-TERM>** in the prompt to modify the parameter values.

   ![08251639](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/2824633561/p440530.png)

3. Click the **SlowSQL** tab.

4. Filter the slow SQL statements.

   1 Specify the filter conditions.

      * **<UI-TERM key="ocp-v2.Detail.Analyze.TimesChart.TimeRange">Time Range</UI-TERM>**: You can select **<UI-TERM key="ocp-v2.component.RangeTimeDropdown.LastMinutes">Last 5 Minutes</UI-TERM>**, **<UI-TERM key="ocp-v2.component.OCPRangePicker.constant.NearlyMinutes.1">Last 10 Minutes</UI-TERM>**, **<UI-TERM key="ocp-v2.SQLDiagnosis.Digest.LastMinutes.3">Last 20 Minutes</UI-TERM>**, **<UI-TERM key="ocp-v2.component.OCPRangePicker.constant.NearlyMinutes.3">Last 30 Minutes</UI-TERM>**, **<UI-TERM key="ocp-v2.SQLDiagnosis.Digest.LastHour">Last 1 Hour</UI-TERM>**, **<UI-TERM key="ocp-v2.src.constant.log.NearlyHours">Last 3 Hours</UI-TERM>**, or **<UI-TERM key="ocp-v2.src.constant.log.NearlyHours.1">Last 6 Hours</UI-TERM>** from the **<UI-TERM key="ocp-v2.Detail.Analyze.TimesChart.TimeRange">Time Range</UI-TERM>** drop-down list. You can also select **<UI-TERM key="ocp-v2.component.OCPRangePicker.CustomTime">Custom Time</UI-TERM>** from the drop-down list and specify the start time and end time as needed. By default, the information of the last 6 hours is displayed.

      * **OBServer**: You can select one OBServer node or all OBServer nodes in the list. If you select one OBServer node, only SQL statements executed on the selected OBServer node are queried.

      * **<UI-TERM key="ocp-v2.SQLDiagnosis.attributes.slowSqlAttributes.InternalSql">Internal SQL</UI-TERM>**: If you select this option, the SQL statements internally initiated in OceanBase Database are displayed in the query result.

      * **<UI-TERM key="ocp-v2.Alarm.Template.Keywords">Keyword</UI-TERM>**: If you specify a keyword, the SQL statements that contain the keyword are displayed in the query result.

      * **Advanced Search**: You can select metrics such as **SQL ID**, **<UI-TERM key="ocp-v2.Log.Trace.NumberOfExecutions">Executions</UI-TERM>**, **or Executions per Second** from the drop-down list and specify the value range. The SQL statements that match the specified conditions are displayed in the query result.
      * **<UI-TERM key="ocp-v2.Realtime.SQLDiagnosis.QuickFilter">Quick Filter</UI-TERM>**: You can select an option, such as **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.FullTableScan.1">Full Table Scan</UI-TERM>** or **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.MultiPartitionScan">Multi-Partition Scan</UI-TERM>**, to quickly identify SQL statements that need to be optimized.

      ![08251824](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/2824633561/p440521.png)

   2. Click **<UI-TERM key="ocp-v2.Auth.User.loginHistory.Query">Search</UI-TERM>** to list all SQL statements that meet the filter conditions.

5. Click **Export SlowSQL** to export all SQL statements in the query result.

6. View information about slow SQL statements.

   1. Click **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.ColumnManager.ColumnManagement">Column Management</UI-TERM>**. In the dialog box that appears, select the columns to display. Then, you can view the selected columns in the slow SQL statement list.

      ![Image 16](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/2824633561/p440522.png)

   2. On the **SlowSQL** tab, you can view the columns selected. You can copy the SQL text of an SQL statement, view and copy the sample, filter the SQL statements by database and user, and sort the SQL statements by the number of executions, total response time, response time, and CPU time.

      ![Image 174](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/2824633561/p440523.png)

   3. You can click the SQL text of an SQL statement to go to the **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetail.SqlDetails">SQL Details</UI-TERM>** page of the statement.

      On the **<UI-TERM key="ocp-v2.ParallelSQL.TraceDetail.SqlDetails">SQL Details</UI-TERM>** page, you can view the following details of the SQL statement:

      * In the **<UI-TERM key="ocp-v2.Component.SampleSqlRawTextModal.SqlText">SQL Text</UI-TERM>** section, you can view the complete SQL statement. You can view and copy the sample.

      * In the **<UI-TERM key="ocp-v2.Detail.Optimize.OptimizationSuggestions">Optimization Suggestions</UI-TERM>** section, you can view the optimization suggestions for the SQL statement. For more information, see the **View optimization suggestions** section in [View the details of an SQL statement](../100.manage-sql-diagnosis/1000.view-sql-details.md).

      * In the **<UI-TERM key="ocp-v2.Component.SQLDetail.SQLTraceTable.SqlSampling">SQL Sampling</UI-TERM>** section, you can view the details of the slow SQL statement. You can view the original SQL text, request time, request IP address, database, user, response time, CPU time, plan execution time, and number of threads for executing the SQL statement in the last 5 minutes, last 10 minutes, last 20 minutes, last 30 minutes, last 1 hour, last 3 hours, last 6 hours, or a custom time range. You can copy the original SQL text. You can also sort the SQL statements by the request time, response time, CPU time, plan execution time, and number of threads for executing the SQL statement.

        <main id="notice" type='explain'>
          <h4>Note</h4>
          <p>You can view traces only if you use OceanBase Database V4.0.0 or later and the end-to-end tracing feature is enabled. </p>
        </main>

        ![Image 175](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/432/sql%E9%87%87%E6%A0%B7.png)

        You can click **<UI-TERM key="ocp-v2.Trace.Visualizer.ViewTrace">View Trace</UI-TERM>** in the **<UI-TERM key="ocp-v2.ResourceManager.ResourceGroupTab.Operation">Actions</UI-TERM>** column to view the trace of the SQL statement. For more information about how to enable end-to-end tracing, see [Configure full link tracking for a tenant](../../700.tenant-functions/600.manage-a-tenant/600.full-link-diagnostic-configuration-of-tenant.md).

        ![Image 176](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/421/OAS/SQL%E9%87%87%E6%A0%B7-2.png)

      * On the **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetailTabs.HistoricalTrends">Previous Tendency</UI-TERM>** tab, you can view the historical trends of the SQL statement. For more information, see the **View the historical trends of an SQL statement** section in [View the details of an SQL statement](../100.manage-sql-diagnosis/1000.view-sql-details.md).

      * On the **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetailTabs.ExecutionPlan">Execution Plans</UI-TERM>** tab, you can view the execution plans of the SQL statement, or bind an execution plan to the statement. For more information, see the **View the execution plans of an SQL statement** section in [View the details of an SQL statement](../100.manage-sql-diagnosis/1000.view-sql-details.md).

      * On the **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetailTabs.Index">Index</UI-TERM>** tab, you can view the indexes bound to the SQL statement. For more information, see the **View and bind indexes** section in [View the details of an SQL statement](../100.manage-sql-diagnosis/1000.view-sql-details.md).

      * On the **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetailTabs.SqlThrottling">SQL Throttling</UI-TERM>** tab, you can view or set throttling for the SQL statement. For more information, see the **Set throttling for the SQL statement** section in [View the details of an SQL statement](../100.manage-sql-diagnosis/1000.view-sql-details.md).

      * You can view the binding records of the SQL statement in section ① as illustrated on the **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetailTabs.ExecutionPlan">Execution Plans</UI-TERM>**, **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetailTabs.Index">Index</UI-TERM>**, and **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.SqlThrottling">SQL Throttling</UI-TERM>** tabs.

        ![1217](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/2824633561/p440526.png)

        In the binding records, you can view the status of a bound execution plan, or click **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetailTabs.Unbind">Unbind</UI-TERM>** to unbind the plan from the SQL statement. You can click **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetailTabs.BindPlan">Bind Plan</UI-TERM>** to bind the plan to the SQL statement again.

7. Set throttling.

   * You can click **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetailTabs.SetThrottling">Enable Throttling</UI-TERM>** to enable throttling for the SQL statement. For more information, see the **Set throttling for the SQL statement** section in [View the details of an SQL statement](../100.manage-sql-diagnosis/1000.view-sql-details.md).

   * You can also select multiple SQL statements and click **<UI-TERM key="ocp-v2.Component.SQLTable.SetThrottling.2">Batch Set Throttling</UI-TERM>**. In the dialog box that appears, specify the maximum number of SQL statements that can be executed concurrently.

    <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>Keyword-based throttling is not supported in batch throttling. </p>
    </main>
