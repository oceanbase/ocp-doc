# Diagnose parallel SQL statements

A parallel SQL statement is an SQL statement executed by using parallel scheduling in a tenant. You can use the parallel SQL diagnostics feature to identify SQL statements that do not meet query performance expectations in analytical processing.

You can diagnose parallel SQL statements by using one of the following methods:

* **Method 1**: Log in to the OceanBase Cloud Platform (OCP) console. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.hook.useMenu.AutonomousService">OceanBase Autonomy Service</UI-TERM>**. On the page that appears, find the target cluster and click its name to go to the **<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">Real-time Diagnostics</UI-TERM>** page.

* **Method 2**: Log in to the OCP console. On the **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** page of a tenant, click **<UI-TERM key="ocp-v2.Detail.Monitor.SqlDiagnosis">SQL Diagnostics</UI-TERM>** in the left-side navigation pane.

<main id="notice" type='notice'>
   <h4>Applicability</h4>
   <p>OCP Community Edition does not support OceanBase Autonomy Service. To use this service, go to the relevant page by using <b>Method 2</b>. </p>
</main>

## Prerequisites

* To diagnose parallel SQL statements by using **Method 1**, make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">Real-time Diagnostics</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.hook.useMenu.AutonomousService">OceanBase Autonomy Service</UI-TERM>**

* To diagnose parallel SQL statements by using **Method 2**, make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.page.Iframe.SqlDiagnosis">SQL Diagnostics</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.constant.auditEvent.Tenant">Tenants</UI-TERM>**

* You have enabled parameters in the **<UI-TERM key="ocp-v2.component.OperationConfig.List.SqlDiagnosticCollection">SQL Diagnostics Collection</UI-TERM>** section by referring to [Manage parameters](../../600.cluster-functions/300.manage-a-cluster/1200.manage-om-configuration/200.manage-om-configuration-parameters.md).

## Procedure

The procedure of **Method 1** is described as follows:

1. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Diagnosis.AutonomousService">OceanBase Autonomy Service</UI-TERM>**. On the **<UI-TERM key="ocp-v2.page.Diagnosis.ClusterDetails">Cluster Details</UI-TERM>** page, click the name of the target cluster to go to its **<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">Real-time Diagnostics</UI-TERM>** page.

2. By default, the **<UI-TERM key="ocp-v2.SQLDiagnosis.Digest.SqlDiagnosis">SQL Diagnostics</UI-TERM>** tab appears.

    The SQL diagnostic data is not displayed on the **<UI-TERM key="ocp-v2.Detail.Monitor.SqlDiagnosis">SQL Diagnostics</UI-TERM>** tab if you do not set the values of both the cluster parameter `enable_sql_audit` and the tenant parameter `ob_enable_sql_audit` to `True`. You can click **<UI-TERM key="ocp-v2.Detail.SQLDiagnosis.ModifyClusterParameters">Change Cluster Parameters</UI-TERM>** in the prompt to modify the parameter values.

    ![08251639](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/0924633561/p440531.png)
  
3. Click the **ParallelSQL** tab.

4. Filter the parallel SQL statements.

   1. Specify the filter conditions.

     * **<UI-TERM key="ocp-v2.Detail.Analyze.TimesChart.TimeRange">Time Range</UI-TERM>**: You can select **<UI-TERM key="ocp-v2.component.RangeTimeDropdown.LastMinutes">Last 5 Minutes</UI-TERM>**, **<UI-TERM key="ocp-v2.Information.Detail.CreateCollectDrawer.NearlyMinutes">Last 10 Minutes</UI-TERM>**, **<UI-TERM key="ocp-v2.component.RangeTimeDropdown.LastMinutes.2">Last 20 Minutes</UI-TERM>**, **<UI-TERM key="ocp-v2.Information.Detail.CreateCollectDrawer.NearlyMinutes.2">Last 30 Minutes</UI-TERM>**, **<UI-TERM key="ocp-v2.src.component.RangeTimeDropdown.LastHour">Last 1 Hour</UI-TERM>**, **<UI-TERM key="ocp-v2.component.OCPRangePicker.constant.NearlyHours">Last 3 Hours</UI-TERM>**, or **<UI-TERM key="ocp-v2.component.OCPRangePicker.constant.NearlyHour.6">Last 6 Hours</UI-TERM>** from the **<UI-TERM key="ocp-v2.Detail.Analyze.TimeRange">Time Range</UI-TERM>** drop-down list. You can also select **<UI-TERM key="ocp-v2.component.OCPRangePicker.CustomTime">Custom Time</UI-TERM>** from the drop-down list and specify the start time and end time as needed. By default, the information of the last 6 hours is displayed.

     * **OBServer**: You can select one OBServer node or all OBServer nodes in the list. If you select one OBServer node, only SQL statements executed on the selected OBServer node are queried.

     * **<UI-TERM key="ocp-v2.SQLDiagnosis.attributes.slowSqlAttributes.InternalSql">Internal SQL</UI-TERM>**: If you select this option, the SQL statements internally initiated in OceanBase Database are displayed in the query result.

     * **<UI-TERM key="ocp-v2.Detail.SQLDiagnosis.KeyWords">Keyword</UI-TERM>**: If you specify a keyword, the SQL statements that contain the specified keyword are displayed in the query result. The keywords filter SQL statements in the same way as the SQL LIKE operator. The entered strings are automatically prefixed and suffixed with a percent sign (%).

     * **Advanced Search**: You can add multiple filter conditions in **Advanced Search**. Click **<UI-TERM key="ocp-v2.component.CPUBindCoreConfigDrawer.BindConfigRangeDrawer.Add">Add</UI-TERM>**. In the **Add Advanced Conditions** dialog box, you can specify a metric, an operator, and a metric value. The SQL statements that match the specified conditions are displayed in the query result.

     ![Image 9](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/1924633561/p440532.png)

   2. Click **<UI-TERM key="ocp-v2.page.QueryLog.Query">Search</UI-TERM>** to list all SQL statements that meet the filter conditions.

5. Click **Export ParallelSQL** to export all SQL statements in the query result.

6. View information about parallel SQL statements.

   1. Click **<UI-TERM key="ocp-v2.Component.filter.ColumnManagement">Column Management</UI-TERM>**. In the dialog box that appears, select the columns to display. Then, you can view the selected columns in the parallel SQL statement list.

     ![Image 176](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/1924633561/p440533.png)

   2. On the **ParallelSQL** tab, you can view the columns selected. You can copy the SQL text and filter the SQL statements by database. You can also sort the SQL statements by the degree of parallelism, number of executions, total response time, and average response time. You can also view the diagnostic result.

     ![Image 177](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/0924633561/p440534.png)

   3. You can click the SQL text of an SQL statement to go to the **<UI-TERM key="ocp-v2.ParallelSQL.TraceDetail.SqlDetails">SQL Details</UI-TERM>** page of the statement, where you can view the following details of the SQL statement:

     * In the **<UI-TERM key="ocp-performance-report.ReportTables.SqlInfo.SQLInfoTable.SqlText">SQL Text</UI-TERM>** section, you can view the complete SQL statement.

     * In the **<UI-TERM key="ocp-v2.Component.SQLDetail.ParallelSQLTraceTable.SqlExecutionProfiling">SQL Execution Profile</UI-TERM>** section, you can view the execution details of the SQL statement at the operator level in the data collection time range. For more information, see the **View the execution profile of an SQL statement** section in [View the details of an SQL statement](../100.manage-sql-diagnosis/1000.view-sql-details.md).

     * On the **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.Plan.HistoricalTrends">Previous Tendency</UI-TERM>** tab, you can view the historical trends and plan generation time of the SQL statement. For more information, see the **View the historical trends of an SQL statement** section in [View the details of an SQL statement](../100.manage-sql-diagnosis/1000.view-sql-details.md).

     * On the **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetailTabs.ExecutionPlan">Execution Plans</UI-TERM>** tab, you can view the execution plans of the SQL statement, or bind an execution plan to the statement. For more information, see the **View the execution plans of an SQL statement** section in [View the details of an SQL statement](../100.manage-sql-diagnosis/1000.view-sql-details.md).

     * On the **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetailTabs.Index">Index</UI-TERM>** tab, you can view the indexes bound to the SQL statement. For more information, see the **View and bind indexes** section in [View the details of an SQL statement](../100.manage-sql-diagnosis/1000.view-sql-details.md).

     * On the **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetailTabs.SqlThrottling">SQL Throttling</UI-TERM>** tab, you can view or set throttling for the SQL statement. For more information, see the **Set throttling for the SQL statement** section in [View the details of an SQL statement](../100.manage-sql-diagnosis/1000.view-sql-details.md).

     * You can view the binding records of the SQL statement in section ① as illustrated on the **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetailTabs.ExecutionPlan">Execution Plans</UI-TERM>**, **<UI-TERM key="ocp-v2.Capacity.Resource.Top.Index">Index</UI-TERM>**, and **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetailTabs.SqlThrottling">SQL Throttling</UI-TERM>** tabs.

       In the binding records, you can view the status of a bound execution plan, or click **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetailTabs.Unbind">Unbind</UI-TERM>** to unbind the plan from the SQL statement. You can click **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetailTabs.BindPlan">Bind Plan</UI-TERM>** to bind the plan to the SQL statement again.

     ![Image 178](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/0924633561/p440536.png)

7. Set throttling.

   * You can click **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetailTabs.SetThrottling">Enable Throttling</UI-TERM>** to enable throttling for the SQL statement. For more information, see the **Set throttling for the SQL statement** section in [View the details of an SQL statement](../100.manage-sql-diagnosis/1000.view-sql-details.md).

   * You can also select multiple SQL statements and click **<UI-TERM key="ocp-v2.Component.SQLTable.SetThrottling.2">Batch Set Throttling</UI-TERM>**. In the dialog box that appears, specify the maximum number of SQL statements that can be executed concurrently.
