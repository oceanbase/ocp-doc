View outlines
==================================

On the **<UI-TERM key="ocp-v2.Detail.SQLDiagnosis.Outline.OutlineInformation">Outlines</UI-TERM>** page, you can view the outlines of an OceanBase Database tenant, including the outlines for throttling, execution plan binding, and index binding.

Features
-----------------------------

The outline feature relies on the hint and plan cache features of OceanBase Database. The hint feature determines the selection of the physical plan generation path by specifying the index and the connection method. The plan cache caches physical plans for SQL statements. When the same SQL statement is executed again in the same environment, the system reads its execution plan from the plan cache. It does not have to go through the parser, resolver, rewriter, and optimizer modules again. This speeds up the execution of SQL statements. The outline feature uses hints to specify how to fix plans by modifying the physical execution plan in the plan cache.

Prerequisites
----------------------------------

* Make sure that you have the following permissions:
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.page.Diagnosis.SqlDiagnosis">SQL Diagnostics</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Detail.Resource.Unit.Tenant">Tenants</UI-TERM>**

* For a tenant in MySQL mode, the password box of the OceanBase Cloud Platform (OCP) user must contain the password of the tenant.

* For a tenant in Oracle mode, the password box of the OCP user must contain the password of the SYS tenant in the cluster.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>To bind indexes and execution plans and configure throttling, the logged-on tenant in the OCP console must have the permission to update the tenant .</p>
  </main>

Procedure
------------------------------

1. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Compaction.DetailV4.CompactionTenantListMyDrawer.Tenant">Tenants</UI-TERM>** and click the target tenant in the **<UI-TERM key="ocp-v2.Resource.Component.Block.Tenant">Tenants</UI-TERM>** list to go to the **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** page of the tenant.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Detail.Realtime.SqlDiagnosis">SQL Diagnostics</UI-TERM>** to go to the **<UI-TERM key="ocp-v2.Detail.Monitor.SqlDiagnosis">SQL Diagnostics</UI-TERM>** page.

   ![Image 136](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/8824633561/p440558.png)

3. Click **View Outlines** in the upper-right corner.

   The **<UI-TERM key="ocp-v2.Detail.SQLDiagnosis.Outline.OutlineInformation">Outlines</UI-TERM>** page that displays valid outlines automatically appears. You can perform the following operations on this page:
   * Click **<UI-TERM key="ocp-v2.Detail.SQLDiagnosis.Outline.CancelThrottling">Disable Throttling</UI-TERM>** or **<UI-TERM key="ocp-v2.Detail.SQLDiagnosis.Outline.Unbind">Unbind</UI-TERM>** in the **<UI-TERM key="ocp-v2.page.Task.Operation">Actions</UI-TERM>** column.

   * Click a value in the **<UI-TERM key="ocp-v2.Detail.SQLDiagnosis.Outline.SqlIdText">SQL ID/Text</UI-TERM>** column to go to the details page of the corresponding SQL statement. For more information about the operations that you can perform on the SQL Details page, see [View SQL statement details](../100.manage-sql-diagnosis/1000.view-sql-details.md).

   ![137](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/8824633561/p440559.png)

4. Click the **<UI-TERM key="ocp-v2.component.MonitorSearch.All">All</UI-TERM>** tab, and you can view information of all outlines that were created or deleted in OCP in the past 30 days.

5. Click **Export Valid Outlines** in the upper-right corner to export all columns except the **<UI-TERM key="ocp-v2.page.OBProxy.Operation">Actions</UI-TERM>** column on the page to an Excel file.
