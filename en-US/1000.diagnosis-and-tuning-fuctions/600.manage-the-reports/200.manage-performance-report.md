# Manage performance reports

This topic describes how to use a performance report. A performance report provides you with information about the cluster load, performance, and SQL statements within a specified period of time, and helps you learn the cluster running status and troubleshoot performance-related issues.

You can view and manage performance reports by using the following methods:

* **Method 1**: Log in to the OceanBase Cloud Platform (OCP) console. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Diagnosis.AutonomousService">OceanBase Autonomy Service</UI-TERM>**. On the page that appears, find the target cluster and click its name to go to the **<UI-TERM key="ocp-v2.Detail.Report.ReportCenter">Report Center</UI-TERM>** page.

* **Method 2**: Log in to the OCP console, go to the **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** page of the target cluster, and click **<UI-TERM key="ocp-v2.src.util.menu.PerformanceReport">Performance Report</UI-TERM>** on the left side.

<main id="notice" type='notice'>
  <h4>Applicability</h4>
  <p>This topic applies only to OCP Enterprise Edition. OCP Community Edition does not support this feature. </p>
</main>

## Introduction

OCP can generate cluster performance reports. On the **<UI-TERM key="ocp-v2.Detail.Report.PerformanceReport">Performance Report</UI-TERM>** page, you can view report information in the following columns: **<UI-TERM key="ocp-v2.Report.Component.GenerateReportModal.ReportName">Report Name</UI-TERM>**, **<UI-TERM key="ocp-v2.Detail.Report.StartSnapshotPoint">Snapshot Start Point</UI-TERM>**, **<UI-TERM key="ocp-v2.Detail.Report.EndSnapshot">Snapshot End Point</UI-TERM>**, **<UI-TERM key="ocp-v2.component.ParameterTemplate.Founder">Created By</UI-TERM>**, **<UI-TERM key="ocp-v2.Detail.Report.GenerationStatus">Generation Status</UI-TERM>**, and **<UI-TERM key="ocp-v2.Detail.Report.GenerationTime">Generation Time</UI-TERM>**. The **<UI-TERM key="ocp-v2.Cluster.Arbitration.Operation">Actions</UI-TERM>** column provides the **<UI-TERM key="ocp-v2.src.constant.inspection.ViewReports">View Report</UI-TERM>** and **<UI-TERM key="ocp-v2.src.constant.inspection.DownloadReport">Download Report</UI-TERM>** options.

* You can sort the reports by **<UI-TERM key="ocp-v2.Detail.Report.StartSnapshotPoint">Snapshot Start Point</UI-TERM>**, **<UI-TERM key="ocp-v2.Report.Component.GenerateReportModal.EndSnapshot">Snapshot End Point</UI-TERM>**, and **<UI-TERM key="ocp-v2.Detail.Report.GenerationTime">Generation Time</UI-TERM>**.

* You can filter the reports by **<UI-TERM key="ocp-v2.Detail.Report.GenerationStatus">Generation Status</UI-TERM>**.

## Prerequisites

* To manage the performance reports of a cluster by using **Method 1**, make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** permission
  * Permission on the **<UI-TERM key="ocp-v2.src.hook.useMenu.ReportCenter">Report Center</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.hook.useMenu.AutonomousService">OceanBase Autonomy Service</UI-TERM>**

* To manage the performance reports of a cluster by using **Method 2**, make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.Report.PerformanceReport">Performance Report</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>**

## Procedure

The procedure of **Method 1** is described as follows:

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.hook.useMenu.AutonomousService">OceanBase Autonomy Service</UI-TERM>**.

3. In the **<UI-TERM key="ocp-v2.page.Diagnosis.ClusterDetails">Cluster Details</UI-TERM>** section, click the name of the cluster that you want to view. The **<UI-TERM key="ocp-v2.Detail.Realtime.RealTimeDiagnosis">Real-time Diagnostics</UI-TERM>** page appears.

4. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Detail.Report.ReportCenter">Report Center</UI-TERM>**.

5. Go to the **<UI-TERM key="ocp-v2.Report.Detail.PerformanceReport">Performance Report</UI-TERM>** tab.

6. Click **<UI-TERM key="ocp-v2.Detail.Report.GeneratePerformanceReports">Generate Performance Report</UI-TERM>**.

7. In the dialog box that appears, set the following parameters.
   ![07062023](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9345265261/p292019.png)

   |  Parameter   |                     Description                      |
   |-------|---------------------------------------------|
   | Report Name   | Required. The name of the report.                                    |
   | Snapshot Start Point | You can select only a point in time in the past 30 days. The available points in time are fixed and cannot be customized.        |
   | Snapshot End Point | You can select only a point in time within 24 hours after the time you specified for **<UI-TERM key="ocp-v2.Detail.Report.StartSnapshotPoint">Snapshot Start Point</UI-TERM>**. The available points in time are fixed and cannot be customized. |

8. If the SQL monitoring data of a tenant is abnormal in the performance report, select the tenant from the **<UI-TERM key="ocp-v2.Detail.Report.GoToTenantActiveSession">View OceanBase Tenant ASH Report</UI-TERM>** drop-down list to go to the **<UI-TERM key="ocp-v2.Session.Report.Detail.ActiveSessionHistoryReport">ASH Report</UI-TERM>** page of the tenant.

   ![09141847](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/7965723461/p394049.png)

9. Click **<UI-TERM key="ocp-v2.component.MyDrawer.Determine">OK</UI-TERM>**. A report is generated for the performance between the snapshot start point and the snapshot end point. OCP saves performance reports generated in the last 90 days. You can view and download a report in the report list.

   * To view a performance report, click **<UI-TERM key="ocp-v2.Inspection.Item.ViewReports">View Report</UI-TERM>** in the **<UI-TERM key="ocp-v2.MultiAzone.Parameter.Operation">Actions</UI-TERM>** column.

   * To download a performance report in the HTML format, click **<UI-TERM key="ocp-v2.src.constant.inspection.DownloadReport">Download Report</UI-TERM>** in the **<UI-TERM key="ocp-v2.page.Host.Operation">Actions</UI-TERM>** column.

## Report content

You can view the following information in a performance report:

* Basic information

  |    Parameter    | Description    |
  |----------|---------|
  | Basic Cluster Information   | The cluster version, cluster type, number of hosts, number of tenants, and start time and end time of the last major compaction. <blockquote>**<UI-TERM key="ocp-v2.Detail.Parameter.Description">Note</UI-TERM>**</br>If the version of OceanBase Database is V4.0 or later, you cannot view information related to major compactions. </blockquote> |
  | Node Basic Information   | The host IP address, zone, availability of RootServer, status, service start time, and last offline time.                                                      |
  | Node Resources   | The host IP address, zone, total CPU cores, allocated CPU cores, allocated CPU resources in percentage, total memory in MB, allocated memory in MB, allocated memory in percentage, total disk space in GB, used disk space in GB, and disk usage in percentage. |
  | Node Partitions | The host IP address, zone, associated tenants, number of partitions, and number of leader partitions. Note that the number of partitions includes the number of leader partitions.  <blockquote>**<UI-TERM key="ocp-v2.Detail.Parameter.Description">Note</UI-TERM>**</br>If the version of OceanBase Database is V4.0 or later, you cannot view partition information about nodes. </blockquote> |
  | Tenant Resources   | The tenant name, tenant ID, tenant type, resource unit configuration, zone priority, locality, and server list.                                                        |
  | Tenant Capacity | The associated tenants, tenant ID, associated hosts, and data capacity.                                                                                  |

* **<UI-TERM key="ocp-v2.Report.AWR.CacheStatistics">Cache Statistics</UI-TERM>**

  This module provides the average KV cache hit rate of tenants. The statistics are sourced from the OceanBase Database view `gv$systat`. The hit rate is accurate to two decimal places.

  You can view the statistics of the following 7 types of caches: block cache, block index cache, clog cache, clog index cache, Bloom filter cache, location cache, and row cache.
  The following statistics are displayed: cache hit rate, cache requests, and cache size.
  
   <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>In the statistic report, you can hover the pointer over a parameter in the table header to view the parameter description. </p>
   </main>
  
  |  Parameter   |                                                                            Description                                                                            |
  |-------|----------------------------------------------------------------------------------------------------------------------------------------------------------|
  | Cache Hit Rate | The hit rates of different types of caches in different tenants during the snapshot period. For more information about the cache types, see [Caching](https://www.oceanbase.com/docs/oceanbase-database/oceanbase-database/V3.2.1/caching-mechanism). |
  | Cache Request  | Information about caches and cache requests in different tenants during the snapshot period, such as the number of cache requests, cache hits, and cache mishits.                                                                                                                   |
  | Cache Size  | The size of different types of caches in different tenants during the snapshot period. The start and end positions are displayed.                                                                                                                             |
