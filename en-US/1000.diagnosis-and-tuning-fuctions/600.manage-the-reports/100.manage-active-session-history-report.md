# Manage ASH reports

This topic describes how to generate and view Active Session History (ASH) reports. An ASH report allows you to learn about the SQL statements that use the most database resources during a diagnostic period, the execution details of historical sessions of an OceanBase cluster, and other information. You can optimize the SQL statements based on the information and improve the SQL execution efficiency.

You can view and manage ASH reports by using one of the following methods:

* **Method 1**: Log in to the OceanBase Cloud Platform (OCP) console. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Diagnosis.AutonomousService">OceanBase Autonomy Service</UI-TERM>**. On the page that appears, find the target cluster and click its name to go to the **<UI-TERM key="ocp-v2.Detail.Report.ReportCenter">Report Center</UI-TERM>** page.

* **Method 2**: Log in to the OCP console and go to the **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">Overview</UI-TERM>** page of the target tenant. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Detail.Realtime.SessionManagement">Session Management</UI-TERM>** and go to the **Active Session History Report** tab.

  <h4>Applicability</h4>

## Prerequisites

* To manage the ASH reports of a cluster by using **Method 1**, make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.Report.ReportCenter">Report Center</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.hook.useMenu.AutonomousService">OceanBase Autonomy Service</UI-TERM>**

* To manage the ASH reports of a cluster by using **Method 2**, make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.Realtime.SessionManagement">Session Management</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.constant.auditEvent.Tenant">Tenants</UI-TERM>**

* You have enabled parameters in the **<UI-TERM key="ocp-v2.component.OperationConfig.List.ActiveSessionHistoryCollection">ASH Collection</UI-TERM>** section by referring to [Manage parameters](../../600.cluster-functions/300.manage-a-cluster/1200.manage-om-configuration/200.manage-om-configuration-parameters.md).

## Procedure

The procedure of **Method 1** is described as follows:

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Diagnosis.AutonomousService">OceanBase Autonomy Service</UI-TERM>**.

3. In the **<UI-TERM key="ocp-v2.page.Diagnosis.ClusterDetails">Cluster Details</UI-TERM>** section, click the name of the cluster that you want to view. The **<UI-TERM key="ocp-v2.Detail.Realtime.RealTimeDiagnosis">Real-time Diagnostics</UI-TERM>** page appears.

4. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.hook.useMenu.ReportCenter">Report Center</UI-TERM>**.

5. Go to the **Active Session History Report** tab.

6. Click **<UI-TERM key="ocp-v2.Session.Report.GenerateReports">Generate Report</UI-TERM>**.

   The **<UI-TERM key="ocp-v2.Session.Report.GenerateReportModal.GenerateActiveSessionHistoryReports">Generate ASH Report</UI-TERM>** dialog box appears.

7. Specify **<UI-TERM key="ocp-v2.Session.Report.GenerateReportModal.AnalysisTime">Analysis Time</UI-TERM>** and **<UI-TERM key="ocp-v2.Detail.Report.ReportName">Report Name</UI-TERM>**.

   * **<UI-TERM key="ocp-v2.Session.Report.GenerateReportModal.AnalysisTime">Analysis Time</UI-TERM>**: Specify the start time and end time for active session analysis.

   * **<UI-TERM key="ocp-v2.Detail.Report.ReportName">Report Name</UI-TERM>**: The report name is automatically generated based on the specified time in the following format: "OBASH_cluster name_tenant name_start time_end time". You can also use a custom report name.

   ![09134113](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/9628667361/p345671.png)

8. Click **<UI-TERM key="ocp-v2.Auth.Org.CreateOrg.Ok">OK</UI-TERM>**.

   Wait until the report is generated.

9. In the **<UI-TERM key="ocp-v2.Session.Report.ReportList">Reports</UI-TERM>** list, enter the name of report or creator in the search box and click the search icon. The reports that meet the filter condition are displayed in the **<UI-TERM key="ocp-v2.Session.Report.ReportList">Reports</UI-TERM>** list.

   * Click **<UI-TERM key="ocp-v2.Detail.Overview.View">View</UI-TERM>** in the **<UI-TERM key="ocp-v2.Statistics.components.StatTable.Operation">Actions</UI-TERM>** column to view the report online.

   * Click **<UI-TERM key="ocp-v2.Information.Detail.DownloadCollectDrawer.Download">Download</UI-TERM>** in the **<UI-TERM key="ocp-v2.Alarm.Shield.Operation">Actions</UI-TERM>** column to download the report and view it on your local machine.

## Report content

You can view the following information in an ASH report:

* **<UI-TERM key="ocp-v2.Component.OBServerList.OBServerModal.BasicInformation">Basic Information</UI-TERM>**

  |    Parameter     |                                               Description                                               |
  |-----------|------------------------------------------------------------------------------------------------|
  | Basic information of the report   | The information of data analysis is provided in the following columns: **<UI-TERM key="ocp-v2.Log.Trace.StartTime">Start Time</UI-TERM>**, **<UI-TERM key="ocp-v2.Statistics.components.TaskTable.EndTime">End Time</UI-TERM>**, **<UI-TERM key="ocp-performance-report.ReportTable.BasicInfo.BasicInfo.ElapsedTime">Elapsed Time</UI-TERM>**, **Sample Points**, and **<UI-TERM key="ocp-performance-report.ReportTable.ActivityOverTime.ActivityOverTimeTable.AverageNumberOfActiveSessions">Average Active Sessions</UI-TERM>**.                                                        |
  | Basic information of the tenant   | The basic information of the target tenant is provided in the following columns: **<UI-TERM key="ocp-performance-report.ReportTables.RpcStatInfo.GtsRpcTenantTable.TenantName">Tenant Name</UI-TERM>**, **<UI-TERM key="ocp-v2.component.ModifyClusterParameterDrawer.Cluster">Cluster</UI-TERM>**, **<UI-TERM key="ocp-v2.Backup.Component.BackupNowDrawer.ObVersion">OceanBase Version</UI-TERM>**, **<UI-TERM key="ocp-v2.component.TenantList.TenantMode">Mode</UI-TERM>**, **<UI-TERM key="ocp-performance-report.ReportTable.BasicInfo.TenantBasicInfo.NumberOfReplicas">Replicas</UI-TERM>**, **<UI-TERM key="ocp-performance-report.ReportTable.BasicInfo.TenantBasicInfo.TenantCreationTime">Tenant Creation Time</UI-TERM>**, **<UI-TERM key="ocp-performance-report.ReportTable.BasicInfo.TenantBasicInfo.DeploymentDistribution">Replica Distribution</UI-TERM>**, and **<UI-TERM key="ocp-performance-report.ReportTables.BasicInfo.TenantInfoTable.ZonePriority">Primary Zone</UI-TERM>**.                         |
  | Basic information of the tenant resources | The information of the tenant resources is provided in the following columns: **<UI-TERM key="ocp-v2.Component.OBServerList.OBServerModal.BelongsZone">Zone</UI-TERM>**, **OBServer**, **<UI-TERM key="ocp-performance-report.ReportTable.BasicInfo.TenantResInfoTable.UnitResourceConfiguration">Unit Resource Configuration</UI-TERM>**, **<UI-TERM key="ocp-performance-report.ReportTable.BasicInfo.TenantResInfoTable.ReplicaType">Replica Type</UI-TERM>**, **Active MemStore Size Limit (GB)**, and **MemStore Size Limit (GB)**. |

* **<UI-TERM key="ocp-performance-report.pages.ASH.ReportContent.TopPendingEvents">Top Wait Events</UI-TERM>**

  The top 5 events with the longest wait time are displayed.
  
* **<UI-TERM key="ocp-performance-report.pages.ASH.ReportContent.TopsqlCommandType">Command Types of Top SQLs</UI-TERM>**

  The following information is displayed: **TopSQL's SQL Command Type**, **<UI-TERM key="ocp-performance-report.ReportTable.TopLoadProfile.TopLoadProfileTable.UniqueSqlId">Unique SQL IDs</UI-TERM>**, **<UI-TERM key="ocp-performance-report.ReportTable.TopLoadProfile.TopLoadProfileTable.PercentageOfResponseTime">Proportion of Response Time (%)</UI-TERM>**, and **<UI-TERM key="ocp-performance-report.ReportTable.SQL.SordByWaitEventTable.AverageNumberOfActiveSessions">Average Active Sessions</UI-TERM>**.
  
* **<UI-TERM key="ocp-performance-report.pages.Report.Content.SqlStatistics">SQL Statistics</UI-TERM>**

  * SQL statements sorted by wait time: The top 5 SQL statements with the longest wait time are displayed.

  * List of full SQL text: The full text of the top 5 SQL statements with the longest wait time is displayed.

* **<UI-TERM key="ocp-performance-report.pages.ASH.SessionsSortedByWaitingEvent">Sessions Sorted by Wait Events</UI-TERM>**

  The following information is displayed: the top 5 sessions with the highest wait event activity rate, and top 3 wait events with the longest wait time among these sessions.
  
* **<UI-TERM key="ocp-performance-report.pages.ASH.ActiveTimeSlice">Activity Time Slices</UI-TERM>**

  The following information is displayed: **<UI-TERM key="ocp-v2.page.Task.StartTime">Start Time</UI-TERM>**, **<UI-TERM key="ocp-v2.Trace.Visualizer.EndTime">End Time</UI-TERM>**, and **<UI-TERM key="ocp-v2.Detail.Monitor.TimeRange">Duration</UI-TERM>** of all time slices, as well as **<UI-TERM key="ocp-performance-report.ReportTable.SQL.SordByWaitEventTable.AverageNumberOfActiveSessions">Average Active Sessions</UI-TERM>**, **<UI-TERM key="ocp-performance-report.ReportTable.TopSession.TopSessionEventsTable.TopWaitingEvents">Top 3 Wait Events</UI-TERM>**, **Wait Event Activity Rate**, and **Proportion of Wait Event Time**.
