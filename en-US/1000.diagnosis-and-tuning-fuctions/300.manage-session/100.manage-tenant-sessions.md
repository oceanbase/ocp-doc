# Manage the sessions of a tenant

This topic describes how to manage the sessions of a tenant.

You can access the session management page by using one of the following methods:

* **Method 1**: Log in to the OceanBase Cloud Platform (OCP) console. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.hook.useMenu.AutonomousService">OceanBase Autonomy Service</UI-TERM>**. On the page that appears, find the target cluster and click its name to go to the **<UI-TERM key="ocp-v2.Detail.Realtime.RealTimeDiagnosis">Real-time Diagnostics</UI-TERM>** page. Then, click the **<UI-TERM key="ocp-v2.src.util.menu.SessionManagement">Session Management</UI-TERM>** tab.

* **Method 2**: Log in to the OCP console and go to the **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">Overview</UI-TERM>** page of the target tenant. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Iframe.SessionManagement">Session Management</UI-TERM>** to go to the **<UI-TERM key="ocp-v2.Realtime.Session.TenantSession">Tenant Session</UI-TERM>** tab.

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>OCP Community Edition does not support OceanBase Autonomy Service. To use this service, go to the relevant page by using <b>Method 2</b>. </p>
</main>

## Prerequisites

* To manage the sessions of a tenant by using **Method 1**, make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">Real-time Diagnostics</UI-TERM>** menu of **<UI-TERM key="ocp-v2.page.Diagnosis.AutonomousService">OceanBase Autonomy Service</UI-TERM>**

* To manage the sessions of a tenant by using **Method 2**, make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.Realtime.SessionManagement">Session Management</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Compaction.DetailV4.CompactionTenantListMyDrawer.Tenant">Tenants</UI-TERM>**

## Procedure

The procedure of **Method 1** is described as follows:

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Diagnosis.AutonomousService">OceanBase Autonomy Service</UI-TERM>**.

3. In the **<UI-TERM key="ocp-v2.page.Diagnosis.ClusterDetails">Cluster Details</UI-TERM>** section, click the name of the cluster that you want to view.

4. Go to the **<UI-TERM key="ocp-v2.src.util.menu.SessionManagement">Session Management</UI-TERM>** tab of the **<UI-TERM key="ocp-v2.Detail.Realtime.RealTimeDiagnosis">Real-time Diagnostics</UI-TERM>** page. The **<UI-TERM key="ocp-v2.Detail.Session.TenantSession">Tenant Session</UI-TERM>** tab appears.

5. View all sessions.

    The **<UI-TERM key="ocp-v2.Realtime.Session.TenantSession">Tenant Session</UI-TERM>** tab displays information about all sessions of the current tenant in the following columns: **<UI-TERM key="ocp-v2.Transaction.Detail.SessionId">Session ID</UI-TERM>**, **SQL**, **SQL ID**, **<UI-TERM key="ocp-v2.Detail.Component.ChangeUserLinkModal.User">User</UI-TERM>**, **<UI-TERM key="ocp-v2.Detail.Session.List.Source">Source</UI-TERM>**, **<UI-TERM key="ocp-v2.Statistics.components.ManualCollectDrawer.DatabaseName">Database Name</UI-TERM>**, **<UI-TERM key="ocp-v2.Detail.Session.List.Command">Command</UI-TERM>**, **<UI-TERM key="ocp-v2.Detail.Session.List.ExecutionTimeS">Execution Time (s)</UI-TERM>**, **<UI-TERM key="ocp-v2.Statistics.components.StatTable.Status">Status</UI-TERM>**, **OBServer**, and **OBProxy**. You can search for a session by its ID.

6. View SQL information.

    For a session in the **ACTIVE** state, click the SQL text in the **SQL** column. In the dialog box that appears, you can view the SQL details of this session. You can copy the SQL text.

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/%E7%A7%9F%E6%88%B7sql-1.png)

7. Search for sessions.

    You can perform a search in the **<UI-TERM key="ocp-v2.Auth.User.loginHistory.User">User</UI-TERM>**, **<UI-TERM key="ocp-v2.Detail.Session.Statistics.Source">Source</UI-TERM>**, and **<UI-TERM key="ocp-v2.Detail.Overview.DatabaseName">Database Name</UI-TERM>** columns. You can click the search icon next to the column name to open the search box.

    ![08161423](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/4825306461/p254789.png)

8. View active sessions.

    You can select **<UI-TERM key="ocp-v2.Detail.Session.List.ViewOnlyActiveSessions">View Active Sessions Only</UI-TERM>** in the upper-right corner of the session list to view only sessions in the **ACTIVE** state.

    ![2020092205](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/%E6%9F%A5%E7%9C%8B%E6%B4%BB%E8%B7%83%E4%BC%9A%E8%AF%9D-1.png)

9. Close a session.

    Click **<UI-TERM key="ocp-v2.Detail.Session.List.CloseSession">Close Session</UI-TERM>** in the **<UI-TERM key="ocp-v2.Alarm.Subscriptions.Operation">Actions</UI-TERM>** column of a session to close it.

10. Exit the session query.

    Click the **<UI-TERM key="ocp-v2.Cluster.Component.MachineResource.SeeMore">More</UI-TERM>** icon in the **<UI-TERM key="ocp-v2.Alarm.Subscriptions.Operation">Actions</UI-TERM>** column and select **<UI-TERM key="ocp-v2.Detail.Session.List.CloseTheCurrentQuery">Close Current Query</UI-TERM>** to exit the query.

11. Configure end-to-end tracing.

    Click the **<UI-TERM key="ocp-v2.Component.AddBackupStrategy.ViewMore">More</UI-TERM>** icon in the **<UI-TERM key="ocp-v2.User.Component.AccessKeyCardTable.Operation">Actions</UI-TERM>** column and select **<UI-TERM key="ocp-v2.src.component.TraceConfigModal.FullLinkDiagnosticConfiguration">Full link tracking configuration</UI-TERM>**. For more information, see [Configure full link tracking for a tenant](../../700.tenant-functions/600.manage-a-tenant/600.full-link-diagnostic-configuration-of-tenant.md).

    <main id="notice" type='explain'>
      <h4>Note</h4>
      <p><ul><li>This option is available only when you access the session management page by using <b>Method 2</b>. </li><li>You can configure end-to-end tracing at the session level only in OceanBase Database V4.2.1 or later. </li></ul></p>
    </main>
