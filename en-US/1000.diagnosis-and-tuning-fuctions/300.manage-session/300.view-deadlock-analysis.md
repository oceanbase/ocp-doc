# View the deadlock history

This topic describes how to view the deadlock history.

You can view deadlock analysis information by using the following methods:

* **Method 1**: Log in to the OceanBase Cloud Platform (OCP) console. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Diagnosis.AutonomousService">OceanBase Autonomy Service</UI-TERM>**. On the page that appears, find the target cluster and click its name to go to the **<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">Real-time Diagnostics</UI-TERM>** page. Then, click the **<UI-TERM key="ocp-v2.Detail.Realtime.SessionManagement">Session Management</UI-TERM>** tab.

* **Method 2**: Log in to the OCP console and go to the **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** page of the target tenant. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Iframe.SessionManagement">Session Management</UI-TERM>** and go to the **<UI-TERM key="ocp-v2.Detail.Session.ViewDeadlockHistory">View Deadlock History</UI-TERM>** tab.

## Prerequisites

* To view the deadlock history by using **Method 1**, make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.Realtime.RealTimeDiagnosis">Real-time Diagnostics</UI-TERM>** menu of **<UI-TERM key="ocp-v2.page.Diagnosis.AutonomousService">OceanBase Autonomy Service</UI-TERM>**

* To view the deadlock history by using **Method 2**, make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.page.Iframe.SessionManagement">Session Management</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Detail.Resource.Unit.Tenant">Tenants</UI-TERM>**

* Automatic detection of deadlocks is enabled for the cluster where the tenant belongs. For more information, see [Enable automatic detection of deadlocks](../../600.cluster-functions/300.manage-a-cluster/1000.enable-automatic-deadlock-detection.md).

## Procedure

The procedure of **Method 1** is described as follows:

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Diagnosis.AutonomousService">OceanBase Autonomy Service</UI-TERM>**.

3. In the **<UI-TERM key="ocp-v2.page.Diagnosis.ClusterDetails">Cluster Details</UI-TERM>** section, click the name of the cluster that you want to view.

4. Go to the **<UI-TERM key="ocp-v2.page.Iframe.SessionManagement">Session Management</UI-TERM>** tab of the **<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">Real-time Diagnostics</UI-TERM>** page.

5. Click the **<UI-TERM key="ocp-v2.Detail.Session.ViewDeadlockHistory">View Deadlock History</UI-TERM>** tab and view the historical deadlock information.
