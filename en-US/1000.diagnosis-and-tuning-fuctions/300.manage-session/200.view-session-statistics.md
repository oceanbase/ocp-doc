# View session statistics

This topic describes how to view the session statistics of a tenant.

You can view the session statistics of a tenant by using the following methods:

* **Method 1**: Log in to the OceanBase Cloud Platform (OCP) console. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Diagnosis.AutonomousService">OceanBase Autonomy Service</UI-TERM>**. On the page that appears, find the target cluster and click its name to go to the **<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">Real-time Diagnostics</UI-TERM>** page. Then, click the **<UI-TERM key="ocp-v2.page.Iframe.SessionManagement">Session Management</UI-TERM>** tab.

* **Method 2**: Log in to the OCP console and go to the **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** page of the target tenant. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.util.menu.SessionManagement">Session Management</UI-TERM>** and go to the **<UI-TERM key="ocp-v2.Detail.Session.SessionStatistics">Session Statistics</UI-TERM>** tab.

<main id="notice" type='notice'>
   <h4>Applicability</h4>
   <p>OCP Community Edition does not support the OceanBase Autonomy Service. To use this service, go to the relevant page by using <b>Method 1</b>. </p>
</main>

## Prerequisites

* To view the session statistics of a tenant by using **Method 1**, make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">Real-time Diagnostics</UI-TERM>** menu of **<UI-TERM key="ocp-v2.page.Diagnosis.AutonomousService">OceanBase Autonomy Service</UI-TERM>**

* To view the session statistics of a tenant by using **Method 2**, make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.util.menu.SessionManagement">Session Management</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Backup.Backup.Data.Tenant">Tenants</UI-TERM>**

## Procedure

The procedure of **Method 1** is described as follows:

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.hook.useMenu.AutonomousService">OceanBase Autonomy Service</UI-TERM>**.

3. In the **<UI-TERM key="ocp-v2.page.Diagnosis.ClusterDetails">Cluster Details</UI-TERM>** section, click the name of the cluster that you want to view.

4. Go to the **<UI-TERM key="ocp-v2.src.util.menu.SessionManagement">Session Management</UI-TERM>** tab of the **<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">Real-time Diagnostics</UI-TERM>** page.

5. Click the **<UI-TERM key="ocp-v2.Detail.Session.SessionStatistics">Session Statistics</UI-TERM>** tab and view the statistics of all sessions of the tenant.

   You can view the overall session statistics, such as the total number of sessions, number of active sessions, and maximum duration of active sessions. Statistics about the total number of sessions and the number of active sessions are further displayed by user, IP address, and database.

   <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>Statistics by IP address are provided only for OceanBase Database V2.2.30 and later. </p>
   </main>
