# View a materialized view

This topic describes how to view details of a materialized view of a tenant.

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OCP Enterprise Edition. OCP Community Edition does not support this feature.</p>
</main>

## Prerequisites

The user logged in to OCP has the following permissions:

* **Cluster Read-Only** or **Tenant Read-Only** resource permission.
* **Real-Time Diagnosis** permission for autonomous services.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Diagnosis.AutonomousService">OceanBase Autonomy Service</UI-TERM>**.

3. In the **<UI-TERM key="ocp-v2.page.Diagnosis.ClusterDetails">Cluster Details</UI-TERM>** section, click the name of the cluster that you want to view.

4. In the **<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">Real-time Diagnostics</UI-TERM>** section, go to the **Materialized View** tab and select a tenant.

5. On the **List** tab, you can view all automatically refreshed materialized views of the selected tenant. The view information includes **ID**, **<UI-TERM key="ocp-v2.Detail.Session.Statistics.Database">Database</UI-TERM>**, **<UI-TERM key="ocp-v2.Host.Detail.OCPAgent.Name">Name</UI-TERM>**, **View Definition**, **Build Mode**, **Refresh Mode**, **Refresh Method**, **Refresh Interval**, **Current Latency (s)**, **Next Refresh**, **Last Refresh Time**, and **Last Refresh Time (s)**.

   * You can filter views by **<UI-TERM key="ocp-v2.Session.LockAnalysis.Database">Database</UI-TERM>**.
   * To view the details of a view definition, click **<UI-TERM key="ocp-v2.Detail.Backup.See">View</UI-TERM>** in the **View Definition** column.

6. On the **Refresh Records** tab, you can view the refresh records of the selected tenant. The record information includes **ID**, **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetail.Database">Database</UI-TERM>**, **<UI-TERM key="ocp-v2.MultiCluster.Detail.Name">Name</UI-TERM>**, **Refresh Method**, **Refresh Time (s)**, **<UI-TERM key="ocp-v2.TraceContent.PlanOperation.StartTime">Start Time</UI-TERM>**, **<UI-TERM key="ocp-v2.Trace.Visualizer.EndTime">End Time</UI-TERM>**, and **Result**.

   * You can filter records by time range. By default, the system displays records of the last 3 hours. You can select a time range in the upper-right corner to view records of that time range.
   * You can filter refresh records by selecting the **View Only Timeout Records** or **View Base Table Content** check box. If you select a check box, only refresh records that meet the condition are displayed. If you select **View Base Table Content**, the **Number of Rows Inserted to Base Table**, **Number of Rows Updated in Base Table**, and **Number of Rows Deleted from Base Table** columns are displayed below the list.
   * You can filter refresh records by **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetail.Database">Database</UI-TERM>**.
