# Delete an alert push

This topic describes how to delete an alert push. 

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance**, **Tenant Maintenance**, **OBProxy Maintenance**, **Arbitration Service Maintenance**, **Binlog Service Maintenance**, or **Host Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Component.ArbitrationTransfer.All">All</UI-TERM>** menu of the **<UI-TERM key="ocp-v2.page.Alarm.Alarm">Alert Center</UI-TERM>**

* You have created an alert push. For more information, see [Creat an alert push](../600.manage-alert-push/100.create-an-alert-push.md). 

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console. 

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Alarm.Alarm">Alert Center</UI-TERM>**. 

3. Click the **Alert Pushes** tab. 

4. On the **Alert Pushes** tab, specify search criteria in the search area to search for alert pushes. Exact match is supported. All alert pushes that match the search criteria will be displayed in the **<UI-TERM key="ocp-v2.Alarm.Subscriptions.PushConfigurationList">Push Configurations</UI-TERM>** list. 

5. Find the target alert push and click **<UI-TERM key="ocp-v2.Component.ServiceName.Delete">Delete</UI-TERM>** in the **<UI-TERM key="ocp-v2.Component.OBServerList.Operation">Actions</UI-TERM>** column. 

5. In the dialog box that appears, click **<UI-TERM key="ocp-v2.ResourceManager.ResourceGroupConfig.SelectGroupName.Delete">Delete</UI-TERM>**.
