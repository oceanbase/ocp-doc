# Monitoring metrics for custom alerts

This topic lists the monitoring metrics that are not configured with alerts in the current version. If you need alerts, you can configure them using OCP's custom alert feature.

## Background information

OCP has built-in many alert items based on the supported monitoring metrics. For more information, see [Alert reference overview](../1900.reference-guide/100.alarm-reference/100.alert-reference-overview.md).

For the remaining monitoring metrics that are not configured with alerts, you can configure alerts by using custom alerts. For detailed operations, see [Create an alert rule](300.manage-alert-rules/100.create-an-alert-rule.md).
