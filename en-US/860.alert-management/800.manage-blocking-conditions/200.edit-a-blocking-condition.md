# Edit an alert blocking condition

This topic describes how to edit an alert blocking condition. 

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance**, **Tenant Maintenance**, **OBProxy Maintenance**, **Arbitration Service Maintenance**, **Binlog Service Maintenance**, or **Host Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.alarm.FormListWithExclude.ClusterWithExclude.All">All</UI-TERM>** menu of the **<UI-TERM key="ocp-v2.src.hook.useMenu.AlarmCenter">Alert Center</UI-TERM>**

* You have created a blocking condition. For more information, see [Create a blocking condition](100.create-a-blocking-condition.md). 

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console. 

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.page.Alarm.Alarm">Alert Center</UI-TERM>**.

3. Click the **<UI-TERM key="ocp-v2.component.alarm.ShieldModal.ShieldedAlarm">Alert Blocking</UI-TERM>** tab.

4. On the **<UI-TERM key="ocp-v2.component.alarm.ShieldModal.ShieldedAlarm">Alert Blocking</UI-TERM>** tab, specify search criteria in the search area to search for blocking conditions. Exact match is supported. All blocking conditions that match the search criteria will be displayed in the masking list.

5. Find the target blocking condition and click **<UI-TERM key="ocp-v2.Alarm.Channel.Editing">Edit</UI-TERM>** in the **<UI-TERM key="ocp-v2.component.ParameterTemplate.Operation">Actions</UI-TERM>** column.

   In the **<UI-TERM key="ocp-v2.Alarm.Shield.EditMaskConditions">Edit Blocking Condition</UI-TERM>** panel, modify the configurations of the blocking condition. For more information about the parameters, see [Create a blocking condition](100.create-a-blocking-condition.md).

6. Click **<UI-TERM key="ocp-v2.Detail.ResourceManager.CreateResourcePlan.Ok">OK</UI-TERM>**.
