# Delete an alert rule

A system administrator and OceanBase Cloud Platform (OCP) alert administrator can delete alert rules. System built-in alert rules cannot be deleted.

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance**, **Tenant Maintenance**, **OBProxy Maintenance**, **Arbitration Service Maintenance**, **Binlog Service Maintenance**, or **Host Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Plan.Component.PlanTemplateTable.All">All</UI-TERM>** menu of the **<UI-TERM key="ocp-v2.src.hook.useMenu.AlarmCenter">Alert Center</UI-TERM>**

* You have created an alert rule. For more information, see [Create an alert rule](../300.manage-alert-rules/100.create-an-alert-rule.md). You can delete only custom alert rules.

## Procedure

1. Log on to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Alarm.Alarm">Alert Center</UI-TERM>**.

3. Click the **<UI-TERM key="ocp-v2.Alarm.Rule.Detail.AlertRules">Alert Rules</UI-TERM>** tab.

4. On the **<UI-TERM key="ocp-v2.Alarm.Rule.AlertRules">Alert Rules</UI-TERM>** tab, find the specified alert rule.

5. In the **<UI-TERM key="ocp-v2.Settings.Credential.Host.Operation">Actions</UI-TERM>** column of the alert rule, click the More icon (**...**) and select **<UI-TERM key="ocp-v2.page.External.Delete">Delete</UI-TERM>**.

   ![Image 122](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E5%88%A0%E9%99%A4%E5%91%8A%E8%AD%A6%E8%A7%84%E5%88%992.png)

6. In the confirmation dialog box that appears, click **<UI-TERM key="ocp-v2.User.MySQL.Delete">Delete</UI-TERM>**.
