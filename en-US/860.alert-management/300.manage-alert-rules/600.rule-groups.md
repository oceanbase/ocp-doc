# Alert rule groups

To facilitate alert pushing, OceanBase Cloud Platform (OCP) allows you to create alert rule groups.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance**, **Tenant Maintenance**, **OBProxy Maintenance**, **Arbitration Service Maintenance**, **Binlog Service Maintenance**, or **Host Maintenance** permission
* **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.alarm.FormListWithExclude.ArbitrationServiceWithExclude.All">All</UI-TERM>** menu of the **<UI-TERM key="ocp-v2.page.Alarm.Alarm">Alert Center</UI-TERM>**

## Procedure

### Manage rule groups

1. Log on to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Alarm.Alarm">Alert Center</UI-TERM>**.

3. Click the **<UI-TERM key="ocp-v2.Alarm.Event.Detail.AlertRules">Alert Rules</UI-TERM>** tab.

4. Manage rule groups in the left-side navigation pane of the **<UI-TERM key="ocp-v2.page.Alarm.AlertRules">Alert Rules</UI-TERM>** tab.

   * Create a custom group: Click the Create icon next to **Rule Groups** and enter the name of the new group.

     ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E6%96%B0%E5%BB%BA%E5%91%8A%E8%AD%A6%E5%88%86%E7%BB%84.png)

   * Change the name of a group: Click the **<UI-TERM key="ocp-v2.page.Welcome.SeeMore">More</UI-TERM>** icon next to a specific group and select **<UI-TERM key="ocp-v2.Detail.Component.RenameTenantModal.Rename">Rename</UI-TERM>**.

     ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E5%91%8A%E8%AD%A6%E9%87%8D%E5%91%BD%E5%90%8D.png)

   * Copy a group: Click the **<UI-TERM key="ocp-v2.Component.AddBackupStrategy.ViewMore">More</UI-TERM>** icon next to a specific group and select **<UI-TERM key="ocp-v2.page.External.Copy">Copy</UI-TERM>**.

      The system creates a group based on the source group. The new group contains the alert rule information of the source group. By default, the name of the new group is in the format of "name of the source group_Copy. You can rename the new group.

   * Delete a group: Click the **<UI-TERM key="ocp-v2.page.Welcome.SeeMore">More</UI-TERM>** icon next to a specific group and select **<UI-TERM key="ocp-v2.component.ZoneFormList.Delete">Delete</UI-TERM>**.

     <main id="notice" type='explain'>
     <h4>Note</h4>
     <p>Built-in groups in the system cannot be renamed or deleted. </p>
     </main>

### View alert rules in a group

1. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.Layout.BasicLayout.Alert">Alerts</UI-TERM>**.

2. On the **<UI-TERM key="ocp-v2.Alarm.Rule.AlertRules">Alert Rules</UI-TERM>** tab, view all rule groups in the **Rule Groups** section.

   Click the name of a group. All alert rules in the group are displayed on the right.

   ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E6%9F%A5%E7%9C%8B%E5%91%8A%E8%AD%A6%E5%88%86%E7%BB%84.png)

3. Specify search criteria in the search section at the top of the page. The alert rules that match the search criteria will be displayed.

### Add alert rules to a group

* Add a single alert rule to a group:

   1. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.Backup.Component.BackupAlarm.Alarm">Alerts</UI-TERM>**.

   2. On the **<UI-TERM key="ocp-v2.Alarm.Rule.AlertRules">Alert Rules</UI-TERM>** tab, find the specified alert rule.

   3. In the Actions column of the alert rule, click the **<UI-TERM key="ocp-v2.Component.AddBackupStrategy.ViewMore">More</UI-TERM>** icon and select **<UI-TERM key="ocp-v2.Alarm.Rule.AddToRuleGroup">Add to Rule Group</UI-TERM>**.

   4. In the dialog box that appears, select a rule group.

   5. Click **<UI-TERM key="ocp-v2.MultiCluster.Detail.Determine">OK</UI-TERM>**.

      ![4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/Image%20117.png)

* Add multiple alert rules to a group:

   1. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.page.Information.Alert">Alerts</UI-TERM>**.

   2. On the **<UI-TERM key="ocp-v2.Alarm.Rule.Detail.AlertRules">Alert Rules</UI-TERM>** tab, select the alert rules that you want to add.

   3. Click **<UI-TERM key="ocp-v2.Alarm.Rule.AddToRuleGroupsInBatches">Batch Add to Rule Group</UI-TERM>**.

   4. In the dialog box that appears, select a rule group.

   5. Click **<UI-TERM key="ocp-v2.page.AuditEvent.Determine">OK</UI-TERM>**.

      ![5](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E6%89%B9%E9%87%8F%E6%B7%BB%E5%8A%A0%E5%88%B0%E5%91%8A%E8%AD%A6%E5%88%86%E7%BB%842.png)

   <main id="notice" type='explain'>
   <h4>Note</h4>
   <p>Ensure that each alert rule is added to a rule group so that related personnel can be notified in case alerts are generated based on the alert rule.</p>
   </main>

### Remove alert rules

1. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.src.constant.auth.Alert">Alerts</UI-TERM>**.

2. On the **<UI-TERM key="ocp-v2.Alarm.Rule.New.AlertRules">Alert Rules</UI-TERM>** tab, select a group from the **Rule Groups** list in the left-side navigation pane. All alert rules in the group are displayed on the right.

   Click **<UI-TERM key="ocp-v2.Alarm.Rule.Remove">Remove</UI-TERM>** in the **<UI-TERM key="ocp-v2.Cluster.Arbitration.Operation">Actions</UI-TERM>** column of an alert rule to remove it from the group. You can also select multiple alert rules and click **<UI-TERM key="ocp-v2.Alarm.Rule.BatchRemoval">Batch Remove</UI-TERM>** to remove the alert rules.

   ![6](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E6%89%B9%E9%87%8F%E5%88%A0%E9%99%A4.png)

   <main id="notice" type='explain'>
   <h4>Note</h4>
   <p>This operation only removes alert rules from a group. It does not delete the alert rules.</p>
   </main>

### Default groups

The system provides eight default groups that you can edit but cannot delete.

| **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.Plan.Name">Name</UI-TERM>** | **<UI-TERM key="ocp-v2.Auth.Role.Description">Description</UI-TERM>** |
|----------|-------|
| Database kernel | This group contains alert rules related to database resources, such as alert rules for OceanBase clusters, OceanBase Database tenants, and OBServer nodes.  |
| dev | This group contains alert rules to which O&M personnel must pay attention.  |
| Backup and restore | This group contains alert rules to which backup and restore administrators must pay attention, which are generally alert rules related to backup and restore.  |
| Data migration | This group contains alert rules related to OceanBase Migration Service (OMS).  |
| Reminder | This group contains the reminder information, such as the reminders for the results of O&M operations.  |
| ocp | This group contains alert rules related to OCP components, such as OCP-Agent, MetaDB, OBProxy on which MetaDB depends, and internal OCP components.  |
| oas | This group contains alert rules on which intelligent diagnostics depend.  |
| Log | This group contains alert rules related to OceanBase Database logs, OBProxy logs, OBServer message logs, and OCP Agent logs.  |
| Self-healing | This group contains alert rules for which an emergency plan can be executed with a few clicks.  |
| Resource | This group contains usage reminders about server resources, such as memory, handles, and disk.  |
| Performance | This group contains alert rules related to server performance.  |
| Availability | This group contains alert rules related to high availability.  |
