# View an alert rule

This topic describes how to view an alert rule.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only**, **Tenant Read-only**, **OBProxy Read-only**, **Arbitration Service Read-only**, **Binlog Service Read-only**, or **Host Read-only** permission
* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.SQLDiagnosis.Outline.All">All</UI-TERM>** menu of the **<UI-TERM key="ocp-v2.page.Alarm.Alarm">Alert Center</UI-TERM>**

## Procedure

1. Log on to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.hook.useMenu.AlarmCenter">Alert Center</UI-TERM>**.

3. Click the **<UI-TERM key="ocp-v2.Alarm.Rule.New.AlertRules">Alert Rules</UI-TERM>** tab.

4. On the **<UI-TERM key="ocp-v2.Alarm.Rule.New.AlertRules">Alert Rules</UI-TERM>** tab, specify search criteria in the search area to search for alert rules. Exact match is supported. The alert rules that match the search criteria will be displayed.

   ![Image 143](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E5%91%8A%E8%AD%A6%E5%88%97%E8%A1%A8.png)

5. Click the name of an alert rule to view its details.

   ![Image 144](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E5%91%8A%E8%AD%A6%E8%AF%A6%E6%83%85.png)
