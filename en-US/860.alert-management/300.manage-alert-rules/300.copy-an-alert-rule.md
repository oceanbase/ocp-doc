# Copy an alert rule

To create an alert rule similar to an existing one, you can copy the existing alert rule, and then modify the settings as needed.

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance**, **Tenant Maintenance**, **OBProxy Maintenance**, **Arbitration Service Maintenance**, **Binlog Service Maintenance**, or **Host Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.alarm.FormListWithExclude.TenantWithExclude.All">All</UI-TERM>** menu of the **<UI-TERM key="ocp-v2.page.Alarm.Alarm">Alert Center</UI-TERM>**

* You have created an alert rule. For more information, see [Create an alert rule](../300.manage-alert-rules/100.create-an-alert-rule.md).

## Procedure

1. Log on to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.hook.useMenu.AlarmCenter">Alert Center</UI-TERM>**.

3. Click the **<UI-TERM key="ocp-v2.Alarm.Rule.AlertRules">Alert Rules</UI-TERM>** tab.

4. On the **<UI-TERM key="ocp-v2.Alarm.Event.Detail.AlertRules">Alert Rules</UI-TERM>** tab, find the alert rule to copy in the **<UI-TERM key="ocp-v2.Alarm.Rule.AlertRules">Alert Rules</UI-TERM>** list.

5. In the **<UI-TERM key="ocp-v2.Detail.Overview.Operation">Actions</UI-TERM>** column, click the More icon (**...**) and select **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.Copy">Copy</UI-TERM>**.

   ![Image 93](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E5%A4%8D%E5%88%B6%E5%91%8A%E8%AD%A6%E8%A7%84%E5%88%992.png)

6. (Optional) On the **Copy Alert Rule** page, modify the basic information, rule configuration, and alert details of the alert rule.

7. Click **<UI-TERM key="ocp-v2.component.OperationConfig.ModifyParameterDrawer.Submit">Submit</UI-TERM>**.
