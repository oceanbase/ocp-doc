# Edit an alert channel

An administrator can modify the basic information, notification content, and channel configuration of existing alert channels as needed. 

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance**, **Tenant Maintenance**, **OBProxy Maintenance**, **Arbitration Service Maintenance**, **Binlog Service Maintenance**, or **Host Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Auth.Role.util.All">All</UI-TERM>** menu of the **<UI-TERM key="ocp-v2.page.Alarm.Alarm">Alert Center</UI-TERM>**

* You have created an alert channel. For more information, see [Create an alert channel](../500.manage-alert-channels/100.create-an-alert-channel.md). 

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console. 

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Alarm.Alarm">Alert Center</UI-TERM>**.

3. Click the **<UI-TERM key="ocp-v2.Alarm.Channel.AlarmChannel">Alert Channels</UI-TERM>** tab.

4. On the **<UI-TERM key="ocp-v2.Alarm.Channel.AlarmChannel">Alert Channels</UI-TERM>** tab, find the target alert channel and click **<UI-TERM key="ocp-v2.Alarm.Shield.Editing">Edit</UI-TERM>** in the **<UI-TERM key="ocp-v2.page.Tags.TagList.Operation">Actions</UI-TERM>** column.

5. Configure the basic information of the channel as prompted. 

6. Edit **<UI-TERM key="ocp-v2.Alarm.Channel.Detail.ChannelConfiguration">Channel Configuration</UI-TERM>** as prompted.

7. Edit **<UI-TERM key="ocp-v2.Alarm.Channel.Detail.MessageConfiguration">Message Configuration</UI-TERM>** as prompted.

   1. Edit **<UI-TERM key="ocp-v2.Alarm.Channel.Detail.AlertMessageTemplate">Alert Message Template</UI-TERM>**.

   2. Specify whether to enable **<UI-TERM key="ocp-v2.Alarm.Channel.Detail.AlertMessageAggregation">Alert Message Aggregation</UI-TERM>**.

      Alert message aggregation can help you avoid missing important messages when you receive too many messages in a short time. You can check the aggregation rule as prompted. 

8. Click **<UI-TERM key="ocp-v2.Alarm.Channel.New.SendTestMessages">Send Test Message</UI-TERM>**. If the message is sent, click **<UI-TERM key="ocp-v2.Template.Component.AddTargetDrawer.Submit">Submit</UI-TERM>**.
