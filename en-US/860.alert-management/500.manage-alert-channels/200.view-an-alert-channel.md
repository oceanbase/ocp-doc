# View an alert channel

This topic describes how to view an alert channel. 

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only**, **Tenant Read-only**, **OBProxy Read-only**, **Arbitration Service Read-only**, **Binlog Service Read-only**, or **Host Read-only** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.alarm.FormListWithExclude.ObproxyClusterWithExclude.All">All</UI-TERM>** menu of the **<UI-TERM key="ocp-v2.page.Alarm.Alarm">Alert Center</UI-TERM>**

* You have created an alert channel. For more information, see [Create an alert channel](../500.manage-alert-channels/100.create-an-alert-channel.md). 

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console. 

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.hook.useMenu.AlarmCenter">Alert Center</UI-TERM>**.

3. Click the **<UI-TERM key="ocp-v2.Alarm.Channel.AlarmChannel">Alert Channels</UI-TERM>** tab.

4. On the **<UI-TERM key="ocp-v2.Alarm.Channel.AlarmChannel">Alert Channels</UI-TERM>** tab, click the name of an alert channel to view its details.
