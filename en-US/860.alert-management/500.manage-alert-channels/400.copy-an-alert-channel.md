# Copy an alert channel

To create an alert channel similar to an existing one, you can copy the existing alert channel, and then modify the settings as needed. 

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance**, **Tenant Maintenance**, **OBProxy Maintenance**, **Arbitration Service Maintenance**, **Binlog Service Maintenance**, or **Host Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.Analyze.All">All</UI-TERM>** menu of the **<UI-TERM key="ocp-v2.src.hook.useMenu.AlarmCenter">Alert Center</UI-TERM>**

* You have created an alert channel. For more information, see [Create an alert channel](../500.manage-alert-channels/100.create-an-alert-channel.md). 

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console. 

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Alarm.Alarm">Alert Center</UI-TERM>**. 

3. Click the **<UI-TERM key="ocp-v2.Alarm.Channel.AlarmChannel">Alert Channels</UI-TERM>** tab. 

4. On the **<UI-TERM key="ocp-v2.Alarm.Channel.AlarmChannel">Alert Channels</UI-TERM>** tab, find the target alert channel and click **<UI-TERM key="ocp-v2.Auth.User.Detail.Copy">Copy</UI-TERM>** in the **<UI-TERM key="ocp-v2.Auth.Role.Operation">Actions</UI-TERM>** column. 

   ![Image 93](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422-en/copy-alert-channel-1.png)

6. (Optional) On the **<UI-TERM key="ocp-v2.Alarm.Channel.New.CopyChannel">Copy Channel</UI-TERM>** page, modify the basic information, channel configuration, and message configuration of the alert channel. 

7. Click **<UI-TERM key="ocp-v2.Alarm.Channel.New.SendTestMessages">Send Test Message</UI-TERM>**. If the message is sent, click **<UI-TERM key="ocp-v2.Alarm.Channel.New.Submit">Submit</UI-TERM>**.
