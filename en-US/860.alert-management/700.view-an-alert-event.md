# View alert events

This topic describes how to view details about an alert event and temporarily block an alert event.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only**, **Tenant Read-only**, **OBProxy Read-only**, **Arbitration Service Read-only**, **Binlog Service Read-only**, or **Host Read-only** permission
* **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.component.common.ServerDropdown.All">All</UI-TERM>** menu of the **<UI-TERM key="ocp-v2.src.hook.useMenu.AlarmCenter">Alert Center</UI-TERM>**

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Alarm.Alarm">Alert Center</UI-TERM>**.

3. By default, the **<UI-TERM key="ocp-v2.page.Alarm.AlarmEvent">Alert Events</UI-TERM>** tab appears.

4. Specify search criteria in the search area. All alert events that match the search criteria will be displayed in the **<UI-TERM key="ocp-v2.page.Alarm.AlarmEvent">Alert Events</UI-TERM>** list.

   * You can search for an alert event by **<UI-TERM key="ocp-v2.Alarm.Rule.Application">Application</UI-TERM>**, **<UI-TERM key="ocp-v2.component.alarm.Search.ObjectType">Object Type</UI-TERM>**, **<UI-TERM key="ocp-v2.Alarm.Rule.New.AlarmLevel">Alert Level</UI-TERM>**, **<UI-TERM key="ocp-v2.Detail.SQLDiagnosis.KeyWords">Keyword</UI-TERM>**, **<UI-TERM key="ocp-v2.Log.Trace.StartTime">Start Time</UI-TERM>**, and **<UI-TERM key="ocp-v2.component.alarm.Search.EndTime">End Time</UI-TERM>**.

   * You can click **<UI-TERM key="ocp-v2.Alarm.Event.ActiveAlert">Active Alerts</UI-TERM>** and **<UI-TERM key="ocp-v2.Alarm.Event.HistoricalAlerts">Alert History</UI-TERM>** to switch between the alert lists.

   * You can click **Export Alert Event** to export all alert events that match the search criteria to your computer.

   * If alert pushes are configured for the alert event, you can click **<UI-TERM key="ocp-v2.src.constant.alarm.Failed">Failed</UI-TERM>** in the **<UI-TERM key="ocp-v2.Alarm.Event.MessagePush">Message Push</UI-TERM>** column to view details about the alert event.

   * If no alert push is configured for the alert event, you can click **Message Push Not Configured** in the **<UI-TERM key="ocp-v2.Alarm.Event.MessagePush">Message Push</UI-TERM>** column to configure alert pushes for the alert event. For more information, see [Create an alert push](600.manage-alert-push/100.create-an-alert-push.md).

   * For an active alert event of the **Log** type that occurs only once and needs to be manually acknowledged, the Actions column provides two options: **<UI-TERM key="ocp-v2.src.constant.information.Resolved">Resolved</UI-TERM>** and **<UI-TERM key="ocp-v2.Alarm.Event.Detail.MaskAlarm">Mask Alerts</UI-TERM>**.

      * If the alert event has been resolved, you can click **<UI-TERM key="ocp-v2.src.constant.alarm.Resolved">Resolved</UI-TERM>** in the **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.Operation">Actions</UI-TERM>** column to clear the alert. After the alert is cleared, you cannot perform any operations on it.

      * If the alert event does not need to be concerned, you can click **<UI-TERM key="ocp-v2.Alarm.Event.Detail.MaskAlarm">Mask Alerts</UI-TERM>** in the **<UI-TERM key="ocp-v2.component.TraceTimelineDrawer.Operation">Actions</UI-TERM>** column to quickly block the alert message. Then the alert will not be reported before the block period expires. For more information, see [Create a blocking condition](800.manage-blocking-conditions/100.create-a-blocking-condition.md).

   ![Image 3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/active-alerts.png)

5. Click the description in the Alert Description column of an alert event. The **<UI-TERM key="ocp-v2.Alarm.Event.Detail.Details">Details</UI-TERM>** page of the alert event appears.

   1. In the **<UI-TERM key="ocp-v2.Report.Scan.ReportContent.BasicInformation">Basic Information</UI-TERM>** section, view the basic information of the alert event.

      * Click the name of an alert object to view its details.
      * Click the name of an alert rule to view its details. To modify an alert rule, click **<UI-TERM key="ocp-v2.Alarm.Rule.New.EditAlertRules">Edit Alert Rule</UI-TERM>** on the details page of the rule. For more information, see [Edit an alert rule](300.manage-alert-rules/400.edit-an-alert-rule.md).
      * Click **<UI-TERM key="ocp-v2.Alarm.Event.Detail.ViewAlertHandlingSuggestions">Suggestions on How to Deal with Alerts</UI-TERM>** to view the suggestions on handling the alert.

      ![Image 4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/alert-details.png)

   2. In the **<UI-TERM key="ocp-v2.Alarm.Event.Detail.AlarmEventHistory">Alert Event History</UI-TERM>** section, view the alert event history and related information, including **Alert Time**, **<UI-TERM key="ocp-v2.Alarm.Rule.Detail.AlarmLevel">Alert Level</UI-TERM>**, and **<UI-TERM key="ocp-v2.page.Overview.AlertStatus">Alert Status</UI-TERM>**.

      ![5](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/403-cn/%E5%91%8A%E8%AD%A6%E4%BA%8B%E4%BB%B6%E5%8E%86%E5%8F%B21.png)

   3. View the alert notification history in the **Alert Messages** list.

      ![6](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/alert-message.png)

   4. On the details page of the alert event, click **<UI-TERM key="ocp-v2.Alarm.Event.Detail.MaskAlarm">Mask Alerts</UI-TERM>** in the upper-right corner to block alert messages.

      Then the alert will not be reported before the block period expires.

   5. On the details page of the alert event, click **<UI-TERM key="ocp-v2.Alarm.Event.Detail.AlarmAnalysisData">Alert Analysis Data</UI-TERM>** in the upper-right corner to download the logs related to alert analysis.

6. When many alert events are received, you can clear alert messages as needed.

   1. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.Detail.Parameter.ParameterManagement">Parameter Management</UI-TERM>**.
   2. Search for the `ocp.alarm.notification.expired-days` parameter in the parameter list to set the retention period of alert messages, in days.

      After you specify this parameter, the alert messages and alert events that exceed the retention period will be deleted. The following data will be deleted upon expiration:

      * `ocp2_alarm_notification`
      * `ocp_alarm_event_notification`
      * `ocp2_alarm_event_history`
      * `ocp_alarm_event_record`
      * `ocp2_alarm_filter` (Cleared data will be written to `ocp2_alarm_filter_history`. The amount of rule information is small and therefore the rule history table does not need to be cleared.)

     <main id="notice" type='notice'>
     <h4>Notice</h4>
     <p><ul><li>We recommend that you set the alert clearing period to a proper value, for example, several months. </li><li>Alerts must not be left uncleared and unhandled for a long time. You can configure alert message push. We recommend that you promptly handle received alert messages. </li><ul></p>
     </main>
