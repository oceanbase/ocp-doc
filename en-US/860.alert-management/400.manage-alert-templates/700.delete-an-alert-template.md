# Delete an alert template

A system administrator and OceanBase Cloud Platform (OCP) alert administrator can delete alert templates. System built-in alert templates cannot be deleted. 

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance**, **Tenant Maintenance**, **OBProxy Maintenance**, **Arbitration Service Maintenance**, **Binlog Service Maintenance**, or **Host Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Auth.Role.All">All</UI-TERM>** menu of the **<UI-TERM key="ocp-v2.src.hook.useMenu.AlarmCenter">Alert Center</UI-TERM>**

* You have created an alert template. For more information, see [Create an alert template](../400.manage-alert-templates/100.create-an-alert-template.md). You can delete only custom alert templates. 

## Procedure

1. Log on to the OCP console. 

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.hook.useMenu.AlarmCenter">Alert Center</UI-TERM>**.

3. Click the **Alert Templates** tab. 

4. On the **Alert Templates** tab, find the alert template, and click **<UI-TERM key="ocp-v2.Detail.Backup.Delete">Delete</UI-TERM>** in the **<UI-TERM key="ocp-v2.Plan.Component.PlanTemplateTable.Operation">Actions</UI-TERM>** column.

   ![Image 122](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422-en/delete-alert-template-1.png)

5. In the confirmation dialog box that appears, click **<UI-TERM key="ocp-v2.Detail.Component.DeleteModal.Ok">OK</UI-TERM>**.
