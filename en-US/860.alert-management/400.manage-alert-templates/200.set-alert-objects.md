# Set alert objects

After you set an alert template, you must set alert objects for the alert template. If you have configured an alert rule for an alert object in **<UI-TERM key="ocp-v2.Alarm.Rule.New.AlertRules">Alert Rules</UI-TERM>**, the system will apply the alert rule specified here for the alert template. 

You can create a cluster-level backup strategy by using the following three methods:

* After you create an alert template, click **<UI-TERM key="ocp-v2.Template.Component.Result.SetAlertObjects">Set Alert Object</UI-TERM>** on the submission result page. 
* On the alert template list page, select the specified alert template. Then click the More icon (**...**) in the Actions column and select **<UI-TERM key="ocp-v2.Template.Component.AddTargetDrawer.SetAlertObjects">Set Alert Object</UI-TERM>**. 

This topic describes how to set alert objects on the alert template list page. 

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance**, **Tenant Maintenance**, **OBProxy Maintenance**, **Arbitration Service Maintenance**, **Binlog Service Maintenance**, or **Host Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.alarm.FormListWithExclude.TenantWithExclude.All">All</UI-TERM>** menu of the **<UI-TERM key="ocp-v2.page.Alarm.Alarm">Alert Center</UI-TERM>**

* You have created an alert template. For more information, see [Create an alert template](../400.manage-alert-templates/100.create-an-alert-template.md). 

## Procedure

1. Log on to the OCP console. 

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Alarm.Alarm">Alert Center</UI-TERM>**. 

3. Click the **Alert Templates** tab. 

4. On the **Alert Templates** tab, find the alert template, click the **<UI-TERM key="ocp-v2.Component.AddBackupStrategy.ViewMore">More</UI-TERM>** icon in the **<UI-TERM key="ocp-v2.component.ParameterTemplate.Operation">Actions</UI-TERM>** column, and select **<UI-TERM key="ocp-v2.Template.Component.AddTargetDrawer.SetAlertObjects">Set Alert Object</UI-TERM>**. 

6. In the **<UI-TERM key="ocp-v2.Template.Component.AddTargetDrawer.SetAlertObjects">Set Alert Object</UI-TERM>** panel, select alert objects as needed. 

   If you select **<UI-TERM key="ocp-v2.Detail.Analyze.TimesChart.All">All</UI-TERM>**, existing objects and objects added in the future that are of the current alert object type will be included. You can select **<UI-TERM key="ocp-v2.alarm.FormListWithExclude.HostWithExclude.ExcludeObjects">Excluded Objects</UI-TERM>** on the right to exclude objects that do not need to use the alert template. 

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422-en/set-alert-objects.png)

7. Click **<UI-TERM key="ocp-v2.component.OperationConfig.ModifyParameterDrawer.Submit">Submit</UI-TERM>**.
