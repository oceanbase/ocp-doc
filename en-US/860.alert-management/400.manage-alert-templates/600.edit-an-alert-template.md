# Edit an alert template

A system administrator and OceanBase Cloud Platform (OCP) alert administrator can edit alert templates. 

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance**, **Tenant Maintenance**, **OBProxy Maintenance**, **Arbitration Service Maintenance**, **Binlog Service Maintenance**, or **Host Maintenance** permission
* **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.component.MonitorSearch.All">All</UI-TERM>** menu of the **<UI-TERM key="ocp-v2.src.hook.useMenu.AlarmCenter">Alert Center</UI-TERM>**

## Procedure

1. Log on to the OCP console. 

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Alarm.Alarm">Alert Center</UI-TERM>**.

3. Click the **Alert Templates** tab. 

4. On the **Alert Templates** tab, find the alert template, click the **<UI-TERM key="ocp-v2.Component.AddBackupStrategy.ViewMore">More</UI-TERM>** icon in the **<UI-TERM key="ocp-v2.User.Oracle.RolesList.Operation">Actions</UI-TERM>** column, and select **<UI-TERM key="ocp-v2.Alarm.Template.EditTemplate">Edit Template</UI-TERM>**.

   * Specify the fields in the **<UI-TERM key="ocp-v2.Report.Scan.ReportContent.BasicInformation">Basic Information</UI-TERM>** section of the alert template.

      ![12060106](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422-en/edit-alert-template-1.png)

   * Configure the rules of the alert template. For more information, see [Create an alert rule](../300.manage-alert-rules/100.create-an-alert-rule.md). 

      ![Image 142](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422-en/edit-alert-template-2.png)

5. Click **<UI-TERM key="ocp-v2.Template.Component.AddTargetDrawer.Submit">Submit</UI-TERM>**.
