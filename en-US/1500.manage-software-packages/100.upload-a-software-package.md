# Upload a software package

This topic describes how to upload a software package.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance**, **Tenant Maintenance**, **OBProxy Maintenance**, **Arbitration Service Maintenance**, **Binlog Service Maintenance**, or **Host Maintenance** permission
* **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.page.Package.Package">Packages</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>**

## Procedure

1. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.SoftwarePackageManagement">Software Package Management</UI-TERM>** to go to the **<UI-TERM key="ocp-v2.page.Package.Package">Packages</UI-TERM>** page.

2. Click **<UI-TERM key="ocp-v2.Detail.Component.UpgradeObproxiesModal.Upload">Upload</UI-TERM>**. In the panel that appears, click **Select a Software Package**, select a local package, and click **<UI-TERM key="ocp-v2.component.ParameterTemplate.ParameterTemplateDropdown.Ok">Upload</UI-TERM>**.

   You can upload an installation package in the `.rpm` format, for example, an OceanBase Database installation package, binlog service installation package, OCP Agent installation package, OBProxy installation package, or backup and restore service installation package.

   <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p><ul><li>You can upload up to 10 packages of the <code>.rpm</code> or <code>tar.gz</code> format at a time. </li><li>If your system version is <code>debian</code>, we recommend that you use an OCP Agent package with the <code>.tar.gz</code> extension and set the installation directory by using the <code>ocp.agent.home.path.prefix</code> system parameter. </li><li>It is risky to deploy an unofficial package in a production cluster. </li><li>OCP Enterprise Edition verifies the signature of the uploaded package. If the verification fails, the package cannot be uploaded. We recommend that you select another package and upload it again. </li></ul></p>
   </main>

3. After the package is uploaded, you can view it in the package list.

## Related operations
You can view the package information in the package list, including **Package Name**, **Type**, **Version**, **OS**, **Architecture**, **Size (MiB)**, and **Uploaded At**.
* You can filter packages by **Type**, **Version**, **OS**, and **Architecture**.
* You can sort packages by **Package Name** and **<UI-TERM key="ocp-v2.page.Package.UploadTime">Uploaded At</UI-TERM>**.
