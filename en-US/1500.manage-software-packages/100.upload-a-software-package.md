# Upload a software package

This topic describes how to upload a software package.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance**, **Tenant Maintenance**, **OBProxy Maintenance**, **Arbitration Service Maintenance**, **Binlog Service Maintenance**, or **Host Maintenance** permission
* **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.page.Package.Package">Packages</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>**

## Procedure

1. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.SoftwarePackageManagement">Software Package Management</UI-TERM>** to go to the **<UI-TERM key="ocp-v2.page.Package.Package">Packages</UI-TERM>** page.

2. Click **<UI-TERM key="ocp-v2.Detail.Component.UpgradeObproxiesModal.Upload">Upload</UI-TERM>**. In the panel that appears, click **Select File**, select a local package, and click **<UI-TERM key="ocp-v2.component.ParameterTemplate.ParameterTemplateDropdown.Ok">OK</UI-TERM>**.

   You can upload an installation package in the `.rpm` format, for example, an OceanBase Database installation package, binlog service installation package, OceanBase Cloud Platform (OCP) Agent installation package, OBProxy installation package, or backup and restore service installation package.

   <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p><ul><li>You can upload at most 10 <code>.rpm</code> packages at a time. </li><li>An informal package will cause risks. We recommend that you do not install informal packages in a production cluster. </li><li>OCP Enterprise Edition performs signature-based verification on the uploaded packages. A package that fails the verification cannot be uploaded. </li></ul></p>
   </main>

3. After a package is uploaded, you can view it in the package list.
