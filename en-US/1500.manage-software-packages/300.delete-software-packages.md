# Delete a software package

This topic describes how to delete a software package.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance**, **Tenant Maintenance**, **OBProxy Maintenance**, **Arbitration Service Maintenance**, **Binlog Service Maintenance**, or **Host Maintenance** permission
* **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.page.Package.Package">Packages</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>**

## Procedure

1. In the left-side navigation pane, choose **System Management > Packages** to go to the Packages page.

2. Click **<UI-TERM key="ocp-v2.Cluster.Arbitration.Delete">Delete</UI-TERM>** next to the software package that you want to delete. In the dialog box that appears, click **<UI-TERM key="ocp-v2.Detail.LoadBalance.Delete">Delete</UI-TERM>**.
