# Download a software package

This topic describes how to download a software package.

## Prerequisites

Make sure that you have the following permissions:

* **Resource Permissions**: **Cluster Read-only**, **Tenant Read-only**, **OBProxy Read-only**, **Arbitration Service Read-only**, **Binlog Service Read-only**, or **Host Read-only** permission
* **Menu Permissions**: Permission on the **Packages** menu of **System Management**

## Procedure

1. In the left-side navigation pane, choose **System Management > Packages** to go to the Packages page.

2. Click **Download** next to a software package to download it.
