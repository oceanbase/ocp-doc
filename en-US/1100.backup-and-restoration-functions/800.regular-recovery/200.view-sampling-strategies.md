# View sampling strategies

This topic describes how to view sampling strategies.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
* **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **Restore** menu of **<UI-TERM key="ocp-v2.src.constant.compute.BackupAndRestoration">Backup & Recovery</UI-TERM>**

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.Backup.Component.RestoreNow.BackupAndRestoration">Backup & Recovery</UI-TERM>** **>** **<UI-TERM key="ocp-v2.Restore.SamplingStrategy.New.Recovery">Recovery</UI-TERM>** to go to **<UI-TERM key="ocp-v2.Backup.Restore.Recovery">Recovery</UI-TERM>** page.

3. Click **<UI-TERM key="ocp-v2.Backup.Restore.SamplingPolicy">Sampling Strategies</UI-TERM>** tab.

    The table on the **Sampling Policies** tab contains the following columns: **Policy Name, Sampled Cluster, Target Cluster, Backup Method, Target Tenant, Created At, Status**, and **<UI-TERM key="ocp-v2.Backup.Backup.Data.Operation">Actions</UI-TERM>**. You can filter the sampling strategies by status.

    ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/%E6%81%A2%E5%A4%8D3.png)

    | **<UI-TERM key="ocp-performance-report.ReportTables.ParameterStatInfo.ZoneParamInfoTable.Parameter">Parameter</UI-TERM>** | **<UI-TERM key="ocp-v2.Host.Detail.Basic.Description">Description</UI-TERM>** |
    | --- | --- |
    | Policy Name | Click the name of a strategy in the **<UI-TERM key="ocp-v2.Restore.SamplingStrategy.PolicyName">Policy Name</UI-TERM>** column. The strategy overview page appears. This page provides the following strategy management options: **Stop, Edit**, and **<UI-TERM key="ocp-v2.Plan.Component.PlanTemplateTable.Delete">Delete</UI-TERM>**.  |
    | Sampled Cluster | Click the name of a cluster in the **Sampled Cluster** column. The cluster overview page appears.  |
    | Backup Method | Valid values: **<UI-TERM key="ocp-v2.src.constant.backup.PhysicalBackup">Physical Backup</UI-TERM>** and **<UI-TERM key="ocp-v2.Component.AddBackupStrategy.LogicalBackup">Logical Backup</UI-TERM>**  |
    | Target Cluster | The cluster to which the data of the backup cluster is recovered.  |
    | Target Tenant | The tenant to which the data of the backup tenant is recovered.  |
    | Created At | The time when the strategy was created.  |
    | Status | Valid values: **Start, Recovering Data, Recovering Logs, Failed to Recover Data, Failed to Recover Logs, and Completed**.  |
    | Actions | You can click **Stop, Edit**, or **<UI-TERM key="ocp-v2.component.DatabasePrivilegeTransfer.PrivilegesCheckbox.Delete">Delete</UI-TERM>** in the Actions column to manage sampling strategies.  |
