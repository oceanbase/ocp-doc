# View second backup tasks

You can specify a time range to view second data backup tasks and second log backup tasks, and start or stop a task.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
* **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Component.BackupStrategyCard.Backup">Backup</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.constant.auditEvent.BackupAndRestoration">Backup & Recovery</UI-TERM>**

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, choose **Backup \& Recovery** **\>** **<UI-TERM key="ocp-v2.src.constant.compute.Backup">Backup</UI-TERM>** .
  
3. Click **<UI-TERM key="ocp-v2.Component.AddBackupStrategy.SecondaryBackup">Second Backup</UI-TERM>**, view second data backup tasks.

    The table on the Second Data Backup tab contains the following columns: **ID, Cluster, Tenant, Backup Set ID, Start Time, End Time** , **<UI-TERM key="ocp-v2.Backup.Service.Detail.StorageDirectory">Storage Directory</UI-TERM>** , and **<UI-TERM key="ocp-v2.Statistics.components.PartitionDrawer.Status">Status</UI-TERM>** . You can filter the second backup tasks by status.

      * **<UI-TERM key="ocp-v2.page.Overview.Cluster">Cluster</UI-TERM>** column: Click a cluster name in this column to go to the **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">Overview</UI-TERM>** page of the cluster. You can search for clusters.

      * **<UI-TERM key="ocp-v2.Backup.SecondaryBackup.Data.BackupSetId">Backup Set ID</UI-TERM>** column: Click an ID in this column to view all data backup tasks for the backup set.

    In the upper-right corner of the tab, you can select **Last 24 Hours, Last 7 Days, or Last 30 Days,** or select **<UI-TERM key="ocp-v2.component.OCPRangePicker.CustomTime">Custom Time</UI-TERM>** and specify a time range, to filter second data backup tasks by time.

    ![Image 44](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/8564633561/p440344.png)

4. View second log backup tasks.

    The table on the **<UI-TERM key="ocp-v2.Component.StorageTrend.LogBackup">Log Backup</UI-TERM>** tab contains the following columns: **Cluster, Latest Backup Time, Storage Directory** , **<UI-TERM key="ocp-v2.Log.Trace.StartTime">Start Time</UI-TERM>** , and **<UI-TERM key="ocp-v2.Backup.Backup.Data.State">Status</UI-TERM>** .

    In the upper-right corner of the tab, you can select **Last 24 Hours, Last 7 Days, or Last 30 Days,** or select **<UI-TERM key="ocp-v2.component.RangeTimeDropdown.CustomTime">Custom Time</UI-TERM>** and specify a time range, to filter second log backup tasks by time.

    ![Image 45](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/9564633561/p440345.png)
