# View backup tasks

This topic describes how to filter data backup tasks, log backup tasks, and cleanup tasks of regular backups by time, and how to start or stop a task.

You can view backup data by using the following methods:

* **Method 1**: Log in to the OceanBase Cloud Platform (OCP) console. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.Backup.Component.RestoreNow.BackupAndRestoration">Backup & Recovery</UI-TERM>** > **<UI-TERM key="ocp-v2.src.constant.backup.Backup">Backup</UI-TERM>**. You can view the backup task information on the **<UI-TERM key="ocp-v2.page.Overview.BackupTask">Backup Tasks</UI-TERM>** tab.

* **Method 2**: Log in to the OCP console and go to the **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** page of a cluster. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Backup.Component.RestoreNow.BackupAndRestoration">Backup & Recovery</UI-TERM>**. You can view the backup information of the cluster on the **<UI-TERM key="ocp-v2.page.Overview.BackupTask">Backup Tasks</UI-TERM>** tab.

* **Method 3**: Log in to the OCP console and go to the **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** page of a tenant. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.constant.compute.BackupAndRestoration">Backup & Recovery</UI-TERM>**. You can view the backup information of the tenant on the **<UI-TERM key="ocp-v2.page.Overview.BackupTask">Backup Tasks</UI-TERM>** tab.

## Prerequisites

On the **<UI-TERM key="ocp-v2.page.Overview.BackupTask">Backup Tasks</UI-TERM>** tab, the required permissions vary based on the operations to be performed.

* **View task information**

  * To view backup task information by using **Method 1**, make sure that you have the following permissions:

    * **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
    * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Component.BackupStrategyCard.Backup">Backup</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.util.menu.BackupAndRestoration">Backup & Recovery</UI-TERM>**

  * To view backup task information by using **Method 2**, make sure that you have the following permissions:

    * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** permission
    * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Backup.BackupStrategy.New.BackupAndRestoration">Backup & Recovery</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>**

  * To view backup task information by using **Method 3**, make sure that you have the following permissions:

    * **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
    * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Backup.BackupStrategy.New.BackupAndRestoration">Backup & Recovery</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Detail.Resource.Unit.Tenant">Tenants</UI-TERM>**

* **Stop or start a backup task**

  * To stop or start a backup task by using **Method 1**, make sure that you have the following permissions:

    * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** or **Tenant Maintenance** permission
    * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.constant.compute.Backup">Backup</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.constant.compute.BackupAndRestoration">Backup & Recovery</UI-TERM>**

  * To stop or start a backup task by using **Method 2**, make sure that you have the following permissions:

    * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** permission
    * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Backup.BackupStrategy.New.BackupAndRestoration">Backup & Recovery</UI-TERM>** menu of **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>**

  * To stop or start a backup task by using **Method 3**, make sure that you have the following permissions:

    * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** or **Tenant Maintenance** permission
    * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Backup.BackupStrategy.Edit.BackupAndRestoration">Backup & Recovery</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Detail.Resource.Unit.Tenant">Tenants</UI-TERM>**

## Procedure

The procedure of **Method 1** is described as follows:

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.Detail.Backup.BackupAndRestoration">Backup & Recovery</UI-TERM>** > **<UI-TERM key="ocp-v2.Component.AddBackupStrategy.Backup">Backup</UI-TERM>**. By default, the **<UI-TERM key="ocp-v2.page.Overview.BackupTask">Backup Tasks</UI-TERM>** tab appears.

3. View data backup tasks.

    On the **<UI-TERM key="ocp-v2.Component.StorageTrend.DataBackup">Data Backup</UI-TERM>** tab, you can view information about data backup tasks in the following columns: **<UI-TERM key="ocp-v2.Session.Deadlock.DeadlockHistoryTable.Id">ID</UI-TERM>**, **<UI-TERM key="ocp-v2.Component.UpgradeDrawer.Cluster">Cluster</UI-TERM>**, **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.Tenant">Tenant</UI-TERM>**, **<UI-TERM key="ocp-v2.Backup.Component.BackupNowDrawer.DataBackupMethod">Data Backup Method</UI-TERM>**, **<UI-TERM key="ocp-v2.Backup.Backup.Data.BackupSetId">Backup Set ID</UI-TERM>**, **<UI-TERM key="ocp-v2.Backup.SecondaryBackup.Data.StartTime">Started At</UI-TERM>**, **<UI-TERM key="ocp-v2.Backup.SecondaryBackup.Data.EndTime">Ended At</UI-TERM>**, **Restorable Time Point**, **<UI-TERM key="ocp-v2.Component.BackupStrategyDetail.SecondaryBackup">Second Backup</UI-TERM>**, **<UI-TERM key="ocp-v2.Plan.Component.PlanTemplateTable.Status">Status</UI-TERM>**, and **<UI-TERM key="ocp-v2.page.Host.Operation">Actions</UI-TERM>**. You can also filter the data backup tasks by status. The following table describes more information.

    In the upper-right corner of the tab, you can select **<UI-TERM key="ocp-v2.component.TenantMonitorTop5.LastHour">Last 1 Hour</UI-TERM>**, **<UI-TERM key="ocp-v2.src.component.RangeTimeDropdown.LastDay">Last 24 Hours</UI-TERM>**, **<UI-TERM key="ocp-v2.component.TenantMonitorTop5.LastWeek">Last 7 Days</UI-TERM>**, or **<UI-TERM key="ocp-v2.src.constant.backup.NearlyDays">Last 30 Days</UI-TERM>**, or select **<UI-TERM key="ocp-v2.component.OCPRangePicker.CustomTime">Custom Time</UI-TERM>** and specify a time range, to filter the data backup tasks.

5. View backup cleanup tasks.

   <main id="notice" type='explain'>
     <h4>Note</h4>
     <p>You can clean up only logical backups. Logical backup is supported in OceanBase Database of a version earlier than V2.2.60. </p>
   </main>

    On the **<UI-TERM key="ocp-v2.Backup.Overview.Task.BackupCleanup">Backup Cleanup</UI-TERM>** tab, you can view information about backup cleanup tasks in the following columns: **<UI-TERM key="ocp-v2.Session.Deadlock.DeadlockHistoryTable.Id">ID</UI-TERM>**, **<UI-TERM key="ocp-v2.component.ModifyClusterParameterDrawer.Cluster">Cluster</UI-TERM>**, **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.StartTime">Started At</UI-TERM>**, **<UI-TERM key="ocp-v2.Backup.Restore.RestoreTask.EndTime">Ended At</UI-TERM>**, and **<UI-TERM key="ocp-v2.Instance.Overview.Status">Status</UI-TERM>**. You can also filter the backup cleanup tasks by status. A backup cleanup task can be in any of the following states: **<UI-TERM key="ocp-v2.src.constant.plan.PendingExecution">Pending</UI-TERM>**, **<UI-TERM key="ocp-v2.src.constant.alarm.Running">Executing</UI-TERM>**, **<UI-TERM key="ocp-v2.component.UploadPackageDrawer.Failed">Failed</UI-TERM>**, and **<UI-TERM key="ocp-v2.Detail.Statistics.utils.Completed">Completed</UI-TERM>**.

    In the upper-right corner of the tab, you can select **<UI-TERM key="ocp-v2.component.TenantMonitorTop5.LastHour">Last 1 Hour</UI-TERM>**, **<UI-TERM key="ocp-v2.component.TenantMonitorTop5.LastDay">Last 24 Hours</UI-TERM>**, **<UI-TERM key="ocp-v2.component.TenantMonitorTop5.LastWeek">Last 7 Days</UI-TERM>**, or **<UI-TERM key="ocp-v2.src.constant.backup.NearlyDays">Last 30 Days</UI-TERM>**, or select **<UI-TERM key="ocp-v2.component.RangeTimeDropdown.CustomTime">Custom Time</UI-TERM>** and specify a time range, to filter the cleanup tasks by time.
