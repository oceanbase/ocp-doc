# Delete a cluster-level backup strategy

This topic describes how to delete a cluster-level backup strategy.

You can delete a cluster-level backup strategy by using one of the following methods.

* Method 1:

   1. Log on to the OceanBase Cloud Platform (OCP) console.

   2. To go to the **Clusters Overview** page. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Detail.Backup.BackupAndRestoration">Backup & Recovery</UI-TERM>**.

   3. Click the **<UI-TERM key="ocp-v2.Detail.Backup.BackupPolicy">Backup Strategy</UI-TERM>** tab.

* Method 2:

   1. Log on to the OceanBase Cloud Platform (OCP) console.

   2. To go to the **Clusters Overview** page. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Detail.Backup.BackupAndRestoration">Backup & Recovery</UI-TERM>**.

   3. Click **...** in the upper-right corner of the page and choose **Delete Cluster-level Backup Strategy** from the drop-down list.

## Prerequisites

* Make sure that you have the following permissions:
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Backup.BackupStrategy.New.BackupAndRestoration">Backup & Recovery</UI-TERM>** menu of **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>**
* The cluster has created a backup strategy.

## Procedure

The following takes **Method 1** as an example.

1. Log on to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** to go to the **Clusters Overview** page.

3. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.constant.package.BackupAndRestoration">Backup & Recovery</UI-TERM>**.

4. Click the **<UI-TERM key="ocp-v2.Detail.Backup.BackupPolicy">Backup Strategy</UI-TERM>** tab.

5. Click **<UI-TERM key="ocp-v2.Detail.Overview.Delete">Delete</UI-TERM>** in the upper-right corner of the Cluster Backup Strategy section to modify the backup strategy.
