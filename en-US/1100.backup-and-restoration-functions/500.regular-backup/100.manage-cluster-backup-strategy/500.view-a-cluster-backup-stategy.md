# View a cluster-level backup stategy

This section introduces you how to view the detailed configuration of the cluster-level backup strategy.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** permission
* **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.Backup.BackupAndRestoration">Backup & Recovery</UI-TERM>** menu of **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>**

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>**. The cluster overview page appears.

3. Find the target cluster in the **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** list and click its name to go to the **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** page of the cluster.

4. In the left-side navigation pane, click the **<UI-TERM key="ocp-v2.Detail.Backup.BackupPolicy">Backup Strategy</UI-TERM>** tab to view the cluster-level and tenant-level backup strategies for the cluster.

    <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>If no tenant-level backup strategy is configured for tenants in the cluster, the <strong>Tenant-level Backup Strategy</strong> section is not displayed.</p>
    </main>
