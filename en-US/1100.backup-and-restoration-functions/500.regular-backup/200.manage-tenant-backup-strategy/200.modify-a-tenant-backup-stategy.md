# Modify a tenant-level backup strategy

This topic describes how to modify a tenant-level backup strategy.

You can modify a tenant-level backup strategy by using one of the following methods.

* Method 1:

   1. Log on to the OceanBase Cloud Platform (OCP) console.

   2. To go to the **Tenants Overview** page. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Backup.BackupStrategy.New.BackupAndRestoration">Backup & Recovery</UI-TERM>**.

   3. Click the **<UI-TERM key="ocp-v2.Detail.Backup.BackupPolicy">Backup Strategy</UI-TERM>** tab.

* Method 2:

   1. Log on to the OceanBase Cloud Platform (OCP) console.

   2. To go to the **Tenants Overview** page. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.util.menu.BackupAndRestoration">Backup & Recovery</UI-TERM>**.

   3. Click **...** in the upper-right corner of the page and choose **<UI-TERM key="ocp-v2.Backup.BackupStrategy.Edit.EditATenantLevelBackupPolicy">Edit Tenant-level Backup Strategy</UI-TERM>** from the drop-down list.

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** or **Tenant Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.constant.auditEvent.BackupAndRestoration">Backup & Recovery</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Detail.Component.DeleteTenantModal.Tenant">Tenants</UI-TERM>**

* The tenant has created a backup strategy.

## Procedure

The following takes **Method 1** as an example.

1. Log on to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Resource.Component.Block.Tenant">Tenants</UI-TERM>** to go to the **Tenants Overview** page.

3. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Backup.BackupStrategy.New.BackupAndRestoration">Backup & Recovery</UI-TERM>**.

4. Click the **<UI-TERM key="ocp-v2.Detail.Backup.BackupPolicy">Backup Strategy</UI-TERM>** tab.

5. Click **<UI-TERM key="ocp-v2.page.MultiCluster.Parameter.Modify">Modify</UI-TERM>** in the upper-right corner of the Tenant Backup Strategy section to modify the backup strategy. For more information, see [Create a tenant-level backup strategy](../200.manage-tenant-backup-strategy/100.creat-a-tenant-backup-stategy.md).
