View services
=========================

On the **<UI-TERM key="ocp-v2.Backup.Service.ServiceList">Services</UI-TERM>** page, you can install services and view existing services. The **<UI-TERM key="ocp-v2.Component.BinlogInstanceList.Operation">Actions</UI-TERM>** column in the **<UI-TERM key="ocp-v2.Backup.Service.ServiceList">Services</UI-TERM>** list provides the following options: **<UI-TERM key="ocp-v2.Service.Component.ServiceModal.AddNode">Add Node</UI-TERM>**, **<UI-TERM key="ocp-v2.Detail.Component.UpgradeModal.UpgradedVersion">Upgrade Version</UI-TERM>**, **Update Configuration**, **<UI-TERM key="ocp-v2.Auth.Role.Copy">Copy</UI-TERM>**, and **<UI-TERM key="ocp-v2.Restore.SamplingStrategy.Delete">Delete</UI-TERM>**.

<main id="notice" type='explain'>
<h4>Note</h4>
<p>The <b>service</b> feature applies only to the <b>logical backup</b> scenario where the cluster to back up is of a version earlier than V2.2.60.</p>
</main>

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.util.menu.Service">Service</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Backup.BackupStrategy.New.BackupAndRestoration">Backup & Recovery</UI-TERM>**

Procedure
---------------------------

1. In the left-side navigation pane, choose **Backup & Recovery > Services**.

2. On the **<UI-TERM key="ocp-v2.Backup.Service.ServiceList">Services</UI-TERM>** page, view the information of services. The table on this page contains the following columns: **<UI-TERM key="ocp-v2.Component.ServiceName.ServiceNameModal.ServiceName">Service Name</UI-TERM>**, **<UI-TERM key="ocp-v2.Backup.Service.ServiceType">Service Type</UI-TERM>**, **<UI-TERM key="ocp-v2.src.component.AddArbitrationDrawer.ServiceVersion">Service Version</UI-TERM>**, **<UI-TERM key="ocp-v2.Host.Component.BatchReinstallModal.HardwareArchitecture">Hardware Architecture</UI-TERM>**, **<UI-TERM key="ocp-v2.Backup.Service.NumberOfNodes">Nodes</UI-TERM>**, **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetailTabs.State">Status</UI-TERM>**, and **<UI-TERM key="ocp-v2.component.TenantList.Operation">Actions</UI-TERM>**. For more information, see [Install a service](../1000.manage-backup-and-recovery-service/200.installation-services.md).

   | Parameter  |   Description    |
   |--------|--------|
   | Service Name | Click the name of a service. The service details page appears.    |
   | Status   | Valid values: **<UI-TERM key="ocp-v2.src.constant.backup.Installing">Installing</UI-TERM>**, **<UI-TERM key="ocp-v2.src.constant.compute.NormalOperation">Running</UI-TERM>**, **<UI-TERM key="ocp-v2.src.constant.backup.Upgrading">Upgrading Version</UI-TERM>**, **Updating Configuration**, and **Exception**.   |
   | Actions   | This column provides the following options: **<UI-TERM key="ocp-v2.src.constant.backup.AddNode">Add Node</UI-TERM>**, **Update Configuration**, **<UI-TERM key="ocp-v2.page.External.Copy">Copy</UI-TERM>**, and **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.Delete">Delete</UI-TERM>**. For more information, see [Add a node](300.add-a-node.md), [Upgrade the service version](400.upgrade-the-service-version.md), [Update service configurations](500.update-service-configurations.md), [Copy a service](600.replication-service.md), and [Delete a service](700.delete-a-service.md). |

3. You can click the plus sign "+" next to a service name to view details of the service. You can also stop, restart, and uninstall a node, and view O&M tasks of a node. For more information, see [Stop a node](900.stop-a-node-service.md), [Restart a node](1000.restart-a-node-service.md), [View O&M tasks](1100.view-o-m-tasks.md), and [Uninstall a node](1200.uninstalls-a-node.md).
