Add a node
===============================

This topic describes how to add a node (host) to an installed service. After you add data nodes, data will be backed up to multiple hosts.

Prerequisites
----------------------------------

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Host Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.util.menu.Service">Service</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Backup.BackupStrategy.New.BackupAndRestoration">Backup & Recovery</UI-TERM>**

* You have installed a backup or recovery service. For more information, see [Install a service](../1000.manage-backup-and-recovery-service/200.installation-services.md).

* You have added the node to OceanBase Cloud Platform (OCP). For more information, see [Add a host](../../850.host-features/200.add-a-host.md).

Procedure
------------------------------

1. In the left-side navigation pane, choose **Backup \& Recovery** **\>** **<UI-TERM key="ocp-v2.Backup.Service.Service">Service</UI-TERM>** .

2. Find the service to add a node to, click **<UI-TERM key="ocp-v2.src.constant.backup.AddNode">Add Node</UI-TERM>** in the **<UI-TERM key="ocp-v2.Backup.Service.Operation">Actions</UI-TERM>** column.

   The **<UI-TERM key="ocp-v2.Service.Component.ServiceModal.AddNode">Add Node</UI-TERM>** dialog box appears.

3. Click the **<UI-TERM key="ocp-v2.Component.InstallService.SelectAHost">Select a host</UI-TERM>** field and select the host (node) to add.

   ![11011526](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/6904306461/p346221.png)

4. Click **<UI-TERM key="ocp-v2.Detail.Component.Event.Determine">OK</UI-TERM>** .
