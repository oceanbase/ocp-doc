# View O&M tasks
This topic describes how to view the operation records of the backup and restore service on a host.

## Prerequisites

The backup and restore service has been installed by referring to [Install the service](../1000.manage-backup-and-recovery-service/200.installation-services.md).
## Procedure

1. In the left navigation bar, click **<UI-TERM key="ocp-v2.src.constant.package.BackupAndRestoration">Backup & Restore</UI-TERM>** **\>** **<UI-TERM key="ocp-v2.src.constant.alarm.Service">Service</UI-TERM>**.

2. Find the target service and click its name.
The system navigates to the service details page.

3. In the **<UI-TERM key="ocp-v2.Backup.Service.Detail.ServiceNode">Node Settings</UI-TERM>** list, locate the node you want to view. Click **<UI-TERM key="ocp-v2.src.constant.backup.ViewOMTasks">View O&M Tasks</UI-TERM>** in the Actions column for that node, or click **...** and select **View O&M Tasks**.

The system displays the **O&M Tasks for Node xxx.xxx.xxx.xxx** page.

   <!-- ![ser_start](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9370249161/p268027.png) -->

   Taking the `Install backup agent` task as an example, it shows the task ID, initiator, status, progress, and start/end times.

4. On the **O&M Tasks for Node xxx.xxx.xxx.xxx** page, click a task name such as `Install backup agent`.

   The system navigates to the details page of the `Install backup agent` task in the **System Management \> Tasks** interface. You can refer to [Task management](../../1600.system-management-features/100.manage-tasks.md) to view detailed information about the task.
