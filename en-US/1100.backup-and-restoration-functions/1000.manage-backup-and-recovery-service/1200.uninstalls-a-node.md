# Uninstall a node
This topic describes how to uninstall the Backup and Restore service from a host.

## Prerequisites

* You have installed the Backup and Restore service by referring to [Install the service](../1000.manage-backup-and-recovery-service/200.installation-services.md).
* You have stopped the node service by performing the [Stop the node service](../1000.manage-backup-and-recovery-service/900.stop-a-node-service.md) operation.

## Procedure

1. In the left navigation pane, click **<UI-TERM key="ocp-v2.Backup.Component.RestoreNow.BackupAndRestoration">Backup & Restore</UI-TERM>** **\>** **<UI-TERM key="ocp-v2.Backup.Service.Install.Service">Service</UI-TERM>**.

2. Find the target service and click its name.
The system redirects to the service details page.

3. In the **<UI-TERM key="ocp-v2.Backup.Service.Detail.ServiceNode">Node Settings</UI-TERM>** list, locate the node you want to uninstall, click **...**, and select **<UI-TERM key="ocp-v2.src.constant.backup.Uninstall">Uninstall</UI-TERM>**.

The system prompts "Are you sure you want to uninstall the service for node 'xxx.xxx.xxx.xxx'?"

   <!-- ![ser_start](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9370249161/p268027.png) -->

   3. In the **<UI-TERM key="ocp-v2.Backup.Service.Detail.ServiceNode">Node Settings</UI-TERM>** list, find the node you want to uninstall, click **...**, and select **<UI-TERM key="ocp-v2.src.constant.backup.Uninstall">Uninstall</UI-TERM>**.

The system prompts "Are you sure you want to uninstall the service for node «xxx.xxx.xxx.xxx»?"

   4. Click **<UI-TERM key="ocp-v2.src.constant.backup.Uninstall">Uninstall</UI-TERM>**.

4. Click **Uninstall**.
