# Restart a node service
This section describes how to restart the backup and restore service on a host.

## Prerequisites

You have installed the backup and restore service by following [Install the service](../1000.manage-backup-and-recovery-service/200.installation-services.md).
## Procedure

1. In the left navigation pane, click **<UI-TERM key="ocp-v2.src.constant.compute.BackupAndRestoration">Backup & Restore</UI-TERM>** **\>** **<UI-TERM key="ocp-v2.Backup.Service.Clone.Service">Service</UI-TERM>**.

2. Find the target service and click its name.
The system redirects to the service details page.

3. In the **<UI-TERM key="ocp-v2.Backup.Service.Detail.ServiceNode">Node Settings</UI-TERM>** list, locate the node you want to restart and click **<UI-TERM key="ocp-v2.src.util.component.Restart">Restart</UI-TERM>**.

The system prompts "Are you sure you want to restart the service for node 「xxx.xxx.xxx.xxx」?"

   <!-- ![p268021](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/6927270261/p268315.png) -->

   3. In the **<UI-TERM key="ocp-v2.Backup.Service.Detail.ServiceNode">Node Settings</UI-TERM>** list, find the node you want to restart and click **<UI-TERM key="ocp-v2.src.util.component.Restart">Restart</UI-TERM>**.

The system prompts "Are you sure you want to restart the service for node «xxx.xxx.xxx.xxx»?"

   4. Click **<UI-TERM key="ocp-v2.Overview.components.JVMServiceInfo.Restart">Restart</UI-TERM>**.

4. Click **Restart**.
