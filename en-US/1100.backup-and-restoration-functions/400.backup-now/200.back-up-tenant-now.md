# Back up a tenant now

This topic describes how to back up a tenant immediately.

You can back up a tenant immediately by using one of the following methods.

* **Method 1**: Log in to the OceanBase Cloud Platform (OCP) console. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.Backup.BackupStrategy.Edit.BackupAndRestoration">Backup & Recovery</UI-TERM>** > **<UI-TERM key="ocp-v2.Backup.AddStrategy.Backup">Backups</UI-TERM>**. On the **<UI-TERM key="ocp-v2.Backup.Backup.Backup">Backups</UI-TERM>** page, click **Back up Now** in the upper-right corner of the page and choose **<UI-TERM key="ocp-v2.Backup.Component.BackupNowTenantDrawer.BackupTenant">Back Up Tenant</UI-TERM>** from the drop-down list.

* **Method 1**: Log in to the OCP console and go to the **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** page of the target tenant. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Backup.Guide.BackupAndRestoration">Backup & Recovery</UI-TERM>**. Then, click **Back up Now**.

## Prerequisites

* To back up a tenant by using **Method 1**, make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** or **Tenant Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Component.BackupStrategyDetail.Backup">Backup</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Backup.BackupStrategy.Edit.BackupAndRestoration">Backup & Recovery</UI-TERM>**

* To back up a tenant by using **Method 2**, make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** or **Tenant Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Backup.Component.RestoreNow.BackupAndRestoration">Backup & Recovery</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Tenant.New.Tenant">Tenants</UI-TERM>**

* Tenant backup is supported only in OceanBase Database V3.2.2-20220304134610 and later.

## Procedure

The procedure of **Method 1** is described as follows:

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.Backup.BackupStrategy.Edit.BackupAndRestoration">Backup & Recovery</UI-TERM>** > **<UI-TERM key="ocp-v2.Backup.AddStrategy.Backup">Backups</UI-TERM>**. On the **<UI-TERM key="ocp-v2.Backup.AddStrategy.Backup">Backups</UI-TERM>** page, click **Back up Now** in the upper-right corner of the page and choose **<UI-TERM key="ocp-v2.Backup.Backup.BackupTenant">Back Up Tenant</UI-TERM>** from the drop-down list.

3. Select the object that you want to back up.

   Select the object that you want to back up from the **<UI-TERM key="ocp-v2.Backup.Restore.RestoreTask.BackupTenant">Backup Tenant</UI-TERM>** drop-down list. The system automatically identifies **<UI-TERM key="ocp-v2.Backup.Component.BackupNowDrawer.ObVersion">OceanBase Version</UI-TERM>** and **<UI-TERM key="ocp-v2.Backup.Restore.RestoreTask.BackupMethod">Backup Method</UI-TERM>** of the tenant and automatically populates the fields of **<UI-TERM key="ocp-v2.Component.BackupStrategyDetail.StorageConfiguration">Storage Configuration</UI-TERM>**.

4. Specify **<UI-TERM key="ocp-v2.Component.StorageConfigCard.StorageConfiguration">Storage Configuration</UI-TERM>**.

   * If the tenant that you want to back up has a backup strategy, the fields in the **<UI-TERM key="ocp-v2.Component.StorageConfigCard.StorageConfiguration">Storage Configuration</UI-TERM>** section are automatically populated.

   * Otherwise, you must manually specify the configuration. You can specify the configuration as prompted or by following the instructions of Step 4 in [Create a tenant-level backup strategy](../500.regular-backup/200.manage-tenant-backup-strategy/100.creat-a-tenant-backup-stategy.md).

     Then, click **<UI-TERM key="ocp-v2.Cluster.New.Test">Test</UI-TERM>**.

   ![Image 47](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E7%A7%9F%E6%88%B7%E7%AB%8B%E5%8D%B3%E5%A4%87%E4%BB%BD.png)

5. Select a data backup method.

   For physical backup, select a data backup method. For logical backup, only full backup is supported.

    <main id="notice" type='notice'>
    <h4>Notice</h4>
    <ul>
    <li>For physical backup, you must perform a full backup before you can perform an incremental backup. Otherwise, the following error message is returned in the <code>Check if ready to data backup</code> step: &quot;full data backup needed before incremental data backup.&quot;</li>
    <li>If the error message &quot;Cluster compaction needed before full data backup&quot; is returned in the <code>Start cluster compact if necessary</code> step of a full backup, <a href="../../600.cluster-functions/1100.manage-cluster-merge/200.cluster-perform-merge.md">perform a major compaction</a> and click <strong>Retry</strong>. </li>
    </ul>
    </main>

6. Click **Back up Now**.
