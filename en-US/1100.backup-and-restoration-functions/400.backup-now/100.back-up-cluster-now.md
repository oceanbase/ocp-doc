# Back up a cluster now

This topic describes how to back up a cluster immediately.

You can back up a cluster immediately by using the following methods.

* **Method 1**: Log in to the OceanBase Cloud Platform (OCP) console. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.Backup.Guide.BackupAndRestoration">Backup & Recovery</UI-TERM>** > **<UI-TERM key="ocp-v2.Backup.AddStrategy.Backup">Backups</UI-TERM>**. On the **<UI-TERM key="ocp-v2.Backup.Backup.Backup">Backups</UI-TERM>** page, click **Back up Now** in the upper-right corner of the page and select **<UI-TERM key="ocp-v2.Backup.Backup.BackupCluster">Back Up Cluster</UI-TERM>** from the drop-down list.

* **Method 1**: Log in to the OCP console and go to the **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** page of the target cluster. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.constant.auditEvent.BackupAndRestoration">Backup & Recovery</UI-TERM>**. Then, click **Back up Now**.

## Prerequisites

* To back up a cluster by using **Method 1**, make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** or **Tenant Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Component.BackupStrategyCard.Backup">Backup</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Backup.BackupStrategy.New.BackupAndRestoration">Backup & Recovery</UI-TERM>**

* To back up a cluster by using **Method 2**, make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Backup.BackupStrategy.Edit.BackupAndRestoration">Backup & Recovery</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>**

* A cluster in logical backup mode supports only full backup. A cluster in physical backup mode supports both full backup and incremental backup.

* The cluster to be backed up is not in the **<UI-TERM key="ocp-v2.src.constant.binlog.Upgraded">Upgrading</UI-TERM>** state.

## Procedure

The procedure of **Method 1** is described as follows:

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.Backup.BackupStrategy.New.BackupAndRestoration">Backup & Recovery</UI-TERM>** > **<UI-TERM key="ocp-v2.Backup.Backup.Backup">Backups</UI-TERM>**. On the **<UI-TERM key="ocp-v2.src.util.menu.Backup">Backups</UI-TERM>** page, click **Back up Now** in the upper-right corner of the page and choose **<UI-TERM key="ocp-v2.Backup.Backup.BackupCluster">Back Up Cluster</UI-TERM>** from the drop-down list.

3. Select the object that you want to back up.

   Select the object that you want to back up from the **<UI-TERM key="ocp-v2.Backup.Restore.RestoreTask.BackupCluster">Backup Cluster</UI-TERM>** drop-down list. The system automatically identifies **<UI-TERM key="ocp-v2.Backup.Component.BackupNowDrawer.ObVersion">OceanBase Version</UI-TERM>** and **<UI-TERM key="ocp-v2.Component.BackupStrategyDetail.BackupMethod">Backup Method</UI-TERM>** of the cluster and populates the fields in **<UI-TERM key="ocp-v2.Component.StorageConfigCard.StorageConfiguration">Storage Configuration</UI-TERM>**.

   If the backup mode of the cluster is logical backup, you must first install the backup service. For more information, see [Install a service](../1000.manage-backup-and-recovery-service/100.service-features.md).

4. Specify **<UI-TERM key="ocp-v2.Backup.Service.Detail.StorageConfiguration">Storage Configuration</UI-TERM>**.

   * If the cluster that you want to back up has a backup strategy, the fields in the **<UI-TERM key="ocp-v2.Component.BackupStrategyDetail.StorageConfiguration">Storage Configuration</UI-TERM>** section are automatically populated.

   * Otherwise, you must manually specify the values. You can specify the values as prompted or by following the instructions of Step 4 in [Create a cluster-level backup strategy](../500.regular-backup/100.manage-cluster-backup-strategy/100.create-a-cluster-backup-strategy.md).

     Then, click **<UI-TERM key="ocp-v2.src.component.ArchiveForm.Test">Test</UI-TERM>**.

   ![Image 47](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/6934633561/p440598.png)

5. Select a data backup method.

   For physical backup, select a data backup method. For logical backup, only full backup is supported.

    <main id="notice" type='notice'>
    <h4>Notice</h4>
    <ul>
    <li>For physical backup, you must perform a full backup before you can perform an incremental backup. Otherwise, the following error message is returned in the <code>Check if ready to data backup</code> step: &quot;full data backup needed before incremental data backup.&quot;</li>
    <li>If the error message &quot;Cluster compaction needed before full data backup&quot; is returned in the <code>Start cluster compact if necessary</code> step of a full backup, <a href="../../600.cluster-functions/1100.manage-cluster-merge/200.cluster-perform-merge.md">perform a major compaction</a> and click <strong>Retry</strong>. </li>
    </ul>
    </main>

6. Click **Back up Now**.
