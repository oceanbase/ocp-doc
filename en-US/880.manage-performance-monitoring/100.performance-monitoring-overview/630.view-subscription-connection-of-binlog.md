# View subscription connection monitoring charts

This topic describes how to view the monitoring data of subscription connections of a binlog instance.

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OceanBase Cloud Platform (OCP) Enterprise Edition. OCP Community Edition does not support this feature. </p>
</main>

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Binlog Service Read-only** permission
* **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** menu of the **<UI-TERM key="ocp-v2.Detail.Overview.BinlogService">Binlog Service</UI-TERM>**

## Procedure

1. Log on to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Detail.Overview.BinlogService">Binlog Service</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.Binlog.ClusterList">Cluster List</UI-TERM>** tab automatically appears.

3. On the **<UI-TERM key="ocp-v2.page.Binlog.ClusterList">Cluster List</UI-TERM>** page, find the target binlog cluster and click its name to go to the **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** page.

4. In the **<UI-TERM key="ocp-v2.Component.BinlogInstanceList.BinlogInstanceList">Binlog Instance List</UI-TERM>** section, find the target binlog instance and click its name.

5. On the **<UI-TERM key="ocp-v2.Instance.Overview.BinlogInstanceOverview">Binlog Instance Overview</UI-TERM>** page, configure the monitoring time range in the **<UI-TERM key="ocp-v2.Instance.Overview.SubscriptionConnectionList">Subscription Connection List</UI-TERM>** section.

    By default, the monitoring data of the last 5 minutes is displayed. You can select **<UI-TERM key="ocp-v2.component.RangeTimeDropdown.LastMinutes">Last 5 Minutes</UI-TERM>**, **<UI-TERM key="ocp-v2.src.constant.log.NearFenZhong.1">Last 10 Minutes</UI-TERM>**, **<UI-TERM key="ocp-v2.component.RangeTimeDropdown.LastMinutes.2">Last 20 Minutes</UI-TERM>**, **<UI-TERM key="ocp-v2.component.OCPRangePicker.constant.NearlyMinutes.3">Last 30 Minutes</UI-TERM>**, **Last 3 Hour**, **<UI-TERM key="ocp-v2.component.OCPRangePicker.constant.NearlyHour.6">Last 6 Hours</UI-TERM>**, **<UI-TERM key="ocp-v2.src.constant.log.NearlyHours.2">Last 12 Hours</UI-TERM>**, **<UI-TERM key="ocp-v2.Cluster.Component.PerformanceTop5.LastDay">Last 24 Hours</UI-TERM>**, or **<UI-TERM key="ocp-v2.Cluster.Component.PerformanceTop5.LastWeek">Last 7 Days</UI-TERM>** from the **Monitoring time range** drop-down list to view monitoring data of the selected statistical period. You can also select **<UI-TERM key="ocp-v2.component.RangeTimeDropdown.CustomTime">Custom Time</UI-TERM>** from the drop-down list and specify the start time and end time as needed.

6. Click the plus sign (**+**) on the left of the username to view the real-time monitoring charts of **<UI-TERM key="ocp-v2.Instance.Overview.Monitor.SendDelay">Sending Delay</UI-TERM>**, **<UI-TERM key="ocp-v2.Instance.Overview.SendRps">Associate RPS</UI-TERM>**, and **<UI-TERM key="ocp-v2.Instance.Overview.Monitor.NetworkTraffic">Network Traffic</UI-TERM>**.

   For more information about the monitoring metrics, see [Overview of metrics](../../1900.reference-guide/300.monitoring-indicator-reference/100.overview-of-metrics.md).
