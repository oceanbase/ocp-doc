# View performance monitoring data of a binlog instance

This topic describes how to view the performance monitoring data of a binlog instance.

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OceanBase Cloud Platform (OCP) Enterprise Edition. OCP Community Edition does not support this feature. </p>
</main>

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Binlog Service Read-only** permission
* **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** menu of the **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogService">Binlog Service</UI-TERM>**

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogService">Binlog Service</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** page automatically appears.

3. On the **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** page, find the target binlog cluster and click its name to go to the **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** page.

4. In the **<UI-TERM key="ocp-v2.Component.BinlogInstanceList.BinlogInstanceList">Binlog Instance List</UI-TERM>** section, find the target binlog instance and click its name.

5. In the left-side navigation pane on the page that appears, click **Resource Monitoring**.

6. On the **Binlog Performance Monitoring** tab that automatically appears, view the performance monitoring data of the **Binlog Conversion Delay** and **Binlog Conversion RPS** metrics.

   ![1126](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/434/01061530.png)

   For more information about the monitoring metrics, see [Overview of metrics](../../1900.reference-guide/300.monitoring-indicator-reference/100.overview-of-metrics.md).

   The following features allow you to view and analyze the performance monitoring data on a trend chart.

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/434/01061531.png)

   1. By default, the performance monitoring data of the last 1 hour is displayed. You can select **<UI-TERM key="ocp-v2.component.RangeTimeDropdown.LastMinutes">Last 5 Minutes</UI-TERM>**, **<UI-TERM key="ocp-v2.component.OCPRangePicker.constant.NearlyMinutes.1">Last 10 Minutes</UI-TERM>**, **<UI-TERM key="ocp-v2.component.RangeTimeDropdown.LastMinutes.2">Last 20 Minutes</UI-TERM>**, **<UI-TERM key="ocp-v2.component.OCPRangePicker.constant.NearlyMinutes.3">Last 30 Minutes</UI-TERM>**, **Last 3 Hour**, **<UI-TERM key="ocp-v2.component.OCPRangePicker.constant.NearlyHour.6">Last 6 Hours</UI-TERM>**, **<UI-TERM key="ocp-v2.src.constant.log.NearlyHours.2">Last 12 Hours</UI-TERM>**, **<UI-TERM key="ocp-v2.src.component.RangeTimeDropdown.LastDay">Last 24 Hours</UI-TERM>**, or **<UI-TERM key="ocp-v2.src.component.RangeTimeDropdown.LastWeek">Last 7 Days</UI-TERM>** from the **Monitoring time range** drop-down list to view monitoring data of the selected statistical period. You can also select **<UI-TERM key="ocp-v2.component.RangeTimeDropdown.CustomTime">Custom Time</UI-TERM>** from the drop-down list and specify the start time and end time as needed.

   2. Enable **<UI-TERM key="ocp-v2.Detail.Monitor.AutomaticRefresh">Auto Refresh</UI-TERM>**. The performance monitoring view refreshes every 5 seconds. You can view the performance monitoring data of the binlog instance.

   3. Hide the data of a submetric: To use this feature, click the icon of the submetric. The submetric will then turn gray and its data will be hidden from the chart.

   4. View detailed data of a specific point in time or a period of time: You can hover the pointer over a point in time on the trend chart to view the detailed data. You can also drag the pointer to select a period of time on the trend chart and have a zoomed-in view of data in this period of time. To resume the normal view, double-click the trend chart.

   5. Zoom in on the trend chart: To use this feature, click the zoom-in icon in the upper-right corner. The features indicated by ①, ③, and ④ in the preceding figure are also applicable to a zoomed-in chart.
