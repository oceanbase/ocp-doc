# View performance monitoring

This topic describes how to view performance monitoring of sql diagnostics.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
* **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.Realtime.RealTimeDiagnosis">Real-time Diagnostics</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.hook.useMenu.AutonomousService">OceanBase Autonomy Service</UI-TERM>**

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, click **Autonomous service**.

3. In the **<UI-TERM key="ocp-v2.page.Diagnosis.ClusterDetails">Cluster Details</UI-TERM>** section, click the name of the target cluster.

4. By default, the **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.SqlDiagnosis">SQL Diagnostics</UI-TERM>** tab of the **<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">Real-time Diagnostics</UI-TERM>** page appears. Click **<UI-TERM key="ocp-v2.Detail.Realtime.ViewPerformanceMonitoring">View Performance Monitoring</UI-TERM>**. In the panel that appears, you can view the trend charts of the read/write response time, number of read/write requests, and CPU utilization for the tenant within a specified period of time. For more information, see [Performance monitoring](../100.performance-monitoring-overview/400.view-tenant-performance-and-sql.md).
