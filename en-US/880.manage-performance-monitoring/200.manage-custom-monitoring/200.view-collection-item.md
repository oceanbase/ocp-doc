# View collection items

OceanBase Cloud Platform (OCP) provides built-in collection items. This topic describes how to view and filter collection items.

You can view collection items by using the following three methods:

* **Method 1**: Go to the **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CustomMonitoring">Custom Monitoring</UI-TERM>** page. By default, the **Collection Items** tab appears.
* **Method 2**: If no metrics are created, go to the **<UI-TERM key="ocp-v2.page.Monitor.CustomMonitoring">Custom Monitoring</UI-TERM>** page, and click **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.ViewCollectionItems">View Collection Items</UI-TERM>** on the **<UI-TERM key="ocp-v2.Alarm.Template.Detail.Indicators">Metrics</UI-TERM>** tab.
* **Method 3**: If no charts are created, go to the **<UI-TERM key="ocp-v2.page.Monitor.CustomMonitoring">Custom Monitoring</UI-TERM>** page, and click **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.ViewCollectionItems">View Collection Items</UI-TERM>** on the **Charts** tab.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only**, **Tenant Read-only**, **OBProxy Read-only**, **Arbitration Service Read-only**, **Binlog Service Read-only**, or **Host Read-only** permission
* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.Analyze.All">All</UI-TERM>** menu of the **<UI-TERM key="ocp-v2.src.hook.useMenu.MonitoringDashboard">Monitoring Dashboard</UI-TERM>**

## Procedure

The following procedure demonstrates how to use **Method 1**.

1. Log on to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.Detail.Monitor.PerformanceMonitoring">Performance Monitoring</UI-TERM>**.

3. Click the **<UI-TERM key="ocp-v2.page.Monitor.CustomMonitoring">Custom Monitoring</UI-TERM>** in the upper-right corner. By default, the **<UI-TERM key="ocp-v2.Monitor.AddMonitor.Chart">Chart</UI-TERM>** tab appears.

4. Click the **Collection Items** tab.

   This tab shows the information about each collection item in the following columns: **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.CollectionItemName">Collection Item Name</UI-TERM>**, **<UI-TERM key="ocp-v2.Inspection.Item.ConfigItem.Description">Description</UI-TERM>**, **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.Features">Feature</UI-TERM>**, **<UI-TERM key="ocp-v2.src.template.Table.CollectionInterval">Collection Interval</UI-TERM>**, **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMetricDrawer.Unit">Unit</UI-TERM>**, **<UI-TERM key="ocp-v2.Detail.Overview.Label">Label</UI-TERM>**, **<UI-TERM key="ocp-v2.src.template.Table.ObjectDimension">Object Dimension</UI-TERM>**, and **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.Type">Type</UI-TERM>**.

   | Column | Description |
   |------|---------|
   | Collection Item Name | The unique name of the collection item.  |
   | Description | The additional information about the collection item.  |
   | Feature | The characteristic of the collection item. Valid values: **COUNTER** and **GAUGE**. <ul><li>COUNTER: The collection item works like a counter, whose value increases unless a system reset. The number of sessions and the number of client requests are typical COUNTER collection items. </li><li>GAUGE: The collection item works like a gauge, whose value may increase or decrease over time. A GAUGE collection item reflects the current state of the system. CPU utilization and memory usage are typical GAUGE collection items. </li></ul> |
   | Collection Interval | The data collecting granularity of the collection item. Valid values: **<UI-TERM key="ocp-v2.Channel.FormComponent.RepeatInterval.Seconds">Seconds</UI-TERM>** and **<UI-TERM key="ocp-v2.Channel.FormComponent.RepeatInterval.Minutes">Minutes</UI-TERM>**.  |
   | Unit | <ul><li>-: This is the default value.</li><li>Data unit:<ul><li>bits</li><li>bytes</li><li>KB</li><li>MB</li><li>GB</li><li>TB</li><li>PB</li></ul></li><li>Time unit:<ul><li>Microseconds (µs)</li><li>Milliseconds (ms)</li><li>Seconds (s)</li><li>Minutes</li></ul></li><li>Others: Percentage. Value range: 0 to 100.</li></ul> |
   | Label | The label information that is obtained when the collection item collects data.  |
   | Object Dimension | The dimension from which the collection item collects data. Valid values: **<UI-TERM key="ocp-v2.src.constant.auditEvent.Host">Host</UI-TERM>**, **OceanBase**, and **OBProxy**.  |
   | Type | The type of the collection item. Valid values: **<UI-TERM key="ocp-v2.src.constant.inspection.Custom">Custom</UI-TERM>** and **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.Default">Default</UI-TERM>**. If you require custom collection items, contact OCP Technical Support.  |

   * You can query collection items by page and search for collection items by using keywords in their names.
   * You can filter collection items by using the **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.CollectionInterval">Collection Interval</UI-TERM>**, **<UI-TERM key="ocp-v2.src.template.Table.ObjectDimension">Object Dimension</UI-TERM>**, and **<UI-TERM key="ocp-v2.page.External.SSOInfoDrawer.Type">Type</UI-TERM>** columns.

   For more information about collection items, see [OCP metrics](500.ocp-monitoring-indicator-items.md).
