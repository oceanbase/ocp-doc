# Create a chart

This topic describes how to create a chart. OceanBase Cloud Platform (OCP) allows you to create a chart to display the execution results of custom metrics.

You can create a chart by using the following three methods:

* **Method 1**: On the **<UI-TERM key="ocp-v2.Detail.Monitor.CustomMonitoring">Custom Monitoring</UI-TERM>** page, click **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CreateAChart">Create Chart</UI-TERM>** in the upper-right corner.
* **Method 2**: If no charts are created, go to the **<UI-TERM key="ocp-v2.page.Monitor.CustomMonitoring">Custom Monitoring</UI-TERM>** page, and click **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.CreateAChart">Create Chart</UI-TERM>** on the **Charts** tab.
* **Method 3**: If you have created a metric, go to the **<UI-TERM key="ocp-v2.Host.Detail.Monitor.CustomMonitoring">Custom Monitoring</UI-TERM>** page and click the **<UI-TERM key="ocp-v2.Alarm.Rule.New.Indicators">Metrics</UI-TERM>** tab, where you can create a chart for the metric.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only**, **Tenant Read-only**, **OBProxy Read-only**, **Arbitration Service Read-only**, **Binlog Service Read-only**, or **Host Read-only** permission
* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Component.ArbitrationTransfer.All">All</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Detail.Monitor.PerformanceMonitoring">Performance Monitoring</UI-TERM>**

## Procedure

The following procedure demonstrates how to use **Method 1**.

1. Log on to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.Detail.Realtime.PerformanceMonitoring">Performance Monitoring</UI-TERM>**.

3. Click **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CustomMonitoring">Custom Monitoring</UI-TERM>** in the upper-right corner.

4. On the **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CustomMonitoring">Custom Monitoring</UI-TERM>** page, click **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.CreateAChart">Create Chart</UI-TERM>** in the upper-right corner.

5. In the panel that appears on the right, set the parameters.

   | Parameter | Description |
   |------|---------|
   | Chart Name | The name of the chart. The name can contain uppercase and lowercase letters, digits, and underscores (_), and must be 2 to 48 characters in length.  |
   | Chart Description | The additional information about the chart.  |
   | Chart Position | The location where the chart is displayed. Valid values:<ul><li>Clusters - Database Performance</li><li>Clusters - Host Performance</li><li>Clusters - OBServer Performance</li><li>Tenants - Performance and SQL</li><li>Tenants - Transactions</li><li>Tenants - Storage and Cache</li><li>OBProxy - System Monitoring</li><li>Host Performance</li><li>Host Resources</li><li>Host Process</li></ul> <main id="notice" type='note'><h4>Note</h4><p>When you create a chart for specific metrics, the chart location is automatically generated based on the metrics. </p></main> |
   | Monitoring Metrics | <ul><li>**<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.SelectAMetricItem">Selected Metric</UI-TERM>**: Select a metric from the drop-down list. The selected metric is associated with the chart location. If the required metric does not exist in the drop-down list, you can click **<UI-TERM key="ocp-v2.alarm.ExpressionFormList.MultipleExpressionFormList.AddMetrics">Add Metric</UI-TERM>** at the bottom of the list to create a metric. For more information, see [Create a metric](../300.manage-indicator-items/100.create-a-indicator-item.md). <br>In the **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.SelectAMetricItem">Selected Metric</UI-TERM>** drop-down list, you can select built-in and custom metrics of OCP. For more information about built-in metrics of OCP, see [Overview](../../../1900.reference-guide/300.monitoring-indicator-reference/100.overview-of-metrics.md). </li><li>**<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.DisplayIndicatorName">Displayed Metric Name</UI-TERM>**: the displayed name of the selected metric. This parameter is automatically filled based on the selected metric, and can be modified. </li><li>**<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.IndicatorItemDescription">Metric Description</UI-TERM>**: the description of the selected metric. This parameter is automatically filled based on the selected metric, and can be modified. </li><li>**<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.Unit">Unit</UI-TERM>**: The unit of the selected metric. This parameter is automatically filled based on the selected metric, and can be modified. </li></ul><main id="notice" type='note'><h4>Note</h4><p><ul><li>To use multiple metrics in the chart, click **add a row of data** to add a metric. To remove a metric, click **<UI-TERM key="ocp-v2.Auth.User.Detail.Delete">Delete</UI-TERM>** in the **<UI-TERM key="ocp-v2.Cluster.Arbitration.Operation">Actions</UI-TERM>** column. </li><li>The system consumes server resources to query the monitoring data of a metric. If you use multiple metrics in a chart and server resources are insufficient, data queries are slow. We recommend that you add metrics based on the actual server resources. </li></ul></p></main> |
   | Graphic Style | The style of the chart. Only line charts are supported.  |
