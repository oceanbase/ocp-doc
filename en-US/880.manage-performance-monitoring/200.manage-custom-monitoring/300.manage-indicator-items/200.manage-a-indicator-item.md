# Manage metrics

On the **<UI-TERM key="ocp-v2.Alarm.Rule.Detail.Indicators">Metrics</UI-TERM>** tab, you can edit, copy, and delete custom metrics, create charts, and create alert rules.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only**, **Tenant Read-only**, **OBProxy Read-only**, **Arbitration Service Read-only**, **Binlog Service Read-only**, or **Host Read-only** permission
* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.SQLDiagnosis.Outline.All">All</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.util.menu.PerformanceMonitoring">Performance Monitoring</UI-TERM>**

## Procedure

### Edit a metric

OceanBase Cloud Platform (OCP) allows you to modify the parameters of metrics.

1. Log on to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.PerformanceMonitoring">Performance Monitoring</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.Alarm.Rule.Detail.Indicators">Metrics</UI-TERM>** tab, find the metric that you want to edit and click **<UI-TERM key="ocp-v2.src.constant.oceanbase.Edit">Edit</UI-TERM>** in the **<UI-TERM key="ocp-v2.component.CardAbnormalTable.Operation">Actions</UI-TERM>** column.

4. In the panel that appears on the right, modify the parameters.

5. Click **<UI-TERM key="ocp-v2.Dashboard.component.ImportDashboardModal.Ok">OK</UI-TERM>**.

### Copy a metric

You can quickly create a metric by copying an existing metric and modifying the parameter settings.

1. Log on to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.page.Monitor.PerformanceMonitoring">Performance Monitoring</UI-TERM>**.

3. Click **<UI-TERM key="ocp-v2.Detail.Monitor.CustomMonitoring">Custom Monitoring</UI-TERM>** in the upper-right corner.

4. On the **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CustomMonitoring">Custom Monitoring</UI-TERM>** page, click the **<UI-TERM key="ocp-v2.component.alarm.RuleDetail.Metric">Metrics</UI-TERM>** tab.

5. On the **<UI-TERM key="ocp-v2.Alarm.Rule.New.Indicators">Metrics</UI-TERM>** tab, find the metric that you want to copy and click **<UI-TERM key="ocp-v2.Auth.User.Detail.Copy">Copy</UI-TERM>** in the **<UI-TERM key="ocp-v2.component.CardAbnormalTable.Operation">Actions</UI-TERM>** column.

6. Optional. In the panel that appears on the right, modify the parameters.

7. Click **<UI-TERM key="ocp-v2.MultiCluster.Detail.FailoverModal.Determine">OK</UI-TERM>**.

### Delete a metric

You can delete a metric that you no longer use.

1. Log on to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.Monitor.AddMonitor.PerformanceMonitoring">Performance Monitoring</UI-TERM>**.

3. Click **<UI-TERM key="ocp-v2.Detail.Monitor.CustomMonitoring">Custom Monitoring</UI-TERM>** in the upper-right corner.

4. On the **<UI-TERM key="ocp-v2.Host.Detail.Monitor.CustomMonitoring">Custom Monitoring</UI-TERM>** page, click the **<UI-TERM key="ocp-v2.component.alarm.RuleDetail.Metric">Metrics</UI-TERM>** tab.

5. On the **<UI-TERM key="ocp-v2.Alarm.Rule.New.Indicators">Metrics</UI-TERM>** tab, find the metric that you want to delete and choose **More > Delete** in the **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.Operation">Actions</UI-TERM>** column.

6. In the dialog box that appears, click **<UI-TERM key="ocp-v2.Component.OBServerList.OBServerModal.Ok">OK</UI-TERM>**.

<main id="notice" type='notice'>
<h4>Notice</h4>
<p>If you delete a metric that is used in a chart or alert rule, the chart or alert rule is also deleted. </p>
</main>

### Create a chart

You can use a metric in a chart.

1. Log on to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.Instance.Monitor.PerformanceMonitoring">Performance Monitoring</UI-TERM>**.

3. Click **<UI-TERM key="ocp-v2.page.Monitor.CustomMonitoring">Custom Monitoring</UI-TERM>** in the upper-right corner.

4. On the **<UI-TERM key="ocp-v2.Detail.Monitor.CustomMonitoring">Custom Monitoring</UI-TERM>** page, click the **<UI-TERM key="ocp-v2.Alarm.Template.New.Indicators">Metrics</UI-TERM>** tab.

5. On the **<UI-TERM key="ocp-v2.Alarm.Rule.New.Indicators">Metrics</UI-TERM>** tab, find the metric that you want to use and choose **More > Create Chart** in the **<UI-TERM key="ocp-v2.Settings.Credential.Host.Operation">Actions</UI-TERM>** column.

   For more information, see [Create a chart](../400.manage-chart/100.create-a-chart.md).

### Create an alert rule

You can create an alert rule for a metric. When the metric value exceeds the specified threshold, the system pushes an alert to the specified recipients.

1. Log on to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.PerformanceMonitoring">Performance Monitoring</UI-TERM>**.

3. Click **<UI-TERM key="ocp-v2.Host.Detail.Monitor.CustomMonitoring">Custom Monitoring</UI-TERM>** in the upper-right corner.

4. On the **<UI-TERM key="ocp-v2.Detail.Monitor.CustomMonitoring">Custom Monitoring</UI-TERM>** page, click the **<UI-TERM key="ocp-v2.Component.SQLCondition.Metric">Metrics</UI-TERM>** tab.

5. On the **<UI-TERM key="ocp-v2.Alarm.Rule.AddAlarmMetricModal.Metric">Metrics</UI-TERM>** tab, find the metric that you want to use and choose **More > Create Alert Rule** in the **<UI-TERM key="ocp-v2.Auth.User.Operation">Actions</UI-TERM>** column.

6. Set parameters on the **<UI-TERM key="ocp-v2.Alarm.Rule.New.CreateAlertRule">Create Alert Rule</UI-TERM>** page. For more information, see [Create an alert rule](../../../860.alert-management/300.manage-alert-rules/100.create-an-alert-rule.md).
