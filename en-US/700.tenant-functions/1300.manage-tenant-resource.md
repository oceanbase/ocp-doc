# Manage the resources of a tenant

On the **<UI-TERM key="ocp-v2.page.Iframe.ResourceManagement">Resource Management</UI-TERM>** page of a tenant, you can view the resource usage trend, database, and table group information of the tenant, and filter the information by database, table group, table, or partition.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
* **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.util.menu.ResourceManagement">Resource Management</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Resource.Component.Block.Tenant">Tenants</UI-TERM>**

## Go to the Resource Management page

1. Log on to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, select **<UI-TERM key="ocp-v2.Detail.Component.DeleteTenantModal.Tenant">Tenants</UI-TERM>**. The **<UI-TERM key="ocp-v2.Compaction.DetailV4.CompactionTenantListMyDrawer.Tenant">Tenants</UI-TERM>** tab automatically appears.

3. On the **<UI-TERM key="ocp-v2.src.constant.auditEvent.Tenant">Tenants</UI-TERM>** tab, find the target tenant and click its name to go to the **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">Overview</UI-TERM>** page of the tenant.

4. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.util.menu.ResourceManagement">Resource Management</UI-TERM>**. The **<UI-TERM key="ocp-v2.Detail.Resource.ResourceManagement">Resource Management</UI-TERM>** page of the tenant appears.

   You can filter the resource information to display on this page.

   <main id="notice" type='explain'>
   <h4>Note</h4>
   <p>The system collects statistics on the resource usage trend as well as database and table group information at about 5:00 a.m. every day. For a new cluster, no statistical data is generated on the day when the cluster was created.</p>
   </main>

## Filter by conditions

* You can select **<UI-TERM key="ocp-v2.ComparisonSqlDrawer.DetailedTable.Database">Database</UI-TERM>** for **<UI-TERM key="ocp-v2.Detail.Resource.ConditionRange">Condition Range</UI-TERM>**. After you select Database, you can select all databases or a specific database, all tables or a specific table, and all partitions or a specific partition in the subsequent fields. After you specify the filter conditions, click Search and view information in the **<UI-TERM key="ocp-v2.Detail.Resource.Trend.ResourceUsageTrends">Resource Usage Tendency</UI-TERM>** and **<UI-TERM key="ocp-v2.Detail.Resource.Top.List">Rankings</UI-TERM>** sections.

* You can also select **<UI-TERM key="ocp-v2.Detail.Resource.Top.TableGroup">Table Groups</UI-TERM>** for filtering. In this case, you can select all table groups or a specific table group, all tables or a specific table, and all partitions or a specific partition.

    <main id="notice" type='explain'>
    <h4>Note</h4>
    <ul>
    <li>Tables in the oceanbase system table group are for internal use only. You cannot add tables to this table group. Unlike tables in user-defined table groups, tables in the oceanbase system table group are distributed across three built-in databases. </li>
    <li><strong>non_tablegroup</strong> indicates a table that does not belong to any table group, and this table is not displayed. To get a table that does not belong to any table group, you must select <strong>Database</strong> for Condition Range. </li>
    </ul>
    </main>

## View the resource usage trend

In the **<UI-TERM key="ocp-v2.Detail.Resource.ResourceUsage">Resource Usage</UI-TERM>** section, you can select last 7 or 30 days, or specify a custom period to view the CPU, memory, partition replica, log disk, and data disk usage information of the specified period.

   <main id="notice" type='explain'>
    <h4>Note</h4>
    <ul>
    <li>The <strong>CPU</strong> and <strong>memory</strong> resource usage trend charts are displayed only when no search criteria are specified. </li>
    <li>If the cluster version is OceanBase Database V4.0 or later, the resource usage trend chart of <strong>partition replicas</strong> is not displayed. </li>
    <li>If the cluster version is OceanBase Database V4.0 or later, the resource usage trend chart of the <strong>log disk</strong> is not displayed. </li>
    </ul>
    </main>

## Generate rankings

You can sort databases and table groups by **<UI-TERM key="ocp-v2.Detail.Resource.Trend.Data">Data Amount</UI-TERM>** or **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.UsedDisk">Disk Usage</UI-TERM>**. Click **<UI-TERM key="ocp-v2.Detail.Backup.Details">Details</UI-TERM>** or a database name to view the table data distribution details.
