Modify a parameter
=======================================

You can modify the tenant parameter values as needed. All changes to the parameter values take effect in real time.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** or **Tenant Maintenance** permission
* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.page.Iframe.ParameterManagement">Parameter Management</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Detail.Resource.Unit.Tenant">Tenants</UI-TERM>**

Procedure
------------------------------

1. Log on to OCP. By default, the **<UI-TERM key="ocp-v2.Detail.Overview.ClusterOverview">Cluster Overview</UI-TERM>** page appears.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Compaction.DetailV4.CompactionTenantListMyDrawer.Tenant">Tenants</UI-TERM>** .

3. In the **<UI-TERM key="ocp-v2.page.Tenant.Tenant">Tenants</UI-TERM>** section of the **<UI-TERM key="ocp-v2.Detail.Component.AddDatabaseDrawer.TenantOverview">Tenant Overview</UI-TERM>** page, click the name of the tenant that you want to manage.

4. In the left-side navigation pane of the page that appears, click **<UI-TERM key="ocp-v2.src.util.menu.ParameterManagement">Parameter Management</UI-TERM>** .

5. Optional. In the upper-right corner of the **<UI-TERM key="ocp-v2.page.MultiAzone.ParameterList">Parameters</UI-TERM>** page, enter a keyword in the search box to search for parameters whose names meet specified conditions.

6. Find the parameter you want to modify and click the **<UI-TERM key="ocp-v2.Detail.Parameter.List.ModifyTheValue">Change Value</UI-TERM>**.

   ![10291129](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E5%8F%82%E6%95%B0%E5%88%97%E8%A1%A84.png)

7. In the dialog box that appears, modify the parameter value.

   ![10291130](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E4%BF%AE%E6%94%B9%E5%8F%82%E6%95%B02.png)

8. Click **<UI-TERM key="ocp-v2.component.Compaction.DumpPolicyDrawer.Ok">OK</UI-TERM>** .
