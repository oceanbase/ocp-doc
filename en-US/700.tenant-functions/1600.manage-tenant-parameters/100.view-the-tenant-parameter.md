# View the parameters

You can view the name, category, value type, value range, default value, current value, and description of each parameter of the current tenant. You can also view whether the parameter takes effect after the OBServer is restarted. The search box above the list supports fuzzy search by parameter name.

## Prerequisites

* Make sure that you have the following permissions:
  * **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.page.Iframe.ParameterManagement">Parameter Management</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Compaction.DetailV4.CompactionTenantListMyDrawer.Tenant">Tenants</UI-TERM>**
* The password of the root user of the tenant stored in the password box is correct and the tenant whitelist is configured correctly.

## Procedure

1. Log on to OCP.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Tenant.Tenant">Tenants</UI-TERM>** . In the Tenants, click the name of the tenant that you want to view.

3. In the left-side navigation pane of the page that appears, click **<UI-TERM key="ocp-v2.src.util.menu.ParameterManagement">Parameter Management</UI-TERM>** .

4. On the **<UI-TERM key="ocp-v2.component.OperationConfig.Parameter.ParameterList">Parameters</UI-TERM>** tab, you can view the information of all parameters in the cluster.

   * The information including parameter name, value type, value range, default value, current value, description, and read-only.
   * **<UI-TERM key="ocp-v2.Detail.Parameter.List.DefaultValue">Default Value</UI-TERM>** indicates the default value for new tenants. Read-only indicates whether the parameter can be modified. If it is a modifiable parameter, a button to modify the value will be displayed in the **<UI-TERM key="ocp-v2.Backup.Restore.RestoreTask.Operation">Actions</UI-TERM>** column.
   * Click **<UI-TERM key="ocp-v2.Detail.Parameter.List.ViewOnlyModifiedParameters">View Only Modified Parameters</UI-TERM>**, you can view the list of modified parameters in OCP.
