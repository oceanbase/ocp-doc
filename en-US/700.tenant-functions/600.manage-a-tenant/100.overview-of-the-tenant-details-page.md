# View the details of a tenant

On the details page of a tenant, you can delete the tenant, add a replica, change the password, lock the tenant, and copy the tenant. You can also view the basic information of the tenant, view replica details, and modify zone priorities and the allowlist.

OceanBase Cloud Platform (OCP) allows you to create associated primary and standby tenants in different clusters. Take note of the following considerations on the primary and standby tenants:

* If you modify the tenant configurations, the modification may affect the synchronization efficiency between the primary and standby tenants and the tenant performance. In this case, we recommend that you configure the same settings for the primary and standby tenants.
* If <b>network-based</b> synchronization is used between the primary and standby tenants and archiving is disabled for the primary tenant, REDO logs of the primary tenant may be overwritten before being synchronized to the standby tenant. In this case, we recommend that you enable log archiving for the primary tenant.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
* **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Compaction.DetailV4.CompactionTenantListMyDrawer.Tenant">Tenants</UI-TERM>**

## View basic information

You can view basic tenant information in the following fields: **<UI-TERM key="ocp-v2.Resource.Component.UnitMigrateModal.TenantName">Tenant Name</UI-TERM>**, **<UI-TERM key="ocp-performance-report.ReportTables.BasicInfo.ReplicaSizeInfoTable.TenantId">Tenant ID</UI-TERM>**, **<UI-TERM key="ocp-v2.Detail.Overview.Cluster.1">Cluster</UI-TERM>**, **OceanBase version number**, **<UI-TERM key="ocp-v2.Tenant.New.TenantMode">Tenant Mode</UI-TERM>**, **<UI-TERM key="ocp-v2.Detail.Component.AddDatabaseModal.CharacterSet">Character Set</UI-TERM>**, **Collation**, **<UI-TERM key="ocp-v2.Cluster.New.LoadType">Load Type</UI-TERM>**, **<UI-TERM key="ocp-v2.component.TenantList.DeploymentDistribution">Locality</UI-TERM>**, **<UI-TERM key="ocp-v2.Detail.Component.OBProxyAndConnectionStringModal.ObproxyConnectionString">OBProxy/Connection String</UI-TERM>**, **<UI-TERM key="ocp-v2.page.Binlog.BinlogService">Binlog Service</UI-TERM>**, **<UI-TERM key="ocp-v2.page.Host.Label">Tag</UI-TERM>**, **<UI-TERM key="ocp-v2.component.TenantList.Locking">Lock</UI-TERM>**, **<UI-TERM key="ocp-v2.Tenant.Detail.CreationTime">Created At</UI-TERM>**, **<UI-TERM key="ocp-v2.Component.ShowLimitsModal.Limits">Limitations</UI-TERM>**, **<UI-TERM key="ocp-v2.Arbitration.ArbitrationGroup.CreateArbitrationGroup.Remarks">Remarks</UI-TERM>**, and **<UI-TERM key="ocp-v2.page.Cluster.ArbitrationService">Arbitration Service</UI-TERM>**.

* You can click the name of the cluster to go to its details page. For more information, see [View the details of a cluster](../../600.cluster-functions/300.manage-a-cluster/200.overview-of-the-cluster-details-page.md).

* You can click the **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetail.Copy">Copy</UI-TERM>** icon next to the name of a tenant to copy its name.

* You can **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.View">View</UI-TERM>** next to **<UI-TERM key="ocp-v2.Detail.Component.OBProxyAndConnectionStringModal.ObproxyConnectionString">OBProxy/Connection String</UI-TERM>**, and copy the connection string in the dialog box that appears.

  * **<UI-TERM key="ocp-v2.Detail.Overview.ConnectionString">Connection String</UI-TERM>**: The connection string can be obtained when the cluster of the tenant is associated with the OBProxy.

  * You can associate the cluster with the OBProxy through direct connection. Here is an example:

    ```sql
    obclient -Pxxx.xxx.xxx.xxx0 -u<Username>@<Tenant name#Cluster name> -P2883 -p****** -c -A sys
    ```

* You can click **<UI-TERM key="ocp-v2.Component.ServiceName.AddServiceName">Add Service Name</UI-TERM>** to add a service name. The service name must start with a letter and can contain letters, digits, and underscores (_). It must be 2 to 64 characters in length. You can also edit or delete the added service name in the **<UI-TERM key="ocp-v2.component.ParameterTemplate.SetParameterEditableProTable.Operation">Actions</UI-TERM>** drop-down list. You can select the **<UI-TERM key="ocp-v2.Component.ServiceName.ServiceNameModal.ChangeTheServiceNameOfTheActiveAnd">Sync Service Names of Primary and Standby Tenants</UI-TERM>** option for the primary and standby tenants.

  <main id="notice" type='explain'>
  <h4>Note</h4>
  <p>
  <ul>
  <li>You can configure a service name for a tenant only when the following version requirements are met:<ul><li>OceanBase Database: V4.2.1.9, [V4.2.4.0, V4.3.0.0), or [V4.3.3.0, +∞) </li><li>OBProxy: [V4.3.1.0, +∞) </li></ul></li>
  
  <li>We recommend that you set the same service name for the primary and standby tenants, and that the clusters to which the primary and standby tenants belong be associated with the same OBProxy cluster. This way, your application can implement automatic routing after a switchover. </li>
  <li>For more information, see <a href="800.manage-service-name.md">Manage service names</a>. </li>
  </ul>
  </p></main>

* You can enable the binlog service for a tenant. For more information, see [Manage the binlog service for a tenant](700.manage-binlog-service-of-a-tenant.md).

* You can hover the pointer over the **<UI-TERM key="ocp-v2.Cluster.Arbitration.Label">Tag</UI-TERM>** field to view all tags of the tenant. You can click the **<UI-TERM key="ocp-v2.Auth.User.Detail.Editing">Edit</UI-TERM>** icon to manage the tags. For more information, see [Manage tags](../../1600.system-management-features/300.manage-tags/100.tags-overview.md).

* You can click **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.View">View</UI-TERM>** next to **<UI-TERM key="ocp-v2.Detail.Overview.Limits">Limitations</UI-TERM>** to view the resource usage limits for the tenant under the current resource specifications. When the resource usage approaches the threshold, upgrade the resource specifications for the tenant to avoid database exceptions.

  <main id="notice" type='explain'>
  <h4>Note</h4>
  <p>You can view the resource usage limitations for a tenant only if the cluster to which the tenant belongs meets the following version requirements:<ul><li>OceanBase Database V4.2.x: V4.2.4 or later</li><li>OceanBase Database V4.3.x: V4.3.1 or later</li></ul>
  </p></main>

* You can click the icon next to **<UI-TERM key="ocp-v2.Component.LBLoadBalanceConditon.Remarks">Remarks</UI-TERM>** to modify the description.

* You can click the icon next to **<UI-TERM key="ocp-v2.component.HostSelect.ArbitrationService">Arbitration Service</UI-TERM>** to enable or disable the arbitration service.

* You can perform other management operations on the tenant. For more information, see [Delete a tenant](400.delete-a-tenant.md), [Add a replica](../1000.manage-tenant-replica/200.create-a-replica.md), [Change the password of the sys tenant](500.change-the-sysy-tenant-password.md), [Rename a tenant](250.rename-a-tenant.md), [Lock a tenant](300.locked-a-tenant.md), [Copy a tenant](200.replication-a-tenant.md), [Clone a tenant](350.clone-a-tenant.md), and [Configure full-link tracking for a tenant](600.full-link-diagnostic-configuration-of-tenant.md).

## View replica details

You can view the zone names, replica types, unit specifications, and number of units, and modify or delete a replica. For more information, see [Edit a tenant replica in a zone](../1000.manage-tenant-replica/300.edit-a-replica-of-a-tenant-in-a-private-zone.md) and [Delete a tenant replica from a zone](../1000.manage-tenant-replica/400.delete-a-replica-of-a-tenant-in-a-private-zone.md).

<h4>Note</h4>
<p><li>If the cluster version is earlier than OceanBase Database V4.0, the log disk space and IOPS information is not displayed in the <b>Unit Specification</b> column. </li><li>If the cluster version is OceanBase Database V4.0 or later and you do not specify the log disk space and IOPS information when you <a href="../1630.manage-unit-specification.md">add unit specifications</a>, the log disk space and IOPS information is not displayed in the <b>Unit Specification</b> column. </li></p>
</main>
