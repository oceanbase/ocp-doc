# Change the password of the sys tenant

This topic describes how to change the password of the sys tenant.

## Precautions

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** or **Tenant Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">Overview</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.constant.auditEvent.Tenant">Tenants</UI-TERM>**

* You can change the password of the sys tenant only from the primary tenant.

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Detail.Component.DeleteTenantModal.Tenant">Tenants</UI-TERM>** to go to the **<UI-TERM key="ocp-v2.Tenant.New.Tenant">Tenants</UI-TERM>** page.

3. In the **<UI-TERM key="ocp-v2.Detail.Component.DeleteTenantModal.Tenant">Tenants</UI-TERM>** list, find the target tenant and click its name to go to its details page.

4. Click **<UI-TERM key="ocp-v2.Cluster.Detail.ChangePassword">Change Password</UI-TERM>** in the upper-right corner.

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/420-en/%E4%BF%AE%E6%94%B9sys%E7%A7%9F%E6%88%B7%E5%AF%86%E7%A0%81.png)

5. In the dialog box that appears, enter a new password and confirm it.

   The password must be 8 to 32 characters in length and can contain letters, digits, and special characters. It must contains at least three of the following character types: digits(0\~9), uppercase letters(A\~Z), lowercase letters(a\~z), and special characters (ie: <code>~!@#%^&*_-+=\|(){}[]:;,.?/</code>).

   ![1122](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/420-en/%E4%BF%AE%E6%94%B9%E5%AF%86%E7%A0%81%E5%AF%B9%E8%AF%9D%E6%A1%86.png)

6. Click **<UI-TERM key="ocp-v2.page.Information.Ok">OK</UI-TERM>**.
