# Manage the binlog service for a tenant

The binlog service collects transaction logs of OceanBase Database and converts them into MySQL binlogs. You can enable or disable the binlog service, modify binlog service configurations, and delete the binlog service for a tenant.

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OceanBase Cloud Platform (OCP) Enterprise Edition. OCP Community Edition does not support this feature. </p>
</main>

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** or **Tenant Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.constant.auditEvent.Tenant">Tenants</UI-TERM>**

* The tenant for which the binlog service is to be enabled is in the **<UI-TERM key="ocp-v2.src.constant.backup.NormalOperation">Running</UI-TERM>** state.
* The version of the cluster to which the tenant belongs is V3.2.4.4 or later, or V4.1.0.2 or later.

## Enable the binlog service

1. Log on to the OCP console.

2. In the left-side navigation pane, select **<UI-TERM key="ocp-v2.Tenant.New.Tenant">Tenants</UI-TERM>**. The **<UI-TERM key="ocp-v2.Tenant.New.Tenant">Tenants</UI-TERM>** tab automatically appears.

3. On the **<UI-TERM key="ocp-v2.Compaction.DetailV4.CompactionTenantListMyDrawer.Tenant">Tenants</UI-TERM>** tab, find the target tenant and click its name to go to the **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** page of the tenant.

4. In the **<UI-TERM key="ocp-v2.Alarm.Template.Detail.BasicInformation">Basic Information</UI-TERM>** section, click **<UI-TERM key="ocp-v2.Component.BinlogService.Activate">Activate</UI-TERM>** next to **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogService">Binlog Service</UI-TERM>**.

5. In the dialog box that appears, specify the following parameters.

    | Parameter | Description |
    |------|-------|
    | Associate Binlog Cluster | Select a binlog cluster to be associated with the tenant. You can select only a running binlog cluster.  |
    | Associate OBProxy Cluster | Select an OBProxy cluster that has been associated with the tenant. The version of OBProxy must be V4.2.1.0 or later.  |
    | Retention Duration (Hour) | The retention period of binlogs of the tenant. Expired log files will be automatically deleted. The value is an integer ranging from 1 to 8760. |
    | Maximum Disk Space (GiB) | The maximum size of disk space for binlogs of the tenant. Log files generated after the specified value is reached will be automatically deleted. The value is an integer ranging from 1 to 102400. |

## Other operations

After you enable the binlog service for a tenant, you can perform other operations on the binlog service as needed. For example, you can modify binlog service configurations, view binlog instances, and disable the binlog service.

* Choose **<UI-TERM key="ocp-v2.page.OBProxy.Operation">Actions</UI-TERM>** > **<UI-TERM key="ocp-v2.Component.BinlogService.BinlogServiceConfigModal.ModifyBinlogConfiguration">Modify Binlog Configuration</UI-TERM>** next to **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogService">Binlog Service</UI-TERM>**. You can modify the **Associate OBProxy Cluster**, **<UI-TERM key="ocp-v2.Component.BinlogService.BinlogServiceConfigModal.RetentionDurationHours">Retention Duration (Hour)</UI-TERM>**, and **Maximum Disk Space (GB)** parameters.
* Choose **<UI-TERM key="ocp-v2.Backup.Backup.Log.Operation">Actions</UI-TERM>** > **<UI-TERM key="ocp-v2.Component.BinlogService.ViewBinlogInstances">View Binlog Instances</UI-TERM>** next to **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogService">Binlog Service</UI-TERM>**. On the **<UI-TERM key="ocp-v2.Instance.Overview.BinlogInstanceOverview">Binlog Instance Overview</UI-TERM>** page, you can view details about binlog instances. For more information, see [View a binlog instance](../../820.binlog-service-fuctions/300.manage-a-binlog-cluster/500.manage-binlog-instance/100.binlog-instance-overview.md).
* You can choose **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.Operation">Actions</UI-TERM>** > **<UI-TERM key="ocp-v2.Component.BinlogService.DisableBinlogService">Disable Binlog Service</UI-TERM>** next to **<UI-TERM key="ocp-v2.Detail.Overview.BinlogService">Binlog Service</UI-TERM>** to disable the binlog service. After the binlog service is disabled, all generated binlog files are deleted to release the storage space.
