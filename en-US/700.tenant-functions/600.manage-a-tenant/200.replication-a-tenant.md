# Copy a tenant

This topic describes how to copy a tenant. You can copy the configurations, such as the mode, character set, collation, and unit specifications, of the selected tenant to reduce the time required for creating a new tenant.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** permission
* **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.constant.auditEvent.Tenant">Tenants</UI-TERM>**

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, select **<UI-TERM key="ocp-v2.Resource.Component.Block.Tenant">Tenants</UI-TERM>**. The **<UI-TERM key="ocp-v2.Tenant.New.Tenant">Tenants</UI-TERM>** page automatically appears.

3. On the **<UI-TERM key="ocp-v2.src.util.menu.Tenant">Tenants</UI-TERM>** page, find the target tenant and click **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.Copy">Copy</UI-TERM>** in the **<UI-TERM key="ocp-v2.component.ParameterTemplate.SetParameterEditableProTable.Operation">Actions</UI-TERM>** column.

4. Specify the information on the **<UI-TERM key="ocp-v2.Tenant.New.CopyTenant">Copy Tenant</UI-TERM>** page. For more information, see [Create a tenant](../../500.quickstart/600.quickstart-create-a-tenant.md).

5. Click **<UI-TERM key="ocp-v2.component.Compaction.MergePolicyDrawer.Submit">Submit</UI-TERM>**.
