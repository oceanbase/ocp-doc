# Modify zone priorities

This topic describes how to modify zone priorities.

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** or **Tenant Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.constant.auditEvent.Tenant">Tenants</UI-TERM>**

* In a **standalone centralized** database, you cannot modify the priority of a zone for a tenant.

## Procedure

1. Log in to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, select **<UI-TERM key="ocp-v2.src.constant.auditEvent.Tenant">Tenants</UI-TERM>**. The **<UI-TERM key="ocp-v2.src.constant.auditEvent.Tenant">Tenants</UI-TERM>** page automatically appears.

3. On the **<UI-TERM key="ocp-v2.src.util.menu.Tenant">Tenants</UI-TERM>** page, find the target tenant and click its name to go to the **<UI-TERM key="ocp-v2.page.Overview.Overview">Overview</UI-TERM>** page of the tenant.

4. In the **<UI-TERM key="ocp-v2.Detail.Component.AddDatabaseModal.ZonePriority">Primary Zone</UI-TERM>** section, click **<UI-TERM key="ocp-v2.Compaction.SettingsV4.Modify">Modify</UI-TERM>**.

5. In the dialog box that appears on the right, modify the zone priorities.

    <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>If the OceanBase Database version of the cluster is V4.2.0 or later and the <code>enable_rebalace</code> parameter is set to <code>false</code>, you cannot perform the following operations:<ul><li>Adjust the number of zones with the highest priority specified in <code>primary_zone</code>. </li><li>Adjust the number of full-featured replicas when <code>primary_zone</code> is set to <code>RANDOM</code>. </li></ul></p>
    </main>

6. Click **<UI-TERM key="ocp-v2.Component.ClusterFilter.Ok">OK</UI-TERM>**.
