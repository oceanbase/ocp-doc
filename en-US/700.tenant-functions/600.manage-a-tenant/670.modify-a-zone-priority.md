# Modify the zone priority

This topic describes how to modify the zone priority.

## Prerequisites

* The current login user in the OCP console has the following permissions:

  * **Cluster Maintenance** or **Tenant Maintenance** permissions.
  * **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** permissions in the tenant menu.

* The database to which the tenant belongs is a standalone database.

* If the tenant is a user tenant, and the cluster version is V4.2.0 or later, and the tenant parameter <code>enable_rebalace</code> is <code>false</code>, you cannot perform the following operations:

  * Adjust the number of primary zones.
  * If the primary zone is set to RANDOM, adjust the number of F replicas.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, select **<UI-TERM key="ocp-v2.page.Information.Tenant">Tenant</UI-TERM>**. The **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">Tenants</UI-TERM>** page automatically appears.

3. On the **<UI-TERM key="ocp-v2.component.TenantList.TenantList">Tenants</UI-TERM>** page, find the target tenant and click its name to go to the **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">Overview</UI-TERM>** page.

4. In the **<UI-TERM key="ocp-v2.Cluster.New.ZonePriority">Primary Zone</UI-TERM>** section, click **<UI-TERM key="ocp-v2.TrendAndOutline.SQLLimit.Modify">Modify</UI-TERM>**.

5. In the dialog box that appears on the right, modify the zone priority. You can select one or more zones from the left-side list and add them to the right-side list. The left-side list displays all zones in the current cluster.

   The zones are sorted based on the following rules:

   * The zones selected first have a higher priority than those selected later.
   * If you select multiple zones at the same time, the priority of the selected zones is the same.
   * In the right-side list, the zones at the top have a higher priority than those at the bottom. You can drag the zones to adjust the order.

6. Click **<UI-TERM key="ocp-v2.component.Compaction.MergePolicyDrawer.Ok">OK</UI-TERM>**.
