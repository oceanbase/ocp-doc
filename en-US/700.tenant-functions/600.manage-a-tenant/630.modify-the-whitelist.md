# Modify the allowlist of a tenant

This topic describes how to modify the allowlist of a tenant.

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** or **Tenant Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">Overview</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Detail.Component.DeleteTenantModal.Tenant">Tenants</UI-TERM>**

* You can modify the allowlist of a tenant only from the primary tenant.

## Procedure

1. Log in to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, select **<UI-TERM key="ocp-v2.Resource.Component.Block.Tenant">Tenants</UI-TERM>**. The **<UI-TERM key="ocp-v2.src.constant.auditEvent.Tenant">Tenants</UI-TERM>** page automatically appears.

3. On the **<UI-TERM key="ocp-v2.page.Tenant.Tenant">Tenants</UI-TERM>** page, find the target tenant and click its name to go to the **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">Overview</UI-TERM>** page of the tenant.

4. In the **<UI-TERM key="ocp-v2.Tenant.Detail.Whitelist">Whitelist</UI-TERM>** section, click **<UI-TERM key="ocp-v2.ResourceManager.ResourceGroupTab.Modify">Modify</UI-TERM>** in the **<UI-TERM key="ocp-v2.Detail.Component.LinkList.Operation">Actions</UI-TERM>** column.

5. Configure the allowlist in the dialog box that appears.

   * **Access from all IP addresses is supported**: This tenant can be accessed by any IP address.

   * **<UI-TERM key="ocp-v2.component.WhitelistInput.Custom">Custom</UI-TERM>**: You can add allowed clients into the allowlist in the formats described in the following table. Here is an example:

     |   Format   |     Example     |
     |--------------|--------------|
     | IP address          | xxx.xxx.xxx.1,xxx.xxx.xxx.2    |
     | CIDR block      | xxx.xxx.xxx.1-3  <main id="notice" type='explain'><h4>Note</h4><p><ul><li>The value <code>xxx.xxx.xxx.1-3</code> indicates that the following IP addresses are added: <code>xxx.xxx.xxx.1</code>, <code>xxx.xxx.xxx.2</code>, and <code>xxx.xxx.xxx.3</code>. </li><li>You can add only IPv4 addresses. </li></ul></p></main> |
     | Subnet/Mask  | xxx.xxx.xxx.1/24     |
     | Fuzzy match   | xxx.xxx.xxx.% or xxx.xxx.xxx._   |
     | Mixed | xxx.xxx.xxx.1,xxx.xxx.xxx.2,xxx.xxx.xxx.%,xxx.xxx.xxx._,xxx.xxx.xxx.1/24 |
     | Note   | % indicates that the tenant can be accessed from any client.      |

6. Click **<UI-TERM key="ocp-v2.Statistics.components.EditAutoBasicInfoDrawer.Ok">OK</UI-TERM>**.
