# View tenant topology

OCP provides a new topology feature that allows you to view the replica distribution of a tenant within a cluster.

## Prerequisites

* When you view information about clusters, arbitration services, zones, and servers in the topology graph, make sure that the user who is logged in to OCP has the following permissions:

  * **Cluster Read-Only** or **Tenant Read-Only** resource permissions.
  * The **<UI-TERM key="ocp-v2.src.util.menu.TopologicalGraph">Topology</UI-TERM>** menu permission for the tenant.

* When you perform maintenance operations such as modifying the tenant zone priority, modifying the replica type, modifying the resource pool, deleting a replica, and adding a replica, make sure that the user who is logged in to OCP has the following permissions:

  * **Cluster Maintenance** or **Tenant Maintenance** resource permissions.
  * The **<UI-TERM key="ocp-v2.src.util.menu.TopologicalGraph">Topology</UI-TERM>** menu permission for the tenant.

* Single-node tenants do not display information about their arbitration services and do not support the following operations in the topology graph:

  * Modifying the tenant zone priority
  * Modifying the replica type
  * Modifying the resource pool
  * Deleting a replica
  * Adding a replica

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click a tenant and select the tenant from the **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">Tenants</UI-TERM>** list on the page that appears. The **<UI-TERM key="ocp-v2.page.Overview.Overview">Overview</UI-TERM>** page of the tenant is displayed by default.

3. In the left-side navigation pane, click the topology diagram to go to the **<UI-TERM key="ocp-v2.page.Iframe.TenantTopology">Tenant Topology</UI-TERM>** page, where you can view the topology diagram of the current tenant.

   In the upper-right corner of the page, you can adjust the size of the topology diagram and refresh the topology diagram.

   The topology diagram consists of four layers:

   * Layer 1: clusters

   * Layer 2: tenant arbitration services

   * Layer 3: zones

   * Layer 4: servers

   <main id="notice" type='explain'>
   <h4>Note</h4>
   <p>The <b>tenant arbitration service</b> layer is displayed only when the tenant has an arbitration service enabled. </p>
   </main>

### Cluster

The cluster icon displays the name of the cluster to which the tenant belongs and the current status of the cluster.

Click the operation button on the right side of the icon to open the operation list.

* Click **<UI-TERM key="ocp-v2.Topo.TopoGraph.ViewTheCluster">View Cluster</UI-TERM>** to open the cluster topology on a new page.

* Click **Modify Tenant Zone Priority** to change the zone priority in a dialog box.

### Tenant arbitration service

The tenant arbitration service icon displays the address of the tenant arbitration service and the service status.

Hovering the pointer over the tenant arbitration service icon displays the detailed address of the arbitration service and whether the tenant has enabled the arbitration service.

### Zone

The Zone icon displays the name and current status of the zone.

If the tenant has units distributed in the zone, the zone icon is displayed in purple and the tenant name on the right shows an abbreviation of the replica type. Otherwise, the zone icon is displayed in gray.

* Units are distributed in the zone.

  * When you hover the pointer over the zone icon, a tooltip appears, displaying the replica type and the number of units distributed in the zone.

  * Click the action button on the right of the zone icon to open the action list.

    * Click **<UI-TERM key="ocp-v2.Topo.TopoGraph.ModifyTheCopyType">Change Replica Type</UI-TERM>** to change the replica type.

      <main id="notice" type='explain'>
      <h4>Note</h4>
      <p><ul><li>If the current replica type is <b>Read-Only Columnar Replica</b>, you cannot change it to another replica type. </li><li>If the current replica type is <b>Omni-Replica</b> or <b>Read-Only Replica</b>, you cannot change it to <b>Read-Only Columnar Replica</b>. </li><li>For more information, see the description of replica types in the section about creating a tenant in the topic <a href="../300.create-a-tenant.md">Create a tenant</a>. </li></ul></p>
      </main>

    * Click **<UI-TERM key="ocp-v2.Detail.Component.ModifyResourcePoolModal.ModifyTheResourcePool">Modify Resource Pool</UI-TERM>** to modify the resource pool for the tenant in the zone.

      <main id="notice" type='explain'>
      <h4>Note</h4>
      <p>For more information, see the descriptions of unit specifications and the number of units in the section about creating a tenant in the topic <a href="../300.create-a-tenant.md">Create a tenant</a>. </p>
      </main>

    * Click **<UI-TERM key="ocp-v2.Topo.TopoGraph.DeleteACopy">Delete Replica</UI-TERM>** to delete the replica in the zone. Before you delete the replica, a prompt appears. Click **<UI-TERM key="ocp-v2.Detail.Overview.Delete">Delete</UI-TERM>** to delete the replica.

      <main id="notice" type='explain'>
      <h4>Note</h4>
      <p>Deleting the replica data cannot be recovered. Proceed with caution. </p>
      </main>

* No units are distributed in the zone.

  1. Click the action button on the right of the zone icon to open the action list.

  2. Click **<UI-TERM key="ocp-v2.Tenant.Detail.NewCopy">Create Replica</UI-TERM>** to add a replica. For more information about the parameters, see [Add a replica](../1000.manage-tenant-replica/200.create-a-replica.md).

### Server

The Server icon displays the IP address and port number of the server and the current status of the server.

If the tenant has units distributed on the server, the server icon is displayed in green. Otherwise, the server icon is displayed in gray.
