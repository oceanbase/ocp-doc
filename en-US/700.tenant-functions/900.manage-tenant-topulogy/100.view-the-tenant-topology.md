# View the topology of a tenant

OceanBase Cloud Platform (OCP) provides a topology diagram that allows you to view the distribution of tenant replicas in a cluster.

## Prerequisites

* To view information about clusters, arbitration services, zones, and OBServer nodes in the topology, make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.util.menu.TopologicalGraph">Topology</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Backup.Backup.Data.Tenant">Tenants</UI-TERM>**

* To modify the zone priorities, replica type, resource pool of a tenant, add a replica, or delete a replica, make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** or **Tenant Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.util.menu.TopologicalGraph">Topology</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Backup.Backup.Data.Tenant">Tenants</UI-TERM>**

## Procedure

1. Log in to the OCP console.

2. Click **<UI-TERM key="ocp-v2.Detail.Resource.Unit.Tenant">Tenants</UI-TERM>** in the left-side navigation pane. In the **<UI-TERM key="ocp-v2.Detail.Component.DeleteTenantModal.Tenant">Tenants</UI-TERM>** list, select the target tenant to go to its **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">Overview</UI-TERM>** page.

3. On the left side of the page, click the topology to go to the **<UI-TERM key="ocp-v2.page.Iframe.TenantTopology">Tenant Topology</UI-TERM>** tab.

   You can click the icons in the upper-right corner of the canvas to resize and refresh the topology.

   The topology consists of four layers:

   * The first layer indicates the cluster.

   * The second layer indicates the tenant arbitration service.

   * The third layer indicates the zones.

   * The fourth layer indicates the OBServer nodes.

   <main id="notice" type='explain'>
   <h4>Note</h4>
   <p>The tenant arbitration service layer is displayed only when the arbitration service is enabled for the tenant. </p>
   </main>

### Cluster

The cluster icon displays the name and status of the cluster to which the tenant belongs.

Click the **<UI-TERM key="ocp-v2.Component.AddBackupStrategy.ViewMore">More</UI-TERM>** icon on the right of the cluster icon to view supported operations.

* Click **<UI-TERM key="ocp-v2.Topo.TopoGraph.ViewTheCluster">View Cluster</UI-TERM>** to display the cluster topology on a new page.

* Click **Modify Zone Priority of Tenant** to modify the zone priorities in the dialog box that appears.

![09162028](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/420-en/%E6%9F%A5%E7%9C%8B%E9%9B%86%E7%BE%A4.png)

### Tenant arbitration service

The endpoint and status of the tenant arbitration service are displayed next to the cluster arbitration service icon.

Hover the pointer over the tenant arbitration service icon to view the detailed endpoint of the service and whether the service is enabled for the tenant.

### Zone

The name and status of the zone are displayed next to the zone icon.

If a zone contains a tenant replica, the zone icon is displayed in purple with the initial of the replica type next to the tenant name. Otherwise, the zone icon is in gray.

* Zones with replicas

  * When you hover the pointer over a zone icon, a tooltip appears and displays the type of the replica and the number of units in the zone.

    ![09162029](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/420-en/zone%E5%89%AF%E6%9C%AC%E7%B1%BB%E5%9E%8B.png)
  
  * Click the **<UI-TERM key="ocp-v2.Cluster.Component.MachineResource.SeeMore">More</UI-TERM>** icon on the right of the zone icon to view supported operations.

    ![09162029](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/420-en/zone%E6%93%8D%E4%BD%9C%E5%88%97%E8%A1%A8.png)
  
    * Click **<UI-TERM key="ocp-v2.Topo.TopoGraph.ModifyTheCopyType">Change Replica Type</UI-TERM>** and change the replica type in the dialog box that appears.

      <main id="notice" type='explain'>
      <h4>Note</h4>
      <p><ul><li>You cannot change the <b>Read-only Columnstore Replica</b> type to other types. </li><li>You cannot change the <b>Full-featured Replica</b> or <b>Read-only Replica</b> type to the <b>Read-only Columnstore Replica</b> type. </li><li>For more information about replica types, see <a href="../300.create-a-tenant.md">Create a tenant</a>. </li></ul></p>
      </main>

    * Click **<UI-TERM key="ocp-v2.Topo.TopoGraph.ModifyTheResourcePool">Modify Resource Pool</UI-TERM>** and modify the resource pool of the zone in the dialog box that appears.
  
      <main id="notice" type='explain'>
      <h4>Note</h4>
      <p>For more information about the unit specifications and number of units, see <a href="../300.create-a-tenant.md">Create a tenant</a>. </p>
      </main>
  
      ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/420-en/%E4%BF%AE%E6%94%B9%E8%B5%84%E6%BA%90%E6%B1%A0.png)

    * Click **<UI-TERM key="ocp-v2.Topo.TopoGraph.DeleteACopy">Delete Replica</UI-TERM>**. In the dialog box that appears, click **<UI-TERM key="ocp-v2.Component.ServiceName.Delete">Delete</UI-TERM>** to delete the replica.

      <main id="notice" type='explain'>
      <h4>Note</h4>
      <p>The data of a deleted replica cannot be restored. Proceed with caution. </p>
      </main>
  
      ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/420-en/%E5%88%A0%E9%99%A4%E5%89%AF%E6%9C%AC.png)

* Zones without a replica

  1. Click the **<UI-TERM key="ocp-v2.Component.AddBackupStrategy.ViewMore">More</UI-TERM>** icon on the right of the zone icon to view supported operations.

  2. Click **<UI-TERM key="ocp-v2.Topo.TopoGraph.NewCopy">Create Replica</UI-TERM>** and add a new replica in the dialog box that appears. For more information about the parameters, see [Add a replica](../1000.manage-tenant-replica/200.create-a-replica.md).

### OBServer node

The IP address and current status of an OBServer node are displayed next to the node icon.

If an OBServer node hosts a resource unit of the tenant, the node icon is displayed in green. Otherwise, the node icon is in gray.
