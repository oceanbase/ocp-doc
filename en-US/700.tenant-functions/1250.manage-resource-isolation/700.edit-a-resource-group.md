# Modify a resource group

If the resource configurations in a resource group are no longer applicable, you can modify the resource group.

## Prerequisites

* Make sure that you have the following permissions:
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** or **Tenant Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.hook.useMenu.ResourceIsolation">Resource Isolation</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Detail.Component.DeleteTenantModal.Tenant">Tenants</UI-TERM>**
* Resource isolation depends on the cgroup configuration. Make sure that you have enabled the cgroup feature for the cluster to which the target tenant belongs.
* You have created a resource group for the tenant.

## Procedure

1. Log in to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, select **<UI-TERM key="ocp-v2.page.Tenant.Tenant">Tenants</UI-TERM>**. The **<UI-TERM key="ocp-v2.Detail.Component.DeleteTenantModal.Tenant">Tenants</UI-TERM>** page automatically appears.

3. On the **<UI-TERM key="ocp-v2.src.constant.auditEvent.Tenant">Tenants</UI-TERM>** page, find the target tenant and click its name to go to the **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** page of the tenant.

4. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Detail.ResourceManager.CreateResourcePlan.ResourceIsolation">Resource Isolation</UI-TERM>** to go to the isolation plan page of the tenant.

5. Click the **<UI-TERM key="ocp-v2.Detail.ResourceManager.ResourceGroup">Resource Group</UI-TERM>** tab.

6. Select the target resource group and click **<UI-TERM key="ocp-v2.TrendAndOutline.SQLLimit.Modify">Modify</UI-TERM>** in the **<UI-TERM key="ocp-v2.Statistics.components.StatTable.Operation">Actions</UI-TERM>** column.

    You can modify the **resource isolation type** and resource isolation content of the resource group. For more information, see [Create a resource group](200.create-a-resource-group.md).

7. Click **<UI-TERM key="ocp-v2.Alarm.Subscriptions.New.Submit">Submit</UI-TERM>**.
