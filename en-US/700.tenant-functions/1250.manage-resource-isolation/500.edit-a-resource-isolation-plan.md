# Modify a resource isolation plan

This topic describes how to modify a resource isolation plan.

## Prerequisites

* Make sure that you have the following permissions:
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** or **Tenant Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.hook.useMenu.ResourceIsolation">Resource Isolation</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Detail.Resource.Unit.Tenant">Tenants</UI-TERM>**
* Resource isolation depends on the cgroup configuration. Make sure that you have enabled the cgroup feature for the cluster to which the target tenant belongs.
* You have created a resource isolation plan.

## Procedure

1. Log in to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, select **<UI-TERM key="ocp-v2.Resource.Component.Block.Tenant">Tenants</UI-TERM>**. The **<UI-TERM key="ocp-v2.Resource.Component.Block.Tenant">Tenants</UI-TERM>** page automatically appears.

3. On the **<UI-TERM key="ocp-v2.Tenant.New.Tenant">Tenants</UI-TERM>** page, find the target tenant and click its name to go to the **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** page of the tenant.

4. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Detail.ResourceManager.ResourceIsolation">Resource Isolation</UI-TERM>** to go to the isolation plan page of the tenant.

5. Select the target resource isolation plan and click **<UI-TERM key="ocp-v2.Detail.LoadBalance.Edit">Edit</UI-TERM>** in the upper-right corner.

    You can modify the **resource groups** and **resource isolation restrictions** of the plan. For more information, see [Create a resource isolation plan](300.create-a-resource-isolation-plan.md).

6. Click **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.FieldListDrawer.Determine">OK</UI-TERM>**.
