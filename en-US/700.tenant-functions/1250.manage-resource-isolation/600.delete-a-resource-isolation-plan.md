# Delete a resource isolation plan

This topic describes how to delete a resource isolation plan.

## Prerequisites

* Make sure that you have the following permissions:
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** or **Tenant Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.ResourceManager.ResourceIsolation">Resource Isolation</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.util.menu.Tenant">Tenants</UI-TERM>**
* Resource isolation depends on the cgroup configuration. Make sure that you have enabled the cgroup feature for the cluster to which the target tenant belongs.
* You have created a resource isolation plan.
*The resource isolation plan to be deleted is disabled.

## Procedure

1. Log in to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, select **<UI-TERM key="ocp-v2.Compaction.DetailV4.CompactionTenantListMyDrawer.Tenant">Tenants</UI-TERM>**. The **<UI-TERM key="ocp-v2.Compaction.DetailV4.CompactionTenantListMyDrawer.Tenant">Tenants</UI-TERM>** page automatically appears.

3. On the **<UI-TERM key="ocp-v2.Detail.Resource.Unit.Tenant">Tenants</UI-TERM>** page, find the target tenant and click its name to go to the **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** page of the tenant.

4. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Detail.ResourceManager.CreateResourcePlan.ResourceIsolation">Resource Isolation</UI-TERM>** to go to the isolation plan page of the tenant.

5. Select the target resource isolation plan and click **<UI-TERM key="ocp-v2.Host.Detail.Delete">Delete</UI-TERM>** in the upper-right corner.

    <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>After you delete a resource isolation plan, the resource isolation restrictions are deleted together with the plan. However, the resource name and rules are retained. </p>
    </main>

6. In the dialog box that appears, click **<UI-TERM key="ocp-v2.Detail.Component.DailyChangeTenantModal.Ok">OK</UI-TERM>**.
