# Delete a resource group

If you no longer need a resource group for resource isolation, you can delete the resource group.

## Prerequisites

* Make sure that you have the following permissions:
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** or **Tenant Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.ResourceManager.ResourceIsolation">Resource Isolation</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.constant.auditEvent.Tenant">Tenants</UI-TERM>**
* Resource isolation depends on the cgroup configuration. Make sure that you have enabled the cgroup feature for the cluster to which the target tenant belongs.
* You have created a resource group for the tenant.

## Procedure

1. Log in to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, select **<UI-TERM key="ocp-v2.src.util.menu.Tenant">Tenants</UI-TERM>**. The **<UI-TERM key="ocp-v2.Detail.Resource.Unit.Tenant">Tenants</UI-TERM>** page automatically appears.

3. On the **<UI-TERM key="ocp-v2.Backup.Backup.Data.Tenant">Tenants</UI-TERM>** page, find the target tenant and click its name to go to the **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">Overview</UI-TERM>** page of the tenant.

4. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Detail.ResourceManager.ResourceIsolation">Resource Isolation</UI-TERM>** to go to the isolation plan page of the tenant.

5. Click the **<UI-TERM key="ocp-v2.Detail.ResourceManager.ResourceGroup">Resource Group</UI-TERM>** tab.

6. Select the target resource group and click **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.Delete">Delete</UI-TERM>** in the **<UI-TERM key="ocp-v2.component.CardAbnormalTable.Operation">Actions</UI-TERM>** column.

    <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>After you delete a resource group bound to the resource isolation plan of a tenant, resource usage of the tenant can no longer be limited based on this resource group. </p>
    </main>

7. Click **<UI-TERM key="ocp-v2.component.ParameterTemplate.ParameterTemplateDropdown.Ok">OK</UI-TERM>**.
