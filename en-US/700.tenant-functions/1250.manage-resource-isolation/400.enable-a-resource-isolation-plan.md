# Enable or disable a resource isolation plan

After you create a resource isolation plan for a resource group, you must enable the plan to trigger resource isolation. After you enable the resource isolation plan, resources are allocated in the tenant based on the plan. You can disable the resource isolation plan when you no longer need it.

## Prerequisites

* Make sure that you have the following permissions:
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** or **Tenant Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.ResourceManager.CreateResourcePlan.ResourceIsolation">Resource Isolation</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.util.menu.Tenant">Tenants</UI-TERM>**
* Resource isolation depends on the cgroup configuration. Make sure that you have enabled the cgroup feature for the cluster to which the target tenant belongs.
* You have created a resource isolation plan for the tenant.
* You can enable only one resource isolation plan for a tenant.

## Procedure

1. Log in to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, select **<UI-TERM key="ocp-v2.src.util.menu.Tenant">Tenants</UI-TERM>**. The **<UI-TERM key="ocp-v2.Detail.Resource.Unit.Tenant">Tenants</UI-TERM>** page automatically appears.

3. On the **<UI-TERM key="ocp-v2.src.util.menu.Tenant">Tenants</UI-TERM>** page, find the target tenant and click its name to go to the **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** page of the tenant.

4. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Detail.ResourceManager.ResourceIsolation">Resource Isolation</UI-TERM>** to go to the isolation plan page of the tenant.

5. You can enable a resource isolation plan for a tenant in the following ways:

    * Method 1:

        If no resource isolation plan is enabled for the tenant, click **<UI-TERM key="ocp-v2.ResourceManager.ResourcePlanTab.EnableResourceIsolationPlan">Enable Resource Isolation Plan</UI-TERM>** in the prompt. In the dialog box that appears, select the target plan from the **<UI-TERM key="ocp-v2.Detail.ResourceManager.CreateResourcePlan.ResourceIsolationPlan">Resource Isolation Plan</UI-TERM>** drop-down list and click **<UI-TERM key="ocp-v2.MultiCluster.Detail.SwitchoverModal.Determine">OK</UI-TERM>**.

    * Method 2:

        Go to the tab of the plan to be enabled. Click **<UI-TERM key="ocp-v2.component.CPUBindCoreConfigDrawer.Enable">Enable</UI-TERM>** in the upper-right corner. In the dialog box that appears, click **<UI-TERM key="ocp-v2.Binlog.Component.StopBinlogModal.Ok">OK</UI-TERM>**.

    <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>After you enable a new resource isolation plan for a tenant for which another resource isolation plan has already been enabled, resources in the tenant are allocated based on the new plan, and the old plan no longer takes effect. </p>
    </main>

6. If the resource isolation plan in use is no longer applicable to the tenant, click **<UI-TERM key="ocp-v2.Component.CgroupEditModal.Close">Disable</UI-TERM>** in the upper-right corner to disable the plan.
