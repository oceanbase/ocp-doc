# Manage unit specifications

You can create, modify, and delete unit specifications on the page that appears after you click Unit Specification Management in the upper-right corner of the Tenants page in the OceanBase Cloud Platform (OCP) console.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** or **Tenant Maintenance** permission
* **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** menu of **<UI-TERM key="ocp-v2.page.Tenant.Tenant">Tenants</UI-TERM>**

## Procedure

1. Log on to the OCP console.

2. In the left-side navigation pane, select **<UI-TERM key="ocp-v2.src.util.menu.Tenant">Tenants</UI-TERM>**. The **<UI-TERM key="ocp-v2.Detail.Resource.Unit.Tenant">Tenants</UI-TERM>** tab automatically appears.

3. Click the **<UI-TERM key="ocp-v2.Detail.Component.AddReplicaModal.UnitSpecification">Unit Specifications</UI-TERM>** tab to view the unit specification list.

   In the **<UI-TERM key="ocp-v2.Detail.Component.BatchModifyUnitModal.NumberOfUnits">Units</UI-TERM>**list, you can view information about all units in the following columns: **<UI-TERM key="ocp-v2.Tenant.UnitSpec.Specification">Type Name</UI-TERM>**, **<UI-TERM key="ocp-v2.Host.Detail.Basic.CpuCores">CPU Cores</UI-TERM>**, **<UI-TERM key="ocp-v2.Tenant.UnitSpec.MemoryGb">Memory (GiB)</UI-TERM>**, **<UI-TERM key="ocp-v2.Tenant.UnitSpec.LogDiskGb">Log Disk (GiB)</UI-TERM>**, **IOPS**, **<UI-TERM key="ocp-v2.Tenant.UnitSpec.Type">Unit Types</UI-TERM>**, and **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetailTabs.Operation">Actions</UI-TERM>**.

   * You can sort unit specifications by **<UI-TERM key="ocp-v2.page.Host.CpuCores">CPU Cores</UI-TERM>**, **<UI-TERM key="ocp-v2.Tenant.UnitSpec.MemoryGb">Memory (GiB)</UI-TERM>**, **<UI-TERM key="ocp-v2.Tenant.UnitSpec.LogDiskGb">Log Disk (GiB)</UI-TERM>**, or **IOPS**.

   * You can also filter unit specifications by type, which can be **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.Default">Default</UI-TERM>** or **<UI-TERM key="ocp-v2.src.constant.inspection.Custom">Custom</UI-TERM>**.

   * In the **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.Operation">Actions</UI-TERM>** column, you can click **<UI-TERM key="ocp-v2.Alarm.Subscriptions.Edit">Edit</UI-TERM>** or **<UI-TERM key="ocp-v2.src.constant.oceanbase.Delete">Delete</UI-TERM>** to manage unit specifications.

    <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>If the cluster version of a tenant is earlier than OceanBase Database V4.0, you cannot view or modify the <b>Log Disk (GiB)</b> or <b>IOPS</b> columns. </p>
    </main>

   ![image.png](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/unit-specifications.png)

4. Click **<UI-TERM key="ocp-v2.Tenant.UnitSpec.NewUnitSpecifications">Add Unit Specifications</UI-TERM>**, and specify **Specification Name, CPU (Cores)** and **<UI-TERM key="ocp-v2.Tenant.UnitSpec.MemoryGb">Memory (GiB)</UI-TERM>**.

   The following table describes the parameters.

   | Parameter | Description |
   |--------|--------|
   | Specification Name | The name of the unit specification to be added.  |
   | CPU | The number of CPU cores for the unit specification. The minimum value is 0.5. You must enter an integral multiple of 0.5. <br>If the cluster version is OceanBase Database V4.0 or later, you can enable **<UI-TERM key="ocp-v2.src.component.AddUnitSpecModal.AdvancedCpuSettings">Advanced CPU Settings</UI-TERM>** and configure CPU overprovisioning. Specifically, you can configure the minimum and maximum numbers of CPU cores for the unit specification. <main id="notice" type='explain'><h4>Note</h4><p>If the cluster version is OceanBase Database V4.0 or later, you must select at least 1 CPU core. </p></main> |
   | Memory | The memory for the unit specification, in GiB. The minimum value is 1 GiB. You must enter an integer.  |
   | More Settings (Optional) | You can enable this parameter and configure **<UI-TERM key="ocp-v2.Tenant.UnitSpec.LogDiskGb">Log Disk (GiB)</UI-TERM>** and **IOPS**. <main id="notice" type='explain'><h4>Note</h4><p>If the cluster version is earlier than OceanBase Database V4.0, you cannot configure <b>Log Disk (GiB)</b> or <b>IOPS</b>. </p></main> |
