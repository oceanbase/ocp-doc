# Manage statistics collection tasks

This topic describes how to manage statistics collection tasks.

## Prerequisites

* To view statistics collection tasks, make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.Statistics.StatisticsManagement">Statistics Management</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.util.menu.Tenant">Tenants</UI-TERM>**

* To cancel a statistics collection task, make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** or **Tenant Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.hook.useMenu.StatisticsManagement">Statistics Management</UI-TERM>** menu of **<UI-TERM key="ocp-v2.page.Tenant.Tenant">Tenants</UI-TERM>**

* The OceanBase Database version is V4.2.2 or later, if you want to cancel a statistics collection task.

## View statistics collection tasks

The **<UI-TERM key="ocp-v2.Detail.Statistics.StatisticsTask">Statistics Tasks</UI-TERM>** section displays only statistics collection tasks of the recent 30 days. We recommend that you view statistics collection tasks within the validity period.

1. Log in to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, select **<UI-TERM key="ocp-v2.src.constant.auditEvent.Tenant">Tenants</UI-TERM>**. The **<UI-TERM key="ocp-v2.Tenant.New.Tenant">Tenants</UI-TERM>** page appears.

3. On the **<UI-TERM key="ocp-v2.page.Tenant.Tenant">Tenants</UI-TERM>** page, find the target tenant and click its name to go to the **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** page of the tenant.

4. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Detail.Statistics.StatisticsManagement">Statistics Management</UI-TERM>** to go to the **<UI-TERM key="ocp-v2.Detail.Statistics.OverviewOfStatistics">Statistics Overview</UI-TERM>** page.

5. In the **<UI-TERM key="ocp-v2.Detail.Statistics.StatisticsTask">Statistics Tasks</UI-TERM>** section, you can switch between the **<UI-TERM key="ocp-v2.Detail.Statistics.AutomaticStatistics">Automatically Collected Statistics</UI-TERM>** and **<UI-TERM key="ocp-v2.Detail.Statistics.ManualStatistics">Manually Collected Statistics</UI-TERM>** tabs to view different types of statistics collection tasks.

## Other operations

* You can filter statistics collection tasks by status. A statistics collection task can be in the **<UI-TERM key="ocp-v2.page.Information.Canceled">Canceled</UI-TERM>**, **<UI-TERM key="ocp-v2.page.Information.Completed">Completed</UI-TERM>**, **<UI-TERM key="ocp-v2.src.constant.compute.NormalOperation">Running</UI-TERM>**, or **<UI-TERM key="ocp-v2.component.UploadPackageDrawer.Failed">Failed</UI-TERM>** state.

* You can cancel a statistics collection task in the **<UI-TERM key="ocp-v2.src.constant.oceanbase.NormalOperation">Running</UI-TERM>** state.

    <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>You can cancel a statistics collection task only in OceanBase Database V4.2.2 and later. </p>
    </main>
