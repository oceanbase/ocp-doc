# Manage statistics collection tasks

This topic describes how to manage statistics collection tasks.

## Prerequisites

* To view statistics collection tasks, make sure that you have the following permissions:

  * **Resource Permissions**: **Cluster Read-only** or **Tenant Read-only** permission
  * **Menu Permissions**: Permission on the **Statistics Management** menu of **Tenants**

* To cancel a statistics collection task, make sure that you have the following permissions:

  * **Resource Permissions**: **Cluster Maintenance** or **Tenant Maintenance** permission
  * **Menu Permissions**: Permission on the **Statistics Management** menu of **Tenants**

* The OceanBase Database version is V4.2.2 or later, if you want to cancel a statistics collection task.

## View statistics collection tasks

The **Statistics Tasks** section displays only statistics collection tasks of the recent 30 days. We recommend that you view statistics collection tasks within the validity period.

1. Log in to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, select **Tenants**. The **Tenants** page appears.

3. On the **Tenants** page, find the target tenant and click its name to go to the **Overview** page of the tenant.

4. In the left-side navigation pane, click **Statistics Management** to go to the **Statistics Overview** page.

5. In the **Statistics Tasks** section, you can switch between the **Automatically Collected Statistics** and **Manually Collected Statistics** tabs to view different types of statistics collection tasks.

## Other operations

* You can filter statistics collection tasks by status. A statistics collection task can be in the **Canceled**, **Completed**, **Running**, or **Failed** state.

* You can cancel a statistics collection task in the **Running** state.

    <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>You can cancel a statistics collection task only in OceanBase Database V4.2.2 and later. </p>
    </main>
