# Manage databases

You can view the databases under a tenant, and create, delete, and modify a database under a tenant.

## Prerequisites

* To view the database list, make sure that you have the following permissions:
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.Database.DatabaseManagement">Database Management</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Backup.Backup.Data.Tenant">Tenants</UI-TERM>**
* To create, modify, or delete a database, make sure that you have the following permissions:
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** or **Tenant Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.page.Iframe.DatabaseManagement">Database Management</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Compaction.DetailV4.CompactionTenantListMyDrawer.Tenant">Tenants</UI-TERM>**

* The tenant is a MySQL tenant and a primary tenant.

* The root password of the tenant exists in the password box of the current user.

## Procedure

1. Log in to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, select **<UI-TERM key="ocp-v2.src.constant.auditEvent.Tenant">Tenants</UI-TERM>**. The **<UI-TERM key="ocp-v2.Detail.Resource.Unit.Tenant">Tenants</UI-TERM>** page automatically appears.

3. On the **<UI-TERM key="ocp-v2.Detail.Component.DeleteTenantModal.Tenant">Tenants</UI-TERM>** page, find the target MySQL tenant and click its name to go to the **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** page of the tenant.

4. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Iframe.DatabaseManagement">Database Management</UI-TERM>** to go to the **<UI-TERM key="ocp-v2.page.Iframe.DatabaseManagement">Database Management</UI-TERM>** page.

   * **View database information**

     In the database list, you can view the following database parameters: **<UI-TERM key="ocp-v2.Binlog.New.DatabaseName">Database Name</UI-TERM>**, **<UI-TERM key="ocp-v2.Detail.Component.AddDatabaseModal.CharacterSet">Character Set</UI-TERM>**, **Collation**, **<UI-TERM key="ocp-performance-report.ReportTable.BasicInfo.TenantBasicInfo.ZonePriority">Zone Priority</UI-TERM>**, **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.UsedDisk">Disk Usage</UI-TERM>**, **<UI-TERM key="ocp-v2.Tenant.Detail.CreationTime">Created At</UI-TERM>**, **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.ReadOnly">Read-only</UI-TERM>**, and **<UI-TERM key="ocp-v2.Detail.Database.JdbcConnectionString">JDBC Connection String</UI-TERM>**.

     <main id="notice" type='explain'>
     <h4>Note</h4>
     <p>If the OceanBase Database version is earlier than V2.2.1, you cannot view the creation time. </p>
     </main>

     ![Image 151](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/420-en/%E6%9F%A5%E7%9C%8B%E6%95%B0%E6%8D%AE%E5%BA%93%E4%BF%A1%E6%81%AF.png)

   * **Create a database**

     To create a database, click **<UI-TERM key="ocp-v2.Detail.Component.AddDatabaseModal.CreateADatabase">New Database</UI-TERM>** in the upper-right corner. In the **<UI-TERM key="ocp-v2.Detail.Database.CreateADatabase">New Database</UI-TERM>** panel, configure the **<UI-TERM key="ocp-v2.Statistics.components.ManualCollectDrawer.DatabaseName">Database Name</UI-TERM>**, **<UI-TERM key="ocp-v2.Detail.Database.CharacterSet">Character Set</UI-TERM>**, and **Collation** parameters and specify whether the database is read-only. Then, click **<UI-TERM key="ocp-v2.Detail.Component.AddArbitrationServerDrawer.Submit">Submit</UI-TERM>**.

     |    **<UI-TERM key="ocp-performance-report.ReportTables.ParameterStatInfo.ZoneParamInfoTable.Parameter">Parameter</UI-TERM>**     | **<UI-TERM key="ocp-v2.Settings.Credential.Host.Description">Description</UI-TERM>** |
     |---------------|---|
     | **<UI-TERM key="ocp-v2.Binlog.New.DatabaseName">Database Name</UI-TERM>** | The name of the database. It must start with a letter and contain 2 to 128 characters, including uppercase and lowercase letters, digits, and underscores (_). |
     | **<UI-TERM key="ocp-v2.Tenant.Detail.CharacterSet">Character Set</UI-TERM>** | The character set of the database. Supported character sets are utf8mb4, binary, gbk, gb18030, latin1, and gb18030_2022. The default character set is gbk. |
     | **Collation** | The collation corresponding to the specified character set. |

     <main id="notice" type='explain'>
     <h4>Note</h4>
     <ul>
     <li>The database automatically inherits the zone priorities of the tenant. For information about how to modify zone priorities, see <a href="600.manage-a-tenant/670.modify-a-zone-priority.md">Modify zone priorities</a>. </li>
     <li>If the zone priorities of the database and tenant are inconsistent, you can click <strong>To be consistent with that of the tenant</strong> to modify the zone priorities of the database. </li>
     </ul>
     </main>

     ![Image 152](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/420-en/%E6%96%B0%E5%BB%BA%E6%95%B0%E6%8D%AE%E5%BA%93.png)

   * **Modify database information**

     You can click **<UI-TERM key="ocp-v2.Detail.LoadBalance.Edit">Edit</UI-TERM>** in the **<UI-TERM key="ocp-v2.Alarm.LogFilter.Operation">Actions</UI-TERM>** column of a database to modify the character set, collation, or read-only attribute of the database.

     <main id="notice" type='explain'>
     <h4>Note</h4>
     <ul>
     <li>The database automatically inherits the zone priorities of the tenant. For information about how to modify zone priorities, see <a href="600.manage-a-tenant/670.modify-a-zone-priority.md">Modify zone priorities</a>. </li>
     <li>If the zone priorities of the database and tenant are inconsistent, you can click <strong>To be consistent with that of the tenant</strong> to modify the zone priorities of the database. </li>
     </ul>
     </main>

     ![Image 153](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/420-en/%E7%BC%96%E8%BE%91%E6%95%B0%E6%8D%AE%E5%BA%93.png)

   * **Delete a database**

     To delete a database, click **<UI-TERM key="ocp-v2.alarm.ExpressionFormList.MultipleExpressionFormList.Delete">Delete</UI-TERM>** in the **<UI-TERM key="ocp-v2.Detail.Parameter.Operation">Actions</UI-TERM>** column of the database. In the dialog box that appears, enter **delete** to confirm your operation.

     <main id="notice" type='notice'>
     <h4>Notice</h4>
     <p>After a database is deleted, the data cannot be recovered. Proceed with caution. </p>
     </main>

     ![Image 154](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/420-en/%E5%88%A0%E9%99%A4%E6%95%B0%E6%8D%AE%E5%BA%93.png)
