# Manage users in a MySQL tenant

The user management feature allows you to view users under the current MySQL tenant, create a user, delete a user, and grant and revoke user permissions.

## Prerequisites

* To view the MySQL user list, make sure that you have the following permissions:
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.hook.useMenu.UserManagement">User Management</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Backup.Backup.Data.Tenant">Tenants</UI-TERM>**
* To create, lock, or delete a user, change the password of a user, or modify the permissions of a user, make sure that you have the following permissions:
  * **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** or **Tenant Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.User.MySQL.UserManagement">User Management</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.util.menu.Tenant">Tenants</UI-TERM>**
* Only a primary tenant has the user management permissions.
* 

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, select **<UI-TERM key="ocp-v2.Backup.Backup.Data.Tenant">Tenants</UI-TERM>**. The **<UI-TERM key="ocp-v2.Detail.Resource.Unit.Tenant">Tenants</UI-TERM>** page automatically appears.

3. On the **<UI-TERM key="ocp-v2.Tenant.New.Tenant">Tenants</UI-TERM>** page, find the target tenant and click its name to go to the **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** page of the tenant.

4. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.UserManagement">User Management</UI-TERM>** to go to the **<UI-TERM key="ocp-v2.Auth.User.loginHistory.UserManagement">User Management</UI-TERM>** page.

5. In the user list, view user information in the following columns: **<UI-TERM key="ocp-v2.Instance.Overview.Username">Username</UI-TERM>**, **<UI-TERM key="ocp-v2.User.MySQL.AccessibleDatabases">Accessible Database</UI-TERM>**, **<UI-TERM key="ocp-v2.User.MySQL.LogonConnectionString">Login Connection String</UI-TERM>**, **<UI-TERM key="ocp-v2.Statistics.components.StatTable.Lock">Lock</UI-TERM>**, and **<UI-TERM key="ocp-v2.Detail.Parameter.List.Operation">Actions</UI-TERM>**.

   1. You can lock a user to prevent the user from logging on to the database.

   2. You can perform various operations on users. For example, you can lock a user, change the password of a user, modify the permissions of a user, and delete a user.

   3. You can view and copy the logon connection string.

6. Click **<UI-TERM key="ocp-v2.User.MySQL.CreateUser">Create User</UI-TERM>** in the upper-right corner.

   1. Configure the **<UI-TERM key="ocp-v2.Credential.Component.ImportModal.Username">Username</UI-TERM>**, **<UI-TERM key="ocp-v2.Detail.Component.AddUserDrawer.Hostname">Host Name</UI-TERM>**, **<UI-TERM key="ocp-v2.Channel.FormComponent.EMailForm.Password">Password</UI-TERM>**, **<UI-TERM key="ocp-v2.Binlog.Component.ModifyBinlogSYSPasswordModal.ConfirmPassword">Confirm Password</UI-TERM>**, **<UI-TERM key="ocp-v2.Detail.Component.AddUserDrawer.GlobalPermissions">Global Permissions</UI-TERM>**, and **<UI-TERM key="ocp-v2.Detail.Component.AddUserDrawer.DatabasePermissions">Database Permissions</UI-TERM>** parameters.

      | Parameter | Description |
      |-------|---------|
      | Username   | The username must be 2 to 64 characters in length and can contain lowercase letters, digits, and underscores (_). The name must start with a letter. |
      | Host Name   | Many host name formats are supported, including: <ul><li> `%` </li><li>`localhost` </li><li>IP addresses such as `192.168.1.1`, or subnet masks such as `192.168.1.%` </li><li>Domain names </li></ul> |
      | Password   | It must be 8 to 32 characters in length, and contain characters of at least three of the following types: digits (0 to 9), uppercase letters (A to Z), lowercase letters (a to z), and special characters. Supported special characters are <code>~ ! @ # % ^ & * _ - + = \ | ( ) { } [ ] : ; , . ? /</code>. |
      | Confirm Password | Enter the password you specified for the Password parameter. |
      | Global Permissions  | Optional. Global permissions apply to all databases. For more information, see [System privileges in a MySQL tenant](300.system-privileges-in-a-mysql-tenant.md).   |
      | Database Permissions | Optional. Database permissions apply to all objects in the specified database. |

      ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/432/new-user.png)

   2. Grant permissions to the new user. Select the databases that the user can access, click the **>** icon to move the databases to the right-side pane, and then select the permissions as needed.

   3. Click **<UI-TERM key="ocp-v2.component.Compaction.MergePolicyDrawer.Submit">Submit</UI-TERM>**.

7. Change the password of a user: Click **<UI-TERM key="ocp-v2.Layout.Header.ChangePassword">Change Password</UI-TERM>** in the **<UI-TERM key="ocp-v2.page.Package.UploadPackageTaskDrawer.Operation">Actions</UI-TERM>** column. In the dialog box that appears, change the password.

8. Modify the permissions of a user: Click **<UI-TERM key="ocp-v2.Oracle.Component.ModifyObjectPrivilegeModal.ModifyPermissions">Modify Permission</UI-TERM>** in the **<UI-TERM key="ocp-v2.Statistics.components.StatTable.Operation">Actions</UI-TERM>** column to modify the global permissions and database permissions of the user.

9. Delete a user: Click **<UI-TERM key="ocp-v2.Detail.TakeOver.Delete">Delete</UI-TERM>** in the **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetailTabs.Operation">Actions</UI-TERM>** column to delete the corresponding user. Deleting a user may affect the business that involves this user. Proceed with caution.
