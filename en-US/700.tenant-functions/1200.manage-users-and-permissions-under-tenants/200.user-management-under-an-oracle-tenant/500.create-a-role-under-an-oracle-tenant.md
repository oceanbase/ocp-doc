Create a role under an Oracle tenant
=========================================================

This topic describes how to create a role under an Oracle tenant.

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OceanBase Cloud Platform Enterprise Edition. OceanBase Cloud Platform Community Edition provides only the MySQL tenants. </p>
</main>

## Prerequisites

* Make sure that you have the following permissions:
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** or **Tenant Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.hook.useMenu.UserManagement">User Management</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Backup.Backup.Data.Tenant">Tenants</UI-TERM>**
* Only the primary tenant has the permission to create a role under an Oracle tenant.

Procedure
------------------------------

1. Log on to the OceanBase Cloud Platform (OCP) console. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Tenant.Tenant">Tenants</UI-TERM>** . The Tenant Overview page appears.

2. In the **<UI-TERM key="ocp-v2.Backup.Backup.Data.Tenant">Tenants</UI-TERM>** section, find the target tenant and click its name.The details page of the Oracle tenant appears.

3. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.UserManagement">User Management</UI-TERM>** .

4. Click **<UI-TERM key="ocp-v2.Auth.Role.New.CreateARole">Create Role</UI-TERM>** in the upper-right corner.

   ![10281635](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/1504306461/p345451.png)

5. In the dialog box that appears, specify the following parameters.

   |     Parameter      |                                                                                                                        Description                                                                                                                        |
   |--------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   | Role Name          | A user-defined name that must be 2 to 30 characters in length and begin with a letter, and can contain uppercase letters, lowercase letters, digits, and underscores (_). By default, lowercase letters are automatically converted to uppercase letters. |
   | System Permissions | Optional. For more information, see [System privileges](../300.system-privileges-in-a-mysql-tenant.md).                                                                                                                                                     |
   | Roles              | Optional.                                                                                                                                                                                                                                                 |

6. Click **<UI-TERM key="ocp-v2.Auth.User.New.Submitted">Submit</UI-TERM>** . You can view whether the modification succeeds in the Roles list.
