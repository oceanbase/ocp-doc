Delete a user under an Oracle tenant
=========================================================

This topic describes how to delete a user under an Oracle tenant.

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OceanBase Cloud Platform Enterprise Edition. OceanBase Cloud Platform Community Edition provides only the MySQL tenants. </p>
</main>

## Prerequisites

* Make sure that you have the following permissions:
  * **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** or **Tenant Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Auth.Role.New.UserManagement">User Management</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Tenant.New.Tenant">Tenants</UI-TERM>**
* Only the primary tenant has the permission to delete a user under an Oracle tenant.
* The system default users cannot be deleted.

Procedure
------------------------------

1. Log on to the OceanBase Cloud Platform (OCP) console. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.util.menu.Tenant">Tenants</UI-TERM>** . The Tenant Overview page appears.

2. In the **<UI-TERM key="ocp-v2.Compaction.DetailV4.CompactionTenantListMyDrawer.Tenant">Tenants</UI-TERM>** section, find the target tenant and click its name.The details page of the Oracle tenant appears.

3. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.User.MySQL.UserManagement">User Management</UI-TERM>** .

4. Find the target user, and click **<UI-TERM key="ocp-v2.src.constant.binlog.Delete">Delete</UI-TERM>** in the Actions column.

   ![10281633](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/3504306461/p345449.png)

5. In the dialog box that appears, enter the word **delete** .

6. Click **<UI-TERM key="ocp-v2.Detail.TakeOver.Delete">Delete</UI-TERM>** .
