# Change the password of a user under an Oracle tenant

This topic describes how to change the password of a user under an Oracle tenant.

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OceanBase Cloud Platform Enterprise Edition. OceanBase Cloud Platform Community Edition provides only the MySQL tenants. </p>
</main>

## Prerequisites

* Make sure that you have the following permissions:
  * **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** or **Tenant Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.page.Auth.UserManagement">User Management</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Detail.Component.DeleteTenantModal.Tenant">Tenants</UI-TERM>**
* Only the primary tenant has the permission to change the password of a user under an Oracle tenant.

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Tenant.Tenant">Tenants</UI-TERM>** . The Tenant Overview page appears.

2. In the **<UI-TERM key="ocp-v2.Compaction.DetailV4.CompactionTenantListMyDrawer.Tenant">Tenants</UI-TERM>** section, find the target tenant and click its name.The details page of the Oracle tenant appears.

3. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Auth.Role.Detail.UserManagement">User Management</UI-TERM>** .

4. Find the target user, and click **<UI-TERM key="ocp-v2.Auth.User.ChangePassword">Change Password</UI-TERM>** in the Actions column.

5. In the dialog box that appears, enter a new password and confirm it.

   ![10281629](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/2504306461/p345439.png)

6. Select **Save to Password Box** .

7. Click **<UI-TERM key="ocp-v2.Detail.Component.FailoverDrawer.Determine">OK</UI-TERM>** .
