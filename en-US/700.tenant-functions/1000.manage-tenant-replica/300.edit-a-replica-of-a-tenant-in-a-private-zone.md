# Edit tenant replicas in a zone

This topic describes how to modify the replica type and unit specification of tenant replicas in a single zone.

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Modifying the unit specification will trigger a partition replica migration operation, increasing the storage I/O on OBServer nodes and the network traffic between OBServer nodes. To manage sudden traffic, we recommend that you adjust the parameter values of <code>ha_high_thread_score</code> and <code>ha_mid_thread_score</code>, or implement resource isolation for the background tasks <code>HA_HIGH</code> and <code>HA_MID</code>.</p>
</main>

## Prerequisites

* The login user has the following permissions:

  * **Cluster Maintenance** or **Tenant Maintenance** permissions.
  * The **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">Overview</UI-TERM>** menu permission of the tenant.

* Starting from V4.0.0, clusters will default to limiting the unit specifications. If you need to select a unit specification smaller than the cluster's default, you can adjust the minimum value limit using the <code>__min_full_resource_pool_memory</code> parameter. For example, in a V4.1.0 cluster, you can refer to the steps provided in <a href="https://www.oceanbase.com/docs/common-oceanbase-database-cn-10000000001697240">Modify cluster item configurations</a>.
* If the tenant belongs to a cluster V4.2.0 or later, and the tenant parameter <code>enable_rebalance</code> is set to <code>false</code>, you cannot modify the number of units in the zone.
* If the replica type is <b>Read-Only Columnar Replica</b>, you cannot change it to another type. If the replica type is <b>Universal Replica</b> or <b>Read-Only Replica</b>, you cannot change it to a <b>Read-Only Columnar Replica</b>.
* If the tenant is a standalone database, you cannot modify the replica type.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, select **<UI-TERM key="ocp-v2.Information.Detail.CreateCollectDrawer.Tenant">Tenant</UI-TERM>**. The **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">Tenants</UI-TERM>** page automatically appears.

3. In the **<UI-TERM key="ocp-v2.component.TenantList.TenantList">Tenants</UI-TERM>** list on the **<UI-TERM key="ocp-v2.page.Overview.Overview">Overview</UI-TERM>** page of the tenant, find the target tenant and click its name.

4. In the **<UI-TERM key="ocp-v2.Tenant.Detail.CopyDetails">Replica Details</UI-TERM>** section, select the zone whose replica type and unit specification you want to modify and click **<UI-TERM key="ocp-v2.Alarm.Subscriptions.Edit">Edit</UI-TERM>**.

    <main id="notice" type='explain'>
    <h4>Note</h4>
    <p><ul><li>We recommend that the resources of the units remain consistent within the tenant.</li><li>For more information, see the descriptions of replica type, unit specification, and unit count in <a href="../300.create-a-tenant.md">Create a tenant</a>.</li></ul></p>
    </main>

5. Click **<UI-TERM key="ocp-v2.MultiCluster.Detail.Determine">OK</UI-TERM>**.
