# Manage tenant parameter templates

A tenant parameter template contains predefined tenant parameters. You can use a parameter template to create a series of tenants that have similar configurations without repeatedly configuring tenant parameters.

## Prerequisites

* To view the parameter templates of a tenant, make sure that you have the following permissions:
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Backup.Backup.Data.Tenant">Tenants</UI-TERM>**
* To create, edit, copy, or delete a parameter template, make sure that you have the following permissions:
  * **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** or **Tenant Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.page.Overview.Overview">Overview</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Detail.Resource.Unit.Tenant">Tenants</UI-TERM>**

## Procedure

1. Log on to the OCP console. The **<UI-TERM key="ocp-v2.Compaction.DetailV4.CompactionTenantListMyDrawer.Tenant">Tenants</UI-TERM>** page automatically appears.

2. In the left-side navigation pane, select **<UI-TERM key="ocp-v2.src.util.menu.Tenant">Tenants</UI-TERM>**. The **<UI-TERM key="ocp-v2.src.constant.auditEvent.Tenant">Tenants</UI-TERM>** tab automatically appears.

3. Click the **<UI-TERM key="ocp-v2.page.Tenant.ParameterTemplate">Parameter Template</UI-TERM>** tab to view the tenant parameter template list. If no tenant is available in the current cluster, click **Tenant Parameter Template Management** to create a tenant parameter template.

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/parameter-template.png)

    <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>If you do not have the permission to <b>create a tenant</b>, the button <b>Tenant Parameter Template Management</b> is not displayed.</p>
    </main>

4. On the **Tenant Parameter Template Management** page, you can query a parameter template, create a parameter template, edit a parameter template, copy a parameter template and delete a parameter template.

### Create a parameter template

1. On the **Tenant Parameter Template Management** page, click **<UI-TERM key="ocp-v2.component.ParameterTemplate.CreateAParameterTemplate">Create Parameter Template</UI-TERM>** .

2. On the **Create the tenant parameter template** page, name the template and set parameters in it.

   You can click **<UI-TERM key="ocp-v2.component.ParameterTemplate.SetParameterEditableProTable.AddParameters">Add Parameter</UI-TERM>** to add parameters and set parameter values. 

   ![2](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/0159934461/p394006.png)

3. Click **<UI-TERM key="ocp-v2.page.MultiCluster.Parameter.Submitted">Submit</UI-TERM>** .

    <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>Some parameters are applicable only to tenants in Oracle mode, and cannot be used by tenants in MySQL mode.</p>
    </main>

### Edit a parameter template

1. On the **Tenant Parameter Template Management** page, click **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.Edit">Edit</UI-TERM>** .

2. On the **Edit the tenant parameter template** page, modify the template name and parameters as needed.

3. Click **<UI-TERM key="ocp-v2.Oracle.Component.AddOracleUserOrRoleDrawer.Submitted">Submit</UI-TERM>** .

### Copy a parameter template

You can copy a complex template named A, and rename the template to B. In this way, you do not need to repeatedly set parameters in template B, and need to make only required modification.

1. On the **Tenant Parameter Template Management** page, find the target template in the **Tenant Parameter Templates** list, and click **<UI-TERM key="ocp-v2.Alarm.Channel.Copy">Copy</UI-TERM>** in the Actions column.

2. On the **Copy the Tenant Parameter Template** page, rename the template and modify parameters in the template as needed.

3. Click **<UI-TERM key="ocp-v2.Oracle.Component.AddOracleUserOrRoleDrawer.Submitted">Submit</UI-TERM>** .

### Delete a parameter template

1. On the **Tenant Parameter Template Management** page, find the target template in the **Tenant Parameter Templates** list.

2. Click **<UI-TERM key="ocp-v2.Alarm.Rule.Delete">Delete</UI-TERM>** in the Actions column.

3. Click **<UI-TERM key="ocp-v2.TrendAndOutline.SQLHistory.Ok">OK</UI-TERM>** in the dialog box that appears.

### Query a parameter template

1. On the **Tenant Parameter Template Management** page, specify the template name in the search box above the **Tenant Parameter Templates** list.

2. Click ![1](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/0159934461/p394010.png). The query results appear in the **Tenant Parameter Templates** list.
