# View tenant overview information

A tenant is a logical concept that represents a resource allocation unit in OceanBase Database. It is the basis for the management of database objects and resources. It is critical for system O&M, especially for the O&M of ApsaraDB for OceanBase.

After you log in to the OceanBase Cloud Platform (OCP) console, you can click **<UI-TERM key="ocp-v2.Backup.Backup.Data.Tenant">Tenants</UI-TERM>** in the left-side navigation pane to go to the **<UI-TERM key="ocp-v2.Detail.Component.DeleteTenantModal.Tenant">Tenants</UI-TERM>** page, where you can obtain the tenant overview information. By default, the page displays a list of tenants that you are authorized to view, and displays the performance monitoring charts of the top 5 tenants. You can also perform tenant management operations on this page. For more information, see [Manage unit specifications](1630.manage-unit-specification.md), [Create a tenant](300.create-a-tenant.md), [Lock a tenant](600.manage-a-tenant/300.locked-a-tenant.md), and [Clone a tenant](600.manage-a-tenant/350.clone-a-tenant.md).

## Prerequisites

To view information on the **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** page of a tenant, make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
* **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Tenant.New.Tenant">Tenants</UI-TERM>**

## Tenants

On the **<UI-TERM key="ocp-v2.src.constant.auditEvent.Tenant">Tenants</UI-TERM>** page, you can view tenant information in the following columns: **<UI-TERM key="ocp-v2.MultiCluster.RegisterOcp.Name">Name</UI-TERM>**, **<UI-TERM key="ocp-v2.Session.Deadlock.DeadlockHistoryTable.Id">ID</UI-TERM>**, **<UI-TERM key="ocp-v2.page.Information.Cluster">Cluster</UI-TERM>**, **<UI-TERM key="ocp-v2.Host.Detail.Basic.Label">Tag</UI-TERM>**, **OceanBase version number**, **<UI-TERM key="ocp-v2.component.TenantList.TenantMode">Mode</UI-TERM>**, **<UI-TERM key="ocp-v2.Detail.Database.ZonePriority">Primary Zone</UI-TERM>**, **<UI-TERM key="ocp-v2.src.constant.iam.ReadOnly">Read-only</UI-TERM>**, **<UI-TERM key="ocp-v2.Statistics.components.StatTable.Locked">Locked</UI-TERM>**, **<UI-TERM key="ocp-v2.component.TenantList.CreationTime">Created On</UI-TERM>**, and **<UI-TERM key="ocp-v2.Backup.Backup.Clean.State">Status</UI-TERM>**. The **<UI-TERM key="ocp-v2.component.ParameterTemplate.SetParameterEditableProTable.Operation">Actions</UI-TERM>** column provides options for you to perform related operations on tenants. You can search for multiple tenants at a time by specifying their names separated with spaces.

* You can click the name of a tenant to go to its **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** page. For more information, see [View the details of a tenant](600.manage-a-tenant/100.overview-of-the-tenant-details-page.md).

* You can click the **<UI-TERM key="ocp-v2.Alarm.Channel.Copy">Copy</UI-TERM>** icon next to the ID of a tenant to copy its ID.

* You can hover the pointer over the tag indicating the primary/standby status of a tenant and view its primary tenant or standby tenants in the pop-up window. You can click **<UI-TERM key="ocp-v2.Detail.Topo.MasterSlaveRelationshipMapping">Topology of Primary/Standby Tenants</UI-TERM>** to go to the topology page and view details about the primary tenant or standby tenants of the current tenant. For more information, see [View the topology of primary/standby relationships of a tenant](900.manage-tenant-topulogy/200.view-primary-standby-tenants-topology.md).

* You can hover the pointer over the **<UI-TERM key="ocp-v2.page.Host.Label">Tag</UI-TERM>** field to view all tags of a tenant. You can click the **<UI-TERM key="ocp-v2.ResourceManager.ResourcePlanTab.Edit">Edit</UI-TERM>** icon to manage the tags. For more information, see [Manage tags](../1600.system-management-features/300.manage-tags/100.tags-overview.md).

* You can click the **<UI-TERM key="ocp-v2.Backup.Component.RestoreNow.Copy">Copy</UI-TERM>** icon next to the name of a tenant to copy its name.

* You can sort tenants by cluster. In addition, you can click the name of a cluster to go to the tenant management page of the cluster. For more information, see [View the details of a cluster](../600.cluster-functions/300.manage-a-cluster/200.overview-of-the-cluster-details-page.md).

* When a tenant is in the **<UI-TERM key="ocp-v2.src.constant.oceanbase.OperationsIn">Maintaining</UI-TERM>** state, you can click **<UI-TERM key="ocp-v2.Cluster.Import.ImportClusterResults.ViewTasks">View Task</UI-TERM>** in the **<UI-TERM key="ocp-v2.Component.BinlogInstanceList.Operation">Actions</UI-TERM>** column to go to the task details page of the tenant. On the task details page, you can perform operations such as viewing task logs, rolling back a task, and retrying a task. For more information, see [Manage tasks](../1600.system-management-features/600.manage-tasks.md).

## Top 5 tenants

In this section, you can view the following monitoring data of tenants in the last hour, last 24 hours, or last 7 days: **QPS, TPS, SQL response time, Transaction response time, Sessions, Event waiting_Number of times, Event waiting_Time**, and **Capacity_Number of tables**.

You can click the zoom-in icon in the upper-right corner to zoom in the chart or select a monitoring time range.

![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/top5-1.png)

|   Metric    |                          Description                           |
|----------|-------------------------------------------------------|
| QPS      | The average number of SQL statements processed per second.                              |
| TPS      | The average number of transactions processed per second.                                   |
| Response Time | The SQL response time, in µs.                                         |
| Transaction Response Time   | The average processing time per transaction on the server, in μs.                                    |
| Sessions      | The number of sessions and the number of active sessions. Data source: the __all_virtual_processlist table.  |
| Event waiting_Number of times  | The average number of wait events per second.                                   |
| Event waiting_Time  | The average wait time per wait event, in μs.                                    |
| Capacity_Number of tables   | The number of tables.                                                   |
