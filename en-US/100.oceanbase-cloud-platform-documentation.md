# Document Overview

OceanBase Cloud Platform (OCP) is an enterprise-level management platform tailored for OceanBase database clusters, compatible with all mainstream versions of OceanBase. OCP provides graphical management capabilities for OceanBase clusters, including full lifecycle management, fault recovery, performance diagnostics, monitoring, and alerting for database components and related resources (such as hosts, networks, and software packages). It aims to help customers manage OceanBase clusters more efficiently and reduce enterprise IT O&M costs and user learning barriers.
