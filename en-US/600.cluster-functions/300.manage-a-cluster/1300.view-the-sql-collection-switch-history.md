# View the history of SQL collection switches
This topic describes how to view the history of SQL collection switches.

## Procedure

1. Log in to OCP.
2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Cluster.Arbitration.Cluster.1">Cluster</UI-TERM>** to go to the **<UI-TERM key="ocp-v2.src.constant.monitor.Cluster">Cluster</UI-TERM>** page.

3. In the **<UI-TERM key="ocp-v2.component.ModifyClusterParameterDrawer.Cluster">Cluster</UI-TERM>** page, in the **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** section, find the target cluster and click its name.

4. On the **<UI-TERM key="ocp-v2.pages.Alarm.Overview">Overview</UI-TERM>** page, click **View SQL Collection Switch History** in the upper-right corner.

5. In the dialog box that appears on the right, view the operation time and operation.
