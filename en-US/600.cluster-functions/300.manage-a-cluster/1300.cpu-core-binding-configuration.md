# Manage CPU binding configurations

CPU binding is a technology that binds a specific process or thread to a specific CPU core. This way, key tasks are processed by fixed CPU cores, instead of being frequently switched from one core to another. CPU binding reduces the context switching overhead and improves the overall system performance.

However, excessive use of the technology may lead to a situation where some CPU cores are overloaded while others are idle, decreasing resource utilization in the system. You need to decide whether to use CPU binding and adjust the binding strategy based on your business conditions to achieve the optimal performance and resource utilization.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** permission
* **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** menu of **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>**

## Configure the CPU binding range

1. Log on to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>** page automatically appears.

3. In the cluster list, find the target cluster and click its name.

4. On the **<UI-TERM key="ocp-v2.page.Overview.Overview">Overview</UI-TERM>** page of the cluster, click the **<UI-TERM key="ocp-v2.Component.AddBackupStrategy.ViewMore">More</UI-TERM>** icon in the upper-right corner and select **<UI-TERM key="ocp-v2.component.CPUBindCoreConfigDrawer.CpuCoreBindingConfiguration">CPU Binding Configuration</UI-TERM>**.

5. Click **<UI-TERM key="ocp-v2.component.CPUBindCoreConfigDrawer.BindConfigRangeDrawer.ConfigureCpuBindingRange">Configure CPU Binding Range</UI-TERM>**. You can configure the same CPU binding range for multiple zones or configure different CPU binding ranges for different zones.

   * **Configure the same CPU binding range for multiple zones**

     * Select the binding objects. You can select multiple zones from the drop-down list of the **<UI-TERM key="ocp-v2.component.CPUBindCoreConfigDrawer.BindConfigRangeDrawer.BindObject">Binding Object</UI-TERM>** field. By default, all zones in the cluster are selected. The system completes CPU binding configuration for the observer processes in the selected zones.

     * Specify the CPU binding range. Click **<UI-TERM key="ocp-v2.component.CPUBindCoreConfigDrawer.BindConfigRangeDrawer.Add">Add</UI-TERM>** in the ① section in the following figure to configure more CPU binding ranges for the zones.

   * **Configure different CPU binding ranges for different zones**

     Click **<UI-TERM key="ocp-v2.Detail.TakeOver.Add">Add</UI-TERM>** in the ② section in the following figure to configure a CPU binding range for another zone. A zone can be selected only in one **<UI-TERM key="ocp-v2.component.CPUBindCoreConfigDrawer.ConfirmBindConfigRangeInfoDrawer.BindObject">Binding Object</UI-TERM>** field.

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/432/cpu-binding.png)

6. Click **<UI-TERM key="ocp-v2.page.Inspection.Ok">OK</UI-TERM>**.

7. Click the task ID in the dialog box to view the task progress. When the task status changes to **<UI-TERM key="ocp-v2.src.constant.task.Completed">Completed</UI-TERM>** and the status of the cluster is **<UI-TERM key="ocp-v2.src.constant.backup.NormalOperation">Running</UI-TERM>**, CPU binding configuration for the cluster is successful.

## Enable or disable CPU binding configuration

1. Log on to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>**. The **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** page automatically appears.

3. In the cluster list, find the target cluster and click its name.

4. On the **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** page of the cluster, click the **<UI-TERM key="ocp-v2.Component.AddBackupStrategy.ViewMore">More</UI-TERM>** icon in the upper-right corner and select **<UI-TERM key="ocp-v2.Detail.Overview.CpuCoreBindingConfiguration">CPU Binding Configuration</UI-TERM>**.

5. Select the target CPU binding configuration and enable or disable it.

6. In the dialog box that appears, click **<UI-TERM key="ocp-v2.component.FormEditTable.Determine">OK</UI-TERM>**.
