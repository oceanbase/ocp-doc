# Enable automatic deadlock detection

You can enable automatic deadlock detection based on your business requirements.

## Prerequisites

* The current logged-in account has cluster management permissions.

* The current cluster version is V3.2.0 or later, and the cluster is not a read-only cluster.

* Automatic deadlock detection is not enabled for the cluster.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>For cluster versions V4.0 and later, automatic deadlock detection is enabled by default. You can disable it and then re-enable it later.</p>
  </main>

## Procedure

1. Log in to OCP.

2. In the left navigation bar, click **<UI-TERM key="ocp-v2.page.Information.Cluster">Cluster</UI-TERM>** to go to the **<UI-TERM key="ocp-performance-report.ReportTables.LockStatInfo.LatchStatTable.Cluster">Cluster</UI-TERM>** page.

3. In the **<UI-TERM key="ocp-v2.Alarm.LogFilter.Cluster">Cluster</UI-TERM>** page, in the **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** section, select the target cluster and click its name.

4. On the **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">Overview</UI-TERM>** page, click the **...** icon in the upper-right corner, and then select **<UI-TERM key="ocp-v2.Detail.Overview.EnableAutomaticDeadlockDetection">Enable Automatic Deadlock Detection</UI-TERM>** from the menu.

5. In the dialog box, click **<UI-TERM key="ocp-v2.Component.ClusterFilter.Ok">OK</UI-TERM>** to enable automatic deadlock detection.

   After automatic deadlock detection is enabled, OceanBase Database automatically detects deadlocks, rolls back them, and retains deadlock records for the past 7 days. For more information, see [View deadlock analysis](../../1000.diagnosis-and-tuning-fuctions/300.manage-session/300.view-deadlock-analysis.md).

    <h4>Notice</h4>
    <p>Enabling automatic deadlock detection consumes approximately 2% of performance. Proceed with caution.</p>
