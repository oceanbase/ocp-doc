# Disable automatic deadlock detection

You can disable automatic deadlock detection based on your business requirements.

## Prerequisites

* The current logged-in account has cluster management permissions.

* The current cluster version is V3.2.0 or later.

* Automatic deadlock detection is enabled for the cluster.

## Procedure

1. Log in to OCP.

2. In the left navigation bar, click **<UI-TERM key="ocp-v2.component.ParameterTemplate.Cluster">Cluster</UI-TERM>** to go to the **<UI-TERM key="ocp-v2.Cluster.Arbitration.Cluster.1">Cluster</UI-TERM>** page.

3. In the **<UI-TERM key="ocp-v2.Detail.Overview.Cluster.1">Cluster</UI-TERM>** page, in the **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** section, select the target cluster and click its name.

4. Click the **...** icon in the upper-right corner of the **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** page, then select **<UI-TERM key="ocp-v2.Detail.Overview.DisableAutomaticDeadlockDetection">Disable Automatic Deadlock Detection</UI-TERM>** from the menu.

5. In the dialog box, click **<UI-TERM key="ocp-v2.Inspection.Item.Ok">OK</UI-TERM>** to disable automatic deadlock detection.
