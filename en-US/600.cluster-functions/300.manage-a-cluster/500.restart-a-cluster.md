# Restart a cluster

You can restart the observer processes of all nodes in the cluster or specific zones based on your business requirements.

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.page.Overview.Overview">Overview</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>**

* If a multi-replica OceanBase cluster is to be restarted, the cluster must have three or more replicas. In this case, the OceanBase cluster is restarted in rolling mode, without affecting the business.

   If the OceanBase cluster has less than three replicas, the business will be interrupted during the restart.

* A **standalone centralized** database supports only the **<UI-TERM key="ocp-v2.Detail.Component.RestartModal.ForceRestart">Force Restart</UI-TERM>** mode.

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** to go to the **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** page.

3. In the **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** list on the page, find the target cluster and click its name.

4. Click the More icon in the upper-right corner on the **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** page of the cluster and select **<UI-TERM key="ocp-v2.Topo.TopoGraph.RestartTheCluster">Restart Cluster</UI-TERM>**.

5. In the dialog box that appears, set the following parameters and click **<UI-TERM key="ocp-v2.Cluster.Arbitration.Start">Restart</UI-TERM>**.

   * Set **<UI-TERM key="ocp-v2.Detail.Component.RestartModal.RestartRange">Restart Scope</UI-TERM>** to **<UI-TERM key="ocp-v2.component.common.TenantSelect.All">All</UI-TERM>**, or specify one or more zones.

      * If you set **<UI-TERM key="ocp-v2.Detail.Component.RestartModal.RestartRange">Restart Scope</UI-TERM>** to **<UI-TERM key="ocp-v2.alarm.FormListWithExclude.ArbitrationServiceWithExclude.All">All</UI-TERM>**, the system will restart the observer processes of all nodes in the cluster.

      * If you set **<UI-TERM key="ocp-v2.Detail.Component.RestartModal.RestartRange">Restart Scope</UI-TERM>** to specific zones, the system will restart the observer processes of these zones.

   * Set **<UI-TERM key="ocp-v2.Component.CgroupEditModal.RestartMode">Restart Method</UI-TERM>** to **<UI-TERM key="ocp-v2.src.constant.oceanbase.Restart.4">Restart</UI-TERM>**or **<UI-TERM key="ocp-v2.Component.CgroupEditModal.ForceRestart">Force Restart</UI-TERM>**.

      * **<UI-TERM key="ocp-v2.Component.BinlogInstanceList.Restart">Restart</UI-TERM>** (recommended): Business access to the database is not interrupted.

      * **<UI-TERM key="ocp-v2.Detail.Component.RestartModal.ForceRestart">Force Restart</UI-TERM>**: Business access to the database is interrupted and the business will become unavailable.

   * Specify whether to initiate a minor compaction before stopping the observer process. By default, this option is selected. A minor compaction prolongs the response time required to stop the observer process, but significantly shortens the time required to restore the OBServer node.

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E9%87%8D%E5%90%AF%E9%9B%86%E7%BE%A4-1.png)

6. In the dialog box that appears, click **<UI-TERM key="ocp-v2.Cluster.Import.ImportClusterResults.ViewTasks">View Task</UI-TERM>** to view the progress.

   You can also choose **System Management > Tasks** to view the progress.

   If the task status is **<UI-TERM key="ocp-v2.src.constant.task.Completed">Completed</UI-TERM>**, and the specific zones in the **<UI-TERM key="ocp-performance-report.pages.AWR.ReportContent.Zone">Zones</UI-TERM>** list on the **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">Overview</UI-TERM>** page are in the **<UI-TERM key="ocp-v2.src.constant.compute.NormalOperation">Running</UI-TERM>** state, the cluster is successfully restarted.
