# View details of a cluster

On the specific cluster page, you can view the basic information, resource usage, alert overview, system events of the last 7 days, zone list, and OBServer list of the cluster. You can also perform routine maintenance operations on the cluster.

## Prerequisites

Make sure that the current user logged in to OCP has the following permissions:

* **Cluster Read-Only** resource permissions.
* **<UI-TERM key="ocp-v2.page.Overview.Overview">Overview</UI-TERM>** menu permissions.

## View basic information

On the cluster overview page, you can view the basic information of the cluster, including **Cluster Name, Cluster ID, Cluster Type, OceanBase Version, Number of Regions, Deployment Mode, CPU Architecture, Cgroup Configuration, CPU Overcommit Quota, Number of Hosts, Load Type, Number of Partitions, Number of Tenants, Creator, Startup Time, Online Duration, OBProxy Cluster, Log Transmission Mode, Synchronization Status, Protection Mode, Software Installation Path, Data Disk Path, Log Disk Path**, **ConfigUrl**, and **<UI-TERM key="ocp-v2.page.Host.Label">Tag</UI-TERM>**.

## View resource usage

In the resource usage section, you can view the **<UI-TERM key="ocp-v2.Resource.Component.Block.AllocatedCpu">Allocated CPU</UI-TERM>**, **<UI-TERM key="ocp-v2.Resource.Component.Block.AllocatedMemory">Allocated Memory</UI-TERM>**, **<UI-TERM key="ocp-v2.Detail.Resource.Trend.AssignedLogDisk">Allocated Log Disk</UI-TERM>**, and **<UI-TERM key="ocp-v2.Cluster.Component.WaterLevel.DiskUsed">Data Disk Used</UI-TERM>** of the current cluster. You can also manage the cluster based on the resource usage.

<main id="notice" type='explain'>
<h4>Note</h4>
<p><li>When CPU overcommit is enabled for the cluster, the maximum and minimum number of CPU cores that can be allocated to the cluster are displayed in the resource usage section. </li><li>When the cluster version is earlier than V4.0, the <b>Allocated Log Disk</b> information is not displayed in the <b>Resource Usage</b> section. </li></p>
</main>

## View system events in the last 7 days

In the **<UI-TERM key="ocp-v2.Detail.Component.Event.SystemEventsInTheLast">System Events in Last 7 Days</UI-TERM>** section, you can set the query conditions as needed to view system events in the last seven days.

* In the section marked ① in the figure, you can set the search time.

* In the section marked ② in the figure, you can set the event name.

* In the section marked ③ in the figure, you can set the module to which the event belongs.

* In the section marked ④ in the figure, you can sort the events by the start time in ascending or descending order.

The system will display the system events you want to view based on the settings.

## View the list of OBServer nodes

* You can perform the following operations on an OBServer node: **reboot, stop service, stop process, reinstall, replace, delete**, and **<UI-TERM key="ocp-v2.Detail.Log.LogCard.DownloadLogs">Download Logs</UI-TERM>**. ## Protection mode

* Maximum performance: Ensures the maximum performance of the primary cluster while protecting your data. In this mode, logs are asynchronously transmitted to all standby clusters and the primary cluster.

* Maximum availability: In normal operation, only one standby cluster is in sync with the primary cluster for log transmission.

* Maximum protection: In normal operation, only one standby cluster is in sync with the primary cluster for log transmission, and other standby clusters use asynchronous log transmission.

## Switch clusters

To view the overview information of another cluster, click the name of the cluster in the upper-left corner of the **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">Overview</UI-TERM>** page. The current overview page will then switch to the overview page of the cluster you want to view.
