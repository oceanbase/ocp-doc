# Disable SQL collection
This topic describes how to disable SQL collection.

## Procedure

1. Log in to OCP.
2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.component.MonitorSearch.Cluster">Cluster</UI-TERM>** to go to the **<UI-TERM key="ocp-v2.page.Information.Cluster">Cluster</UI-TERM>** page.

3. In the **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** section, find the target cluster and click its name.

4. On the **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** page, click **Disable SQL Collection** in the upper-right corner.

5. In the dialog box that appears, click **<UI-TERM key="ocp-v2.Detail.Component.SwitchoverModal.Determine">OK</UI-TERM>**.
