# Take over a cluster

You can take over a cluster that was created through CLI commands or another OCP and then manage and operate the new cluster using the current OCP.

## **Prerequisites**

* The user who takes over the cluster has the Cluster Manager role or the permission to create clusters.

* All OBServer nodes in the OceanBase cluster to be taken over are running.

* Takeover follows the primary cluster priority principle:

  * In a single OCP scenario, take over the primary OceanBase cluster before the standby OceanBase cluster.

  * In an OCP multi-cluster scenario, first take over the primary OceanBase cluster in one OCP, and then take over the standby OceanBase cluster through any OCP.

   <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>After the takeover, the OceanBase cluster cannot be properly operated and monitored in the original OCP cluster. Proceed with caution before you take over an OceanBase cluster. </p>
   </main>

* If the OceanBase cluster to be taken over is deployed by obd, check whether the cluster meets the takeover conditions by referring to [Take over an obd-deployed cluster](https://www.oceanbase.com/docs/community-obd-cn-1000000001477802).

## **Procedure**

1. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.component.MonitorSearch.Cluster">Cluster</UI-TERM>** to go to the cluster page.

2. Click **<UI-TERM key="ocp-v2.page.Cluster.TakeOverTheCluster">Take over Cluster</UI-TERM>** in the upper-right corner.

3. Connect to the cluster. You can connect to the cluster directly or by using OBProxy.

   1. **Direct connection:** Specify the access address, port, and **<UI-TERM key="ocp-v2.Cluster.New.RootSysPassword">Root@sys Password</UI-TERM>** of the cluster. You can also **<UI-TERM key="ocp-v2.Cluster.Import.RecordProxyroPassword">record the password of the proxyro account</UI-TERM>**. Then, click **<UI-TERM key="ocp-v2.Cluster.Import.Next">Next</UI-TERM>**.

      <main id="notice" type='explain'>
      <h4>Note</h4>
      <p>The password of the proxyro account is used by OBProxy to access the OceanBase cluster. You can record the password here to ensure the consistency of the proxyro password. For more information about the proxyro account, see <a href="../../800.obproxy-functions/300.manage-a-obproxy-cluster/900.proxyro-user-management.md">Manage the proxyro account</a>. </p>
      </main>

      ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/%E6%8E%A5%E7%AE%A1%E9%9B%86%E7%BE%A4-%E7%9B%B4%E8%BF%9E.png)

   2. **<UI-TERM key="ocp-v2.Detail.Component.RestartObproxyModal.Obproxy">ODP:</UI-TERM>** of the cluster. You can also **<UI-TERM key="ocp-v2.Cluster.Import.RecordProxyroPassword">record the password of the proxyro account</UI-TERM>**. This account is used by OBProxy to access the OceanBase cluster. Then, click **<UI-TERM key="ocp-v2.component.StepsMoveOutCluster.Step1.NextStep">Next</UI-TERM>**.

      <main id="notice" type='explain'>
      <h4>Note</h4>
      <p><ul><li>If the cluster to be taken over is a standby cluster, the cluster ID is mandatory. If both the primary and standby clusters are to be taken over, the primary cluster will be taken over first, followed by the standby cluster. </li><li>The password of the proxyro account is used by OBProxy to access the OceanBase cluster. You can record the password here to ensure the consistency of the proxyro password. For more information about the proxyro account, see <a href="../../800.obproxy-functions/300.manage-a-obproxy-cluster/900.proxyro-user-management.md">Manage the proxyro account</a>. </li></ul></p>
      </main>

      ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/%E6%8E%A5%E7%AE%A1%E9%9B%86%E7%BE%A4-obproxy.png)

4. After the connection is established, the Takeover Check section appears.

   * If the takeover check is passed, select the target host, type, and credentials. Then, click **<UI-TERM key="ocp-v2.Oracle.Component.ModifyObjectPrivilegeModal.Submitted">Submit</UI-TERM>** at the bottom of the page.

     ![09010928](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E6%8E%A5%E7%AE%A1%E9%9B%86%E7%BE%A41.png)

   * If the takeover check is failed, modify the configuration of the OBServer node based on the suggestions on the page. After the modifications are made, click **<UI-TERM key="ocp-v2.Detail.TakeOver.ReCheck">Recheck</UI-TERM>**.
