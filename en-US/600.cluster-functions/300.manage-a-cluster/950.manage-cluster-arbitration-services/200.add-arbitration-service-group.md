# Add an arbitration service group

This topic describes how to add an arbitration service group for a cluster.

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OceanBase Cloud Platform (OCP) Enterprise Edition. OCP Community Edition does not support this feature. </p>
</main>

## Prerequisites

* Make sure that you have the following permissions:

  * Resource permissions: **Cluster maintenance** permission.
  * Menu permissions: Permission on the **Overview** menu of clusters.

* The OceanBase cluster and the arbitration service group are both in the **Running** state.
* The level-1 and level-2 version numbers of the OceanBase cluster are the same as those of the arbitration service group. For example, the version numbers of both the OceanBase cluster and the arbitration service group are V4.2.x.x.
* You can add only one arbitration service group for each cluster.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **Clusters**. The **Clusters** tab automatically appears.

3. On the **Clusters** page, find the target cluster and click its name.

4. On the **Overview** page of the cluster, go to the **Add Service Group** panel in either of the following ways:

   * Click the **More** icon in the upper-right corner and select **Add Service Group**.
   * In the **Arbitration Service List** section, click **Add**, and select **Service Group**.

5. In the **Add Service Group** panel, specify the parameters.

    | Parameter | Description |
    |---------------|----------|
    | Service Group | You can select an existing service group, or click **Create Service Group** at the bottom of the drop-down list to create a service group for the cluster. For more information, see [Create an arbitration service group](../../1370.manage-service-groups/200.create-a-service-group.md).  |
    | Arbitration Service Endpoint | The endpoint of the arbitration service. You can select an existing arbitration service endpoint, or click **Create Arbitration Service** at the bottom of the drop-down list to create an arbitration service of the required version. For more information, see [Create an arbitration service](../../1350.manage-arbitration-services/200.create-arbitration-services.md).  |
    | Enable Arbitration Service for 4F/2F Tenants | If you select this option, the arbitration service is enabled for the tenants that have two or four full-featured replicas in the cluster.  |

6. Click **Add**.
