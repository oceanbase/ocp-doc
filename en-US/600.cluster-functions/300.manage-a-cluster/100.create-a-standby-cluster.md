# Create a standby cluster

If you already have a primary cluster, you can create a standby cluster for it.

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OceanBase Cloud Platform Enterprise Edition. OceanBase Cloud Platform Community Edition only support create primary clusters. </p>
</main>

## Prerequisites

* You have logged in to the OceanBase Cloud Platform (OCP) console and been assigned the **ADMIN** or **ORG_ADMIN** role.
* You are logged on with an account that has the permission to manage the cluster.
* The version of the primary cluster is earlier than V4.0.

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console.

   The **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** page automatically appears.

2. You can go to the Create Standby Cluster page in one of the following ways:

   * Click **<UI-TERM key="ocp-v2.Cluster.New.CreateACluster">Create Cluster</UI-TERM>** in the upper-right corner of the **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** page. On the **<UI-TERM key="ocp-v2.Cluster.New.CreateACluster">Create Cluster</UI-TERM>** page, choose **<UI-TERM key="ocp-performance-report.ReportTables.BasicInfo.ClusterInfoTable.SecondaryCluster">Standby Cluster</UI-TERM>** for **<UI-TERM key="ocp-v2.Cluster.Detail.ClusterType">Cluster Type</UI-TERM>**, and select the corresponding primary cluster from the **<UI-TERM key="ocp-v2.Cluster.New.MasterCluster">Primary Cluster</UI-TERM>** drop-down list.

   * In the **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** list on the **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>** page, find the target primary cluster and click its name. In the upper-right corner on the **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** page, click the **<UI-TERM key="ocp-v2.page.Welcome.SeeMore">More</UI-TERM>** icon and choose **<UI-TERM key="ocp-v2.Cluster.New.CreateASecondaryCluster">Create Standby Cluster</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.page.Welcome.CreateACluster">Create Cluster</UI-TERM>** page, configure the basic information of the standby cluster.

   ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E6%96%B0%E5%BB%BA%E5%A4%87%E9%9B%86%E7%BE%A41.png)

   The following table describes the fields in the Basic Settings section.

   | Field | Description |
   |----------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   | **<UI-TERM key="ocp-v2.Cluster.New.ClusterType">Cluster Type</UI-TERM>** | Select **<UI-TERM key="ocp-v2.src.component.TenantLabel.Standby">Standby</UI-TERM>**. Make sure that the primary cluster is created.  |
   | **<UI-TERM key="ocp-v2.src.constant.oceanbase.MasterCluster">Primary Cluster</UI-TERM>** | Select the primary cluster and the system will create a standby cluster of the selected primary cluster.  |
   | **Standby Cluster OceanBase Version** | Select an OceanBase Database version the same as that of the primary cluster.  <ul><li> If the version exists in the drop-down list, select it.    </li><li> Otherwise, click **Add Version** at the bottom of the list to upload the version. </li> </ul> |

4. Set the deployment mode of the cluster.

   By default, three zones are added for a cluster. To deploy more than three zones for the cluster, click **<UI-TERM key="ocp-v2.alarm.ExpressionFormList.LogExpressionFormList.Add">Add</UI-TERM>**.

   To deploy less than three zones for the cluster, click the Delete icon after the zone to be deleted.

   ![p199912](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E9%83%A8%E7%BD%B2%E6%A8%A1%E5%BC%8F2.png)

   The following table describes the settings for each zone.

   | Field | Description |
   |-----|-------|
   | **<UI-TERM key="ocp-v2.component.FormZoneReplicaTable.ZoneName">Zone Name</UI-TERM>** | You can retain the default name or define a custom name.  A zone name must consist of 2 to 48 characters, including uppercase and lowercase letters, digits, and underscores (_), and start with a letter.  In an OceanBase cluster that consists of multiple zones, you must have a zone that shares the same region as that of the Primary Zone.  |
   | **<UI-TERM key="ocp-v2.OBProxy.New.ComputerRoom">IDC</UI-TERM>** | The IDC of the zone. Each zone can be deployed in only one IDC.  |
   | **<UI-TERM key="ocp-v2.Detail.TakeOver.Models">Host Type</UI-TERM>** | Optional.  If you select a host type, the host list is filtered based on the host type.  |
   | **<UI-TERM key="ocp-v2.page.Host.CpuArchitecture">CPU Architecture</UI-TERM>** | If multiple installation packages with different architectures are available for the selected OceanBase Database version, the selected hardware architecture of the host must match the software package. <blockquote>**Notice**</br><ul><li>By default, the architecture of the first installation package is used. You can change the architecture. After you change the architecture, you can select a host of the selected architecture from the drop-down list of the **<UI-TERM key="ocp-v2.Host.Detail.Host">Host</UI-TERM>** column. </li><li>You can set different architectures for the zones. However, the deployment mode with a hybrid architecture may have stability and performance issues. Proceed with caution. </li></blockquote> |
   | **<UI-TERM key="ocp-v2.src.component.ModifyTagResourceDrawer.Host">Host</UI-TERM>** | You can select or add hosts.  |
   | **Root Server** | You can select an IP address as the host for the Root Service. If you want to create a multi-replica OceanBase cluster, you must specify this parameter for each zone.  |

5. Turn on **Parameter Configurations** and configure the cluster parameters.

   * You can add startup parameters one by one and set values as shown in section ① of the following figure.

   * You can also click **<UI-TERM key="ocp-v2.component.ParameterTemplate.ParameterTemplateDropdown.SelectAParameterTemplate">Select Parameter Template</UI-TERM>** as shown in section ② of the following figure and select a parameter template. The system will automatically populate parameters in this section by using the template.

    <main id="notice" type='explain'>
    <h4>Note</h4>
    <ul>
    <li>If you use OceanBase Database V2.2.77, we recommend that you use the built-in <strong>2.2.77 Version Parameter Template</strong>. This template contains general parameters of OceanBase Database V2.2.77. You can configure a cluster based on this template.</li>
    <li>If no cluster parameter template is available, you can click <strong>Create Cluster Template</strong> to create one. For more information, see <a href="../1400.cluster-parameters-template-management.md">Manage cluster parameter templates</a>.</li>
    </ul>
    </main>

      ![09161737](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E5%8F%82%E6%95%B0%E8%AE%BE%E7%BD%AE2.png)

6. Turn on **<UI-TERM key="ocp-v2.Component.AddOBServerDrawer.CustomSettings">Custom Settings</UI-TERM>** to configure paths and ports.

   * Configure the paths:
      1. In the **<UI-TERM key="ocp-v2.Cluster.New.PathSettings">Path Settings</UI-TERM>** section, specify the **Software Installation Path, Data Disk Path**, and **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.LogDiskPath">Log Disk Path</UI-TERM>** as needed.
      2. Click **<UI-TERM key="ocp-v2.Cluster.New.Test">Test</UI-TERM>** to check whether the paths can be used. If a path cannot be used, you can perform troubleshooting based on the test results, or use another path.

   * Configure the ports:
      1. In the **<UI-TERM key="ocp-v2.Cluster.New.PortSettings">Port Settings</UI-TERM>** section, specify **<UI-TERM key="ocp-v2.Component.OBServerList.SqlPort">SQL Port</UI-TERM>** and **<UI-TERM key="ocp-v2.Cluster.New.RpcPort">RPC Port</UI-TERM>** as needed.
      2. Click **<UI-TERM key="ocp-v2.Component.StorageConfigCard.Test">Test</UI-TERM>** to check whether the ports are occupied. If a port is occupied, you must use another port.

      ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E8%B7%AF%E5%BE%84%E9%85%8D%E7%BD%AE2.png)

7. Click **<UI-TERM key="ocp-v2.Oracle.Component.ModifyObjectPrivilegeModal.Submitted">Submit</UI-TERM>**.

8. In the **<UI-TERM key="ocp-v2.Detail.Overview.ConfirmationInformation">Confirm Information</UI-TERM>** dialog box, confirm the information and then click **<UI-TERM key="ocp-v2.Oracle.Component.AddObjectPrivilegeDrawer.Determine">OK</UI-TERM>**.
