# Import a license

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OCP Enterprise Edition. OCP Community Edition does not support the license feature. </p>
</main>

In standalone mode, you need to upload the license authorization file to the OCP console to activate the corresponding feature components based on the authorization.

## Scenarios

* By default, a standalone instance is provided with a 180-day trial license. If the trial license is about to expire or has expired, you need to import a commercial license.
* If the commercial license is about to expire or has expired, you need to import the latest license.
* After you change the feature components in the license, you need to import the license again.

## Prerequisites

* The current instance is a standalone instance.

* You have obtained a license authorization file.

* The login user has the following permissions:

  * The **Cluster Maintenance** resource permission.
  * The **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** menu permission for the cluster.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Detail.Overview.Cluster.1">Cluster</UI-TERM>**. The **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** page automatically appears.

3. In the cluster list, find the target cluster and click its name.

4. On the **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">Overview</UI-TERM>** page of the cluster, click the **More** icon in the upper-right corner and select **Import License** from the drop-down list.

5. Select the license file that you have downloaded to your local device and upload it.

    * You can upload only one license file at a time.
    * If you upload a new license file after the previous one is uploaded, the new license file will replace the previous one.
