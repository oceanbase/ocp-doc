# Change the password

You can change the password for the root user of the SYS tenant in your cluster as needed.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** permission
* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** menu of **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>**

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>**.

3. In the **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** list, find the target cluster and click its name.

4. Click the More icon ( **...** ) in the upper-right corner on the **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** page and choose **<UI-TERM key="ocp-v2.User.MySQL.ChangePassword">Change Password</UI-TERM>** .

5. In the **<UI-TERM key="ocp-v2.User.MySQL.ChangePassword">Change Password</UI-TERM>** dialog box, set and confirm the new password.

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/403-cn/%E4%BF%AE%E6%94%B9%E9%9B%86%E7%BE%A4%E5%AF%86%E7%A0%811.png)

   The password must be 8 to 32 characters in length, and contains at least three of the following character types: digits(0\~9), uppercase letters(A\~Z), lowercase letters(a\~z), and special characters (ie: <code>~!@#%^&*_-+=\|(){}[]:;,.?/</code>).

6. Click **<UI-TERM key="ocp-v2.Detail.Component.DailyChangeTenantModal.Ok">OK</UI-TERM>** .
