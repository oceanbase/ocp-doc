# View the license

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OCP Enterprise Edition. OCP Community Edition does not support this feature. </p>
</main>

You can view the license to check the license status and related information of the current standalone instance.

## Prerequisites

* The current instance is a standalone instance.

* You have [imported a license](1400.import-license.md).

* The login user has the following permissions:

  * The **Cluster Maintenance** resource permission.
  * The **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** menu permission for the cluster.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Detail.Overview.Cluster.1">Cluster</UI-TERM>**. The **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** page automatically appears.

3. In the cluster list, find the target cluster and click its name.

4. On the **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">Overview</UI-TERM>** page of the cluster, click the **More** icon in the upper-right corner and select **View License**.

5. View the license information in the dialog box. The following table describes the fields.

   | Field  |  Description   |
   |-------|---------|
   | Cluster ID   | The cluster ID of the OceanBase instance on OCP, which is automatically generated when the cluster is started.    |
   | Username  | The username that authorizes the license.  |
   | License ID  | The ID of the license, which is generated by OceanBase Database.  |
   | License Code | The code of the license, which is composed of the contract number.  |
   | License Type | The type of the license. Valid values: <ul><li>Commercial: Commercial License</li><li>Trial: Trial License</li></ul>   |
   | Product Type   | The type of the license. Valid values: <ul><li>SE: Standalone Enterprise Edition</li><li>DE: Distributed Enterprise Edition</li></ul>   |
   | License Issued At   | The date when the license is issued.    |
   | License Activated At   | The date when the license is activated.    |
   | License Expires At   | The date when the license expires.    |
   | License Add-ons   | The add-ons included in the license. Valid values: <ul><li>EE: Basic features of OceanBase Standalone Enterprise Edition</li><li>PS: OceanBase Standalone Cluster Inter-Replication Add-on</li><li>MT: OceanBase Standalone Multi-tenant Add-on</li><li>AP: OceanBase Standalone OLAP Add-on</li></ul>    |
   | Number of Authorized Nodes   | The number of authorized nodes. For a standalone instance, the value is 1.    |
