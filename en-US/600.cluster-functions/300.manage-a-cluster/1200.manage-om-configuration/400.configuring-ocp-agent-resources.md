# Configure resources for OCP Agent

This topic describes how to configure resources for OceanBase Cloud Platform (OCP) Agent on all hosts in a cluster on the **OCP Agent Resource Configuration** tab. For more information about changing the specification of OCP Agent for a specific host, see [View details of a host](../../../850.host-features/150.view-a-host-overview.md).

## Prerequisites

Make sure that you have the following permissions:

* Resource permissions: **Cluster maintenance** permission.
* Menu permissions: Permission on the **Overview** menu of clusters.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **Clusters**. The **Clusters** tab automatically appears.

3. On the **Clusters** page, find the target cluster and click its name.

4. On the **Overview** page of the cluster, click the **More** icon in the upper-right corner and select **O&M Configuration**. The **Parameter Management** tab automatically appears.

5. Click the **OCP Agent Resource Configuration** tab, and view the IP address, name, zone, process, and specification of all hosts in the cluster.

6. Click **Change Specification** in the upper-right corner. In the **Change OCP Agent Specification** panel, adjust the CPU and memory settings of OCP Agent for all hosts in the cluster.
