# View the parameter modification history

On the **<UI-TERM key="ocp-v2.component.OperationConfig.Parameter.ModifyHistory">Change History</UI-TERM>** tab, you can view the modification records of all O&M parameters in the current cluster in the following columns: **<UI-TERM key="ocp-v2.component.ParameterTemplate.SetParameterEditableProTable.Parameter">Parameter Name</UI-TERM>**, **<UI-TERM key="ocp-v2.Detail.Component.ModifyParameterDrawer.ValueBeforeChange">Value before Change</UI-TERM>**, **<UI-TERM key="ocp-v2.component.ModifyClusterParameterDrawer.ValueAfterChange">Value after Change</UI-TERM>**, **<UI-TERM key="ocp-performance-report.ReportTables.ParameterStatInfo.ClusterParamInfoTable.ModificationTime">Modified At</UI-TERM>**, **<UI-TERM key="ocp-v2.page.MultiCluster.Parameter.Type">Parameter Type</UI-TERM>**, and **<UI-TERM key="ocp-v2.Detail.Parameter.History.OperationUser">Changed By</UI-TERM>**.

## Prerequisites

* Make sure that you have the following permissions:
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">Overview</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>**
* You have the permission to manage clusters.

## Procedure

1. Log on to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>** page automatically appears.

3. On the **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>** page, find the target cluster and click its name.

4. On the **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** page of the cluster, click the **<UI-TERM key="ocp-v2.page.Welcome.SeeMore">More</UI-TERM>** icon in the upper-right corner and select **<UI-TERM key="ocp-v2.Detail.Overview.OMConfiguration">O&M Configuration</UI-TERM>**.

5. Click the **<UI-TERM key="ocp-v2.component.OperationConfig.Parameter.ModifyHistory">Change History</UI-TERM>** tab.

6. You can filter parameters by specifying **<UI-TERM key="ocp-v2.Detail.Parameter.History.ModificationDate">Date of Modification</UI-TERM>** or **<UI-TERM key="ocp-v2.Detail.Component.ModifyParameterDrawer.Parameter">Parameter Name</UI-TERM>**. **<UI-TERM key="ocp-v2.Detail.Parameter.History.Parameter">Parameter Name</UI-TERM>** supports fuzzy match.

7. View the modification history of parameters in the search result.
