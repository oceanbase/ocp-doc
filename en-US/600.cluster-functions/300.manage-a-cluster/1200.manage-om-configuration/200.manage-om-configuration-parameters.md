# Manage parameters

This topic describes how to view and modify O&M parameters.

## Prerequisites

* Make sure that you have the following permissions:
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.page.Overview.Overview">Overview</UI-TERM>** menu of **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>**
* You have the permission to manage clusters.
* Modifications of O&M parameters may affect some features of OceanBase Cloud Platform (OCP). We recommend that you proceed with caution and modify O&M parameters with the assistance of OCP Technical Support.

## Procedure

1. Log on to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>** page automatically appears.

3. On the **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** page, find the target cluster and click its name.

4. On the **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">Overview</UI-TERM>** page of the cluster, click the **<UI-TERM key="ocp-v2.page.Welcome.SeeMore">More</UI-TERM>** icon in the upper-right corner and select **<UI-TERM key="ocp-v2.component.OperationConfig.OMConfiguration">O&M Configuration</UI-TERM>**.

5. On the **<UI-TERM key="ocp-v2.page.Property.ParameterList">Parameters</UI-TERM>** tab, manage O&M parameters.

   * Enable or disable parameters

     Click the switch next to **<UI-TERM key="ocp-v2.component.OperationConfig.List.SqlDiagnosticCollection">SQL Diagnostics Collection</UI-TERM>**, **<UI-TERM key="ocp-v2.component.OperationConfig.List.TransactionDiagnosticCollection">Transaction Diagnostics Collection</UI-TERM>**, or **<UI-TERM key="ocp-v2.component.OperationConfig.List.ActiveSessionHistoryCollection">ASH Collection</UI-TERM>** to enable or disable parameters of the corresponding module. After a module is disabled, O&M parameters in this module are not displayed, and the ocp-agent process no longer collects the corresponding data.

   * Modify a parameter value

     When a parameter module is enabled, find the parameter to be modified and click **<UI-TERM key="ocp-v2.Detail.Parameter.List.ModifyTheValue">Change Value</UI-TERM>** in the **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetailTabs.Operation">Actions</UI-TERM>** column. For more information about parameters, see the **<UI-TERM key="ocp-v2.component.OperationConfig.Parameter.ParameterList">Parameters</UI-TERM>** section in [Overview](100.om-configuration-overview.md).

     A parameter modification takes effect for all nodes in the current cluster. After a parameter modification task is submitted, you can view the task progress in **<UI-TERM key="ocp-v2.Layout.BasicLayout.TaskCenter">Task Center</UI-TERM>**.

   * Search for parameters

     You can enter a parameter name in the search box for a fuzzy search.

   * View modified parameters

     You can select **<UI-TERM key="ocp-v2.component.OperationConfig.List.ViewOnlyModifiedParameters">View Modified Parameters Only</UI-TERM>** to view only modified parameters.
