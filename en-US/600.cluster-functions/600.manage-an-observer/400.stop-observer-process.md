# Stop the observer process

This topic describes how to stop the observer process of an OBServer node. If you stop the observer process of an OBServer node, the OBServer node becomes unavailable and cannot provide services. Proceed with caution.

## Prerequisites

* Make sure that you have the following permissions:
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** menu of **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>**

* The target OceanBase cluster is managed in the current OCP cluster.

   Otherwise, you need to use the current OCP cluster to take over the OceanBase cluster. For more information, see [Take over a cluster](../300.manage-a-cluster/400.take-over-a-cluster.md).

## Procedure

1. Log on to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** to go to the **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** page.

3. In the **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** list on this page, find the target cluster and click its name to go to the **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** page of the cluster.

4. In the **<UI-TERM key="ocp-v2.Cluster.Component.MachineResource.NumberOfObservers">OBServers</UI-TERM>** list, find the row of the target OBServer node and choose **More > Stop** in the **<UI-TERM key="ocp-v2.Detail.Database.Operation">Actions</UI-TERM>** column.

   ![Image 169](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/%E5%81%9C%E6%AD%A2%E8%BF%9B%E7%A8%8B.png)

5. In the dialog box that appears, specify whether to initiate a minor compaction before stopping the observer process, and click **<UI-TERM key="ocp-v2.Restore.SamplingStrategy.Stop">Stop</UI-TERM>**. By default, this option is selected.

   A minor compaction prolongs the response time required to stop the observer process, but significantly shortens the time required to restore the OBServer node.

6. In the dialog box that appears, click **<UI-TERM key="ocp-v2.Detail.Report.ViewTasks">View Task</UI-TERM>** to view the progress.

   You can also choose **System Management > Tasks** to view the progress.

   When the task enters the **<UI-TERM key="ocp-v2.src.constant.task.Completed">Completed</UI-TERM>** state, and the status of the observer process is displayed as **<UI-TERM key="ocp-v2.src.constant.binlog.Stopped.3">Stopped</UI-TERM>** in the **<UI-TERM key="ocp-v2.Cluster.Component.MachineResource.NumberOfObservers">OBServers</UI-TERM>** list on the **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** page, the observer process is stopped.
