# Stop an observer process

This topic describes how to stop an observer process. Stopping an observer process makes the OBServer node unavailable. Proceed with caution.

## Prerequisites

* You have logged in to the OCP console as a user with the following privileges:

  * The **Cluster Maintenance** resource privilege.
  * The **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** menu privilege of the cluster.

* Your OceanBase cluster is managed in the current OCP cluster.

  Otherwise, you need to use the current OCP cluster to take over your OceanBase cluster. For more information, see [Take over a cluster](../300.manage-a-cluster/400.take-over-a-cluster.md).

* You cannot stop an observer process on a standalone node.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.alarm.FormListWithExclude.ClusterWithExclude.Cluster">Cluster</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** page automatically appears.

3. On the **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>** page, find the target cluster and click its name to go to the **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">Overview</UI-TERM>** page of the cluster.

4. In the **<UI-TERM key="ocp-v2.Component.OBServerList.ObserverList">OBServers</UI-TERM>** section, find the OBServer node whose process you want to stop and click **<UI-TERM key="ocp-v2.Component.AddSamplingInspectStrategy.More">More</UI-TERM>** > **<UI-TERM key="ocp-v2.src.constant.oceanbase.StopProcess">Stop Process</UI-TERM>** in the Actions column.

5. In the dialog box that appears, specify whether to perform a minor compaction before stopping the process (the default is to perform a minor compaction) and click **<UI-TERM key="ocp-v2.src.constant.oceanbase.StopProcess">Stop Process</UI-TERM>**.

   A minor compaction prolongs the response time for stopping the process but significantly shortens the time required for the OBServer node to resume normal operation.

6. After the task is submitted, you can click **<UI-TERM key="ocp-v2.page.Welcome.ViewTasks">View Tasks</UI-TERM>** in the dialog box to view the task progress, or you can view the task progress in **<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">Task Center</UI-TERM>**.

   When the task status is **<UI-TERM key="ocp-v2.Detail.Log.TaskGraph.Complete">Complete</UI-TERM>**, and the status of the observer process is **<UI-TERM key="ocp-v2.page.Overview.Stopped">Stopped</UI-TERM>** in the **<UI-TERM key="ocp-v2.Component.OBServerList.ObserverList">OBServers</UI-TERM>** section of the **<UI-TERM key="ocp-v2.page.Overview.Overview">Overview</UI-TERM>** page, the process is stopped.
