# Delete an OBServer

This topic describes how to delete an OBServer. When you delete an OBServer, the units on the OBServer are automatically migrated to other OBServer nodes in the same zone. If the available resources of other OBServer nodes in the same zone are insufficient, the units cannot be migrated and will be deleted along with other data on the OBServer node, and cannot be recovered. Therefore, proceed with caution.

## Prerequisites

* You have logged in to OCP as a user with the following permissions:

  * The **Cluster Maintenance** resource permission.
  * The **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** menu permission for the cluster.

* Your OceanBase cluster is managed in the current OCP cluster.

  If not, you can use the current OCP cluster to take over your OceanBase cluster. For more information, see [Take over a cluster](../300.manage-a-cluster/400.take-over-a-cluster.md).

* You cannot delete an OBServer node of a standalone cluster.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-performance-report.ReportTables.SqlInfo.SQLInfoTable.Cluster">Cluster</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** page automatically appears.

3. On the **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">Overview</UI-TERM>** page of the target cluster, click the name of the cluster to go to the **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">Overview</UI-TERM>** page.

4. In the **<UI-TERM key="ocp-v2.Component.OBServerList.ObserverList">OBServers</UI-TERM>** section, find the OBServer node that you want to stop and click **<UI-TERM key="ocp-v2.src.util.component.More">More</UI-TERM>** > **<UI-TERM key="ocp-v2.page.Credential.Binlog.Delete">Delete</UI-TERM>** in the Actions column.

   ![09161858](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E5%88%A0%E9%99%A4observer.png)

5. In the dialog box that appears, click **<UI-TERM key="ocp-v2.component.TenantList.Delete">Delete</UI-TERM>**.

   In the dialog box, you can click **<UI-TERM key="ocp-v2.page.Welcome.ViewTasks">View Tasks</UI-TERM>** to view the progress of the task. You can also view the task progress in **<UI-TERM key="ocp-v2.Layout.BasicLayout.TaskCenter">Task Center</UI-TERM>**.

   When the task status is **<UI-TERM key="ocp-v2.Detail.Log.TaskGraph.Complete">Complete</UI-TERM>**, and the **<UI-TERM key="ocp-v2.Component.OBServerList.ObserverList">OBServers</UI-TERM>** on the **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">Overview</UI-TERM>** page of the cluster no longer contains the OBServer node, the OBServer node is deleted.
