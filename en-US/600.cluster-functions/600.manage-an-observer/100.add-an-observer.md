# Add an OBServer node

You can add OBServer nodes to a cluster that you manage to scale out the cluster.

## Prerequisites

* Make sure that you have the following permissions:
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>**

* The target OceanBase cluster is managed in the current OceanBase Cloud Platform (OCP) cluster.

  Otherwise, you need to take over the OceanBase cluster to the current OCP cluster. For more information, see [Take over a cluster](../300.manage-a-cluster/400.take-over-a-cluster.md).

* You cannot add an OBServer node to a **standalone centralized** database.
  
## Add OBServer nodes to the cluster

You can perform the following steps to add OBServer nodes to multiple zones at a time.

1. Log on to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>**. The **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** page automatically appears.

3. On the **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** page, find the target cluster and click its name.

4. Go to the **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** page of the cluster and click **<UI-TERM key="ocp-v2.Cluster.Detail.AddObserver">Add OBServer</UI-TERM>** in the upper-right corner.

5. In the dialog box that appears, specify the following parameters.

   | Parameter | Description |
   |--------|--------|
   | Software Package Type  | The software installation package type of the OBServer node, which is the same as that of the current OceanBase cluster. If the system cannot identify the software installation package type of the OceanBase cluster, you need to select an appropriate installation package based on the version of your operating system.  |
   | OBServer Information | The model and IP address of the host of one or more OBServer nodes to be added. <br>If you do not need to add an OBServer node to a zone, click the **<UI-TERM key="ocp-v2.component.CreateTagDrawer.Delete">Delete</UI-TERM>** icon of the corresponding zone to remove the zone.  |
   | Custom Settings  | The OS user, path, and port number of the OBServer node. For more information, see the section about custom settings in [Create a distributed cluster](../200.create-a-cluster/100.create-a-distributed-cluster.md). |
   | Parameter Settings | The startup parameters of the OBServer node. For more information, see [Overview](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001375595). |

   <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p><ul><li>You can select only a host that matches the hardware architecture of the current cluster. </li><li>In a production environment, we recommend that the size of the log disk for an OBServer node be at least three times the memory size of the host. To avoid performance issues, we recommend that you do not create the data directory and the log directory on the same disk. </li></ul></p>
    </main>

    ![11181812](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/432/add-observer01.png)

6. Click **<UI-TERM key="ocp-v2.Host.Component.BatchReinstallModal.Determine">OK</UI-TERM>**.

   In the dialog box that appears, you can click **<UI-TERM key="ocp-v2.Detail.Report.ViewTasks">View Task</UI-TERM>** to view the progress. You can also view the task progress in **<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">Task Center</UI-TERM>**.

   When the task enters the **<UI-TERM key="ocp-v2.Detail.Statistics.utils.Completed">Completed</UI-TERM>** state, and the status of the OBServer node is displayed as **<UI-TERM key="ocp-v2.src.constant.tenant.NormalOperation">Running</UI-TERM>** in the OBServer node list on the **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** page of the cluster, the OBServer node is added.

## Add one or more OBServer nodes to a zone

You can perform the following steps to add one or more OBServer nodes to one zone.

1. Log on to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** page automatically appears.

3. On the **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>** page, find the target cluster and click its name.

4. On the **<UI-TERM key="ocp-v2.page.Overview.Overview">Overview</UI-TERM>** page, find the row of the target zone in the **<UI-TERM key="ocp-performance-report.pages.AWR.Zone">Zones</UI-TERM>** list, and click **<UI-TERM key="ocp-v2.Cluster.Detail.AddObserver">Add OBServer</UI-TERM>** in the **<UI-TERM key="ocp-v2.component.CardAbnormalTable.Operation">Actions</UI-TERM>** column.

5. In the dialog box that appears, specify the following parameters.

   | Parameter | Description |
   |--------|--------|
   | Software Package Type  | The software installation package type of the OBServer node, which is the same as that of the current OceanBase cluster. If the system cannot identify the software installation package type of the OceanBase cluster, you need to select an appropriate installation package based on the version of your operating system.  |
   | OBServer Information | The model and IP address of the host of one or more OBServer nodes to be added. <br>By default, only one OBServer node will be added. To add more OBServer nodes, click **<UI-TERM key="ocp-v2.src.constant.oceanbase.AddObserver">Add OBServer</UI-TERM>**.  |
   | Custom Settings  | The OS user, path, and port number of the OBServer node. For more information, see the section about custom settings in [Create a distributed cluster](../200.create-a-cluster/100.create-a-distributed-cluster.md). |
   | Parameter Settings | The startup parameters of the OBServer node. For more information, see [Overview](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001375595). |

   <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p><ul><li>You can select only a host that matches the hardware architecture of the current cluster. </li><li>In a production environment, we recommend that the size of the log disk for an OBServer node be at least three times the memory size of the host. To avoid performance issues, we recommend that you do not create the data directory and the log directory on the same disk. </li></ul></p>
   </main>

   ![09161748](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/432/add-observer02.png)

6. Click **<UI-TERM key="ocp-v2.MultiCluster.Detail.Determine">OK</UI-TERM>**.
