# Restart an arbitration service

This topic describes how to restart an arbitration service.

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OceanBase Cloud Platform Enterprise Edition. OceanBase Cloud Platform Community Edition does not support the arbitration service. </p>
</main>

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Arbitration Service Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>**

* The arbitration service is in the **STOPPED**, **RUNNING**, or **UNAVAILABLE** state.
* Log streams of the tenants associated with the arbitration service are not downgraded.

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>**.

3. Click the **<UI-TERM key="ocp-v2.src.component.ModifyTagResourceDrawer.ArbitrationService">Arbitration Service</UI-TERM>** tab to view the cluster arbitration service list.

4. On the **<UI-TERM key="ocp-v2.Component.ArbitrationServerList.ArbitrationServiceList">Arbitration Service List</UI-TERM>** page, find the arbitration service that you want to restart and hover the pointer over the **...** icon in the **<UI-TERM key="ocp-v2.component.ParameterTemplate.SetParameterEditableProTable.Operation">Actions</UI-TERM>** column and select **<UI-TERM key="ocp-v2.src.constant.oceanbase.RestartTheService">Restart Service</UI-TERM>**.

5. In the dialog box that appears, click **<UI-TERM key="ocp-v2.src.constant.obproxy.Start">Start</UI-TERM>**.

   <main id="notice" type='notice'>
   <h4>Notice</h4>
   <p>During the restart of an arbitration service, the clusters and tenants associated with the arbitration service cannot use the service. Exercise caution when you perform this operation. </p>
   </main>
