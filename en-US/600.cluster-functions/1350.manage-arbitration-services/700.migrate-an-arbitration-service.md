# Migrate an arbitration service

This topic describes how to migrate an arbitration service from an OceanBase Cloud Platform (OCP) cluster.

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OCP Enterprise Edition. OCP Community Edition does not support this feature. </p>
</main>

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **<UI-TERM key="ocp-v2.Cluster.Arbitration.ArbitrationServiceManagement">Arbitration Service Management</UI-TERM>** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>**

* The arbitration service is in the **<UI-TERM key="ocp-v2.src.constant.oceanbase.Stopped">Stopped</UI-TERM>**, **<UI-TERM key="ocp-v2.src.constant.compute.NormalOperation">Running</UI-TERM>**, or **<UI-TERM key="ocp-v2.src.constant.tenant.Unavailable">Unavailable</UI-TERM>** state.

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>**.

3. Click the **<UI-TERM key="ocp-v2.Cluster.Component.RepalceDrawer.ArbitrationService">Arbitration Service</UI-TERM>** tab to view the cluster arbitration service list.

4. On the arbitration service list page that appears, select the arbitration service to be migrated, hover the pointer over the **<UI-TERM key="ocp-v2.page.Welcome.SeeMore">More</UI-TERM>** icon in the **<UI-TERM key="ocp-v2.Detail.Report.Operation">Actions</UI-TERM>** column, and choose **<UI-TERM key="ocp-v2.src.constant.oceanbase.RelocationService">Migrate Service</UI-TERM>**.

5. In the dialog box that appears, click **<UI-TERM key="ocp-v2.component.StepsMoveOutCluster.Step2.MoveOut">Move Out</UI-TERM>**.

    <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>Migrating an arbitration service only dissociates the arbitration service from the OCP cluster and does not affect the running status of the arbitration service. </p>
    </main>

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E8%BF%81%E5%87%BA%E4%BB%B2%E8%A3%81%E6%9C%8D%E5%8A%A111.png)

6. After the arbitration service is migrated, you can disable the arbitration service for the associated tenant on the **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** page of the tenant.
