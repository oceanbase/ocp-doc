# Delete an arbitration service

This topic describes how to delete an arbitration service from a host, This operation will delete the service process and related data of the arbitration service.

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OceanBase Cloud Platform Enterprise Edition. OceanBase Cloud Platform Community Edition does not support the arbitration service. </p>
</main>

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **<UI-TERM key="ocp-v2.Cluster.Arbitration.ArbitrationServiceManagement">Arbitration Service Management</UI-TERM>** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** menu of **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>**

* The arbitration service is in the **RUNNING** state.
* No OceanBase Database cluster is using the arbitration service.

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>**.

3. Click the **<UI-TERM key="ocp-v2.Cluster.Arbitration.ArbitrationService">Arbitration Service</UI-TERM>** tab to view the cluster arbitration service list.

4. On the **<UI-TERM key="ocp-v2.Component.ArbitrationServerList.ArbitrationServiceList">Arbitration Service List</UI-TERM>** page, find the arbitration service that you want to delete and hover the pointer over the **...** icon in the **<UI-TERM key="ocp-v2.Component.SQLTable.Actions">Actions</UI-TERM>** column and select **<UI-TERM key="ocp-v2.src.constant.oceanbase.DeleteAService">Delete Service</UI-TERM>**.

5. In the window that appears, click **<UI-TERM key="ocp-v2.Alarm.Channel.Delete">Delete</UI-TERM>**.
