# Upgrade an arbitration service

This topic describes how to upgrade an arbitration service.

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OceanBase Cloud Platform Enterprise Edition. OceanBase Cloud Platform Community Edition does not support the arbitration service. </p>
</main>

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Arbitration Service Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>**

* The arbitration service is in the **RUNNING** state.
* Log streams of the tenants associated with the arbitration service are not downgraded.

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>**.

3. Click the **<UI-TERM key="ocp-v2.src.constant.information.ArbitrationService">Arbitration Service</UI-TERM>** tab to view the cluster arbitration service list.

4. On the **<UI-TERM key="ocp-v2.Component.ArbitrationServerList.ArbitrationServiceList">Arbitration Service List</UI-TERM>** page, find the arbitration service that you want to upgrade and hover the pointer over the **...** icon in the **<UI-TERM key="ocp-v2.Detail.Parameter.List.Operation">Actions</UI-TERM>** column and select **<UI-TERM key="ocp-v2.Cluster.Arbitration.UpgradeService">Upgrade Service</UI-TERM>**.

5. Confirm the information in the **<UI-TERM key="ocp-v2.Cluster.Arbitration.UpgradeService">Upgrade Service</UI-TERM>** dialog box, and select the software package of the target version.
   If no version is available, click **Add Version** in the drop-down list and upload the package of the required version.

6. Click **<UI-TERM key="ocp-v2.Cluster.Arbitration.Upgrade">Upgrade</UI-TERM>**.

   <main id="notice" type='notice'>
   <h4>Notice</h4>
   <p><ul><li>You can select only the software package of a version later than the current version, and the CPU architecture of the version must be the same as the hardware architecture of the current service. </li><li>During the upgrade, the arbitration service is unavailable, which may affect the high availability feature of the associated clusters. </li></p>
   </main>
