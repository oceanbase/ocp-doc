# Start an arbitration service

This topic describes how to start an arbitration service. You can start an arbitration service that has been stopped.

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OceanBase Cloud Platform Enterprise Edition. OceanBase Cloud Platform Community Edition does not support the arbitration service. </p>
</main>

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Arbitration Service Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** menu of **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>**

* The arbitration service is in the **STOPPED** state.

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>**.

3. Click the **<UI-TERM key="ocp-v2.src.constant.information.ArbitrationService">Arbitration Service</UI-TERM>** tab to view the cluster arbitration service list.

4. On the **<UI-TERM key="ocp-v2.Component.ArbitrationServerList.ArbitrationServiceList">Arbitration Service List</UI-TERM>** page, find the arbitration service that you want to start and click **<UI-TERM key="ocp-v2.src.constant.oceanbase.StartTheService">Start Service</UI-TERM>** in the **<UI-TERM key="ocp-v2.User.Oracle.RolesList.Operation">Actions</UI-TERM>** column.

5. In the dialog box that appears, click **<UI-TERM key="ocp-v2.Detail.Backup.Start">Start</UI-TERM>**.

   After you start an arbitration service, the clusters and tenants associated with the service can continue to use it.
