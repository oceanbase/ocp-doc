# Remove an arbitration service

This topic describes how to remove an arbitration service that you no longer need.

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OceanBase Cloud Platform Enterprise Edition. OceanBase Cloud Platform Community Edition does not support the arbitration service. </p>
</main>

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">Overview</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>**

* The arbitration service is in the **STOPPED**, **RUNNING**, or **UNAVAILABLE** state.
* No OceanBase Database cluster is using the arbitration service.

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>**.

3. Click the **<UI-TERM key="ocp-v2.src.constant.information.ArbitrationService">Arbitration Service</UI-TERM>** tab to view the cluster arbitration service list.

4. In the **<UI-TERM key="ocp-v2.Component.ArbitrationServerList.ArbitrationServiceList">Arbitration Service List</UI-TERM>** section on the **<UI-TERM key="ocp-v2.Detail.Overview.ClusterOverview">Cluster Overview</UI-TERM>** page, find the arbitration service that you want to remove, and click **Remove Service** in the **<UI-TERM key="ocp-v2.Alarm.LogFilter.Operation">Actions</UI-TERM>** column.

   <main id="notice" type='notice'>
   <h4>Notice</h4>
   <p>After the arbitration service is removed, the cluster no longer has the arbitration-based high availability feature. </p>
   </main>
