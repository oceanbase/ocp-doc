# Add an arbitration service

This topic describes how to add an arbitration service for a cluster.

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OceanBase Cloud Platform Enterprise Edition. OceanBase Cloud Platform Community Edition does not support the arbitration service. </p>
</main>

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Arbitration Service Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.page.Overview.Overview">Overview</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>**

* The cluster is of OceanBase Database V4.1.0 or later.
* The cluster is in the **RUNNING** state.
* You can add only one arbitration service for each cluster.

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** to go to the **<UI-TERM key="ocp-v2.Detail.Overview.ClusterOverview">Cluster Overview</UI-TERM>** page.

3. In the **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** list on the page, find the target cluster and click its name.

4. In the upper-right corner of the **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** page of the cluster, click the **...** icon, and choose **<UI-TERM key="ocp-v2.Detail.Overview.AddArbitrationService">Add Arbitration Service</UI-TERM>**.

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E9%9B%86%E7%BE%A4%E6%B7%BB%E5%8A%A0%E4%BB%B2%E8%A3%81%E6%9C%8D%E5%8A%A1-1.png)

5. In the **<UI-TERM key="ocp-v2.Detail.Overview.AddArbitrationService">Add Arbitration Service</UI-TERM>** panel, select an arbitration service endpoint for the cluster. You can also click **<UI-TERM key="ocp-v2.Cluster.New.CreateAService">Create Service</UI-TERM>** at the bottom the drop-down list to create an arbitration service for the cluster. For more information, see [Create an arbitration service](200.create-arbitration-services.md).

6. Click **<UI-TERM key="ocp-v2.Detail.Parameter.List.Submitted">Submit</UI-TERM>**.

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E9%9B%86%E7%BE%A4%E6%B7%BB%E5%8A%A0%E4%BB%B2%E8%A3%81%E9%80%89%E6%8B%A9%E5%9C%B0%E5%9D%80-1.png)
