# Edit a zone

This topic describes how to modify the region or IDC setting of a zone. The modification applies to the region or IDC attribute of all hosts in the zone. Proceed with caution.

## Prerequisites

* Make sure that you have the following permissions:
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** menu of **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>**

* The target OceanBase cluster is managed in the current OceanBase Cloud Platform (OCP) cluster. Otherwise, you need to take over the OceanBase cluster to the current OCP cluster. For more information, see [Take over a cluster](../300.manage-a-cluster/400.take-over-a-cluster.md).

* The OceanBase Database version of the cluster is V3.x or later.

* The zone to be edited is in the **<UI-TERM key="ocp-v2.src.constant.tenant.NormalOperation">Running</UI-TERM>** state.
  
## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** page automatically appears.

3. On the **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** page, find the target cluster and click its name.

4. In the **<UI-TERM key="ocp-performance-report.pages.AWR.ReportContent.Zone">Zones</UI-TERM>** list, click **<UI-TERM key="ocp-v2.Alarm.Channel.Editing">Edit</UI-TERM>** in the **<UI-TERM key="ocp-v2.component.CardAbnormalTable.Operation">Actions</UI-TERM>** column of the target zone.

5. In the dialog box that appears, select a new region and IDC for the zone, and then click **<UI-TERM key="ocp-v2.User.Component.AccessKeyCardTable.Ok">OK</UI-TERM>**.
