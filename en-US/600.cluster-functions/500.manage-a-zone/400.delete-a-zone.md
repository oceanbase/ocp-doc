# Delete a zone

This topic describes how to delete a zone from an OceanBase cluster. This operation removes all OBServer nodes and data from the zone and releases the host resources. Proceed with caution.

## Background information

* If the number of zones in the cluster is even, it may not meet the high availability requirements, posing a data security risk. We recommend that you adjust the configuration to ensure an odd number of zones or enable the arbitration service for the cluster or tenant.
* After the cluster is converted to a single-zone multi-host configuration, it can only enhance the computing power of OceanBase services and does not support multi-replica high availability, making it suitable for development and testing environments.
* After the cluster is converted to a single-zone single-host configuration, it has only one data replica, lacking multi-replica and scaling capabilities. In the event of storage or hardware failures, there is a risk of data loss. We recommend that you regularly back up critical business systems or implement high availability solutions such as tenant primary/standby databases and multi-replica disaster recovery to avoid single points of failure.

## Prerequisites

* The login user has the following permissions:

  * **Cluster Maintenance** resource permissions.
  * **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** menu permissions under the cluster.

* The OceanBase cluster is managed in the current OCP cluster.

  If not, you can use the current OCP cluster to take over your OceanBase cluster. For more information, see [Take over a cluster](../300.manage-a-cluster/400.take-over-a-cluster.md).

* Standalone mode does not support zone deletion.

* The tenant's primary replica is not hosted on the zone to be deleted. If it is, ensure that the tenant has other fully functional replicas available. Otherwise, deleting the zone will result in service interruption and irreversible consequences.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Cluster.Component.WaterLevel.Cluster">Cluster</UI-TERM>**. The **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** page automatically appears.

3. In the **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** list on the page, find the target cluster and click its name.

4. On the **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** page of the cluster, click **<UI-TERM key="ocp-v2.Alarm.Subscriptions.Operation">Actions</UI-TERM>** > **More > Delete** in the **<UI-TERM key="ocp-v2.Component.ZoneList.ZoneList">Zones</UI-TERM>** section.

   A confirmation dialog box appears.

5. In the dialog box, click **<UI-TERM key="ocp-v2.ResourceManager.ResourceGroupTab.Delete">Delete</UI-TERM>**.

   You can click **<UI-TERM key="ocp-v2.src.constant.ViewTasks">View Tasks</UI-TERM>** in the dialog box to view the task progress, or view the task progress in **<UI-TERM key="ocp-v2.Layout.BasicLayout.TaskCenter">Task Center</UI-TERM>**.

   When the task status is **<UI-TERM key="ocp-v2.Detail.Log.TaskGraph.Complete">Complete</UI-TERM>** and the **<UI-TERM key="ocp-v2.Component.ZoneList.ZoneList">Zones</UI-TERM>** list on the **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** page of the cluster no longer contains the zone, the zone has been deleted.
