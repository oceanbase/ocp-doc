# Stop a zone

This topic describes how to stop a zone. Stopping a zone also stops all OBServer nodes in the zone. Proceed with caution.

## Prerequisites

* Make sure that you have the following permissions:
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** menu of **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>**

* The target OceanBase cluster is managed in the current OCP cluster.

   Otherwise, you need to use the current OCP cluster to take over the OceanBase cluster. For more information, see [Take over a cluster](../300.manage-a-cluster/400.take-over-a-cluster.md).

* Check whether the zone to be stopped hosts the leader replica of the tenant. If yes, make sure that a full-featured replica of the tenant is available. Otherwise, stopping the zone will cause business interruptions.

## Procedure

1. Log on to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>** to go to the **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** page.

3. In the **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** list on the page, find the target cluster and click its name.

4. In the **<UI-TERM key="ocp-performance-report.pages.AWR.ReportContent.Zone">Zones</UI-TERM>** list, find the row of the target zone and choose **More > Stop** in the **<UI-TERM key="ocp-v2.Tenant.UnitSpec.Operation">Actions</UI-TERM>** column.

   ![11181758](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/stopzone.png)

5. In the dialog box that appears, specify whether to initiate a minor compaction before stopping the observer process, and click **<UI-TERM key="ocp-v2.Restore.SamplingStrategy.Stop">Stop</UI-TERM>**. By default, this option is selected.

   A minor compaction prolongs the response time required to stop the observer process, but significantly shortens the time required to restore the OBServer node.

6. In the dialog box that appears, click **<UI-TERM key="ocp-v2.Detail.Report.ViewTasks">View Task</UI-TERM>** to view the progress.

   You can also choose **System Management > Tasks** to view the progress.

   When the task enters the **<UI-TERM key="ocp-v2.Detail.Statistics.utils.Completed">Completed</UI-TERM>** state, and the status of the zone is displayed as **<UI-TERM key="ocp-v2.page.Overview.Stopped">Stopped</UI-TERM>** in the **<UI-TERM key="ocp-performance-report.pages.AWR.Zone">Zones</UI-TERM>** list on the **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** page, the zone is stopped.

7. (Optional) If you want to use the zone again, find it in the **<UI-TERM key="ocp-performance-report.pages.AWR.Zone">Zones</UI-TERM>** list, and click **<UI-TERM key="ocp-v2.Component.ZoneList.Start">Start</UI-TERM>** in the **<UI-TERM key="ocp-v2.Auth.Role.Operation">Actions</UI-TERM>** column.
