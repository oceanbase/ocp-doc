# Manage cluster parameter templates

A cluster parameter template contains predefined cluster parameters. You can use a parameter template to create a series of clusters that have similar configurations without repeatedly configuring cluster parameters.

## Prerequisites

* To view the parameter templates of a cluster, make sure that you have the following permissions:
  * **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** menu of **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>**

* To create, edit, copy, or delete a parameter template, make sure that you have the following permissions:
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** menu of **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>**

## Procedure

1. Log on to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>**.

3. Click the **<UI-TERM key="ocp-v2.page.Cluster.ParameterTemplate">Parameter Template</UI-TERM>** tab to view the cluster parameter template list. If no cluster is available in the OCP console, click **Cluster Parameter Template Management** to **create the cluster parameter template** .

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/parameter-template-cluster.png)

   <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>If you do not have the permission to <strong>create a cluster</strong> , the button <strong>Cluster Parameter Template Management</strong> is not displayed.</p>
   </main>

4. On the **Cluster Parameter Template Management** page, you can create a parameter template, edit a parameter template, copy a parameter template, and delete a parameter template.

   <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>The built-in cluster parameter template of the system cannot be edited or deleted.</p>
   </main>

### Create a parameter template

1. On the **Cluster Parameter Template Management** page, click **<UI-TERM key="ocp-v2.component.ParameterTemplate.CreateAParameterTemplate">Create Parameter Template</UI-TERM>** .

2. On the **<UI-TERM key="ocp-v2.component.ParameterTemplate.CreateAParameterTemplate">Create Parameter Template</UI-TERM>** page, name the template and set parameters in it.

   You can click **<UI-TERM key="ocp-v2.component.ParameterTemplate.SetParameterEditableProTable.AddParameters">Add Parameter</UI-TERM>** to add parameters and set parameter values.

   ![2](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/3075723461/p394051.png)

3. Click **<UI-TERM key="ocp-v2.Auth.User.New.Submitted">Submit</UI-TERM>** .

### Edit a parameter template

1. On the **Cluster Parameter Template Management** page, click **<UI-TERM key="ocp-v2.component.ParameterTemplate.AddDrawer.Editing">Edit</UI-TERM>** .

2. On the **Edit Parameter Template** page, modify the template name and parameters as needed.

3. Click **<UI-TERM key="ocp-v2.Binlog.New.Submit">Submit</UI-TERM>** .

### Copy a parameter template

You can copy a complex template named A, and rename the template to B. In this way, you do not need to repeatedly set parameters in template B, and need to make only required modification.

1. On the **Cluster Parameter Template Management** page, find the target template in the **Cluster Parameter Templates** list, and click **<UI-TERM key="ocp-v2.page.External.Copy">Copy</UI-TERM>** in the Actions column.

2. On the **Copy the Tenant Parameter Template** page, rename the template and modify parameters in the template as needed.

3. Click **<UI-TERM key="ocp-v2.Oracle.Component.ModifyObjectPrivilegeModal.Submitted">Submit</UI-TERM>** .

### Delete a parameter template

1. On the **Cluster Parameter Template Management** page, find the target template in the **Cluster Parameter Templates** list, and click **<UI-TERM key="ocp-v2.Backup.Service.Delete">Delete</UI-TERM>** in the Actions column.

2. Click **<UI-TERM key="ocp-v2.TakeOver.Component.LoadBalancer.Ok">OK</UI-TERM>** in the dialog box that appears.
