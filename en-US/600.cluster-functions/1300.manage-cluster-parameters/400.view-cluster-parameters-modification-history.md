# View the history of parameter changes

You can modify parameters in OCP. The Change History tab allows you to view the history of all parameter changes. You can view Parameter Name, Value Before Change, Value After Change, Modified At, and Changed By.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** permission
* **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.component.OperationConfig.ParameterManagement">Parameter Management</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>**

## Procedure

1. Log on to OCP.

2. Click **<UI-TERM key="ocp-v2.component.ModifyClusterParameterDrawer.Cluster">Cluster</UI-TERM>** on the left navigation bar to enter the **<UI-TERM key="ocp-v2.component.ModifyClusterParameterDrawer.Cluster">Cluster</UI-TERM>** Overview page.

3. In the **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>** section of the **<UI-TERM key="ocp-v2.Alarm.LogFilter.Cluster">Cluster</UI-TERM>** Overview page, click the name of the cluster that you want to manage.

4. In the left-side navigation pane of the page that appears, click **<UI-TERM key="ocp-v2.page.Iframe.ParameterManagement">Parameter Management</UI-TERM>** .

5. Click the **<UI-TERM key="ocp-v2.Detail.Parameter.ModifyHistory">Change History</UI-TERM>** tab.

6. You can filter data by specifying **<UI-TERM key="ocp-v2.Detail.Parameter.History.ModificationDate">Date of Modification</UI-TERM>** or **<UI-TERM key="ocp-v2.Detail.Parameter.History.Parameter">Parameter Name</UI-TERM>**.

   In the **<UI-TERM key="ocp-v2.Detail.Parameter.History.Parameter">Parameter Name</UI-TERM>** field, you can enter a keyword to search for parameters that meet specific conditions.

   ![10281420](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E4%BF%AE%E6%94%B9%E5%8E%86%E5%8F%B22.png)

7. In the search result, view the history of parameter changes.
