# Modify parameters

You can modify the values and effective scopes of cluster or tenant parameters as needed.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** permission
* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.page.Iframe.ParameterManagement">Parameter Management</UI-TERM>** menu of **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>**

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** to go to the **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** page.

3. In the **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** list, find the target cluster and click its name.

4. In the left-side navigation pane of the page that appears, click **<UI-TERM key="ocp-v2.Detail.Parameter.ParameterManagement">Parameter Management</UI-TERM>**.

5. Optional. In the search box of the **<UI-TERM key="ocp-v2.page.Property.ParameterList">Parameters</UI-TERM>** page, enter a parameter name to perform a fuzzy search.

   ![Image 107](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/420-en/%E5%8F%82%E6%95%B0%E5%88%97%E8%A1%A8.png)

6. Find the parameter to be modified and click **<UI-TERM key="ocp-v2.Detail.Parameter.List.ModifyTheValue">Change Value</UI-TERM>** in the **<UI-TERM key="ocp-v2.component.CardAbnormalTable.Operation">Actions</UI-TERM>** column.

7. In the dialog box that appears, modify the parameter value, effective scope, and effective objects. Then, click **<UI-TERM key="ocp-v2.Alarm.Template.New.Ok">OK</UI-TERM>**. The following figure shows how to modify a parameter whose effective scope is Cluster.

   ![Image 108](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/420-en/%E4%BF%AE%E6%94%B9%E5%8F%82%E6%95%B0%E5%80%BC.png)

   The effective scope varies with parameters. Therefore, you must select the effective scope when you modify the parameter value.

   * When the effective scope is **<UI-TERM key="ocp-v2.component.ModifyClusterParameterDrawer.Cluster">Cluster</UI-TERM>** or a custom scope, the default effective scope is **<UI-TERM key="ocp-v2.Alarm.LogFilter.Cluster">Cluster</UI-TERM>**. If you need to narrow the effective scope down to Zone or OBServer, select **<UI-TERM key="ocp-performance-report.ReportTables.BasicInfo.ServerInfoServerTable.Zone">Zone</UI-TERM>** or **OBServer** from the **<UI-TERM key="ocp-v2.component.ModifyClusterParameterDrawer.EffectiveRange">Effective Scope</UI-TERM>** drop-down list. Select effective objects. The modified value takes effect on the specified effective objects.

   * When the effective scope is **<UI-TERM key="ocp-v2.Cluster.Component.TakeOverArbitrationDrawer.Tenant">Tenant</UI-TERM>**, you can select specific tenants from the **<UI-TERM key="ocp-v2.component.ModifyClusterParameterDrawer.EffectiveObject">Effective Object</UI-TERM>** drop-down list, or select **<UI-TERM key="ocp-v2.alarm.FormListWithExclude.OBServerWithExclude.All">All</UI-TERM>** to select all tenants. The modified value takes effect on the specified effective objects.

   If you want to specify different parameter values in different scopes, for example, you want the value of **backup_concurrency** to be **10** in **Zone 1**, **12** in **Zone 2**, and `20` on **Server 1**, you can click **<UI-TERM key="ocp-v2.component.ModifyClusterParameterDrawer.AddValue">Add Value</UI-TERM>** to add three record rows, and then select the corresponding effective scope in each row.

    <main id="notice" type='explain'>
    <h4>Note</h4>
    <p><ul><li>If multiple rows of values are displayed after you click <strong>Add Value</strong>, modify the parameter values from the top down. For each successful modification operation, a record is generated on the <strong>Change History</strong> tab. </li><li>You must specify a unit for capacity-related parameters. Otherwise, the parameter configuration will fail. </li></ul></p>
