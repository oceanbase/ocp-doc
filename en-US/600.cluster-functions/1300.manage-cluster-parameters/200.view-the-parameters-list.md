# View parameters

On the Parameters page, you can view the name, category, value type, value range, default value, current value, and description of each parameter of the cluster, and check whether the parameter is read-only and whether a restart is required for a parameter setting to take effect.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** permission
* **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.util.menu.MergeManagement">Compaction Management</UI-TERM>** menu of **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>**

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console.

   The **<UI-TERM key="ocp-v2.Detail.Overview.ClusterOverview">Cluster Overview</UI-TERM>** page automatically appears.

2. In the **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** list, find the target cluster and click its name.

3. In the left-side navigation pane of the page that appears, click **<UI-TERM key="ocp-v2.page.Iframe.ParameterManagement">Parameter Management</UI-TERM>** .

   The **<UI-TERM key="ocp-v2.MultiAzone.Parameter.ParameterList">Parameters</UI-TERM>** page automatically appears. You can also click the **<UI-TERM key="ocp-v2.component.OperationConfig.Parameter.ParameterList">Parameters</UI-TERM>** tab to go to this page.

   You can view all parameters of the current cluster on the **<UI-TERM key="ocp-v2.page.MultiAzone.ParameterList">Parameters</UI-TERM>** page. Click **<UI-TERM key="ocp-v2.Detail.Parameter.List.ViewOnlyModifiedParameters">View Only Modified Parameters</UI-TERM>**, you can view the modified parameter list in OCP.
