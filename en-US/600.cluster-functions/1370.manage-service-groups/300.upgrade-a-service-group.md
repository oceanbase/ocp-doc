# Upgrade an arbitration service group

This topic describes how to upgrade an arbitration service group. The arbitration service stops during the upgrade. If you forcibly start it, the high availability of the associated clusters may be affected. Proceed with caution.

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OceanBase Cloud Platform (OCP) Enterprise Edition. OCP Community Edition does not support this feature. </p>
</main>

## Prerequisites

* Make sure that you have the following permissions:

  * Resource permissions: **Arbitration service maintenance** permission.
  * Menu permissions: Permission on the **Overview** menu of clusters.

* The arbitration service group is in the **Running** state.
* Log streams of the tenants associated with the arbitration service group are not downgraded.
* If the arbitration service group is associated with an OceanBase cluster, the level-1 and level-2 version numbers of the OceanBase cluster  are the same as those of the arbitration service group after the upgrade. For example, the version numbers of both the OceanBase cluster and the arbitration service group are V4.2.x.x.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **Clusters**. On the page that appears, click the **Arbitration Service** tab.

3. Click the **Service Group** tab to view the list of arbitration service groups.

4. Find the arbitration service group that you want to upgrade, and click **Upgrade** in the **Actions** column.

5. In the dialog box that appears, confirm the information and select the software package of the target version. If no version is available, click **Upload Package**. In the dialog box that appears, upload the package of the required version.

6. Click **Upgrade**.

    <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>You can select only the software package of a version later than the current version, and the CPU architecture of the version must be the same as the hardware architecture of the current service group. </p>
    </main>
