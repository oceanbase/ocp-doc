# Initialize system parameters

After OCP is installed, you need to confirm and modify the following system parameters:

|  Parameter name        |   Description    |     Initial value   | Is it supported to modify it on the GUI?  |
|----------------|-----------|-------------|-------------------|
| **server.port**     | The port number for the application server. It takes effect after OCP-Server is restarted.  | 8080    | No |
| **ocp.site.url**    | The URL for external access to the OCP website. The OCP-managed host must be able to access ocp-server through this URL. The URL must start with HTTP (HTTPS is not supported), contain the VIP address, domain name, or port, and not end with a slash (/). | `http://localhost:8080` | Yes |
| **ocp.config-url.site.url**   | The URL for external access to the OCP config url service. The default value is empty, indicating that the value of `ocp.site.url` is used. If the config url service is deployed separately, you must configure a value different from `ocp.site.url`.   | Default value is empty   | Yes |

For parameters that support GUI modification, you can refer to [Modify system parameters](../../../../../1600.system-management-features/500.manage-system-parameter/200.modify-system-parameters.md) for details.

<main id="notice" type='explain'>
<h4>Note</h4>
<ul>
<li>In the Docker image installation scenario, the system automatically provides an OBProxy for OCP to manage the OceanBase cluster. Therefore, you do not need to modify the <code>ocp.system.obproxy.address</code> and <code>ocp.system.obproxy.port</code> parameters. If you do not want to use the built-in OBProxy, you can specify the required OBProxy cluster by setting these parameters. </li>
<li>In the RPM installation scenario, you must manually install an OBProxy for OCP to manage the OceanBase cluster and modify the <code>ocp.system.obproxy.address</code> and <code>ocp.system.obproxy.port</code> parameters. </li>
</ul>
</main>

If you did not connect to the OceanBase cluster where MetaDB is located through a load balancer during the initialization of MetaDB, the automatically generated MonitorDB connection parameters are direct connections to OceanBase. If you want to modify the connection to MonitorDB to use a load balancer (DNS or VIP address), you need to modify the following load balancing-related parameters:

|      Parameter name       |     Description     |   Is it supported to modify it on the GUI?  |
|--------------------|----------------|----------------|
| ocp.monitordb.host | The URL for connecting to MonitorDB |   No    |
| ocp.monitordb.port | The port number for connecting to MonitorDB |   No    |
