# OCP Service Health Monitoring
When an OCP port is still listening but the service is abnormal, you can log in to the OCP console via web, but after entering the username and password, you cannot log in. Therefore, it is necessary to monitor the health of OCP to prevent requests from being sent to an abnormal OCP node via F5.

## Procedure

1. Add an alert rule in **Local Traffic\>Monitors\>add**.
* **Send String:** `GET /api/status HTTP/1.1\r\nConnection: Close\r\nHost: \r\n\r\n`

* **Receive String**: okay

   2. In **Local Traffic\>Monitors**, go to the alert rule created in step 2, select **Test**, enter the OCP address and port, and click **Test**.

   <!-- ![11151336](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2385987361/p352194.png) -->

   * If the return value is bad, OCP is abnormal.

3. Click **Local Traffic\>Pools**, select the profile created in [Access the OCP Console via F5](../200.f5-ltm-and-alert-configuration/200.added-f5-in-the-ocp-console.md), and modify the health monitors here to the monitoring rule created in step 1.

   <!-- ![11151342](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3385987361/p352196.png) -->

   3. Click **Local Traffic\>Pools**, and select [OCP Console Access F5](../200.f5-ltm-and-alert-configuration/200.added-f5-in-the-ocp-console.md) to create a profile, modify the health monitors here to the monitoring rules created in Step 1.

   <!-- ![11151343](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3385987361/p352198.png) -->

3. Click **Local Traffic\>Pools**, and select [OCP Console Access F5](../200.f5-ltm-and-alert-configuration/200.added-f5-in-the-ocp-console.md) to create a profile, modify the health monitors here with the monitoring rules created in Step 1.
