# Product Updates

## OCP V4.3.6 BP1

The core objective of OCP V4.3.6 BP1 is to officially support OceanBase Database Enterprise Edition (standalone edition). This release includes features such as license management, scalability from standalone to distributed clusters, and version upgrades for standalone editions, providing comprehensive O&M support for standalone enterprise scenarios.

### New features

* OceanBase Database Enterprise Edition (standalone edition) now supports license viewing, import, and alerts for license expiration and nearing expiration.
* Supports upgrading OceanBase Database Enterprise Edition (standalone edition) to a distributed cluster.
* Supports upgrading OceanBase Database Enterprise Edition (standalone edition) to a higher database version.

### Product enhancements

* By default, cluster cgroup configuration is disabled when the host operating system kernel version is below 5.1.0.
* If the OBProxy version is below V4.3.1, it cannot be hot-upgraded to V4.3.4.
* When an alert has no specific alert target, automatic resolution can be disabled to prevent the alert from automatically resolving.
* Restricts O&M operations in standalone scenarios, such as not supporting restarting OBServer nodes or stopping zones.

## OCP V4.3.6

OCP V4.3.6 is released! This release focuses on **intelligent operations**, **security enhancements**, and **core capability upgrades** to comprehensively empower enterprise database operations and maintenance.

* **Intelligent O&M Assistant**: OceanBase AI Assistant is newly introduced, integrating large language models with native database capabilities to provide intelligent Q&A services across the OceanBase ecosystem. This enables efficient and precise resolution of operational issues.
* **Enhanced Security Features**: New features include OceanBase Transparent Data Encryption (TDE) and end-to-end SSL encryption, providing comprehensive protection for data from storage to transmission, thereby strengthening the security of the database.
* **IPv6 Support**: Supports IPv6 deployment scenarios and provides full lifecycle management for OceanBase clusters with IPv6 addresses, meeting compliance requirements and supporting network evolution.
* **30+ Feature Enhancements**: Core modules such as performance monitoring, primary/standby management, backup and restore, alert center, and inspection services have been deeply optimized to significantly improve operational convenience and management efficiency, helping users easily manage database operations.

### New features

#### Basic O&M

* **Cluster management**: Supports Internet Protocol version 6 (IPv6) and allows you to manage IPv6 addresses within the cluster. Seamlessly adapts to IPv6 network environments to meet strict cybersecurity regulatory requirements in industries such as government and finance.
  * Supported OceanBase versions: [V4.2.5 BP3 Hotfix3, V4.3.0) and [4.3.5 BP2 Hotfix1, +∞)
  * Supported OBClient versions: [V2.2.9, +∞)
  * Supported OBProxy versions: [V4.3.4, +∞)
* **Cluster management**: Supports Transparent Data Encryption (TDE) for secure data encryption, preventing attackers from bypassing the database and accessing sensitive information directly from the storage layer. Supported OceanBase versions: [V4.0.0, +∞)
* **Cluster management**: Supports TCP and RPC-based SSL encryption to prevent data tampering during communication, enhancing system security. Supported OceanBase versions: [V4.0.0, +∞)
* **OBProxy**: Supports TCP and RPC-based SSL encryption to prevent data tampering during communication, enhancing system security. Supported OBProxy versions: [V2.0.0, +∞)
* **Tenant management**: Supports batch locking and unlocking of regular users to improve user O&M efficiency in scenarios such as data migration and import/export.
* **Tenant management**: Supports creating a standby tenant by copying the backup set of the primary tenant, enhancing disaster recovery management solutions.
* **Host management**: Supports management of regions, IDCs, and host types, but objects with associated hosts cannot be deleted.

#### Monitoring and alerts

* Supports displaying the maximum value (max), average value (avg), and current value (current) of monitoring metrics within the specified monitoring period.
* Supports adding monitoring items such as Commit and Rollback to QPS and response time. Supported OceanBase versions: [V4.2.5 BP3, V4.3.0) and [V4.3.5 BP2, +∞)
* Supports hardware monitoring through queries on `/var/log/messages` to help users promptly detect hardware-related issues.

#### Inspection service

Supports inspection of clock source settings for OBServer nodes within the same cluster to prevent abnormal major compactions caused by inconsistent clock source settings.

#### Binlog management

* Allows you to set the number of instance replicas when enabling the Binlog service. The Binlog service automatically distributes instance replicas based on the number of Binlog servers in the cluster.
* Supports adding instance replicas for Binlog instances. A single business tenant can have a maximum of five instance replicas.
* Supports managing standby Binlog instances, including starting, stopping, throttling, restarting, deleting, and switching the primary instance.
* Supports deleting the primary Binlog instance.
* Prevents accidental operations on the MetaDB of the Binlog service by displaying a prompt, avoiding service disruptions.

#### Backup and restore

* Supports setting backup attributes such as Zone, Region, and IDC to reduce cross-region network traffic in multi-region and multi-IDC deployment scenarios, improving backup speed.
* Supports setting the Zone priority to Random when restoring a tenant.

#### Platform features

* **AI assistant**: Provides intelligent Q&A services for OceanBase and its related products based on Large Language Models (LLMs) + PowerRAG + built-in OceanBase knowledge base.
* **O&M management**: The report center supports creating and downloading resource information reports for OceanBase clusters, tenants, OBProxy clusters, hosts, and Binlog services, and supports modifying the report retention period through the `ocp.report.center.report.retention.days` parameter.
* **Parameter templates**: Supports importing and exporting parameter templates in YAML format for OceanBase clusters, tenants, OBProxy clusters, and Binlog services.
* **Cluster management** > **O&M configuration**: Adds five new collection metric switches to control whether to collect information such as Wait event, cache hit rate, and partition count.

### Feature enhancements

#### Cluster management

* Only clusters in the Stopped, Unavailable, Deprecated, or Migrated state support direct deletion.
* In scenarios where units are to be migrated, support pre-checks for CPU, memory, log disk, and data disk resources to avoid migration issues due to insufficient resources.
* You can enable or disable cgroups without restarting the cluster. Supported OceanBase versions: [V4.2.5 BP2, V4.3.0) and [V4.3.5, +∞).

#### Tenant management

* The major compaction management feature supports displaying monitoring metrics such as MEMStore usage rate, MEMStore usage size, CPU usage rate, and memory usage rate on a per-unit basis, helping you observe resource consumption during major compactions.
* Optimized statistics management attributes, with updated data statistics logic for the **Top 10 Changed Tables** feature. Supported OceanBase versions: [V4.2.5 BP2, V4.3.0) and [V4.3.5, +∞).
* Direct deletion is only allowed for locked primary tenants, with a state validation mechanism to prevent accidental operations.
* When creating users, support grouping permissions by type, such as general and administrator, to help you quickly create database users.
* Support batch setting of role permissions for Oracle tenants.

#### OBProxy management

Direct deletion is only allowed for primary clusters in the Stopped, Unavailable, or Empty state to prevent accidental operations.

#### Other enhancements

* **Platform features**: Support setting the password validity period and password reuse count for users through the system parameters `ocp.iam.password.validity.period.days` and `ocp.iam.password.reuse.times` to ensure password security.
* **Platform features**: Support customizing the installation directory for ocp_agent through the system parameter `ocp.agent.home.path.prefix` on Debian 11 and later operating systems.
* **<UI-TERM key="ocp-v2.page.Alarm.Alarm">Alert Center</UI-TERM>**: Support displaying monitoring metrics data during alert recovery in the alert recovery details.
* **<UI-TERM key="ocp-v2.src.hook.useMenu.AlarmCenter">Alert Center</UI-TERM>**: Support clicking on an alert rule on the alert details page to navigate to a new page.

### Feature changes

The management of hosts and the takeover of clusters no longer supports container-type hosts.

### Key feature insights

#### AI assistant (Experimental)

OceanBase AI assistant leverages deep integration with large language models (LLMs) and PowerRAG (retrieval-augmented generation), while also incorporating OceanBase's built-in knowledge base and native vector and full-text indexing capabilities. This creates a core engine for intelligent Q&A. The multi-round retrieval mechanism of PowerRAG allows the LLM to accurately access technical documents, best practices, and case studies from the knowledge base, providing systematic and professional solutions for key database operations such as system configuration optimization, fault diagnosis and repair, and performance bottleneck analysis.

In terms of large model configuration, OCP allows you to flexibly integrate third-party large model services such as Tongyi Qianwen, Doupai, and DeepSeek, or deploy a self-built large model through the **System Management** > **External Integration** > **AI Model** module. You can configure LLM, embedding, and reranking models (optional) to quickly activate the AI assistant feature. Additionally, OCP supports importing enterprise-specific best practices and standard operating procedures (SOPs) to continuously expand the adaptability of the knowledge base.

#### Secure Sockets Layer (SSL) encryption

In the era of accelerated digital transformation, data transmission security has become a core requirement. OBProxy and OceanBase Database support SSL encryption, which establishes an encrypted communication channel at the transport layer to provide end-to-end protection for network connections. This effectively mitigates the risks of data theft and tampering, ensuring the confidentiality and integrity of communication. This forms the foundation of data transmission security.

As the central hub for end-to-end operations, OCP provides comprehensive management of the certificate lifecycle:

* **Convenient certificate operations**: Supports one-click certificate upload and deletion, simplifying certificate management.
* **Deep security configuration**: Integrates SSL encryption configuration for OBProxy and OceanBase, allowing you to customize certificate update strategies to ensure the ongoing validity of encrypted connections.
* **Multi-format certificate support**: Provides standard format certificates such as p7b/PEM/JKS for business applications, meeting diverse technical stack security access requirements.

Through OCP's unified management, users can easily deploy and monitor secure communication from business applications > OBProxy > OBServer and secure RPC communication between OBServer nodes. This ensures secure data transmission at critical stages such as business access, proxy forwarding, and node interaction, building a comprehensive security barrier for stable database operation.

<main id="notice" type='notice'>
<h4>Notice</h4>
<p><li>After enabling SSL encryption, instance performance will slightly degrade (certificate encryption/decryption consumes computing resources). We recommend enabling instance-level SSL encryption only when transmission encryption is required.</li>
<li>If you enable SSL encryption within the same cluster, ensure that the root certificate <code>ca.pem</code> for OceanBase and OBProxy in the cluster is consistent.</li>
<li>The supported OceanBase version range is [V4.0.0, +∞).</li></p>
