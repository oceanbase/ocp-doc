# How can I locate slow SQL statements that take a long time in a tenant?

Slow SQL statements cause poor user experience and consume a large amount of database resources, resulting in database instability. Therefore, the number of slow SQL statements must be reduced in various dimensions.
For example, to locate SQL statements that take more than 100 ms, you can click **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.ColumnManager.ColumnManagement">Column Management</UI-TERM>** on the **TopSQL** or **SlowSQL** tab, and select **<UI-TERM key="ocp-v2.SQLDiagnosis.Outline.MaximumResponseTime">Maximum Response Time</UI-TERM>**. Then enter **Maximum Response Time >= 100ms** in **<UI-TERM key="ocp-v2.Detail.SQLDiagnosis.AdvancedConditions">Conditions</UI-TERM>** and click **<UI-TERM key="ocp-v2.Detail.Parameter.History.Query">Search</UI-TERM>**.
