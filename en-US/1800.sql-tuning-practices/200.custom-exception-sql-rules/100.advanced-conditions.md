# Conditions

The **<UI-TERM key="ocp-v2.Detail.SQLDiagnosis.AdvancedConditions">Conditions</UI-TERM>** field of SQL diagnostics supports six operators for filtering metrics provided in **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.ColumnManager.ColumnManagement">Column Management</UI-TERM>**. You can search for abnormal SQL statements by specifying multiple conditions in the **<UI-TERM key="ocp-v2.Detail.SQLDiagnosis.AdvancedConditions">Conditions</UI-TERM>** field.

For example, if you want to locate SQL statements that involve multi-partition scans and whose average response time exceeds 100 ms, you can specify the following conditions in the **<UI-TERM key="ocp-v2.Detail.SQLDiagnosis.AdvancedConditions">Conditions</UI-TERM>** field:

* **Average Response Time >= 100**
* **Proportion of Distributed Plans > 0**

![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E9%AB%98%E7%BA%A7%E6%9D%A1%E4%BB%B6-1.png)

You can further add conditions based on the preceding conditions. For example, if you want to search for SQL statements that involve multi-partition scans and whose average response time exceeds 100 ms and parsing time (corresponding to **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.RecordTable.PlanGenerationTime">Plan Generation Time</UI-TERM>** in **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.ColumnManager.ColumnManagement">Column Management</UI-TERM>**) exceeds 10 ms, you can add the conditions shown in the following figure.

![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E9%AB%98%E7%BA%A7%E6%9D%A1%E4%BB%B6%E5%A2%9E%E5%8A%A0-1.png)

You can select multiple metrics in **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.ColumnManager.ColumnManagement">Column Management</UI-TERM>** to search for SQL statements based on your requirements in different scenarios.
