# Enable/Disable an SSO integration task

OceanBase Cloud Platform (OCP) allows you to enable only one single sign-on (SSO) integration task. If multiple SSO integration tasks are created, you can enable or disable an SSO integration task to change the third-party logon mode.

## Prerequisites

You have logged in to the OceanBase Cloud Platform (OCP) console and been assigned the **ADMIN** role.

## Procedure

1. Log on to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.ExternalIntegration">External Integration</UI-TERM>**, and click the **SSO Integration** tab.

3. Find the SSO integration task to be enabled or disabled, and then turn on or off the switch in the **<UI-TERM key="ocp-v2.Inspection.Item.ConfigItem.Enable">Enable</UI-TERM>** column.

4. In the dialog box that appears, click **<UI-TERM key="ocp-v2.Detail.ResourceManager.CreateResourcePlan.Ok">OK</UI-TERM>**.
