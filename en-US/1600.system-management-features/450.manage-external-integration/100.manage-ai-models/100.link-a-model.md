# Connect to an AI model vendor

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OCP Enterprise Edition. OCP Community Edition does not support this feature. </p>
</main>

An AI model vendor is an important infrastructure for creating AI search features. After you integrate mainstream AI services with OCP, the content that you enter is sent to the selected third-party large language model vendor for generating service results when the service is called, and the results are returned to the OCP platform after processing.

Before you use AI intelligent chat, you must select an AI model vendor and connect it to OCP. OCP provides **Tongyi Qianwen**, **Doubao**, and **DeepSeek** as the AI model vendors. If you want to use other vendors, see [Add a model](200.add-a-model.md).

## Prerequisites

* The login user is the **ADMIN** role.
* You have obtained the API-Key of the target AI model vendor.
* The connection status of the target AI model vendor is **Not Connected**.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.page.External.ExternalIntegration">External Integration</UI-TERM>**. The **AI Model** page automatically appears.

3. In the **<UI-TERM key="ocp-v2.AIModel.Component.AiModelDetailDrawer.ModelManufacturer">Model Vendor</UI-TERM>** section, select an AI model vendor and click **<UI-TERM key="ocp-v2.AIModel.Component.LinkAiModel.Connection">Connect</UI-TERM>** on the card.

4. In the dialog box that appears, specify the **API-KEY** and **<UI-TERM key="ocp-v2.Arbitration.ArbitrationGroup.Remarks">Remarks</UI-TERM>**.

5. Click **<UI-TERM key="ocp-v2.AIModel.Component.LinkAiModel.Connection">Connect</UI-TERM>**.

6. After the connection is successful, the connection status of the model vendor changes to **<UI-TERM key="ocp-v2.External.AIModel.Connected">Connected</UI-TERM>**.

## What to do next

* **View an AI model vendor**: Click the card of an AI model vendor to view the model information in the right-side panel.

* **Modify an AI model vendor**: After an AI model vendor is connected, the **<UI-TERM key="ocp-v2.AIModel.Component.LinkAiModel.Connection">Connect</UI-TERM>** button on the card changes to **<UI-TERM key="ocp-v2.AIModel.Component.LinkAiModel.Modification">Modify</UI-TERM>**. When the API-Key or remarks of the model vendor need to be modified, you can click **<UI-TERM key="ocp-v2.page.MultiCluster.Parameter.Modify">Modify</UI-TERM>** to update the information.

  * If the API key is empty, the API key information is not modified.
  * After the information is modified, all available models of the vendor are reloaded to OCP.
