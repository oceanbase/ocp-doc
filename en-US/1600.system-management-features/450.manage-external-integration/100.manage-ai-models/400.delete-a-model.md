# Delete a model

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OCP Enterprise Edition. OCP Community Edition does not support this feature. </p>
</main>

This topic describes how to delete a model. For a model vendor that you added manually, if all the models under the vendor are deleted, the vendor card is removed from the system. The system retains the built-in vendor cards.

## Prerequisites

* You are logged in to OCP as the **ADMIN** user.
* You cannot delete a model that is in use. If you want to delete a model, you must change the current model first. For more information, see [Set a system model](300.set-system-model.md).

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.page.External.ExternalIntegration">External Integration</UI-TERM>**. The **AI Models** page automatically appears.

3. In the **<UI-TERM key="ocp-v2.AIModel.Component.AiModelDetailDrawer.ModelManufacturer">Model Vendor</UI-TERM>** section, click the vendor card to view all the models under the vendor in the right-side panel.

4. Select the model that you want to delete and click **<UI-TERM key="ocp-v2.Component.OBServerList.Delete">Delete</UI-TERM>** in the Actions column.

5. If you want to add the model to OCP again, you must refer to [Add a model](200.add-a-model.md).
