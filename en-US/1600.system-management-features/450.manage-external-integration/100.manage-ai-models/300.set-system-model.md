# Set a system model

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OCP Enterprise Edition. OCP Community Edition does not support this feature. </p>
</main>

After you connect an AI model vendor, you need to select a model from the connected or added vendors to use as the system model. This process is called setting a system model. After you set a system model, the system will refresh the OCP knowledge base based on the selected model, and then you can enable intelligent conversation.

If you have set a system model before, it will be replaced with the latest setting after you re-set it.

## Prerequisites

* You are logged in to OCP as a user with the **ADMIN** role.
* You have connected the target model vendor by referring to [Connect an AI model vendor](100.link-a-model.md), or you have added the required model by referring to [Add a model](200.add-a-model.md).

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.page.External.ExternalIntegration">External Integration</UI-TERM>**. The **AI Models** tab appears.

3. In the **<UI-TERM key="ocp-v2.AIModel.Component.ChatModelSelect.CurrentUse">In Use</UI-TERM>** section, click **<UI-TERM key="ocp-v2.AIModel.Component.SetSystemModel.Setup">Set</UI-TERM>**.

4. In the dialog box that appears, select a model.

    |  Parameter      |  Description   |
    |------------|---------|
    | Chat Model   | A model that learns language patterns and rules through pre-training on large-scale text data, and thus has general language understanding and generation capabilities.   |
    | Embedding Model   | A model that focuses on converting text into fixed-length vectors, which retain the semantic information of the data for subsequent similarity calculations and classification tasks.   |
    | Rerank Model (Optional)   | A model that re-ranks the initial search results to improve the accuracy of the search system. These models typically optimize the search results by combining context information and user intent, providing more relevant results.    |

5. Click **<UI-TERM key="ocp-v2.AIModel.Component.SetSystemModel.Setup">Set</UI-TERM>**.
