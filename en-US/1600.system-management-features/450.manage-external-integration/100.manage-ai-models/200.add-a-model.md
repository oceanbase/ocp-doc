# Add a model

When the built-in models of the system cannot meet your needs, you can manually add the required models.

## Prerequisites

* Make sure that the current login user in the OCP console is the **ADMIN** role.
* OCP only supports models compatible with the OpenAI API format.
* You have obtained the base URL and API key of the target model vendor.
* If you add a model of an existing vendor, the model status of the vendor must be **Connected**.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.page.External.ExternalIntegration">External Integration</UI-TERM>**. The **AI Models** page automatically appears.

3. In the **<UI-TERM key="ocp-v2.AIModel.Component.AiModelDetailDrawer.ModelManufacturer">Model Vendor</UI-TERM>** section, click **<UI-TERM key="ocp-v2.alarm.ExpressionFormList.SingleExpressionFormList.Add">Add</UI-TERM>**.

4. In the right-side panel, specify the model information.

    |  Parameter      |  Description   |
    |------------|---------|
    | Large Model Manufacturer | Select the large model manufacturer. Valid values: **<UI-TERM key="ocp-v2.AIModel.Component.AddAiModelDrawer.ThereAreManufacturers">Existing Vendors</UI-TERM>** and **<UI-TERM key="ocp-v2.Alarm.Template.Custom">Custom</UI-TERM>**.<ul><li>Existing Manufacturer: specifies a model of an existing large model manufacturer.</li><li>Custom: specifies a model of a custom large model manufacturer.</li></ul>   |
    | Manufacturer Name   | <ul><li>When **<UI-TERM key="ocp-v2.AIModel.Component.AddAiModelDrawer.LargeModelManufacturers">Model Vendor</UI-TERM>** is set to **<UI-TERM key="ocp-v2.AIModel.Component.AddAiModelDrawer.ThereAreManufacturers">Existing Vendors</UI-TERM>**, specify the name of a specific large model manufacturer.</li><li>When **<UI-TERM key="ocp-v2.AIModel.Component.AddAiModelDrawer.LargeModelManufacturers">Model Vendor</UI-TERM>** is set to **<UI-TERM key="ocp-v2.Plan.Component.PlanTemplateTable.Custom">Custom</UI-TERM>**, specify the name of the large model manufacturer, which must be 2 to 32 characters in length.<main id="notice" type='explain'><h4>Note</h4><p>If the specified manufacturer name already exists in OCP, the new model will be aggregated with the models of the existing manufacturer.</p></main></li></ul>   |
    | Model Type   | Select the model type based on the usage scenario.<ul><li>Chat: a model that is pre-trained on large-scale text data to learn the patterns and rules of language, thereby achieving general language understanding and generation capabilities.</li><li>Embedding: a model that focuses on converting text into a fixed-length vector to retain the semantic information of the data, facilitating subsequent similarity calculations and classification tasks.</li><li>Rerank: a model that re-ranks the initial search results to improve the accuracy of the search system. These models typically optimize the search results by combining context information and user intent, providing more relevant results.</li></ul>    |
    | Model Name   | Specify the model name. The model name must meet the following requirements:<ul><li>The model name must already exist for the large model manufacturer.</li><li>The model name must be unique within the same large model manufacturer.</li><li>The model name must be 2 to 32 characters in length.</li></ul>    |
    | Access Address   | Specify the access address when **<UI-TERM key="ocp-v2.AIModel.Component.AddAiModelDrawer.LargeModelManufacturers">Model Vendor</UI-TERM>** is set to **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.Custom">Custom</UI-TERM>**. Specify the base URL for the large model, such as `https://api.deepseek.com/v1`.   |
    | API Key    | Specify the API key when **<UI-TERM key="ocp-v2.AIModel.Component.AddAiModelDrawer.LargeModelManufacturers">Model Vendor</UI-TERM>** is set to **<UI-TERM key="ocp-v2.alarm.ExpressionFormList.MultipleExpressionFormList.Custom">Custom</UI-TERM>**. Specify the AccessKey Secret (SK) for the large model. The API key is masked by default and can be viewed in plaintext.<br>After you configure **<UI-TERM key="ocp-v2.AIModel.Component.SystemModelDetailDrawer.AccessAddress">Access Address</UI-TERM>** and **API Key**, click **<UI-TERM key="ocp-v2.AIModel.Component.AddAiModelDrawer.Test">Test</UI-TERM>** to verify whether the specified information is correct.   |
    | Remarks       | Specify additional information about the model.   |

5. Click **<UI-TERM key="ocp-v2.Detail.Component.AddArbitrationGroupDrawer.Add">Add</UI-TERM>**.

6. In the dialog box that appears, click **<UI-TERM key="ocp-v2.User.Oracle.UserList.Determine">OK</UI-TERM>**. The model is displayed on the card of the original manufacturer.
