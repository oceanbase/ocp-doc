# Add a model

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OCP Enterprise Edition. OCP Community Edition does not support this feature. </p>
</main>

If the built-in models cannot meet your needs, you can manually add the required models.

## Prerequisites

* Make sure that the current login user in the OCP console is the **ADMIN** role.
* OCP only supports models compatible with the OpenAI API.
* You have obtained the base URL and API key of the target model vendor.
* If you want to add a model from an existing vendor, the model must be in the **Connected** state.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.page.External.ExternalIntegration">External Integration</UI-TERM>**. The **AI Models** page automatically appears.

3. In the **<UI-TERM key="ocp-v2.AIModel.Component.AiModelDetailDrawer.ModelManufacturer">Model Vendor</UI-TERM>** section, click **<UI-TERM key="ocp-v2.component.CreateTagDrawer.Add">Add</UI-TERM>**.

4. In the right-side panel, specify the model information.

    |  Parameter      |  Description   |
    |------------|---------|
    | Large Model Manufacturer | Select the large model manufacturer type. Valid values: **<UI-TERM key="ocp-v2.AIModel.Component.AddAiModelDrawer.ThereAreManufacturers">Existing Vendors</UI-TERM>** and **<UI-TERM key="ocp-v2.alarm.ExpressionFormList.MultipleExpressionFormList.Custom">Custom</UI-TERM>**.<ul><li>Existing Manufacturer: specifies a model of an existing large model manufacturer. </li><li>Custom: specifies a model of a custom large model manufacturer. </li></ul>   |
    | Manufacturer Name   | <ul><li>When **<UI-TERM key="ocp-v2.AIModel.Component.AddAiModelDrawer.LargeModelManufacturers">Model Vendor</UI-TERM>** is set to **<UI-TERM key="ocp-v2.AIModel.Component.AddAiModelDrawer.ThereAreManufacturers">Existing Vendors</UI-TERM>**, select a large model manufacturer. </li><li>When **<UI-TERM key="ocp-v2.AIModel.Component.AddAiModelDrawer.LargeModelManufacturers">Model Vendor</UI-TERM>** is set to **<UI-TERM key="ocp-v2.alarm.ExpressionFormList.MultipleExpressionFormList.Custom">Custom</UI-TERM>**, enter the name of the large model manufacturer. The name must be 2 to 32 characters in length. <main id="notice" type='explain'><h4>Note</h4><p>If the manufacturer name already exists in OCP, the new model will be aggregated with the models of this manufacturer. </p></main></li></ul>   |
    | Model Type   | Select the model type based on the use case.<ul><li>Chat: a model that is pre-trained on large-scale text data to learn language patterns and achieve general language understanding and generation. </li><li>Embed: a model that focuses on converting text into fixed-length vectors to retain the semantic information of the data, facilitating subsequent similarity calculations and classification tasks. </li><li>Rerank: a model that re-ranks the initial search results to improve the accuracy of the search system. These models typically combine context information and user intent to optimize the search results. </li></ul>    |
    | Model Name   | Enter the name of the model. The name must meet the following requirements: <ul><li>The name must be an actual existing model name of the large model manufacturer. </li><li>The model name must be unique within the same large model manufacturer. </li><li>The name must be 2 to 32 characters in length. </li></ul>    |
    | Access URL   | Enter the Base URL of the large model when **<UI-TERM key="ocp-v2.AIModel.Component.AddAiModelDrawer.LargeModelManufacturers">Model Vendor</UI-TERM>** is set to **<UI-TERM key="ocp-v2.AIModel.Component.AddAiModelDrawer.Custom">Custom</UI-TERM>**. For example, `https://api.deepseek.com/v1`.   |
    | API Key    | Enter the AccessKey Secret (SK) of the large model when **<UI-TERM key="ocp-v2.AIModel.Component.AddAiModelDrawer.LargeModelManufacturers">Model Vendor</UI-TERM>** is set to **<UI-TERM key="ocp-v2.Plan.Component.PlanTemplateTable.Custom">Custom</UI-TERM>**. The API key is masked by default, and you can view the plain text. <br>After you configure **<UI-TERM key="ocp-v2.Cluster.Import.Address">Access Address</UI-TERM>** and **API Key**, click **<UI-TERM key="ocp-v2.Component.StorageConfigCard.Test">Test</UI-TERM>** to verify whether the information is correct.   |
    | Remarks       | Enter additional information about the model.   |

5. Click **<UI-TERM key="ocp-v2.Component.SQLCondition.Add">Add</UI-TERM>**.

6. In the dialog box that appears, click **<UI-TERM key="ocp-v2.Component.ClusterFilter.Ok">OK</UI-TERM>**. The model is displayed on the card of the original manufacturer.
