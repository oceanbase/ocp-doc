# Delete an SSO integration task

If the configurations of an single sign-on (SSO) integration task are no longer suitable for your business scenario, you can delete the SSO integration task.

## Prerequisites

You have logged in to the OceanBase Cloud Platform (OCP) console and been assigned the **ADMIN** role.

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.page.External.ExternalIntegration">External Integration</UI-TERM>**, and click the **SSO Integration** tab.

3. Find the SSO integration task to be deleted and click **<UI-TERM key="ocp-v2.page.Package.Delete">Delete</UI-TERM>** in the **<UI-TERM key="ocp-v2.page.Host.Operation">Actions</UI-TERM>** column.

4. In the dialog box that appears, click **<UI-TERM key="ocp-v2.Component.ServiceName.ServiceNameModal.Ok">OK</UI-TERM>**.
