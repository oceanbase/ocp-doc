# View system parameters

In OCP, system parameters are generally used to configure features, such as account logon and backup and recovery. This topic describes how to view and modify system parameters.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only**, **Tenant Read-only**, **OBProxy Read-only**, **Arbitration Service Read-only**, **Binlog Service Read-only**, or **Host Read-only** permission
* **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.page.Property.SystemParameters">System Parameters</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>**

## Procedure

1. Log on to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** \> **<UI-TERM key="ocp-v2.src.util.menu.SystemParameters">System Parameters</UI-TERM>**.

   By default, the **<UI-TERM key="ocp-v2.page.MultiCluster.Parameter.ParameterList">Parameters</UI-TERM>** list displays all the modifiable parameters.

   You can use the page control in the lower-right corner of the list to go to another page or change the number of parameters displayed on a page.

   ![07021722](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E5%8F%82%E6%95%B0%E5%88%97%E8%A1%A8-1.png)

3. Enter a keyword in the search box in the upper-right corner of the **<UI-TERM key="ocp-v2.MultiAzone.Parameter.ParameterList">Parameters</UI-TERM>** list and click **<UI-TERM key="ocp-v2.page.QueryLog.Query">Search</UI-TERM>**.

   The system parameters whose names match the keyword are displayed in the **<UI-TERM key="ocp-v2.component.OperationConfig.Parameter.ParameterList">Parameters</UI-TERM>** list.
