# Modify system parameters

This topic describes how to modify system parameters.

## Background

System parameters in OceanBase Cloud Platform (OCP) control a series of complex configurations, such as backup and restore and the frequency of resource monitoring. We do not recommend that general users modify system parameters.

After you deploy OCP, it sets a default value for these parameters to satisfy day-to-day usage. If you have a particular need, you can ask an admin to modify the related system parameter for you.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance**, **Tenant Maintenance**, **OBProxy Maintenance**, **Arbitration Service Maintenance**, **Binlog Service Maintenance**, or **Host Maintenance** permission
* **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.page.Property.SystemParameters">System Parameters</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>**

## Procedure

1. Log on to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** \> **<UI-TERM key="ocp-v2.src.util.menu.SystemParameters">System Parameters</UI-TERM>**.

   By default, the **<UI-TERM key="ocp-v2.page.Property.ParameterList">Parameters</UI-TERM>** list displays all the modifiable parameters.

3. Enter a keyword in the search box in the upper-right corner of the **<UI-TERM key="ocp-v2.page.MultiCluster.Parameter.ParameterList">Parameters</UI-TERM>** list and click **<UI-TERM key="ocp-v2.Detail.Parameter.History.Query">Search</UI-TERM>**.

   The system parameters whose names match the keyword are displayed in the **<UI-TERM key="ocp-v2.component.OperationConfig.Parameter.ParameterList">Parameters</UI-TERM>** list.

4. Click the Edit icon in the **<UI-TERM key="ocp-v2.page.Property.Value">Parameter Value</UI-TERM>** column of the target parameter.

   The **<UI-TERM key="ocp-v2.component.OperationConfig.ModifyParameterDrawer.ModifyParameterValues">Modify Parameter Value</UI-TERM>** dialog box appears.

5. Enter a new value for the parameter following the description in [OCP configuration parameters](300.ocp-configuration-parameters.md).

   The following describes how to edit parameters of the JSON data type.

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E4%BF%AE%E6%94%B9%E5%8F%82%E6%95%B0%E5%80%BC-1.png)

   * ① Copy to clipboard: Click the icon to copy the parameter content to the clipboard.
   * ② Add a key: Click the icon to add a key to the node.
   * ③ Edit a key: Click the icon to edit a key on the node.
   * ④ Delete a node or a key: Click the delete icon next to a node or key to delete the node or key.

6. Click **<UI-TERM key="ocp-v2.component.ParameterTemplate.ParameterTemplateDropdown.Ok">OK</UI-TERM>**.

   After you modify the parameters, check how the parameters take effect.
   * For parameters that take effect without a restart, the parameter modifications take effect in about 3 minutes.
   * For parameters that take effect upon a restart, you must restart the OCP server for the modifications to take effect.
