# View operation records

On the **<UI-TERM key="ocp-v2.src.hook.useMenu.OperationAudit">Operation Audit</UI-TERM>** page, you can view operation records of different event types in the following columns: **<UI-TERM key="ocp-v2.page.Information.EventType">Event Type</UI-TERM>**, **<UI-TERM key="ocp-v2.page.AuditEvent.EventAction">Event Operation</UI-TERM>**, **<UI-TERM key="ocp-v2.page.AuditEvent.Resource">Resource Name</UI-TERM>**, **<UI-TERM key="ocp-v2.page.AuditEvent.EventInformation">Event Information</UI-TERM>**, **<UI-TERM key="ocp-v2.page.AuditEvent.Operator">Updated By</UI-TERM>**, **<UI-TERM key="ocp-v2.page.AuditEvent.ExecutionTime">Execution Time</UI-TERM>**, and **<UI-TERM key="ocp-v2.page.AuditEvent.ExecutionResult">Execution Result</UI-TERM>**.

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OceanBase Cloud Platform (OCP) Enterprise Edition. OCP Community Edition does not support this feature. </p>
</main>

## Background information

The operation audit feature records key operations performed in the OCP console, including management operations on hosts, OceanBase clusters, the arbitration service, OceanBase Database tenants, OBProxy clusters, the binlog service, backup and restore, software packages, OCP users, OCP clusters, credentials, alerts, inspection, personal information, custom monitoring, monitoring dashboards, system parameters, labels, SQL performance, and organizations. The event information is displayed to facilitate troubleshooting.

## Prerequisites

You have logged in to the OceanBase Cloud Platform (OCP) console and been assigned the **ADMIN** or **ADMIN_VIEWER** role.

## Procedure

1. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** \> **<UI-TERM key="ocp-v2.page.AuditEvent.HistoricalEvents">Operation Audit</UI-TERM>**. The event information page appears.

2. Search for and view operation records.

   1. You can view operation records within a specific period by selecting a period from the drop-down list or specifying a custom period.

   2. You can also enter the name of the event in the search box, click the search icon or press the Enter key, and then check the search results.

3. Filter and view operation records.

   1. Filter by **<UI-TERM key="ocp-v2.Plan.Component.PlanExecuteTable.EventType">Event Type</UI-TERM>**: Click the Filter icon next to **<UI-TERM key="ocp-performance-report.ReportTable.TopWaitEvent.TopWaitEventTable.EventType">Event Type</UI-TERM>**, select one or more types, and then click **<UI-TERM key="ocp-v2.Dashboard.component.ImportDashboardModal.Ok">OK</UI-TERM>**. Supported event types are host management, OceanBase cluster management, arbitration service management, OceanBase Database tenant management, OBProxy cluster management, binlog service management, backup and restore management, software package management, OCP user management, OCP cluster management, credential management, alert management, inspection management, personal information management, custom monitoring management, monitoring dashboard management, system parameter management, label management, SQL performance management, and organization management.

   2. Filter by **<UI-TERM key="ocp-v2.page.AuditEvent.EventAction">Event Operation</UI-TERM>**: Click the Filter icon next to **<UI-TERM key="ocp-v2.page.AuditEvent.EventAction">Event Operation</UI-TERM>**, select one or more operations, and then click **<UI-TERM key="ocp-v2.Detail.ResourceManager.CreateResourcePlan.Ok">OK</UI-TERM>**.

4. To view the event information of a record, click the information in the **<UI-TERM key="ocp-v2.page.AuditEvent.EventInformation">Event Information</UI-TERM>** column or enter a search criterion in the search box in the **<UI-TERM key="ocp-v2.page.AuditEvent.EventInformation">Event Information</UI-TERM>** column, and view details in the dialog box that appears on the right.

   The event information contains the API calling information of the event. The password and other private parameters are desensitized.

5. To view operation records by operator, click the Filter icon next to **<UI-TERM key="ocp-v2.page.AuditEvent.Operator">Updated By</UI-TERM>**, select one or more operators, and then click **<UI-TERM key="ocp-v2.page.Information.Ok">OK</UI-TERM>**.

6. View operation records by time.

   1. To sort operation records by time from the oldest to the newest, click the up-pointing triangle next to **<UI-TERM key="ocp-v2.SQLDiagnosis.attributes.sqlTrendsAttributes.ExecutionTime">Execution Time</UI-TERM>**.

   2. To sort operation records by time from the newest to the oldest, click the down-pointing triangle next to **<UI-TERM key="ocp-v2.page.AuditEvent.ExecutionTime">Execution Time</UI-TERM>**.

7. To view operation records by execution result, click the Filter icon next to **<UI-TERM key="ocp-v2.page.AuditEvent.ExecutionResult">Execution Result</UI-TERM>** and filter the records by the execution result.
