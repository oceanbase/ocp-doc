# Share resource configurations

This topic describes how to share the resource configurations of one organization with another. After you share a resource, both the original and target organizations have permissions on the shared resource.

<main id="notice" type='notice'>
<h4>Notice</h4>
<p>After resource sharing, newly added resources belong to only the original organization and will not be synchronized to the target organization with which the resource is shared. </p>
</main>

## Prerequisites

You have logged in to the OceanBase Cloud Platform (OCP) console and been assigned the **ADMIN** role.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.User.MySQL.UserManagement">User Management</UI-TERM>**.

3. Click **<UI-TERM key="ocp-v2.Auth.Role.AddRole.Organization">Organization</UI-TERM>** to go to the **<UI-TERM key="ocp-v2.page.Settings.Profile.Organization">Organization</UI-TERM>** tab.

4. Find the target organization with which you want to share a resource, click **<UI-TERM key="ocp-v2.Cluster.Component.MachineResource.SeeMore">More</UI-TERM>** in the **<UI-TERM key="ocp-v2.Auth.User.Operation">Actions</UI-TERM>** column, and select **<UI-TERM key="ocp-v2.Auth.Org.SharedResourceConfiguration">Share Resource Configurations</UI-TERM>**.

5. Go to the **<UI-TERM key="ocp-v2.Auth.Org.SharedResourceDrawer.SharedResourceConfiguration">Share Resource Configurations</UI-TERM>** panel.

6. Select at least one type of resource for sharing.

7. Select one or more target organizations for resource shoring.

8. Click **<UI-TERM key="ocp-v2.Detail.Component.DailyChangeTenantModal.Ok">OK</UI-TERM>**.
