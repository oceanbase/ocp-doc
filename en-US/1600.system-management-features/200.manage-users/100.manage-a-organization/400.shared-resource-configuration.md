# Share resource configurations

This topic describes how to share the resource configurations of one organization with another. After you share a resource, both the original and target organizations have permissions on the shared resource.

<main id="notice" type='notice'>
<h4>Notice</h4>
<p>After resource sharing, newly added resources belong to only the original organization and will not be synchronized to the target organization with which the resource is shared. </p>
</main>

## Prerequisites

You have logged in to the OceanBase Cloud Platform (OCP) console and been assigned the **ADMIN** role.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **System Management** > **User Management**.

3. Click **Organization** to go to the **Organization** tab.

4. Find the target organization with which you want to share a resource, click **More** in the **Actions** column, and select **Share Resource Configurations**.

5. Go to the **Share Resource Configurations** panel.

6. Select at least one type of resource for sharing.

7. Select one or more target organizations for resource shoring.

8. Click **OK**.
