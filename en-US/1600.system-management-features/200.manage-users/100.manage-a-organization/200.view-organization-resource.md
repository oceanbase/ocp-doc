# View the resources of an organization

This topic describes how to view the resources of an organization.

## Prerequisites

You have logged in to the OceanBase Cloud Platform (OCP) console and been assigned the **ADMIN** role.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **System Management** > **User Management**.

3. Click **Organization** to go to the **Organization** tab.

   By default, all organizations are displayed. The organizations may be displayed on several pages. You can use the page control feature below the list to go to another page or change the number of organizations that can be displayed on each page.

4. Enter an organization name keyword in the search box and click **Search**.

   The organizations whose names match the keyword are displayed in the organization list.

5. Find the target organization and click **View Resources** in the **Actions** column.

   In the panel on the right side, view the resource information of the organization in the following columns: **Resource**, **Resource Type**, **Organization**, **Created At**, and **Created By**.
