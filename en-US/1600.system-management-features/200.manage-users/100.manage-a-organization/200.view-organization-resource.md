# View the resources of an organization

This topic describes how to view the resources of an organization.

## Prerequisites

You have logged in to the OceanBase Cloud Platform (OCP) console and been assigned the **ADMIN** role.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.UserManagement">User Management</UI-TERM>**.

3. Click **<UI-TERM key="ocp-v2.Auth.User.New.Tissue">Organization</UI-TERM>** to go to the **<UI-TERM key="ocp-v2.page.Settings.Profile.Tissue">Organization</UI-TERM>** tab.

   By default, all organizations are displayed. The organizations may be displayed on several pages. You can use the page control feature below the list to go to another page or change the number of organizations that can be displayed on each page.

4. Enter an organization name keyword in the search box and click **<UI-TERM key="ocp-v2.Detail.SQLDiagnosis.Query">Search</UI-TERM>**.

   The organizations whose names match the keyword are displayed in the organization list.

5. Find the target organization and click **<UI-TERM key="ocp-v2.Auth.Org.ViewResources">View Resources</UI-TERM>** in the **<UI-TERM key="ocp-v2.User.Oracle.RolesList.Operation">Actions</UI-TERM>** column.

   In the panel on the right side, view the resource information of the organization in the following columns: **Resource**, **<UI-TERM key="ocp-v2.Auth.User.New.ResourceType">Resource Type</UI-TERM>**, **<UI-TERM key="ocp-v2.Auth.User.New.Tissue">Organization</UI-TERM>**, **<UI-TERM key="ocp-v2.Restore.SamplingStrategy.Created">Created At</UI-TERM>**, and **<UI-TERM key="ocp-v2.component.alarm.Search.Founder">Created By</UI-TERM>**.
