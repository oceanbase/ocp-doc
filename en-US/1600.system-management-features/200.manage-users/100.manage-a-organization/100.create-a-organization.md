# Create an organization

This topic describes how to create an organization in OceanBase Cloud Platform (OCP).

## Prerequisites

You have logged in to the OCP console and been assigned the **ADMIN** role.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.Auth.User.New.UserManagement">User Management</UI-TERM>**.

3. In the upper-right corner of the **<UI-TERM key="ocp-v2.page.Auth.Organization">Organization</UI-TERM>** tab, click **<UI-TERM key="ocp-v2.Auth.User.New.CreateAnOrganization">Create Organization</UI-TERM>**.

4. In the dialog box that appears, enter the name of the organization to create.

   The organization name must start with a letter and end with a letter or a digit. It can contain letters, digits, and underscores (_), and must be 2 to 256 characters in length.

5. Click **<UI-TERM key="ocp-v2.Inspection.Item.ConfigRule.Submit">Submit</UI-TERM>**.
