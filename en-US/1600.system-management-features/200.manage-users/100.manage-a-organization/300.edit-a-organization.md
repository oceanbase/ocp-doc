# Rename an organization

This topic describes how to rename an organization. After you rename an organization, the new organization name takes effect for all users in this organization.

## Prerequisites

* You have logged in to the OceanBase Cloud Platform (OCP) console and been assigned the **ADMIN** role.
* The organization to be renamed is not the default organization named **default**.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.UserManagement">User Management</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.Auth.Role.Organization">Organization</UI-TERM>** tab, enter an organization name keyword in the search box and click **<UI-TERM key="ocp-v2.page.QueryLog.Query">Search</UI-TERM>**.

   The organizations whose names match the keyword are displayed in the organization list.

4. Find the target organization and click **<UI-TERM key="ocp-v2.Alarm.Shield.Editing">Edit</UI-TERM>** in the **<UI-TERM key="ocp-v2.Alarm.Rule.Operation">Actions</UI-TERM>** column.

   In the **<UI-TERM key="ocp-v2.Auth.Org.CreateOrg.EditOrganization">Edit Organization</UI-TERM>** dialog box, enter the new name of the organization.

5. Click **<UI-TERM key="ocp-v2.Detail.Component.UpgradeObproxiesModal.Ok">OK</UI-TERM>**.
