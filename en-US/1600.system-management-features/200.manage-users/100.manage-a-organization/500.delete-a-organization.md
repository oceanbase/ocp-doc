# Delete an organization

This topic describes how to delete an organization. After an organization is deleted, the resources belonging to it are moved to the default organization named **default**.

## Prerequisites

* You have logged in to the OceanBase Cloud Platform (OCP) console and been assigned the **ADMIN** role.
* The organization to be deleted is not the default organization named **default**.
* You have deleted all users in the organization.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.User.MySQL.UserManagement">User Management</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.page.Auth.Organization">Organization</UI-TERM>** tab, enter an organization name keyword in the search box and click **<UI-TERM key="ocp-v2.page.QueryLog.Query">Search</UI-TERM>**.

   The organizations whose names match the keyword are displayed in the organization list.

4. Find the organization to be deleted, click **<UI-TERM key="ocp-v2.Component.AddBackupStrategy.ViewMore">More</UI-TERM>** in the **<UI-TERM key="ocp-v2.ResourceManager.ResourceGroupTab.Operation">Actions</UI-TERM>** column, and select **<UI-TERM key="ocp-v2.Backup.Service.Detail.Delete">Delete</UI-TERM>**.

5. In the confirmation dialog box that appears, click **<UI-TERM key="ocp-v2.component.TenantList.Delete">Delete</UI-TERM>**.
