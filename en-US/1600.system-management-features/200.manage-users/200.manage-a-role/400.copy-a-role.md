# Copy a role

You can create a role with similar configurations of an existing role by copying the existing role.

## Prerequisites

* You have logged in to the OceanBase Cloud Platform (OCP) console and been assigned the **ADMIN** or **ORG_ADMIN** role.

* The role to be copied is not a default role.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.User.Oracle.UserManagement">User Management</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.Auth.Role.New.Role">Role</UI-TERM>** tab, enter a role name keyword in the search box and click **<UI-TERM key="ocp-v2.Auth.User.loginHistory.Query">Search</UI-TERM>**.

   The roles whose names match the keyword are displayed in the role list.

4. Find the role to be copied, click **<UI-TERM key="ocp-v2.page.Welcome.SeeMore">More</UI-TERM>** in the **<UI-TERM key="ocp-v2.Detail.Parameter.Operation">Actions</UI-TERM>** column, and select **<UI-TERM key="ocp-v2.Auth.User.Copy">Copy</UI-TERM>**.

   The **<UI-TERM key="ocp-v2.Auth.Role.New.CopyRoles">Copy Role</UI-TERM>** page appears.

5. On the **<UI-TERM key="ocp-v2.Auth.Role.New.CopyRoles">Copy Role</UI-TERM>** page, modify the role name, description, and permissions.

   For more information about role permissions, see Step 4 in [Create a role](100.create-a-role.md).

6. Click **<UI-TERM key="ocp-v2.Alarm.Template.New.Submit">Submit</UI-TERM>**.
