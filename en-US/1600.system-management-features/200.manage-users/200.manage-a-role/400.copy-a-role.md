# Copy a role

You can create a role with similar configurations of an existing role by copying the existing role.

## Prerequisites

* You have logged in to the OceanBase Cloud Platform (OCP) console and been assigned the **ADMIN** or **ORG_ADMIN** role.

* The role to be copied is not a default role.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **System Management** > **User Management**.

3. On the **Role** tab, enter a role name keyword in the search box and click **Search**.

   The roles whose names match the keyword are displayed in the role list.

4. Find the role to be copied, click **More** in the **Actions** column, and select **Copy**.

   The **Copy Role** page appears.

5. On the **Copy Role** page, modify the role name, description, and permissions.

   For more information about role permissions, see Step 4 in [Create a role](100.create-a-role.md).

6. Click **Submit**.
