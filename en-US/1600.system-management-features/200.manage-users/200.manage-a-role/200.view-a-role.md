# View a role

This topic describes how to view a role.

## Prerequisites

You have logged in to the OCP console and been assigned the **ADMIN** or **ORG_ADMIN** role.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **System Management** > **User Management**.

3. Click **Role** to go to the **Role** tab.

   By default, all roles are displayed. The roles may be displayed on several pages. You can use the page control feature below the list to go to another page or change the number of roles that can be displayed on each page.

4. Enter a role name keyword in the search box and click **Search**.

   The roles whose names match the keyword are displayed in the role list.

5. Click the name of a role.

   The **Role Details** page appears, where you can view the detailed information of the role.
