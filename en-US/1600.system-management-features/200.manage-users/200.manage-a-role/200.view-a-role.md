# View a role

This topic describes how to view a role.

## Prerequisites

You have logged in to the OCP console and been assigned the **ADMIN** or **ORG_ADMIN** role.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.page.Iframe.UserManagement">User Management</UI-TERM>**.

3. Click **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.Role">Role</UI-TERM>** to go to the **<UI-TERM key="ocp-v2.Oracle.Component.AddOracleUserOrRoleDrawer.Role">Role</UI-TERM>** tab.

   By default, all roles are displayed. The roles may be displayed on several pages. You can use the page control feature below the list to go to another page or change the number of roles that can be displayed on each page.

4. Enter a role name keyword in the search box and click **<UI-TERM key="ocp-v2.Auth.User.loginHistory.Query">Search</UI-TERM>**.

   The roles whose names match the keyword are displayed in the role list.

5. Click the name of a role.

   The **<UI-TERM key="ocp-v2.Auth.Role.Detail.RoleDetails">Role Details</UI-TERM>** page appears, where you can view the detailed information of the role.
