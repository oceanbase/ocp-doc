# Delete a role

This topic describes how to delete a role.

## Prerequisites

* You have logged in to the OceanBase Cloud Platform (OCP) console and been assigned the **ADMIN** or **ORG_ADMIN** role.

* The role to be deleted is not a default role.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.Auth.User.New.UserManagement">User Management</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.Auth.User.Role">Role</UI-TERM>** tab, enter a role name keyword in the search box and click **<UI-TERM key="ocp-v2.Auth.User.loginHistory.Query">Search</UI-TERM>**.

   The roles whose names match the keyword are displayed in the role list.

4. Find the target role and click **<UI-TERM key="ocp-v2.src.constant.credential.Delete">Delete</UI-TERM>** in the **<UI-TERM key="ocp-v2.page.Host.Operation">Actions</UI-TERM>** column.

   The system prompts `Are you sure that you want to delete the XX role?`.

5. Click **<UI-TERM key="ocp-v2.User.Oracle.RolesList.Delete">Delete</UI-TERM>**.
