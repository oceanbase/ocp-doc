# Edit a role

This topic describes how to edit a role.

## Prerequisites

* You have logged in to the OceanBase Cloud Platform (OCP) console and been assigned the **ADMIN** or **ORG_ADMIN** role.

* The role to be edited is not a default role.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.Auth.User.loginHistory.UserManagement">User Management</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.Scan.ReportTable.ZoneInfoTable.Role">Role</UI-TERM>** tab, enter a role name keyword in the search box and click **<UI-TERM key="ocp-v2.Auth.User.loginHistory.Query">Search</UI-TERM>**.

   The roles whose names match the keyword are displayed in the role list.

4. Find the target role and click **<UI-TERM key="ocp-v2.Alarm.Shield.Editing">Edit</UI-TERM>** in the **<UI-TERM key="ocp-v2.component.CardAbnormalTable.Operation">Actions</UI-TERM>** column.

   The **<UI-TERM key="ocp-v2.Auth.Role.New.EditRoles">Edit Role</UI-TERM>** page appears, where you can edit the permissions of the role. For more information, see Step 4 in [Create a role](100.create-a-role.md).

5. Click **<UI-TERM key="ocp-v2.Auth.Role.New.Submitted">Submit</UI-TERM>**.
