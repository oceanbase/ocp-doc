# Copy a user

You can create a user with similar configurations of an existing user by copying the existing user.

## Prerequisites

* You have logged in to the OceanBase Cloud Platform (OCP) console and been assigned the **ADMIN** or **ORG_ADMIN** role.
* You have logged in as the **ADMIN** role, if you want to copy the admin user.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.Auth.Role.Detail.UserManagement">User Management</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.User.1">User</UI-TERM>** tab, find the target user, click **<UI-TERM key="ocp-v2.page.Welcome.SeeMore">More</UI-TERM>** in the **<UI-TERM key="ocp-v2.Instance.Overview.Operation">Actions</UI-TERM>** column, and select **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.Copy">Copy</UI-TERM>**.

   Edit the user information. For more information about the parameters, see [Create a user](100.create-a-user.md).

   You must modify the following fields in the **<UI-TERM key="ocp-v2.TraceDetail.TraceContent.BasicInformation">Basic Information</UI-TERM>** section: **<UI-TERM key="ocp-v2.Instance.Overview.Username">Username</UI-TERM>**, **<UI-TERM key="ocp-v2.Credential.Component.ImportModal.Password">Password</UI-TERM>**, and **<UI-TERM key="ocp-v2.Auth.User.Detail.Mailbox">Email Address</UI-TERM>**.

4. Click **<UI-TERM key="ocp-v2.Detail.Parameter.List.Submitted">Submit</UI-TERM>**.

   The new user has the same roles and permissions as the original user.
