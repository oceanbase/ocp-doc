# Edit a user

This topic describes how to edit a user.

## Prerequisites

* You have logged in to the OceanBase Cloud Platform (OCP) console and been assigned the **ADMIN** or **ORG_ADMIN** role.
* You have logged in as the **ADMIN** role, if you want to modify the information of the admin user.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.Auth.Role.Detail.UserManagement">User Management</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.Detail.Component.ChangeUserLinkModal.User">User</UI-TERM>** tab, find the target user and click **<UI-TERM key="ocp-v2.Component.ServiceName.Edit">Edit</UI-TERM>** in the **<UI-TERM key="ocp-v2.Detail.SQLDiagnosis.Outline.Operation">Actions</UI-TERM>** column.

   Modify the user information. For more information about the parameters, see [Create a user](100.create-a-user.md).

   <main id="notice" type='explain'>
   <h4>Note</h4>
   <p>You cannot modify the username or organization of a user. </p>
   </main>

4. Click **<UI-TERM key="ocp-v2.component.OperationConfig.ModifyParameterDrawer.Submit">Submit</UI-TERM>**.
