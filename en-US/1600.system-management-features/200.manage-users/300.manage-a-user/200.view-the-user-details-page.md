# View a user

This topic describes how to view the detailed information about a user.

## Prerequisites

You have logged in to the OCP console and been assigned the **ADMIN**, **ADMIN_VIEWER**, or **ORG_ADMIN** role.

## Procedure

1. Log in to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.UserManagement">User Management</UI-TERM>**.

3. View the user list on the **<UI-TERM key="ocp-v2.Detail.Session.Statistics.User">User</UI-TERM>** tab.

   * If you log in as the `ADMIN` role, the information about all users in the system is displayed.
   * If you log in as the `ORG_ADMIN` role, the information about all users in the organization, except the organization information, is displayed.

4. Click a username in the user list.

   The **<UI-TERM key="ocp-v2.Auth.User.Detail.UserDetails">User Details</UI-TERM>** page appears, where you can view basic information and permissions of the user.

   You can also change the user password, copy the user, edit the user, delete the user, and create an AccessKey pair. For more information, see [Change the password of a user](500.change-user-password.md), [Copy a user](400.copy-a-user.md), [Edit a user](300.edit-a-user.md), [Delete a user](600.delete-a-user.md), and [Create an AccessKey pair](../../700.manage-user-center/100.configure-personal-information.md).
