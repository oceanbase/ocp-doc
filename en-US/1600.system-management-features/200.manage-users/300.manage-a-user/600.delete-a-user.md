# Delete a user

This topic describes how to delete a user.

## Prerequisites

* You have logged in to the OceanBase Cloud Platform (OCP) console and been assigned the **ADMIN** or **ORG_ADMIN** role.

* The user to be deleted is not the admin user.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.page.Auth.UserManagement">User Management</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.Auth.User.loginHistory.User">User</UI-TERM>** tab, find the target user, click **<UI-TERM key="ocp-v2.Cluster.Component.MachineResource.SeeMore">More</UI-TERM>** in the **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.Operation">Actions</UI-TERM>** column, and select **<UI-TERM key="ocp-v2.src.component.DeleteUnitSpecModal.Delete">Delete</UI-TERM>**.

   The system prompts "Are you sure that you want to delete the xx user?"

4. Click **<UI-TERM key="ocp-v2.src.constant.oceanbase.Delete">Delete</UI-TERM>**.

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>A deleted user cannot be recovered. Proceed with caution. </p>
  </main>
