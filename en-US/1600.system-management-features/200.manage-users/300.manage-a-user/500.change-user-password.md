# Change the password of a user

This topic describes how to change the password of a user.

## Prerequisites

* You have logged in to the OceanBase Cloud Platform (OCP) console and been assigned the **ADMIN** or **ORG_ADMIN** role.
* You have logged in as the **ADMIN** role, if you want to change the password of the admin user.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.UserManagement">User Management</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.Auth.User.loginHistory.User">User</UI-TERM>** tab, find the target user, click **<UI-TERM key="ocp-v2.Component.AddBackupStrategy.ViewMore">More</UI-TERM>** in the **<UI-TERM key="ocp-v2.Auth.Role.Operation">Actions</UI-TERM>** column, and select **<UI-TERM key="ocp-v2.User.MySQL.ChangePassword">Change Password</UI-TERM>**.

   The password change dialog box appears.

4. Enter the new password in the dialog box.

   The password must be 8 to 32 characters in length. It must contain characters of at least three of the following types: digits (0 to 9), uppercase letters (A to Z), lowercase letters (a to z), and special characters. Supported special characters are the following ones: <code>~!@#%^&*_-+=\|(){}[]:;,.?/$`'"<>\\</code>.

5. Click **<UI-TERM key="ocp-v2.ResourceManager.ResourceGroupTab.CreateResourceGroup.Ok">OK</UI-TERM>**.
