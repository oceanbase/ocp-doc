# View the login history

This topic describes how to view the login information, client information, login result, and whether automatic locking is triggered during the specified time range.

## Prerequisites

You have logged in to the OceanBase Cloud Platform (OCP) console and been assigned the **ADMIN**, **ADMIN_VIEWER**, or **ORG_ADMIN** role.

## Procedure

1. In the left-side navigation pane, choose **System Management** > **User Management**. On the **User** page that appears, select **Logon History** in the upper-right corner.

2. In the **Username** drop-down list, select the user to view.

3. Specify a time range in **Logon Time**.

4. Click **Search**. All users that meet the filter conditions are displayed in the **Logon List** section.

   * In the list, you can view login information in the following columns: **Username**, **IP Address**, **Client**, **Logon Time**, **Logon Result**, and **Automatically Lock**.

      ![05101553](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/435/1630.png)

   * You can click a username in **Logon List** to go to the user details page. For more information, see [View a user](200.view-the-user-details-page.md).
