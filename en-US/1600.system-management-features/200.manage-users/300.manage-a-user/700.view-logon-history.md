# View the login history

This topic describes how to view the login information, client information, login result, and whether automatic locking is triggered during the specified time range.

## Prerequisites

You have logged in to the OceanBase Cloud Platform (OCP) console and been assigned the **ADMIN**, **ADMIN_VIEWER**, or **ORG_ADMIN** role.

## Procedure

1. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.Auth.Role.Detail.UserManagement">User Management</UI-TERM>**. On the **<UI-TERM key="ocp-v2.Detail.Component.ChangeUserLinkModal.User">User</UI-TERM>** page that appears, select **<UI-TERM key="ocp-v2.Auth.User.LogonHistory">Logon History</UI-TERM>** in the upper-right corner.

2. In the **<UI-TERM key="ocp-v2.Settings.Credential.Cluster.UserName">Username</UI-TERM>** drop-down list, select the user to view.

3. Specify a time range in **<UI-TERM key="ocp-v2.Auth.User.loginHistory.LogonTime">Logon Time</UI-TERM>**.

4. Click **<UI-TERM key="ocp-v2.page.QueryLog.Query">Search</UI-TERM>**. All users that meet the filter conditions are displayed in the **<UI-TERM key="ocp-v2.Auth.User.loginHistory.LogonList">Logon List</UI-TERM>** section.

   * In the list, you can view login information in the following columns: **<UI-TERM key="ocp-v2.Detail.Component.AddUserDrawer.UserName">Username</UI-TERM>**, **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.IpAddress">IP Address</UI-TERM>**, **<UI-TERM key="ocp-v2.Auth.User.loginHistory.Client">Client</UI-TERM>**, **<UI-TERM key="ocp-v2.Auth.User.loginHistory.LogonTime">Logon Time</UI-TERM>**, **<UI-TERM key="ocp-v2.Auth.User.loginHistory.LogonResult">Logon Result</UI-TERM>**, and **<UI-TERM key="ocp-v2.Auth.User.loginHistory.AutomaticallyLockAccounts">Automatically Lock</UI-TERM>**.

      ![05101553](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/435/1630.png)

   * You can click a username in **<UI-TERM key="ocp-v2.Auth.User.loginHistory.LogonList">Logon List</UI-TERM>** to go to the user details page. For more information, see [View a user](200.view-the-user-details-page.md).
