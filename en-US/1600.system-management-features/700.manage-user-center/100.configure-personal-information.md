# Configure personal information

This topic describes how to configure your basic information and create an AccessKey pair on the **<UI-TERM key="ocp-v2.Layout.Header.PersonalSettings">Personal Settings</UI-TERM>** page.

## Prerequisites

You have been assigned the **ADMIN** or **ORG_ADMIN** role, if you want to create an AccessKey pair.

## Procedure

### Configure basic information

1. Log in to the OceanBase Cloud Platform (OCP) console.

2. In the upper-right corner of the OCP console, click the username and select **<UI-TERM key="ocp-v2.Layout.Header.PersonalSettings">Personal Settings</UI-TERM>**.

   ![07021628](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/402-en/%E4%B8%AA%E4%BA%BA%E8%AE%BE%E7%BD%AE1.png)

3. In the **<UI-TERM key="ocp-v2.Detail.Overview.BasicInformation">Basic Information</UI-TERM>** section, click **<UI-TERM key="ocp-v2.Arbitration.ArbitrationGroup.Edit">Edit</UI-TERM>** in the upper-right corner to set your email address, mobile number, organization, department, and description.

   ![07021625](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/402-en/%E7%BC%96%E8%BE%91%E5%9F%BA%E7%A1%80%E4%BF%A1%E6%81%AF1.png)

4. Click **<UI-TERM key="ocp-v2.Detail.Parameter.List.Submitted">Submit</UI-TERM>**.

### Create an AccessKey pair

If you want to call an OCP API in AK/SK authentication mode, you must create an AccessKey pair. For more information, see [Rules for generating a signature by using AK/SK](../../1900.reference-guide/200.api-reference/300.ak-sk-sign-roles.md).

1. Log in to the OCP console.

2. In the upper-right corner of the OCP console, click the username and select **<UI-TERM key="ocp-v2.page.Settings.Profile.PersonalSettings">Personal Settings</UI-TERM>**.

3. In the **<UI-TERM key="ocp-v2.src.component.ArchiveForm.AccessKey">AccessKey</UI-TERM>** section, click **Create AccessKey Pair** in the upper-right corner.

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/accesskey.png)

4. In the **AccessKey created successfully** dialog box, view the created AccessKey ID and AccessKey secret.

   * Click **<UI-TERM key="ocp-v2.page.External.CreateDrawer.Copy">Copy</UI-TERM>** to copy the AccessKey pair.
   * Click **<UI-TERM key="ocp-v2.User.Component.AccessKeyCardTable.DownloadCsvFile">Download CSV File</UI-TERM>** to export the AccessKey pair to a local CSV file.

      ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/402-en/%E7%94%9F%E6%88%90asks%E6%88%90%E5%8A%9F.png)

    <main id="notice" type='explain'>
    <h4>Note</h4>
    <p><ul><li>You can create up to five AccessKey pairs. </li><li>An AccessKey pair created earlier is at higher risk of leakage. We recommend that you create new AccessKey pairs to replace those at risk. </li></ul></p>
    </main>

5. If an AccessKey pair is not in use, you can click **<UI-TERM key="ocp-v2.Detail.Overview.Close">Disable</UI-TERM>** in the **<UI-TERM key="ocp-v2.page.Information.Operation">Actions</UI-TERM>** column to disable it.

   You can delete or enable a disabled AccessKey pair.

   ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/402-en/%E7%A6%81%E7%94%A8ak1.png)

      <main id="notice" type='alert'>
      <h4>Notice</h4>
      <p>If an AccessKey pair is in use, disabling it may cause business interruption. Proceed with caution. </p>
      </main>
