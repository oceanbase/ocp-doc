# Export a credential

This topic describes how to export a credential.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only**, **Tenant Read-only**, **OBProxy Read-only**, **Binlog Service Read-only**, or **Host Read-only** permission
* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.page.Credential.CredentialManagement">Credential Management</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>**

## Procedure

1. Log in to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.src.component.AddOBCredentialModal.CredentialManagement">Credential Management</UI-TERM>** to go to the **<UI-TERM key="ocp-v2.page.Credential.Cluster.CredentialList">Credentials</UI-TERM>** page.

3. On the **OceanBase**, **OBProxy**, or **<UI-TERM key="ocp-v2.Settings.Credential.Host">Host</UI-TERM>** tab, find the credential to be exported.

4. Hover the pointer over the **<UI-TERM key="ocp-v2.page.Welcome.SeeMore">...</UI-TERM>** icon in the **<UI-TERM key="ocp-v2.Detail.Transaction.Actions">Actions</UI-TERM>** column of the credential and click **<UI-TERM key="ocp-v2.Monitor.Dashboard.Export">Export</UI-TERM>**.

5. In the dialog box that appears, enter the encryption password, which must meet the following requirements:
    <ul>
    <li>Be 8 to 32 characters in length. </li>
    <li>Contain characters of at least three of the following types: digits (0 to 9), uppercase letters (A to Z), lowercase letters (a to z), and special characters. </li>
    <li>Supported special characters are <code>~ ! @ # % ^ &amp; * _ - + = \ | ( ) { } [ ] : ; , . ? /</code> </li>
    </ul>
    </li>
    </ul>

6. Click **<UI-TERM key="ocp-v2.component.MoveOutClusterDrawer.Export">Export</UI-TERM>**.

   <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>When you <a href="300.import-a-credential.md">import a credential</a>, you must use the encryption password for decryption. You can memorize the password, or click <strong>Copy Password</strong> to save it. </p>
