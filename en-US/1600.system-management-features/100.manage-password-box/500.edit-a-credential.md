# Edit a credential

This topic describes how to edit a credential.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance**, **Tenant Maintenance**, **OBProxy Maintenance**, **Binlog Service Maintenance**, or **Host Maintenance** permission
* **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.page.Credential.CredentialManagement">Credential Management</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>**

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.src.component.AddBinlogCredentialModal.CredentialManagement">Credential Management</UI-TERM>** to go to the **<UI-TERM key="ocp-v2.Settings.Credential.Host.Secrets">Credentials</UI-TERM>** page.

3. Find the credential to be modified and click **<UI-TERM key="ocp-v2.component.ParameterTemplate.AddDrawer.Editing">Edit</UI-TERM>** in the **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.Operation">Actions</UI-TERM>** column of the credential.

4. In the **<UI-TERM key="ocp-v2.src.component.AddOBProxyCredentialModal.UpdateCredentials">Update Credential</UI-TERM>** dialog box, modify the credential information.

   | **Object type** | **Editable content** |
   | --- | --- |
   | OceanBase cluster | You can edit the **<UI-TERM key="ocp-v2.Channel.FormComponent.EMailForm.Password">Password</UI-TERM>** and **<UI-TERM key="ocp-v2.component.alarm.RuleDetail.Description">Description</UI-TERM>** fields.  |
   | OBProxy cluster | You can edit the **<UI-TERM key="ocp-v2.src.component.AddHostCredentialDrawer.Password">Password</UI-TERM>** and **<UI-TERM key="ocp-v2.Detail.Parameter.List.Description">Description</UI-TERM>** fields.  |
   | Host | You can edit the **<UI-TERM key="ocp-v2.src.component.AddHostCredentialDrawer.SecretName">Credential Name</UI-TERM>**, **<UI-TERM key="ocp-v2.src.component.AddHostCredentialDrawer.UserType">User Type</UI-TERM>**, **<UI-TERM key="ocp-v2.Cluster.Component.OBProxyClusterAndUserSelect.UserName">Username</UI-TERM>**, **Password/Private Key**, **Applied Host**, and **<UI-TERM key="ocp-v2.Detail.LoadBalance.AddObproxyLoadBalanceAppDrawer.Description">Description</UI-TERM>** fields.  |

5. Click **<UI-TERM key="ocp-v2.MultiCluster.Detail.FailoverModal.Determine">OK</UI-TERM>**.
