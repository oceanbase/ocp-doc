# Create a credential

This topic describes how to create a credential used by OceanBase Cloud Platform (OCP) to connect to a cluster or host. You can directly select the created credential when you need to connect to an OceanBase or OBProxy cluster or add a host for a task managed in a new OCP cluster.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance**, **Tenant Maintenance**, **OBProxy Maintenance**, **Binlog Service Maintenance**, or **Host Maintenance** permission
* **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.component.AddOBCredentialModal.CredentialManagement">Credential Management</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>**

## Procedure

1. Log on to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.src.component.AddHostCredentialDrawer.CredentialManagement">Credential Management</UI-TERM>** to go to the **<UI-TERM key="ocp-v2.page.Credential.Cluster.CredentialList">Credentials</UI-TERM>** page.

3. Click **<UI-TERM key="ocp-v2.src.component.AddOBProxyCredentialModal.CreateCredentials">Create Credential</UI-TERM>** in the upper-right corner and select the type of the credential.

   Supported types are **OceanBase**, **OBProxy**, and **<UI-TERM key="ocp-v2.component.alarm.AlarmTargetLabel.Host">Host</UI-TERM>**.

4. In the **<UI-TERM key="ocp-v2.src.component.AddBinlogCredentialModal.CreateCredentials">Create Credential</UI-TERM>** dialog box, specify the information about the credential.

   | **Object type** | **Required information** |
   | --- | --- |
   | OceanBase | Specify the OceanBase cluster and tenant to which the connected object belongs, as well as the username and password of the connection user.  |
   | OBProxy | Specify the OBProxy cluster to which the connected object belongs and the username and password of the connection user.  |
   | Host | Specify the information about the credential for connecting to a host.  |

    <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>A credential of the sys tenant can be used to connect to the sys tenant and the cluster to which the sys tenant belongs. A credential of a tenant other than the sys tenant can be used to connect only to the current tenant. </p>
    </main>

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E6%96%B0%E5%BB%BA%E5%87%AD%E6%8D%AE1.png)

5. Click **<UI-TERM key="ocp-v2.component.FormEditTable.Determine">OK</UI-TERM>**.

   The password box performs a connection test for the credential. If the test fails, the credential creation fails.
