# Verify a credential

This topic describes how to verify whether a credential is available.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only**, **Tenant Read-only**, **OBProxy Read-only**, **Binlog Service Read-only**, or **Host Read-only** permission
* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.hook.useMenu.CredentialManagement">Credential Management</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>**

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.src.component.AddOBCredentialModal.CredentialManagement">Credential Management</UI-TERM>** to go to the **<UI-TERM key="ocp-v2.page.Credential.Cluster.CredentialList">Credentials</UI-TERM>** page.

3. On the **OceanBase**, **OBProxy**, or **<UI-TERM key="ocp-v2.page.Host.Host">Host</UI-TERM>** tab, find the credential to be verified.

4. Click **<UI-TERM key="ocp-v2.page.Credential.Binlog.Verification">Verify</UI-TERM>** in the **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.Operation">Actions</UI-TERM>** column of the credential.

5. If the verification succeeds, a **<UI-TERM key="ocp-v2.page.Credential.OBProxy.VerificationCompleted">Verified</UI-TERM>** label appears next to the cluster name or credential name. If the verification fails, you need to modify the credential and try again.
