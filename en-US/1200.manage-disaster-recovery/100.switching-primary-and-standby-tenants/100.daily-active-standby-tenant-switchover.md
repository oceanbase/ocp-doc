# Switchover

This topic describes the primary/standby switchover procedure. You can choose one of the following switchover methods based on the business needs:

* Method 1: Perform a switchover for a specified primary tenant.
* Method 2: Perform a switchover for all primary tenants in a cluster.

## Method 1: Perform a switchover for a specified primary tenant

You can switch a specified primary tenant to the STANDBY role.

### Prerequisites

* Make sure that you have the following permissions:
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** or **Tenant Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Detail.Resource.Unit.Tenant">Tenants</UI-TERM>**

* The current primary tenant has at least one standby tenant in the **<UI-TERM key="ocp-v2.src.constant.compute.NormalOperation">Running</UI-TERM>** state.

### Considerations

We recommend that you set the same service name for the primary and standby tenants, and that the clusters to which the primary and standby tenants belong be associated with the same OBProxy cluster. Otherwise, automatic routing cannot be implemented after the switchover.

### Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Detail.Component.DeleteTenantModal.Tenant">Tenants</UI-TERM>**. In the tenant list, find the target primary tenant and click its name to go to its basic information page.

2. Click the **<UI-TERM key="ocp-v2.Cluster.Component.MachineResource.SeeMore">More</UI-TERM>** icon in the upper-right corner and select **<UI-TERM key="ocp-v2.MultiCluster.Detail.SwitchoverModal.DailySwitchover">Switchover</UI-TERM>** from the menu.

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/switchover.png)

3. In the dialog box that appears, confirm the information and click **<UI-TERM key="ocp-v2.Detail.Component.DailyChangeTenantModal.StartSwitching">Start Switch</UI-TERM>**.

    * If the primary tenant has multiple standby tenants, you must select a standby tenant for the switchover from the **<UI-TERM key="ocp-v2.Component.ChangeTenantView.NewMasterTenant">New Primary Tenants</UI-TERM>** drop-down list. If the OCP multi-cluster mode is enabled, remote standby tenants managed by other OCP clusters are also displayed in the drop-down list.
    * If the synchronization mode of the selected standby tenant is **<UI-TERM key="ocp-v2.src.constant.tenant.ArchiveBased">Archiving-based</UI-TERM>** and archiving is not enabled for the standby tenant, you must first configure an archiving address. The following table describes the parameters for configuring an archiving address.

      | Parameter | Description |
      |--------|---------|
      | Storage Type  | The type of the storage service for backup files. Valid values: <ul><li>**<UI-TERM key="ocp-v2.Detail.TakeOver.File">File</UI-TERM>**: your local file storage system. Generally, Network File System (NFS) is used. </li><li>**OSS**: Alibaba Cloud Object Storage Service (OSS), which is supported only in OceanBase Database V2.2.76 and later. </li></ul>|
      |  Storage Directory  | The directory in which the backup files are stored on the storage service. <main id="notice" type='explain'><h4>Note</h4><p>The primary and standby tenants must have the read/write permissions on this directory. </p></main>  |
      | Domain        | If you select **OSS** for **<UI-TERM key="ocp-v2.Component.StorageConfigCard.StorageType">Storage Type</UI-TERM>**, enter the domain name for accessing the files stored in the OSS bucket. You can append a port number to the domain name, for example, `oss.ap-shanghai.myqcloud.com:8080`. |
      | User        | If you select **OSS** for **<UI-TERM key="ocp-v2.Component.BackupStrategyDetail.StorageType">Storage Type</UI-TERM>**, enter the user for accessing the files stored in the OSS bucket. |
      | AccessKey Pair          | If you select **OSS** for **<UI-TERM key="ocp-v2.Component.StorageConfigCard.StorageType">Storage Type</UI-TERM>**, enter the AccessKey pair for accessing the files stored in the OSS bucket.    |

4. Click the task ID in the dialog box to view the task progress.

## Method 2: Perform a switchover for all primary tenants in a cluster

If you require standby tenants to provide services to ensure service continuity during the O&M of a cluster, you can switch all primary tenants in this cluster to the STANDBY role before the O&M.

### Prerequisites

* Make sure that you have the following permissions:
  * **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** or **Tenant Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Detail.Component.DeleteTenantModal.Tenant">Tenants</UI-TERM>**

* You have created primary tenants in the current cluster, and the primary tenants have available standby tenants.

* You have set service names for the primary and standby tenants. Otherwise, automatic routing cannot be implemented after the switchover.

* The clusters to which the primary and standby tenants belong have been associated with the same OBProxy cluster. Otherwise, automatic routing cannot be implemented after the switchover.

### Procedure

1. Log on to the OCP console. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>**. On the **<UI-TERM key="ocp-v2.page.Binlog.ClusterList">Cluster List</UI-TERM>** page, go to the **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** page of the target cluster.

2. Click the **<UI-TERM key="ocp-v2.Component.AddBackupStrategy.ViewMore">More</UI-TERM>** icon in the upper-right corner and select **<UI-TERM key="ocp-v2.Detail.Overview.TenantDailySwitching">Tenant Switchover</UI-TERM>** from the menu.

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/tenant-switchover.png)

3. In the dialog box that appears, select the tenants for which you want to perform a switchover and click **<UI-TERM key="ocp-v2.Detail.Component.DailyChangeTenantModal.DailySwitching">Switchover</UI-TERM>**.

    * If a primary tenant has multiple standby tenants, you must select one of the standby tenants as the new primary tenant from the **<UI-TERM key="ocp-v2.Component.ChangeTenantView.NewMasterTenant">New Primary Tenants</UI-TERM>** drop-down list. If the OCP multi-cluster mode is enabled, remote standby tenants managed by other OCP clusters are also displayed in the drop-down list.

      Before you perform a switchover, the system will check the primary and standby tenants against the following conditions. If the check fails, you cannot perform a switchover for the selected tenants.

      * The primary and standby tenants are in the **<UI-TERM key="ocp-v2.src.constant.oceanbase.NormalOperation">Running</UI-TERM>** state.
      * The clusters to which the primary and standby tenants belong are in the **<UI-TERM key="ocp-v2.src.constant.oceanbase.NormalOperation">Running</UI-TERM>** state and are of the same version.
      * The synchronization latency of the standby tenant does not exceed the threshold, which is 5,000 ms by default. You can choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.page.Property.SystemParameters">System Parameters</UI-TERM>** and change the value of `ocp.standby.tenant.delay.threshold` to adjust the threshold.

    * If the synchronization mode of the selected standby tenant is **<UI-TERM key="ocp-v2.src.constant.tenant.ArchiveBased">Archiving-based</UI-TERM>** and archiving is not enabled for the standby tenant, you must first configure an archiving address. The following table describes the parameters for configuring an archiving address.

      | Parameter | Description |
      |--------|---------|
      | Storage Type  | The type of the storage service for backup files. Valid values: <ul><li>**<UI-TERM key="ocp-v2.Detail.TakeOver.File">File</UI-TERM>**: your local file storage system. Generally, Network File System (NFS) is used. </li><li>**OSS**: Alibaba Cloud Object Storage Service (OSS), which is supported only in OceanBase Database V2.2.76 and later. </li></ul>|
      |  Storage Directory  | The directory in which the backup files are stored on the storage service.  <main id="notice" type='explain'><h4>Note</h4><p>The primary and standby tenants must have the read/write permissions on this directory. </p></main>  |
      | Domain        | If you select **OSS** for **<UI-TERM key="ocp-v2.Component.BackupStrategyDetail.StorageType">Storage Type</UI-TERM>**, enter the domain name for accessing the files stored in the OSS bucket. You can append a port number to the domain name, for example, `oss.ap-shanghai.myqcloud.com:8080`. |
      | User        | If you select **OSS** for **<UI-TERM key="ocp-v2.src.component.ArchiveForm.StorageType">Storage Type</UI-TERM>**, enter the user for accessing the files stored in the OSS bucket. |
      | AccessKey Pair          | If you select **OSS** for **<UI-TERM key="ocp-v2.Backup.Service.Detail.StorageType">Storage Type</UI-TERM>**, enter the AccessKey pair for accessing the files stored in the OSS bucket.    |

    <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>This operation may cause the cluster where the new primary tenant resides to be overloaded. Proceed with caution. </p>
    </main>

4. Click the task ID in the dialog box to view the task progress.
