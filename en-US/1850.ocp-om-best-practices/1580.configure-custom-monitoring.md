# Configure custom monitoring

This topic describes how to configure custom monitoring.

## Scenarios

If the default GUI-based monitoring cannot meet your needs, you can configure custom monitoring.

## Prerequisites

* Make sure that you have the following permissions:
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only**, **Tenant Read-only**, **OBProxy Read-only**, **Arbitration Service Read-only**, **Binlog Service Read-only**, or **Host Read-only** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.component.alarm.RuleSelect.All">All</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.hook.useMenu.PerformanceMonitoring">Performance Monitoring</UI-TERM>**
* OceanBase Cluster Platform (OCP) has collected the required metrics but the GUI-based monitoring has not been configured.

## Procedure

### Go to the Custom Monitoring page

1. Log on to the OCP console.

2. In the left-side navigation pane, select **<UI-TERM key="ocp-v2.src.util.menu.PerformanceMonitoring">Performance Monitoring</UI-TERM>** to go to the **<UI-TERM key="ocp-v2.src.hook.useMenu.Monitoring">Monitoring</UI-TERM>** page.

3. Click **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CustomMonitoring">Custom Monitoring</UI-TERM>** in the upper-right corner.

### Create a custom chart

1. If you go to the **<UI-TERM key="ocp-v2.Monitor.AddMonitor.Chart">Chart</UI-TERM>** tab on the **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CustomMonitoring">Custom Monitoring</UI-TERM>** page for the first time, no custom charts are available. You can click **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.CreateAChart">Create Chart</UI-TERM>** to create one.

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/%E5%88%9B%E5%BB%BA%E5%9B%BE%E8%A1%A8.png)

2. On the **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CreateAChart">Create Chart</UI-TERM>** page, specify the parameters and click **<UI-TERM key="ocp-v2.Compaction.Settings.EditCard.Save">Save</UI-TERM>**.

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/create-chart.png)

   The parameters of a custom chart are described as follows:

   * **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.ChartLocation">Chart Position</UI-TERM>**: The valid values are monitoring subdirectories displayed on the GUI. Metrics supported in each subdirectory are different. For example, you can create only a cluster-related monitoring chart under a cluster-level subdirectory.

      ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/chart-position.png)

   * **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.SelectAMetricItem">Selected Metric</UI-TERM>**: Each metric corresponds to a PromQL expression. You can hover over a metric to view its name, description, and expression, as well as OceanBase Database versions that support the metric. If no specific OceanBase Database versions are displayed, the metric is supported in all versions.

      ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/monitoring-metrics.png)

      The default available metrics are built-in metrics in OCP and can be directly used. As shown in the following figure, you can click **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMetricDrawer.CreateIndicatorItems">Create Metric</UI-TERM>** in section ①, or click **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMetricDrawer.CreateIndicatorItems">Create Metric</UI-TERM>** in section ② on the **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.IndicatorItem">Metric</UI-TERM>** tab to create a custom metric based on your business.

      ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/create-metric.png)

   * **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.GraphicStyle">Graphic Style</UI-TERM>**: Only **<UI-TERM key="ocp-v2.Monitor.Dashboard.constants.LineChart">Line Chart</UI-TERM>** is supported.

3. After you create a chart, you can view its information in the table on the **<UI-TERM key="ocp-v2.Monitor.AddMonitor.Chart">Chart</UI-TERM>** tab or directly view the chart at the position specified by **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.ChartLocation">Chart Position</UI-TERM>**. By default, a new chart is sorted after existing ones.

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/chart.png)

### Create a custom metric

1. If you go to the **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.IndicatorItem">Metric</UI-TERM>** tab on the **<UI-TERM key="ocp-v2.Detail.Monitor.CustomMonitoring">Custom Monitoring</UI-TERM>** page for the first time, no custom metrics are available. You can click **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMetricDrawer.CreateIndicatorItems">Create Metric</UI-TERM>** to create one.

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/%E5%88%9B%E5%BB%BA%E6%8C%87%E6%A0%87%E9%A1%B9.png)

2. On the **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.CreateIndicatorItems">Create Metric</UI-TERM>** page, specify the parameters and click **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.Save">Save</UI-TERM>**.

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/createmetric.png)

   The parameters of a custom metric are described as follows:

   * **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMetricDrawer.CollectionItem">Collection Item</UI-TERM>**: A collection item is a metric used in a PromQL expression. You can hover over a collection item to view its information, such as its name, description, type (COUNTER or GAUGE), collection interval, unit, label, and the object dimension.

      ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/collection-item.png)

   * **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMetricDrawer.CreateMode">Creation Mode</UI-TERM>**: **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.SelectExpression">Select Expression</UI-TERM>** and **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.CustomExpression">Custom Expression</UI-TERM>** modes are supported.

      * If you select **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.SelectExpression">Select Expression</UI-TERM>**, you can select only a single collection item and a simple calculation expression that is provided based on the selected collection item.

         ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/select-expression.png)

      * If the default expressions cannot meet your needs, you can select **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.CustomExpression">Custom Expression</UI-TERM>** and specify a custom PromQL expression. OCP verifies the PromQL syntax of the custom expression. You can view syntax rules below the text box of the calculation expression.

         ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/custom-expression.png)

3. After you create a metric, you can view its information in the table on the **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.IndicatorItem">Metric</UI-TERM>** tab. Custom metrics can be used in custom charts.

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/metrics.png)

### Create an alert rule

You can also use custom metrics to create alert rules. To do so, click **<UI-TERM key="ocp-v2.Alarm.Rule.New.CreateAlertRule">Create Alert Rule</UI-TERM>** to go to the alert rule creation page.

![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/create-alert-rule.png)

### View collection item information

You can view information of all collection items supported by OCP on the **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectionItem">Collection Item</UI-TERM>** tab.

![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/collectionitem.png)
