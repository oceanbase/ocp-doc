# Restart OCP-Agent

This topic describes how to restart OCP-Agent.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Host Maintenance** permission
* **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Plan.Component.PlanTemplateTable.All">All</UI-TERM>** menu of **<UI-TERM key="ocp-v2.page.Host.HostList">Hosts</UI-TERM>**

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Host.HostList">Hosts</UI-TERM>**.

3. Click **<UI-TERM key="ocp-v2.Host.Detail.OCPAgent.RestartOcpAgent">Restart OCP Agent</UI-TERM>** next to the host where OCP-Agent to restart is installed.

   ![1223](https://help-static-aliyun-doc.aliyuncs.com/assets/img/en-US/6699934461/p393966.png)

   The system prompts you to confirm the restart.

4. In the dialog box that appears, click **<UI-TERM key="ocp-v2.Report.Component.GenerateReportModal.Determine">OK</UI-TERM>**.

5. In the **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.HostList">Hosts</UI-TERM>** list, find the target host, and click **<UI-TERM key="ocp-v2.Detail.Report.ViewTasks">View Task</UI-TERM>** in the **<UI-TERM key="ocp-v2.Backup.Service.Operation">Actions</UI-TERM>** column to view the progress.
