# View details of a host

On the details page of a host, you can view basic information, OceanBase Cloud Platform (OCP) Agent information, and monitoring data of the host.

## Prerequisites

Make sure that you have the following permissions:

* Resource permissions: **Cluster read-only**, **tenant read-only**, or **host read-only** permission.
* Menu permissions: Permission on all menus of hosts.

## View basic information of a host

On the **Basic Information** tab of the host, you can view the details and disk usage information of the host, and manage tags.

* In the **View Details** section, you can view the status, name, alias, SSH port number, IDC, type, category, region, disk usage, service, clock offset, current time, time zone, operating system, CPU architecture, CPU model, number of CPU cores, tags, total memory size, and description of the host.

    You can hover the pointer over the **Tag** field of the host to view all its tags, and then click the **Edit** icon to manage the tags. For more information, see [Manage tags](../1600.system-management-features/300.manage-tags/100.tags-overview.md).

* In the **Disk Usage** section, you can view disk path information such as the total size of the disk partition, used size of the disk partition, available size of the disk partition, disk partition usage, and mounted directory.

## View OCP Agent information

On the **OCP Agent** tab, you can view information about OCP Agent in the **View Details** and **Processes** sections.

* The **View Details** section displays the status, installation directory, installation time, version, log directory, and future available periods of OCP Agent.

* The **Processes** section displays the details of processes, such as the ID, name, startup command, operating system user, port number, specification, uptime, future available periods, and status of processes.

  * Click **Download Logs** in the **Actions** column of a process to download its logs.

  * Click **Change Specification** in the **Actions** column of the `ocp_monagent` process to adjust the specification of OCP Agent for the host.
