# View details of a host

On the details page of a host, you can view basic information, OceanBase Cloud Platform (OCP) Agent information, and monitoring data of the host.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only**, **Tenant Read-only**, or **Host Read-only** permission
* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.Analyze.All">All</UI-TERM>** menu of **<UI-TERM key="ocp-v2.page.Host.HostList">Hosts</UI-TERM>**

## View basic information of a host

On the **<UI-TERM key="ocp-v2.Binlog.Component.AddBinlogNodeModal.BasicInformation">Basic Information</UI-TERM>** tab of the host, you can view the details and disk usage information of the host, and manage tags.

* In the **<UI-TERM key="ocp-v2.Alarm.Event.Detail.Details">Details</UI-TERM>** section, you can view the status, name, alias, SSH port number, IDC, type, category, region, disk usage, service, clock offset, current time, time zone, operating system, CPU architecture, CPU model, number of CPU cores, tags, total memory size, and description of the host.

    You can hover the pointer over the **<UI-TERM key="ocp-v2.page.Tags.Label">Tag</UI-TERM>** field of the host to view all its tags, and then click the **<UI-TERM key="ocp-v2.Alarm.Channel.Editing">Edit</UI-TERM>** icon to manage the tags. For more information, see [Manage tags](../1600.system-management-features/300.manage-tags/100.tags-overview.md).

* In the **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.UsedDisk">Disk Usage</UI-TERM>** section, you can view disk path information such as the total size of the disk partition, used size of the disk partition, available size of the disk partition, disk partition usage, and mounted directory.

## View OCP Agent information

On the **OCP Agent** tab, you can view information about OCP Agent in the **View Details** and **Processes** sections.

* The **View Details** section displays the status, installation directory, installation time, version, log directory, and future available periods of OCP Agent.

* The **Processes** section displays the details of processes, such as the ID, name, startup command, operating system user, port number, specification, uptime, future available periods, and status of processes.

  * Click **Download Logs** in the **Actions** column of a process to download its logs.

  * Click **Change Specification** in the **Actions** column of the `ocp_monagent` process to adjust the specification of OCP Agent for the host.

     <main id="notice" type='notice'>
     <h4>Notice</h4>
     <p><li>We recommend that you set the specification to no greater than 6 cores and 12 GiB of memory. </li><li>We recommend that the memory specified for the `ocp_monagent` process be lower than the available physical memory size of each host in the cluster. Otherwise, the configuration may fail. To view the memory usage of a host, choose <b>Performance Monitoring</b> > <b>Host Performance</b> > <b>Host Dimension</b> > <b>Memory</b>. </li><li>The specification change takes effect after OCP Agent restarts. During the restart, OCP cannot perform O&M operations, and some monitoring data will be lost. Proceed with caution. For more information, see <a href="400.restart-the-ocp-agent.md">Restart OCP Agent</a>. </li><li>For information about how to adjust the resource specification of OCP Agent for all hosts in a cluster, see <a href="../600.cluster-functions/300.manage-a-cluster/1200.manage-om-configuration/400.configuring-ocp-agent-resources.md">Configure resources for OCP Agent</a>. </li></p>
     </main>

## View monitoring data

On the **<UI-TERM key="ocp-v2.src.hook.useMenu.Monitoring">Monitoring</UI-TERM>** tab, you can view host monitoring data on the Host Performance, Host Resources and Host Processes tabs. For more information, see [View host performance](../880.manage-performance-monitoring/100.performance-monitoring-overview/300.view-host-performance.md), [View host resources](../880.manage-performance-monitoring/100.performance-monitoring-overview/700.view-host-resources.md), and [View host processes](../880.manage-performance-monitoring/100.performance-monitoring-overview/750.view-host-process.md).
