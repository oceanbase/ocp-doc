# Perform host standardization checks

Database clusters are the cornerstone of data. The performance and stability of database clusters are crucial for a production environment. To ensure the full play of the value of database clusters, we recommend that you perform standardization checks on hosts and fix possible risks before you deploy the database clusters.

This topic describes how to perform host standardization checks. For more information about the host check items, see [Host standardization check items](../850.host-features/700.host-standardized-inspection-scope.md).

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Host Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Auth.Role.Detail.All">All</UI-TERM>** menu of **<UI-TERM key="ocp-v2.page.Host.HostList">Hosts</UI-TERM>**

* The host is in the **<UI-TERM key="ocp-v2.Compaction.Detail.MiniCompactionChart.Idle">Idle</UI-TERM>** state.

## Procedure

1. Log in to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Host.HostList">Hosts</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.HostList">Hosts</UI-TERM>** page, find the entry to host standardization based on the actual business scenario.

   * If a new host is in the **<UI-TERM key="ocp-v2.src.constant.compaction.Idle">Idle</UI-TERM>** state and you have completed host standardization for the host or you have clicked **<UI-TERM key="ocp-v2.page.Host.NoMorePrompt">Do not remind me again</UI-TERM>** in the prompt in the **<UI-TERM key="ocp-performance-report.ReportTables.BasicInfo.ServerInfoServerTable.State">Status</UI-TERM>** column, you can click the **...** icon in the **<UI-TERM key="ocp-v2.Alarm.Rule.Operation">Actions</UI-TERM>** column and select **<UI-TERM key="ocp-v2.page.Host.HostStandardization">Host Standardization</UI-TERM>**.

        ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E4%B8%BB%E6%9C%BA%E6%A0%87%E5%87%86%E5%8C%96-2.png)

   * When a new host is in the **<UI-TERM key="ocp-v2.Compaction.Detail.MiniCompactionChart.Idle">Idle</UI-TERM>** state and standardization has not been performed for the host, hover the pointer over the ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E7%A9%BA%E9%97%B2%E5%9B%BE%E6%A0%87.png) icon in the **<UI-TERM key="ocp-v2.Backup.Service.State">Status</UI-TERM>** column of the host. In the prompt that appears, click **<UI-TERM key="ocp-v2.page.Host.HostStandardization">Host Standardization</UI-TERM>**.

        ![09162134](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E4%B8%BB%E6%9C%BA%E6%A0%87%E5%87%86%E5%8C%96-1.png)

4. Select the type of operation to perform on the host and click **<UI-TERM key="ocp-v2.page.Inspection.Ok">OK</UI-TERM>**.

   * **<UI-TERM key="ocp-v2.page.Host.CheckAndRepairAutomatically">Check & Auto Repair</UI-TERM>**: The system checks the host and automatically fixes the risks found in the check.
      * Click **<UI-TERM key="ocp-v2.page.Host.ViewTheFixReport">View Repair Report</UI-TERM>** to view the detailed risk details. If risks persist, manually fix the risks based on the information in the report.

5. After the check task is completed, click **View Check Report** to view the detailed check results.

      * After the risks are fixed, click **<UI-TERM key="ocp-v2.Detail.TakeOver.ReCheck">Recheck</UI-TERM>** to recheck the host.

         ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E6%A3%80%E6%9F%A5%E4%B8%94%E4%BF%AE%E5%A4%8D-1.png)

   * Check Only: The system only checks the host and will not automatically fix the risks found in the check.
      * After the check task is completed, click **<UI-TERM key="ocp-v2.page.Host.ViewInspectionReports">View Check Report</UI-TERM>** to view the detailed check results.

         ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E6%9F%A5%E7%9C%8B%E6%A3%80%E6%9F%A5%E6%8A%A5%E5%91%8A-1.png)

      * If the check report contains risks that can be automatically fixed, click **<UI-TERM key="ocp-v2.page.Host.AutomaticRepair.1">Auto Repair</UI-TERM>**. The system automatically fixes the risks.
      * For risks that cannot be automatically fixed, fix them manually according to the information in the report.
      * After the risks are fixed, click **<UI-TERM key="ocp-v2.Detail.TakeOver.ReCheck">Recheck</UI-TERM>** to recheck the host.

         ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E6%9F%A5%E7%9C%8B%E4%BF%AE%E5%A4%8D%E6%8A%A5%E5%91%8A%E8%AF%A6%E6%83%85-1.png)
