# View the details of tasks on a host

This topic describes how to view the details of O&M tasks on a host.

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only**, **Tenant Read-only**, or **Host Read-only** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.component.DatabasePrivilegeTransfer.PrivilegesCheckbox.All">All</UI-TERM>** menu of **<UI-TERM key="ocp-v2.page.Host.HostList">Hosts</UI-TERM>**

* The host is in the **<UI-TERM key="ocp-v2.src.constant.oceanbase.OperationsIn">Maintaining</UI-TERM>** state. A host is in the **<UI-TERM key="ocp-v2.src.constant.oceanbase.OperationsIn">Maintaining</UI-TERM>** state when you restart or reinstall OCP-Agent, or delete the host. For more information, see [Restart OCP-Agent](400.restart-the-ocp-agent.md), and [Reinstall OCP Agent](500.reinstall-ocp-agent.md).

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.HostList">Hosts</UI-TERM>**.

3. Find the target host and click **<UI-TERM key="ocp-v2.Detail.Report.ViewTasks">View Task</UI-TERM>** in the **<UI-TERM key="ocp-v2.component.CreateTagDrawer.Operation">Actions</UI-TERM>** column.

4. In the dialog box that appears, view the information about the task that is in progress on the host, and click the task ID to go to the task details page. On the task details page, you can perform operations such as viewing task logs, rolling back the task, and retrying the task.
