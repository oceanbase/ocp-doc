Modify a host
==================================

This topic describes how to modify a host.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Host Maintenance** permission
* **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.component.common.ServerDropdown.All">All</UI-TERM>** menu of **<UI-TERM key="ocp-v2.page.Host.HostList">Hosts</UI-TERM>**

**<UI-TERM key="ocp-v2.SQLDiagnosis.Component.Plan.Procedure">Procedure</UI-TERM>**
----------------------------------

1. Log on to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Host.HostList">Hosts</UI-TERM>** .

3. Click **<UI-TERM key="ocp-v2.ResourceManager.ResourceGroupTab.Modify">Modify</UI-TERM>** next to the host to modify.

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E4%BF%AE%E6%94%B9%E4%B8%BB%E6%9C%BA-1.png)

4. In the dialog box that appears, you can modify the host IP address, SSH port, host type, data center, type, credentials, host alias, and description.

5. Click **<UI-TERM key="ocp-v2.Resource.Component.UnitMigrateModal.Determine">OK</UI-TERM>** .
