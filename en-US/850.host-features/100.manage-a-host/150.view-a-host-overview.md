# View Host Details

On the Host Details page, you can view the basic information, OCP Agent information, and monitoring data of the host.

## Prerequisites

Make sure that the user who logs in to the OCP console has the following permissions:

* **Cluster Read-Only**, **Tenant Read-Only**, or **Host Read-Only** permissions.
* The **<UI-TERM key="ocp-v2.alarm.FormListWithExclude.ObproxyClusterAndHostWithExclude.All">All</UI-TERM>** permission on the host.

## View host basic information

You can view the host details and disk usage on the **<UI-TERM key="ocp-v2.TraceDetail.TraceContent.BasicInformation">Basic Information</UI-TERM>** tab, and perform tag management operations.

* On the **<UI-TERM key="ocp-v2.Alarm.Event.Detail.Details">Details</UI-TERM>** tab, you can view the host status, host name, host alias, SSH port, IDC, host type, host category, region, disk usage, service to which the host belongs, clock offset, current time, time zone, operating system, CPU architecture, CPU model, number of CPU cores, tags, total memory, and description.

    Hover the pointer over a host group tag to view all the tags of the host. You can click the edit icon to manage the tags. For more information, see [Manage tags](../../1600.system-management-features/300.manage-tags/100.tags-overview.md).

* On the **<UI-TERM key="ocp-v2.Host.Detail.Basic.DiskUsage">Disk Usage</UI-TERM>** tab, you can view the disk usage of each path, the amount of disk space used, the size of available disk space, the usage rate, and the mount directory.

## View OCP Agent information

You can view the details and process list of the OCP Agent on the **OCP Agent** tab.

* On the **<UI-TERM key="ocp-v2.Alarm.Event.Detail.Details">Details</UI-TERM>** tab, you can view the OCP Agent status, installation directory, installation time, version, log directory, and the last available time.

* On the **<UI-TERM key="ocp-v2.Host.Detail.OCPAgent.Processes">Processes</UI-TERM>** tab, you can view detailed process information, including the process ID, name, startup command, operating system user, port number, specification, running time, last available time, and status.

  * You can click **<UI-TERM key="ocp-v2.Host.Detail.OCPAgent.DownloadLogs">Download Logs</UI-TERM>** in the Actions column to download the logs of the current process.

  * You can click **<UI-TERM key="ocp-v2.Host.Detail.OCPAgent.ChangeSpecifications">Change Specification</UI-TERM>** in the Actions column of the `ocp_monagent` process to change the OCP Agent specification of the current host.

     <main id="notice" type='notice'>
     <h4>Notice</h4>
     <p><ul><li>We recommend that you set the maximum specification to 6C/12GiB. </li><li>We recommend that the memory configuration of the ocp_monagent process be lower than the available physical memory of all hosts in the cluster. Otherwise, resource allocation may fail. ## View monitoring information

You can view the monitoring data of **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.HostPerformance">Host Performance</UI-TERM>**, **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.HostResources">Host Resources</UI-TERM>**, and **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.HostProcess">Host Process</UI-TERM>** on the **<UI-TERM key="ocp-v2.src.hook.useMenu.Monitoring">Monitoring</UI-TERM>** tab. For more information, see [View host performance](../../880.manage-performance-monitoring/100.performance-monitoring-overview/300.view-host-performance.md), [View host resources](../../880.manage-performance-monitoring/100.performance-monitoring-overview/700.view-host-resources.md), and [View host process](../../880.manage-performance-monitoring/100.performance-monitoring-overview/750.view-host-process.md).
