# Host management operations

If you are assigned with the role of system administrator, host manager (HOST_MANAGER), or host read-only viewer (HOST_VIEWER), you can click **<UI-TERM key="ocp-v2.page.Host.HostList">Hosts</UI-TERM>** in the left-side navigation pane go to the **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.HostList">Hosts</UI-TERM>** page.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only**, **Tenant Read-only**, or **Host Read-only** permission
* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Auth.Role.Detail.All">All</UI-TERM>** menu of **<UI-TERM key="ocp-v2.page.Host.HostList">Hosts</UI-TERM>**

## View hosts

The **<UI-TERM key="ocp-v2.page.Host.HostList">Hosts</UI-TERM>** list displays the information of each host in the following columns: **<UI-TERM key="ocp-v2.page.Host.IpAddress">IP Address</UI-TERM>**, **<UI-TERM key="ocp-v2.Detail.Component.AddUserDrawer.Hostname">Host Name</UI-TERM>**, **<UI-TERM key="ocp-v2.page.Tags.Label">Tag</UI-TERM>**, **<UI-TERM key="ocp-v2.Host.Detail.Basic.HostType">Host Category</UI-TERM>**, **<UI-TERM key="ocp-v2.Detail.Resource.Unit.Models">Host Type</UI-TERM>**, **<UI-TERM key="ocp-v2.Component.AddZoneDrawer.ComputerRoom">IDC</UI-TERM>**, **<UI-TERM key="ocp-v2.Component.BinlogServerList.Region">Region</UI-TERM>**, **<UI-TERM key="ocp-v2.Detail.Overview.Cluster.1">Cluster</UI-TERM>**, **<UI-TERM key="ocp-v2.Backup.Service.Service">Service</UI-TERM>**, and **<UI-TERM key="ocp-performance-report.ReportTables.BasicInfo.ServerInfoServerTable.State">Status</UI-TERM>**.

* You can search for hosts by page and by host IP address, host name, or cluster name. You can search for multiple hosts at a time by specifying their IP addresses separated with spaces.
* You can hover the pointer over the **<UI-TERM key="ocp-v2.page.Tags.Label">Tag</UI-TERM>** column of a host to view all its tags. You can click the **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.Edit">Edit</UI-TERM>** icon to manage the tags. 
* You can filter hosts by **<UI-TERM key="ocp-v2.component.TagLabel.Label">Tag</UI-TERM>**, **<UI-TERM key="ocp-v2.page.Host.HostType">Host Category</UI-TERM>**, **<UI-TERM key="ocp-v2.Detail.TakeOver.Models">Host Type</UI-TERM>**, **<UI-TERM key="ocp-v2.Component.LBLoadBalanceConditon.DataCenter">IDC</UI-TERM>**, **<UI-TERM key="ocp-v2.Component.BackupStrategyDetail.Region">Region</UI-TERM>**, **<UI-TERM key="ocp-v2.page.Cluster.Cluster">Cluster</UI-TERM>**, **<UI-TERM key="ocp-v2.Backup.Service.Edit.Service">Service</UI-TERM>**, and **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.State">Status</UI-TERM>**.
* When a host is in the **<UI-TERM key="ocp-v2.src.constant.oceanbase.OperationsIn">Maintaining</UI-TERM>** state, you can click **<UI-TERM key="ocp-v2.Detail.Report.ViewTasks">View Task</UI-TERM>** in the **<UI-TERM key="ocp-v2.Settings.Credential.Host.Operation">Actions</UI-TERM>** column to go to the task details page of the cluster. On the task details page, you can perform operations such as viewing task logs, rolling back a task, and retrying a task. 
* You can click the IP address of a host to view its basic information, OceanBase Cloud Platform (OCP) Agent information, and monitoring data. For more information, see [View details of a host](150.view-a-host-overview.md).
* You can click the name of a cluster to go to the **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** page of the cluster and view its details.

You can also click the + icon in front of a host to view the following information: **<UI-TERM key="ocp-v2.page.Host.HostId">Host ID</UI-TERM>**, **<UI-TERM key="ocp-v2.src.component.AddHostDrawer.PortMapping">Port Mapping</UI-TERM>**, **<UI-TERM key="ocp-v2.page.Host.SshPort">SSH Port</UI-TERM>**, **<UI-TERM key="ocp-v2.Host.Component.BatchReinstallModal.OcpAgentVersion">OCP Agent Version</UI-TERM>**, **<UI-TERM key="ocp-v2.Host.Detail.Basic.OperatingSystem">Operating System</UI-TERM>**, **<UI-TERM key="ocp-v2.component.ZoneFormList.CpuArchitecture">CPU Architecture</UI-TERM>**, **<UI-TERM key="ocp-v2.Host.Detail.Basic.CpuModel">CPU Model</UI-TERM>**, **<UI-TERM key="ocp-v2.Tenant.UnitSpec.CpuCores">CPU Cores</UI-TERM>**, **<UI-TERM key="ocp-v2.page.Host.TotalMemory">Total Memory</UI-TERM>**, and **<UI-TERM key="ocp-v2.src.component.AddHostCredentialDrawer.Description">Description</UI-TERM>**.

| Parameter | Description |
|--------|-----------|
| Cluster | The cluster where the host resides, including the OceanBase cluster and the OBProxy cluster. You can click the name of a cluster to go to the **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** page of the cluster.  |
| Host Category | Physical hosts, container hosts, and Alibaba Cloud Elastic Compute Service (ECS) hosts are supported.<li>You can deploy multiple services of different types on a physical host. Do not deploy multiple services of the same type on the same physical host; otherwise, conflicts may arise. </li><li> You can deploy only one type of service on a container host. We recommend that you do not deploy an OceanBase cluster on a container host.  </li> |
| Status | The status of the host. Valid values: Newly Submitted, Idle, Online, Offline, Deleting, Re-installing OCP Agent, and Restarting OCP Agent.  |
| Port Mapping | The mapping relationship between OCP-Agent and the host and between the ocp_exporter process and the host in the following format: `<host port>:<OCP-Agent port in docker>`, and `<host port>:<ocp_exporter port 1 in docker>`.  |
