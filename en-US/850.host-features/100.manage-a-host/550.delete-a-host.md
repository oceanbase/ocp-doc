# Remove a host

This topic describes how to remove a host.

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Host Management** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.alarm.FormListWithExclude.ClusterWithExclude.All">All</UI-TERM>** menu of **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.HostList">Hosts</UI-TERM>**

* The host to remove is in the **<UI-TERM key="ocp-v2.src.constant.compaction.Idle">Idle</UI-TERM>** or **<UI-TERM key="ocp-v2.Component.RecoverableTimeRange.Offline">Offline</UI-TERM>** state.

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.HostList">Hosts</UI-TERM>**.

3. Find the host that you want to remove and click **<UI-TERM key="ocp-v2.component.ZoneFormCardList.Delete">Delete</UI-TERM>** in section ①. You can also select multiple hosts that you want to remove and click **<UI-TERM key="ocp-v2.Tenant.Detail.BatchDelete">Batch Delete</UI-TERM>** in section ②.

    <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p><ul><li>If you remove a host, all information and configurations of the host are permanently deleted from OCP. </li><li>If a host is in the <b>Offline</b> state, you can click only <b>Force Delete</b> to remove it. After the host is forcibly removed, all information and configurations of the host are permanently deleted from OCP. However, you must log on to the host and manually delete the internal services and configurations of the host. </li></ul></p>
    </main>

4. In the dialog box that appears, click **<UI-TERM key="ocp-v2.src.constant.obproxy.Delete">Delete</UI-TERM>**.
