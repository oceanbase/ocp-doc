# Reinstall OCP Agent

This topic describes how to reinstall OceanBase Cloud Platform (OCP) Agent.

<main id="notice" type='notice'>
<h4>Notice</h4>
<p>The reinstallation may interrupt ongoing cluster O&amp;M operations and cause absence of host monitoring for a period of time. Proceed with caution. </p>
</main>

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Host Maintenance** permission
* **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.component.common.ObUserSelect.All">All</UI-TERM>** menu of **<UI-TERM key="ocp-v2.page.Host.HostList">Hosts</UI-TERM>**

## Procedure

1. Log on to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Host.HostList">Hosts</UI-TERM>**.

3. Click **<UI-TERM key="ocp-v2.src.constant.compute.ReloadOcpAgent">Reinstall OCP Agent</UI-TERM>** in the **<UI-TERM key="ocp-v2.page.Host.Operation">Actions</UI-TERM>** column of the target host.

   ![09162134](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E9%87%8D%E8%A3%85agent1.png)

4. In the dialog box that appears, select the software package that matches the hardware architecture of the host and click **<UI-TERM key="ocp-v2.MultiCluster.Detail.FailoverModal.Determine">OK</UI-TERM>**.

   ![1122](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E7%A1%AE%E8%AE%A4%E9%87%8D%E8%A3%851.png)

<main id="notice" type='explain'>
<h4>Note</h4>
<p>If you want to use a custom port number for OCP Agent, contact OCP Technical Support for assistance. </p>
</main>
