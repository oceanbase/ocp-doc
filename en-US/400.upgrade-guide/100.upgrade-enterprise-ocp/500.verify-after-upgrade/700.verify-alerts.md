# Verify alerts

After upgrading OCP, you must log in to the OCP console to verify whether the features are working properly.

## Procedure

1. Log in to the OCP console by using the admin account.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.hook.useMenu.AlarmCenter">Alert Center</UI-TERM>**.

3. Verify the alert feature:

   * On the **<UI-TERM key="ocp-v2.Alarm.Rule.AlertRules">Alert Rules</UI-TERM>** page, check whether any alert rules are not enabled. You can also disable an alert rule on the page that appears when you create or edit an alert rule.

   * On the **<UI-TERM key="ocp-v2.Alarm.Rule.Detail.AlertRules">Alert Rules</UI-TERM>** page, click **Group Management** to check whether the copy feature is supported.

     You can click **<UI-TERM key="ocp-v2.Auth.User.Detail.Copy">Copy</UI-TERM>** to quickly create an alert rule group that is the same as the source group (including the alert rules in the source group).

   * After you go to the specific alert page, click the language icon in the upper-right corner to switch the language and check whether the alert events are properly localized.

   * Check the link for handling suggestions of alert events.
