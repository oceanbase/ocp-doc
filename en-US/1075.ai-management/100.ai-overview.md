# Overview

## Background information

OceanBase Database is a native distributed database system. Its complex distributed architecture, involving multi-node collaboration and data distribution, presents significant challenges in management and technical support. Administrators must not only be familiar with routine database operations and maintenance but also have a deep understanding of distributed system principles, including complex issues such as data consistency and load balancing. In terms of technical support, once a failure occurs, it is challenging to search for relevant documentation and diagnose the issue, as it requires considering factors such as network, node, and software configurations. The high level of technical expertise and extensive experience required of the technical support team poses a significant burden for many enterprises.

To address the challenges of managing and providing technical support for OceanBase Database, we aim to leverage the capabilities of PowerRAG and large language models to implement intelligent Q&A functionality that can be activated from any interface. This approach will help users better understand and manage OceanBase Database, effectively reducing maintenance costs and improving service quality and efficiency.

## Features

OceanBase AI Assistant integrates advanced large language models (LLMs) and retrieval-enhanced generation (PowerRAG) technology, along with the built-in OceanBase knowledge base and native vector and full-text indexing capabilities of the database. This combination forms the core engine for intelligent Q&A. Based on PowerRAG's multi-round retrieval mechanism, the LLM can precisely access technical documentation, best practices, and failure cases stored in the knowledge base. This enables the AI assistant to provide systematic and professional solutions for key database management scenarios, including system configuration optimization, failure diagnosis and repair, and performance bottleneck analysis.

In terms of large model configuration, OCP allows you to flexibly integrate third-party large model services such as Tongyi Qianwen from Alibaba Cloud, Baidu's ErnieBot, and DeepSeek, or deploy a self-built large model through the **System Management** > **External Integration** > **AI Model** module. You can then configure LLMs, embedding models, and reranking models (optional) to quickly activate the AI assistant feature.

## Technical principles

In OCP, the AI assistant stores documents as vectors in OceanBase Database. When you use the **Smart Chat** feature to ask questions, the AI assistant converts the questions into vectors using the large model. It then searches for similar vectors in the database, retrieves the corresponding document content, and sends the documents and questions to the large model. The large model generates a more accurate answer based on the provided documents.

## Prerequisites

Before using the AI intelligent chat feature, ensure that the current OCP meets the following conditions:

* The MetaDB of OCP must be V4.3.5 BP2 or later.
* If OCP is newly deployed, the OAT version used to deploy OCP must be V4.3.2 or later.

## Procedure

Before enabling the AI intelligent chat feature, you need to perform the following configurations:

1. [Connect to an AI model vendor](../1600.system-management-features/450.manage-external-integration/100.manage-ai-models/100.link-a-model.md). After connecting to a built-in AI model vendor, all models of the vendor can be selected in the system model settings.
2. (Optional) [Add a model](../1600.system-management-features/450.manage-external-integration/100.manage-ai-models/200.add-a-model.md). If the built-in vendors or models do not meet your needs, you can add custom vendors or models.
3. [Set the system model](../1600.system-management-features/450.manage-external-integration/100.manage-ai-models/300.set-system-model.md). Select the model that you want to use for the AI assistant from the existing models in the system.
4. Enable the AI intelligent chat feature.
