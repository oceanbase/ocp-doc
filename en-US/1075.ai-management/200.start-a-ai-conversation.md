# Start a conversation

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OCP Enterprise Edition. OCP Community Edition does not provide this feature. </p>
</main>

This topic describes how to use the intelligent conversation and knowledge base search features of the AI assistant in OCP.

## Start an intelligent conversation

You can refer to this topic to start an AI intelligent conversation. The AI assistant analyzes, diagnoses, and interprets your questions based on the large model.

### Prerequisites

You have completed the following operations:

* [Connected a model vendor](../1600.system-management-features/450.manage-external-integration/100.manage-ai-models/100.link-a-model.md) or [Added a custom model](../1600.system-management-features/450.manage-external-integration/100.manage-ai-models/200.add-a-model.md).
* [Set the system model](../1600.system-management-features/450.manage-external-integration/100.manage-ai-models/300.set-system-model.md).

### Procedure

1. Log in to the OCP console.

2. On any page of the OCP console, click the AI assistant icon in the upper-right corner.

3. On the AI assistant page, select **Intelligent Conversation**.

4. Click **Enable**.

5. In the dialog box, enter any question about OceanBase Database. The AI assistant outputs the answer based on the large model.

## Use the knowledge base search

You can refer to this topic to start a normal conversation. A normal conversation only uses the knowledge base search feature of OceanBase Database and does not enable the large model content generation.

### Procedure

1. Log in to the OCP console.

2. On any page of the OCP console, click the AI assistant icon in the upper-right corner.

3. On the AI assistant page, select **Knowledge Base Search**.

4. Click **Enable**.

5. In the dialog box, enter the content you want to search for. OCP outputs the answer based on the knowledge base.
