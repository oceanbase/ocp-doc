# Create a user

This topic describes how to create a user.

## Background information

When you use OceanBase Cloud Platform (OCP), we recommend that you create users with different permissions and assign the minimum necessary permissions to each user. This way, each user can perform only operations within in the authorized scope. This prevents misoperations by non-professionals and information leakage, thereby ensuring information security.

## Prerequisites

You have logged in to the OCP console and been assigned the **ADMIN** or **ORG_ADMIN** role.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.Auth.Role.New.UserManagement">User Management</UI-TERM>**.

3. In the upper-right corner of the **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetail.User">User</UI-TERM>** tab, click **<UI-TERM key="ocp-v2.User.MySQL.CreateUser">Create User</UI-TERM>**.

4. Specify the following basic information of the user.

   |  Parameter     |       Description         |
   |-----------|---------------------------------------|
   | Username    | Required. The username must be 4 to 48 characters in length and start with a lowercase letter. The username can contain lowercase letters, digits, underscores (_), hyphens (-), and periods (.). The username cannot be changed after the user is created.   |
   | Password      | Required. The password must be 8 to 32 characters in length. It must contain characters of at least three of the following types: digits (0 to 9), uppercase letters (A to Z), lowercase letters (a to z), and special characters. Supported special characters are the following ones: <code>~!@#%^&*_-+=\|(){}[]:;,.?/$`'"<>\\</code>. |
   | Email Address      | Required.         |
   | Phone Number  | Optional.         |
   | Organization       | Required. If you log in as the ORG_ADMIN role, this parameter is disabled. </br>If the required organization is unavailable, you can select **<UI-TERM key="ocp-v2.Auth.Org.CreateOrg.CreateAnOrganization">Create Organization</UI-TERM>** from the drop-down list to create one.          |
   | Department      | Optional.         |
   | Description      | Optional.         |

   ![image.png](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/435/1625.png)

5. Assign roles to the user.

   * You can select existing roles as needed. You must select at least one role.

   * If the existing roles cannot satisfy your needs, you can click **<UI-TERM key="ocp-v2.Auth.Role.CreateARole">Create Role</UI-TERM>** in the upper-right corner to create a role and assign it to the new user. For more information, see [Create a role](../1600.system-management-features/200.manage-users/200.manage-a-role/100.create-a-role.md).

   * If you log in as the ORG_ADMIN role, you can select only existing roles in the organization.

   ![050807](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/435/1626.png)

6. Toggle on **<UI-TERM key="ocp-v2.Auth.User.New.AccessControl">Access Control</UI-TERM>** and configure the access control parameters.

   * **<UI-TERM key="ocp-v2.Auth.User.New.MaximumNumberOfVisits">Upper Limit of Access Requests</UI-TERM>**: Specify the maximum number of times that the user can access OCP per unit time.

   * **<UI-TERM key="ocp-v2.Auth.User.New.FineGrainedAccessControl">Fine-grained Access Control</UI-TERM>**: Specify the maximum number of times that the user can access hosts, tenants, alerts, and resources per unit time.

   ![050806](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/435/1627.png)

7. Click **<UI-TERM key="ocp-v2.ResourceManager.ResourceGroupTab.CreateResourceGroup.Submit">Submit</UI-TERM>** in the lower-right corner of the page.
