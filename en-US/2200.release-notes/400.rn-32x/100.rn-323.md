# OCP V3.2.3

<!--#RNDate#2021-12-27-->

OceanBase Cloud Platform (OCP) V3.2.3 introduces new features including log query on the web interface and parameter template functionality. It also brings significant updates to monitoring and alerting. Performance monitoring now supports drill-down analysis, and some performance metrics have been refined to help you understand and analyze your business more comprehensively. SQL diagnostics supports setting SQL throttling, plan binding, and binding history for queries. Performance reports have added statistics display for PRC, memory, and parameter configuration changes. The alerting feature in this version not only supports multiple thresholds but also introduces 10 built-in alerts to enhance OCP's operational capabilities for OceanBase clusters.

## Version information

* **Version:** V3.2.3

* **Previous version:** V3.1.5

* **Release date:** December 27, 2021

* **Supported upgrade path:** You can directly upgrade from OCP V2.3.x and later versions to this version. For versions earlier than OCP V2.3.0, you must first upgrade to V2.3.x and then to this version.

## Supported OceanBase Database versions

OceanBase Cloud Platform V3.2.3 supports the following versions of OceanBase Database:

* OceanBase V1.4.x

* OceanBase V2.1.x

* OceanBase V2.2.x

* OceanBase V3.1.x

* OceanBase V3.2.x

## New features

* The **<UI-TERM key="ocp-v2.page.Monitor.Monitoring">Performance Monitoring</UI-TERM>** section for clusters and tenants supports drill-down analysis.

  With the drill-down feature, you can directly view monitoring metrics at the tenant or OBServer node level without navigating through complex paths to the tenant's **<UI-TERM key="ocp-v2.Instance.Monitor.PerformanceMonitoring">Performance Monitoring</UI-TERM>** page or the host's **<UI-TERM key="ocp-v2.Host.Detail.Surveillance">Monitoring</UI-TERM>** tab.

* A new log query feature is available. You can set query conditions on the OCP interface to view the required logs. The query scope covers all types of logs, including those on OBServer nodes, OBProxies, and hosts. This allows you to easily search logs without downloading them.

* SQL diagnostics supports binding indexes, plans, and setting SQL throttling for an SQL statement on its details page, along with displaying the binding history.

* Ten built-in alerts are introduced to provide comprehensive monitoring and early warning for active session count, clog synchronization latency, and cross-cloud management of OCP. Alerts also support multiple thresholds, providing stronger assurance for the performance and stability of OceanBase clusters.

* A new parameter template feature is available. If you need to create multiple tenants or clusters with the same configuration, you can create a parameter template first and then apply it when creating a tenant via **<UI-TERM key="ocp-v2.Detail.Tenant.NewTenant">Create Tenant</UI-TERM>** or a cluster via **<UI-TERM key="ocp-v2.page.Welcome.CreateACluster">Create Cluster</UI-TERM>**. This avoids repeating cluster/tenant parameter configurations when creating a cluster via **<UI-TERM key="ocp-v2.Tenant.New.CreateACluster">Create Cluster</UI-TERM>** or a tenant via **<UI-TERM key="ocp-v2.Topo.TopoGraph.CreateATenant">Create Tenant</UI-TERM>**.

  * For creating a template, refer to: [Manage cluster parameter templates](https://www.oceanbase.com/docs/enterprise-oceanbase-ocp-cn-10000000000377800).

  * For creating a cluster or tenant, refer to: [Create a cluster](https://www.oceanbase.com/docs/enterprise-oceanbase-ocp-cn-10000000000378283) and [Create a tenant](https://www.oceanbase.com/docs/enterprise-oceanbase-ocp-cn-10000000000377507).

## Feature enhancements

* The performance monitoring feature has been optimized. Relevant metrics for clusters and tenants have been further subdivided to provide you with more detailed performance information. These metrics include:

  * Cluster: **QPS**, **Query response time**, **TPS**, and **Transaction response time**.

  * Tenant: **Request waiting queue**, **TPS**, and **Transaction response time**.

* The logic for upgrading and restarting OBServer nodes has been optimized to support upgrades and restarts while the node is stopped. This optimization meets your need to quickly upgrade and restart OBServer nodes when business continuity is not a requirement.

* The **Performance report** feature for clusters has been improved. The report now includes statistics for **Memory**, **RPC**, and **Parameter configuration changes**.

## Bug fixes

OceanBase Cloud Platform V3.2.3 fixes the following issues:

* Incomplete SQL diagnostic collection and slow frontend loading.

* Data loss in the performance report.

* Abnormal retry and abort behavior after a task fails.

## Version usage limitations

### Hardware requirements

OCP-Server can be installed on physical servers or run in Docker containers. OCP-Server supports high-availability deployment across multiple nodes.

The minimum hardware requirements for an OCP-Server node are listed in the following table.

| Hardware | Requirements |
| ----- | ------------------------------------ |
| CPU | <li>x86_64, 8-core</li><li>ARM AArch64 architecture, 8-core</li> |
| Memory | Available Memory: 16 GB |
| NIC | 10 Gbit/s NIC |

OCP-Agent consumes very few resources and has no specific hardware requirements for the installation node.

### Operating system requirements

The operating system requirements for installing the OCP server (including OCP-Agent) are listed in the following table.

| Server Type | Operating System | Supported Versions |
| ------------- | ------------ | ----------- |
| x86_64 | RHEL | 7.2 and later |
| x86_64 | CentOS | 7.2 and later |
| x86_64 | AliOS | 7.2 and later |
| x86_64 | openSUSE | 12 SP3 and later |
| ARM aarch64 | AliOS | 7.2 and later |
| ARM aarch64 | NeoKylin | 7.6 |
| ARM aarch64 | Huawei EulerOS | 2.0 SP8 |

### Client requirements

Users typically access OCP services through a web browser. The client requirements are as follows.

| Browser | Minimum Version |
| --------- | ------ |
| Chrome | 81 |
| Firefox | 64 |
| Safari | 10 |

| Operating System | Minimum Version |
| ------ | ------ |
