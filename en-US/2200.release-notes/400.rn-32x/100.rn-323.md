# OCP V3.2.3

#RNDate#2021-12-27

OceanBase Cloud Platform (OCP) V3.2.3 introduces the ability to query logs through a graphical interface and parameter templates. It also features significant updates in monitoring and alerting capabilities. Performance monitoring now supports drill-down analysis, with detailed performance metrics for comprehensive business understanding. SQL diagnostics allow setting SQL throttling, plan binding, and query binding history. Performance reports now include statistics on PRC, memory, and parameter configuration changes. The alerting feature now supports multiple thresholds and includes 10 new built-in alerts to enhance OCP's operational capabilities for OceanBase clusters.

## Version information

* **Version:** V3.2.3

* **Previous Version:** V3.1.5

* **Date of release:** December 27, 2021

* **Supported upgrade path:** Direct upgrade from OCP V2.3.x and later is supported. Upgrades from OCP versions earlier than V2.3.0 require first upgrading to V2.3.x before upgrading to this version.

## Supported OceanBase Database versions

OceanBase Cloud V3.2.3 supports the following OceanBase Database versions:

* OceanBase V1.4.x

* OceanBase V2.1.x

* OceanBase V2.2.x

* OceanBase V3.1.x

* OceanBase V3.2.x

## New features

* Drill down the **<UI-TERM key="ocp-v2.Monitor.AddMonitor.PerformanceMonitoring">Performance Monitoring</UI-TERM>** for clusters and tenants.

  By using the drill-down feature, you can directly view the metrics for a specified tenant or OBServer node in the tenant or OBServer node page without needing to manually switch to the **<UI-TERM key="ocp-v2.page.Monitor.Monitoring">Performance Monitoring</UI-TERM>** page of the tenant or the **<UI-TERM key="ocp-v2.Host.Detail.Surveillance">Monitoring</UI-TERM>** tab of the host.

* The query feature for logs is provided, which allows you to set search conditions in the OCP console and view the logs you need. The query feature covers logs of OBServer, OBProxy, and hosts. You can quickly search for logs without downloading them.

* SQL Diagnostics supports binding indexes, plan binding, and throttling for SQL, as well as querying bind history on the SQL details page.

* Added 10 new built-in alert types to monitor and alert for metrics such as active sessions, CLog synchronization latency, and OCP cross-cloud control. It now supports multiple threshold alerting, offering more reliable performance and stability assurance for OceanBase clusters.

* Support for template parameter creation. You can create parameter templates and apply these templates when you create a tenant or a cluster. This can help you avoid repeatedly configuring parameters when you create a tenant or a cluster.

  * For information about how to create a template, see [Cluster parameter templates](https://www.oceanbase.com/docs/enterprise-oceanbase-ocp-cn-10000000000377800).

  * To create a cluster or a tenant, see [Create a cluster](https://www.oceanbase.com/docs/enterprise-oceanbase-ocp-cn-10000000000378283) and [Create a tenant](https://www.oceanbase.com/docs/enterprise-oceanbase-ocp-cn-10000000000377507).

## Enhancements

* Enhanced the performance monitoring functionality by further subdivide the metrics for clusters and tenants. These metrics include:

  * Cluster: **QPS**, **Query response time**, **TPS**, **Transaction response time**.

  * Tenant: **Waiting Request Queue** , **Transactions per second (TPS)**, and **Transaction Response Time**

* Optimizes and enhances the logic for upgrading and restarting OBServer nodes, supporting scheduled maintenance upgrades and restarts. This optimization allows you to quickly upgrade and restart OBServer nodes without requiring business continuity.

* Enhance the **<UI-TERM key="ocp-v2.Detail.Report.PerformanceReport">Performance Report</UI-TERM>** feature. Performance reports now show new statistics including **<UI-TERM key="ocp-v2.src.component.DeleteUnitSpecModal.Memory">Memory</UI-TERM>**, **RPC**, and **<UI-TERM key="ocp-performance-report.pages.AWR.ParameterConfigurationChanges">Parameter Changes</UI-TERM>**.

## Fixes

The OceanBase Cloud platform version V3.2.3 fixes the following issues:

* Resolved incomplete SQL diagnostic collection and slow front-end loading issues.

* Data loss in performance reports.

* Task retry and abandon exceptions after failure.

## Limitations

### Hardware requirements

OCP-Server can be installed on a physical server or in a Docker container. OCP-Server supports multi-node high availability deployment.

The minimum hardware requirements for OCP-Server nodes are shown in the following table.

| Hardware |                 Requirements                 |
|-----|------------------------------------|
| CPU | <li>X86_64, 8 cores</li><li>ARM aarch 64 architecture, 8 cores</li> |
| Memory  | 16 GB of available memory                         |
| NIC  | 10 GbE NIC                               |

OCP-Agent consumes very little resources and has no special requirements for the installation node's hardware.

### Operating system requirements

The following table shows the operating system requirements for installing OCP-Server (including OCP-Agent).
