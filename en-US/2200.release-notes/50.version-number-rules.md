# Version number rules

This topic describes the version number rules of OCP and their meanings.

OCP is iterated and optimized continuously. New versions of OCP are released periodically. The features and functions of different versions of OCP may vary significantly. Therefore, you must identify the version number of OCP to obtain accurate documentation information.

The version number of OCP is in the V.x.y.z-t format, where:

* x indicates the major version. This version usually involves architecture upgrades or the release of major new features.

* y indicates the planned iterative version. This version is part of the normal iteration plan and includes important feature or function updates and improvements.

* z indicates the release update version. This version includes minor feature or function updates and fixes for known issues.

* t is usually a date and time string, such as 4.3.2-20241011163611 or 4.3.5-20250610150154. This is used when a higher version number is required for feature updates or bug fixes.

## View the version number

After you deploy OCP, you can view the version number of OCP.

1. Log in to the OCP console.

2. Hover the pointer over **Help** in the upper-right corner and click **About OCP**.

3. In the dialog box that appears, view the version number of OCP. For example, the version number is 4.3.2-20241011163611.
