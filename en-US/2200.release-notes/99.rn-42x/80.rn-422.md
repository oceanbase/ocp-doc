# OCP V4.2.2

<!--#RNDate#2024-2-21-->

## V4.2.2

OCP V4.2.2 officially supports OceanBase Database V4.2.2 and fully implements the end-to-end management capabilities of the OceanBase full-chain traceability module. It supports features such as cluster migration out of OceanBase Database and OBProxy, as well as takeover and migration out of arbitration services. The completeness of basic O&M features has reached 95%. This version also introduces a powerful feature: the monitoring dashboard, which allows users to monitor in real time during peak business scenarios and customize performance monitoring. In terms of backup and restore, it supports Huawei Cloud OBS, further enhancing support for storage media of major domestic cloud service providers. Additionally, this version optimizes and enhances 30+ features in monitoring alerts, task management, backup and restore, password management, and tag management. It provides 900+ product error codes, significantly improving product usability and stability, and builds a more simple and user-friendly full-lifecycle database management platform to help users better manage OceanBase Database.

### Version information

### New features

#### OceanBase V4.x support

* Added monitoring metrics: maximum tenant-level log synchronization delay. For more information, see [Clog synchronization delay
](https://www.oceanbase.com/docs/common-ocp-1000000000585563).
* Added support for OceanBase read-only parameter configurations (EDIT_LEVEL='READONLY').
* Added support for network primary/standby replication roles in OceanBase Oracle tenant mode, simplifying user authorization operations.
* Added support for GIS types in OceanBase Oracle tenant mode.
* Added support for granting PL permissions to global users in OceanBase MySQL mode.

#### Dashboard

The dashboard is designed to meet the needs of users in scenarios such as monitoring during major events like Double 11 and custom monitoring views. It provides features such as multi-instance and multi-metric monitoring view comparisons, chart interactivity, and support for seven chart types including pie charts, tables, and bar charts. This helps monitor the overall performance and running status of the database system. For more information, see [Dashboard](https://www.oceanbase.com/docs/common-ocp-1000000000584639).

#### Tag management

OCP tags offer organization, categorization, quick search and filtering, task and project management, team collaboration, and sharing capabilities. They provide a flexible and efficient way to help users organize, search, and manage various database objects, enhancing team collaboration. For more information, see [Manage tags](https://www.oceanbase.com/docs/common-ocp-1000000000585054).

### Key features

#### Monitoring dashboard

The monitoring dashboard primarily addresses scenarios such as "monitoring" during events like Double 11 and supports user-defined monitoring views. On the monitoring dashboard tab, you can create multiple monitoring dashboard pages. Each monitoring dashboard page can include multiple charts to display different metrics and data, such as multi-instance and multi-metric monitoring views, as well as different monitoring metrics for single or multiple clusters. The monitoring dashboard also provides four comparison modes: year-over-year, day-over-day, week-over-week, and month-over-month, helping you easily identify data anomalies. You can also choose from seven different chart types, such as line charts, pie charts, and tables, based on the characteristics and requirements of your data to better understand and analyze it. Additionally, the monitoring dashboard supports grouping, allowing you to organize related metrics into the same group for unified management, facilitating better monitoring and analysis of database status. The monitoring dashboard supports features such as chart dragging, chart zooming, drilling down (in single-metric scenarios), and chart linkage, helping you achieve the goal of monitoring the overall performance and operational status of the database system.

#### Tag management

OCP supports tagging operations for five object types: OceanBase clusters, arbitration services, tenants, OBProxy clusters, and hosts. It also supports management features such as creating, editing, deleting, and modifying associated objects. You can choose from two different styles to display tags based on your business needs. On various object type pages, such as OceanBase clusters, you can tag clusters to assign business meanings, such as system type and manager. You can also use tag filtering capabilities to organize, search, and manage cluster objects, improving your work efficiency.

### Fixed issues

OCP V4.2.2 mainly fixed the following issues:

* Fixed the issue where OceanBase Database V4.2 failed to upgrade due to the `EnableRebalance` parameter setting.
* Fixed the issue where the `obproxyd.sh` script failed to start after a server restart.
* Fixed the issue where the startup item did not take effect on Kylin V10 systems.
* Fixed the issue where the resource display ratio of the log disk was abnormal.
* Optimized the monitoring query logic to reduce the occurrence of garbage collection.
* Optimized the access performance of multiple frontend pages to improve access speed under the same management scale.

### Limitations

#### Hardware requirements

OCP-Server can be installed on a physical server or in a Docker container. OCP-Server supports multi-node high availability deployment.

The following table lists the minimum hardware requirements for OCP-Server nodes.

| Hardware | Requirements |
|-------|------------------------------------|
| CPU  | <li>X86_64, 8 cores</li><li>ARM aarch 64 architecture, 8 cores</li> |
| Memory | 16 GB of available memory |
| NIC | 10 GbE |

OCP-Agent consumes very few resources and does not have special requirements for the hardware resources of the installation node.

#### Operating system requirements

The following table lists the operating system requirements for installing OCP-Server (including OCP-Agent).

| Server type    | Operating system    | Supported versions   |
|-------------|------------|-----------|
| x86_64   | RHEL    | 7.2 and later |
| x86_64   | CentOS   | 7.2 and later |
| x86_64   | AliOS   | 7.2 and later |
| x86_64   | openSUSE  | 12SP3 and later |
| ARM aarch64 | AliOS   | 7.2 and later |
