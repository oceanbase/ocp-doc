# OCP V3.3.5

<!--#RNDate#2023-07-25-->

## V3.3.5 BP2

### Version information

* **Version:** V3.3.5 BP2

* **Previous version:** V3.3.5 BP1

* **Release date:** November 29, 2023

### Bug fixes

* Reduced the switchover time for Switchover.

* Fixed an issue where managing a large number of tenants could result in an unexpected number of threads being generated.

* Fixed an issue where only data from the last hour could be viewed in monitoring data.

* Fixed an issue where the downgrade for exceeding SQL collection memory limits did not take effect.

## V3.3.5

The new version of OceanBase Cloud Platform (OCP) primarily introduces additional audit events and improves and optimizes other features.

### Version information

* **Version:** V3.3.5

* **Previous version:** V3.3.4

* **Version release date:** July 25, 2023

* **Supported upgrade path:** You can directly upgrade from OCP V2.3.x and later versions to this version. For versions earlier than OCP V2.3.0, you must first upgrade to V2.3.x and then to this version.

### Supported OceanBase Database versions

OCP V3.3.5 supports the following versions of OceanBase Database:

* OceanBase V1.4.x

* OceanBase V2.1.x

* OceanBase V2.2.x

* OceanBase V3.1.x

* OceanBase V3.2.x

### New features

* Added a tenant-level monitoring metric **Thread Usage** to facilitate troubleshooting.

* Optimized the calculation logic for the tenant-level monitoring metric **CPU Consumption** to provide a more accurate resource consumption ratio.

### Fixed issues

OCP V3.3.5 fixes the following issues:

1. Fixed an issue where upgrading from V3.3.4-BP1 to a higher V3.x version caused errors on the diagnostics page.

2. Fixed other issues in upgrades from V3.3.x-BP series versions.

3. Optimized the software package download logic to better support concurrent upgrades on multiple hosts.

4. Optimized the data management logic to support automatic cleanup of historical task data older than 30 days, reducing storage space usage.

### Known issues

None.

### Version usage limitations

#### Hardware requirements

OCP-Server can be installed on physical servers or run in Docker containers. OCP-Server supports high-availability deployment across multiple nodes.

The minimum hardware requirements for an OCP-Server node are listed in the following table.

| Hardware | Requirements |
| ------- | ------------------------------------ |
| CPU | <li>x86_64 architecture, 8-core processor</li><li>ARM AArch64 architecture, 8-core processor</li> |
| Memory | Available Memory: 16 GB |
| NIC | 10 Gbit/s NIC |

OCP-Agent consumes very few resources and has no specific hardware requirements for the installation node.

#### Operating system requirements

The operating system requirements for installing the OCP server (including OCP-Agent) are listed in the following table.

| Server Type | Operating System | Supported Versions |
| ------------- | ------------ | ----------- |
| x86_64 | RHEL | 7.2 and later |
| x86_64 | CentOS | 7.2 and later |
| x86_64 | AliOS | 7.2 and later |
| x86_64 | openSUSE | 12 SP3 and later |
| ARM aarch64 | AliOS | 7.2 and later |
| ARM aarch64 | NeoKylin | 7.6 |
| ARM aarch64 | Huawei EulerOS | 2.0 SP8 |

#### Client requirements

Users typically access OCP services through a web browser. The client requirements are as follows.

| Browser | Minimum Version |
| --------- | ------ |
| Chrome | 81 |
| Firefox | 64 |
| Safari | 10 |
| Edge | 13 |

If you need to access OCP from a device running iOS, the version requirements are listed in the following table.

| Operating System | Minimum Version |
| ------ | ------ |
| iOS | 10 |

For the best user experience, we recommend using a display with a resolution greater than 1440 × 810.
