## V3.3.5 BP2

### Version information

* **Version:** V3.3.5 BP2

* **Previous version:** V3.3.5 BP1

* **Version release date:** November 29, 2023

### Bug fixes

* Reduces the switchover time.

* Fixes the issue where an unexpected number of threads are generated when managing a large number of tenants.

* Fixes the issue where only the data of the last hour can be viewed in the monitoring data.

* Fixes the issue where degradation of an SQL collection process that causes memory overflow does not take effect.

## V3.3.5

OceanBase Cloud Platform (OCP) V3.3.5 introduces new audit events and enhances and optimizes other features.

### Version information

* **Version:** V3.3.5

* **Previous version:** V3.3.4

* **Version release date:** July 25, 2023

* **Supported upgrade path:** OCP V2.3.x and later versions can be directly upgraded to this version. For OCP versions earlier than V2.3.0, upgrade them to a V2.3.x version first before upgrading to this version.

### Supported OceanBase Database versions

OCP V3.3.5 supports OceanBase Database of the following versions.

* OceanBase V1.4.x

* OceanBase V2.1.x

* OceanBase V2.2.x

* OceanBase V3.1.x

* OceanBase V3.2.x

### New features

* The new **<UI-TERM key="ocp-v2.page.Overview.Content.ThreadUsage">Thread Usage</UI-TERM>** metric at the tenant level is added. This metric is convenient for troubleshooting.

* The calculation logic of the **CPU consumption** metric at the tenant level is optimized, providing more accurate resource usage.

### Bug fixes

OCP V3.3.5 fixes the following issues:

1. Fixes the issue where an error occurs in the diagnostic page when V3.3.4-BP1 is upgraded to V3.x of a higher version.

2. Fixes other issues in the upgrade of V3.3.x-BP series versions.

3. Optimizes the package download logic to better support concurrent upgrade on multiple hosts.

4. Optimizes the data management logic to support automatic cleanup of task data from 30 days ago to reduce the storage space usage.

### Known issues

None.

### Version limitations

#### Hardware requirements

OCP-Server can be installed on physical servers and also supports installation and operation in Docker containers. OCP-Server supports a multi-node high-availability deployment.

The following table lists the minimum hardware requirements for an OCP-Server node.

| Hardware | Requirement |
|-------|------------------------------------|
| CPU   | <li>X86 X64 architecture, 8-core CPU</li><li>ARM aarch 64 architecture, 8-core CPU</li> |
| Memory  | 16 GB available memory |
| NIC  | 10 GB NIC |

OCP-Agent consumes few resources and does not have specific hardware requirements.

#### Operating system requirements

The following table lists the operating system requirements for installing OCP Server and OCP-Agent.

| Server type | Operating system | Supported version |
|-------------|------------|-----------|
| x86_64      | RHEL       | RHEL 7.2 and later |
| x86_64      | CentOS     | CentOS 7.2 and later |
| x86_64      | AliOS      | AliOS 7.2 and later |
| x86_64      | openSUSE   | openSUSE 12SP3 and later |
| ARM aarch64 | AliOS      | AliOS 7.2 and later |
| ARM aarch64 | NeoKylin       | NeoKylin 7.6       |
| ARM aarch64 | Huawei EulerOS | Huawei EulerOS 2.0 SP8   |

#### Client requirements

General users access OCP through a Web browser. The following table lists the client requirements.

| Browser | Minimum version |
|---------|------|
| Chrome  | 81   |
| Firefox | 64   |
| Safari  | 10   |
| Edge    | 13   |

If you want to access OCP from an iOS device, refer to the following table for the OS requirements.

| Operating system | Minimum version |
|------|------|
| iOS  | 10   |

For the best user experience, we recommend that you use a display with a screen resolution of greater than 1440 x 810.
