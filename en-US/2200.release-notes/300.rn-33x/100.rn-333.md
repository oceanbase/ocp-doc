# OCP V3.3.3

<!--#RNDate#2022-07-18-->

OceanBase Cloud Platform (OCP) V3.3.3 is an upgrade to the previous version. This version optimizes the Password Box and inspection features and adapts to the new version of OceanBase Database.

## Version information

* **Version:** V3.3.3

* **Previous version:** V3.3.1

* **Version release date:** July 18, 2022

* **Supported upgrade path:** OCP V2.3.x and later can be directly upgraded to this version. OCP V2.3.0 and earlier require an upgrade to V2.3.x before proceeding.

## Supported OceanBase Database versions

The following versions of OceanBase Database are supported in OCP V3.3.2:

* OceanBase V1.4.x

* OceanBase V2.1.x

* OceanBase V2.2.x

* OceanBase V3.1.x

* OceanBase V3.2.x

## New features

### Password Box

* You can import, export, and share the password of an OceanBase cluster or tenant to be taken over.

* You can share connection credentials of the Password Box to other users in OCP.

### Monitoring

The **Memory Usage** indicator is added to the Tenant Performance tab to display the percentage of used memory of OceanBase Database tenants.

### Security

* You can set a password to activate an account. You must modify the password of the built-in account for the first time you log in to OCP.

* No prompt for plain text passwords appears on the browser console, improving system security.

## Feature enhancements

### ODP

You can modify and restart ODP clusters and make parameter changes take effect.

### Inspection

The **Cluster Health Inspection** feature is unified to the **<UI-TERM key="ocp-v2.Inspection.Item.ConfigItem.Inspection">Inspection</UI-TERM>** module. The inspection feature is improved and optimized.

### Version adaptation

* OCP V3.3.2 is adapted to OceanBase V3.2.4. You can import SRS data when you create a MySQL tenant.

* OCP V3.3.2 is adapted to OceanBase V3.2.3.1. The kernel version number is obtained in accordance with the new rule.

## Fixed issues

OCP V3.3.2 fixes the following issues:

* The performance of several Agents is optimized, and the stability of the Agents is improved.

* The logic of server-side thread pools is optimized, and the query performance of the monitoring system is improved.

* The backup and restore data collection process is optimized, and the stability of OCP in large-scale backups is improved.

* SQL diagnostic data is real-time, and the diagnostic data acquisition speed of OAS is improved.

* The admin account organization permission verification logic is optimized to adapt to the dedicated cloud scenario.

* The pre-checking process of the default directory when a cluster is created is optimized. If an error occurs, the error is displayed in advance to avoid the complete rollback of a task.

* The issue of leftover file descriptors of monagent is fixed.

* The issue of an error about cluster connection failure in special scenarios is fixed.

* The issue of backup and restore scheduling timeout is fixed.

* The issue that services cannot be viewed after backup and restore upgrades from OceanBase V2.x to OceanBase V3.x is fixed.

* The issue of failed status filtering in backup and restore is fixed.

* The issue of an NPE on the merge management tab when no data exists is fixed.

* The issue that the deployment of OCP V3.3.0 by using OAT fails is fixed.

* The internationalization issue of inspection is fixed.

* The issue that the usage rate of data disks exceeds 100% under specific circumstances is fixed.

* The issue of no alerts on CPU sys usage in abnormal conditions is fixed.

## Limitations

### Hardware requirements

OCP-Server can be installed on physical servers or Docker containers. It supports multi-node high availability deployment.

The following table describes the minimum hardware requirements for an OCP-Server node.

| Hardware  |                 Requirements                 |
|-----|------------------------------------|
| CPU | <li>X86_64, 8 cores</li><li>ARM aarch 64 architecture, 8 cores</li> |
| Memory  | 16 GB of available memory                         |
| Network interface card  | 10-GbE                               |

OCP-Agent itself requires few resources and has no special hardware requirements for installation.
