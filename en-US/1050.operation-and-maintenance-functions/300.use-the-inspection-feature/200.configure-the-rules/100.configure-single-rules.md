# Configure a scheduling rule for a single inspection object

You can refer to this topic to configure a personalized scheduling rule for an inspection object. If you want to configure a unified scheduling rule for objects managed by OCP, see [Configure a global scheduling rule](../200.configure-the-rules/200.configure-global-rules.md).

## Background information

After you configure a scheduling rule for an inspection object, OCP performs periodic inspections on the object based on the rules defined in the scheduling rule. For more information, see [Inspection feature](../100.inspection-management.md).

## Prerequisites

Make sure that the user who logs in to the OCP console has the following permissions:

* **Cluster Maintenance** or **Tenant Maintenance** permissions.
* **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">Inspection Service</UI-TERM>** permissions in the **O&M Management** module.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">O&M Management</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">Inspection Service</UI-TERM>**.

3. The **<UI-TERM key="ocp-v2.Inspection.Item.ConfigRule.InspectionList">Inspection List</UI-TERM>** page automatically appears.

4. Click the tab that contains the inspection object.

5. In the list, find the inspection object for which you want to configure a scheduling rule and click **<UI-TERM key="ocp-v2.src.util.component.More">More</UI-TERM>** > **<UI-TERM key="ocp-v2.Inspection.Item.ConfigRule.ConfigureSchedulingRules">Configure Scheduling Rules</UI-TERM>** in the Actions column.

6. On the **<UI-TERM key="ocp-v2.src.constant.inspection.ConfigureSchedulingRules">Configure Scheduling Rules</UI-TERM>** page, configure the scheduling period and scheduling time for different inspection scenarios, and set the scheduling deadline and whether to enable the scheduling rule.

   <main id="notice" type='explain'>
    <h4>Note</h4>
    You must configure the scheduling period and scheduling time for at least one inspection scenario.
   </main>

7. Click **<UI-TERM key="ocp-v2.Alarm.Subscriptions.New.Submit">Submit</UI-TERM>**.
