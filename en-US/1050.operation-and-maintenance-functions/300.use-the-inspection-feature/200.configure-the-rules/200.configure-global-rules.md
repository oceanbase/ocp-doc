# Configure global scheduling rules

This topic describes how to configure unified scheduling rules for objects managed by OCP. If you need to configure personalized scheduling rules based on object characteristics, see [Configure scheduling rules for an object](../200.configure-the-rules/100.configure-single-rules.md).

## Background information

After you configure global scheduling rules, OCP performs periodic inspections on OceanBase clusters, OceanBase tenants, and OBProxy clusters managed by OCP based on the rules. For more information, see [Inspection feature](../100.inspection-management.md).

## Prerequisites

Make sure that the user who logs in to OCP has the following permissions:

* **Cluster Maintenance** or **Tenant Maintenance** resource permissions.
* The **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">Inspection Service</UI-TERM>** menu permission under **O&M Management**.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">O&M Management</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">Inspection Service</UI-TERM>**.

3. The **<UI-TERM key="ocp-v2.Inspection.Item.ConfigItem.InspectionList">Inspection List</UI-TERM>** page automatically appears.

4. Click **<UI-TERM key="ocp-v2.page.Inspection.ConfigureGlobalSchedulingRules">Configure Global Scheduling Rules</UI-TERM>** in the upper-right corner to go to the **<UI-TERM key="ocp-v2.page.Inspection.ConfigureGlobalSchedulingRules">Configure Global Scheduling Rules</UI-TERM>** page.

5. Select the **<UI-TERM key="ocp-v2.Inspection.Task.InspectionObject">Inspection Objects</UI-TERM>** for which the scheduling rule applies.

   You can configure scheduling rules for **<UI-TERM key="ocp-v2.Inspection.Item.ConfigRule.ObjectsWithNoSchedulingRulesConfigured">Objects Without Scheduling Rules</UI-TERM>** and **All Objects** (which includes objects without scheduling rules and those with existing scheduling rules).
   * Objects Without Scheduling Rules: Configure scheduling rules only for objects without personalized scheduling rules. Objects with existing scheduling rules will continue to be inspected based on the existing rules.
   * All Objects: Reconfigure scheduling rules for all objects. If you choose to configure scheduling rules for **All Objects**, the new scheduling rules will override any personalized scheduling rules already in place for the inspection objects.

6. On the **<UI-TERM key="ocp-v2.Inspection.Item.ConfigRule.ConfigureSchedulingRules">Configure Scheduling Rules</UI-TERM>** page, configure the scheduling period and time for different inspection scenarios, and set the scheduling deadline and whether to enable the scheduling rule.

   <main id="notice" type='explain'>
    <h4>Note</h4>
    You must configure the scheduling period and time for at least one inspection scenario.
   </main>

7. Click **<UI-TERM key="ocp-v2.component.OperationConfig.ModifyParameterDrawer.Submit">Submit</UI-TERM>**.
