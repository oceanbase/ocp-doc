# Configure inspection items

This topic describes how to configure inspection items for an inspection object.

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OceanBase Cloud Platform Enterprise Edition. OceanBase Cloud Platform Community Edition does not support the inspection service. </p>
</main>

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">Inspection Service</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">O&M Management</UI-TERM>**

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">Inspection Service</UI-TERM>**.

2. Wait until the **<UI-TERM key="ocp-v2.Inspection.Item.ConfigItem.InspectionList">Inspection List</UI-TERM>** page appears.

3. Click the tab containing the target inspection object.

4. Select the inspection object for which you want to configure inspection items from the list, move the pointer over the More icon (**...**) in the **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.Operation">Actions</UI-TERM>** column, and select **<UI-TERM key="ocp-v2.Inspection.Item.ConfigItem.ConfigureInspectionItems">Configure Inspection Items</UI-TERM>**.

5. On the **<UI-TERM key="ocp-v2.Inspection.Item.ConfigItem.ConfigureInspectionItems">Configure Inspection Items</UI-TERM>** page, view the information about all built-in inspection items in OCP, including the name, type, inspection scenario, description, inspection scenario, and enable status of each inspection item.

   * You can click the search icon in the **<UI-TERM key="ocp-v2.Inspection.Item.ConfigItem.InspectionItems">Inspection Item</UI-TERM>** column to search for inspection items. Fuzzy match is supported.
   * You can filter inspection items by the **<UI-TERM key="ocp-v2.Report.Inspection.ReportContent.InspectionScenario">Inspection Scenario</UI-TERM>** or **<UI-TERM key="ocp-v2.src.constant.backup.Enable">Enable</UI-TERM>** column.

6. Enable or disable the inspection items for the inspection object as needed.
