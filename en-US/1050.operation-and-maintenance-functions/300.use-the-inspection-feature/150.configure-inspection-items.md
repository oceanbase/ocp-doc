# Configure inspection items

This topic describes how to configure inspection items for an inspection object.

## Prerequisites

The login user has the following permissions:

* **Cluster Maintenance** or **Tenant Maintenance** resource permissions.
* The **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">Inspection Service</UI-TERM>** menu permission under **O&M Management**.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">O&M Management</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">Inspection Service</UI-TERM>**.

3. The **<UI-TERM key="ocp-v2.Inspection.Item.ConfigItem.InspectionList">Inspection List</UI-TERM>** page automatically appears.

4. Click the tab of the inspection object.

5. In the list, find the inspection object for which you want to configure inspection items and click **<UI-TERM key="ocp-v2.Component.AddSamplingInspectStrategy.More">More</UI-TERM>** > **<UI-TERM key="ocp-v2.src.constant.inspection.ConfigureInspectionItems">Configure Inspection Items</UI-TERM>** in the Actions column.

6. On the **<UI-TERM key="ocp-v2.src.constant.inspection.ConfigureInspectionItems">Configure Inspection Items</UI-TERM>** page, view the information about all built-in inspection items of OCP, including the name, type, scenario, description, inspection rules, and status of each inspection item.

   * Click the search icon in the **<UI-TERM key="ocp-v2.Inspection.Item.ConfigItem.InspectionItems">Inspection Item</UI-TERM>** column to perform a fuzzy search for an inspection item.
   * You can also filter inspection items by specifying the value in the **<UI-TERM key="ocp-v2.Inspection.Item.ConfigItem.InspectionItemScenario">Inspection Scenario</UI-TERM>** or **<UI-TERM key="ocp-v2.src.constant.backup.Enable">Enable</UI-TERM>** column.

7. Enable or disable inspection items based on the actual situation of the inspection object.
