# View an inspection task

This topic describes how to view an inspection task on the inspection task page.

## Prerequisites

The login user has the following permissions:

* **Cluster Read-only** or **Tenant Read-only** resource permissions.
* The **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">Inspection Service</UI-TERM>** menu permission under the **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">O&M Management</UI-TERM>** module.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">O&M Management</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">Inspection Service</UI-TERM>**.

3. Click the **<UI-TERM key="ocp-v2.page.Inspection.InspectionHistory">Inspection History</UI-TERM>** tab.

4. In the inspection task list, click the inspection task ID to go to the task details page. You can view information such as **<UI-TERM key="ocp-v2.Inspection.Task.TaskStatus">Task Status</UI-TERM>**, **<UI-TERM key="ocp-v2.Task.Detail.CurrentProgress">Current Progress</UI-TERM>**, **<UI-TERM key="ocp-v2.TraceDetail.TraceContent.StartTime">Started At</UI-TERM>**, **<UI-TERM key="ocp-v2.Task.Detail.AccumulatedTaskTime">Time Consumed</UI-TERM>**, and **<UI-TERM key="ocp-v2.Task.Detail.TaskInitiator">Initiated By</UI-TERM>**.

5. Click **<UI-TERM key="ocp-v2.Task.Detail.LogView">Log View</UI-TERM>** or **<UI-TERM key="ocp-v2.Task.Detail.FlowView">Flow View</UI-TERM>** to switch views.

6. Click **<UI-TERM key="ocp-v2.Task.Detail.LocateTheCurrentProgress">Locate Current Progress</UI-TERM>** to view the task execution progress.

7. Click **<UI-TERM key="ocp-v2.Detail.Log.LogCard.DownloadLogs">Download Logs</UI-TERM>** to download the log information to your local device for viewing.

   <main id="notice" type='explain'>
    <h4>Note</h4>
    <ul>
    <li>Click the <strong>Download Logs</strong> icon in the upper-right corner to download the task details and log details.</li>
    <li>Click the <strong>Download Logs</strong> icon in the upper-right corner of the task execution process to download the log details.</li>
    </ul>
