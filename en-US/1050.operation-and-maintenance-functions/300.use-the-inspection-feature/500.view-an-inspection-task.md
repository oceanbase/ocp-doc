# View an inspection task

This topic describes the page of an inspection task in detail. You can view the basic information about the inspection task and view and download the inspection report.

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OceanBase Cloud Platform Enterprise Edition. OceanBase Cloud Platform Community Edition does not support the inspection service. </p>
</main>

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
* **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">Inspection Service</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">O&M Management</UI-TERM>**

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">Inspection Service</UI-TERM>**.

2. Click the **<UI-TERM key="ocp-v2.page.Inspection.InspectionHistory">Inspection History</UI-TERM>** tab.

3. In the inspection task list, click the ID of an inspection task to access its details page. You can view the status, current progress, start time, accumulated time, and initiator of the task.

4. Click **<UI-TERM key="ocp-v2.Task.Detail.LogView">Log View</UI-TERM>** or **<UI-TERM key="ocp-v2.Task.Detail.FlowView">Flow View</UI-TERM>** to switch between views.

5. Click **<UI-TERM key="ocp-v2.Task.Detail.LocateTheCurrentProgress">Locate Current Progress</UI-TERM>** to view the task execution progress.

6. Click **<UI-TERM key="ocp-v2.Detail.Log.TaskGraph.DownloadLogs">Download Logs</UI-TERM>** to download the logs locally.
