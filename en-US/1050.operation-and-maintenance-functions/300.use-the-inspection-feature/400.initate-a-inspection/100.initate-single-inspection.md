# Initiate an inspection for a single object

This topic describes how to initiate an inspection for a single object. To initiate an inspection for all objects, see [Initiate an inspection for all objects](../400.initate-a-inspection/200.initiate-global-inspection.md).

## Background information

After you initiate an inspection, OCP immediately checks the cluster based on the inspection rules. For more information, see [Inspection features](../100.inspection-management.md).

## Prerequisites

The login user has the following permissions:

* **Cluster Maintenance** or **Tenant Maintenance** permissions.
* **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">Inspection Service</UI-TERM>** permissions under **O&M Management**.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">O&M Management</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">Inspection Service</UI-TERM>**.

3. The **<UI-TERM key="ocp-v2.page.Inspection.InspectionList">Inspection List</UI-TERM>** page automatically appears.

4. Click the tab that contains the inspection object.

5. In the list, select the object to initiate an inspection. Hover the pointer over **<UI-TERM key="ocp-v2.Inspection.Item.InitiateInspection">Initiate Inspection</UI-TERM>** in the Actions column, and select the required inspection scenario from the drop-down list.

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E5%8F%91%E8%B5%B7%E5%8D%95%E4%B8%AA%E5%B7%A1%E6%A3%801.png)

6. Click **<UI-TERM key="ocp-v2.Oracle.Component.AddObjectPrivilegeDrawer.Determine">OK</UI-TERM>** in the dialog box that appears.

7. Click the task ID in the dialog box or view the task progress in **<UI-TERM key="ocp-v2.Layout.BasicLayout.TaskCenter">Task Center</UI-TERM>**. For more information, see [Task management](../../../1600.system-management-features/600.manage-tasks.md).
