# Initiate a global inspection

This topic describes how to initiate a global inspection. To initiate an inspection for a single object, see [Initiate an inspection for a single object](../400.initate-a-inspection/100.initate-single-inspection.md).

## Background information

After you initiate a global inspection, OCP will immediately check the OceanBase clusters, OceanBase tenants, and OBProxy clusters managed by OCP based on the configurations in the inspection items. For more information, see [Inspection feature](../100.inspection-management.md).

## Prerequisites

Make sure that the login user has the following permissions:

* **Cluster Maintenance** or **Tenant Maintenance** permissions.
* **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">Inspection Service</UI-TERM>** permissions.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">O&M Management</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">Inspection Service</UI-TERM>**.

3. The **<UI-TERM key="ocp-v2.Inspection.Item.ConfigRule.InspectionList">Inspection List</UI-TERM>** page automatically appears.

4. Hover the pointer over **<UI-TERM key="ocp-v2.page.Inspection.InitiateAGlobalInspection">Initiate Global Inspection</UI-TERM>** in the upper-right corner of the page, and select the required inspection scenario from the drop-down list.

5. Click **<UI-TERM key="ocp-v2.Detail.ResourceManager.CreateResourcePlan.Ok">OK</UI-TERM>** in the dialog box that appears.

   <main id="notice" type='explain'>
    <h4>Note</h4>
    <ul>
    <li>Clusters that are being inspected in the selected scenario will be skipped.</li>
    <li>Hosts that are being inspected in the selected scenario will be skipped.</li>
    </ul>
   </main>

6. Click the task ID in the dialog box or view the task progress on the **<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">Task Center</UI-TERM>** page. For more information, see [Manage tasks](../../../1600.system-management-features/600.manage-tasks.md).
