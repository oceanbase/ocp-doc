# Download an inspection report

This topic describes how to download an inspection report.

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OceanBase Cloud Platform Enterprise Edition. OceanBase Cloud Platform Community Edition does not support the inspection service. </p>
</main>

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission
* **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">Inspection Service</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">O&M Management</UI-TERM>**

## Procedure

1. Log on to the OceanBase Cloud Platform (OCP) console. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">Inspection Service</UI-TERM>**.
2. Click the **<UI-TERM key="ocp-v2.page.Inspection.InspectionHistory">Inspection History</UI-TERM>** tab.
3. In the inspection history list, select the target task, hover the pointer over the More icon (**...**) in the **<UI-TERM key="ocp-v2.Alarm.Shield.Operation">Actions</UI-TERM>** column, and then select **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.DownloadReport">Download Report</UI-TERM>** from the drop-down list to download the inspection report in the HTML format to your local computer.

   You can view inspection details in the report. For more information, see [View an inspection report](100.view-inspection-report.md).

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/%E4%B8%8B%E8%BD%BD%E5%B7%A1%E6%A3%80%E6%8A%A5%E5%91%8A-1.png)

   <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>You cannot download the inspection report of an inspection task in <strong>Executing</strong> or <strong>Failed</strong> state. You can click the ID of an inspection task to view the current progress or the failure cause. </p>
   </main>
