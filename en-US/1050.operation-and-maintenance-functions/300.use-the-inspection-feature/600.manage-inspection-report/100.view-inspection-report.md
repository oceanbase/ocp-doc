# View an inspection report

This topic describes how to view an inspection report.

<main id="notice" type='notice'>
<h4>Applicability</h4>

2. View the inspection report on the **<UI-TERM key="ocp-v2.page.Inspection.InspectionHistory">Inspection History</UI-TERM>** tab.

## Prerequisites

Make sure that you have the following permissions:
* **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** or **Tenant Read-only** permission

* **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">Inspection Service</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">O&M Management</UI-TERM>**

## Procedure

This topic describes how to view an inspection report on the **<UI-TERM key="ocp-v2.page.Inspection.InspectionHistory">Inspection History</UI-TERM>** tab.

1. Log on to the OceanBase Cloud Platform (OCP) console. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">Inspection Service</UI-TERM>**.

2. Click the **<UI-TERM key="ocp-v2.page.Inspection.InspectionHistory">Inspection History</UI-TERM>** tab.

3. In the inspection history list, locate the task that you want to view, move the pointer over the More icon (**···**) in the Actions column, and select **<UI-TERM key="ocp-v2.src.constant.inspection.ViewReports">View Report</UI-TERM>**.

4. Access the **<UI-TERM key="ocp-v2.Detail.Report.ReportList">Reports</UI-TERM>** page and view the inspection details, including **<UI-TERM key="ocp-v2.Transaction.Detail.BasicInformation">Basic Information</UI-TERM>**, **<UI-TERM key="ocp-v2.Report.Inspection.ReportContent.OverviewOfInspectionResults">Overview of Inspection Results</UI-TERM>**, and risk details.

   You can query risk details on the following two tabs: **Displayed by Risk** and **Displayed by Inspection Item**. On the **Summary by Risk** tab, you can filter inspection results by risk level.

    <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>If the value of an inspection item in the inspection report cannot be queried, you can view the cause in the logs of the inspection task. For more information, see <a href="../500.view-an-inspection-task.md">View an inspection task</a>.</p>
    </main>

## Related operations

OCP allows you to periodically clear historical inspection reports by using system parameters:

1. The `ocp.inspection.report.expired.cleanup.enabled` parameter specifies whether to clear the expired inspection reports. The default value is `false`. If you set the value to `true`, OCP automatically clears all inspection reports that were generated the specified number of days before, which is specified in the `ocp.inspection.report.expired.days` parameter.

2. The `ocp.inspection.report.expired.days` parameter specifies the number of days after which an inspection report expires. The default value is 15 days. If you enable the automatic cleanup feature, OCP clears all expired inspection reports except the standardized host check reports at 00:00 every day.
