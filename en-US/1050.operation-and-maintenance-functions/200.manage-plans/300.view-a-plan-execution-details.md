# View plan execution details

This topic describes how to view the detailed execution information about a plan.

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OceanBase Cloud Platform (OCP) Enterprise Edition. OCP Community Edition does not support this feature. </p>
</main>

## View a plan execution task

You can view the execution details of a plan in the **<UI-TERM key="ocp-v2.src.constant.plan.Running">Executing</UI-TERM>**, **<UI-TERM key="ocp-v2.Detail.Report.Failed">Failed</UI-TERM>**, or **<UI-TERM key="ocp-v2.page.Information.Completed">Completed</UI-TERM>** state.

### Prerequisites

To view a plan execution task, make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster read-only** or **Tenant Read-only** permission
* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.page.Plan.PlanManagement">Plan Management</UI-TERM>** menu of **O&M management**

### Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">O&M Management</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.PlanManagement">Plan Management</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.Plan.PlanExecutionList">Plans</UI-TERM>** tab appears.

3. Find the target plan and click **<UI-TERM key="ocp-v2.Cluster.Import.ImportClusterResults.ViewTasks">View Task</UI-TERM>** in the **<UI-TERM key="ocp-v2.Component.SQLDetail.ParallelSQLTraceTable.Actions">Actions</UI-TERM>** column.

4. The alert details page corresponding to the plan event appears, where you can view the execution information about the plan. For more information, see [Execute the alert clearance plan](../../1900.reference-guide/100.alarm-reference/500.appendix/400.execute-the-plan.md).

## View SQL information

For an SQL-related plan, you can view the SQL information about the corresponding event if the plan is in the **<UI-TERM key="ocp-v2.src.constant.task.ToBeExecuted">Pending</UI-TERM>**, **<UI-TERM key="ocp-v2.src.constant.alarm.Running">Executing</UI-TERM>**, **<UI-TERM key="ocp-v2.src.constant.package.Failed">Failed</UI-TERM>**, or **<UI-TERM key="ocp-v2.src.constant.plan.Completed">Completed</UI-TERM>** state.

### Prerequisites

To view SQL information, make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Read-only** permission
* **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.page.Plan.PlanManagement">Plan Management</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">O&M Management</UI-TERM>**
* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.Realtime.RealTimeDiagnosis">Real-time Diagnostics</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.hook.useMenu.AutonomousService">OceanBase Autonomy Service</UI-TERM>**

### Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">O&M Management</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.PlanManagement">Plan Management</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.Plan.PlanExecutionList">Plans</UI-TERM>** tab appears.

3. Find the target plan and click **<UI-TERM key="ocp-v2.Plan.Component.PlanExecuteTable.ViewSql">View SQL</UI-TERM>** in the **<UI-TERM key="ocp-v2.Statistics.components.TaskTable.Operation">Actions</UI-TERM>** column.

4. The **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetail.SqlDetails">SQL Details</UI-TERM>** page appears, where you can view SQL information. For more information, see [View details of an SQL statement](../../1000.diagnosis-and-tuning-fuctions/100.manage-sql-diagnosis/1000.view-sql-details.md).
