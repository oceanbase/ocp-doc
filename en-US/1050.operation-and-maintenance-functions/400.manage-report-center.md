# Manage the report center

The report center supports the generation and download of reports on basic information, resource allocation, and usage of management objects such as **clusters**, **tenants**, **OBProxy**, **hosts**, **Binlogs**, and **arbitration services**.

O&M personnel can monitor resource anomalies in real time and handle potential risks promptly. Resource planners can accurately plan resource allocation and scaling based on historical and real-time data. Business leaders can clearly understand their business resource costs and scientifically evaluate the input-output benefits. This provides solid data support for enterprise resource optimization and decision-making, effectively enhancing overall resource management efficiency.

## Create a report<a id="parameter"></a>

This topic describes how to create a report for the managed objects.

### Prerequisites

Ensure that the login user is assigned to the **ADMIN** or **ORG_ADMIN** role.

### Procedure

1. Log in to OCP.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">O&M Management</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.ReportCenter">Report Center</UI-TERM>** . The **<UI-TERM key="ocp-v2.src.hook.useMenu.ReportCenter">Report Center</UI-TERM>** page automatically appears.

3. Click **Create Report** in the upper-right corner.

4. In the right-side panel, configure the report. The following table describes the parameters.

    |  Parameter   |  Description   |
    |---------|---------|
    | Report Name  | <ul><li>The name must start with Chinese characters or English letters and end with Chinese characters, English letters, or digits. </li><li>The name must be 2 to 32 characters in length. </li><li>Underscores are the only special character supported. </li></ul>    |
    | Type      | The type of the managed object. Valid values: **<UI-TERM key="ocp-v2.Detail.Monitor.Cluster">Cluster</UI-TERM>**, **<UI-TERM key="ocp-v2.component.ParameterTemplate.DetailDrawer.Tenant">Tenant</UI-TERM>**, OBProxy, **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.Host">Host</UI-TERM>**, Binlog, and **<UI-TERM key="ocp-v2.Detail.Overview.ArbitrationService">Arbitration Service</UI-TERM>**.    |
    | Object  | The specific managed objects. <br>When you select **All**, you can unselect specific objects for which no reports are to be generated by clicking **<UI-TERM key="ocp-v2.alarm.FormListWithExclude.HostWithExclude.ExcludeObjects">Excluded Objects</UI-TERM>** on the right.    |
    | Attribute      | The attributes displayed in the report. The attributes to be displayed vary with the value of **<UI-TERM key="ocp-v2.page.External.CreateDrawer.Type">Type</UI-TERM>**.     |
    | Remarks      | Additional information about the report.     |

5. Click **<UI-TERM key="ocp-v2.page.Inspection.Ok">OK</UI-TERM>**.

## View and download a report

After a report is created, you can view the report list and download the reports to your local device to view the reports. By default, the reports will be deleted 30 days after creation. It is recommended that you download the reports within this period.

### Prerequisites

* Ensure that the login user is assigned to the **ADMIN** or **ORG_ADMIN** role.

* You can view and download only the reports created by yourself.

* The report has been created by referring to [Create a report](#parameter).

### Procedure

1. Log in to OCP.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">O&M Management</UI-TERM>** > **<UI-TERM key="ocp-v2.Detail.Report.ReportCenter">Report Center</UI-TERM>**. The **<UI-TERM key="ocp-v2.Detail.Report.ReportCenter">Report Center</UI-TERM>** page automatically appears.

3. Find the report that you want to download and click **<UI-TERM key="ocp-v2.page.Information.Download">Download</UI-TERM>** in the **...** option.

4. The report is downloaded to your local device.

## Delete a report

In addition to system automatic deletion, you can also manually delete the generated reports.

### Prerequisites

* Ensure that the login user in OCP has the **ADMIN** or **ORG_ADMIN** role.

* Only reports created by the current user can be deleted.

* The report has been created by referring to [Create a report](#parameter).

### Procedure

1. Log in to OCP.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">O&M Management</UI-TERM>** > **<UI-TERM key="ocp-v2.Detail.Report.ReportCenter">Report Center</UI-TERM>**. The **<UI-TERM key="ocp-v2.src.hook.useMenu.ReportCenter">Report Center</UI-TERM>** page appears.

3. Find the report that you want to delete and click **<UI-TERM key="ocp-v2.Auth.Role.Detail.Delete">Delete</UI-TERM>** in the **...** column.

4. In the dialog box that appears, click **<UI-TERM key="ocp-v2.Detail.Component.LinkList.Delete">Delete</UI-TERM>**.

## Change the report retention period

By default, reports are retained for 30 days. You can set the `ocp.report.center.report.retention.days` parameter under **System Management** > **System Parameters** to change the report retention period. For more information, see [Modify system parameters](../1600.system-management-features/500.manage-system-parameter/200.modify-system-parameters.md).
