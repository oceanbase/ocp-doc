# Create an information collection task

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OceanBase Cloud Platform (OCP) Enterprise Edition. OCP Community Edition does not support this feature. </p>
</main>

This topic describes how to manually initiate a collection task to promptly collect exception information about the specified object.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Cluster Maintenance** or **Tenant Maintenance** permission
* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.InformationCollection">Information Collection</UI-TERM>** menu of **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">O&M Management</UI-TERM>**

## Procedure

1. Log on to the OCP console. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">O&M Management</UI-TERM>** > **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.InformationCollection">Information Collection</UI-TERM>**.

2. The **Information Collection List** page automatically appears.

3. Click **<UI-TERM key="ocp-v2.Information.Detail.CreateCollectDrawer.CreateInformationCollection">Create Information Collection Task</UI-TERM>** in the upper-right corner.

4. In the panel that appears, complete the information collection settings and then click **<UI-TERM key="ocp-v2.Component.OBServerList.OBServerModal.Ok">OK</UI-TERM>**.

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/create-information-collection-task.png)

    The following table describes the parameters.

    | Parameter | Description |
    |--------|---------|
    |  Object Type  | The type of the object for which the exception information is to be collected. Valid values: **<UI-TERM key="ocp-v2.src.component.ModifyTagResourceDrawer.OceanbaseCluster">OceanBase Cluster</UI-TERM>**, **<UI-TERM key="ocp-v2.Information.Detail.CreateCollectDrawer.OceanbaseTenants">OceanBase Database Tenant</UI-TERM>**, **<UI-TERM key="ocp-v2.Alarm.Event.ObproxyCluster">OBProxy Cluster</UI-TERM>**, and **<UI-TERM key="ocp-v2.Cluster.Arbitration.Host">Host</UI-TERM>**.   |
    |  Object      | The name of the object whose information is to be collected.   |
    |  Information Collection Range  | The time range within which the information is to be collected. Valid values: **<UI-TERM key="ocp-v2.src.constant.log.NearFenZhong.1">Last 10 Minutes</UI-TERM>**, **<UI-TERM key="ocp-v2.src.constant.log.NearMins">Last 15 Minutes</UI-TERM>**, **<UI-TERM key="ocp-v2.component.OCPRangePicker.constant.NearlyMinutes.3">Last 30 Minutes</UI-TERM>**, **<UI-TERM key="ocp-v2.Cluster.Component.PerformanceTop5.LastHour">Last 1 Hour</UI-TERM>**, and **<UI-TERM key="ocp-v2.component.OCPRangePicker.constant.NearlyHours">Last 3 Hours</UI-TERM>**.   |
    |  Information Collection Scenario  | The information collection scenario, which varies based on the object type. Collection scenarios supported for different types of objects are listed as follows: <ul><li><b>OceanBase cluster</b><ul><li>obproxy exception</li><li>ocp_agent exception</li><li>data disk exception</li><li>merge exception</li><li>obcluster exception</li><li>memory exception</li><li>cpu exception</li></ul></li><li><b>OceanBase Database tenant</b><ul><li>data disk exception</li><li>merge exception</li><li>memory exception</li><li>cpu exception</li></ul></li><li><b>OBProxy cluster</b><ul><li>obproxy exception</li><li>cpu exception</li></ul></li><li><b>Host</b><ul><li>ocp_agent exception</li><li>cpu exception</li></ul></li></ul> <main id="notice" type='notice'><h4>Notice</h4><p>Proceed with caution if you want to select a <b>obcluster exception</b> scenario. The **obcluster exception** scenario involves a large number of collection items, which take a long time to collect. </p></main>    |
