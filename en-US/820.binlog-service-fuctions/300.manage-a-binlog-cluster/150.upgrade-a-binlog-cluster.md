# Upgrade a binlog cluster

You can upgrade a binlog cluster as needed. If the binlog instances in the binlog cluster run in single-replica mode, downstream business may encounter a delay of several minutes. If the binlog instances run in multi-replica mode, the system performs a leader switchover by default. This may cause a delay of several seconds to downstream business. Proceed with caution.

In OceanBase Cloud Platform (OCP), you can upgrade a binlog cluster by using the following methods:

* **Method 1**: On the **Clusters** page, click **Upgrade Version** in the **Actions** column of the target cluster.
* **Method 2**: On the **Binlog Cluster Overview** page, click the **More** icon in the upper-right corner and select **Upgrade Version**.

## Prerequisites

* To upgrade a binlog cluster, make sure that you have the following permissions:

  * **Resource Permissions**: **Binlog Service Maintenance** permission
  * **Menu Permissions**: Permission on the **Binlog Cluster Overview** menu of the **Binlog Service**

* The binlog cluster to be upgraded and the binlog instances in the binlog cluster are all in the **Running** state.
* You can upgrade the binlog cluster to only V4.2.0.0 or later.

## Procedure

The procedure of **Method 2** is described as follows:

1. Log in to the OCP console.

2. In the left-side navigation pane, click **Binlog Service**. The **Clusters** page appears.

3. On the **Clusters** page, find the target binlog cluster and click its name.

4. On the **Overview** page of the binlog cluster, click the **More** icon in the upper-right corner and select **Upgrade Version**.

5. In the **Upgrade Version** dialog box, click **Upgrade**.

   If the required software package is unavailable, you can click **Upload Package** to upload the required software package.

6. View the task progress in **Task Center**. When the task status changes to **ExecuteSuccessful** and the status of the cluster changes to **Normal Operation**, the cluster is successfully upgraded.
