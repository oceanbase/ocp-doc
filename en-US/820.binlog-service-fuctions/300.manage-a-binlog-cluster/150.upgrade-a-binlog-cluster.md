# Upgrade a binlog cluster

You can upgrade a binlog cluster as needed. If the binlog instances in the binlog cluster run in single-replica mode, downstream business may encounter a delay of several minutes. If the binlog instances run in multi-replica mode, the system performs a leader switchover by default. This may cause a delay of several seconds to downstream business. Proceed with caution.

In OceanBase Cloud Platform (OCP), you can upgrade a binlog cluster by using the following methods:

* **Method 1**: On the **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** page, click **<UI-TERM key="ocp-v2.Binlog.Component.UpgradeBinlogModal.UpgradedVersion">Upgrade Version</UI-TERM>** in the **<UI-TERM key="ocp-v2.Host.Detail.OCPAgent.Operation">Actions</UI-TERM>** column of the target cluster.
* **Method 2**: On the **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** page, click the **<UI-TERM key="ocp-v2.page.Welcome.SeeMore">More</UI-TERM>** icon in the upper-right corner and select **<UI-TERM key="ocp-v2.src.constant.backup.UpgradedVersion">Upgrade Version</UI-TERM>**.

## Prerequisites

* To upgrade a binlog cluster, make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Binlog Service Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** menu of the **<UI-TERM key="ocp-v2.page.Binlog.BinlogService">Binlog Service</UI-TERM>**

* The binlog cluster to be upgraded and the binlog instances in the binlog cluster are all in the **<UI-TERM key="ocp-v2.src.constant.compute.NormalOperation">Running</UI-TERM>** state.
* You can upgrade the binlog cluster to only V4.2.0.0 or later.

## Procedure

The procedure of **Method 2** is described as follows:

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Detail.Overview.BinlogService">Binlog Service</UI-TERM>**. The **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** page appears.

3. On the **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** page, find the target binlog cluster and click its name.

4. On the **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** page of the binlog cluster, click the **<UI-TERM key="ocp-v2.Cluster.Component.MachineResource.SeeMore">More</UI-TERM>** icon in the upper-right corner and select **<UI-TERM key="ocp-v2.Cluster.Detail.UpgradedVersion">Upgrade Version</UI-TERM>**.

5. In the **<UI-TERM key="ocp-v2.src.constant.backup.UpgradedVersion">Upgrade Version</UI-TERM>** dialog box, click **<UI-TERM key="ocp-v2.Arbitration.ArbitrationGroup.UpgradeArbitrationGroup.Upgrade">Upgrade</UI-TERM>**.

   If the required software package is unavailable, you can click **<UI-TERM key="ocp-v2.src.component.PackageUploadModal.UploadSoftwarePackage">Upload Package</UI-TERM>** to upload the required software package.

6. View the task progress in **<UI-TERM key="ocp-v2.Layout.BasicLayout.TaskCenter">Task Center</UI-TERM>**. When the task status changes to **ExecuteSuccessful** and the status of the cluster changes to **<UI-TERM key="ocp-v2.src.constant.binlog.NormalOperation">Normal Operation</UI-TERM>**, the cluster is successfully upgraded.
