# Start and stop a binlog cluster

You can start or stop a binlog cluster based on your business needs. Stopping a binlog cluster does not affect the normal operations of binlog instances in the cluster or the consumption of binlog data.

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Binlog Service Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** menu of the **<UI-TERM key="ocp-v2.Detail.Overview.BinlogService">Binlog Service</UI-TERM>**

* The binlog cluster to be stopped is in the **<UI-TERM key="ocp-v2.src.constant.compute.NormalOperation">Running</UI-TERM>** state.
* The binlog cluster to be started is in the **<UI-TERM key="ocp-v2.src.constant.oceanbase.Stopped">Stopped</UI-TERM>** state.

## Procedure

1. Log on to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Detail.Overview.BinlogService">Binlog Service</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.Binlog.ClusterList">Cluster List</UI-TERM>** tab automatically appears.

3. On the **<UI-TERM key="ocp-v2.page.Binlog.ClusterList">Cluster List</UI-TERM>** page, find the target binlog cluster and click its name.

4. On the **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** tab, click the **<UI-TERM key="ocp-v2.Component.AddBackupStrategy.ViewMore">More</UI-TERM>** icon in the upper-right corner and select **<UI-TERM key="ocp-v2.Detail.Overview.StopBinlogCluster">Stop Binlog Cluster</UI-TERM>**.

5. In the dialog box that appears, click **<UI-TERM key="ocp-v2.Restore.SamplingStrategy.Detail.Stop">Stop</UI-TERM>**.

   You can view the task progress in **<UI-TERM key="ocp-v2.Layout.BasicLayout.TaskCenter">Task Center</UI-TERM>**. When the task status changes to **ExecuteSuccessful** and the status of the cluster changes to **<UI-TERM key="ocp-v2.src.constant.binlog.Stopped.3">Stopped</UI-TERM>**, the cluster is successfully stopped.

6. Start the cluster.

   After the cluster is stopped, you can click the **<UI-TERM key="ocp-v2.page.Welcome.SeeMore">More</UI-TERM>** icon in the upper-right corner on the **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** page and select **<UI-TERM key="ocp-v2.Detail.Overview.StartTheBinlogCluster">Start Binlog Cluster</UI-TERM>** to start the cluster.
