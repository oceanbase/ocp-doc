# Restart a binlog cluster

You can restart a binlog cluster as needed. Restarting a binlog cluster does not affect the normal operations of binlog instances in the cluster or the consumption of binlog data.

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Binlog Service Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** menu of the **<UI-TERM key="ocp-v2.page.Binlog.BinlogService">Binlog Service</UI-TERM>**

* The binlog cluster to be restarted is in the **<UI-TERM key="ocp-v2.src.constant.backup.NormalOperation">Running</UI-TERM>** state.

## Procedure

1. Log on to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Binlog.BinlogService">Binlog Service</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.Binlog.ClusterList">Cluster List</UI-TERM>** tab automatically appears.

3. On the **<UI-TERM key="ocp-v2.page.Binlog.ClusterList">Cluster List</UI-TERM>** page, find the target binlog cluster and click its name.

4. On the **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** tab, click the **<UI-TERM key="ocp-v2.Component.AddBackupStrategy.ViewMore">More</UI-TERM>** icon in the upper-right corner and select **<UI-TERM key="ocp-v2.Detail.Overview.RestartTheBinlogCluster">Restart Binlog Cluster</UI-TERM>**.

5. In the dialog box that appears, click **<UI-TERM key="ocp-v2.src.constant.compute.Restart">Restart</UI-TERM>**.

   You can view the task progress in **<UI-TERM key="ocp-v2.Layout.BasicLayout.TaskCenter">Task Center</UI-TERM>**. When the task status changes to **ExecuteSuccessful** and the status of the cluster changes to **<UI-TERM key="ocp-v2.src.constant.binlog.NormalOperation">Normal Operation</UI-TERM>**, the cluster is successfully restarted.
