# Restart a binlog instance

You can restart a binlog instance as needed. Restarting a binlog instance interrupts the subscription connections to the instance. Proceed with caution.

In OceanBase Cloud Platform (OCP), you can restart a binlog instance by using either of the following methods:

* **Method 1**: Go to the **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** page, find the target binlog instance in the **<UI-TERM key="ocp-v2.Component.BinlogInstanceList.BinlogInstanceList">Binlog Instance List</UI-TERM>** section, click **<UI-TERM key="ocp-v2.Component.AddBackupStrategy.ViewMore">More</UI-TERM>** in the **<UI-TERM key="ocp-v2.Backup.Backup.Log.Operation">Actions</UI-TERM>** column, and select **<UI-TERM key="ocp-v2.src.constant.binlog.RestartTheBinlogInstance">Restart Binlog Instance</UI-TERM>**.
* **Method 2**: Go to the **<UI-TERM key="ocp-v2.Instance.Overview.BinlogInstanceOverview">Binlog Instance Overview</UI-TERM>** page, click the **<UI-TERM key="ocp-v2.Cluster.Component.MachineResource.SeeMore">More</UI-TERM>** icon in the upper-right corner and select **<UI-TERM key="ocp-v2.Instance.Overview.RestartTheBinlogInstance">Restart Binlog Instance</UI-TERM>**.

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Binlog Service Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** menu of the **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogService">Binlog Service</UI-TERM>**

* The binlog instance to be restarted is in the **<UI-TERM key="ocp-v2.src.constant.backup.NormalOperation">Running</UI-TERM>** or **<UI-TERM key="ocp-v2.page.Overview.Unavailable">Unavailable</UI-TERM>** state.

## Procedure

The following procedure describes how to restart a binlog instance by using **Method 2**.

1. Log on to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogService">Binlog Service</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.Binlog.ClusterList">Cluster List</UI-TERM>** tab automatically appears.

3. On the **<UI-TERM key="ocp-v2.page.Binlog.ClusterList">Cluster List</UI-TERM>** page, find the target binlog cluster and click its name to go to the **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** page.

4. In the **<UI-TERM key="ocp-v2.Component.BinlogInstanceList.BinlogInstanceList">Binlog Instance List</UI-TERM>** section, find the binlog instance to be restarted and click its name.

5. Go to the **<UI-TERM key="ocp-v2.Instance.Overview.BinlogInstanceOverview">Binlog Instance Overview</UI-TERM>** page, click the **<UI-TERM key="ocp-v2.page.Welcome.SeeMore">More</UI-TERM>** icon in the upper-right corner and select **<UI-TERM key="ocp-v2.src.constant.binlog.RestartTheBinlogInstance">Restart Binlog Instance</UI-TERM>**.

6. In the dialog box that appears, click **<UI-TERM key="ocp-v2.Component.ZoneList.Restart">Restart</UI-TERM>**.

   You can view the task progress in **<UI-TERM key="ocp-v2.Layout.BasicLayout.TaskCenter">Task Center</UI-TERM>**. When the task status changes to **ExecuteSuccessful** and the status of the instance changes to **<UI-TERM key="ocp-v2.src.constant.binlog.NormalOperation">Normal Operation</UI-TERM>**, the instance is successfully restarted.
