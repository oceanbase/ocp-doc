# Configure throttling

When a binlog instance handles a large amount of conversion and subscription data, it uses more resources such as the bandwidth, CPU, and memory, thereby compromising service stability. In this case, you can configure throttling for the binlog instance.

In OceanBase Cloud Platform (OCP), you can configure throttling for a binlog instance by using either of the following methods:

* **Method 1**: Go to the **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** page, find the target binlog instance in the **<UI-TERM key="ocp-v2.Component.BinlogInstanceList.BinlogInstanceList">Binlog Instance List</UI-TERM>** section, click **<UI-TERM key="ocp-v2.Cluster.Component.MachineResource.SeeMore">More</UI-TERM>** in the **<UI-TERM key="ocp-v2.Restore.SamplingStrategy.Operation">Actions</UI-TERM>** column, and select **<UI-TERM key="ocp-v2.Binlog.Component.FlowBinlogModal.ConfigureThrottling">Configure Throttling</UI-TERM>**.
* **Method 2**: Go to the **<UI-TERM key="ocp-v2.Instance.Overview.BinlogInstanceOverview">Binlog Instance Overview</UI-TERM>** page, and click **<UI-TERM key="ocp-v2.Binlog.Component.FlowBinlogModal.ConfigureThrottling">Configure Throttling</UI-TERM>** in the upper-right corner.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Binlog Service Maintenance** permission
* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** menu of the **<UI-TERM key="ocp-v2.Detail.Overview.BinlogService">Binlog Service</UI-TERM>**

## Procedure

The following procedure describes how to configure throttling for a binlog instance by using **Method 2**.

1. Log on to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Detail.Overview.BinlogService">Binlog Service</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>** page automatically appears.

3. On the **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>** page, find the target binlog cluster and click its name to go to the **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** page.

4. In the **<UI-TERM key="ocp-v2.Component.BinlogInstanceList.BinlogInstanceList">Binlog Instance List</UI-TERM>** section, find the binlog instance for throttling configuration and click its name.

5. On the **<UI-TERM key="ocp-v2.Instance.Overview.BinlogInstanceOverview">Binlog Instance Overview</UI-TERM>** page, and click **<UI-TERM key="ocp-v2.Binlog.Component.FlowBinlogModal.ConfigureThrottling">Configure Throttling</UI-TERM>** in the upper-right corner.

6. In the dialog box that appears, configure throttling parameters and click **<UI-TERM key="ocp-v2.Host.Component.ReinstallModal.Determine">OK</UI-TERM>**.

   You can configure the following four throttling parameters for a binlog instance: **<UI-TERM key="ocp-v2.Binlog.Component.FlowBinlogModal.ConversionTrafficMbS">Conversion Traffic (MiB/s)</UI-TERM>**, **<UI-TERM key="ocp-v2.Binlog.Component.FlowBinlogModal.SubscriptionTrafficMbS">Subscription Traffic (MiB/s)</UI-TERM>**, **<UI-TERM key="ocp-v2.Binlog.Component.FlowBinlogModal.ConvertRps">Conversion RPS</UI-TERM>**, and **<UI-TERM key="ocp-v2.Binlog.Component.FlowBinlogModal.SubscribeToRps">Subscription RPS</UI-TERM>**. If any of the parameters is set to 0, the corresponding item is not throttled.
