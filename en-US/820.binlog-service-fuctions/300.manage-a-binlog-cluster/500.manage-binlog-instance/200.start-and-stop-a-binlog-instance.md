# Start and stop a binlog instance

The following table describes how to start and stop a binlog instance as needed. Stopping a binlog instance will affect its operations and related subscription tasks. Proceed with caution.

In OceanBase Cloud Platform (OCP), you can start or stop a binlog instance by using either of the following methods:

* **Method 1**: Go to the **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** page, find the target binlog instance in the **<UI-TERM key="ocp-v2.Component.BinlogInstanceList.BinlogInstanceList">Binlog Instance List</UI-TERM>** section, click **<UI-TERM key="ocp-v2.page.Welcome.SeeMore">More</UI-TERM>** in the **<UI-TERM key="ocp-v2.page.Credential.Binlog.Operation">Actions</UI-TERM>** column, and select **<UI-TERM key="ocp-v2.src.constant.binlog.StopTheBinlogInstance">Stop Binlog Instance</UI-TERM>** or **<UI-TERM key="ocp-v2.Instance.Overview.StartTheBinlogInstance">Start Binlog Instance</UI-TERM>**.
* **Method 2**: Go to the **<UI-TERM key="ocp-v2.Instance.Overview.BinlogInstanceOverview">Binlog Instance Overview</UI-TERM>** page, click the **<UI-TERM key="ocp-v2.Component.AddBackupStrategy.ViewMore">More</UI-TERM>** icon in the upper-right corner and select **<UI-TERM key="ocp-v2.Instance.Overview.StopTheBinlogInstance">Stop Binlog Instance</UI-TERM>** or **<UI-TERM key="ocp-v2.Instance.Overview.StartTheBinlogInstance">Start Binlog Instance</UI-TERM>**.

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Binlog Service Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** menu of the **<UI-TERM key="ocp-v2.page.Binlog.BinlogService">Binlog Service</UI-TERM>**

* The binlog instance to be stopped is in the **<UI-TERM key="ocp-v2.page.Overview.Content.NormalOperation">Running</UI-TERM>** state.
* The binlog instance to be started is in the **<UI-TERM key="ocp-v2.page.Overview.Stopped">Stopped</UI-TERM>** state.

## Procedure

The following procedure describes how to stop and then start a binlog instance by using **Method 2**.

1. Log on to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Binlog.BinlogService">Binlog Service</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.Binlog.ClusterList">Cluster List</UI-TERM>** tab automatically appears.

3. On the **<UI-TERM key="ocp-v2.page.Binlog.ClusterList">Cluster List</UI-TERM>** page, find the target binlog cluster and click its name to go to the **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** page.

4. On the **<UI-TERM key="ocp-v2.page.Binlog.ClusterList">Cluster List</UI-TERM>** page, find the binlog instance to be stopped and click its name.

5. On the **<UI-TERM key="ocp-v2.Instance.Overview.BinlogInstanceOverview">Binlog Instance Overview</UI-TERM>** page, click the **<UI-TERM key="ocp-v2.page.Welcome.SeeMore">More</UI-TERM>** icon in the upper-right corner and select **<UI-TERM key="ocp-v2.src.constant.binlog.StopTheBinlogInstance">Stop Binlog Instance</UI-TERM>**.

6. In the dialog box that appears, enter **stop** and click **<UI-TERM key="ocp-v2.Host.Component.BatchReinstallModal.Determine">OK</UI-TERM>**.

   You can view the task progress in **<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">Task Center</UI-TERM>**. When the task status changes to **ExecuteSuccessful** and the status of the instance changes to **<UI-TERM key="ocp-v2.src.constant.oceanbase.Stopped">Stopped</UI-TERM>**, the instance is successfully stopped.

7. Start the instance.

   After the instance is stopped, you can click the **<UI-TERM key="ocp-v2.page.Welcome.SeeMore">More</UI-TERM>** icon in the upper-right corner of the **<UI-TERM key="ocp-v2.Instance.Overview.BinlogInstanceOverview">Binlog Instance Overview</UI-TERM>** page and select **<UI-TERM key="ocp-v2.Instance.Overview.StartTheBinlogInstance">Start Binlog Instance</UI-TERM>** to start the instance.
