# Manage binlog instance parameters

You can modify the parameter values of a binlog instance based on the description in this topic.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Binlog Service Maintenance** permission
* **<UI-TERM key="ocp-v2.Auth.Role.Detail.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** menu of the **<UI-TERM key="ocp-v2.page.Binlog.BinlogService">Binlog Service</UI-TERM>**

## Procedure

1. Log on to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Detail.Overview.BinlogService">Binlog Service</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.Binlog.ClusterList">Cluster List</UI-TERM>** tab automatically appears.

3. On the **<UI-TERM key="ocp-v2.page.Binlog.ClusterList">Cluster List</UI-TERM>** page, find the target binlog cluster and click its name to go to the **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** page.

4. In the **<UI-TERM key="ocp-v2.Component.BinlogInstanceList.BinlogInstanceList">Binlog Instance List</UI-TERM>** section, find the target binlog instance and click its name.

5. In the left-side navigation pane of the page that appears, click **<UI-TERM key="ocp-v2.src.util.menu.ParameterManagement">Parameter Management</UI-TERM>**.

6. (Optional) In the search box of the **<UI-TERM key="ocp-v2.page.Property.ParameterList">Parameters</UI-TERM>** page, enter a parameter name to perform a fuzzy search.

7. Find the parameter to be modified and click **<UI-TERM key="ocp-v2.Detail.Parameter.List.ModifyTheValue">Change Value</UI-TERM>** in the **<UI-TERM key="ocp-v2.Statistics.components.StatTable.Operation">Actions</UI-TERM>** column.

8. In the dialog box that appears, modify the parameter value and click **<UI-TERM key="ocp-v2.Cluster.Component.TakeOverArbitrationDrawer.Ok">OK</UI-TERM>**.
