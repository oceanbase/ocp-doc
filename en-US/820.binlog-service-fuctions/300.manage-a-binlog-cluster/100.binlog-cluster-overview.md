# View information about a binlog cluster

On the specific cluster page, you can view the basic information, Binlog instance information, and Binlog server information of the Binlog cluster, and perform routine operations on the cluster.

## Prerequisites

To view the Binlog cluster overview data, the logged-in user in the OCP console must have the following permissions:

* **Binlog Service Read-Only** resource permission.
* **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** menu permission.

## Basic information of the cluster

On the **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** page, you can view basic information about the cluster, including **<UI-TERM key="ocp-v2.Binlog.Component.UpgradeBinlogModal.BinlogClusterName">Binlog Cluster Name</UI-TERM>**, **<UI-TERM key="ocp-v2.Host.Detail.Basic.State">Status</UI-TERM>**, **<UI-TERM key="ocp-v2.Binlog.Component.UpgradeBinlogModal.VersionNumber">Version No.</UI-TERM>**, **<UI-TERM key="ocp-v2.Detail.Overview.CdcVersion">CDC Version</UI-TERM>**, **<UI-TERM key="ocp-performance-report.ReportTables.ParameterStatInfo.ZoneParamInfoTable.ModificationTime">Modified At</UI-TERM>**, **<UI-TERM key="ocp-v2.Detail.Overview.MetadbInformation">MetaDB Information</UI-TERM>**, **<UI-TERM key="ocp-v2.Detail.Overview.SoftwareInstallationDirectory">Software Installation Directory</UI-TERM>**, and **Binlog File Generation Directory**.

| Parameter | Description |
| --- | --- |
| Binlog Cluster Name |  |
| Status | The current running status of the cluster. Valid values: **<UI-TERM key="ocp-v2.Detail.Statistics.utils.Running">Running</UI-TERM>**, **<UI-TERM key="ocp-v2.src.constant.obproxy.Creating">Creating</UI-TERM>**, **<UI-TERM key="ocp-v2.src.constant.binlog.OM">In Operation Maintenance</UI-TERM>**, **<UI-TERM key="ocp-v2.Topo.TopoGraph.Deleting">Deleting</UI-TERM>**, **<UI-TERM key="ocp-v2.src.constant.backup.Starting">Starting</UI-TERM>**, **<UI-TERM key="ocp-v2.src.constant.compute.Restarting">Restarting</UI-TERM>**, **<UI-TERM key="ocp-v2.src.constant.compute.Stopping">Stopping</UI-TERM>**, and **<UI-TERM key="ocp-v2.src.constant.binlog.Stopped.3">Stopped</UI-TERM>**. |
| Version | The version of the Binlog cluster. |
| CDC Version | The version of OceanBase CDC. |
| Created At | The creation time of the cluster. |
| Modified At | The last modification time of the cluster. |
| MetaDB Information | Click **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.View">View</UI-TERM>** to view the MetaDB configuration information of the Binlog cluster in the dialog box that appears. |
| Software Installation Directory | The installation path of Binlog. This section displays the path that you specified when you [created the Binlog cluster](../200.create-a-binlog-cluster.md). |
| Binlog File Generation Directory | The data storage path of Binlog. The default value is `Software Installation Directory/run`. |

## View the Binlog instance list

**<UI-TERM key="ocp-v2.Component.BinlogInstanceList.BinlogInstanceList">Binlog Instance List</UI-TERM>** displays all the instance information of a Binlog cluster. You can view the information about Binlog instances in different business tenants, including **<UI-TERM key="ocp-v2.Component.BinlogInstanceList.BinlogInstanceName">Binlog Instance Name</UI-TERM>**, **<UI-TERM key="ocp-v2.Component.BinlogInstanceList.NodeIp">Node IP</UI-TERM>**, **Conversion Latency**, **Conversion RPS**, **Subscribed Connection Count**, and **<UI-TERM key="ocp-v2.component.TaskBubble.State">Status</UI-TERM>**. You can also **<UI-TERM key="ocp-v2.src.constant.binlog.ConfigureThrottling">Configure Throttling</UI-TERM>**, **<UI-TERM key="ocp-v2.Cluster.Arbitration.Stop">Stop</UI-TERM>**, **<UI-TERM key="ocp-v2.src.constant.binlog.Start">Start</UI-TERM>**, and **<UI-TERM key="ocp-v2.src.constant.backup.Restart">Restart</UI-TERM>** a Binlog instance. For more information, see [Manage a Binlog instance](500.manage-binlog-instance/100.binlog-instance-overview.md).

![Binlog Server instance](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/435/06261430.png)

## View the Binlog server list

You can view the **IP**, **<UI-TERM key="ocp-v2.Detail.Component.AddUserDrawer.Hostname">Host Name</UI-TERM>**, **<UI-TERM key="ocp-v2.src.component.AddHostDrawer.HostType">Host Type</UI-TERM>**, **<UI-TERM key="ocp-v2.OBProxy.New.ModelOptional">Host Type</UI-TERM>**, **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.ComputerRoom">IDC</UI-TERM>**, **<UI-TERM key="ocp-v2.Component.BackupStrategyDetail.Region">Region</UI-TERM>**, and **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.State">Status</UI-TERM>** of each Binlog server in the **Binlog Server List**. You can also **<UI-TERM key="ocp-v2.Component.BinlogServerList.Stop">Stop</UI-TERM>**, **<UI-TERM key="ocp-v2.Component.BinlogInstanceList.Start">Start</UI-TERM>**, and **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.Delete">Delete</UI-TERM>** a Binlog server. For more information, see [Manage a Binlog server](600.manage-binlog-server/100.add-a-binlog-server.md).

![Binlog server list](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/431/binlogserver%E5%88%97%E8%A1%A8.png)

## Manage a Binlog cluster

On the **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** page, you can also perform basic cluster management operations. For more information, see [Upgrade a Binlog cluster](150.upgrade-a-binlog-cluster.md), [Add a Binlog server](600.manage-binlog-server/100.add-a-binlog-server.md), [Stop/Start a Binlog cluster](200.stop-and-start-a-binlog-cluster.md), [Restart a Binlog cluster](300.restart-a-binlog-cluster.md), [Delete a Binlog cluster](400.delete-a-binlog-cluster.md), and [View logs](../../1300.log-service/100.log-query.md).

You can also perform routine operations on clusters by using the left-side navigation pane. For more information, see [Manage parameters of a Binlog cluster](../400.manage-binlog-cluster-parameters.md).

## Switch Binlog clusters

To view the overview information of another Binlog cluster, click the name of the Binlog cluster at the top left of the **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** page and select the Binlog cluster that you want to view. The current overview page switches to the overview page of the Binlog cluster that you want to view.
