# Delete a binlog cluster

You can delete a binlog cluster that is no longer required. A deleted binlog cluster cannot be recovered. After a binlog cluster is deleted, the associated binlog subscription tasks will be cleared and all binlog instances in the cluster will be stopped. Proceed with caution.

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Binlog Service Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** menu of the **<UI-TERM key="ocp-v2.page.Binlog.BinlogService">Binlog Service</UI-TERM>**

* The binlog cluster to be deleted is in the **<UI-TERM key="ocp-v2.src.constant.tenant.NormalOperation">Running</UI-TERM>** or **<UI-TERM key="ocp-v2.src.constant.binlog.Stopped.3">Stopped</UI-TERM>** state.

## Procedure

1. Log on to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Detail.Overview.BinlogService">Binlog Service</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.Binlog.ClusterList">Cluster List</UI-TERM>** tab automatically appears.

3. On the **<UI-TERM key="ocp-v2.page.Binlog.ClusterList">Cluster List</UI-TERM>** page, find the target binlog cluster and click its name.

4. On the **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** tab, click the **<UI-TERM key="ocp-v2.Cluster.Component.MachineResource.SeeMore">More</UI-TERM>** icon in the upper-right corner and select **<UI-TERM key="ocp-v2.Binlog.Component.DeleteBinlogModal.DeleteABinlogCluster">Delete Binlog Cluster</UI-TERM>**.

5. In the dialog box that appears, enter **delete** and then click **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.Delete">Delete</UI-TERM>**.

   You can view the task progress in **<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">Task Center</UI-TERM>**. When the task status changes to **ExecuteSuccessful** and the binlog cluster no longer exists on the **<UI-TERM key="ocp-v2.page.Binlog.ClusterList">Cluster List</UI-TERM>** page, the cluster is successfully deleted.
