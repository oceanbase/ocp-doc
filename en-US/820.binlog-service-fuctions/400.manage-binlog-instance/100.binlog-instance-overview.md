# View a binlog instance

A binlog instance is a tenant-level instance responsible for generating and sending binlogs, and for monitoring and processing SQL requests through TCP based on the MySQL protocol. On the **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** page of a binlog instance, you can view its basic information and subscription connection information, and perform basic O&M operations on the binlog instance.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Binlog Service Read-only** permission
* **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** menu of the **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogService">Binlog Service</UI-TERM>**

## View the basic information of a binlog instance

In the **<UI-TERM key="ocp-v2.Instance.Overview.BinlogInstanceOverview">Binlog Instance Overview</UI-TERM>** section, you can view basic instance information in the following fields: **<UI-TERM key="ocp-v2.Instance.Overview.BinlogInstanceName">Binlog Instance Name</UI-TERM>**, **<UI-TERM key="ocp-v2.Instance.Overview.BusinessCluster">Business Cluster</UI-TERM>**, **<UI-TERM key="ocp-v2.Component.BinlogInstanceList.BusinessTenant">Business Tenant</UI-TERM>**, **<UI-TERM key="ocp-v2.Backup.SecondaryBackup.Data.State">Status</UI-TERM>**, **<UI-TERM key="ocp-v2.Binlog.Component.UpgradeBinlogModal.VersionNumber">Version No.</UI-TERM>**, **Created Time**, **Subscription Connections**, **Connected OBProxy Clusters**, and **Binlog File Generation Directory**.

* You can click the cluster name next to **<UI-TERM key="ocp-v2.Instance.Overview.BusinessCluster">Business Cluster</UI-TERM>** to go to the overview page of the business cluster.

* You can click the tenant name next to **<UI-TERM key="ocp-v2.Instance.Overview.BusinessTenant">Business Tenant</UI-TERM>** to go to the overview page of the business tenant.

* You can click the cluster name next to **Connected OBProxy Cluster** to go to the overview page of the OBProxy cluster.

## View the subscription connection list

In the **<UI-TERM key="ocp-v2.Instance.Overview.SubscriptionConnectionList">Subscription Connection List</UI-TERM>** section, you can view the subscription connection information about a binlog instance in the following columns: **<UI-TERM key="ocp-v2.src.component.AddHostCredentialDrawer.UserName">Username</UI-TERM>**, **Client IP**, **<UI-TERM key="ocp-v2.Alarm.Channel.Detail.Port">Port</UI-TERM>**, **<UI-TERM key="ocp-v2.Instance.Overview.SendingPoint">Sending Point</UI-TERM>**, **<UI-TERM key="ocp-v2.Instance.Overview.TransmissionDelayMs">Sending Delay (ms)</UI-TERM>**, **<UI-TERM key="ocp-v2.Instance.Overview.Monitor.SendRps">Associate RPS</UI-TERM>**, and **<UI-TERM key="ocp-v2.Instance.Overview.Monitor.NetworkTraffic">Network Traffic</UI-TERM>**.

* You can click the plus sign (**+**) on the left of the username to view the real-time monitoring charts of **<UI-TERM key="ocp-v2.Instance.Overview.Monitor.SendDelay">Sending Delay</UI-TERM>**, **<UI-TERM key="ocp-v2.Instance.Overview.SendRps">Associate RPS</UI-TERM>**, and **<UI-TERM key="ocp-v2.Instance.Overview.Monitor.NetworkTraffic">Network Traffic</UI-TERM>**.

* You can select **<UI-TERM key="ocp-v2.component.RangeTimeDropdown.LastMinutes">Last 5 Minutes</UI-TERM>**, **<UI-TERM key="ocp-v2.Information.Detail.CreateCollectDrawer.NearlyMinutes">Last 10 Minutes</UI-TERM>**, **<UI-TERM key="ocp-v2.SQLDiagnosis.Digest.LastMinutes.3">Last 20 Minutes</UI-TERM>**, **<UI-TERM key="ocp-v2.component.OCPRangePicker.constant.NearlyMinutes.3">Last 30 Minutes</UI-TERM>**, **<UI-TERM key="ocp-v2.Cluster.Component.PerformanceTop5.LastHour">Last 1 Hour</UI-TERM>**, **<UI-TERM key="ocp-v2.component.OCPRangePicker.constant.NearlyHours">Last 3 Hours</UI-TERM>**, **<UI-TERM key="ocp-v2.component.OCPRangePicker.constant.NearlyHour.6">Last 6 Hours</UI-TERM>**, **<UI-TERM key="ocp-v2.src.constant.log.NearlyHours.2">Last 12 Hours</UI-TERM>**, **<UI-TERM key="ocp-v2.component.TenantMonitorTop5.LastDay">Last 24 Hours</UI-TERM>**, or **<UI-TERM key="ocp-v2.component.TenantMonitorTop5.LastWeek">Last 7 Days</UI-TERM>** from the **Monitoring time range** drop-down list to view monitoring data of the selected statistical period. You can also select **<UI-TERM key="ocp-v2.component.OCPRangePicker.CustomTime">Custom Time</UI-TERM>** from the drop-down list and specify the start time and end time as needed. By default, the monitoring data of the last 5 minutes is displayed.

## Manage binlog instances

In the **<UI-TERM key="ocp-v2.Component.OCPObjscope.BinlogInstance">Binlog Instance</UI-TERM>** section, you can perform basic O&M operations on binlog instances. For more information, see [Configure throttling](150.configure-throttling.md), [Start and stop a binlog instance](200.start-and-stop-a-binlog-instance.md), [Restart a binlog instance](300.restart-a-binlog-instance.md), [View subscription connection monitoring charts](../../880.manage-performance-monitoring/100.performance-monitoring-overview/630.view-subscription-connection-of-binlog.md), [View performance monitoring data of a binlog instance](../../880.manage-performance-monitoring/100.performance-monitoring-overview/650.view-performance-monitoring-of-binlog.md), [View resource monitoring data of a binlog instance](../../880.manage-performance-monitoring/100.performance-monitoring-overview/670.view-resource-monitoring-of-binlog.md), and [Manage binlog instance parameters](500.manage-a-binlog-instance-parameters.md).

## Switch between binlog instances

To view the information about another binlog instance in the same binlog cluster, click the name of the instance in the upper-left corner of the **<UI-TERM key="ocp-v2.Instance.Overview.BinlogInstanceOverview">Binlog Instance Overview</UI-TERM>** page to switch to its overview page.
