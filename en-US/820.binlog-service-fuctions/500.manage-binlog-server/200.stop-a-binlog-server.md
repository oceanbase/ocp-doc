# Start and stop a binlog server

This topic describes how to stop and start a binlog server.

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Binlog Service Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** menu of the **<UI-TERM key="ocp-v2.Detail.Overview.BinlogService">Binlog Service</UI-TERM>**

* Both the binlog server to be stopped and the binlog cluster to which the binlog server belongs are in the **<UI-TERM key="ocp-v2.src.constant.backup.NormalOperation">Running</UI-TERM>** state.
* The binlog server to be started is in the **<UI-TERM key="ocp-v2.src.constant.binlog.Stopped.3">Stopped</UI-TERM>** state and the binlog cluster to which the binlog server belongs is in the **<UI-TERM key="ocp-v2.src.constant.tenant.NormalOperation">Running</UI-TERM>** or **<UI-TERM key="ocp-v2.src.constant.oceanbase.Stopped">Stopped</UI-TERM>** state.

## Procedure

1. Log on to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogService">Binlog Service</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.Binlog.ClusterList">Cluster List</UI-TERM>** tab automatically appears.

3. On the **<UI-TERM key="ocp-v2.page.Binlog.ClusterList">Cluster List</UI-TERM>** page, find the target binlog cluster and click its name to go to the **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** page.

4. In the **Binlog Server List** section, select the binlog server to be stopped and click **<UI-TERM key="ocp-v2.src.constant.binlog.Stop">Stop</UI-TERM>** in the **<UI-TERM key="ocp-v2.Component.OBServerList.Operation">Actions</UI-TERM>** column.

5. In the dialog box that appears, click **<UI-TERM key="ocp-v2.Detail.Overview.Stop">Stop</UI-TERM>**.

   You can view the task progress in **<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">Task Center</UI-TERM>**. When the task enters the **ExecuteSuccessful** state and the status of the corresponding binlog node is displayed as **<UI-TERM key="ocp-v2.page.Overview.Stopped">Stopped</UI-TERM>** in the **Binlog Server List** section, the task succeeds.

6. Start the binlog server.

   After the binlog server is stopped, you can click **<UI-TERM key="ocp-v2.Restore.SamplingStrategy.Start">Start</UI-TERM>** in the **<UI-TERM key="ocp-v2.page.Host.Operation">Actions</UI-TERM>** column of the binlog server in **Binlog Server List** to start the binlog server.
