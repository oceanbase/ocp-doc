# Delete a binlog server

This topic describes how to delete a binlog server from a binlog cluster.

## Prerequisites

* Make sure that you have the following permissions:

  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">Resource Permissions</UI-TERM>**: **Binlog Service Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** menu of the **<UI-TERM key="ocp-v2.page.Binlog.BinlogService">Binlog Service</UI-TERM>**

* The cluster to which the binlog server to be deleted belongs is in the **<UI-TERM key="ocp-v2.page.Overview.Content.NormalOperation">Running</UI-TERM>** or **<UI-TERM key="ocp-v2.page.Overview.Stopped">Stopped</UI-TERM>** state.
* To delete the only binlog server from a binlog cluster, you need to delete the binlog cluster.

## Procedure

1. Log on to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Binlog.BinlogService">Binlog Service</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.Binlog.ClusterList">Cluster List</UI-TERM>** tab automatically appears.

3. On the **<UI-TERM key="ocp-v2.page.Binlog.ClusterList">Cluster List</UI-TERM>** page, find the target binlog cluster and click its name to go to the **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** page.

4. In the **Binlog Server List** section, select the binlog server to be deleted and click **<UI-TERM key="ocp-v2.Alarm.Rule.Delete">Delete</UI-TERM>** in the **<UI-TERM key="ocp-v2.page.Package.UploadPackageTaskDrawer.Operation">Actions</UI-TERM>** column.

5. In the dialog box that appears, enter **delete** and then click **<UI-TERM key="ocp-v2.src.constant.backup.Delete">Delete</UI-TERM>**.

   You can view the task progress in **<UI-TERM key="ocp-v2.Layout.BasicLayout.TaskCenter">Task Center</UI-TERM>**. When the task enters the **ExecuteSuccessful** state and the binlog server no longer exists in the **Binlog Server List** section, the binlog server is successfully deleted.

## Related operations

After you delete a binlog server, you need to manually clear the binlog instances on the host as needed. For more information, see [Clear binlog instances on a host](400.clean-binlog-instance-on-a-host.md).
