# Add a binlog node

You can add binlog nodes to a binlog cluster to scale out the cluster.

In OceanBase Cloud Platform (OCP), you can add a binlog node by using either of the following methods:

* **Method 1**: On the **<UI-TERM key="ocp-v2.page.Binlog.ClusterList">Cluster List</UI-TERM>** page, click **<UI-TERM key="ocp-v2.src.constant.binlog.AddNode">New Node</UI-TERM>** in the **<UI-TERM key="ocp-v2.page.OBProxy.Operation">Actions</UI-TERM>** column of the target cluster.
* **Method 2**: On the **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** tab, click **<UI-TERM key="ocp-v2.Detail.Overview.AddNode">New Node</UI-TERM>** in the upper-right corner.

## Prerequisites

Make sure that you have the following permissions:

* **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Binlog Service Maintenance** permission
* **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** menu of the **<UI-TERM key="ocp-v2.Detail.Overview.BinlogService">Binlog Service</UI-TERM>**

## Procedure

The following procedure describes how to add a binlog node by using **Method 2**.

1. Log on to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogService">Binlog Service</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.Binlog.ClusterList">Cluster List</UI-TERM>** tab automatically appears.

3. On the **<UI-TERM key="ocp-v2.page.Binlog.ClusterList">Cluster List</UI-TERM>** page, find the target binlog cluster and click its name.

4. On the **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** tab, click **<UI-TERM key="ocp-v2.Binlog.Component.AddBinlogNodeModal.AddNode">New Node</UI-TERM>** in the upper-right corner.

5. In the **<UI-TERM key="ocp-v2.Detail.Overview.AddNode">New Node</UI-TERM>** dialog box, specify the IDC, model, and host of the binlog node to be added. You can select multiple hosts.

    By default, only one binlog node is added. To add more binlog nodes, click **New Binlog Server**.

6. Click **<UI-TERM key="ocp-v2.User.Oracle.UserList.Determine">OK</UI-TERM>** to submit the task to add a binlog node.

   You can view the task progress in **<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">Task Center</UI-TERM>**. When the task enters the **ExecuteSuccessful** state and the status of the corresponding binlog node is displayed as **<UI-TERM key="ocp-v2.src.constant.binlog.NormalOperation">Normal Operation</UI-TERM>** in the **Binlog Server List** section on the **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** page, the binlog node is successfully added.
