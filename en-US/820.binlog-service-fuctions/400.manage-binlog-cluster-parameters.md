# Manage binlog cluster parameters

On the **<UI-TERM key="ocp-v2.component.OperationConfig.Parameter.ParameterList">Parameters</UI-TERM>** page, you can view the name, current value, and description of each parameter in the current binlog cluster, and modify parameter values as needed.

## Prerequisites

* To view the parameter settings of a binlog cluster, make sure that you have the following permissions:
  * **<UI-TERM key="ocp-v2.Auth.Role.ResourcePermissions">Resource Permissions</UI-TERM>**: **Binlog Service Read-only** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.Detail.Parameter.ParameterManagement">Parameter Management</UI-TERM>** menu of the **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogService">Binlog Service</UI-TERM>**
* To modify the parameters of a binlog cluster, make sure that you have the following permissions:
  * **<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourcePermissions">Resource Permissions</UI-TERM>**: **Binlog Service Maintenance** permission
  * **<UI-TERM key="ocp-v2.Auth.Role.AddRole.MenuPermissions">Menu Permissions</UI-TERM>**: Permission on the **<UI-TERM key="ocp-v2.page.Iframe.ParameterManagement">Parameter Management</UI-TERM>** menu of the **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogService">Binlog Service</UI-TERM>**

## Procedure

1. Log on to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogService">Binlog Service</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.Binlog.ClusterList">Cluster List</UI-TERM>** tab automatically appears.

3. On the **<UI-TERM key="ocp-v2.page.Binlog.ClusterList">Cluster List</UI-TERM>** page, find the target binlog cluster and click its name.

4. In the left-side navigation pane of the page that appears, click **<UI-TERM key="ocp-v2.component.OperationConfig.ParameterManagement">Parameter Management</UI-TERM>**.

5. On the **<UI-TERM key="ocp-v2.page.Property.ParameterList">Parameters</UI-TERM>** page that automatically appears, you can view all parameters of the current binlog cluster.

6. (Optional) In the search box of the **<UI-TERM key="ocp-v2.page.Property.ParameterList">Parameters</UI-TERM>** page, enter a parameter name to perform a fuzzy search.

7. Find the parameter to be modified and click **<UI-TERM key="ocp-v2.Detail.Parameter.List.ModifyTheValue">Change Value</UI-TERM>** in the **<UI-TERM key="ocp-v2.component.TenantList.Operation">Actions</UI-TERM>** column.

8. In the dialog box that appears, modify the parameter value and click **<UI-TERM key="ocp-v2.Host.Component.ReinstallModal.Determine">OK</UI-TERM>**.
