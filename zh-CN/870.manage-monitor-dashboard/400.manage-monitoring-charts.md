# 管理图表

当创建大盘后，可在大盘中新增您想关注的监控图表。

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **集群只读**、**租户只读**、**OBProxy 只读**、**仲裁服务只读**、**Binlog 服务只读** 或 **主机只读** 任一资源权限。
  * **<UI-TERM key="ocp-v2.Monitor.Dashboard.MonitoringDashboard">监控大盘</UI-TERM>** 菜单权限。

* 不同用户创建的大盘相互隔离，仅可查看和管理自己名下的监控大盘。
* 每个大盘最多可添加 32 个监控图表。

## 操作步骤

### 新增图表

OCP 支持如下 3 种方式新增图表：

* 方式 1：单击大盘右上角 **<UI-TERM key="ocp-v2.Dashboard.Detail.AddChart">添加图表</UI-TERM>**。
* 方式 2：当大盘中暂无图表时，单击大盘中的 **<UI-TERM key="ocp-v2.component.AddChartDrawer.AddChart">添加图表</UI-TERM>** 按钮进行添加。
* 方式 3：在大盘中选择具体分组，单击分组中的![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E5%88%86%E7%BB%84%E6%96%B0%E5%A2%9E%E5%9B%BE%E8%A1%A8.png)图标，在下拉列表中选择 **<UI-TERM key="ocp-v2.Dashboard.component.AddPanelDropdown.AddChart">添加图表</UI-TERM>**。

以下步骤以 **方式 1** 为例。

1. 登录 OCP 。

2. 在左侧导航栏选择 **<UI-TERM key="ocp-v2.Monitor.Dashboard.MonitoringDashboard">监控大盘</UI-TERM>** 。

3. 进入待添加图表的大盘页签下，单击右上角 **<UI-TERM key="ocp-v2.component.AddChartDrawer.AddChart">添加图表</UI-TERM>**。

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/435/20251503.png)

4. 在面板中输入图表相关信息，单击 **<UI-TERM key="ocp-v2.Cluster.Component.TakeOverArbitrationDrawer.Ok">确定</UI-TERM>**。

    相关参数说明如下。

   |     参数  |  说明  |

   | 选择监控对象和指标 | 您可参考如下步骤进行配置：<ol><li>选择监控对象类型：支持 **<UI-TERM key="ocp-v2.src.component.ModifyTagResourceDrawer.OceanbaseCluster">OceanBase 集群</UI-TERM>**、**<UI-TERM key="ocp-v2.src.component.ModifyTagResourceDrawer.OceanbaseTenants">OceanBase 租户</UI-TERM>**、**<UI-TERM key="ocp-v2.src.component.ArchitectureAndVpcAlert.ObproxyCluster">OBProxy 集群</UI-TERM>** 和 **<UI-TERM key="ocp-v2.Arbitration.ArbitrationGroup.Host">主机</UI-TERM>** 四种类型。</li><li>选择监控对象：在下拉列表中选择具体监控对象，可选择的对象与 **监控对象类型** 存在关联，支持多选。</li><li>选择监控指标：在下拉列表中选择具体指标项，可选择的指标项与 **监控对象** 存在关联，支持多选。<ul><li>若列表中存在所需的指标项，可从列表中直接选择；否则，可单击列表下方的 **<UI-TERM key="ocp-v2.Alarm.Rule.New.AddMetric">添加指标</UI-TERM>** 来创建所需的指标项，详情可参见 [新建指标项](../880.manage-performance-monitoring/200.manage-custom-monitoring/300.manage-indicator-items/100.create-a-indicator-item.md)。</li><li>可选择的监控指标中包括 OCP 内置指标项和用户自定义指标项。关于 OCP 内置指标项的详细说明，可参见 [监控指标参考](../1900.reference-guide/300.monitoring-indicator-reference/100.overview-of-metrics.md)。</li></ul><main id="notice" type='notice'><h4>注意</h4><p>所选指标的单位最多不能超过两种。</p></main></li><li>选择图表类型：选择监控指标的展示方式，目前支持的图表类型包括如下 3 大类 7 种图表。<ul><li>趋势类：**<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.LineChart">折线图</UI-TERM>**、**<UI-TERM key="ocp-v2.Monitor.Dashboard.constants.AreaMap">面积图</UI-TERM>**、**<UI-TERM key="ocp-v2.Monitor.Dashboard.constants.Histogram">柱状图</UI-TERM>**。</li><li>展示类：**<UI-TERM key="ocp-v2.Monitor.Dashboard.constants.DigitalIndicatorCard">数字指标卡</UI-TERM>**、**<UI-TERM key="ocp-v2.Monitor.Dashboard.constants.Table">表格</UI-TERM>**。</li><li>占比类：**<UI-TERM key="ocp-v2.Monitor.Dashboard.constants.WaterWaveDiagram">水波图</UI-TERM>**、**<UI-TERM key="ocp-v2.Dashboard.constant.chart.CircularDiagram">环形图</UI-TERM>**。</li></ul> </li></ol>  |

   系统默认只添加一个图表，如果您需要批量添加多个图表，可以在下方单击 **<UI-TERM key="ocp-v2.component.AddChartDrawer.ContinueAdding">继续添加</UI-TERM>**，添加多个图表。

### 相关操作

您可对大盘中的监控图表进行如下运维操作。

* **移动图表**：拖拽图表头部，可在大盘中自由调整图表位置。
* **查看详细信息**：将光标悬停于趋势图中某时刻，可查看该时刻的详细数据；拖拽光标选中某区域，系统会放大显示该区域的趋势信息，您可查看该指标的在此时间段的详细趋势，双击该趋势图可恢复。
* **隐藏图例信息**：单击趋势图下方的图例标识，使其置灰，趋势图中将不展示该图例相关信息。您可通过此功能隐藏其他图例数据。
* **<UI-TERM key="ocp-v2.widgets.Chart.MonitorDrillDown">监控下钻</UI-TERM>**：单击下图 ① 处的 **<UI-TERM key="ocp-v2.component.MetricChart.Item.DrillDownAnalysis">下钻分析</UI-TERM>** 图标，可下钻查看不同维度的监控数据。当您发现监控对象的监控数据异常时，您可通过下钻分析，定位到引起响应时间异常的服务器。

    <main id="notice" type='explain'>
    <h4>说明</h4>
    <p>仅 <b>折线图</b> 支持监控下钻功能，且监控对象需为单个 OceanBase 集群或租户。</p>
    </main>

* **<UI-TERM key="ocp-v2.widgets.Chart.MonitoringComparison">监控对比</UI-TERM>**：单击下图 ② 处的 **<UI-TERM key="ocp-v2.widgets.Chart.MonitoringComparison">监控对比</UI-TERM>** 图标，自定义需要对比的时间段后，可查看该时间段监控数据的环比数据（对比上个时间段）、日同比数据（对比前一天该时间段）、周同比数据（对比上周该时间段）及月同比数据（对比上个月该时间段）。
* **<UI-TERM key="ocp-v2.src.constant.credential.Edit">编辑</UI-TERM>**：单击下图 ③ 处的 **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.EditChart">编辑图表</UI-TERM>** 图标，可修改图表信息。
* **<UI-TERM key="ocp-v2.src.constant.compute.Delete">删除</UI-TERM>**：单击下图 ④ 处的 **<UI-TERM key="ocp-v2.widgets.Chart.DeleteChart">删除图表</UI-TERM>** 图标，可将该图表从大盘中删除。
* **放大某一趋势图**：单击下图 ⑤ 处的 **<UI-TERM key="ocp-v2.widgets.Chart.ZoomInToView">放大查看</UI-TERM>** 图标，**查看详细信息** 与 **隐藏细分指标** 功能在放大的趋势图中同样适用。
* **调整图表大小**：单击下图 ⑥ 处的调整图标，可对整个图表进行放大或缩小操作，如上所有功能在放大和缩小的趋势图中同样适用。
