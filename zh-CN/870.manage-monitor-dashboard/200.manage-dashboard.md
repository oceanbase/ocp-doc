# 管理大盘

OCP 支持通过将指标预先定义到同一个页面，实现自定义您所关注的部分监控指标。每个大盘为一个页签，方便您对关注的监控图表进行归类。

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **集群只读**、**租户只读**、**OBProxy 只读**、**仲裁服务只读**、**Binlog 服务只读** 或 **主机只读** 任一资源权限。
  * **<UI-TERM key="ocp-v2.Monitor.Dashboard.MonitoringDashboard">监控大盘</UI-TERM>** 菜单权限。

* 不同用户创建的大盘相互隔离，仅可查看和管理自己名下的监控大盘。

## 操作步骤

### 新建大盘

在添加监控图表之前，您需先创建大盘。

1. 登录 OCP 。

2. 在左侧导航栏选择 **<UI-TERM key="ocp-v2.Monitor.Dashboard.MonitoringDashboard">监控大盘</UI-TERM>** 。

3. 单击页面右上角 **<UI-TERM key="ocp-v2.Dashboard.component.AddDashboardModal.CreateADashboard">新建大盘</UI-TERM>**。

4. 在弹窗中输入大盘名称，并单击 **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.Determine">确定</UI-TERM>**。

    大盘名称需具有唯一性，且长度为 2~64 个字符。

### 导入大盘

可选择导入本地已保存的大盘文件，避免重复配置相同的监控大盘信息。

1. 登录 OCP 。

2. 在左侧导航栏选择 **<UI-TERM key="ocp-v2.Monitor.Dashboard.MonitoringDashboard">监控大盘</UI-TERM>** 。

3. 单击页面右上角 **<UI-TERM key="ocp-v2.Monitor.Dashboard.Import">导入</UI-TERM>** 。

4. 在弹窗中单击 **<UI-TERM key="ocp-v2.Dashboard.component.ImportDashboardModal.SelectFile">选择文件</UI-TERM>**，上传需导入的大盘 json 文件。

5. 单击 **<UI-TERM key="ocp-v2.page.Information.Ok">确定</UI-TERM>**。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>仅支持导入 OCP 大盘的 json 文档。</p>
</main>

### 导出大盘

OCP 支持 **<UI-TERM key="ocp-v2.Monitor.Dashboard.ExportOcpDashboard">导出 OCP 大盘</UI-TERM>** 和 **导出 Grafana 大盘**。导出大盘后，OCP 会在本地保存一份 json 文件，您可在其它 OCP 或其它监控平台使用该监控大盘数据。

1. 登录 OCP 。

2. 在左侧导航栏选择 **<UI-TERM key="ocp-v2.Monitor.Dashboard.MonitoringDashboard">监控大盘</UI-TERM>** 。

3. 单击右上角 **<UI-TERM key="ocp-v2.Monitor.Dashboard.Export">导出</UI-TERM>** ，在下拉框中选择需要导出的大盘类型。

4. 在弹窗中选择待导出的大盘名称。

5. 单击 **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLLimit.Determine">确定</UI-TERM>**。

### 相关操作

OCP 支持对监控大盘进行如下运维操作。

* **<UI-TERM key="ocp-v2.Cluster.New.Switch">切换</UI-TERM>**：所有大盘均以页签形式呈现，单击大盘名称可进行大盘切换。
* **排序**：拖拽大盘名称左右移动，可对大盘位置进行重新排序。
* **<UI-TERM key="ocp-v2.Compaction.SettingsV4.Modify">修改</UI-TERM>**：单击下图 ① 处的 **<UI-TERM key="ocp-v2.Monitor.Dashboard.ModifyName">修改名称</UI-TERM>** 按钮，可对大盘进行重命名。
* **<UI-TERM key="ocp-v2.Detail.TakeOver.Delete">删除</UI-TERM>**：单击下图 ② 处的 **<UI-TERM key="ocp-v2.Monitor.Dashboard.DeleteDashboard">删除大盘</UI-TERM>** 按钮，可对大盘进行删除操作。

   <main id="notice" type='notice'>
   <h4>注意</h4>
   <p>大盘删除后将无法恢复，请谨慎操作。</p>
   </main>

* **<UI-TERM key="ocp-v2.Detail.Transaction.AutomaticRefresh">自动刷新</UI-TERM>**：单击下图 ③ 处的 **<UI-TERM key="ocp-v2.Session.Deadlock.Refresh">刷新</UI-TERM>** 按钮，可选择立即刷新或为大盘配置自动刷新频率。配置自动刷新后，大盘将按照所配置的频率自动刷新监控数据，您可通过该功能查看大盘下监控图表的最新情况。可以选择的刷新频率为 5 秒、10 秒、30 秒，默认为 **Off** 状态。
* **时间筛选**：单击下图 ④ 处的时间选择器，选择某一段时间范围，可在大盘中查看该时间范围内的监控数据。
* **<UI-TERM key="ocp-v2.Dashboard.Detail.ChartLinkage">图表联动</UI-TERM>**：单击下图 ⑤ 处的 **<UI-TERM key="ocp-v2.Dashboard.Detail.ChartLinkage">图表联动</UI-TERM>** 按钮，开启图表联动后，将光标悬停于图表的某个时刻，同一大盘下的其他图表会同时展示同一时刻的横轴定位点，您可通过该功能对不同指标进行监控对比。

   <main id="notice" type='explain'>
   <h4>说明</h4>
   <p>目前仅支持 <b>折线图</b> 和 <b>面积图</b> 进行图表联动。</p>
   </main>

* **<UI-TERM key="ocp-v2.Dashboard.Detail.ChartLayout">图表布局</UI-TERM>**：单击下图 ⑥ 处的 **<UI-TERM key="ocp-v2.Dashboard.Detail.ChartLayout">图表布局</UI-TERM>** 菜单，可以设置每行显示监控指标趋势图的数量。支持 **<UI-TERM key="ocp-v2.Dashboard.Detail.OneInARow">一行 1 个</UI-TERM>**、**<UI-TERM key="ocp-v2.Dashboard.Detail.InARow">一行 2 个</UI-TERM>**、**<UI-TERM key="ocp-v2.Dashboard.Detail.InARow.1">一行 3 个</UI-TERM>** 或 **<UI-TERM key="ocp-v2.Dashboard.Detail.InARow.2">一行 4 个</UI-TERM>** 四种布局模式，默认每行展示 2 个监控指标趋势图。
