# 日常切换 OCP 集群（Switchover）

本页面为您介绍将 OCP 备集群日常切换为主集群的操作。执行 Switchover 操作后，主集群会与对应的备集群交换集群角色，其主备关系仍存在。

<main id="notice" type='notice'>
<h4>功能适用性</h4>
<p>该内容仅适用于 OCP 企业版，OCP 社区版不提供此功能。</p>
</main>

## 前提条件

* 请确保当前登录 OCP 的用户为 **ADMIN** 角色。
* 当进行 OCP 主集群删除操作时，需进行日常切换，将主集群切换为备集群后进行下线，详情参见 [下线 OCP 集群](../300.ocp-multi-cluster-mode/800.remove-an-ocp-cluster.md)。其它情况下，请谨慎进行日常切换操作。

## 操作步骤

1. 登录 OCP 云平台。

2. 在左侧导航栏中单击 **系统管理\>OCP 多集群模式** 。

3. 在 **<UI-TERM key="ocp-v2.page.MultiCluster.MasterSlaveDetails">主备详情</UI-TERM>** 页签， **当前 OCP 基本信** 息中，单击 **<UI-TERM key="ocp-v2.MultiCluster.Detail.SwitchToPrimaryOcp">切换为主 OCP</UI-TERM>** 。

   ![1](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0800872261/p280235.png)

4. 单击 **<UI-TERM key="ocp-v2.MultiCluster.Detail.SwitchoverModal.DailySwitchover">日常切换</UI-TERM>** 。

   ![2](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0800872261/p280219.png)

5. 完成切换后可在 **<UI-TERM key="ocp-v2.Layout.BasicLayout.TaskCenter">任务中心</UI-TERM>** 中查看详细进展，详情参见 [任务管理](../../1600.system-management-features/600.manage-tasks.md)。
