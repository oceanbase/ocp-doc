# 管理报告中心

报告中心支持生成和下载 **集群** 、**租户** 、**OBProxy** 、**主机** 、**Binlog** 、**仲裁服务** 等管控对象的基础信息、资源分配及使用情况的报表数据。

运维人员通过报表能实时监测资源异常，及时处理潜在风险；资源规划人员可依据历史与实时数据，精准规划资源分配与扩容方案；业务负责人能清晰了解业务资源成本，科学评估投入产出效益，为企业资源优化与决策提供坚实数据支撑，有效提升整体资源管理效能。

## 新建报告<a id="parameter"></a>

本节为您介绍如何为管控对象新增报告。

### 前提条件

请确保当前登录 OCP 的用户为 **ADMIN** 角色或 **ORG_ADMIN** 角色。

### 操作步骤

1. 登录 OCP。

2. 在左侧导航栏选择 **运维管理** > **报告中心** ，进入 **报告中心** 页面。

3. 单击右上角 **新建报告** 。

4. 在右侧面板中配置报告相关信息，具体参数说明如下。

    |  参数   |  说明   |
    |---------|---------|
    | 报告名称  | <ul><li>仅支持以中文或英文字母开头，中文、字母或数字结尾。</li><li>支持 2 ~ 32 个字符。</li><li>特殊符号仅支持下划线。</li></ul>    |
    | 类型      | 选择管控对象的类型，支持 **集群** 、**租户** 、**OBProxy** 、**主机** 、**Binlog** 和 **仲裁服务** 6 种类型。    |
    | 选择对象  | 依据实际需要，选择具体的管控对象。<br>当选择全部对象，您可通过勾选右侧的 **排除对象** ，对不需要生成报告的对象进行排除。    |
    | 属性      | 将会在报告中展示的属性信息。当选择不同 **类型** 时，展示的属性信息会有所不同。     |
    | 备注      | 为报告添加额外说明。     |

5. 单击 **确定** 。

## 下载报告

生成报告后，您可将报告下载至本地，即时查看管控对象的报表数据。报告默认 30 天后将被自动删除，建议您在有效期内进行下载。

### 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **集群维护** 或 **租户维护** 资源权限。
  * 运维管理 **报告中心** 菜单权限。

* 已 [新建报告](#parameter) 。

### 操作步骤

1. 登录 OCP。

2. 在左侧导航栏选择 **运维管理** > **报告中心** ，进入 **报告中心** 页面。

3. 选择需要下载的报告，在操作列 **...** 中单击 **下载** 。

4. 即可将此报告下载至本地进行查看。

## 删除报告

除系统自动删除报告外，您还可以对所生成的报告执行手动删除。

### 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **集群维护** 或 **租户维护** 资源权限。
  * 运维管理 **报告中心** 菜单权限。

* 已 [新建报告](#parameter) 。

### 操作步骤

1. 登录 OCP。

2. 在左侧导航栏选择 **运维管理** > **报告中心** ，进入 **报告中心** 页面。

3. 选择需要下载的报告，在操作列 **...** 中单击 **删除** 。

4. 在对话框中单击 **删除**，即可立即删除此报告。

## 修改报告保留时长

报告默认仅保留 30 天，您可在 **系统管理** > **系统参数** 中，通过 `ocp.report.center.report.retention.days` 参数修改报告保留时长，操作详情可参考 [修改系统参数](../1600.system-management-features/500.manage-system-parameter/200.modify-system-parameters.md)。
