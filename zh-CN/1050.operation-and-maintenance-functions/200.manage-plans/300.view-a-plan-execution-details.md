# 查看预案执行详情

您可参考本节内容查看预案执行的详情信息。

<main id="notice" type='notice'>
<h4>功能适用性</h4>
<p>该内容仅适用于 OCP 企业版，OCP 社区版不支持此功能。</p>
</main>

## 查看预案执行任务

当预案处于 **<UI-TERM key="ocp-v2.src.util.task.Running">执行中</UI-TERM>** 、**<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.ExecutionFailed">执行失败</UI-TERM>** 或 **<UI-TERM key="ocp-v2.src.constant.task.Completed">已完成</UI-TERM>** 状态时，您可查看预案任务的详细执行信息。

### 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **集群只读** 或 **租户只读** 资源权限。
* 运维管理 **<UI-TERM key="ocp-v2.src.hook.useMenu.PlanManagement">预案管理</UI-TERM>** 菜单权限。

### 操作步骤

1. 登录 OCP 平台。

2. 在左侧导航栏选择 **运维管理 > 预案管理**，系统默认进入 **<UI-TERM key="ocp-v2.page.Plan.PlanExecutionList">预案执行列表</UI-TERM>** 页签。

3. 选择需要操作的预案，单击操作列的 **<UI-TERM key="ocp-v2.page.Welcome.ViewTasks">查看任务</UI-TERM>**。

4. 页面将跳转至预案事件对应的告警详情页面，您可在该页面查看预案的执行信息，详情可参考 [告警预案处理](../../1900.reference-guide/100.alarm-reference/500.appendix/400.execute-the-plan.md)。

## 查看 SQL 信息

针对 SQL 类型的预案，当预案处于 **<UI-TERM key="ocp-v2.src.constant.plan.PendingExecution">待执行</UI-TERM>**、**<UI-TERM key="ocp-v2.Plan.Component.PlanExecuteTable.Running">执行中</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.ExecutionFailed">执行失败</UI-TERM>** 或 **<UI-TERM key="ocp-v2.src.constant.backup.Completed">已完成</UI-TERM>** 状态时，您可查看对应事件的 SQL 信息。

### 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **集群只读** 资源权限。
* 运维管理 **<UI-TERM key="ocp-v2.page.Plan.PlanManagement">预案管理</UI-TERM>** 菜单权限。
* 自治服务 **<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">实时诊断</UI-TERM>** 菜单权限。

### 操作步骤

1. 登录 OCP 平台。

2. 在左侧导航栏选择 **运维管理 > 预案管理**，系统默认进入 **<UI-TERM key="ocp-v2.page.Plan.PlanExecutionList">预案执行列表</UI-TERM>** 页签。

3. 选择需要操作的预案，单击操作列的 **<UI-TERM key="ocp-v2.Plan.Component.PlanExecuteTable.ViewSql">查看 SQL</UI-TERM>**。

4. 页面将跳转至 SQL 详情页面，详情可参考 [查看 SQL 详情](../../1000.diagnosis-and-tuning-fuctions/100.manage-sql-diagnosis/1000.view-sql-details.md)。
