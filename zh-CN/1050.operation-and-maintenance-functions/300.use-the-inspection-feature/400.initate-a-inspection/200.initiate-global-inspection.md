# 发起全局巡检

本页面为您介绍发起全局巡检的操作步骤。若您要对单个对象发起巡检，可参考 [发起单个对象巡检](../400.initate-a-inspection/100.initate-single-inspection.md)。

<main id="notice" type='notice'>
<h4>功能适用性</h4>
<p>该内容仅适用于 OCP 企业版，OCP 社区版不提供此功能。</p>
</main>

## 背景信息

进行发起巡检操作后，OCP 将会立即按照巡检项中的配置对 OCP 内管理的 OceanBase 集群、OceanBase 租户和 OBProxy 集群进行检查，更多内容参见 [巡检功能](../100.inspection-management.md)。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **集群维护** 或 **租户维护** 资源权限。
* 运维管理 **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">巡检服务</UI-TERM>** 菜单权限。

## 操作步骤

1. 登录 OCP 平台。

2. 在左侧导航栏选择 **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">运维管理</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">巡检服务</UI-TERM>** 。

3. 默认进入 **<UI-TERM key="ocp-v2.Inspection.Item.ConfigRule.InspectionList">巡检列表</UI-TERM>** 页面。

4. 将光标悬停于页面右上角的 **<UI-TERM key="ocp-v2.page.Inspection.InitiateAGlobalInspection">发起全局巡检</UI-TERM>** 上，在下拉列表中选择所需要的巡检场景。

5. 单击弹出框中的 **<UI-TERM key="ocp-v2.Detail.ResourceManager.CreateResourcePlan.Ok">确定</UI-TERM>** 。

   <main id="notice" type='explain'>
    <h4>说明</h4>
    <ul>
    <li>若有集群正在进行所选场景的巡检，则会跳过该集群。</li>
    <li>若有主机正在进行所选场景的巡检，则会跳过该主机。</li>
    </ul>
   </main>

6. 单击弹出框中的任务 ID 或在 **<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">任务中心</UI-TERM>** 中查看任务进展，详情参见 [任务管理](../../../1600.system-management-features/600.manage-tasks.md)。
