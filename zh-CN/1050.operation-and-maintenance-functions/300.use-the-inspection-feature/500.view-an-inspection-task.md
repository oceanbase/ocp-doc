# 查看巡检任务

本页面为您介绍巡检任务页面的详细内容，您可在巡检任务页面查看任务的基本信息，并可进行查看报告和下载报告操作。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **集群只读** 或 **租户只读** 资源权限。
* 运维管理 **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">巡检服务</UI-TERM>** 菜单权限。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏选择 **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">运维管理</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">巡检服务</UI-TERM>** 。

3. 单击 **<UI-TERM key="ocp-v2.page.Inspection.InspectionHistory">巡检历史</UI-TERM>** 页签。

4. 在巡检任务列表中，单击巡检任务 ID，进入任务详情页。您可查看 **<UI-TERM key="ocp-v2.Inspection.Task.TaskStatus">任务状态</UI-TERM>**、**<UI-TERM key="ocp-v2.Task.Detail.CurrentProgress">当前进度</UI-TERM>**、**<UI-TERM key="ocp-v2.TraceDetail.TraceContent.StartTime">开始执行时间</UI-TERM>**、**<UI-TERM key="ocp-v2.Task.Detail.AccumulatedTaskTime">任务累计耗时</UI-TERM>** 和 **<UI-TERM key="ocp-v2.Task.Detail.TaskInitiator">任务发起人</UI-TERM>** 等信息。

5. 单击 **<UI-TERM key="ocp-v2.Task.Detail.LogView">日志视图</UI-TERM>** 或 **<UI-TERM key="ocp-v2.Task.Detail.FlowView">流转视图</UI-TERM>** ，可进行视图切换。

6. 单击 **<UI-TERM key="ocp-v2.Task.Detail.LocateTheCurrentProgress">定位当前进度</UI-TERM>** ，查看任务执行进度。

7. 单击 **<UI-TERM key="ocp-v2.Detail.Log.LogCard.DownloadLogs">下载日志</UI-TERM>** ，将日志信息下载至本地进行查看。
