# 查看巡检报告

本页面为您介绍查看巡检报告的详细内容，您可通过如下两个入口查看巡检报告：

* **入口一**：在 **<UI-TERM key="ocp-v2.page.Inspection.InspectionList">巡检列表</UI-TERM>** 页面的巡检进度中单击 **<UI-TERM key="ocp-v2.src.constant.inspection.ViewReports">查看报告</UI-TERM>**。
* **入口二**：在 **<UI-TERM key="ocp-v2.page.Inspection.InspectionHistory">巡检历史</UI-TERM>** 页面进行查看。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **集群只读** 或 **租户只读** 资源权限。
* 运维管理 **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">巡检服务</UI-TERM>** 菜单权限。

## 操作步骤

以下操作步骤以 **入口二** 为例。

1. 登录 OCP。

2. 在左侧导航栏选择 **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">运维管理</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">巡检服务</UI-TERM>** 。

3. 单击 **<UI-TERM key="ocp-v2.page.Inspection.InspectionHistory">巡检历史</UI-TERM>** 页签。

4. 在巡检历史列表中，选择需要查看的任务，单击操作列的 **<UI-TERM key="ocp-v2.src.util.component.More">更多</UI-TERM>** > **<UI-TERM key="ocp-v2.Inspection.Item.ViewReports">查看报告</UI-TERM>** 。

5. 进入 **<UI-TERM key="ocp-v2.page.Report.InspectionReport">巡检报告</UI-TERM>** 页面，查看巡检详情。包括 **<UI-TERM key="ocp-v2.Component.AddOBServerDrawer.BasicInformation">基本信息</UI-TERM>** 、**<UI-TERM key="ocp-v2.Report.Inspection.ReportContent.OverviewOfInspectionResults">巡检结果概览</UI-TERM>** 及风险详情。

   您可通过 **<UI-TERM key="ocp-v2.Report.Inspection.ReportContent.SummaryByRisk">按风险汇总</UI-TERM>** 和 **<UI-TERM key="ocp-v2.Report.Inspection.ReportContent.SummaryByInspectionItems">按巡检项汇总</UI-TERM>** 两种方式查看详细风险信息。其中，**<UI-TERM key="ocp-v2.Report.Inspection.ReportContent.SummaryByRisk">按风险汇总</UI-TERM>** 支持通过风险等级对巡检结果进行筛选。

## 相关操作

OCP 支持通过系统参数来定期清理历史巡检报告：

1. `ocp.inspection.report.expired.cleanup.enabled` 为巡检报告过期清理开关，默认为 `false`。设置为 `true` 后 OCP 会自动清理 `ocp.inspection.report.expired.days` 参数中指定的天数之前的所有巡检报告。

2. `ocp.inspection.report.expired.days` 用来设置巡检报告的过期天数，默认为 15 天。当自动清理的功能打开后，OCP 会在每天 0 点整开始清理该参数指定的天数之前所有巡检报告（不包含主机标准化的检查报告）。
