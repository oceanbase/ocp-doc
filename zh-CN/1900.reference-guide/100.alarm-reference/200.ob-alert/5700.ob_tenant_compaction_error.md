# ob_tenant_compaction_error OceanBase 租户合并出错

## 告警描述

OceanBase V4.0 及之后的版本支持按租户进行合并，租户合并出错时触发该告警。

## 告警原理

| 参数     | 值 |
| -------- | ------- |
| 监控指标 | compaction_is_error，该指标表示 OceanBase 租户是否合并出错，指标值为 `0` 时表示租户合并正常；指标值为 `1` 时表示租户合并出错，并触发告警。 |
| 监控表达式 | ```max(ob_compaction_is_error{@LABELS}) by (@GBLABELS)``` |
| 采集指标 | ob_compaction_is_error |
| 指标来源 | 采集自内部视图，采集 SQL：```select tenant_id, frozen_scn as frozen_version, LAST_SCN as last_version, case is_error when 'YES' then 1 else 0 end as is_error, case is_suspended when 'YES' then 1 else 0 end as is_suspended, time_to_usec(start_time) as start_time, time_to_usec(frozen_time) as frozen_time, time_to_usec(now()) as current from CDB_OB_MAJOR_COMPACTION```  |
| 采集周期 | 5 秒   |

## 规则信息

| 监控表达式 | 默认阈值 | 持续时间  | 检测周期 | 消除周期 |
| -------- | -------- | -------- | ------- | ------- |
| compaction_is_error  | 1 | 0 秒 | 20 秒 | 5 分钟 |

## 告警信息

| 告警触发方式 | 告警等级 | 范围     |
| ---------- | --------- | ---------- |
| 基于监控指标的表达式 | 严重 | 租户 |

## 告警模板

* **告警概述**

  * 模板：\${alarm_target} \${alarm_name}
  * 样例：alarm_template_id=0:ob_cluster=C1-1000:tenant_name=T1 OceanBase 租户合并出错

* **告警详情**

  * 模板：集群：\${ob_cluster_name}，租户：\${tenant_name}，告警：\${alarm_name}。
  * 样例：集群：obcluster，租户：T1，告警：OceanBase 租户合并出错。

* **告警恢复**

  * 模板：告警：${alarm_name}，OceanBase 租户合并错误标志：\${recover_value}
  * 样例：告警：OceanBase 租户合并出错，OceanBase 租户合并错误标志：0

## 对系统的影响

会导致 OceanBase 集群部分副本数据不一致，如副本之间不一致或主表与索引表之间不一致。

## 可能原因

理论上存在的极端场景，无常见原因。
