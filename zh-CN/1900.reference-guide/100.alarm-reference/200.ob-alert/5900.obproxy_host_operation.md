# obproxy_host_operation OBProxy 主机运维操作提醒

## 告警描述

对 OBProxy Server 执行运维任务后会发出一条 **<UI-TERM key="ocp-v2.src.constant.alarm.Reminder">提醒</UI-TERM>** 级别的告警，告警等级可以修改为其他等级。

运维任务列表：

* 添加 OBProxy Server
* 接管 OBProxy Server
* 重启 OBProxy Server
* 升级 OBProxy Server
* 刷新配置
* 删除 OBProxy Server

## 告警原理

无。

## 规则信息

| 监控指标 | 默认阈值 | 持续时间 | 检测周期 | 消除周期 |
| -------- | -------- | -------- | -------- | -------- |
| NA       | NA       | 0 秒     | NA       | 5 分钟   |

## 告警信息

| 告警触发方式 | 告警等级 | 范围    |
| ------------ | -------- | ------- |
| 运维事件触发 | 提醒     | 主机 |

## 告警模板

* 告警概述

  * 模板：\${alarm_target} \${alarm_name}
  * 样例：alarm_template_id=0:obproxy_cluster=obproxy1-1:host=xxx.xxx.xxx.xxx:operation_name=Restart obproxy SUCCESS

* 告警详情

  * 模板：OBProxy 集群：\${obproxy_cluster}，服务器：\${host}，告警：\${operation_name} \${operation_result}，操作者 \${operator}，运行结果：\${task_result}。
  * 样例：OBProxy 集群：obproxy1，服务器：xxx.xxx.xxx.xxx，告警：Restart obproxy SUCCESS，操作者 admin，运行结果：success。

## 对系统的影响

系统故障常见于日常运维，需要关注运维之后系统是否出现异常，并根据具体情况具体分析。

## 可能原因

无常见原因。

## 处理方法

1. 如果运维后出现异常问题，可联系技术支持人员协助解决。
2. 如果对业务造成重大影响，请及时回滚运维操作。
