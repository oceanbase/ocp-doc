# ob_tenant_tde_kms_host_not_match 租户 TDE KMS 服务地址和当前 OCP 服务地址不匹配

## 告警描述

该告警检测租户的 TDE KMS 服务地址和当前 OCP 服务地址是否匹配。其中：

* 租户 TDE KMS 服务地址：从 `GV$OB_PARAMETERS` 视图中对应租户 `external_kms_info` 参数中的 `kms_host` 字段值获取。
* 当前 OCP 服务地址：系统参数中的 `ocp.site.url` 值。

## 告警原理

| 参数       | 值     |
| ---------- | ------------ |
| 监控指标   | ob_tenant_tde_kms_host_match_status，该指标表示 OceanBase 租户 KMS 地址与当前 OCP 地址的匹配状态，参数值为 `0` 时表示服务地址匹配；参数值为 `1` 时表示服务地址不匹配，并触发告警。 |
| 监控表达式 | ```max(ob_tenant_tde_kms_host_match_status{@LABELS}) by (@GBLABELS)``` |
| 采集指标   | ob_tenant_tde_kms_host_match_status |
| 数据来源   | 由 OCP-Server 定时查询 `kms_host` 和 `ocp.site.url` 是否匹配，如果不匹配则发出告警。 |
| 采集周期   | 5 秒 |

## 规则信息

| 监控表达   | 默认阈值  | 持续时间 | 检测周期 | 消除周期 |
| ---------- | ----------- | -------- | -------- | -------- |
|  ob_tenant_tde_kms_host_match_status    |  1    |  120 秒    |   60 秒   |  5 分钟  |

## 告警信息

| 告警触发方式 | 告警等级 | 范围   |
| ------------ | -------- | ------ |
| 基于监控指标的表达式 | 严重     | 租户 |

## 告警模板

* **告警概述**

  * 模板：${alarm_target} ${alarm_name}
  * 样例：alarm_template_id=0:ob_cluster=xxx:tenant_name=xxx 租户 TDE KMS 服务地址和当前 OCP 服务地址不匹配

* **告警详情**

  * 模板：OceanBase 集群 ${ob_cluster_name} 中租户 ${tenant_name} 的 KMS 地址与 OCP 地址不一致。
  * 样例：OceanBase 集群 Test 中租户 xxx 的 KMS 地址与 OCP 地址不一致。

* **告警恢复**

  * 模板：告警：${alarm_name}，租户 TDE KMS 服务地址是否和当前 OCP 服务地址匹配：\${value}
  * 样例：告警：租户 TDE KMS 服务地址和当前 OCP 服务地址不匹配，租户 TDE KMS 服务地址和当前 OCP 服务地址不匹配：0

## 对系统的影响

添加 OBServer、新建备租户及新建加密表空间等功能将不可用。

## 可能原因

* OCP 当前服务地址发生变化，系统参数 `ocp.site.url` 的值与租户 TDE 加密前的 `GV$OB_PARAMETERS` 视图的 `external_kms_info` 参数中 `kms_host` 值不一致。
* 黑屏修改了租户的 `external_kms_info` 信息，导致 `ocp.site.url` 的值与 `kms_host` 值不一致。
* 迁出并接管集群后未及时完成相关租户 TDE 加密配置。

## 处理方法

* 方式一：进入告警对应集群概览模块，根据页面提示信息单击 **修改加密**，进入 **安全配置** > **TDE 透明加密** 修改对应租户的 TDE 加密信息。
* 方式二：在租户所属集群中，进入 **安全配置** > **TDE 透明加密**，修改对应租户的 TDE 加密信息。
