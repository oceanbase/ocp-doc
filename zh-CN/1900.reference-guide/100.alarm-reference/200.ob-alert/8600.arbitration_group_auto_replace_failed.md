# arbitration_group_auto_replace_failed 仲裁服务组自动切换仲裁服务失败

## 告警描述

<main id="notice" type='explain'>
<h4>说明</h4>
此告警仅针对 V4.2.0.0 及以上版本的 OceanBase 集群生效。
</main>

当仲裁服务关联的 OceanBase 集群与仲裁服务失连，且触发仲裁服务组自动切换策略时，OceanBase 集群会自动切换到组内其他仲裁服务。当 OceanBase 集群自动切换仲裁服务任务失败时会触发此告警，提示用户切换失败并提供相关任务 ID。

## 告警原理

| 参数 | 值 |
| ---------- | ------------ |
| 监控指标   | arbitration_group_auto_replace_task_status |
| 数据来源   | 由 OCP-Server 定时查询有无仲裁服务自动切换失败任务，如果存在，则从任务中解析仲裁服务组信息，发出告警。 |
| 采集指标   | arbitration_group_auto_replace_task_status |
| 监控表达式 | sum(arbitration_group_auto_replace_task_status{@LABELS}) by (@GBLABELS) |
| 采集周期   | 60 秒 |

监控指标 `arbitration_group_auto_replace_task_status` 的值只有 0 或者 1，1 表示该仲裁服务组不存在切换失败的任务，0 表示仲裁服务组存在切换失败的任务。

## 规则信息

| 监控表达式 | 默认阈值 | 持续时间 | 检测周期 | 消除周期 |
| ---------- | -------- | ------------ | -------- | -------- |
|  arbitration_group_auto_replace_task_status  | 0 |  120 秒    |   60 秒   |  5 分钟  |

## 告警信息

| 告警触发方式 | 告警等级 | 范围   |
| ----------- | -------- | ------ |
| 基于监控指标的表达式 | 严重     | OceanBase 集群 |

## 告警模板

* 告警概述

  * 模板：\${group_name} \${alarm_name}
  * 样例：arbitration_group_A 仲裁服务组自动切换仲裁服务失败

* 告警详情

  * 模板：仲裁服务组 \${group_name} 自动切换仲裁服务失败。Task ID: \${task_id}
  * 样例：仲裁服务组 arbitration_group_A 自动切换仲裁服务失败。Task ID: 12521

## 对系统的影响

OceanBase 集群自动切换仲裁服务任务失败，可能导致集群长时间没有仲裁服务，影响 2F/4F 租户的高可用能力。在出现租户副本故障时，直接影响系统服务。

## 可能原因

1. 切换任务执行过程中，目标仲裁服务服务器宕机。
2. 切换任务执行过程中，目标仲裁服务进程停止运行。
3. OCP 与 OceanBase 集群无法连接。

## 处理方法

1. 检查目标仲裁服务服务器是否处于运行状态。
2. 检查目标服务器进程是否存在，是否对外提供服务。
3. 检查 OCP 是否可以连通 OceanBase 集群，OceanBase 集群是否存活。
