# arbitration_auto_replace_operation_info OceanBase 集群自动切换仲裁服务任务提醒

## 告警描述

<main id="notice" type='explain'>
<h4>说明</h4>
此告警仅针对 V4.2.0.0 及以上版本的 OceanBase 集群生效。
</main>

当仲裁服务关联的 OceanBase 集群与仲裁服务失连，且触发仲裁服务组自动切换策略时，OceanBase 集群会自动切换到组内其他仲裁服务。此时 OCP 会发送该告警，提醒用户 OceanBase 集群正在自动切换仲裁服务。

## 告警原理

该告警不依赖监控信息，OCP 发起 OceanBase 自动切换仲裁服务任务时，主动发送该告警。

## 规则信息

| 监控表达   | 默认阈值（单位：秒） | 持续时间 | 检测周期 | 消除周期 |
| ---------- | ----------- | -------- | -------- | -------- |
|  无        |  无         |  0 秒    |   0 秒   |  5 分钟  |

## 告警信息

| 告警触发方式 | 告警等级 | 范围   |
| ------------ | -------- | ------ |
| OCP 主动发起 | 提示     | OceanBase 集群 |

## 告警模板

* 告警概述

  * 模板：\${alarm_name}
  * 样例：OceanBase 集群自动切换仲裁服务任务提醒

* 告警详情

  * 模板：OceanBase 集群 \${ob_cluster_names} 由于触发仲裁服务自动切换策略，发起切换仲裁服务任务。
  * 样例：OceanBase 集群 clusterA,clusterB 由于触发仲裁服务自动切换策略，发起切换仲裁服务任务。

## 对系统的影响

OceanBase 集群自动切换仲裁服务，表明 OceanBase 集群与原仲裁服务存在断连，并触发了仲裁服务组的切换策略。如果不及时切换，集群中的 2F/4F 租户无法实现高可用，可能对系统产生灾难性影响。

## 可能原因

1. OceanBase 集群与原仲裁服务的服务端口因网络原因不通。
2. 原仲裁服务所在的服务器宕机。
3. 原仲裁服务进程停止运行。

## 处理方法

1. 检查原仲裁服务进程是否存在，端口是否可以对外服务。
2. 检查 OceanBase 集群与原仲裁服务之间的网络是否通。
