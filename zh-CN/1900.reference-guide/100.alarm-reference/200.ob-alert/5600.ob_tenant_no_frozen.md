# ob_tenant_no_frozen OceanBase 租户长时间未冻结

## 告警描述

OceanBase V4.0 及之后的版本支持按租户进行冻结，租户长时间未冻结触发该告警。

## 告警原理

| 参数 | 值 |
| --------- | -------- |
| 监控指标 | no_frozen_seconds，该指标表示 OceanBase 租户距离上一次冻结的时间，当时间大于阈值时触发告警。 |
| 监控表达式 | ```(max(ob_compaction_current_timestamp{@LABELS}) by (@GBLABELS) - max(ob_compaction_frozen_time{@LABELS}) by (@GBLABELS)) / 1000000```   |
| 采集指标 | ob_compaction_current_timestamp、ob_compaction_frozen_time  |
| 指标来源 | 采集自内部视图，采集 SQL：```select tenant_id, frozen_scn as frozen_version, LAST_SCN as last_version, case is_error when 'YES' then 1 else 0 end as is_error, case is_suspended when 'YES' then 1 else 0 end as is_suspended, time_to_usec(start_time) as start_time, time_to_usec(frozen_time) as frozen_time, time_to_usec(now()) as current from CDB_OB_MAJOR_COMPACTION```  |
| 采集周期 | 5 秒 |

## 规则信息

| 监控表达式 | 默认阈值（单位：秒） | 持续周期  | 检测周期 | 消除周期 |
| ---------- | ------- | ---------- | -------- | ---------- |
| no_frozen_seconds | 90000  | 0 秒  | 20 秒 | 5 分钟 |

## 告警信息

| 告警触发方式 | 告警等级 | 范围 |
| ----------- | -------- | --------- |
| 基于监控指标的表达式 | 严重 | 租户 |

## 告警模板

* **告警概述**

  * 模板：\${alarm_target} \${alarm_name}
  * 样例：alarm_template_id=0:ob_cluster=C1-1000:tenant_name=T1 OceanBase 租户长时间未冻结

* **告警详情**

  * 模板：集群：\${ob_cluster_name}，租户：\${tenant_name}，告警：\${alarm_name}。距上一次冻结时间为 ${value_shown} 超过 ${alarm_threshold} 秒。
  * 样例：集群：obcluster，租户：T1，告警：OceanBase 租户长时间未冻结。距上一次冻结时间为 130000 秒超过 90000 秒。

* **告警恢复**

  * 模板：告警：${alarm_name}，OceanBase 租户距离上一次冻结的间隔：\${recover_value}
  * 样例：告警：OceanBase 租户长时间未冻结，OceanBase 租户距离上一次冻结的间隔：8600 秒

## 对系统的影响

长时间不发起冻结或合并会导致磁盘空间增大，磁盘爆满，影响业务写入。

## 可能原因

* 每日合并被关闭或升级模式参数开启。
* Root Service 服务异常暂停，比如无主节点，或者进程异常暂停。
