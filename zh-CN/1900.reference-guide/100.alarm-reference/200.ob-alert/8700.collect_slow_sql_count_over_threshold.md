# collect_slow_sql_count_over_threshold 监控采集慢 SQL 个数超限

## 告警描述

监控数据采集慢 SQL 的个数超过阈值，则触发该告警。

## 告警原理

| 参数   | 值    |
|--------|---------|
| 监控指标  | collect_slow_sql_count  |
| 指标来源  | agent 采集监控指标时埋点统计  |
| 采集指标  | collect_slow_sql_count  |
| 监控表达式  | max(slow_sql_count{@LABELS}) by (@GBLABELS)  |
| 采集周期  | 1 分钟  |

## 规则信息

| 监控表达式 | 默认阈值 | 持续时间 | 检测周期 | 消除周期 |
|------------|---------|-----------|---------|---------|
| collect_slow_sql_count | 10 | 0 秒 | 60 秒 | 5 分钟 |

## 告警信息

| 告警触发方式 | 告警等级 | 范围 |
|--------------|---------|-----------|
| 基于监控指标的表达式 | 警告 | OBServer |

## 告警模板

* **告警概述**

  * 模板：${alarm_target} ${alarm_name}
  * 样例：alarm_template_id=0:ob_cluster=cluster01-5:host=xxx.xxx.xxx.xxx:slow_sql_name=ob_query_rt_redis_total 采集慢 SQL 个数超限

* **告警详情**

  * 模板：集群：${ob_cluster_name}，主机：${host}，告警：${alarm_name}。采集慢 SQL {slow_sql_name} 个数 ${value_shown} 超过 ${alarm_threshold}
  * 样例：集群：cluster01，主机：xxx.xxx.xxx.xxx，告警：采集慢 SQL 个数超限。采集慢 SQL ob_query_rt_redis_total 个数 322 超过 10

* **告警恢复**

  * 模板：告警：${alarm_name}, 采集慢 SQL 个数：${value_down}
  * 样例：告警：采集慢 SQL 个数超限，采集慢 SQL 个数：3

## 对系统的影响

* 可能导致部分监控图表无数据。
* 超时导致监控数据缺失，进一步影响依赖监控数据的告警项无法告警。

## 可能原因

* SQL 查询出的数据量较大，导致执行时长超过慢 SQL 阈值。
* 系统负载较高，导致产生慢 SQL。

## 处理办法

查看 OCP 监控页面，确认是否存在监控数据缺失的情况出现。若有，可联系运维人员排查；若无，可手动屏蔽该告警或联系运维人员调整该 SQL 的慢 SQL 阈值。
