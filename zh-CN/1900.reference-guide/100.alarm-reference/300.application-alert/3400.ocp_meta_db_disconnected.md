# ocp_meta_db_disconnected OCP 元数据库断开连接

## 告警描述

OCP monitor DB 持续三分钟都无法连接时，会发生断连检测告警。

## 告警原理

| 参数 | 值 |
|------|------|
| 监控指标 | ocp_meta_db_health，该指标表示 OCP 元数据库是否可以正常连接，指标值为 `1` 时可连接；指标值为 `0` 时连接失败，并触发告警。 |
| 监控表达式 | ```ocp_meta_db_health{@LABELS}``` |
| 采集指标 | ocp_meta_db_health   |
| 指标来源 | OCP Server 埋点数据。 |
| 采集周期 | 5 秒|

## 规则信息

| 监控指标 | 默认阈值 | 持续时间 | 检测周期 | 消除周期 |
|----------|---------|----------|----------|----------|
| ocp_meta_db_health | 0 | 60 秒 | 15 秒 | 5 分钟 |

## 告警信息

| 告警触发方式 | 告警等级 | 范围 |
| ------------ | -------- | ------ |
| 基于监控指标的表达式 | 停服 | 服务 |

## 告警模板

* **告警概述**

  * 模板：${alarm_target} ${alarm_name}
  * 样例：alarm_template_id=0:svr_ip=xxx.xxx.xxx.xxx:db=monitor OCP 元数据库断开连接。

* **告警详情**

  * 模板：[${alarm_name}] OCP ${db} 数据库出现断连。
  * 样例：[OCP 元数据库断开连接] OCP monitor 数据库出现断连。

* **告警恢复**

  * 模板：告警：${alarm_name}，OCP meta DB 健康状态：\${recover_value}
  * 样例：告警：OCP 元数据库断开连接，OCP meta DB 健康状态：1

## 对系统的影响

若是持续断连会使 OCP 功能异常，导致 OCP 不工作；OCP monitor DB 丢失监控数据。

## 可能原因

* 网络不稳定。
* monitor DB 服务异常。

## 处理方法

1. 可尝试手动连接查看断连复现情况。

2. 若频繁断连，请检查 monitor DB 状态或网络环境。

3. 可尝试重启 monitor DB，仍无法解决则需查看日志并联系管理员进行排查。
