# ssl_certificate_is_expired SSL 证书过期告警

## 告警描述

<main id="notice" type='explain'>
<h4>说明</h4>
此告警仅针对 V4.0.0.0 及以上版本的 OceanBase 集群生效。
</main>

当用户在 **证书管理** 中上传的 SSL 证书过期时，发出此告警提醒用户更新证书。

## 告警原理

下表列出了该告警监控逻辑中涉及的关键参数。

| 参数     | 值     |
| -------- | ---------- |
| 监控指标 | ssl_certificate_expired_status，该指标表示 SSL 证书是否过期，指标值为 `0` 时表示该证书文件未过期；指标值为 `1` 时表示证书文件过期，并触发告警。   |
| 监控表达式 | ```max(ssl_certificate_expired_status{@LABELS}) by (@GBLABELS)``` |
| 采集指标 | ssl_certificate_expired_status |
| 数据来源 | 由 OCP-Server 定时查询有无过期证书存在。 |
| 采集周期 | 5 秒 |

## 规则信息

| 监控指标 | 默认阈值 | 持续时间 | 检测周期 | 消除周期 |
| -------- | -------- | -------- | ------- | -------- |
| ssl_certificate_expired_status | 0 | 0 秒 | 60 秒 | 5 分钟 |

## 告警信息

| 告警触发方式  | 告警等级    | 范围      |
| ------------- | ---------- | --------- |
| 基于监控指标的表达式 | 停服 | 服务      |

## 告警模板

* **告警概述**

  * 模板：\${alarm_target} \${alarm_name}
  * 样例：alarm_template_id=0:certificate_group=real_chain:certificate_file=ca_chain.pem:expired_time=1970-01-01T08:02:01+08:00 SSL 证书过期告警

* **告警详情**

  * 模板：SSL 证书组 \${certificate_group} 中的证书文件 \${certificate_file} 已过期，过期时间 \${expired_time}，请及时更新证书避免无法建立网络连接导致业务停服。
  * 样例：SSL 证书组 real_chain 中的证书文件 ca_chain.pem 已过期，过期时间 1970-01-01T08:02:01+08:00，请及时更新证书避免无法建立网络连接导致业务停服。

* **告警恢复**

  * 模板：告警：${alarm_name}，SSL 证书过期状态：\${recover_value}
  * 样例：告警：SSL 证书过期告警，SSL 证书过期状态：0

## 对系统的影响

SSL 证书过期，可能导致正在使用该 SSL 证书的 OceanBase 集群、ObProxy 集群无法建立 SQL 和 RPC 连接，进而导致服务停服。

## 可能原因

SSL 证书过期。

## 处理方法

1. 重新签发 CA 证书获取服务器证书。
2. 在 OCP 中 [上传证书](../../../1600.system-management-features/150.manage-certificates/200.upload-certificates.md)。
3. 参考 OceanBase 集群 [管理 SSL 链路加密](../../../600.cluster-functions/1200.manage-security-configuration/100.manage-ssl-link-encryption-of-an-ob-cluster.md) 和 OBProxy 集群 [管理 SSL 链路加密](../../../800.obproxy-functions/550.manage-ssl-link-encryption-of-an-obproxy-cluster.md)，对使用过期证书的 OceanBase 集群、OBProxy 集群进行证书更新。
