# message_hardware_error 主机硬件故障

## 告警描述

主机内存硬件发生故障出现日志 “Hardware Error” 时，会触发该告警。

## 告警原理

匹配主机上 `/var/log/messages` 文件中的关键字 “Hardware Error”，如果匹配到，则触发告警。

## 规则信息

| 监控指标 | 默认阈值 | 持续时间 | 检测周期 | 消除周期 |
| -------- | ------- | -------- | -------- | -------- |
| NA       | NA      | 0 秒     | 相同告警每 3 分钟触发一次 | 5 分钟 |

## 告警信息

| 告警触发方式 | 告警等级  | 范围    |
| ------------ | -------- | -------- |
| 日志解析     | 严重     | 服务器   |

## 告警模板

* 告警模板详情：[\${alarm_name}] 集群：\${ob_cluster_name}，主机：\${host}，日志类型：\${server_type}，日志文件：\${filename}，日志级别：\${log_level}，关键字=\${keyword}，错误码=\${error_code}，日志详情=\${error_message}。
* 告警详情样例：[系统 message 日志] 集群：danxue_422，主机：xx.xx.xx.xx，日志类型：kern，日志文件：/var/log/messages，日志级别：ERROR，关键字=Hardware Error，错误码=-1，日志详情=Mar 21 18:07:34 sqaappecsv62s2011162217016.sa128 su[267465]: [Hardware Error] pam_unix(su:session): session closed for user root。

其中：

* ${alarm_name}：表示告警名称，如：OceanBase 日志告警。
* ${ob_cluster_name}：表示产生告警的集群名称。
* ${host}：表示产生告警服务器的 IP 或主机名。
* ${server_type}：表示日志的类型。
* ${filename}：日志文件。
* ${log_level}：日志级别。
* ${keyword}：关键字。
* ${error_code}：错误码。
* ${error_message}：日志详情。

## 对系统的影响

当进程使用到该故障内存时，会发生 core。

## 可能原因

主机内存存在可恢复错误。

## 处理方法

建议尽快更换内存。
