# ocp_http_request_timeout OCP HTTP 接口请求超时

## 告警描述

OCP HTTP 接口请求延时过长，平均请求耗时超过五秒发生告警。

## 告警原理

| 参数 | 值 |
|------|------|
| 监控指标 | ocp_http_request_duration_seconds，该指标表示 OCP HTTP 接口请求的超时时间，当参数值大于或等于阈值时触发告警。 |
| 指标来源 | OCP Server 埋点数据。 |
| 采集指标 | http_server_requests_seconds_sum、http_server_requests_seconds_count  |
| 监控表达式 | ```sum(rate(http_server_requests_seconds_sum{status="200",uri!~"/api/v2/software-package.*\|/api/v2/object-storage.*\|/api/v2/overview/status.*\|root",@LABELS}[60s])) by (@GBLABELS) / sum(rate(http_server_requests_seconds_count{status="200",uri!~"/api/v2/software-package.*\|/api/v2/object-storage.*\|/api/v2/overview/status.*\|root",@LABELS}[60s])) by (@GBLABELS)```    |
| 采集周期 | 5 秒 |

## 规则信息

| 监控指标 | 默认阈值（单位：秒） | 持续时间 | 检测周期 | 消除周期 |
|----------|---------------------|----------|----------|---------|
| ocp_http_request_duration_seconds | 5 | 120 秒 | 15 秒 | 5 分钟 |

## 告警信息

| 告警触发方式 | 告警等级 | 范围 |
|--------------|---------|-------|
| 基于监控指标的表达式 | 警告  | 服务 |

## 告警模板

* **告警概述**

  * 模板：\${alarm_target} \${alarm_name}
  * 样例：alarm_template_id=0:uri=/api/v2/time:method=GET OCP HTTP 接口请求超时。

* **告警详情**

  * 模板：[\${alarm_name}] OCP HTTP 接口的 uri 为 ${uri}，方法为：${method}，请求耗时 ${value_shown} 过长。
  * 样例：[OCP HTTP 接口请求超时] OCP HTTP 接口的 uri 为 /api/v2/time，方法为：GET，请求耗时 11 秒过长。

* **告警恢复**

  * 模板：告警：${alarm_name}，OCP HTTP 请求耗时：\${value_shown}
  * 样例：告警：OCP HTTP 接口请求超时，OCP HTTP 请求耗时：3 秒

## 对系统的影响

OCP 接口请求较慢，会影响用户体验，严重时将影响系统功能。

## 可能原因

* 网络不稳定。
* 系统状态异常（内存不足、CPU 打满）。
* 业务代码不高效。

## 处理方法

1. 若是预期内的网络波动或网络延迟所导致的，可调大检查阈值。

2. 若频繁报延时过大。

   1. 检查 CPU 服务器状态，如 CPU、内存的情况是否正常，可根据实际情况及时调整。

   2. 若服务器状态一切正常但请求耗时还是较久，可联系管理员检查日志，排查是否为接口出现性能问题。
