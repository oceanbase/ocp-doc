# ob_license_expired OB 许可证过期时间

## 告警描述

<main id="notice" type='explain'>
<h4>说明</h4>
此告警仅针对单机生效。
</main>

检测当前 OCP 管理的 OceanBase 单机中存在 License 许可证过期的情况。

## 告警原理

| 参数       | 值   |
|------------|-------|
| 监控指标   | ob_license_expired_second_duration，该指标表示 OceanBa 许可证的过期时间，不同指标值将触发不同等级的告警。  |
| 监控表达式 | ```min(ob_license_expired_second_duration{@LABELS}) by (@GBLABELS)```  |
| 采集指标   | ob_license_expired_second_duration   |
| 指标来源   | 检测到单机许可证的过期时间离当前时间的间隔是否符合告警要求。   |
| 采集周期   | 5 秒   |

## 规则信息

| 监控表达式 | 默认阈值 | 持续时间 | 检测周期 | 消除周期 |
|------------|---------|----------|----------|----------|
| ob_license_expired_second_duration | 该指标存在三个默认阈值：<li>ob_license_expired_second_duration == 0</li><li>ob_license_expired_second_duration > 0 and ob_license_expired_second_duration < 2592000</li><li>ob_license_expired_second_duration >= 2592000 and ob_license_expired_second_duration < 5184000</li> | 0 秒 | 60 秒 | 7200 秒 |

## 告警信息

| 告警触发方式 | 告警等级 | 范围 |
|--------------|---------|----------|
| 基于监控指标的表达式 | <li>ob_license_expired_second_duration == 0：停服</li><li>ob_license_expired_second_duration > 0 and ob_license_expired_second_duration < 2592000：严重</li><li>ob_license_expired_second_duration >= 2592000 and ob_license_expired_second_duration < 5184000：警告</li> | 服务 |

## 告警模版

* **告警概述**

  * 模板：${alarm_target} ${alarm_name}
  * 样例：ob_cluster_id=10003:expired_time=2025-10-10 OB 许可证过期时间

* **告警详情**

  * 模板：OceanBase 单机版集群 ID ${ob_cluster_id}，License 已过期或即将过期，过期时间为 ${expired_time}，请及时更新单机版许可证以避免服务中断。
  * 样例：OceanBase 单机版集群 ID 10003，License 已过期或即将过期，过期时间为 2025-10-10，请及时更新单机版许可证以避免服务中断。

## 对系统的影响

当单机的 License 已过期时，集群会处于停机状态，将无法提供正常服务。

## 可能原因

单机的 License 已过期或处于过期前 60 天。

## 处理方法

申请新的 License，并参考 [导入 License](../../../600.cluster-functions/300.manage-a-cluster/1400.import-license.md) 重新导入，OCP 会自动更新 License 的过期时间等信息。
