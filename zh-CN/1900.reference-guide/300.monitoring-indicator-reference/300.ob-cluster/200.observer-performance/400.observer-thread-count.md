# 进程线程数

本节为您介绍 OceanBase 集群的性能指标 **进程线程数** 。您可指定统计范围，查询 OceanBase 集群在单个 Zone 或 OBServer 节点的 **进程线程数** 。

## 指标介绍

统计范围内，集群 OBServer 节点的进程线程数。

## 指标参数说明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">指标项</UI-TERM>** |   **指标名称**   | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.Unit">单位</UI-TERM>** |
|---------|--------------|--------|
| observer_threads   | observer_thread_count | -     |

## 计算表达式

avg(process_thread_count{name="observer",@LABELS}) by (@GBLABELS)
