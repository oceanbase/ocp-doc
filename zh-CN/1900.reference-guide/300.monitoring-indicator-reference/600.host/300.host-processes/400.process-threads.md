# 进程线程数

本节为您介绍主机进程的监控指标 **进程线程数** 。

## observer 进程

### 指标介绍

observer 进程的线程数量。

### 指标参数说明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">指标项</UI-TERM>** | **指标名称** | **<UI-TERM key="ocp-v2.src.template.Table.Unit">单位</UI-TERM>** |
|---------|----------|--------|
| observer | observer_thread_count | 个     |

### 计算表达式

avg(process_thread_count{name="observer",@LABELS}) by (@GBLABELS)
