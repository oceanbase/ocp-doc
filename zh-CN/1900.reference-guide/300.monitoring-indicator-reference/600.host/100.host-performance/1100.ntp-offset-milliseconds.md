# NTP 时钟偏移

本节为您介绍主机 **NTP 时钟偏移** 相关的监控指标。

## 指标介绍

服务器 NTP 时钟偏移数据。

## 指标参数说明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">指标项</UI-TERM>** |    **指标名称**    | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.Unit">单位</UI-TERM>** |
|---------|----------------|--------|
| ntp_offset       | ntp_offset_milliseconds | ms     |

## 计算表达式

max(abs(node_ntp_offset_seconds{@LABELS})) by (@GBLABELS) * 1000
