# 网络吞吐率

本节为您介绍主机的性能指标 **网络吞吐率** 。

## receive

### 指标介绍

每秒接收数据量。

### 指标参数说明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">指标项</UI-TERM>** | **指标名称** | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.Unit">单位</UI-TERM>** |
|---------|----------|--------|
| receive | net_recv | MiB     |

### 计算表达式

avg(rate(node_network_receive_bytes_total{device!="lo",@LABELS}[@INTERVAL])) by (@GBLABELS) / 1048576

## send

### 指标介绍

每秒发送数据量。

### 指标参数说明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">指标项</UI-TERM>** | **指标名称** | **<UI-TERM key="ocp-v2.src.template.Table.Unit">单位</UI-TERM>** |
|---------|----------|--------|
| send    | net_send | MiB     |

### 计算表达式

avg(rate(node_network_transmit_bytes_total{device!="lo",@LABELS}[@INTERVAL])) by (@GBLABELS) / 1048576
