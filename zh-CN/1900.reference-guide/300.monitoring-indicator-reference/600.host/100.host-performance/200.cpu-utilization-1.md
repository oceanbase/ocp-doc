# CPU 使用率

本节为您介绍主机的性能指标 **<UI-TERM key="ocp-v2.Compaction.DetailV4.CpuAndMemoryChart.CpuUsage">CPU 使用率</UI-TERM>** 。

## all

### 指标介绍

主机的 CPU 使用率。

### 指标参数说明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">指标项</UI-TERM>** |  **指标名称**   | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMetricDrawer.Unit">单位</UI-TERM>** |
|---------|-------------|--------|
| all | cpu_percent | %      |

### 计算表达式

100 * (1 - sum(rate(node_cpu_seconds_total{mode="idle",@LABELS}[@INTERVAL])) by (@GBLABELS) / sum(rate(node_cpu_seconds_total{@LABELS}[@INTERVAL])) by (@GBLABELS))
