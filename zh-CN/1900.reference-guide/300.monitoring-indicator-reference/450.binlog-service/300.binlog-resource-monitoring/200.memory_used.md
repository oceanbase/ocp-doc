# 内存占用

本节为您介绍 Binlog 实例的资源监控指标 **内存占用**。

## 指标介绍

Binlog 内存使用量（MiB）。

## 指标参数说明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">指标项</UI-TERM>** |   **指标名称**    | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.Unit">单位</UI-TERM>** |
|---------|---------------|--------|
| memory_used     | binlog_instance_mem_used_size_mb | MiB      |

## 计算表达式

sum(binlog_instance_mem_used_size_mb{@LABELS}) by (@GBLABELS)
