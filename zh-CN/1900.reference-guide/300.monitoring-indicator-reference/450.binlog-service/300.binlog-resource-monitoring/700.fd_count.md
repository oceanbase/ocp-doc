# 文件 FD 数

本节为您介绍 Binlog 实例的资源监控指标 **文件 FD 数**。

## 指标介绍

Binlog instance 使用文件 FD 数。

## 指标参数说明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">指标项</UI-TERM>** |   **指标名称**    | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.Unit">单位</UI-TERM>** |
|---------|---------------|--------|
| file_fd     | binlog_instance_fd_count | -    |

## 计算表达式

sum(binlog_instance_fd_count{@LABELS}) by (@GBLABELS)
