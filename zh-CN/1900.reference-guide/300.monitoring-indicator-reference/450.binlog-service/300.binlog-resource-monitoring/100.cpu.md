# CPU

本节为您介绍 Binlog 实例的资源监控指标 **CPU**。

## 指标介绍

Binlog CPU 占用百分比。

## 指标参数说明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">指标项</UI-TERM>** |   **指标名称**    | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMetricDrawer.Unit">单位</UI-TERM>** |
|---------|---------------|--------|
| cpu_used_ratio     | binlog_instance_cpu_used_ratio | %      |

## 计算表达式

100 * sum(binlog_instance_cpu_used_ratio{@LABELS}) by (@GBLABELS)
