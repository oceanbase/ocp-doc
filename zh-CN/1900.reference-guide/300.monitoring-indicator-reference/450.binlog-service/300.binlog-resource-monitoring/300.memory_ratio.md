# 内存占用比

本节为您介绍 Binlog 实例的资源监控指标 **内存占用比**。

## 指标介绍

Binlog 内存占用百分比。

## 指标参数说明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">指标项</UI-TERM>** |   **指标名称**    | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.Unit">单位</UI-TERM>** |
|---------|---------------|--------|
| memory_percent     | binlog_instance_mem_used_ratio | %      |

## 计算表达式

100 * sum(binlog_instance_mem_used_ratio{@LABELS}) by (@GBLABELS)
