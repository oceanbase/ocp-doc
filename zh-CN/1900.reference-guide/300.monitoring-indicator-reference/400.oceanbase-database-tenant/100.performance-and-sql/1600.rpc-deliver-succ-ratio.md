# RPC 请求成功率

本节为您介绍 OceanBase 租户的监控指标 **RPC 请求成功率**。您可指定统计范围，查询租户在单个 Zone 或 OBServer 节点的 **RPC 请求成功率**。

## 指标介绍

统计范围内，RPC 请求的成功率。

## 指标参数说明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">指标项</UI-TERM>** |     **指标名称**      | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.Unit">单位</UI-TERM>** |
|---------|-------------------|--------|
| rpc_deliver_succ_ratio    | rpc_deliver_succ_ratio |   %    |

## 计算表达式

100 * (1 - sum(rate(ob_sysstat{stat_id="10004",@LABELS}[@INTERVAL])) by (@GBLABELS) / (sum(rate(ob_sysstat{stat_id="10004",@LABELS}[@INTERVAL])) by (@GBLABELS) + sum(rate(ob_sysstat{stat_id="10000",@LABELS}[@INTERVAL])) by (@GBLABELS) + sum(rate(ob_sysstat{stat_id="10002",@LABELS}[@INTERVAL])) by (@GBLABELS)))

## 采集 SQL

* OceanBase V2.2.70 及以上、OceanBase V4.0 以下版本：

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (10004, 10000, 10002) and (con_id > 1000 or con_id = 1) and class < 1000
  ```

* OceanBase V4.0 及以上版本：

  ```sql
  select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (10004, 10000, 10002) and (con_id > 1000 or con_id = 1) and class < 1000
  ```
