# 响应时间

本节为您介绍租户 OBKV_Redis 类型监控项的性能指标 **响应时间**，该指标统计了租户平均每秒处理的 SQL 行数。您可指定统计范围，查询租户在单个 Zone 或 OBServer 节点的 OBKV_Redis 类型的 **响应时间** 数据。
