# RPC 会话数

本节为您介绍 OBProxy 的监控指标 **RPC 会话数**。

## rpc_session_client

### 指标介绍

当前客户端的 ODP RPC session 数量。

### 指标参数说明

|    **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">指标项</UI-TERM>**     |          **指标名称**           | **<UI-TERM key="ocp-v2.src.template.Table.Unit">单位</UI-TERM>** |
|----------------|-----------------------------|--------|
| rpc_session_client | odp_current_rpc_session_client | -  |

### 计算表达式

sum(rate(odp_current_rpc_session{sessionType="client", @LABELS}[@INTERVAL])) by (@GBLABELS)'
