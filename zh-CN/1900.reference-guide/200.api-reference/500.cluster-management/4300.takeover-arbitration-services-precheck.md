# 接管仲裁服务预检查

## 功能说明

检查待接管仲裁服务的主机是否已存在，以及主机上 observer 进程是否存在，判断主机是否能够正常执行接管仲裁服务。

## 调用说明

### 接口约束

调用者需具有仲裁服务的 **ARBITRATION:CREATE** 权限。

### 请求路径

`POST /api/v2/arbitration/services/takeOverPreCheck`

### 请求参数

**body：**

|  参数          |  类型     | 必选   | 示例值     |  描述   |
|----------------|-----------|--------|------------|----------|
|  hostId        | Long      |  是    |  1          | 仲裁服务所在主机 ID。  |
|  svrPort       | Integer   |  是    |  2883       | 仲裁服务的服务端口。  |
|  description   | String    |  否    |  takeoverPreCheck     |  描述信息。  |

### 返回结果

**基础数据结构**

|  参数        |  类型      |  说明                               |
|--------------|------------|----------------------------------|
|  data        |  Object    | 详情参见 **接管仲裁服务预检查结果**。  |
|  successful  |  Boolean   | 请求是否成功。                          |
|  timestamp   |  Datetime  | 服务端完成请求的时间戳。                     |
|  duration    |  Integer   | 服务端处理请求的时间（毫秒）。                  |
|  status      |  Integer   | 符合 HTTP Status 规范的编码。            |
|  traceId     |  String    | 请求的 Trace ID，用于排查问题。             |
|  server      |  String    | 响应请求的应用服务的地址。                    |

|  hostId              | Long         | 主机 ID。  |

|  svrPort             | Integer      | 服务端口。  |

|  version             | String       | 仲裁服务版本。  |
