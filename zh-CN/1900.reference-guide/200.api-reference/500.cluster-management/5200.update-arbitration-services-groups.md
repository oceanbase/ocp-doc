# 更新仲裁服务组

## 功能说明

修改指定仲裁服务组信息。

## 调用说明

### 接口约束

调用者需具有仲裁服务列表中所有仲裁服务的 **ARBITRATION:UPDATE** 权限。

### 请求路径

`PATCH /api/v2/arbitration/services/groups/{id}`

### 请求参数

**path：**

|  参数                   |  类型     | 必选   | 示例值      |  描述   |
|-------------------------|-----------|--------|-------------|----------|
|  id                     | Long      |  是    |  1    | 待更新的仲裁服务组 ID。  |

**body：**

|  参数                    |  类型        | 必选   | 示例值      |  描述   |
|--------------------------|--------------|--------|-------------|----------|
|  name                     | String      |  是    |  group_a    | 仲裁服务组名。  |
|  arbitrationServiceIdList | List<Long>  |  是    |  21,22      | 组内仲裁服务 ID 列表，ID 之间用英文逗号隔开。  |
|  autoReplace              | Boolean     |  是    |  true       | 是否实施自动切换。  |
|  autoReplaceStrategy      | Object      |  是    |  -          | 详情参见 **自动切换策略**。  |
|  description              | String      |  否    |  arbitrationServiceGroup  | 备注信息。  |

**自动切换策略：**

|  参数             |  类型   | 描述   |
|-------------------|---------|---------|
|  strategyType     | String  | 自动切换策略类型。  |
|  threshold        | Integer | 阈值，具体取决于 **strategyType**：<li>UNIT_COUNT：个数</li><li>UNIT_PERCENTAGE：百分比</li><li>DEFAULT：空</li>  |
|  duration         | Long    | 持续时长，秒级时间。0 表示触发条件立即切换。  |

### 返回结果

**基础数据结构**

|  参数        |  类型      |  说明                               |
|--------------|------------|----------------------------------|
|  data        |  Object    | 详情参见 **仲裁服务组信息**。             |
|  successful  |  Boolean   | 请求是否成功。                          |
|  timestamp   |  Datetime  | 服务端完成请求的时间戳。                     |
|  duration    |  Integer   | 服务端处理请求的时间（毫秒）。                  |
|  status      |  Integer   | 符合 HTTP Status 规范的编码。            |
|  traceId     |  String    | 请求的 Trace ID，用于排查问题。             |
|  server      |  String    | 响应请求的应用服务的地址。                    |
