# 获取仲裁服务参数信息列表

## 功能说明

获取仲裁服务参数信息列表。

## 调用说明

### 接口约束

调用者需要至少拥有仲裁服务只读权限。

### 请求路径

`GET /api/v2/arbitration/services/parameterInfos`

### 请求参数

**path：**

|  参数            |  类型    | 必选   | 示例值        |  描述   |
|------------------|----------|--------|--------------|----------|
|  name            | String   |  否    | foo          | 参数名。  |
|  version         | String   |  否    | 4.2.0.0      | OceanBase 集群版本。  |

### 返回结果

**基础数据结构**

|  参数        |  类型      |  说明                               |
|--------------|------------|----------------------------------|
|  data        |  Object    | 详情参见 **仲裁服务参数信息列表**。  |
|  successful  |  Boolean   | 请求是否成功。                          |
|  timestamp   |  Datetime  | 服务端完成请求的时间戳。                     |
|  duration    |  Integer   | 服务端处理请求的时间（毫秒）。                  |
|  status      |  Integer   | 符合 HTTP Status 规范的编码。            |
|  traceId     |  String    | 请求的 Trace ID，用于排查问题。             |
|  server      |  String    | 响应请求的应用服务的地址。                    |

**仲裁服务参数信息列表**

|  参数            |  类型      |  说明                               |
|------------------|------------|----------------------------------|
|  id              |  Long     |  参数元信息 ID。    |
|  name            |  String   |  参数名。    |
|  version         |  String   |  OceanBase 集群版本。    |
|  valueRange      |  Object   |  详情参见 **<UI-TERM key="ocp-v2.component.ParameterTemplate.SetParameterEditableProTable.ValidValues">取值范围</UI-TERM>**。    |
|  defaultValue    |  String   |  默认值。    |
|  recommendValue  |  String   |  建议值。    |
|  description     |  String   |  描述。    |
|  needRestart     |  Boolean  |  是否重启生效。    |
|  readonly        |  Boolean  |  是否只读。    |

**<UI-TERM key="ocp-v2.component.ParameterTemplate.DetailDrawer.ValidValues">取值范围</UI-TERM>**

|  参数           |  类型    |  说明                               |
|-----------------|----------|----------------------------------|
|  type           |  String  |  取值范围类型。   |
|  allowedValues  |  String  |  允许的取值范围，当 **type** 为 `ENUM` 时生效，多个值使用逗号分隔，如 `TRUE,FALSE`。   |
|  maxValue       |  String  |  最大值。   |
|  minValue       |  String  |  最小值。   |
