# 获取集群内所有 OBServer 资源统计信息

## 功能说明

该接口用于获取集群内所有 OBServer 资源统计信息。

## 调用说明

### 接口约束

调用者需要通过 OCP 应用服务鉴权。

### 请求路径

`GET /api/v2/ob/clusters/{id}/serverStats`

### 请求参数

**path：**

|  参数  |  类型  |  必选  |  示例值  |  描述  |
|------|-----------|------|-----|-----------|
|  id  |  Integer  |  是  |  -  |  集群 ID。  |

### 返回结果

**基础数据结构**

|  参数        |  类型      | 说明                               |
|--------------|------------|----------------------------------|
|  data        |  Object    | 详情参见 **ServerResourceStats 的数据结构**。 |
|  successful  |  Boolean   | 请求是否成功。                          |
|  timestamp   |  Datetime  | 服务端完成请求的时间戳。                     |
|  duration    |  Integer   | 服务端处理请求的时间（毫秒）。                  |
|  status      |  Integer   | 符合 HTTP Status 规范的编码。            |
|  traceId     |  String    | 请求的 Trace ID，用于排查问题。             |
|  server      |  String    | 响应请求的应用服务的地址。                    |

**ServerResourceStats 的数据结构**

|  参数                 |  类型     |  说明     |
|-----------------------|-----------|----------|
|  ip                   |  String   |  OBServer IP。  |
|  port                 |  Integer  |  OBServer 端口号。  |
|  zone                 |  String   |  Zone 名称。  |
|  partitionCount       |  Long     |  分区数量（Leader 副本数量，非副本数量）。  |
|  timestamp            |  Long     |  时间戳。  |
|  unitCount            |  Long     |  Unit 数量。  |
|  cpuTotal             |  Number   |  CPU 总量。  |
|  cpuAssigned          |  Number   |  CPU 分配量。  |
|  cpuTotalMin          |  Double   |  仅在开启超卖后需要关注，表示实际的 CPU 总量。  |
|  cpuTotalMax          |  Double   |  仅在开启超卖后需要关注，表示超卖后的 CPU 总量，即实际的 CPU 总量 * 超卖比例。  |
|  cpuAssignedMin       |  Double   |  仅在开启超卖后需要关注，表示 CPU Min 分配量，即所有租户的 Min CPU 总和。  |
|  cpuAssignedMax       |  Double   |  仅在开启超卖后需要关注，表示 CPU Max 分配量，即所有租户的 Max CPU 总和。  |
|  memoryTotalByte      |  Long     |  内存总量，单位 byte。  |
|  memoryAssignedByte   |  Long     |  内存分配量，单位 byte。  |
|  logDiskTotalByte     |  Long     |  日志盘总量，单位 byte。  |
|  logDiskAssignedByte  |  Long     |  日志盘分配量，单位 byte。  |
|  logDiskUsedByte      |  Long     |  日志盘使用量，单位 byte。  |
|  dataDiskTotalByte    |  Long     |  数据盘总量，单位 byte。  |
|  dataDiskUsedByte     |  Long     |  数据盘使用量，单位 byte。  |
|  systemMemoryByte     |  Long     |  500 租户系统内存，单位 byte。  |
