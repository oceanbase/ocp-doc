# 查询仲裁服务列表

## 功能说明

获取所有仲裁服务的信息列表。

## 调用说明

### 接口约束

调用者需要至少拥有仲裁服务只读权限。

### 请求路径

`GET /api/v2/arbitration/services`

### 请求参数

**path：**

|  参数        |  类型         |  必选 |  示例值       |  描述   |
|--------------|---------------|-------|--------------|----------|
|  hostId      | Long          | 否    | 1002         | 仲裁服务所在主机 ID。 |
|  keyword     | String        | 否    | arbitration  | 关键词。       |
|  statusList  | List<String>  | 否    | RUNNING,UNAVAILABLE,STOPPED      | 仲裁服务状态列表。 |
|  tagIdList   | List<Long>    | 否    | 1,2,3        | 标签列表。 |

### 返回结果

**基础数据结构**

|  参数        |  类型      | 说明                               |
|--------------|------------|----------------------------------|
|  data        |  Object    | 详情参见 **<UI-TERM key="ocp-v2.Component.ArbitrationServerList.ArbitrationServiceList">仲裁服务列表</UI-TERM>**。  |
|  successful  |  Boolean   | 请求是否成功。                          |
|  timestamp   |  Datetime  | 服务端完成请求的时间戳。                     |
|  duration    |  Integer   | 服务端处理请求的时间（毫秒）。                  |
|  status      |  Integer   | 符合 HTTP Status 规范的编码。            |
|  traceId     |  String    | 请求的 Trace ID，用于排查问题。             |
|  server      |  String    | 响应请求的应用服务的地址。                    |

**<UI-TERM key="ocp-v2.Component.ArbitrationServerList.ArbitrationServiceList">仲裁服务列表</UI-TERM>**

|  参数                     |  类型           | 说明                               |
|---------------------------|-----------------|----------------------------------|
|  contents                 | List<Object>    | 详情参见 **仲裁服务信息**。  |
|  page                     | Page            | 详情参见 **分页参数**。  |

**仲裁服务信息**

|  参数                     |  类型           | 说明                               |
|---------------------------|-----------------|----------------------------------|
|  id                       | Long            | 仲裁服务 ID。  |
|  hostId                   | Long            | 仲裁服务所在的主机 ID。  |
|  svrIp                    | String          | 仲裁服务所在的主机 IP 地址。  |
|  svrPort                  | Integer         | 仲裁服务的服务端口。  |
|  status                   | String          | 仲裁服务状态。  |
|  groupId                  | Long            | 所属仲裁服务组 ID。  |
|  groupName                | String          | 所属仲裁服务组名。  |
|  priority                 | Integer         | 仲裁服务在服务组中的优先级。  |
|  operatingTaskInstanceId  | Long            | 运维中的任务 ID。  |
|  statusAnalysis           | Object          | 详情参见 **异常状态原因分析**。  |
|  version                  | String          | 仲裁服务版本。  |
|  installPath              | String          | 仲裁服务安装目录。  |
|  runPath                  | String          | 仲裁服务运行目录。  |
|  runUser                  | String          | 仲裁服务运行用户。  |
|  architecture             | String          | 仲裁服务所在主机的架构信息。  |
|  description              | String          | 仲裁服务描述。  |
|  clusters                 | List<Object>    | 详情参见 **仲裁服务关联的集群信息**。  |
|  createTime               | OffsetDateTime  | 仲裁服务创建时间。  |
|  updateTime               | OffsetDateTime  | 仲裁服务修改时间。  |
|  startupParameters        | Object          | 详情参见 **仲裁服务启动参数**。  |
|  tags                     | List<Object>    | 标签信息。  |

**异常状态原因分析**

|  参数              |  类型          |  说明          |
|--------------------|----------------|----------------|
|  startTime         | OffsetDateTime | 状态开始时间。  |
|  reason            | String         | 状态产生的原因。  |
|  action            | String         | 解决方案。  |
|  reasonType        | String         | 状态产生的原因类型。  |
|  diagnosisType     | String         | 诊断类型。  |
|  diagnosisContent  | Object         | 诊断内容。  |

**仲裁服务关联的集群信息**

|  参数          |  类型         |  说明        |
|----------------|---------------|--------------|
|  id            | Long          | 集群 ID。  |
|  name          | String        | 集群名。  |
|  obClusterId   | Long          | 集群内部 ID。  |
|  status        | String        | 集群状态。  |
|  tenants       | List<Object>  | 详情参见 **集群下的租户信息**。  |
|  tags          | List<Object>  | 详情参见 **标签信息**。  |

**集群下的租户信息**

|  参数              |  类型        |  说明        |
|--------------------|--------------|--------------|
|  id                | Long         | 租户 ID。  |
|  name              | String       | 租户名。  |
|  obTenantId        | Long         | OceanBase 内部租户 ID。  |
|  arbitrationStatus | String       | 仲裁状态。  |
|  degradedLsIdList  | List<Long>   | 已发生降级的日志流 ID 列表。  |

**标签信息**

|  参数     |  类型        |  说明        |
|-----------|--------------|--------------|
|  id       | Long         | 标签 ID。  |
|  key      | String       | 标签的键。  |
|  value    | String       | 标签的值。  |
|  refs     | List<Object> | 详情参见 **标签资源列表**。  |

**标签资源列表**

|  参数          |  类型        |  说明        |
|----------------|--------------|--------------|
|  id            |  Long        |  标签 ID。   |
|  name          |  String      |  标签名。    |
|  resourceType  |  String      |  资源类型。  |

**仲裁服务启动参数**

|  参数          |  类型    |  描述     |
|----------------|----------|----------|
| name           | String   | 参数名。  |
| value          | String   | 参数值。  |

**分页参数**

|  参数          |  类型     |  描述     |
|----------------|-----------|----------|
| number         | Integer   | 页码。  |
| size           | Integer   | 每页的大小。  |
| totalElements  | Integer   | 总记录数。  |
| totalPages     | Integer   | 总页数。  |
