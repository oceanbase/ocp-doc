# 批量替换仲裁服务预检查

## 功能说明

批量为 OceanBase 集群替换仲裁服务预检查。

## 调用说明

### 接口约束

* 调用者需具有目标仲裁服务的 **ARBITRATION:UPDATE** 权限。
* 调用者需具有集群 ID 列表中所有集群的 **CLUSTER:UPDATE** 权限。

### 请求路径

`POST /api/v2/ob/clusters/batchReplaceArbitrationPreCheck`

### 请求参数

**body：**

|  参数                    |  类型        | 必选   | 示例值      |  描述   |
|--------------------------|--------------|--------|-------------|----------|
|  arbitrationServiceId    | Long         |  是    |  1          | 目标仲裁服务 ID。  |
|  clusterIdList           | List<Long>   |  是    |  83,84      | 待替换仲裁服务的 OceanBase 集群 ID 列表，集群 ID 之间用英文逗号隔开。  |

### 返回结果

**基础数据结构**

|  参数        |  类型      |  说明                               |
|--------------|------------|----------------------------------|
|  data        |  Object    | 详情参见 **预检查结果**。              |
|  successful  |  Boolean   | 请求是否成功。                          |
|  timestamp   |  Datetime  | 服务端完成请求的时间戳。                     |
|  duration    |  Integer   | 服务端处理请求的时间（毫秒）。                  |
|  status      |  Integer   | 符合 HTTP Status 规范的编码。            |
|  traceId     |  String    | 请求的 Trace ID，用于排查问题。             |
|  server      |  String    | 响应请求的应用服务的地址。                    |

**预检查结果**

|  参数         |  类型         |  说明               |
|---------------|---------------|--------------------|
|  valid        |  Boolean      |  是否检查成功。   |
|  checkResults |  List<Object> |  详情参见 **错误信息列表**。   |

**错误信息列表**

|  参数          |  类型      |  说明        |
|----------------|------------|------------------|
|  errorCode     |  String    |  错误码。  |
|  args          |  Object[]  |  错误码参数。  |
|  errorMessage  |  String    |  国际化的错误信息。  |
|  extraInfo     |  Object    |  额外信息。  |

## 示例

### 请求示例

`POST /api/v2/ob/clusters/batchReplaceArbitrationPreCheck`

```JSON
{
  "clusterIdList":[83,84],
  "arbitrationServiceId":21
}
```

### 返回示例

```JSON
{
    "data": {
        "checkResults": [],
        "valid": true
    },
    "duration": 1067,
    "server": "5e11a5f435",
    "status": 200,
    "successful": true,
    "timestamp": "2025-01-22T18:11:12.627+08:00",
    "traceId": "22c9ca17d3541108"
}
```
