# 批量关联 OceanBase 集群

## 功能说明

批量为 OceanBase 集群添加仲裁服务。

## 调用说明

### 接口约束

* 调用者需具有目标仲裁服务的 **ARBITRATION:UPDATE** 权限。
* 调用者需具有集群 ID 列表中所有集群的 **CLUSTER:UPDATE** 权限。

### 请求路径

`POST /api/v2/ob/clusters/batchAddArbitration`

### 请求参数

**body：**

|  参数                    |  类型        | 必选   | 示例值      |  描述   |
|--------------------------|--------------|--------|-------------|----------|
|  arbitrationServiceId    | Long         |  是    |  25         | 目标仲裁服务 ID。  |
|  clusterIdList           | List<Long>   |  是    |  83,84      | 待添加仲裁服务的 OceanBase 集群 ID 列表，集群 ID 之间用英文逗号隔开。  |
|  enabledArbitration      | Boolean      |  是    |  true       | 是否自动开启 2F/4F 的仲裁服务。  |

### 返回结果

**基础数据结构**

|  参数        |  类型      |  说明                               |
|--------------|------------|----------------------------------|
|  data        |  Object    | 异步任务信息，详情参见 [任务信息](../400.task-return-structure.md)。             |
|  successful  |  Boolean   | 请求是否成功。                          |
|  timestamp   |  Datetime  | 服务端完成请求的时间戳。                     |
|  duration    |  Integer   | 服务端处理请求的时间（毫秒）。                  |
|  status      |  Integer   | 符合 HTTP Status 规范的编码。            |
|  traceId     |  String    | 请求的 Trace ID，用于排查问题。             |
|  server      |  String    | 响应请求的应用服务的地址。                    |

## 示例

### 请求示例

`POST /api/v2/ob/clusters/batchAddArbitration`

```JSON
{
  "arbitrationServiceId":25,
  "clusterIdList":[83,84],
  "enabledArbitration":true
}
```
