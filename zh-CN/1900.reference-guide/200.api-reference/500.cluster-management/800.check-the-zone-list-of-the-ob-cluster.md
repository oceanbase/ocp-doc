# 查询 OceanBase 集群 Zone 列表

## 功能说明

该接口用于查询 OceanBase 集群的 Zone 列表。

## 调用说明

### 接口约束

* 调用者需具备查看 OceanBase 集群的权限。

  关于调用者的权限，详情可参见 [用户及权限概述](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md)。
  
* 调用者需要通过 OCP 应用服务鉴权。

### 请求路径

`GET /api/v2/ob/clusters/{id}/zones`

**path:**

| 参数 |   类型    | 必选 | 示例值 |               描述               |
|----|---------|----|-----|--------------------------------|
| id | Integer | 是  | 100 | 需查询 Zone 列表的 OceanBase 集群的 ID。 |

### 返回结果

**基础数据结构**

|        参数        |    类型    |          说明           |
|------------------|----------|-----------------------|
| data             | Object   | 请求的数据。                |
| ├─ contents      | Object   | 详情参见 **Zone 数据结构**。   |
| ├─ page          | Object   | 分页信息。                 |
| ├─ totalElements | Integer  | 总记录数。                 |
| ├─ totalPage     | Integer  | 总页数。                  |
| ├─ number        | Integer  | 当前页码。                 |
| ├─ size          | Integer  | 当前页大小。                |
| successful       | Boolean  | 请求是否成功。               |
| timestamp        | Datetime | 服务端完成请求的时间戳。          |
| duration         | Integer  | 服务端处理请求的时间（毫秒）。       |
| status           | Integer  | 符合 HTTP Status 规范的编码。 |
| traceId          | String   | 请求的 Trace ID，用于排查问题。  |
| server           | String   | 响应请求的应用服务的地址。         |

**Zone 数据结构**

|     参数      |   类型    |        说明        |
|-------------|---------|------------------|
| name        | String  | Zone 名。           |
| idcName     | String  | 所属机房名。            |
| regionName  | String  | 所属地域。             |
| servers     | Object  | 详情参见 **Server 数据结构**。        |
| clusterId   | Long    | 机器 ID。            |
| obClusterId | Long    | OceanBase 集群的 ID。 |
| serverCount | Integer | Server 数。         |
| hostCount   | Integer | 主机数。              |
| architecture | String | CPU 架构。          |
| status      | Enum    | Zone 状态，取值范围：<li>RUNNING：运行中。</li><li>UNAVAILABLE：不可用。</li><li>SERVICE_STOPPED：服务已停止。</li><li>STOPPED：已停止。</li><li>DELETED：已删除。</li><li>CREATING：创建中（运维中间态）。</li><li>STOPPING：停止中（运维中间态）。</li><li>STARTING：启动中（运维中间态）。</li><li>RESTARTING：重启中（运维中间态）。</li><li>DELETING：删除中（运维中间态）。</li><li>OPERATING：运维中（运维中间态）。</li>    |
| innerStatus | Enum    | OceanBase Zone 内部状态，内部表 `__all_zone status` 的值。取值范围：<li>ACTIVE</li><li>INACTIBE</li>  |
| compactionStatus  | Enum  | 合并状态，取值范围：<li>IDLE：空闲中。</li><li>MERGING：合并中。</li><li>INDEX INDEXING：索引中，MERGING 之后进行 INDEX，OceanBase V2.2 及之后版本已不再使用 INDEX 状态。</li><li>ERROR：错误状态。</li><li>TIMEOUT：超时状态。</li><li>MOST_MERGED：已合并。</li>    |
| rootServer  | Object  | Root Server 列表。          |

**Server 数据结构**

|       参数       |    类型    |       说明        |
|----------------|----------|-----------------|
| id             | String   | OBserver ID。    |
| ip             | String   | OBserver IP。    |
| port           | Integer  | 端口。              |
| sqlPort        | Integer  | SQL 端口。           |
| runUser        | String   | 操作系统用户。    |
| runPath        | String   | 运行路径。    |
| installPath    | String   | 安装路径。    |
| version        | String   | 版本。              |
| withRootserver | Boolean  | 是否带 Root Service。 |
| status         | String   | 状态。              |
| innerStatus    | Enum     | OceanBase 内部状态，取值范围：<li>ACTIVE</li><li>INACTIVE</li><li>DELETING</li><li>TAKEOVER_BY_RS</li>    |
| clusterId      | Long     | 所属集群 ID。          |
| zoneName       | String   | 所属 Zone 名称。        |
| regionName     | String   | 所属地域。            |
| idcName        | String   | 所属机房。            |
| hostId         | Long     | 对应主机 ID。          |
| hostTypeName   | String   | 机型名称。            |
| hostStatus     | Enum     | 主机状态，取值范围：<li>NEW。</li><li>ONLINE：主当前正在运行服务。</li><li>OFFLINE：当前无法访问-无法连接。</li><li>AGENT_RESTARTING：Agent 重启状态。</li><li>AGENT_REINSTALLING：Agent 重新安装状态。</li><li>SHUTDOWN：关闭。</li><li>DELETING：删除。</li><li>AVAILABLE：可访问。</li>    |
| startTime      | DateTime | 启动时间。            |
| stopTime       | DateTime | 停止时间。            |
| arbitrationStatus  | Enum  | OceanBase 的仲裁服务联通性，仅 OceanBase V4.2.0.0 以上支持。取值范围：<li>ACTIVE</li><li>INACTIVE</li>   |
| onlineCpuCoreRange  | String | OceanBase 的 CPU 核范围。    |
