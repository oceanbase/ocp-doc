# 查询监控指标描述信息

## 功能说明

查询 OCP 应用当前提供的指标的描述信息。使用者可以根据这些描述信息，进一步查询对应的监控数据。

## 调用说明

### 接口约束

调用者需要通过 OCP 应用服务鉴权。

### 请求路径

`GET /api/v2/monitor/metricGroups`

### 请求参数

**body：**

|  参数   |   类型    | 必选 |   示例值    |       描述     |
|-------|---------|----|----------|----------------------------|
| page  | Integer | 否  | 1        | 请求数据的分页页码。值从 1 开始，默认值为 1。     |
| size  | Integer | 否  | 10       | 请求数据的分页大小。默认值为 10，最大值为 2000。     |
| sort  | String  | 否  | asc,name | 请求数据的排序规则，默认按 ID 升序排序。    |
| type  | String  | 是  | TOP      | 查询的指标类型：<li>TOP：查询 Top 类指标的元数据。</li><li>NORMAL：查询普通指标的元数据。<li>     |
| scope | String  | 是  | CLUSTER  | 查询的指标范围：<li>CLUSTER：集群的指标。</li><li>TENANT：租户的指标。</li><li>HOST：主机的指标。</li><li>OBPROXY：OBProxy 的指标。</li>    |
| target | String  | 否  | OBCLUSTER  | 指标元信息类型：<li>OBCLUSTER：OceanBase 集群。</li><li>OBPROXY：OBProxy 集群。</li>    |
| targetId | Integer    | 否  | 1  | 指标元信息 ID：<li>当 `target` 为 OBCLUSTER 时，传入 OceanBase 集群 ID。</li><li>当 `target` 为 OBPROXY 时，传入 OBProxy 集群 ID。</li>    |

### 返回结果

**基础数据结构**

|        参数        |    类型    |          说明           |
|------------------|----------|-----------------------|
| data             | Object   | 请求的数据。                |
| ├─ contents      | Array    | 指标大类的元数据数据，详情参见 **指标大类数据结构**。   |
| ├─ page          | Object   | 分页信息，详情参见 **page 数据结构**。                 |
| ├─ totalElements | Integer  | 总记录数。                 |
| ├─ totalPage     | Integer  | 总页数。                  |
| ├─ number        | Integer  | 当前页码。                 |
| ├─ size          | Integer  | 当前页大小。                |
| successful       | Boolean  | 请求是否成功。               |
| timestamp        | Datetime | 服务端完成请求的时间戳。          |
| duration         | Integer  | 服务端处理请求的时间（毫秒）。       |
| status           | Integer  | 符合 HTTP Status 规范的编码。 |
| traceId          | String   | 请求的 Trace ID，用于排查问题。  |
| server           | String   | 响应请求的服务端的地址。          |

**指标大类数据结构**

|      参数      |   类型    |     说明    |
|--------------|---------|-------------|
| id           | Integer | 指标大类的 ID。   |
| key          | String  | 指标大类的编码名称。     |
| name         | String  | 指标大类的名称。支持国际化。   |
| description  | String  | 指标大类的说明信息。支持国际化。  |
| scope        | String  | 指标范围：<li>CLUSTER：集群的指标。</li><li>TENANT：租户的指标。</li><li>HOST：主机的指标。</li><li>OBPROXY：OBProxy 的指标</li>    |
| type         | String  | 指标类型：<li>TOP：查询 Top 类指标的元数据。</li><li>NORMAL：查询普通指标的元数据。</li>    |
| metricGroups | Array   | 指标分组的数组，详情参见 **指标分组数据结构**。       |
| dimensions   | Array   | 包含的维度列表。    |
| defaultDimension | String  | 默认维度。    |

**指标分组数据结构**

|     参数      |   类型    |           说明              |
|-------------|---------|-----------------------------------|
| id          | Integer | 指标分组的 ID。                      |
| key         | String  | 指标分组的编码名称。             |
| name        | String  | 指标分组的名称。支持国际化。      |
| description | String  | 指标分组的说明信息。支持国际化。    |
| metrics     | Array   | 指标元数据的数组，详情参见 **指标元数据数据结构**。       |
| withLabel   | Boolean | 是否为带标签的监控数据群组。             |
| dimension   | String  | 维度。                                 |

**指标元数据数据结构**

|        参数        |   类型    |       说明       |
|------------------|---------|----------------|
| id               | Integer | 指标的 ID。        |
| key              | String  | 指标的编码名称。       |
| name             | String  | 指标的名称，支持国际化。   |
| description      | String  | 指标的说明信息，支持国际化。 |
| unit             | String  | 指标的单位。          |
| displayByDefault | Boolean | 是否默认展示。         |

**page 数据结构**

|  参数  |  类型  |  说明  |
|--------|---------|--------|
|  totalElements  |  Integer  |  总记录数。  |
|  totalPages     |  Integer  |  总页数。  |
|  number         |  Integer  |  当前页码。  |
|  size           |  Integer  |  当前页大小。   |

## 示例

### 请求示例

查询集群范围、Top 类型的指标的元数据：

```json
GET /api/v2/monitor/metricGroups?scope=CLUSTER&type=TOP
```
