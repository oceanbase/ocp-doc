# 查询全部租户列表

## 功能说明

查询全部租户列表。

## 调用说明

### 接口约束

* 调用者需要通过 OCP 应用服务鉴权。

* 只会返回调用者具有集群读权限下的租户。

### 请求路径

`GET /api/v2/ob/tenants`

### 请求参数

**body：**

|    参数  |     类型    | 必选 |   示例值  |        描述     |
|----------|-------------|------|----------|------------------|
| page     | Integer     | 否   | 1        | 请求数据的分页页码。值从 1 开始，默认值：1。      |
| size     | Integer     | 否   | 10       | 请求数据的分页大小。默认值：10，最大值：2000。      |
| sort     | String      | 否   | name,asc | 请求数据的排序规则。        |
| name     | String      | 否   | foo      | 查询名称包含关键词的租户，不区分大小写。      |
| mode     | StringArray | 否   | ORACLE   | 查询指定模式的租户，取值范围：<li>ORACLE：Oracle 模式。</li><li>MYSQL：MySQL 模式。</li>     |
| locked   | Boolean     | 否   | false    | 根据租户的锁定状态查询，取值范围：<li>不指定时，查询所有租户。</li><li>值为 `true` 时，只查询处于锁定状态的租户。</li><li>值为 `false` 时，只查询未处于锁定状态的租户。</li>      |
| clusterName  | String  | 否   | cluster1   | 集群名称。   |
| readonly | Boolean     | 否   | false    | 根据租户的只读状态查询，取值范围：<li>不指定时，查询所有租户。</li><li>值为 `true` 时，只查询处于只读状态的租户。</li><li>值为 `false` 时，只查询未处于只读状态的租户。</li> |
| status   | StringArray | 否   | NORMAL   | 查询指定状态的租户，取值范围：<li>NORMAL：运行中。</li><li>CREATING：创建中。</li><li>MODIFYING：修改中。</li><li>UNAVAILABLE：不可用。</li><li>OPERATING：运维中。</li><li>CLONING：克隆中。</li><li>RESTORING：恢复中。</li><li>DISCONNECTING：解耦中。</li><li>FAILOVER：容灾切换。</li><li>SWITCHOVER：日常切换。</li><li>TDE_ENABLING：TDE 加密中。</li>    |
| withRemote  | Enum    | 否    | NONE     | 多 OCP 集群模式下有效，是否包含远端 OCP 下的 OceanBase 租户。取值范围：<li>NONE：不获取。</li><li>ALL：全部获取。</li><li>RELATED：获取本地租户以及有主备关系的远程租户。</li>   |
| tagId    | Array       | 否   | -         | 标签 ID 集合。   |

## 示例

```json
GET /api/v2/ob/tenants?name=foo&status=NORMAL,CREATING&page=2&size=10
```
