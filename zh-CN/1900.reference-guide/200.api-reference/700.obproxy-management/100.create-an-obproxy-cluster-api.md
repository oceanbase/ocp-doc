# 创建 OBProxy 集群

## 功能说明

创建 OBProxy 集群时使用的接口。

## 调用说明

### 接口约束

调用者需要通过 OCP 应用服务鉴权。

### 请求路径

`POST /api/v2/obproxy/clusters`

### 请求参数

**body：**

|   参数          |   类型    | 必选 |  示例值         |        描述       |
|---------------------|---------|-------|--------------|---------------|
| name                | String  | 是  | OBProxy001     | OBProxy 集群名。    |
| address             | String  | 是  | foo.bae        | OBProxy 集群访问地址。      |
| port                | Integer | 是  | 2883           | OBProxy 集群访问端口。       |
| workMode            | String  | 是  | CONFIG_URL     | OBProxy 集群工作模式：<li>CONFIG_URL</li><li>RS_LIST</li>   |
| obproxyInstallParam | Object  | 是  | --             | 创建 OBProxy 集群时需要安装的 OBProxy 信息。      |
| ├─hostIds           | Array   | 是  | \[1,2\]        | 待安装 OBProxy 的主机 ID。     |
| ├─sqlPort           | Integer | 是  | 2883           | OBProxy SQL 端口。       |
| ├─exportPort        | Integer | 是  | 2884           | OBProxy Exproter 端口。       |
| ├─version           | String  | 否  | obproxy-x.x.x.-752024120610.el7.x86_64.rpm | OBProxy 软件包版本，不部署 OBProxy Server 时不需要指定。         |
| obLinks             | Array   | 否  | --             | 可连接 OceanBase 集群信息，详情参见 **ObLink 数据结构**。<li>RS_LIST 模式下有且只能有一个可连接 OceanBase 集群。</li><li>CONFIG_URL 模式下无限制。</li>      |
| startupParameters   | Array   | 否  | --             | OBProxy 启动参数，详情参见 **ObproxyParameter 数据结构**，可以为空数组。      |
| parameters          | Array   | 否  | --             | OBProxy 非启动参数，详情参见 **ObproxyParameter 数据结构**，可以为空数组。      |
| password            | String  | 否  | --             | proxysys 账号的密码，OBProxy V3.1.0 之前的版本不支持指定该密码。      |
| installPath         | String  | 是  | /home/admin/obproxy | OBProxy 安装路径。      |
| runUser             | String  | 是  | admin          | OBProxy 运行用户。       |

**ObLink 数据结构**

|     参数      |   类型    | 必选 |   示例值   |    描述    |
|-------------|---------|----|---------|----------|
| clusterName | String  | 是  | foo     | 集群名。   |
| obClusterId | Integer | 否  | 1       | 集群在 OceanBase 侧的集群 ID。 |
| username    | String  | 是  | proxyro | 连接集群用户。   |

**ObproxyParameter 数据结构**

|  参数   |   类型   | 必选 | 示例值 |  描述  |
|-------|--------|----|-----|------|
| name  | String | 是  | foo | 参数名称。 |
| value | String | 是  | bar | 参数值。  |

### 返回结果

**基础数据结构**

|     参数     |    类型    |                                说明                                |
|------------|----------|------------------------------------------------------------------|
| data       | Object   | 异步任务信息，详情参见 [任务信息](../400.task-return-structure.md)。 |
| successful | Boolean  | 请求是否成功。                                                          |
| timestamp  | Datetime | 服务端完成请求的时间戳。                                                     |
| duration   | Integer  | 服务端处理请求的时间（毫秒）。                                                  |
| status     | Integer  | 符合 HTTP Status 规范的编码。                                            |
| traceId    | String   | 请求的 Trace ID，用于排查问题。                                             |
| server     | String   | 响应请求的应用服务的地址。                                                    |

    "workMode": "CONFIG_URL",
    "obproxyInstallParam": {

        "sqlPort": 2883,

    }
}
