# 删除 OBProxy

## 功能说明

删除 OBProxy Server 时使用的接口。

## 调用说明

### 接口约束

调用者需要通过 OCP 应用服务鉴权。

### 请求路径

`POST /api/v2/obproxy/clusters/{id}/servers/delete`

### 请求参数

**path：**

|   参数     | 类型  | 必选  | 示例值   |        描述         |
|------------|-------|-------|---------|-------------------|
| id         | Long  | 是    | 13153297       | OBProxy 集群 ID。     |

**body：**

|    参数                    | 类型  | 必选  | 示例值   |        描述         |
|----------------------------|-------|-------|---------|-------------------|
| obproxyServerIds           | Long  | 是    | 1,2,3   | 待删除的 OBProxy Server ID 列表。 |
| skipHostOperationServerIds | Long  | 否    | 1       | 跳过主机操作的 OBProxy Server ID 列表，通常用于主机不可用场景，需要手动清理主机。    |

### 返回结果

**基础数据结构**

|   参数     |    类型    |                                说明                                |
|------------|----------|------------------------------------------------------------------|
| data       | Object   | 异步任务信息，详情参见 [任务信息](../400.task-return-structure.md)。 |
| successful | Boolean  | 请求是否成功。                                                          |
| timestamp  | Datetime | 服务端完成请求的时间戳。                                                     |
| duration   | Integer  | 服务端处理请求的时间（毫秒）。                                                  |
| status     | Integer  | 符合 HTTP Status 规范的编码。                                            |
| traceId    | String   | 请求的 Trace ID，用于排查问题。                                             |
| server     | String   | 响应请求的应用服务的地址。                                                    |

## 示例

### 请求示例

`POST /api/v2/obproxy/clusters/13153297/servers/delete`

```shell
{
  "obproxyServerIds": [
    1,
    2,
    3
  ],
  "skipHostOperationServerIds": [
    1
  ]
}
```
