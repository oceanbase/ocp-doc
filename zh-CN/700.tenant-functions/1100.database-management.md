# 管理数据库

数据库管理为您提供该租户下的数据库列表信息，以及提供数据库的创建、删除和修改等功能。

## 前提条件

* 查看数据库列表信息时，请确保登录 OCP 的用户具备如下权限：

  * **集群只读** 或 **租户只读** 资源权限。
  * 租户 **<UI-TERM key="ocp-v2.page.Iframe.DatabaseManagement">数据库管理</UI-TERM>** 菜单权限。

* 执行新建数据库、修改数据库信息、删除数据库等运维操作时，请确保登录 OCP 的用户具备如下权限：

  * **集群维护** 或 **租户维护** 资源权限。
  * 租户 **<UI-TERM key="ocp-v2.Detail.Database.DatabaseManagement">数据库管理</UI-TERM>** 菜单权限。

* 本功能针对 MySQL 兼容模式的主租户。

* 当前用户密码箱中具有该租户的 root 密码。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏选择 **<UI-TERM key="ocp-v2.component.ParameterTemplate.Tenant">租户</UI-TERM>** ，系统默认进入 **<UI-TERM key="ocp-v2.component.TenantList.TenantList">租户列表</UI-TERM>** 页签。

3. 在 **<UI-TERM key="ocp-v2.page.Tenant.TenantList">租户列表</UI-TERM>** 中选择待操作的 MySQL 租户并单击其租户名，进入租户 **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概览</UI-TERM>** 页面。

4. 在左导航栏单击 **<UI-TERM key="ocp-v2.src.util.menu.DatabaseManagement">数据库管理</UI-TERM>** ，进入数据库管理页面。

   * **查看数据库信息**

     您可在数据库列表中查看 **<UI-TERM key="ocp-v2.Detail.Component.AddDatabaseModal.DatabaseName">数据库名</UI-TERM>**、**<UI-TERM key="ocp-v2.Tenant.Detail.CharacterSet">字符集</UI-TERM>**、**Collation**、**<UI-TERM key="ocp-v2.component.TenantList.ZonePriority">Zone 优先级</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Database.DiskUsage">磁盘使用量</UI-TERM>**、**<UI-TERM key="ocp-v2.Tenant.Detail.CreationTime">创建时间</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Component.AddDatabaseModal.ReadOnly">只读</UI-TERM>** 和 **<UI-TERM key="ocp-v2.Detail.Database.JdbcConnectionString">JDBC 连接串</UI-TERM>**。

     <main id="notice" type='explain'>
     <h4>说明</h4>
     <p>当 OceanBase 版本低于 V2.2.1 时，将无法查看创建时间。</p>
     </main>

     ![Image 151](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0756189461/p429268.png)

   * **<UI-TERM key="ocp-v2.Detail.Component.AddDatabaseModal.CreateADatabase">新建数据库</UI-TERM>**

     单击页面右上角 **<UI-TERM key="ocp-v2.Detail.Database.CreateADatabase">新建数据库</UI-TERM>** ，在 **<UI-TERM key="ocp-v2.Detail.Database.CreateADatabase">新建数据库</UI-TERM>** 面板中填写 **<UI-TERM key="ocp-v2.Detail.Component.AddDatabaseModal.DatabaseName">数据库名</UI-TERM>**、**<UI-TERM key="ocp-v2.Tenant.New.CharacterSet">字符集</UI-TERM>**、**Collation** 的信息，选择是否只读，单击 **<UI-TERM key="ocp-v2.Detail.Parameter.List.Submitted">提交</UI-TERM>** 。

     |    **配置**     | **<UI-TERM key="ocp-v2.Auth.Role.Detail.Description">描述</UI-TERM>** |
     |---------------|---------|
     | **<UI-TERM key="ocp-v2.Detail.Overview.DatabaseName">数据库名称</UI-TERM>**  | 您可自定义设置，长度为 2~64 个字符，支持包含数字（0\~9）、大写字母（A\~Z）、小写字母（a\~z）和特殊符号（<code>_-</code>）。数据库名称中的大写字母将会默认转为小写。 |
     | **<UI-TERM key="ocp-v2.Tenant.New.CharacterSet">字符集</UI-TERM>**    |可选字符集包括 utf8mb4、binary、gbk、gb18030、latin1 和 gb18030_2022；默认为 gbk。 |
     | **Collation** | 与字符集对应的详细排序规则。 |

     <main id="notice" type='explain'>
     <h4>说明</h4>
     <ul>
     <li>数据库优先级默认继承租户的 Zone 优先级设置。若需要对租户优先级进行修改，可参考 <a href="600.manage-a-tenant/670.modify-a-zone-priority.md">修改 Zone 优先级</a> 进行修改。</li>
     <li>当数据库优先级与租户优先级不一致时，您可单击 <strong>修改为和租户一致</strong> 按钮进行修改。</li>
     </ul>
     </main>

     ![Image 152](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/%E6%96%B0%E5%BB%BA%E6%95%B0%E6%8D%AE%E5%BA%93.png)

   * **修改数据库信息**

     单击数据库 **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.Operation">操作</UI-TERM>** 列的 **<UI-TERM key="ocp-v2.src.constant.credential.Edit">编辑</UI-TERM>** ，对 **字符集、Collation、是否只读** 的信息进行修改。

     <main id="notice" type='explain'>
     <h4>说明</h4>
     <ul>
     <li>数据库优先级默认继承租户的 Zone 优先级设置。若需要对租户优先级进行修改，可参考 <a href="600.manage-a-tenant/670.modify-a-zone-priority.md">修改 Zone 优先级</a> 进行修改。</li>
     <li>当数据库优先级与租户优先级不一致时，您可单击 <strong>修改为和租户一致</strong> 按钮进行修改。</li>
     </ul>
     </main>

     ![Image 153](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/%E7%BC%96%E8%BE%91%E6%95%B0%E6%8D%AE%E5%BA%93.png)

   * **<UI-TERM key="ocp-v2.Detail.Database.DeleteADatabase">删除数据库</UI-TERM>**

     单击数据库 **<UI-TERM key="ocp-v2.MultiAzone.Parameter.Operation">操作</UI-TERM>** 列的 **<UI-TERM key="ocp-v2.Alarm.Channel.Delete">删除</UI-TERM>** ，输入 **delete** 确认操作，删除数据库。

     <main id="notice" type='notice'>
     <h4>注意</h4>
     <p>数据库删除后数据将不可恢复，请谨慎操作。</p>
     </main>
