# 删除资源隔离计划

当您业务中已不再需要某项资源隔离计划时，您可对该计划进行删除操作。

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **集群维护** 或 **租户维护** 资源权限。
  * 租户 **<UI-TERM key="ocp-v2.Detail.ResourceManager.CreateResourcePlan.ResourceIsolation">资源隔离</UI-TERM>** 菜单权限。

* 资源隔离功能依赖 Cgroup，请先为租户所属集群开启 Cgroup。
* 已创建资源隔离计划。
* 被删除的资源隔离计划未被启用。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏选择 **<UI-TERM key="ocp-v2.page.AuditEvent.Tenant">租户</UI-TERM>** ，系统默认进入 **<UI-TERM key="ocp-v2.page.Tenant.TenantList">租户列表</UI-TERM>** 页签。

3. 在 **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">租户列表</UI-TERM>** 中选择待操作的租户并单击其租户名，进入租户 **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概览</UI-TERM>** 页面。

4. 在左侧显示的导航栏中单击 **<UI-TERM key="ocp-v2.src.hook.useMenu.ResourceIsolation">资源隔离</UI-TERM>** ，进入该租户的 **<UI-TERM key="ocp-v2.Detail.ResourceManager.QuarantinePlan">隔离计划</UI-TERM>** 页面。

5. 选择需要删除的资源隔离计划，进入该计划的页签下，单击右侧 **<UI-TERM key="ocp-v2.Settings.Credential.Cluster.Delete">删除</UI-TERM>** 按钮。

    <main id="notice" type='explain'>
    <h4>说明</h4>
    <p>删除操作仅涉及计划本身，会同步删除计划与限制，保留资源组名称及规则。</p>
    </main>

6. 在对话框中单击 **<UI-TERM key="ocp-v2.Detail.Component.UpgradeObproxiesModal.Ok">确定</UI-TERM>**。
