# 修改资源隔离计划

当您需要重新对资源隔离计划中进行配置时，您可参考本节内容修改资源隔离计划的信息。

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **集群维护** 或 **租户维护** 资源权限。
  * 租户 **<UI-TERM key="ocp-v2.Detail.ResourceManager.CreateResourcePlan.ResourceIsolation">资源隔离</UI-TERM>** 菜单权限。

* 资源隔离功能依赖 Cgroup，请先为租户所属集群开启 Cgroup。
* 已创建资源隔离计划。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏选择 **<UI-TERM key="ocp-v2.component.alarm.AlarmTargetLabel.Tenant">租户</UI-TERM>** ，系统默认进入 **<UI-TERM key="ocp-v2.page.Tenant.TenantList">租户列表</UI-TERM>** 页签。

3. 在 **<UI-TERM key="ocp-v2.page.Tenant.TenantList">租户列表</UI-TERM>** 中选择待操作的租户并单击其租户名，进入租户 **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概览</UI-TERM>** 页面。

4. 在左侧显示的导航栏中单击 **<UI-TERM key="ocp-v2.src.hook.useMenu.ResourceIsolation">资源隔离</UI-TERM>** ，进入该租户的 **<UI-TERM key="ocp-v2.Detail.ResourceManager.QuarantinePlan">隔离计划</UI-TERM>** 页面。

5. 选择需要修改的资源隔离计划，进入该计划的页签下，单击右侧 **<UI-TERM key="ocp-v2.component.ParameterTemplate.AddDrawer.Editing">编辑</UI-TERM>** 按钮。

    支持对计划中的 **<UI-TERM key="ocp-v2.Detail.ResourceManager.ResourceGroup">资源组</UI-TERM>** 和 **<UI-TERM key="ocp-v2.Detail.ResourceManager.CreateResourcePlan.ResourceIsolationLimits">资源隔离限制</UI-TERM>** 信息进行修改，具体配置说明可参考 [创建资源隔离计划](300.create-a-resource-isolation-plan.md)。

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/%E7%BC%96%E8%BE%91%E8%B5%84%E6%BA%90%E9%9A%94%E7%A6%BB%E8%AE%A1%E5%88%92.png)

6. 单击 **<UI-TERM key="ocp-v2.Detail.Component.Event.Determine">确定</UI-TERM>**。
