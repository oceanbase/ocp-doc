# 启用/停用资源隔离计划

为资源组创建资源隔离计划后，您需通过启用资源隔离计划来触发资源隔离生效。启用后，租户内资源分配受所选资源隔离计划内的配置影响；当您不再使用该资源隔离计划时，可对其进行停用操作。

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **集群维护** 或 **租户维护** 资源权限。
  * 租户 **<UI-TERM key="ocp-v2.Detail.ResourceManager.ResourceIsolation">资源隔离</UI-TERM>** 菜单权限。

* 资源隔离功能依赖 Cgroup，请先为租户所属集群开启 Cgroup。
* 租户已创建资源隔离计划。
* 一个租户仅可启用一项资源隔离计划。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏选择 **<UI-TERM key="ocp-v2.page.Overview.Tenant">租户</UI-TERM>** ，系统默认进入 **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">租户列表</UI-TERM>** 页签。

3. 在 **<UI-TERM key="ocp-v2.component.TenantList.TenantList">租户列表</UI-TERM>** 中选择待操作的租户并单击其租户名，进入租户 **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概览</UI-TERM>** 页面。

4. 在左侧显示的导航栏中单击 **<UI-TERM key="ocp-v2.src.hook.useMenu.ResourceIsolation">资源隔离</UI-TERM>** ，进入该租户的 **<UI-TERM key="ocp-v2.Detail.ResourceManager.QuarantinePlan">隔离计划</UI-TERM>** 页面。

5. 您可通过如下两种方式启用隔离计划。

    * 方式一：

        当租户未启用任何资源隔离计划时，单击页面提示文案中的 **<UI-TERM key="ocp-v2.ResourceManager.ResourcePlanTab.EnableResourceIsolationPlan">启用资源隔离计划</UI-TERM>**，在弹窗的 **<UI-TERM key="ocp-v2.ResourceManager.ResourceGroupTab.ResourceIsolationPlan">资源隔离计划</UI-TERM>** 下拉列表中选择需要启用的计划，单击 **<UI-TERM key="ocp-v2.Detail.Monitor.Determine">确定</UI-TERM>**。

        ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/%E5%90%AF%E7%94%A8%E9%9A%94%E7%A6%BB%E8%AE%A1%E5%88%92.png)

    * 方式二：

        进入待启用计划的页签下，单击右侧的 **<UI-TERM key="ocp-v2.component.CPUBindCoreConfigDrawer.Enable">启用</UI-TERM>** 按钮，在弹出的对话框中单击 **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.Ok">确定</UI-TERM>**。

        ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/%E5%90%AF%E7%94%A8%E8%AE%A1%E5%88%92.png)

    <main id="notice" type='explain'>
    <h4>说明</h4>
    <p>当您在已启用旧资源隔离计划的基础上启用新的资源隔离计划时，租户内资源分配开始受新资源隔离计划的配置影响，旧资源隔离计划将不再生效。</p>
    </main>

6. 当资源隔离计划已不再适用于租户时，您可通过 **<UI-TERM key="ocp-v2.ResourceManager.ResourcePlanTab.Disable">停用</UI-TERM>** 功能停止该资源隔离行为。

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/%E5%81%9C%E7%94%A8%E8%B5%84%E6%BA%90%E9%9A%94%E7%A6%BB%E8%AE%A1%E5%88%92.png)
