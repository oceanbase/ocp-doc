# 修改 Oracle 租户用户密码

本页面为您介绍修改 Oracle 租户用户密码的操作步骤。

<main id="notice" type='notice'>
<h4>功能适用性</h4>
<p>该内容仅适用于 OCP 企业版，OCP 社区版仅提供 MySQL 租户。</p>
</main>

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **集群维护** 或 **租户维护** 资源权限。
  * 租户 **<UI-TERM key="ocp-v2.Auth.User.New.UserManagement">用户管理</UI-TERM>** 菜单权限。

* 仅主租户具有修改 Oracle 租户用户密码的权限。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏选择 **<UI-TERM key="ocp-v2.component.alarm.AlarmTargetLabel.Tenant">租户</UI-TERM>** ，系统默认进入 **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">租户列表</UI-TERM>** 页签。

3. 在 **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">租户列表</UI-TERM>** 中选择待操作的 Oracle 租户并单击其租户名，进入租户 **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概览</UI-TERM>** 页面。

4. 单击左侧导航栏中的 **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.UserManagement">用户管理</UI-TERM>** 。

5. 在 **<UI-TERM key="ocp-v2.User.MySQL.UserList">用户列表</UI-TERM>** 页面，选择需要修改密码的租户，单击操作列的 **<UI-TERM key="ocp-v2.src.component.ModifyUserPasswordModal.ChangePassword">修改密码</UI-TERM>** 。

6. 在弹出框中输入新密码并确认密码。

   ![1126](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8054944461/p359534.png)

7. 勾选 **保存到密码箱** 。

8. 单击 **<UI-TERM key="ocp-v2.component.TagFilterDropDown.Ok">确定</UI-TERM>** ，修改成功后可在用户列表中查看。
