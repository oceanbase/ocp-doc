# 删除 Oracle 租户用户

本页面为您介绍删除 Oracle 租户用户的操作步骤。删除用户将删除该用户下的所有对象和数据，您需谨慎操作。

<main id="notice" type='notice'>
<h4>功能适用性</h4>
<p>该内容仅适用于 OCP 企业版，OCP 社区版仅提供 MySQL 租户。</p>
</main>

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **集群维护** 或 **租户维护** 资源权限。
  * 租户 **<UI-TERM key="ocp-v2.Auth.User.Detail.UserManagement">用户管理</UI-TERM>** 菜单权限。

* 仅主租户具有删除 Oracle 租户用户的权限。

* 不支持删除系统默认用户。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏选择 **<UI-TERM key="ocp-v2.src.component.TenantLabel.Tenant">租户</UI-TERM>** ，系统默认进入 **<UI-TERM key="ocp-v2.page.Tenant.TenantList">租户列表</UI-TERM>** 页签。

3. 在 **<UI-TERM key="ocp-v2.component.TenantList.TenantList">租户列表</UI-TERM>** 中选择待操作的 Oracle 租户，单击其租户名，进入租户 **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概览</UI-TERM>** 页面。

4. 单击左侧导航栏中的 **<UI-TERM key="ocp-v2.Auth.Role.Detail.UserManagement">用户管理</UI-TERM>** 。

5. 在 **<UI-TERM key="ocp-v2.User.MySQL.UserList">用户列表</UI-TERM>** 页面，选择需要删除的租户，在操作列 **...** 中单击 **<UI-TERM key="ocp-v2.src.constant.binlog.Delete">删除</UI-TERM>** 。

6. 在对话框中确认用户信息，输入 **delete** 。

7. 单击 **<UI-TERM key="ocp-v2.Detail.Database.Delete">删除</UI-TERM>** 。
