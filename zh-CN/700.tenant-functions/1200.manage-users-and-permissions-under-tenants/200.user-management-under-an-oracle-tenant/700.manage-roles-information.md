# 管理角色信息

本页面为您介绍修改角色系统权限、修改角色和添加对象的操作方法。

<main id="notice" type='notice'>
<h4>功能适用性</h4>
<p>该内容仅适用于 OCP 企业版，OCP 社区版仅提供 MySQL 租户。</p>
</main>

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **集群维护** 或 **租户维护** 资源权限。
  * 租户 **<UI-TERM key="ocp-v2.Auth.User.New.UserManagement">用户管理</UI-TERM>** 菜单权限。

* 仅主租户具有角色管理权限。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏选择 **<UI-TERM key="ocp-v2.Alarm.Event.Detail.Tenant">租户</UI-TERM>**，系统默认进入 **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">租户列表</UI-TERM>** 页签。

3. 在 **<UI-TERM key="ocp-v2.page.Tenant.TenantList">租户列表</UI-TERM>** 中选择待操作的 Oracle 租户并单击其租户名，进入租户 **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概览</UI-TERM>** 页面。

4. 单击左导航栏中的 **<UI-TERM key="ocp-v2.page.Auth.UserManagement">用户管理</UI-TERM>** 。

5. 选择 **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.RoleList">角色列表</UI-TERM>** 页签，进入 **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.RoleList">角色列表</UI-TERM>** 页面。

6. 单击 **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.RoleList">角色列表</UI-TERM>** 中待操作的角色的角色名，进入角色详情页。

   ![1126](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/%E8%A7%92%E8%89%B2%E8%AF%A6%E6%83%85.png)

   1. 单击 **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.ModifySystemPermissions">修改系统权限</UI-TERM>** ，在弹出框中修改权限。

   2. 单击 **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.ModifyARole">修改角色</UI-TERM>** ，在弹出框中选择角色。

   3. 单击 **<UI-TERM key="ocp-v2.Oracle.Component.AddObjectPrivilegeDrawer.AddObjects">添加对象</UI-TERM>** ，在弹出框中选择如下信息：

      |  参数  |                                   说明                                    |
      |------|-------------------------------------------------------------------------|
      | 对象类型 | 包括 **表、视图** 和 **<UI-TERM key="ocp-v2.src.constant.tenant.StoredProcedure">存储过程</UI-TERM>** 。                                                |
      | 选择对象 | 支持批量粘贴多个对象到输入框，请按照"用户名.对象名"（如 schemaname.tablename）的格式可以粘贴多个对象，用英文逗号隔开。 |
      | 授予权限 | 勾选需要的权限，详情参见 [系统权限列表](../300.system-privileges-in-a-mysql-tenant.md)。     |

      ![09162104](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4560562361/p327453.png)

7. 单击 **<UI-TERM key="ocp-v2.MultiCluster.Detail.SwitchoverModal.Determine">确定</UI-TERM>** 。

   修改成功后可在角色列表中查看。
