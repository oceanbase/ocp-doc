# 新建 Oracle 租户用户

本页面为您介绍新建 Oracle 租户用户的操作步骤。

<main id="notice" type='notice'>
<h4>功能适用性</h4>
<p>该内容仅适用于 OCP 企业版，OCP 社区版仅提供 MySQL 租户。</p>
</main>

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **集群维护** 或 **租户维护** 资源权限。
  * 租户 **<UI-TERM key="ocp-v2.Auth.User.Detail.UserManagement">用户管理</UI-TERM>** 菜单权限。

* 仅主租户具有新建 Oracle 租户用户的权限。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏选择 **<UI-TERM key="ocp-v2.src.constant.alarm.Tenant">租户</UI-TERM>** ，系统默认进入 **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">租户列表</UI-TERM>** 页签。

3. 在 **<UI-TERM key="ocp-v2.component.TenantList.TenantList">租户列表</UI-TERM>** 中选择待操作的 Oracle 租户并单击其租户名，进入租户 **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概览</UI-TERM>** 页面。

4. 单击左侧导航栏中的 **<UI-TERM key="ocp-v2.User.MySQL.UserManagement">用户管理</UI-TERM>** 。

5. 单击右上角 **<UI-TERM key="ocp-v2.User.MySQL.CreateUser">新建用户</UI-TERM>** ，在弹出框中填写如下信息。

   |   参数   |         说明       |
   |--------|---------------|
   | 用户名    | 您可自定义设置，长度为 2~30 个字符，支持包含数字（0\~9）、大写字母（A\~Z）、小写字母（a\~z）和特殊符号（<code>_-</code>）。角色名中的小写字母将会默认转为大写。   |
   | 密码     | 长度为 8\~32 个字符，至少包含数字（0\~9）、大写字母（A\~Z）、小写字母（a\~z）和特殊字符（<code>~!@#%^&*_-+=\|(){}[]:;,.?/</code>）四种类型中的三种。 |
   | 确认密码   | 请与初次输入的密码保持一致。     |
   | 拥有系统权限 | 可选，详情参见 [系统权限列表](../300.system-privileges-in-a-mysql-tenant.md)。       |
   | 拥有角色   | 可选，详情参见 [新建 Oracle 租户角色](../200.user-management-under-an-oracle-tenant/500.create-a-role-under-an-oracle-tenant.md)。      |

   ![09162057](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3067491361/p327440.png)

6. 勾选 **保存到密码箱** 。

7. 单击 **<UI-TERM key="ocp-v2.Detail.Component.AddArbitrationServerDrawer.Submit">提交</UI-TERM>** ，创建成功后可在用户列表中查看。
