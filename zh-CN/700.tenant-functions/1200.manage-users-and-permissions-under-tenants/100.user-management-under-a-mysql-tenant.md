# 管理 MySQL 租户用户

用户管理为您提供查看当前 MySQL 用户列表、新建用户、删除用户、授予用户权限、撤销用户权限等功能。

## 前提条件

* 查看 MySQL 用户列表信息时，请确保登录 OCP 的用户具备如下权限：

  * **集群只读** 或 **租户只读** 资源权限。
  * 租户 **<UI-TERM key="ocp-v2.src.hook.useMenu.UserManagement">用户管理</UI-TERM>** 菜单权限。

* 执行新建用户、锁定用户、修改密码、修改权限、删除用户等运维操作时，请确保登录 OCP 的用户具备如下权限：

  * **集群维护** 或 **租户维护** 资源权限。
  * 租户 **<UI-TERM key="ocp-v2.Auth.Role.Detail.UserManagement">用户管理</UI-TERM>** 菜单权限。

* 仅主租户具有用户管理权限。

* 不支持对系统默认用户执行锁定、修改权限和删除操作。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏选择 **<UI-TERM key="ocp-v2.component.MonitorSearch.Tenant">租户</UI-TERM>** ，系统默认进入 **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">租户列表</UI-TERM>** 页签。

3. 在 **<UI-TERM key="ocp-v2.component.TenantList.TenantList">租户列表</UI-TERM>** 中选择待操作的租户并单击其租户名，进入租户 **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概览</UI-TERM>** 页面。

4. 在导航栏中单击 **<UI-TERM key="ocp-v2.Auth.User.loginHistory.UserManagement">用户管理</UI-TERM>** ，进入用户管理页面。

5. 查看用户列表。在用户列表中，可查看 **<UI-TERM key="ocp-v2.Cluster.Component.OBProxyClusterAndUserSelect.UserName">用户名</UI-TERM>** 、**<UI-TERM key="ocp-v2.User.MySQL.AccessibleDatabases">可访问数据库</UI-TERM>** 、**<UI-TERM key="ocp-v2.User.Oracle.UserList.LogonConnectionString">登录连接串</UI-TERM>** 、**<UI-TERM key="ocp-v2.Statistics.components.PartitionDrawer.Lock">锁定</UI-TERM>** 和 **<UI-TERM key="ocp-v2.User.Oracle.RolesList.Operation">操作</UI-TERM>** 信息。

   1. 可对用户进行锁定操作，锁定后该用户将无法登录。

   2. 可对用户进行 **<UI-TERM key="ocp-v2.Statistics.components.PartitionDrawer.Lock">锁定</UI-TERM>** 、**<UI-TERM key="ocp-v2.Cluster.Detail.ChangePassword">修改密码</UI-TERM>** 、**<UI-TERM key="ocp-v2.User.MySQL.ModifyPermissions">修改权限</UI-TERM>** 、**<UI-TERM key="ocp-v2.Detail.LoadBalance.Delete">删除</UI-TERM>** 等操作。

   3. 可复制或查看用户登录连接串详情。

      ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/%E7%94%A8%E6%88%B7%E5%88%97%E8%A1%A8.png)

6. 单击页面右上角 **<UI-TERM key="ocp-v2.User.Oracle.CreateUser">新建用户</UI-TERM>** 。

   1. 输入 **<UI-TERM key="ocp-v2.component.common.ObUserSelect.UserName">用户名</UI-TERM>** 、**<UI-TERM key="ocp-v2.Component.BinlogServerList.Hostname">主机名</UI-TERM>** 、**<UI-TERM key="ocp-v2.Auth.User.New.Password">密码</UI-TERM>** 、**<UI-TERM key="ocp-v2.Detail.Component.ChangePasswordModal.ConfirmPassword">确认密码</UI-TERM>** 、**<UI-TERM key="ocp-v2.Detail.Component.AddUserDrawer.GlobalPermissions">全局权限</UI-TERM>**（选填）、**<UI-TERM key="ocp-v2.Detail.Component.AddUserDrawer.DatabasePermissions">数据库权限</UI-TERM>**（选填）。

      |  参数   |        说明       |
      |-------|---------|
      | 用户名   | 您可自定义设置，长度为 2~30 个字符，支持包含数字（0\~9）、大写字母（A\~Z）、小写字母（a\~z）和特殊符号（<code>_-</code>）。 |
      | 主机名   | 支持的形式包括并不限于如下：<ul><li> `%` 。</li><li>`localhost` 。</li><li>IP 地址如 `192.168.1.1`、子网掩码如 `192.168.1.%` 。</li><li>域名。</li></ul>  |
      | 新密码   | 长度为 8\~32 个字符，至少包含数字（0\~9）、大写字母（A\~Z）、小写字母（a\~z）和特殊字符（<code>~!@#%^&*_-+=\|(){}[]:;,.?/</code>）四种类型中的三种。 |
      | 确认密码 | 与新密码保持一致。 |
      | 全局权限  | 选填，详情可参见 [MySQL 租户系统权限列表](300.system-privileges-in-a-mysql-tenant.md) ，该参数适用于所有的数据库。   |
      | 数据库权限 | 选填，该参数适用于一个指定数据库中的所有目标。 |

      ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/432/%E6%96%B0%E5%BB%BA%E6%95%B0%E6%8D%AE%E5%BA%93%E7%94%A8%E6%88%B7.png)

   2. 对新用户进行授权。勾选新用户可访问的数据库，单击 **\>** 图标，将目标数据库移动至右侧区域，并勾选需要添加的权限。

   3. 单击 **<UI-TERM key="ocp-v2.Alarm.Rule.New.Submit">提交</UI-TERM>** ，完成新用户的创建。

7. 修改密码：单击用户操作列的 **<UI-TERM key="ocp-v2.Tenant.Detail.ChangePassword">修改密码</UI-TERM>** ，在弹出框内进行密码修改。

8. 修改权限：单击用户操作列的 **<UI-TERM key="ocp-v2.Oracle.Component.ModifyObjectPrivilegeModal.ModifyPermissions">修改权限</UI-TERM>** ，对用户的全局权限和数据库权限进行修改。

9. 删除用户：单击用户操作列的 **<UI-TERM key="ocp-v2.ResourceManager.ResourceGroupConfig.SelectGroupName.Delete">删除</UI-TERM>** 。删除用户可能会影响正在使用该用户的业务，请谨慎操作。
