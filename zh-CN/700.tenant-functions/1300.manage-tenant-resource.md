# 管理租户资源

您可在租户资源管理页面，查看租户的资源使用趋势和数据库、表组信息，并支持对数据库、表组、表、分区等条件进行筛选。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **集群只读** 或 **租户只读** 资源权限。
* 租户 **<UI-TERM key="ocp-v2.src.util.menu.ResourceManagement">资源管理</UI-TERM>** 菜单权限。

## 进入资源管理页面

1. 登录 OCP。

2. 在左侧导航栏选择 **<UI-TERM key="ocp-v2.Cluster.Arbitration.Tenant">租户</UI-TERM>**，系统默认进入 **<UI-TERM key="ocp-v2.page.Tenant.TenantList">租户列表</UI-TERM>** 页签。

3. 在 **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">租户列表</UI-TERM>** 中选择待操作的租户并单击其租户名，进入租户 **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概览</UI-TERM>** 页面。

4. 在左侧显示的导航栏中单击 **<UI-TERM key="ocp-v2.Detail.Resource.ResourceManagement">资源管理</UI-TERM>** ，进入该租户的 **<UI-TERM key="ocp-v2.page.Iframe.ResourceManagement">资源管理</UI-TERM>** 页面。

   在该页面中，您可按条件筛选出您想查看的资源。

   <main id="notice" type='explain'>
   <h4>说明</h4>
   <p>每天凌晨 5 点左右，系统会对租户的资源使用趋势和数据库、表组信息进行统计。当集群为新建集群时，新建集群当天将不会展示统计数据</p>
   </main>

## 按条件筛选

* 您可在 **<UI-TERM key="ocp-v2.Detail.Resource.ConditionRange">条件范围</UI-TERM>** 后，选择按 **<UI-TERM key="ocp-v2.Trace.TraceDetailDrawer.Database">数据库</UI-TERM>** 进行筛选后，选择全部数据库或某一数据库，选择全部表或某一表，选择全部分区或某一分区。确定筛选条件后，即可在 **<UI-TERM key="ocp-v2.Detail.Resource.Trend.ResourceUsageTrends">资源使用趋势</UI-TERM>** 和 **<UI-TERM key="ocp-v2.Detail.Resource.Top.List">排行榜</UI-TERM>** 区域查看信息。

* 也可选择按 **<UI-TERM key="ocp-v2.Detail.Resource.Top.TableGroup">表组</UI-TERM>** 进行筛选，选则全部表组或某一表组，选择全部表或某一表，选择全部分区或某一分区。

    <main id="notice" type='explain'>
    <h4>说明</h4>
    <ul>
    <li>oceanbase 系统表组，这个表组的表是内部表使用的，用户无法把更多表添加到这个表组。和用户自行添加的表组不同， oceanbase 表组下的表会跨数据库，在 3 个系统内置数据库下分布。</li>
    <li><strong>non_tablegroup</strong> 指不属于任何表组的表，这个表不会进行展示。当表不属于任何表组时，需要使用 <strong>数据库</strong> 条件范围进行筛选。</li>
    </ul>
    </main>

## 资源使用趋势

您可在资源使用趋势通过时间条件筛选，查看最近一周、最近一个月或自定义时间段内的 **CPU**、**<UI-TERM key="ocp-v2.Compaction.Detail.Memory">内存</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Resource.Trend.PartitionCopy">分区副本</UI-TERM>**、**<UI-TERM key="ocp-v2.page.Diagnosis.LogDisk">日志盘</UI-TERM>** 和 **<UI-TERM key="ocp-v2.Component.OBServerList.Disk">数据盘</UI-TERM>** 信息。

   <main id="notice" type='explain'>
    <h4>说明</h4>
    <ul>
    <li>当对条件范围不进行设置时，才会展示 <strong>CPU</strong> 和 <strong>内存</strong> 的资源使用趋势图。</li>
    <li>当租户所属集群为 V4.0 及以上版本时，不展示 <strong>分区副本</strong> 的资源使用趋势图。</li>
    <li>当租户所属集群为 V4.0 及以上版本时，不展示 <strong>日志盘</strong> 的资源使用趋势图。</li>
    </ul>
   </main>

## 排行榜

可根据 **<UI-TERM key="ocp-v2.Detail.Resource.Trend.Data">数据量</UI-TERM>** 或 **<UI-TERM key="ocp-v2.Detail.Resource.Top.DiskUsage">磁盘占用量</UI-TERM>** 对数据库和表组进行排序。单击 **<UI-TERM key="ocp-v2.Detail.Backup.Details">详情</UI-TERM>** 或数据库名称，可查看表数据信息分布详情。
