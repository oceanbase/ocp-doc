# 管理 Unit 规格

在租户总览页面单击 Unit 规格管理，可进行新增 Unit 规格、修改规格和删除规格的操作。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **集群维护** 或 **租户维护** 资源权限。
* 租户 **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概览</UI-TERM>** 菜单权限。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏选择 **<UI-TERM key="ocp-v2.src.constant.plan.Tenant">租户</UI-TERM>** ，系统默认进入 **<UI-TERM key="ocp-v2.component.TenantList.TenantList">租户列表</UI-TERM>** 页签。

3. 切换至 **<UI-TERM key="ocp-v2.Tenant.New.UnitSpecifications">Unit 规格</UI-TERM>** 页签，进入 **<UI-TERM key="ocp-v2.Tenant.UnitSpec.UnitList">Unit 规格列表</UI-TERM>** 页面。

   在 **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.UnitList">Unit 列表</UI-TERM>** 中，可查看所有 Unit 的 **<UI-TERM key="ocp-v2.Tenant.UnitSpec.Specification">规格名</UI-TERM>**、**<UI-TERM key="ocp-v2.Tenant.UnitSpec.CpuCores">CPU 核数</UI-TERM>**、**<UI-TERM key="ocp-v2.Tenant.UnitSpec.MemoryGb">内存（GiB）</UI-TERM>**、**<UI-TERM key="ocp-v2.src.component.AddUnitSpecModal.LogDiskGb">日志盘（GiB）</UI-TERM>**、**IOPS**、**<UI-TERM key="ocp-v2.Tenant.UnitSpec.Type">规格类型</UI-TERM>** 和 **<UI-TERM key="ocp-v2.Settings.Credential.Cluster.Operation">操作</UI-TERM>** 信息。

   * 可根据 **<UI-TERM key="ocp-v2.Host.Detail.Basic.CpuCores">CPU 核数</UI-TERM>**、**<UI-TERM key="ocp-v2.Tenant.UnitSpec.MemoryGb">内存（GiB）</UI-TERM>**、**<UI-TERM key="ocp-v2.src.component.AddUnitSpecModal.LogDiskGb">日志盘（GiB）</UI-TERM>**、**IOPS** 大小对规格进行排序。

   * 可根据 **<UI-TERM key="ocp-v2.Tenant.UnitSpec.Type">规格类型</UI-TERM>** 对规格进行筛选，规格类型包括 **<UI-TERM key="ocp-v2.src.constant.oceanbase.Default">系统默认</UI-TERM>** 和 **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.Custom">自定义</UI-TERM>** 。

   * 操作包括： **<UI-TERM key="ocp-v2.Auth.User.Editing">编辑</UI-TERM>** 和 **<UI-TERM key="ocp-v2.component.ZoneFormCardList.Delete">删除</UI-TERM>** 。

    <main id="notice" type='explain'>
    <h4>说明</h4>
    <p>当租户所属集群为 V4.0 以下版本时，不支持查看或修改 <b>日志盘（GiB）</b> 列及 <b>IOPS</b> 列信息。</p>
    </main>

   ![image.png](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/unit%E8%A7%84%E6%A0%BC%E5%88%97%E8%A1%A8.png)

4. 单击 **<UI-TERM key="ocp-v2.Tenant.UnitSpec.NewUnitSpecifications">新增 Unit 规格</UI-TERM>** ，填写 **规格名称、 CPU（核）** 和 **<UI-TERM key="ocp-v2.src.component.AddUnitSpecModal.MemoryGb">内存（GiB）</UI-TERM>** 。

   具体参数说明如下。

   |  参数  |  说明  |
   |--------|--------|
   |  规格名称  |  填写待新增的 Unit 规格名称。   |
   |  CPU  |  配置 Unit 规格的 CPU（核）数，CPU 的最小配置核数为 0.5 核，请输入 0.5 的整倍数。<br>当租户所属集群为 V4.0 及以上版本时，支持通过 **<UI-TERM key="ocp-v2.src.component.AddUnitSpecModal.AdvancedCpuSettings">CPU 高级设置</UI-TERM>** 对 CPU 超卖进行分配。开启高级设置后，可分别配置最小 CPU（核）数和最大 CPU（核）数。<main id="notice" type='explain'><h4>说明</h4><p>当租户所属集群为 V4.0 及以上版本时，不支持选择 1C 以下的 CPU 规格。</p></main>   |
   |  内存  |  配置 Unit 规格的内存（GiB），内存的最小配置大小为 1 GiB，请输入 1 的整倍数。   |
   |  更多配置（可选）  | 填写 **<UI-TERM key="ocp-v2.src.component.AddUnitSpecModal.LogDiskGb">日志盘（GiB）</UI-TERM>** 和 **IOPS** 配置信息。<main id="notice" type='explain'><h4>说明</h4><p>当租户所属集群为 V4.0 以下版本时，不支持配置 <b>日志盘（GiB）</b> 和 <b>IOPS</b> 信息。</p></main>   |
