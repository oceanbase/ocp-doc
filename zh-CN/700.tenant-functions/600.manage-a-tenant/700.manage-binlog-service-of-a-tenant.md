# 管理租户 Binlog 服务

Binlog 服务是用于收集 OceanBase 的事务日志并转换为 MySQL Binlog 的服务。您可参考本节内容，对租户的 Binlog 服务进行管理，包括如何开通/关闭 Binlog 服务、如何修改 Binlog 配置，以及如何删除租户 Binlog 服务。

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **集群维护** 或 **租户维护** 资源权限。
  * 租户 **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概览</UI-TERM>** 菜单权限。

* 仅支持 **<UI-TERM key="ocp-v2.src.constant.compute.NormalOperation">正常运行</UI-TERM>** 状态的租户开通 Binlog 服务。
* 租户所属集群 V3.x 版本要求不低于 V3.2.4.4；V4.x 版本要求不低于 V4.1.0.2。

## 开通 Binlog 服务

1. 登录 OCP。

2. 在左侧导航栏选择 **<UI-TERM key="ocp-v2.src.constant.plan.Tenant">租户</UI-TERM>** ，系统默认进入 **<UI-TERM key="ocp-v2.page.Tenant.TenantList">租户列表</UI-TERM>** 页签。

3. 在 **<UI-TERM key="ocp-v2.component.TenantList.TenantList">租户列表</UI-TERM>** 中选择待操作的租户并单击其租户名，进入租户 **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概览</UI-TERM>** 页面。

4. 在 **<UI-TERM key="ocp-v2.Alarm.Event.Detail.BasicInformation">基本信息</UI-TERM>** 模块，单击 Binlog 服务后的 **<UI-TERM key="ocp-v2.Component.BinlogService.Activate">开通</UI-TERM>**。

5. 在对话框中配置如下信息。

    | 参数               | 说明                |
    |--------------------|--------------|
    | 关联 Binlog 集群    |  为租户选择关联的 Binlog 集群，仅支持选择运行中的 Binlog 集群。  |
    | 关联 OBProxy 集群   |  选择该租户已关联的 OBProxy 集群，OBProxy 版本号需大于等于 V4.2.1.0。  |
    | 保留时长（小时）    |  本租户 Binlog 日志保存的时长，超过此时长日志文件会启动自动清理。请输入大于等于 1 的整数，上限为 8760。 |
    | 磁盘空间上限（GiB） |  本租户 Binlog 日志占用空间保护值，超过此值日志文件会启动自动清理。请输入大于等于 1 的整数，上限为 102400。 |
    | 实例副本数          |  为租户配置实例副本。Binlog 服务会基于本集群 Binlog Server 数量自动分布实例副本，建议 1 个 Binlog Server 仅承载业务租户的 1 个 Binlog 实例副本，同时单个业务租户最大支持 5 个实例副本。 |
    | 配置 Binlog 起始点  |  支持选择特定时间作为起始点位创建 Binlog 实例，用于转换历史时刻的事务日志。请务必保障您所选择的时间所在的 Clog 文件存在并处于有效状态，否则会造成 Binlog 实例创建失败。若您不做选择，则默认按照当前时间作为起始位点创建 Binlog 实例。  |

## 其它操作

Binlog 服务开通后，您可以根据业务需要对租户的 Binlog 服务进行其它操作，如修改 Binlog 配置、查看 Binlog 实例和关闭 Binlog 服务。

* 单击 **<UI-TERM key="ocp-v2.page.Binlog.BinlogService">Binlog 服务</UI-TERM>** 后的 **<UI-TERM key="ocp-v2.page.Credential.Binlog.Operation">操作</UI-TERM>** > **<UI-TERM key="ocp-v2.Component.BinlogService.ModifyBinlogConfiguration">修改 Binlog 配置</UI-TERM>** ，支持修改关联的 OBProxy 集群、Binlog 的保留时长（小时）和磁盘空间上限（GiB）。
* 单击 **<UI-TERM key="ocp-v2.Detail.Overview.BinlogService">Binlog 服务</UI-TERM>** 后的 **<UI-TERM key="ocp-v2.Detail.Component.LinkList.Operation">操作</UI-TERM>** > **<UI-TERM key="ocp-v2.Component.BinlogService.ViewBinlogInstances">查看 Binlog 实例</UI-TERM>** ，可跳转至 Binlog 实例概览页，查看实例的详细信息，详情可参考 [查看 Binlog 实例](../../820.binlog-service-fuctions/400.manage-binlog-instance/100.binlog-instance-overview.md)。
* 单击 **<UI-TERM key="ocp-v2.page.Binlog.BinlogService">Binlog 服务</UI-TERM>** 后的 **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.Operation">操作</UI-TERM>** > **<UI-TERM key="ocp-v2.Component.BinlogService.DisableBinlogService">关闭 Binlog 服务</UI-TERM>** ，可以关闭 Binlog 服务。Binlog 服务关闭后，已生成的日志文件会全部删除，其占用的存储空间也会被释放。
