# 修改租户白名单

本页面为您介绍修改租户白名单的操作。

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **集群维护** 或 **租户维护** 资源权限。
  * 租户 **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概览</UI-TERM>** 菜单权限。

* 仅主租户支持修改租户白名单。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏选择 **<UI-TERM key="ocp-v2.src.constant.monitor.Tenant">租户</UI-TERM>** ，系统默认进入 **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">租户列表</UI-TERM>** 页签。

3. 在 **<UI-TERM key="ocp-v2.component.TenantList.TenantList">租户列表</UI-TERM>** 中选择待操作的租户并单击其租户名，进入租户 **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概览</UI-TERM>** 页面。

4. 在 **<UI-TERM key="ocp-v2.Detail.Component.CloneTenantModal.Whitelist">白名单</UI-TERM>** 模块，单击 **<UI-TERM key="ocp-v2.Compaction.Settings.Modify">修改</UI-TERM>** 。

5. 在弹出框中进行白名单设置。

   * 所有 IP 都可访问：所有的 IP 都可访问该租户。

      <main id="notice" type='notice'>
      <h4>注意</h4>
      <p>此方式存在访问安全风险，请谨慎操作。</p>
      </main>

   * 自定义：指定允许登陆的客户端列表，支持的格式有 IP 地址、IP 段、子网/掩码、模糊匹配、多种格式混合和特殊说明。示例如下：

     |   格式       |     示例     |
     |--------------|--------------|
     | IP 地址      | xxx.xxx.xxx.1,xxx.xxx.xxx.2    |
     | IP 段      | xxx.xxx.xxx.1-3  <main id="notice" type='explain'><h4>说明</h4><p><ul><li>xxx.xxx.xxx.1-3 代表同时增加 xxx.xxx.xxx.1、xxx.xxx.xxx.2、xxx.xxx.xxx.3 3 个 IP 地址。</li><li>仅 IPV4 网络支持添加 IP 段，IPV6 网络暂不支持。</li></ul></p></main>  |
     | 子网/掩码    | xxx.xxx.xxx.1/24     |
     | 模糊匹配     | xxx.xxx.xxx.% 或 xxx.xxx.xxx._   |
     | 多种格式混合 | xxx.xxx.xxx.1,xxx.xxx.xxx.2,xxx.xxx.xxx.%,xxx.xxx.xxx._,xxx.xxx.xxx.1/24 |
     | 特殊说明     | % 表示所有客户端都可以连接      |

6. 单击 **<UI-TERM key="ocp-v2.Detail.Component.SwitchoverModal.Determine">确定</UI-TERM>**，完成修改。
