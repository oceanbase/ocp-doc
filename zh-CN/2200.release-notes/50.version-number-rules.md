# 版本号规则

本文主要介绍 OCP 的版本号规则及其含义。

随着 OCP 的不断迭代和优化，OCP 会不定期发布新的版本。不同版本的 OCP 在功能及特性方面的差异可能会很大，因此需要识别 OCP 版本号，以便获取准确的文档信息。

OCP 的版本格式通过 V.x.y.z-t 表示，其中：

* x 表示主要的大版本。该版本通常会有架构升级或较大的新功能发布。

* y 表示计划迭代版本。该版本是正常迭代计划，包含重要功能或特性更新和提升。

* z 表示发布更新版本。该版本包含少量功能或特性更新，以及对已知问题进行修复。

* t 通常以发布的日期时间字符串进行展示，例如，4.3.2-20241011163611 等，针对因功能特性或修复问题需要发布高版本号的场景。

## 查看版本号

部署 OCP 后，您可以通过下述操作查看当前 OCP 的版本号。

1. 登录 OCP。

2. 鼠标悬停至右上角的 **帮助**，单击 **关于 OCP**。

3. 在弹出框中，查看当前 OCP 的版本号。例如，版本号为 4.3.2-20241011163611。
