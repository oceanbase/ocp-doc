# 添加主机

在创建集群之前，需要将用到的主机添加到 OCP 中。创建 1-1-1 的集群，需要添加 4 台主机。3 个 Zone 每一个占用一台主机，OBProxy 占用一台主机。

## 前提条件

当前登录 OCP 的用户为 **ADMIN** 角色或 **ORG_ADMIN** 角色。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏中单击 **<UI-TERM key="ocp-v2.component.AddChartDrawer.ChartConfigPanel.Host">主机</UI-TERM>**。

3. 在 **主机** 页签中，单击页面右上角的 **<UI-TERM key="ocp-v2.component.HostSelect.AddHost">添加主机</UI-TERM>** 。

4. 填写 **<UI-TERM key="ocp-v2.src.component.AddHostDrawer.IpAddress">IP 地址</UI-TERM>** 和 **SSH 端口号** 。输入新主机的 IPv4/IPv6 地址，支持同时添加多个 IP 地址（多个 IP 之间用英文逗号分隔）；SSH 端口号默认 22。

   <main id="notice" type='notice'>
   <h4>注意</h4>
   <p>当主机 IP 为 IPv6 地址时，具有如下版本要求：
   <ul>
   <li>OceanBase 版本为 [V4.2.5 BP3 Hotfix3, V4.3.0)、[4.3.5 BP2 Hotfix1, +∞)。</li>
   <li>OBClient 版本为 [V2.2.9, +∞)</li>
   <li>OBProxy 版本为 [V4.3.4, +∞)</li>
   </ul>
   </p>
   </main>

5. 选择机型。如果没有对应的机型，可以单击 **<UI-TERM key="ocp-v2.src.component.HostTypeSelect.NewModel">新增机型</UI-TERM>**，立即在 OCP 中新增机型。

   更多操作详情，可参考 [管理机型](../200.manage-host-type.md)。

6. 选择机房。如果没有对应的机房，可以单击 **<UI-TERM key="ocp-v2.src.component.IdcSelect.NewDataCenter">新增机房</UI-TERM>**，立即在 OCP 中新增机房。

   更多操作详情，可参考 [管理机房](../300.manage-idc.md) 和 [管理区域](../400.mange-region.md)。

7. 选择主机类型，并为主机选择连接凭据和设置主机别名。

   | 参数  |   说明   |
   |-------|----------|
   | 主机类型  |  选择所添加主机的类型，包括物理机与 ECS。  |
   | 凭据  |  选择密码箱中的凭据，如果没有对应的凭据，可以单击 **<UI-TERM key="ocp-v2.src.component.CredentialSelect.AddSecrets">新增凭据</UI-TERM>** 为该主机创建新的连接凭据。<br><ul><li>凭据名：以英文字母开头、英文或数字结尾，可包含英文、数字和下划线，且长度为 2 \~ 32。</li><li>授权类型：包含 **用户名/密码**、**SSH 私钥** 和 **已配置免密** 三种方式。</li><li>用户类型：连接服务器的用户类型，支持 **root 用户** 及 **普通用户** 两种。<ul><li>**root 用户**：拥有 ROOT 权限的 SSH 用户。</li><li>**普通用户**：拥有 ROOT 权限的普通用户，该用户须先配置免密执行 sudo 指令。OCP 目前仅支持配置所有指令免密执行 sudo，即在 `/etc/sudoers` 文件中，添加 `username ALL=(ALL) NOPASSWD:ALL`。</li></ul></li><li>用户名：当用户类型为 **普通用户** 时填写，填写连接服务器的用户。</li><li>密码：当授权类型为 **用户名/密码** 时填写，填写连接服务器的密码。</li><li>私钥：当授权类型为 **SSH 私钥** 时填写，为服务器添加 SSH 凭证。</li><li>OCP 主机私钥文件路径：当授权类型为 **已配置免密** 时填写，填写主机私钥文件的存放路径，默认为 `/home/admin/.ssh/id_rsa`。若 OCP 部署方式为 Docker，私钥文件请使用 Docker 内的文件路径。</li><li>说明：为凭据补充额外信息。</li></ul> |
   | 主机别名  | 选填，为主机设置其它名称。   |

8. （可选）填写主机说明。

9. 单击 **<UI-TERM key="ocp-v2.page.Information.Ok">确定</UI-TERM>** 。

<main id="notice" type='explain'>
<h4>说明</h4>
<p>若您需要自定义 agent 的端口号，可联系 OCP 技术支持团队协助处理。</p>
</main>
