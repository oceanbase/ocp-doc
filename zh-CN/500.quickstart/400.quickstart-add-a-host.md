# 添加主机

在创建集群之前，需要将用到的主机添加到 OCP 中。创建 1-1-1 的集群，需要添加 4 台主机。3 个 Zone 每一个占用一台主机，OBProxy 占用一台主机。

## 前提条件

当前登录 OCP 的用户为 **ADMIN** 角色或 **ORG_ADMIN** 角色。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏中单击 **<UI-TERM key="ocp-v2.component.AddChartDrawer.ChartConfigPanel.Host">主机</UI-TERM>**。

3. 在 **主机** 页签中，单击页面右上角的 **<UI-TERM key="ocp-v2.component.HostSelect.AddHost">添加主机</UI-TERM>** 。

4. 填写 **<UI-TERM key="ocp-v2.src.component.AddHostDrawer.IpAddress">IP 地址</UI-TERM>** 和 **SSH 端口号** 。输入新主机的 IPv4/IPv6 地址，支持同时添加多个 IP 地址（多个 IP 之间用英文逗号分隔）；SSH 端口号默认 22。

   <main id="notice" type='notice'>
   <h4>注意</h4>
   <p>当主机 IP 为 IPv6 地址时，具有如下限制：<ul>
   <li>部署 OceanBase、OBClient 和 OBProxy 时：<ul>
   <li>OceanBase 版本须为 [V4.2.5 BP3 Hotfix3, V4.3.0) 或 [V4.3.5 BP2 Hotfix1, +∞)。</li>
   <li>OBClient 版本须为 [V2.2.9, +∞)。</li>
   <li>OBProxy 版本须为 [V4.3.4, +∞)。</li>
   </ul></li></ul>
   <ul><li>Binlog 服务暂不支持 IPv6 部署。</li></ul>
   </ul>
   </p>
   </main>

5. 选择机型。如果没有对应的机型，可以单击 **<UI-TERM key="ocp-v2.src.component.HostTypeSelect.NewModel">新增机型</UI-TERM>**，立即在 OCP 中新增机型。

   更多操作详情，可参考 [管理机型](../850.host-features/200.manage-host-type.md)。

6. 选择机房。如果没有对应的机房，可以单击 **<UI-TERM key="ocp-v2.src.component.IdcSelect.NewDataCenter">新增机房</UI-TERM>**，立即在 OCP 中新增机房。

   更多操作详情，可参考 [管理机房](../850.host-features/300.manage-idc.md) 和 [管理区域](../850.host-features/400.mange-region.md)。

7. 选择主机类型，并为主机选择连接凭据和设置主机别名。

   | 参数  |   说明   |
   |-------|----------|
   | 主机类型  |  选择所添加主机的类型，包括物理机与 ECS。  |
   | 凭据  |  选择密码箱中的凭据，如果没有对应的凭据，可以单击 **<UI-TERM key="ocp-v2.src.component.CredentialSelect.AddSecrets">新增凭据</UI-TERM>** 为该主机创建新的连接凭据。<br><ul><li>凭据名：以英文字母开头、英文或数字结尾，可包含英文、数字和下划线，且长度为 2 \~ 32。</li><li>授权类型：包含 **用户名/密码**、**SSH 私钥** 和 **已配置免密** 三种方式。</li><li>用户类型：连接服务器的用户类型，支持 **root 用户** 及 **普通用户** 两种。<ul><li>**root 用户**：拥有 ROOT 权限的 SSH 用户。</li><li>**普通用户**：拥有 ROOT 权限的普通用户，该用户需先在 `/etc/sudoers` 文件中对部分指令配置免密执行 sudo，详情可参考文末的 **配置 sudo 权限**。</li></ul></li><li>用户名：当用户类型为 **普通用户** 时填写，填写连接服务器的用户。</li><li>密码：当授权类型为 **用户名/密码** 时填写，填写连接服务器的密码。</li><li>私钥：当授权类型为 **SSH 私钥** 时填写，为服务器添加 SSH 凭证。</li><li>OCP 主机私钥文件路径：当授权类型为 **已配置免密** 时填写，填写主机私钥文件的存放路径，默认为 `/home/admin/.ssh/id_rsa`。若 OCP 部署方式为 Docker，私钥文件请使用 Docker 内的文件路径。</li><li>说明：为凭据补充额外信息。</li></ul> |
   | 主机别名  | 选填，为主机设置其它名称。   |

8. （可选）填写主机说明。

9. 单击 **<UI-TERM key="ocp-v2.page.Information.Ok">确定</UI-TERM>** 。

<main id="notice" type='explain'>
<h4>说明</h4>
<p>若您需要自定义 agent 的端口号，可联系 OCP 技术支持团队协助处理。</p>
</main>

## 配置 sudo 权限

请参考如下命令为相关指令配置免密执行 sudo：

```shell
#杀进程
Cmnd_Alias KILL_CMD = /bin/kill -9 *
#查看端口占用
Cmnd_Alias NETSTAT_CMD = /bin/netstat -ant
#动态修改 agent 配置
Cmnd_Alias AGENT_CONFIG_UPDATE = /home/admin/ocp_agent*/bin/ocp_agentctl -c /home/admin/ocp_agent*/conf/agentctl.yaml config --update *
#重启 agent 进程
Cmnd_Alias AGENT_RESTART = /home/admin/ocp_agent*/bin/ocp_agentctl restart
#启动 agent 进程
Cmnd_Alias AGENT_START = /home/admin/ocp_agent*/bin/ocp_agentctl start
#删除目录
Cmnd_Alias RM_CMD = /bin/rm -rf */tmp/*, /bin/rm -rf */home/admin/ocp_agent*/*
#拷贝软件包
Cmnd_Alias CP_CMD = /bin/cp -r */tmp/* */home/admin/ocp_agent/pkg_store*
#RPM操作
Cmnd_Alias RPM_CMD = /bin/rpm *, /bin/rpm -Uvh *, /bin/rpm -e *
#下载软件包
Cmnd_Alias CURL_CMD = /usr/bin/curl -s -S -k -o /tmp/* *
# 校验文件
Cmnd_Alias SHA1SUM_CMD = /usr/bin/sha1sum *
# Agent 服务管理
Cmnd_Alias AGENT_SERVICE_CMD = /home/admin/ocp_agent*/bin/ocp_agentctl service start *, /home/admin/ocp_agent*/bin/ocp_agentctl service stop *

# debian 系统专用
test ALL=(ALL) NOPASSWD: /usr/bin/install -D * *
# debian 系统专用
test ALL=(ALL) NOPASSWD: /usr/bin/alien -k -i *
# debian 系统专用
test ALL=(ALL) NOPASSWD: /usr/bin/dpkg -P *

# 用户权限配置
test ALL=(ALL) NOPASSWD:KILL_CMD, NETSTAT_CMD, AGENT_CONFIG_UPDATE, AGENT_START, AGENT_RESTART, RM_CMD, CP_CMD, RPM_CMD, CURL_CMD, SHA1SUM_CMD, AGENT_SERVICE_CMD
```
