# 编辑标签

当标签中的信息需要进行更新时，您可参考本节修改标签信息。

<main id="notice" type='explain'>
<h4>说明</h4>
<p>当标签已被引用时，修改标签后，对应对象上的标签会随之改变。</p>
</main>

## 前提条件

请确保当前登录 OCP 的用户为 ADMIN 角色。

## 操作步骤

以下操作步骤以 **系统管理 > 标签管理** 入口为例。

1. 登录 OCP。

2. 在左侧导航栏中单击 **系统管理 > 标签管理** 。

3. 在 **<UI-TERM key="ocp-v2.src.constant.auth.Label">标签</UI-TERM>** 列表中选择需要修改的标签，或在上方搜索栏中填写标签关键字进行搜索，列表中将显示符合条件的标签。

4. 单击要修改的标签 **<UI-TERM key="ocp-v2.Plan.Component.PlanTemplateTable.Operation">操作</UI-TERM>** 列的 **<UI-TERM key="ocp-v2.Alarm.Channel.Editing">编辑</UI-TERM>** 按钮。

5. 在面板中修改标签信息，并单击 **<UI-TERM key="ocp-v2.component.ParameterTemplate.ParameterTemplateDropdown.Ok">确定</UI-TERM>**。

    标签相关参数说明可参考 [新建标签](200.create-a-tag.md)。
