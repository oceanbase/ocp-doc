# 上传证书

<main id="notice" type='notice'>
<h4>功能适用性</h4>
<p>该内容仅适用于 OCP 企业版，OCP 社区版不提供此功能。</p>
</main>

为了方便用户管理证书，OCP 提供证书管理功能，用于存储和管理证书文件。用户在 OCP 上传证书文件和私钥文件，即 CA 证书、Server 证书和 Server 证书私钥，该 3 个文件为一组证书文件，要求三个文件都以 `pem` 作为后缀。

## 前提条件

* 请确保当前登录 OCP 的用户为 **ADMIN** 角色或 **ORG_ADMIN** 角色。

* 若启用同一集群内 SSL 链路加密，请确保集群内 OceanBase 和 OBProxy 的根证书 `ca.pem` 保持一致。

## 操作步骤

1. 登录 OCP。

2. 单击左侧导航栏 **系统管理** \> **证书管理** ，进入 **证书管理** 页面。

3. 单击右上角 **上传证书** 。

4. 在对话框中填写或选择如下信息。

    | 信息     | 说明   |
    |----------|--------|
    | 证书名称 | 证书名称具有唯一性。<ul><li>仅支持以英文字母开头，英文字母或数字结尾。</li><li>支持 2 ~ 32 个字符。</li><li>特殊符号仅支持下划线。</li></ul>  |
    | 上传证书 | 每次最多支持上传三个 pem 文件，请确保上传的证书文件有效且符合 OBProxy 和 OceanBase 数据库使用规范，且必须包含 CA 证书、Server 证书和 Server 证书私钥，否则 SSL 链路加密可能失败。  |
    | 备注     | 为上传的证书添加额外说明。 |

5. 单击 **上传** 。
