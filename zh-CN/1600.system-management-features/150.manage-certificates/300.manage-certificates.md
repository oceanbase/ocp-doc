# 删除证书

<main id="notice" type='notice'>
<h4>功能适用性</h4>
<p>该内容仅适用于 OCP 企业版，OCP 社区版不提供此功能。</p>
</main>

您可参考本页面删除已上传的证书。证书删除后，对应的文件将从此证书中移除，仍在有效期中的文件，可在新证书中重新上传。

## 前提条件

* 请确保当前登录 OCP 的用户为 **ADMIN** 角色或 **ORG_ADMIN** 角色。

* 当证书存在使用对象时，暂不支持删除。若需要删除，请先关闭对应集群的 SSL 链路加密，详情可参考 [管理 OceanBase 集群 SSL 链路加密](../../600.cluster-functions/1200.manage-security-configuration/100.manage-ssl-link-encryption-of-an-ob-cluster.md) 和 [管理 OBProxy 集群 SSL 链路加密](../../800.obproxy-functions/550.manage-ssl-link-encryption-of-an-obproxy-cluster.md)。

## 操作步骤

1. 登录 OCP。

2. 单击左导航栏 **系统管理** \> **证书管理**，进入 **证书管理** 页面。

3. 选择待删除的证书，单击操作栏的 **删除** 。

4. 在对话框中单击 **删除** 。
