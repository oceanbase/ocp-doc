# 复制用户

如需创建与已有用户 A 配置大致相同的用户 B，可通过复制用户的方法来快速创建新的用户。

## 前提条件

* 请确保当前登录 OCP 的用户为 **ADMIN** 角色或 **ORG_ADMIN** 角色。
* 仅 **ADMIN** 角色支持复制 admin 用户。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏中单击 **系统管理 > 用户管理** 。

3. 在 **<UI-TERM key="ocp-v2.Auth.User.New.User">用户</UI-TERM>** 页签单击用户列表 **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.Operation">操作</UI-TERM>** 列的 **更多 > 复制** 。

   参考 [创建用户](100.create-a-user.md) 小节中的参数说明，重新定义部分用户信息。

   其中 **<UI-TERM key="ocp-v2.Backup.Component.BackupNowTenantDrawer.BasicInformation">基础信息</UI-TERM>** 的 **<UI-TERM key="ocp-v2.Auth.User.loginHistory.UserName">用户名</UI-TERM>** 、**<UI-TERM key="ocp-v2.src.component.AddBinlogCredentialModal.Password">密码</UI-TERM>** 和 **<UI-TERM key="ocp-v2.Auth.User.New.Mailbox">邮箱</UI-TERM>** 必须重定义。

4. 单击 **<UI-TERM key="ocp-v2.Detail.Component.AddUserDrawer.Submitted">提交</UI-TERM>** 。

   系统新建与 A 用户角色或访问控制一样的 B 用户。
