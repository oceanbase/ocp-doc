# 查看登录历史

本节介绍如何查看用户在指定时间范围内的登录信息、客户端信息、登录结果、是否触发自动锁定情况。

## 前提条件

请确保当前登录 OCP 的用户为 **ADMIN** 角色、 **ADMIN_VIEWER** 角色或 **ORG_ADMIN** 角色。

## 操作步骤

1. 单击左导航栏 **系统管理 > 用户管理**，进入 **<UI-TERM key="ocp-v2.Detail.Session.List.User">用户</UI-TERM>** 页签，在 **<UI-TERM key="ocp-v2.SQLDiagnosis.attributes.slowSqlAttributes.User">用户</UI-TERM>** 页签中右上角选择 **<UI-TERM key="ocp-v2.Auth.User.loginHistory.LogonHistory">登录历史</UI-TERM>** 。

2. 在 **<UI-TERM key="ocp-v2.Credential.Component.ImportModal.Username">用户名</UI-TERM>** 下拉框中选择想要查看的用户。

3. 在 **<UI-TERM key="ocp-v2.Auth.User.loginHistory.LogonTime">登录时间</UI-TERM>** 中选择时间区间。

4. 单击 **<UI-TERM key="ocp-v2.page.QueryLog.Query">查询</UI-TERM>**，**<UI-TERM key="ocp-v2.Auth.User.loginHistory.LogonList">登录列表</UI-TERM>** 中返回所有符合查询条件的用户。

   * 您可在 **<UI-TERM key="ocp-v2.Auth.User.loginHistory.LogonList">登录列表</UI-TERM>** 中查看 **<UI-TERM key="ocp-v2.Component.LBLoadBalanceConditon.Username">用户名</UI-TERM>**、**<UI-TERM key="ocp-v2.Auth.User.loginHistory.IpSource">IP 来源</UI-TERM>**、**<UI-TERM key="ocp-v2.Auth.User.loginHistory.Client">客户端</UI-TERM>**、**<UI-TERM key="ocp-v2.Auth.User.loginHistory.LogonTime">登录时间</UI-TERM>**、**<UI-TERM key="ocp-v2.Auth.User.loginHistory.LogonResult">登录结果</UI-TERM>** 和 **<UI-TERM key="ocp-v2.Auth.User.loginHistory.AutomaticallyLockAccounts">自动锁定账号</UI-TERM>** 情况。

      ![05101553](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/434/12091440.png)

   * 您可单击 **<UI-TERM key="ocp-v2.Auth.User.loginHistory.LogonList">登录列表</UI-TERM>** 中的用户名，系统跳转到用户详情页，用户详情页也可参考 [查看用户](200.view-the-user-details-page.md) 理解。
