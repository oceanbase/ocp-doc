# 编辑用户

本节介绍如何修改用户信息。

## 前提条件

* 请确保当前登录 OCP 的用户为 **ADMIN** 角色或 **ORG_ADMIN** 角色。
* 仅 **ADMIN** 角色支持修改 admin 用户信息。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏中单击 **系统管理 > 用户管理** 。

3. 在 **<UI-TERM key="ocp-v2.Oracle.Component.AddOracleUserOrRoleDrawer.User">用户</UI-TERM>** 页签单击用户列表 **<UI-TERM key="ocp-v2.Component.ServiceName.Operation">操作</UI-TERM>** 列的 **<UI-TERM key="ocp-v2.src.constant.credential.Edit">编辑</UI-TERM>** 。

   参考 [创建用户](100.create-a-user.md) 小节中的参数说明重新编辑用户信息。

   <main id="notice" type='explain'>
   <h4>说明</h4>
   <p><b>用户名</b> 不支持修改。</p>
   </main>

4. 单击 **<UI-TERM key="ocp-v2.Inspection.Item.ConfigRule.Submit">提交</UI-TERM>** 。
