# 编辑凭据

本节介绍如何编辑凭据。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **集群维护**、**租户维护**、**OBProxy 维护**、**Binlog 服务维护** 或 **主机维护** 任一资源权限。
* 系统管理 **<UI-TERM key="ocp-v2.page.Credential.CredentialManagement">凭据管理</UI-TERM>** 菜单权限。

## 操作步骤

1. 登录 OCP。

2. 单击左导航栏 **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">系统管理</UI-TERM>** \> **<UI-TERM key="ocp-v2.src.component.AddHostCredentialDrawer.CredentialManagement">凭据管理</UI-TERM>**，进入凭据列表页面。

3. 找到要修改的凭据，单击该凭据 **<UI-TERM key="ocp-v2.page.MultiCluster.Parameter.Operation">操作</UI-TERM>** 列的 **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.Edit">编辑</UI-TERM>**。

4. 在弹出的 **<UI-TERM key="ocp-v2.src.component.AddBinlogCredentialModal.EditCredentials">编辑凭据</UI-TERM>** 对话框中修改凭据信息。

    | **<UI-TERM key="ocp-v2.Statistics.components.TaskTable.ObjectType">对象类型</UI-TERM>** | **可编辑内容** |
    | --- | --- |
    | OceanBase 集群 | 编辑凭据的 **<UI-TERM key="ocp-v2.src.component.AddHostCredentialDrawer.Password">密码</UI-TERM>** 和 **<UI-TERM key="ocp-v2.MultiAzone.Parameter.Description">说明</UI-TERM>**。 |
    | OBProxy 集群 | 编辑凭据的 **<UI-TERM key="ocp-v2.src.component.AddOBProxyCredentialModal.Password">密码</UI-TERM>** 和 **<UI-TERM key="ocp-v2.page.Host.Description">说明</UI-TERM>**。 |
    | 主机 | 编辑凭证信息。包括 **<UI-TERM key="ocp-v2.Credential.Component.ImportModal.CredentialName">凭据名</UI-TERM>**、**<UI-TERM key="ocp-v2.src.component.AddHostCredentialDrawer.UserType">用户类型</UI-TERM>**、**<UI-TERM key="ocp-v2.page.Settings.Profile.UserName">用户名</UI-TERM>**、**<UI-TERM key="ocp-v2.Auth.User.New.Password">密码</UI-TERM>**、**<UI-TERM key="ocp-v2.src.component.AddHostCredentialDrawer.ApplicationHost">应用主机</UI-TERM>** 和 **<UI-TERM key="ocp-v2.Detail.LoadBalance.AddObproxyLoadBalanceAppDrawer.Description">说明</UI-TERM>**。 |

5. 单击 **<UI-TERM key="ocp-v2.Component.ZoneList.EditZoneModal.Ok">确定</UI-TERM>**。
