# 批量操作连接凭证

本节介绍如何批量验证、批量导出和批量删除连接凭证。

## 前提条件

* **<UI-TERM key="ocp-v2.Credential.Component.FilterBar.BatchVerification">批量验证</UI-TERM>** 和 **<UI-TERM key="ocp-v2.Credential.Component.FilterBar.BatchExport">批量导出</UI-TERM>** 时，请确保当前登录 OCP 的用户具备如下权限：

  * **集群只读**、**租户只读**、**OBProxy 只读**、**Binlog 服务只读** 或 **主机只读** 任一资源权限。
  * 系统管理 **<UI-TERM key="ocp-v2.page.Credential.CredentialManagement">凭据管理</UI-TERM>** 菜单权限。

* **<UI-TERM key="ocp-v2.page.Host.BatchDelete">批量删除</UI-TERM>** 时，请确保当前登录 OCP 的用户具备如下权限：

  * **集群维护**、**租户维护**、**OBProxy 维护**、**Binlog 服务维护** 或 **主机维护** 任一资源权限。
  * 系统管理 **<UI-TERM key="ocp-v2.src.component.AddOBCredentialModal.CredentialManagement">凭据管理</UI-TERM>** 菜单权限。

## 操作步骤

1. 登录 OCP。

2. 单击左导航栏 **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">系统管理</UI-TERM>** \> **<UI-TERM key="ocp-v2.src.hook.useMenu.CredentialManagement">凭据管理</UI-TERM>**，进入凭据列表页面。

3. 在 **OceanBase**、**OBProxy** 或 **<UI-TERM key="ocp-v2.src.component.AddArbitrationDrawer.Host">主机</UI-TERM>** 页签中勾选要批量操作的凭据对象。

4. 单击需要操作的类型。

   包括 **<UI-TERM key="ocp-v2.Credential.Component.FilterBar.BatchVerification">批量验证</UI-TERM>**、**<UI-TERM key="ocp-v2.Credential.Component.FilterBar.BatchExport">批量导出</UI-TERM>** 和 **<UI-TERM key="ocp-v2.Alarm.Rule.BatchDeletion">批量删除</UI-TERM>**。

   * 批量验证：单击 **批量测试**，可批量测试凭据是否连接成功。

   * 批量导出：单击 **<UI-TERM key="ocp-v2.Credential.Component.FilterBar.BatchExport">批量导出</UI-TERM>**，在弹出的对话框中输入加密密码，并单击 **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.ExportSqlButton.Export">导出</UI-TERM>**。

   * 批量删除：单击 **<UI-TERM key="ocp-v2.Credential.Component.FilterBar.BatchDeletion">批量删除</UI-TERM>**，在弹出的对话框中单击 **<UI-TERM key="ocp-v2.Backup.BackupStrategy.Detail.Delete">删除</UI-TERM>**。
