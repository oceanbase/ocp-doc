# 导出凭据

本节介绍导出凭据的操作步骤。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **集群只读**、**租户只读**、**OBProxy 只读**、**Binlog 服务只读** 或 **主机只读** 任一资源权限。
* 系统管理 **<UI-TERM key="ocp-v2.src.component.AddOBProxyCredentialModal.CredentialManagement">凭据管理</UI-TERM>** 菜单权限。

## 操作步骤

1. 登录 OCP。

2. 单击左导航栏 **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">系统管理</UI-TERM>** \> **<UI-TERM key="ocp-v2.page.Credential.CredentialManagement">凭据管理</UI-TERM>**，进入凭据列表页面。

3. 在 **OceanBase**、**OBProxy** 或 **<UI-TERM key="ocp-v2.src.constant.alarm.Host">主机</UI-TERM>** 页签中找到要导出的凭据对象。

4. 将光标悬停至该对象 **<UI-TERM key="ocp-v2.Component.SQLDetail.ParallelSQLTraceTable.Actions">操作</UI-TERM>** 列的 **<UI-TERM key="ocp-v2.src.util.component.More">更多</UI-TERM>** ，在选择框中单击 **<UI-TERM key="ocp-v2.Monitor.Dashboard.Export">导出</UI-TERM>** 。

5. 在对话框中输入加密密码，密码设置规范如下：

    * 长度为 8~32 个字符。
    * 至少包含数字（0\~9）、大写字母（A\~Z）、小写字母（a\~z）和特殊字符四种类型中的三种。
    * 支持的特殊字符为 <code>~!@#%^&*_-+=\|(){}[]:;,.?/</code>。

6. 单击 **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.ExportSqlButton.Export">导出</UI-TERM>**。

   > **<UI-TERM key="ocp-v2.component.UploadPackageDrawer.Description">说明</UI-TERM>**
   >
   > [导入凭据](300.import-a-credential.md) 时需使用该加密密码进行解密，请您牢记密码，您也可单击 <strong>复制密码</strong> 进行保存。
