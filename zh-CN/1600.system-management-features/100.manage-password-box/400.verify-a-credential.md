# 验证凭据

本节介绍如何验证凭据是否可用。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **集群只读**、**租户只读**、**OBProxy 只读**、**Binlog 服务只读** 或 **主机只读** 任一资源权限。
* 系统管理 **<UI-TERM key="ocp-v2.page.Credential.CredentialManagement">凭据管理</UI-TERM>** 菜单权限。

## 操作步骤

1. 登录 OCP。

2. 单击左导航栏 **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">系统管理</UI-TERM>** \> **<UI-TERM key="ocp-v2.src.component.AddOBCredentialModal.CredentialManagement">凭据管理</UI-TERM>**，进入凭据列表页面。

3. 在 **OceanBase**、**OBProxy** 或 **<UI-TERM key="ocp-v2.Cluster.New.Host">主机</UI-TERM>** 页签中找到需要验证的凭据对象。

4. 单击该凭据 **<UI-TERM key="ocp-v2.Component.OBServerList.Operation">操作</UI-TERM>** 列的 **<UI-TERM key="ocp-v2.page.Credential.OBProxy.Verification">验证</UI-TERM>**。

5. 若凭据验证成功，该凭据对象集群名或凭据名后将展示 **<UI-TERM key="ocp-v2.page.Credential.Host.VerifiedSuccessfully">验证成功</UI-TERM>** 标签；若验证失败，您需重新输入凭据信息。
