# 删除凭证

本节介绍如何删除凭证。

<main id="notice" type='explain'>
<h4>说明</h4>
<p>删除凭据后将影响 OceanBase 集群、租户、OBProxy 集群、主机的运维，运维过程中可能因找不到凭据而失败。</p>
</main>

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **集群维护**、**租户维护**、**OBProxy 维护**、**Binlog 服务维护** 或 **主机维护** 任一资源权限。
* 系统管理 **<UI-TERM key="ocp-v2.src.constant.auditEvent.CredentialManagement">凭据管理</UI-TERM>** 菜单权限。

## 操作步骤

1. 登录 OCP。

2. 单击左导航栏 **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">系统管理</UI-TERM>** \> **<UI-TERM key="ocp-v2.src.component.AddOBCredentialModal.CredentialManagement">凭据管理</UI-TERM>**，进入凭据列表页面。

3. 找到要删除的凭据对象，将光标悬停至该对象 **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.Operation">操作</UI-TERM>** 列的 **<UI-TERM key="ocp-v2.src.util.component.More">更多</UI-TERM>** ，在选择框中单击 **<UI-TERM key="ocp-v2.component.ZoneFormList.Delete">删除</UI-TERM>** 。

4. 在对话框中单击 **<UI-TERM key="ocp-v2.component.FormEditTable.Delete">删除</UI-TERM>**。
