# 删除模型

您可参考本节内容，对大模型厂商下的模型进行删除管理。针对用户手动增加的大模型厂商，当厂商下的所有模型均被删除后，该厂商卡片将被同步移除，系统内置的厂商卡片则会保留。

## 前提条件

* 请确保当前登录 OCP 的用户为 **ADMIN** 角色。
* 正在使用中的模型无法删除；若需删除，请先参考 [设置系统模型](300.set-system-model.md) 变更当前使用的模型。

## 操作步骤

1. 登录 OCP。

2. 单击左导航栏 **系统管理** > **外部集成**，默认进入 **AI 模型** 页面。

3. 在 **模型厂商** 模块，单击模型厂商卡片，可在右侧面板中查看该厂商下的所有模型信息。

4. 选择待删除的模型，单击操作列的 **删除**。

5. 模型删除后，若需要将其重新添加至 OCP，可参考 [添加模型](200.add-a-model.md) 进行操作。
