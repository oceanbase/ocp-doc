# 设置系统模型

连接 AI 模型厂商后，您需在已连接的模型厂商中选择系统待使用的模型，即设置系统模型。设置完成后，系统将根据所选模型刷新 OCP 知识库，此时智能对话才可启用。

若之前已设置过系统模型，重新设置后，系统模型将替换为最新设置的模型。

## 前提条件

* 请确保当前登录 OCP 的用户为 **ADMIN** 角色。
* 已参考 [连接 AI 模型厂商](100.link-a-model.md) 连接目标模型所在的厂商，或已通过 [添加模型](200.add-a-model.md) 添加了所需的模型。

## 操作步骤

1. 登录 OCP。

2. 单击左导航栏 **系统管理** > **外部集成**，默认进入 **AI 模型** 页面。

3. 在 **当前使用** 模块，单击 **设置**。

4. 在弹出的对话框中，选择具体的模型。

    |  参数      |  说明   |
    |------------|---------|
    | 聊天模型   | 通过在大规模文本数据上进行预训练，学习语言的规律和模式，获得通用语言理解能力和生成能力的模型。   |
    | 嵌入模型   | 模型专注于将文本转换为固定长度的向量展示，向量保留数据的语义信息，便于后续的相似度计算、分类等任务。   |
    | Rerank 模型（可选）   | 用于对初步检索结果进行重新排序，以提高检索系统的精度。这些模型通常结合上下文信息和用户意图，对初步检索到的结果进行排序优化，提供更相关的结果。    |

5. 单击 **设置**。
