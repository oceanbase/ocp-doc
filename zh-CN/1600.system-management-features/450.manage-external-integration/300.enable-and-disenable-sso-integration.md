# 启用/停用 SSO 集成配置

OCP 仅支持开启一个 SSO 集成，当创建多个 SSO 集成时，您可通过启用和停用操作进行第三方登录方式的切换。

## 前提条件

请确保当前登录 OCP 的用户为 **ADMIN** 角色。

## 操作步骤

1. 登录 OCP。

2. 单击左导航栏 **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">系统管理</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.ExternalIntegration">外部集成</UI-TERM>**，进入 **<UI-TERM key="ocp-v2.page.External.SsoIntegrationList">SSO 集成列表</UI-TERM>** 页面。

3. 选择需要启用/停用的 SSO 集成，单击 **<UI-TERM key="ocp-v2.src.component.TraceConfigModal.WhetherToEnable">是否启用</UI-TERM>** 列的开关。

4. 在弹窗中单击 **<UI-TERM key="ocp-v2.component.ParameterTemplate.ParameterTemplateDropdown.Ok">确定</UI-TERM>**。
