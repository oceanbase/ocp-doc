# 编辑 SSO 集成

当已创建的 SSO 集成配置信息需要更新时，您可参考本节内容对其进行修改。

## 前提条件

请确保当前登录 OCP 的用户为 ADMIN 角色。

## 操作步骤

1. 登录 OCP。

2. 单击左导航栏 **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">系统管理</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.ExternalIntegration">外部集成</UI-TERM>**，进入 **<UI-TERM key="ocp-v2.page.External.SsoIntegrationList">SSO 集成列表</UI-TERM>** 页面。

3. 选择需要启用/停用的 SSO 集成配置，单击 **<UI-TERM key="ocp-v2.Settings.Credential.Cluster.Operation">操作</UI-TERM>** 列的 **<UI-TERM key="ocp-v2.Alarm.Channel.Editing">编辑</UI-TERM>**。
4. 在弹窗中更新配置信息，并单击 **<UI-TERM key="ocp-v2.ResourceManager.ResourceGroupTab.CreateResourceGroup.Ok">确定</UI-TERM>**。
