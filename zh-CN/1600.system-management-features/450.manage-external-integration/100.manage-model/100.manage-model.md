# 管理 AI 模型

OCP 为向您提供 AI 服务，您的输入内容将在调用服务时将传输至您选择的第三方大模型开发主体，用于生成相应的服务结果，并在处理后返回至 OCP 平台。

关于具体第三方处理您个人数据的情况，请您查阅相应的第三方隐私政策文件。如果您不同意数据的此类传输和处理，请勿使用相关第三方大模型。

## 前提条件

请确保当前登录 OCP 的用户为 **ADMIN** 角色。

## 操作步骤

### 查看内置模型厂商

OCP 提供 **通义千问**、**豆包**、**DeepSeek** 3 种默认模型厂商，您可查看各个厂商的模型信息。

1. 登录 OCP。

2. 单击左导航栏 **系统管理** > **外部集成**，默认进入 **AI 模型** 页面。

3. 在 **模型厂商** 模块，单击厂商卡片，可在右侧面板中查看该厂商的详细模型信息。

### 添加模型

当系统内置模型无法满足您的需求时，您可自主添加所需模型。目前 OCP 仅支持兼容 OpenAI API 格式的模型。

1. 登录 OCP。

2. 单击左导航栏 **系统管理** > **外部集成**，默认进入 **AI 模型** 页面。

3. 在 **模型厂商** 模块，单击 **添加**。

4. 在右侧面板中，填写模型信息。

    |  参数      |  说明   |
    |------------|---------|
    | 大模型厂商 | 选择大模型厂商类型，支持 **已有厂商** 和 **自定义** 两种。<ul><li>已有厂商：为系统内置模型厂商单独添加一个模型。</li><li>自定义：为其它大模型厂商添加模型。</li></ul>   |
    | 厂商名称   | <ul><li>当 **大模型厂商** 选择 **已有厂商** 时，请选择具体厂商。</li><li>当 **大模型厂商** 选择 **自定义** 时，请输入厂商名称，可包含中文、英文、数字和下划线，且长度为 2 ~ 32 个字符。</li></ul>   |
    | 模型类型   | 根据使用场景，选择具体的模型类型。<ul><li>聊天：通过在大规模文本数据上进行预训练，学习语言的规律和模式，获得通用语言理解能力和生成能力的模型。</li><li>嵌入：通过在大规模文本数据上进行预训练，学习语言的规律和模式，获得通用语言理解能力和生成能力的模型。</li><li>Rerank：用于对初步检索结果进行重新排序，以提高检索系统的精度。这些模型通常结合上下文信息和用户意图，对初步检索到的结果进行排序优化，提供更相关的结果。</li></ul>    |
    | 模型名称   | 请输入模型名称。具有如下要求：<ul><li>请填写大模型厂商已对外提供的模型名称。</li><li>同一模型厂商下，模型名称需保持唯一性。</li><li>可包含中文、英文、数字和下划线，且长度为 2 ~ 32 个字符。</li></ul>    |
    | 访问地址   | 请输入大模型调用的 URL 地址。   |
    | API Key   | 请输入大模型调用的 SK 信息，默认掩码展示，支持查看明文。<br>**访问地址** 及 **API Key** 配置完成后，单击 **测试**，校验所填信息是否可以联通。   |
    | 备注      | 为模型补充其它说明。   |

5. 单击 **添加**。

### 设置系统模型

系统将根据所选模型刷新 OCP 知识库，刷新后智能对话将被启用。

1. 登录 OCP。

2. 单击左导航栏 **系统管理** > **外部集成**，默认进入 **AI 模型** 页面。

3. 在 **当前使用** 模块，单击 **设置**。

4. 在弹出的对话框中，选择具体的模型。

    |  参数      |  说明   |
    |------------|---------|
    | 聊天模型 | 通过在大规模文本数据上进行预训练，学习语言的规律和模式，获得通用语言理解能力和生成能力的模型。   |
    | 嵌入模型   | 通过在大规模文本数据上进行预训练，学习语言的规律和模式，获得通用语言理解能力和生成能力的模型。   |
    | Rerank 模型   | 用于对初步检索结果进行重新排序，以提高检索系统的精度。这些模型通常结合上下文信息和用户意图，对初步检索到的结果进行排序优化，提供更相关的结果。    |

5. 单击 **设置**。

### 修改模型厂商

您可参考本节内容更新模型厂商的 API-KEY 信息。修改 API-KEY 后，该厂商下的所有可用模型将重新加载至 OCP。

1. 登录 OCP。

2. 单击左导航栏 **系统管理** > **外部集成**，默认进入 **AI 模型** 页面。

3. 在 **模型厂商** 模块，选择待修改的模型厂商，单击 **修改**。

4. 在弹出的对话框中，填写 **API-KEY** 及 **备注** 信息。

5. 单击 **保存**。

### 删除模型厂商

当添加的自定义模型不再适用时，您可参考本节内容进行删除。删除后，该厂商信息将无法恢复，您需谨慎操作。

1. 登录 OCP。

2. 单击左导航栏 **系统管理** > **外部集成**，默认进入 **AI 模型** 页面。

3. 在 **模型厂商** 模块，选择待删除的模型厂商，单击 **删除**。

4. 在弹出的对话框中，单击 **删除**。
