# SQL Audit 对接 SLS

本文为您介绍 SQL Audit 如何对接 SLS 数据源。

## 前提条件

* 请确保当前登录 OCP 的用户为 admin、组织管理员或集群管理员角色。
* 请确保 OCP Agent 与 SLS 的网络连通性。

## 操作步骤

1. 登录 OCP。

2. 单击左侧导航栏 **系统管理** > **外部集成**。

3. 在页面顶部 **SLS** 页签中，单击右上角 **新建**。

4. 在弹出的对话框中，配置如下参数。

   | 参数  |   描述   |
   |-----|-------|
   | **<UI-TERM>数据源名称</UI-TERM>**          | 2 ~ 32 个字符，可包含中文、英文、数字、下划线。  |
    | **<UI-TERM>访问域名</UI-TERM>**          | SLS 服务访问域名。  |
    | **<UI-TERM>AccessKey ID</UI-TERM>**          | SLS 服务访问 ID，用于标识用户。  |
    | **<UI-TERM>AccessKey Secret</UI-TERM>**          | 用于加密签名字符串和日志服务用来验证签名字符串的密钥，必须保密。  |
    | **<UI-TERM>地域</UI-TERM>**          | 当前专有云 region。  |
    | **<UI-TERM>项目</UI-TERM>**          | SLS 服务 project 名称。  |
    | **<UI-TERM>备注</UI-TERM>**          | 可选。  |

5. 单击对话框右下角 **<UI-TERM>验证</UI-TERM>**。

6. 验证通过后，单击 **<UI-TERM>新建</UI-TERM>**。

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/440/sls.png)

## 相关操作

* **验证 SLS 数据源**：在数据源操作列，单击 **<UI-TERM>验证</UI-TERM>**。若验证通过，会在数据源名称后显示 **<UI-TERM>验证成功</UI-TERM>**。

* **编辑 SLS 数据源**：在数据源操作列，选择 **<UI-TERM>... > 编辑</UI-TERM>** ，在弹出的对话框中修改相关信息，然后单击 **<UI-TERM>保存</UI-TERM>**。

* **删除 SLS 数据源**：在数据源操作列，选择 **<UI-TERM>... > 删除</UI-TERM>** ，在弹出的对话框中单击 **<UI-TERM>确定</UI-TERM>**。
