# SQL Audit 对接 SLS/ES 概述

本功能支持将 OceanBase 数据库的 SQL Audit 数据对接至外部存储系统（SLS 和 ElasticSearch），旨在最大程度简化用户配置流程，提供必要的监控手段确保数据传输的及时性和可靠性，提升数据库操作的可见性和安全性。

## 背景信息

在企业级数据库管理环境中，保留 SQL Audit 数据不仅是出于技术和管理的需求，更是为了应对日益复杂的安全挑战和严格的合规要求。SQL Audit 为企业提供了全面的操作透明度，是保障数据安全、优化运营效率、支持合规审计以及快速响应问题的重要基础。

通过科学管理和分析 SQL Audit 数据，企业能够在竞争中保持更高的安全性和运营效率，同时降低潜在的法律和业务风险。

## 概念介绍

### SQL Audit

SQL Audit 是指对数据库执行的 SQL 语句进行审计记录的功能，包含 SQL 执行的相关元数据信息，如执行时间、用户信息、客户端 IP 等。

### 日志服务（SLS）

* 日志服务（SLS）是云原生观测与分析平台，为 Log、Metric、Trace等数据提供大规模、低成本、实时的平台化服务。

* 日志服务一站式提供数据采集、加工、查询与分析、可视化、告警、消费与投递等功能，全面提升研发、运维、运营、安全等场景的数字化能力。

### ElasticSearch

* ElasticSearch 是基于 Lucene 的分布式搜索与分析引擎，支持实时数据存储、检索和复杂分析。它具备高扩展性，可轻松构建集群应对海量数据，通过 RESTful API 提供灵活查询。
* ElasticSearch 广泛用于日志分析、全文搜索、实时数据监控等场景，快速处理结构化与非结构化数据，助力企业实现数据洞察与决策优化。

## 应用场景

### 安全合规审计

满足行业监管要求，提供完整的 SQL 操作审计记录。

### 性能分析优化

通过对历史 SQL 执行记录的分析，识别性能瓶颈并进行优化。

### 故障排查定位

快速定位数据库异常操作，提高问题排查效率。
