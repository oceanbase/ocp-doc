# 查看主机资源

本节为您介绍 OCP 的主机资源监控功能。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **集群只读**、**租户只读** 或 **主机只读** 任一资源权限。
* 主机 **<UI-TERM key="ocp-v2.component.common.ServerSelect.All">全部</UI-TERM>** 菜单权限。

## 操作步骤

1. 登录 OCP 。

2. 选择 **<UI-TERM key="ocp-v2.src.component.ModifyTagResourceDrawer.Host">主机</UI-TERM>** 。

3. 在 **<UI-TERM key="ocp-v2.page.Host.HostList">主机列表</UI-TERM>** 区域，选择待操作的主机并单击该主机 IP 地址。

4. 在显示的页面上，单击 **<UI-TERM key="ocp-v2.src.hook.useMenu.Monitoring">监控</UI-TERM>** 页签。

5. 在 **<UI-TERM key="ocp-v2.Host.Detail.Surveillance">监控</UI-TERM>** 页面中，单击 **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.HostResources">主机资源</UI-TERM>** 页签，配置监控数据筛选条件。

   筛选条件说明如下表所示：

   |     筛选条件  |  描述  |
   |---------------|---------|
   | 刷新  | 刷新监控数据。支持开启自动刷新，默认关闭；开启自动刷新时支持配置刷新频率。 |
   | 选择时间（又称：监控窗口） | 自动刷新模式下不展示。选择某一段时间范围，用于返回这段时间范围内的数据。  |

6. 查看主机的资源监控数据。

   * 所有监控项均支持展示每个细分指标的最大值（max）、平均值（avg）和当前值（current）。
   * 所有监控项的具体含义及取值来源，您都可参考 [监控指标概述](../../1900.reference-guide/300.monitoring-indicator-reference/100.overview-of-metrics.md) 理解。

   下述功能能够帮您更好的在趋势图中查看和分析资源监控数据，您可结合图片及下述文字理解。

   ![1129](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/436/1602.png)

   * 查看及隐藏其他细分指标的数据：将光标悬停于指标区域，上下滑动鼠标滚轮，可查看趋势图中展示的所有细分指标数据。单击其他细分指标标识，使其置灰，趋势图中将不展示该指标信息。

   * 将光标悬停于趋势图中某时刻，可查看某时刻详细数据；拖拽光标选中某区域，系统会放大显示该区域的趋势信息，您可查看该指标的在此时间段的详细趋势，双击该趋势图可恢复。

   * 放大某一趋势图：单击趋势图右上角的放大图标。上图中的 ①、② 的功能在放大的趋势图中同样适用。

   * 编辑监控指标：单击趋势图右上角的编辑图标，可选择仅展示需关注的细分指标。

7. 单击 **自定义监控**，您可以根据自身所需自定义监控指标和图表，详情可参见 [自定义监控概述](../200.manage-custom-monitoring/100.custom-monitoring-overview.md)。
