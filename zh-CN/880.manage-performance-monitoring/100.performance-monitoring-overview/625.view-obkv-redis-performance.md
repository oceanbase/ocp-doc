# 查看 OBKV_Redis

本页面为您介绍如何查看租户 OBKV_Redis 类型的监控数据。OBKV-Redis 是 OceanBase 数据库自 V4.2.5 版本开始支持的能力，它是基于 OceanBase 数据库开发的完全兼容 Redis 协议的持久化缓存数据库。OBKV-Redis 旨在解决传统 Redis + RDS 成本高昂、可伸缩性差、运维和管理复杂、数据一致性和安全性难以保证等痛点。OBKV-Redis 的 P99 在 10ms 以内，满足 80% 场景的时延以及吞吐。

您可以通过以下两个入口查看 OBKV_Redis 监控数据：

* **入口一**：登录 OCP，进入租户概览页面，单击左侧导航栏的 **<UI-TERM key="ocp-v2.Instance.Monitor.PerformanceMonitoring">性能监控</UI-TERM>**。

* **入口二**：登录 OCP，在左侧导航栏单击 **<UI-TERM key="ocp-v2.src.hook.useMenu.PerformanceMonitoring">性能监控</UI-TERM>**，进入 **<UI-TERM key="ocp-v2.Task.TaskObjectAndType.OceanbaseTenants">OceanBase 租户</UI-TERM>** 页签下。

## 前提条件

* 通过 **入口一** 查看租户 OBKV_Redis 监控数据时，请确保当前登录 OCP 的用户具备如下权限：

  * **集群只读** 或 **租户只读** 资源权限。
  * 租户 **<UI-TERM key="ocp-v2.Detail.Monitor.PerformanceMonitoring">性能监控</UI-TERM>** 菜单权限。

* 通过 **入口二** 查看租户 OBKV_Redis 监控数据时，请确保当前登录 OCP 的用户具备如下权限：

  * **集群只读**、**租户只读** 或 **主机只读** 任一资源权限。
  * 性能监控 **<UI-TERM key="ocp-v2.Detail.Component.RestartModal.All">全部</UI-TERM>** 菜单权限。

* 仅 OceanBase V4.2.5.1 及以上版本支持查看 OBKV_Redis 监控数据。

* 当 OceanBase 满足如下任一版本要求时，才可查看 <b>响应时间</b> 中关于 <code>99-all</code>、<code>95-all</code>、<code>90-all</code> 的细分指标数据。
  * [V4.2.5.1, V4.3.0.0)
  * [V4.3.4.1, +∞)

## 操作步骤

以下步骤以 **入口一** 为例：

1. 登录 OCP 。

2. 在左侧导航栏选择 **<UI-TERM key="ocp-v2.src.constant.plan.Tenant">租户</UI-TERM>** ，系统默认进入 **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">租户列表</UI-TERM>** 页签。

3. 在 **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">租户列表</UI-TERM>** 中选择待操作的租户，单击租户名，进入租户 **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概览</UI-TERM>** 页面。

4. 在左侧显示的导航栏中单击 **<UI-TERM key="ocp-v2.Detail.Monitor.PerformanceMonitoring">性能监控</UI-TERM>** 。

5. 在 **<UI-TERM key="ocp-v2.component.MonitorSearch.DataFiltering">数据筛选</UI-TERM>** 区域，配置监控数据筛选条件。

   筛选条件说明如下表所示：

   |     筛选条件  |  描述  |
   |---------------|---------|
   | 刷新  | 刷新监控数据。支持开启自动刷新，默认关闭。开启时，可选择 5s/10s/30s 不同的刷新评率。|
   | 选择时间（又称：监控窗口） | 自动刷新模式下不展示。选择某一段时间范围，用于返回这段时间范围内的数据。  |
   | 租户 | 选择某一个租户，对该租户进行监控。  |
   | Zone  | 默认对所有 Zone 进行监控。|
   | OBServer | 默认对所有 OBServer 节点进行监控。|
  
6. 单击 **OBKV_Redis** 页签，在该页签中查看相关监控数据。

   * OCP 支持以租户和 Unit 2 个维度查看监控数据，默认以租户维度进行展示，不同维度支持查看的监控指标有所不同。
   * 系统默认展示当前维度下的所有监控项，若您无需关注某项监控，可以单击区域右侧的 **已选图表** 面板中取消勾选该监控项。
   * 所有监控项均支持展示每个细分指标的最大值（max）、平均值（avg）和当前值（current）。
   * 所有监控项的具体含义及取值来源，您都可参考 [监控指标概述](../../1900.reference-guide/300.monitoring-indicator-reference/100.overview-of-metrics.md) 理解。如统计范围内涉及多台 OBServer 节点时，则展示聚合值。

   下述功能能够帮您更好地在趋势图中查看和分析详细性能监控数据，您可结合图片及下述文字理解。

   ![Image 114](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/436/1725.png)

   * 查看及隐藏其他细分指标的数据：将光标悬停于指标区域，上下滑动鼠标滚轮，可查看趋势图中展示的所有细分指标数据。单击其他细分指标标识，使其置灰，趋势图中将不展示该指标信息。

   * 将光标悬停于趋势图中某时刻，可查看某时刻详细数据；拖拽光标选中某区域，系统会放大显示该区域的趋势信息，您可查看该指标的在此时间段的详细趋势，双击该趋势图可恢复。

   * 放大某一趋势图：单击趋势图右上角的放大图标。上图中的 ①、② 的功能在放大的趋势图中同样适用。

   * 编辑监控指标：单击趋势图右上角的编辑图标，可选择仅展示需关注的细分指标。

   * 下钻查看不同维度的监控数据：在 **<UI-TERM key="ocp-performance-report.pages.AWR.Tenant">租户维度</UI-TERM>** 页签下，当您发现租户的监控数据异常时，如响应时间过高，您可通过下钻分析，定位到引起响应时间异常的服务器。单击趋势图右上角的 **<UI-TERM key="ocp-v2.component.MetricChart.Item.DrillDownAnalysis">下钻分析</UI-TERM>** 图标，即可查看下钻分析详情，**OBKV_Redis** 支持的下钻维度为：**租户 \> OBServer**。

       上图中 ①、② 的功能在下钻页面的趋势图中同样适用，此外您还可以：

       * 在下钻页面重新设置筛选条件，如您未设置则会自动继承上层设置。

       * 如该指标存在细分指标，您可以选择细分指标进行查看。

       * 趋势图为您提供了 **前往主机性能监控** 功能，将光标悬停于 **前往主机性能监控** 的链接上，选择您想查看的主机，即可跳转到相关主机的 **<UI-TERM key="ocp-v2.Monitor.AddMonitor.PerformanceMonitoring">性能监控</UI-TERM>** 页面查看主机监控详情。

   * 查看 SQL 请求分析：在 **<UI-TERM key="ocp-v2.src.constant.monitor.ResponseTime">响应时间</UI-TERM>** 趋势图中，单击趋势图右上角的 **<UI-TERM key="ocp-v2.component.MetricChart.Item.SqlRequestAnalysis">SQL 请求分析</UI-TERM>** 图标，可查看请求分析详情，详见 [查看请求分析](../../1000.diagnosis-and-tuning-fuctions/100.manage-sql-diagnosis/1300.view-request-analysis.md) 。
