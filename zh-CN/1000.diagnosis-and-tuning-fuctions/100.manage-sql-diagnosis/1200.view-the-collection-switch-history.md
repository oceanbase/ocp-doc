# 查看采集开关历史

本页面为您介绍如何查看 SQL 采集开关历史。

您可通过如下两个入口查看采集开关历史：

* **入口一**：登录 OCP，在左侧导航栏单击 **<UI-TERM key="ocp-v2.page.Diagnosis.AutonomousService">自治服务</UI-TERM>**，选择需要查看的集群，进入集群 **<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">实时诊断</UI-TERM>** 页面。

* **入口二**：登录 OCP，进入租户 **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概览</UI-TERM>** 页面，在左侧导航栏单击 **<UI-TERM key="ocp-v2.ParallelSQL.TraceDetail.SqlDiagnosis">SQL 诊断</UI-TERM>**。

<main id="notice" type='notice'>
   <h4>功能适用性</h4>
   <p>社区版暂不支持自治服务，该功能需要通过 <b>入口二</b> 访问查看。</p>
</main>

## 前提条件

* 当通过 **入口一** 查看采集开关历史时，请确保当前登录 OCP 的用户具备如下权限：

  * **集群只读** 或 **租户只读** 资源权限。
  * 自治服务 **<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">实时诊断</UI-TERM>** 菜单权限。

* 当通过 **入口二** 查看采集开关历史时，请确保当前登录 OCP 的用户具备如下权限：

  * **集群只读** 或 **租户只读** 资源权限。
  * 租户 **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.SqlDiagnosis">SQL 诊断</UI-TERM>** 菜单权限。

## 操作步骤

以下操作步骤以 **入口一** 为例。

1. 在左导航栏单击 **<UI-TERM key="ocp-v2.src.hook.useMenu.AutonomousService">自治服务</UI-TERM>** ，并在 **<UI-TERM key="ocp-v2.page.Diagnosis.ClusterDetails">集群详情</UI-TERM>** 中单击集群名进入集群 **<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">实时诊断</UI-TERM>** 页面。

2. 系统默认进入 **<UI-TERM key="ocp-v2.Detail.Monitor.SqlDiagnosis">SQL 诊断</UI-TERM>** 页签。

3. 单击 **<UI-TERM key="ocp-v2.Detail.SQLDiagnosis.ViewCollectionSwitchHistory">查看采集开关历史</UI-TERM>** 按钮。

   ![Image 161](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4891489461/p429487.png)

4. 在右侧 **<UI-TERM key="ocp-v2.component.TraceTimelineDrawer.SqlCollectionSwitchHistory">SQL 采集开关历史</UI-TERM>** 面板中，查看操作时间和具体操作详情。

   * 可根据操作时间对开关操作进行排序。

   * 可根据 **开启、关闭** 不同操作对开关操作进行排序。
