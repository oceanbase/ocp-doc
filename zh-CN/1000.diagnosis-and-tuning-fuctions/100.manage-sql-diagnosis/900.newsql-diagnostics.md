# 诊断新增 SQL

新增 SQL 指在查询区间往前一段时间（默认 7 天）没有执行过，但是在查询区间内有执行记录的 SQL。本节为您如何对新增 SQL 进行诊断。

<main id="notice" type='notice'>
    <h4>功能适用性</h4>
    <p>该内容仅适用于 OCP 企业版，OCP 社区版不提供此功能。</p>
</main>

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **集群只读** 或 **租户只读** 资源权限。
  * 自治服务 **<UI-TERM key="ocp-v2.Detail.Realtime.RealTimeDiagnosis">实时诊断</UI-TERM>** 菜单权限。

* 已在 [管理参数](../../600.cluster-functions/300.manage-a-cluster/1200.manage-om-configuration/200.manage-om-configuration-parameters.md) 中开启 **<UI-TERM key="ocp-v2.component.OperationConfig.List.SqlDiagnosticCollection">SQL 诊断采集</UI-TERM>** 模块参数。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏中，单击 **<UI-TERM key="ocp-v2.src.hook.useMenu.AutonomousService">自治服务</UI-TERM>**。

3. 在 **<UI-TERM key="ocp-v2.page.Diagnosis.ClusterDetails">集群详情</UI-TERM>** 区域，单击需要查看的集群名称。

4. 默认进入 **<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">实时诊断</UI-TERM>** 的 **<UI-TERM key="ocp-v2.Detail.Realtime.SqlDiagnosis">SQL 诊断</UI-TERM>** 页面。

5. 单击 **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.AddSql">新增 SQL</UI-TERM>** 页签。

6. 配置筛选条件，对新增 SQL 进行筛选。

     * 时间范围：可在 **<UI-TERM key="ocp-v2.Detail.Analyze.TimesChart.TimeRange">时间范围</UI-TERM>** 下拉框中选择 近 5 分钟、近 10 分钟、近 20 分钟、近 30 分钟、近 1 小时、近 3 小时、近 6 小时来快速选择时间范围；也可在下拉框中选择自定义时间，并配置开始时间和结束时间。默认显示近 6 小时内的信息。

     * OBServer：选择 OBServer 节点，查询时将只查询在该 OBServer 节点上执行的 SQL。

     * 内部 SQL：若勾选，则查询结果中会包含由 OceanBase 内部发起的 SQL。

     * 关键词：查询结果中会显示 SQL 文本中包含该关键词的 SQL。匹配方式与 SQL 的 like 相同，且默认自动在输入的字符串前后加了 % 符号。

     * 高级条件： **<UI-TERM key="ocp-v2.Detail.SQLDiagnosis.AdvancedConditions">高级条件</UI-TERM>** 支持同时添加多个过滤条件。单击 **<UI-TERM key="ocp-v2.alarm.FormListWithExclude.ObproxyClusterAndHostWithExclude.Add">添加</UI-TERM>** ，在 **<UI-TERM key="ocp-v2.Component.SQLCondition.AddAdvancedConditions">添加高级条件</UI-TERM>** 面板中对指标、运算符和值进行配置，查询时将获取指标满足条件的 SQL 展示在查询结果列表中。

7. 单击 **<UI-TERM key="ocp-v2.Auth.User.loginHistory.Query">查询</UI-TERM>** ，下方列表中将展示所有符合查询条件的 SQL。您可对所查询的新增 SQL 进行如下操作：

      1. 单击 **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.ColumnManager.ColumnManagement">列管理</UI-TERM>** ，在面板中选择需要查看的信息。勾选完成后即可在新增 SQL 列表中查看到相关结果。

      2. 在 **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.AddSql">新增 SQL</UI-TERM>** 页签下， 可查看上一步骤选择的列信息。支持复制 SQL 文本，并根据数据库对 SQL 文本进行筛选。

      3. 单击 SQL 文本，您可进入 **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetail.SqlDetails">SQL 详情</UI-TERM>** 页面，查看该 SQL 的详细信息，包括：

        * 在 **<UI-TERM key="ocp-performance-report.ReportTables.SqlInfo.SQLInfoTable.SqlText">SQL 文本</UI-TERM>** 处查看 SQL 的完整语句。

        * 在 **<UI-TERM key="ocp-v2.Component.SQLDetail.SQLTunning.OptimizationSuggestions">优化建议</UI-TERM>** 处查看对于该 SQL 的优化建议，详见 [查看优化建议](../100.manage-sql-diagnosis/1000.view-sql-details.md)。

        * 在 **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.Plan.HistoricalTrends">历史趋势</UI-TERM>** 页签，查看该 SQL 的 SQL 运行趋势图和 SQL 计划生成趋势图，详见 [查看 SQL 运行的历史趋势](../100.manage-sql-diagnosis/1000.view-sql-details.md)。

        * 在 **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetailTabs.ExecutionPlan">执行计划</UI-TERM>** 页签，查看该 SQL 的执行计划，或为其绑定执行计划，详见 [查看 SQL 的执行计划](../100.manage-sql-diagnosis/1000.view-sql-details.md)。

        * 在 **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetailTabs.Index">索引</UI-TERM>** 页签，查看该 SQL 绑定的索引，详见 [查看和绑定索引](../100.manage-sql-diagnosis/1000.view-sql-details.md)。

        * 在 **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetailTabs.SqlThrottling">SQL 限流</UI-TERM>** 页签，查看该 SQL 的限流情况，或为其设置限流，详见 [设置 SQL 限流](../100.manage-sql-diagnosis/1000.view-sql-details.md)。
