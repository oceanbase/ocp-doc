# 查看优化中心

本节为您介绍优化中心的使用方法。

<main id="notice" type='notice'>
  <h4>功能适用性</h4>
  <p>该内容仅适用于 OCP 企业版，OCP 社区版不提供此功能。</p>
</main>

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **集群只读** 或 **租户只读** 资源权限。
* 自治服务 **<UI-TERM key="ocp-v2.Detail.Optimize.OptimizationCenter">优化中心</UI-TERM>** 菜单权限。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏中，单击 **<UI-TERM key="ocp-v2.page.Diagnosis.AutonomousService">自治服务</UI-TERM>**。

3. 在 **<UI-TERM key="ocp-v2.page.Diagnosis.ClusterDetails">集群详情</UI-TERM>** 区域，单击需要查看的集群名称。

4. 在左侧导航栏单击 **<UI-TERM key="ocp-v2.Detail.Optimize.OptimizationCenter">优化中心</UI-TERM>**。

5. 在 **<UI-TERM key="ocp-v2.Component.SQLDetail.SQLTunning.OptimizationSuggestions">优化建议</UI-TERM>** 页签可查看如下信息。

   1. 在页面顶部会显示近 3 天的优化信息，可以看到异常事件和事件的 **<UI-TERM key="ocp-v2.Alarm.Rule.Object">对象</UI-TERM>**、**异常名称**、**<UI-TERM key="ocp-v2.component.CardAbnormalTable.AbnormalPerformance">异常表现</UI-TERM>**、**<UI-TERM key="ocp-v2.component.CardAbnormalTable.CurrentStatus">当前状态</UI-TERM>**、**<UI-TERM key="ocp-v2.Session.Deadlock.OccurrenceTime">发生时间</UI-TERM>**、**<UI-TERM key="ocp-v2.Backup.Restore.RestoreTask.RecoveryTime">恢复时间</UI-TERM>**、**持续时间等信息**。

   2. 在 **<UI-TERM key="ocp-v2.page.Information.Tenant">租户</UI-TERM>** 位置选择单一租户或者所有租户，查看对应的 QPS、响应时间、会话数、租户 CPU 消耗信息等图表。

      * **QPS**：平均每秒处理 SQL 语句数。
      * **<UI-TERM key="ocp-v2.src.constant.monitor.ResponseTime">响应时间</UI-TERM>**：SQL 语句平均处理耗时。
      * **<UI-TERM key="ocp-v2.src.constant.monitor.Sessions">会话数</UI-TERM>**：租户会话数量。
      * **<UI-TERM key="ocp-v2.src.constant.monitor.TenantCpuConsumption">租户 CPU 消耗</UI-TERM>**：租户 CPU 使用量 * 100 / 租户 CPU 分配量。

      把指针放在图表的时间点上，可以快捷查看对应时间点下的数据信息，点击图标右上角的放大按钮也可放大查看。

   3. 在右上方选择近 5 分钟，30 分钟，1 小时、6 小时或者其他自定义时间，筛选出一段时间内的记录。

   4. 在下方区域看到 SQL 类和结构类的优化记录，包括 **优化类型**、**<UI-TERM key="ocp-v2.Detail.Overview.Tenant">租户</UI-TERM>**、**<UI-TERM key="ocp-v2.Trace.TraceDetailDrawer.Database">数据库</UI-TERM>**、**优化对象**、**诊断理由**、**优化建议信息** 等内容。

   5. 单击 **查看SQL诊断** ，跳转查看实时诊断信息。

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/%E4%BC%98%E5%8C%96%E4%B8%AD%E5%BF%83.png)

6. 单击打开 **<UI-TERM key="ocp-v2.Detail.Optimize.OptimizedRecords">优化记录</UI-TERM>** 页签。

   在右上方选择近事件进行筛选，查看执行时间段内的优化记录，包含记录的 **<UI-TERM key="ocp-v2.Detail.Optimize.OperationDescription">操作描述</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Optimize.TenantName">租户名</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Component.AddDatabaseModal.DatabaseName">数据库名</UI-TERM>**、**<UI-TERM key="ocp-v2.Auth.Role.AddRole.OperationType">操作类型</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Optimize.OperationDetails">操作详情</UI-TERM>**、**SQL ID**、**<UI-TERM key="ocp-v2.Detail.Optimize.OperationTime">操作时间</UI-TERM>** 和 **<UI-TERM key="ocp-v2.Detail.Backup.State">状态</UI-TERM>**。可以根据 **<UI-TERM key="ocp-v2.Detail.Optimize.OperationType">操作类型</UI-TERM>**和 **<UI-TERM key="ocp-v2.Component.OBServerList.State">状态</UI-TERM>** 进行进一步的筛选。
