# SSL 链路加密

## 应用场景

1. **全链路 SSL 认证**：业务应用 > OBProxy > OceanBase 全链路使用 SSL 认证方式建立连接及数据加密传输。
2. **OBProxy SSL认证**：单独为 OBProxy 集群开启 SSL 认证，使业务应用 => OBProxy 采用 SSL 认证方式建立连接及数据加密传输。
3. **OceanBase SSL 认证**： 单独为 OceanBase 集群开启 SSL 认证，在没有 OBProxy 的场景中，使得业务应用 > OceanBase 集群采用 SSL 认证方式建立连接及数据加密传输。

## 前提条件

**证书申请和签发**

1. 预先在权威 CA 证书机构申请 CA 根证书，保证 CA 根证书未过期。
2. 预先使用 CA 根证书签发服务器证书，保证服务器证书未过期，保留证书与私钥。
3. 上述操作后，产生 3 个 pem 格式文件（文件类型必须是 PEM，文件名不限）：CA 根证书（ca.pem）、服务器证书（server.pem）、服务器私钥（server-key.pem）。

关于使用 CA 根证书签发服务器证书，请务必关注相关 [注意事项](#parameter)。

**开启 SSL 链路加密**

1. OceanBase、OBProxy 集群必须处于 **正常运行** 状态。
2. OceanBase 集群为 V4.0.0.0 以上版本。

## 技术原理

### OceanBase 开启 SSL 认证

**步骤一：上传证书文件**

开启 OceanBase SSL 认证前，需要将 CA 根证书、服务器证书、服务器私钥放置在每台 OBServer 的 `${run_path}/wallet` 目录下。当 OceanBase 开启 SSL 认证后，在添加 OBServer、重装 OBServer、替换 OBSevrer、添加 Zone 的场景下，OCP 会主动在新 OBServer 上放置证书文件。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>OCP 在接管开启 SSL 认证的集群后，新 OCP 内可能没有该集群的证书文件，此时 OCP 在上述场景中将无法上传证书文件到新 OBServer。您可以通过在 OCP 重新上传证书文件、更新 SSL 证书的方式解决该问题。</p>
</main>

**步骤二：开启 SSL 开关**

OceanBase 的 SSL 认证分为 RPC SSL 认证和 SQL SSL 认证，分别限制 OceanBase 与 OBServer 建立 RPC 连接、SQL 连接是否通过 SSL 认证。两种协议共用同一套证书。

打开 RPC SSL 认证的 SQL 如下:

```sql
# 指定 SSL 证书获取方式，仅支持 file，从本地文件获取，关闭为空串。
ALTER SYSTEM SET ssl_external_kms_info = '{"ssl_mode":"file"}';

# 设置 OceanBase 分别作为服务端和客户端的 RPC 认证方式: 
# 作为 RPC 服务端可以同时建立 SSL 连接和非 SSL 连接。关闭则取值为 ALL。
ALTER SYSTEM SET rpc_server_authentication_method = 'ALL';

# 作为 RPC 客户端只建立 SSL 连接。关闭则取值为 NONE。
ALTER SYSTEM SET rpc_client_authentication_method = 'SSL_NO_ENCRYPT';

# 开启 SQL RPC 认证开关。
ALTER SYSTEM SET ssl_client_authentication = True;

# 设置 TLS 协议版本。
ALTER SYSTEM SET sql_protocol_min_tls_version = "TLSv1.1";
```

### OBProxy 开启 SSL 认证

**步骤一：上传证书文件**

与 OceanBase 类似，需要将 3 个文件上传到所有 OBProxy Server 的 `${run_path}/wallet` 目录下。添加 OBProxy Server 场景下 OCP 同样会在新 OBProxy Server 上放置证书文件。

**步骤二：开启 SSL 认证**

1. 使用 OBProxy 管理员用户 root@proxysys 连接 OBProxy，执行以下 SQL 配置证书绝对路径。

    ```sql
    update proxyconfig.security_config set CONFIG_VAL= '{"sourceType" : "FILE", "CA" : "/xxx/wallet/ca.pem", "publicKey": "/xxx/wallet/proxy-cert.pem", "privateKey" : "/xxx/wallet/proxy-key.pem"}' where APP_NAME = 'obprox
    ' and VERSION = '1';
    ```

2. 开启 SSL 认证开关。

    ```sql
    # 开启客户端 SSL 认证，开启后业务应用可以通过 SSL 认证连接 OBProxy。
    alter proxyconfig set enable_client_ssl=true;

    # 开启服务端 SSL 认证，开启后，OBProxy 可以通过 SSL 认证连接 OceanBase。
    alter proxyconfig set enable_server_ssl=true;
    ```

客户端与 OBProxy 的 SSL 认证不是强制的，可以同时支持 SSL、非 SSL 认证方式建立连接。如果 OBProxy 开启了 SSL 认证，它同时支持关联开启 SSL 认证与未开启 SSL 认证的 OceanBase 集群。OBProxy 建立连接时，会先与 OceanBase 协商使用何种方式建立连接。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>通常情况下，OBProxy 与其关联的所有 OceanBase 集群要使用同一套证书。考虑企业的 CA 证书一般情况下只有一份，关联 OBProxy 与 OceanBase 集群时，OCP 将不再进行额外检查，该场景由用户自行保证。</p>
</main>

## 注意事项

### 服务器证书签发<a id="parameter"></a>

使用 CA 根证书签发服务器证书，OceanBase 和 OBProxy 对服务器证书的签发方式具有如下特殊要求。

1. 签发服务器证书生成私钥时，需要指定密钥长度为 2048，示例如下。

    ```shell
    openssl genkey -algorithm RSA -out server-key.pem -pkeyopt rsa_keygen_bits:2048
    ```

2. OBProxy 与 OceanBase 同时开启 SSL 认证时，若 OceanBase 与 OBProxy 使用同一套服务器证书，则该证书既作为客户端证书也作为服务端证书，证书的 **Extended Key Usage** 必须同时包含 `Client Authentication` 和 `Server Authentication`。您可以通过以下指令确认是否正确。

    ```sql
    openssl x509 -in 服务器证书文件路径 -text -noout
    ```

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/436/1617.png)

3. 若您有二级证书需求，则需注意使用 CA 根证书签发二级证书时，需要指定二级证书是 CA 证书。可以对签发完成的二级证书执行如下指令确认。

    ```shell
    openssl x509 -in 二级证书文件路径 -text -noout
    ```

    `CA:TRUE` 表示二级证书是 CA 证书，可用来签发其他证书。

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/436/1618.png)

### 全链路 SSL 认证

OceanBase/OBProxy 同时开启 SSL 认证时，OBProxy 与 OceanBase 将使用双向 SSL 认证。OceanBase 侧需要用户手动设置租户参数 `ob_ssl_invited_common_names`，将 OBProxy 证书的 subject 中的 `cn` 字段追加到该参数中，否则 OBProxy 将无法访问租户。

详情可参考 [ob_ssl_invited_common_names](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000002015566)。

## 操作步骤

**步骤一：上传证书组**

在 OCP 的证书管理页面，上传 CA 根证书、服务器证书、服务器私钥，作为一个证书组。

![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/436/1628.png)

**步骤二：开启 SSL 链路加密**

进入 OceanBase/OBProxy 的安全配置页面，开启 OceanBase/OBProxy 的 SSL 链路加密。
