# 将监控大盘导入到 Grafana

本节将为您介绍如何将 OCP 监控大盘导入到 Grafana。

## 应用场景

用户需要使用自有的 Prometheus 和 Grafana 系统。

## 操作步骤

1. 在 Grafana 中配置 Prometheus 数据源。

2. 配置 `prometheus_sd` 相关信息。

   1. 登录 OCP，在左侧导航栏单击 **系统管理** > **系统参数**，将 OCP 系统参数 `ocp.monitor.server.exporter.auth.enabled` 与 `ocp.agent.auth.metric-auth-enabled` 的参数值设置为 `false`，并重启 OCP。

   2. 在 Prometheus 的配置文件中配置 `ocp_sd` 相关信息，参考如下示例：

        ```sql
        scrape_configs:
        - job_name: ocp_sd
            http_sd_configs:
            - url: 'http://xxx.xxx.xxx.xxx:8080/api/v2/monitor/prometheus_sd'
                basic_auth:
                username: admin
                password: '......'
        ```

   3. 进入 Prometheus 控制台，查看 `ocp_sd` 的状态是否都为 `up`。

3. 登录 OCP，进入 **监控大盘** 页面，单击 **导出** > **导出 Grafana 大盘**，并选择待导出的监控大盘。

4. 导出成功后，在 Grafana 中导入该文件即可。
