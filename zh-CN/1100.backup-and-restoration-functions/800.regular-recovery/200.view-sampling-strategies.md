# 查看抽检策略

本页面为您介绍如何查看备份恢复的抽检策略。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **集群只读** 或 **租户只读** 资源权限。
* 备份恢复 **<UI-TERM key="ocp-v2.Restore.SamplingStrategy.New.Recovery">恢复</UI-TERM>** 菜单权限。

## 操作步骤

1. 登录 OCP。

2. 在左导航栏中单击 **<UI-TERM key="ocp-v2.Detail.Backup.BackupAndRestoration">备份恢复</UI-TERM>** **\>** **<UI-TERM key="ocp-v2.src.constant.compute.Recovery">恢复</UI-TERM>**，进入 **<UI-TERM key="ocp-v2.src.util.menu.Recovery">恢复</UI-TERM>** 页面。

3. 单击 **<UI-TERM key="ocp-v2.Backup.Restore.SamplingPolicy">抽检策略</UI-TERM>** 页签，您可根据时间进行筛选，查看 **<UI-TERM key="ocp-v2.Backup.Restore.SamplingPolicy">抽检策略</UI-TERM>** 列表信息。

![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/%E6%8A%BD%E6%A3%80%E7%AD%96%E7%95%A5.png)

| **<UI-TERM key="ocp-performance-report.ReportTables.ParameterStatInfo.ZoneParamInfoTable.Parameter">参数</UI-TERM>** | **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.Description">说明</UI-TERM>** |
| --- | --- |
| 策略名称 | 单击 **<UI-TERM key="ocp-v2.Restore.SamplingStrategy.PolicyName">策略名称</UI-TERM>**，可进入策略总览页面，对该策略进行 **停止、编辑** 和 **删除。** |
| 抽检集群 | 单击 **<UI-TERM key="ocp-v2.Component.AddSamplingInspectStrategy.SpotCheckCluster">抽检集群</UI-TERM>**，可进入集群总览页面。 |
| 备份方式 | 包括 **<UI-TERM key="ocp-v2.Backup.Component.BackupNowDrawer.PhysicalBackup">物理备份</UI-TERM>** 和 **<UI-TERM key="ocp-v2.src.constant.backup.LogicalBackup">逻辑备份</UI-TERM>**。 |
| 目标集群 | 恢复数据的集群，将备份集群的数据恢复至目标集群。 |
| 目标租户 | 恢复数据的租户，将备份租户的数据恢复至目标租户。 |
| 创建时间 | 该策略的创建时间。 |
| 状态 | 包括 **开始、数据恢复中、日志恢复中、数据恢复失败、日志恢复失败、已完成** 等。 |
| 操作 | 您可通过操作后的 **停止、编辑** 和 **<UI-TERM key="ocp-v2.src.constant.binlog.Delete">删除</UI-TERM>**，对当前的抽检策略进行操作。 |
