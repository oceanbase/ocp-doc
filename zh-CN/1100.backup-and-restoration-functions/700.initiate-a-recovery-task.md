# 发起恢复

您可参考本页面对已备份的集群发起恢复。

您可通过如下三个入口发起恢复：

* **入口一**：登录 OCP，进入 **备份恢复 > 恢复** ，单击 **<UI-TERM key="ocp-v2.Backup.Component.RestoreNow.InitiateRecovery">发起恢复</UI-TERM>**。

* **入口二**：登录 OCP，进入集群 **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概览</UI-TERM>** 页面，在左侧导航栏选择 **<UI-TERM key="ocp-v2.Backup.BackupStrategy.Edit.BackupAndRestoration">备份恢复</UI-TERM>**，在该集群的 **<UI-TERM key="ocp-v2.Backup.Guide.BackupAndRestoration">备份恢复</UI-TERM>** 页面单击 **<UI-TERM key="ocp-v2.Backup.Restore.RestoreNow.InitiateRecovery">发起恢复</UI-TERM>** 。

   <main id="notice" type='explain'>
   <h4>说明</h4>
   <p>若有如下情况，则无法从入口二对该集群发起恢复：<ul><li>该集群状态不为 “运行中”。</li><li>该集群没有备份策略。</li></ul></p>
   </main>

* **入口三**：登录 OCP，进入租户 **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概览</UI-TERM>** 页面，在左侧导航栏选择 **<UI-TERM key="ocp-v2.Backup.Guide.BackupAndRestoration">备份恢复</UI-TERM>**，在该租户的 **<UI-TERM key="ocp-v2.Backup.BackupStrategy.New.BackupAndRestoration">备份恢复</UI-TERM>** 页面单击 **<UI-TERM key="ocp-v2.Backup.Restore.RestoreNow.InitiateRecovery">发起恢复</UI-TERM>** 。

   <main id="notice" type='explain'>
   <h4>说明</h4>
   <p>若有如下情况，则无法从入口三对该租户发起恢复：<ul><li>该租户状态不为 “运行中”。</li><li>该租户没有备份策略。</li></ul></p>
   </main>

## 前提条件

* 通过 **入口一** 发起恢复时，请确保当前登录 OCP 的用户具备如下权限：

  * **集群维护** 或 **租户维护** 资源权限。
  * 备份恢复 **<UI-TERM key="ocp-v2.Restore.SamplingStrategy.New.Recovery">恢复</UI-TERM>** 菜单权限。

* 通过 **入口二** 发起恢复时，请确保当前登录 OCP 的用户具备如下权限：

  * **集群维护** 资源权限。
  * 集群 **<UI-TERM key="ocp-v2.Detail.Backup.BackupAndRestoration">备份恢复</UI-TERM>** 菜单权限。

* 通过 **入口三** 发起恢复时，请确保当前登录 OCP 的用户具备如下权限：

  * **集群维护** 或 **租户维护** 资源权限。
  * 租户 **<UI-TERM key="ocp-v2.src.util.menu.BackupAndRestoration">备份恢复</UI-TERM>** 菜单权限。

* 对要恢复的内容，已执行了 [立即备份](400.backup-now/100.back-up-cluster-now.md) 。

* 已进行物理备份的 OceanBase 集群在发起备份恢复时，不支持从高版本恢复到低版本。

## 操作步骤

以下步骤以 **入口一** 为例。

1. 登录 OCP。

2. 在左导航栏单击 **备份恢复 > 恢复** 。

3. 进入 **<UI-TERM key="ocp-v2.Backup.Component.RestoreNow.Recovery">恢复</UI-TERM>** 页面，在右上方单击 **<UI-TERM key="ocp-v2.src.constant.backup.InitiateRecovery">发起恢复</UI-TERM>** 。

4. （可选）在全局页面发起恢复时，需填写存储配置，您可自定义或选择已有的存储配置。自定义时，需参考下述参数配置；选择已有配置时，单击 **<UI-TERM key="ocp-v2.Backup.Component.StorageConfigDropdown.SelectAnExistingConfiguration">选择已有配置</UI-TERM>** 下述参数会自动填充。

   <main id="notice" type='notice'>
   <h4>注意</h4>
   <p>当存在原生的 OSS、COS 存储类型时，建议优先使用 OSS、COS 方式进行配置。</p>
   </main>

    * **File**：本地文件存储，一般为 NFS。

      | 参数  |  说明  |
      |--------|-------|
      | 存储目录  |  备份文件在当前介质上的存储目录。  |
      | 解析主机  |  选择可访问该目录的主机。如解析逻辑备份，请选择备份恢复服务所在的主机；如解析物理备份，请选择 V2.2.70 及以上版本的 OceanBase 集群所在的主机。单击 **<UI-TERM key="ocp-v2.Component.StorageConfigCard.Parsing">解析</UI-TERM>** ，获取可恢复的集群列表。  |

    * **OSS**：阿里云 OSS 对象存储，仅 OceanBase V2.2.76 及以上版本支持。

      | 参数  |  说明  |
      |--------|-------|
      | 存储目录 | 选择备份文件所在的目录。   |
      | 访问域名 | 填写访问阿里云存储端的域名。如：`oss-cn-hangzhou.aliyuncs.com`。  |
      | 访问用户 | 填写访问阿里云存储端的 AccessKey ID。  |
      | 访问秘钥 | 填写访问阿里云存储端的 AccessKey Secret。  |
      | 解析主机 | 选择可访问该目录的主机。如解析逻辑备份，请选择备份恢复服务所在的主机；如解析物理备份，请选择 V2.2.70 及以上版本的 OceanBase 集群所在的主机。单击 **<UI-TERM key="ocp-v2.Component.StorageConfigCard.Parsing">解析</UI-TERM>** ，获取可恢复的集群列表。  |

    * **COS**：腾讯云 COS 对象存储，仅 OceanBase V2.2.76 及以上、V4.0 以下版本或者 V4.2.1 及以上版本支持。

      | 参数  |  说明  |
      |--------|-------|
      | 存储目录 | 选择备份文件所在的目录。  |
      | 访问域名 | 填写访问腾讯云 COS 存储桶中对象的域名。如：`cos.ap-beijing.myqcloud.com`。  |
      | 资源标志（APPID） | 开发者访问 COS 服务时拥有的用户维度唯一资源标识，可在对应产品的 API 秘钥管理页面获取。  |
      | 项目身份识别 ID | 开发者拥有的项目身份识别 ID，可在对应产品的 API 秘钥管理页面获取。  |
      | 项目身份秘钥 | 开发者拥有的项目身份秘钥，可在对应产品的 API 秘钥管理页面获取。  |
      | 解析主机 | 选择可访问该目录的主机。如解析逻辑备份，请选择备份恢复服务所在的主机；如解析物理备份，请选择 V2.2.70 及以上版本的 OceanBase 集群所在的主机。单击 **<UI-TERM key="ocp-v2.Component.StorageConfigCard.Parsing">解析</UI-TERM>** ，获取可恢复的集群列表。  |

    * **OBS**：华为云 OBS 对象存储，仅 OceanBase V3.2.3.2-105000062022090916 以上，V4.0.0.0 以下版本支持。

      | 参数  |  说明  |
      |--------|-------|
      | 存储目录 | 选择备份文件所在的目录。  |
      | 访问域名 | 填写访问华为云 OBS 对象的域名。如：`obs.cn-north-4.myhuaweicloud.com`。  |
      | AK | OBS 存储空间的秘钥 ID。  |
      | SK | OBS 存储空间的访问秘钥。  |
      | 解析主机 | 选择可访问该目录的主机。如解析逻辑备份，请选择备份恢复服务所在的主机；如解析物理备份，请选择 V2.2.70 及以上版本的 OceanBase 集群所在的主机。单击 **<UI-TERM key="ocp-v2.Component.StorageConfigCard.Parsing">解析</UI-TERM>** ，获取可恢复的集群列表。  |

    * **S3**：支持兼容 AWS S3 协议的存储介质，包含原生 AWS S3、华为云 OBS、天翼云 OBS 以及 Google GCS 等，仅 OceanBase V4.2.1-BP7 和 4.2.3-BP1(含) 及以上版本支持。关于 AWS S3 协议的存储介质说明，可参见 [S3 协议说明](../2100.appendix/900.s3-overview.md)。

      | 参数  |  说明  |
      |--------|-------|
      | 存储目录 | 备份文件在当前介质上的存储目录。  |
      | 访问域名 | 填写访问 S3 存储空间（Bucket）中对象的域名，如：`s3.us-west-2.amazonaws.com`。  |
      | AK | 填写 S3 存储空间的秘钥 ID。  |
      | SK | 填写 S3 存储空间的访问秘钥。  |
      | 地域 | 填写 S3 存储空间的地域信息。  |
      | 解析主机 | 选择可访问该目录的主机。如解析逻辑备份，请选择备份恢复服务所在的主机；如解析物理备份，请选择 V2.2.70 及以上版本的 OceanBase 集群所在的主机。单击 **<UI-TERM key="ocp-v2.Component.StorageConfigCard.Parsing">解析</UI-TERM>** ，获取可恢复的集群列表。  |

      <main id="notice" type='notice'>
      <h4>注意</h4>
      <p>当存储介质为 AWS S3 时，<b>地域</b> 信息为必填配置项，其余存储介质如华为云 OBS、天翼云 OBS 或 Google GCS 等则无需填写。</p>
      </main>

5. 填写 **<UI-TERM key="ocp-v2.Backup.Component.RestoreNow.RestoreSourceInformation">恢复源信息</UI-TERM>**。

   <main id="notice" type='explain'>
   <h4>说明</h4>

7. 填写如下参数配置 Zone ，并对 Zone 进行优先级排序。

   |   参数    |说明   |
   |---------|---|
   | 副本类型    | 取值范围： <ul><li>全能型副本：目前支持的普通副本，拥有事务日志、MemTable 和 SSTable 等全部完整的数据和功能。它可以随时快速切换为 Leader 以对外提供服务。</li><li> 日志型副本：只包含日志的副本，没有 MemTable 和 SSTable。它参与日志投票并对外提供日志服务，可以参与其他副本的恢复，但自己不能变为主提供数据库服务。   </li><li> 只读型副本：包含完整的日志、MemTable 和 SSTable 等。建议在业务对读取数据的一致性要求不高时选择。 </li></ul>   |
   | Unit 规格 | 该副本所占用的资源规格。 <ul><li>可选择已有规格。</li><li> 也可根据实际需要新建规格后再选择。 </li></ul>  |
