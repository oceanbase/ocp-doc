# 立即进行租户备份

您可参考本章节对租户进行立即备份。

您可通过如下两个入口对租户进行备份：

* **入口一**：登录 OCP，进入 **备份恢复 > 备份** ，在页面右上方 **<UI-TERM key="ocp-v2.src.constant.backup.BackUpNow">立即备份</UI-TERM>** 下拉列表中选择 **<UI-TERM key="ocp-v2.Backup.Backup.BackupTenant">备份租户</UI-TERM>** 。

* **入口二**：登录 OCP，进入租户 **<UI-TERM key="ocp-v2.page.Overview.Overview">概览</UI-TERM>** 页面，在左侧导航栏选择 **<UI-TERM key="ocp-v2.Backup.BackupStrategy.New.BackupAndRestoration">备份恢复</UI-TERM>**，单击 **<UI-TERM key="ocp-v2.Backup.Component.BackupNowDrawer.BackUpNow">立即备份</UI-TERM>** 。

## 前提条件

* 通过 **入口一** 对租户立即备份时，请确保当前登录 OCP 的用户具备如下权限：

  * **集群维护** 或 **租户维护** 资源权限。
  * 备份恢复 **<UI-TERM key="ocp-v2.Component.AddBackupStrategy.Backup">备份</UI-TERM>** 菜单权限。

* 通过 **入口二** 对租户立即备份时，请确保当前登录 OCP 的用户具备如下权限：

  * **集群维护** 或 **租户维护** 资源权限。
  * 租户 **<UI-TERM key="ocp-v2.src.constant.compute.BackupAndRestoration">备份恢复</UI-TERM>** 菜单权限。

* OceanBase 为 V3.2.2-20220304134610 及以上版本的租户才可进行租户备份。
* OceanBase 不支持备份处于已锁定状态的租户。

## 操作步骤

以下步骤以 **入口一** 为例。

1. 登录 OCP。

2. 单击左导航栏 **<UI-TERM key="ocp-v2.src.constant.compute.BackupAndRestoration">备份恢复</UI-TERM>** **\>** **<UI-TERM key="ocp-v2.src.constant.backup.Backup">备份</UI-TERM>** ，在页面右上方 **<UI-TERM key="ocp-v2.Detail.Backup.BackUpNow">立即备份</UI-TERM>** 下拉列表中选择 **<UI-TERM key="ocp-v2.Backup.Backup.BackupTenant">备份租户</UI-TERM>** 。

3. 选择备份对象。

   在 **<UI-TERM key="ocp-v2.Backup.Backup.BackupTenant">备份租户</UI-TERM>** 下拉列表中选择需要备份的对象，系统会自动识别租户的 **<UI-TERM key="ocp-v2.Cluster.New.ObVersion">OceanBase 版本</UI-TERM>**、**<UI-TERM key="ocp-v2.Backup.Backup.Log.BackupMethod">备份方式</UI-TERM>**，并自动填充 **<UI-TERM key="ocp-v2.Backup.Service.Detail.StorageConfiguration">存储配置</UI-TERM>** 。

4. 填写存储配置。

   * 若待备份的租户已有备份策略，则存储配置会自动填充。

   * 若待备份的租户无备份策略，则需手动填写存储配置。您可根据界面提示进行填写，或参考 [新建租户级备份策略](../500.regular-backup/200.manage-tenant-backup-strategy/100.creat-a-tenant-backup-stategy.md) 中的步骤 4 进行填写。

     填写完成后，单击 **<UI-TERM key="ocp-v2.Cluster.New.Test">测试</UI-TERM>** ，测试存储配置。

5. （可选）打开自定义备份范围功能开关。

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <ul>
    <li>当前支持自定义备份范围的 OceanBase 版本为：[4.2.1.11, 4.2.0) 和 [4.2.5.2, 4.3.0)。</li>
    <li>当存在租户级备份策略时，立即备份不支持自定义备份范围。</li>
    <li>数据备份默认从 Follower 副本读取备份数据，日志备份默认从 Leader 副本读取备份数据。</li>
    <li>选择需要备份的 Zone 时，需进行优先级排序，否则可能造成备份失败或产生跨机房流量。</li>
    <li>打开自定义备份范围功能开关时，不建议设置 Primary Zone 为 random。</li>
    </ul>
    </main>

   1. 选择数据备份类型：Zone、地域或机房，然后通过穿梭框设置 Zone、地域或机房的优先级。

   2. 选择日志备份类型：Zone、地域或机房，然后通过穿梭框设置 Zone、地域或机房的优先级。

      ![Image 49](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/436/%E8%87%AA%E5%AE%9A%E4%B9%89%E5%A4%87%E4%BB%BD%E8%8C%83%E5%9B%B4.jpg)

6. 选择数据备份方式。

   物理备份时需选择数据备份方式，逻辑备份时仅支持全量备份。

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <ul>
    <li>物理备份时，增量备份之前必须要有一次全量的数据备份，否则 <code>Check if ready to data backup</code> 步骤会报错提示&quot;full data backup needed before incremental data backup.&quot;</li>
    <li>全量备份时，如遇 <code>Start cluster compact if necessary</code> 步骤报错，且提示为&quot;Cluster compaction needed before full data backup&quot;。您可尝试 <a href="../../600.cluster-functions/1100.manage-cluster-merge/200.cluster-perform-merge.md">执行合并</a> 后，再单击 <strong>重试</strong> 按钮继续执行备份。</li>
    </ul>
    </main>

7. 单击 **<UI-TERM key="ocp-v2.Detail.Backup.BackUpNow">立即备份</UI-TERM>** 。
