# 复制恢复任务

本节为您介绍如何复制恢复任务信息。

您可通过如下三个入口复制恢复任务：

* **入口一**：登录 OCP，进入 **备份恢复 > 恢复** ，在 **<UI-TERM key="ocp-v2.Backup.Overview.Task.RestoreTask">恢复任务</UI-TERM>** 页签下，复制恢复任务。

* **入口二**：登录 OCP，进入集群 **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概览</UI-TERM>** 页面，在左侧导航栏选择 **备份恢复 > 恢复**，找到 **<UI-TERM key="ocp-v2.Backup.Overview.Task.RestoreTask">恢复任务</UI-TERM>** 页签，复制集群的恢复任务。

* **入口三**：登录 OCP，进入租户 **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概览</UI-TERM>** 页面，在左侧导航栏选择 **备份恢复 > 恢复**，找到 **<UI-TERM key="ocp-v2.Backup.Overview.Task.RestoreTask">恢复任务</UI-TERM>** 页签，复制租户的恢复任务。

## 前提条件

* 目标任务的状态必须为 **<UI-TERM key="ocp-v2.src.constant.backup.Completed">已完成</UI-TERM>**。

* 通过 **入口一** 复制恢复任务时，请确保当前登录 OCP 的用户具备如下权限：

  * **集群管理** 或 **<UI-TERM key="ocp-v2.src.util.menu.TenantManagement">租户管理</UI-TERM>** 资源权限。
  * 备份恢复 **<UI-TERM key="ocp-v2.src.constant.compute.Recovery">恢复</UI-TERM>** 菜单权限。

* 通过 **入口二** 复制恢复任务时，请确保当前登录 OCP 的用户具备如下权限：

  * **集群管理** 资源权限。
  * 集群 **<UI-TERM key="ocp-v2.Backup.BackupStrategy.Edit.BackupAndRestoration">备份恢复</UI-TERM>** 菜单权限。

* 通过 **入口三** 复制恢复任务时，请确保当前登录 OCP 的用户具备如下权限：

  * **集群管理** 或 **<UI-TERM key="ocp-v2.Detail.Tenant.TenantManagement">租户管理</UI-TERM>** 资源权限。
  * 租户 **<UI-TERM key="ocp-v2.Backup.BackupStrategy.New.BackupAndRestoration">备份恢复</UI-TERM>** 菜单权限。

## 操作步骤

以下步骤以 **入口一** 为例。

1. 登录 OCP。

2. 在左侧导航栏中单击 **备份恢复 > 恢复**。系统默认进入 **<UI-TERM key="ocp-v2.Backup.Overview.Task.RestoreTask">恢复任务</UI-TERM>** 页签。

3. 在 **<UI-TERM key="ocp-v2.Backup.Overview.Task.RestoreTask">恢复任务</UI-TERM>** 页签，找到目标任务并单击其 **<UI-TERM key="ocp-v2.Inspection.Component.TaskTable.Operation">操作</UI-TERM>** 列的 **<UI-TERM key="ocp-v2.component.TenantList.Copy">复制</UI-TERM>** 按钮。

4. 在 **<UI-TERM key="ocp-v2.Backup.Component.RestoreNow.CopyAndRestoreTasks">复制恢复任务</UI-TERM>** 页面，填写 **<UI-TERM key="ocp-v2.Backup.Component.RestoreNow.RestoreSourceInformation">恢复源信息</UI-TERM>**。

   * 租户恢复

      |  参数   |              说明               |
      |-------|-------------------------------|
      | 源集群   | 默认当前租户所在集群。 |
      | 源租户   | 默认当前租户。                    |
      | 恢复对象   | 请选择 **<UI-TERM key="ocp-v2.Arbitration.ArbitrationGroup.UpgradeArbitrationGroup.Tenant">租户</UI-TERM>**。                    |
      | 恢复日期  | 需在提示的可恢复时间段内。                 |

   * 库恢复

      <main id="notice" type='explain'>
      <h4>说明</h4>
      <p>仅 OceanBase 4.x 支持库恢复。</p>
      </main>

      |  参数   |              说明               |
      |-------|-------------------------------|
      | 源集群   | 默认当前租户所在集群。 |
      | 源租户   | 默认当前租户。                    |
      | 恢复对象   | 请选择 **<UI-TERM key="ocp-v2.Backup.Component.RestoreTenantCard.Library">库</UI-TERM>**。                    |
      | 恢复日期  | 需在提示的可恢复时间段内。                 |
      | 恢复库对象 | 从左侧 **<UI-TERM key="ocp-v2.Backup.Component.RestoreNow.RecoverableObject">可恢复对象</UI-TERM>** 中选择需要恢复的库，通过 **>** 添加到右侧 **<UI-TERM key="ocp-v2.component.TreeTransfer.SelectedObjects">已选对象</UI-TERM>** 中。需保持库名称唯一，OCP 支持对库进行重命名，如下图所示。  |

      ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/433/rename.png)

      <main id="notice" type='explain'>
      <h4>说明</h4>
      <p>最多支持选择 200 个库对象。</p>
      </main>

   * 表恢复

      <main id="notice" type='explain'>
      <h4>说明</h4>
      <p><ul><li>仅支持恢复用户表，不支持单独恢复列存表、临时表、视图、物化视图、物化视图日志、索引等。</li><li>表数据恢复成功即表示表恢复成功，允许索引、约束或其他关联的 Schema 恢复失败。</li></ul></p>
      </main>

      |  参数   |              说明               |
      |-------|-------------------------------|
      | 源集群   | 默认当前租户所在集群。 |
      | 源租户   | 默认当前租户。                    |
      | 恢复对象   | 请选择 **<UI-TERM key="ocp-v2.src.constant.tenant.Table">表</UI-TERM>**。                    |
      | 恢复日期  | 需在提示的可恢复时间段内。                 |
      | 恢复表对象 | 从左侧 **<UI-TERM key="ocp-v2.Backup.Component.RestoreNow.RecoverableObject">可恢复对象</UI-TERM>** 中选择需要恢复的表，通过 **>** 添加到右侧 **<UI-TERM key="ocp-v2.Backup.Component.RestoreNow.SelectedObjects">已选对象</UI-TERM>** 中。需保持表名称唯一，OCP 支持对表进行重命名，如下图所示。  |

      ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/433/table-rename.png)

      <main id="notice" type='explain'>
      <h4>说明</h4>
      <p>最多支持选择 200 个表对象。</p>
      </main>

6. 填写 **<UI-TERM key="ocp-v2.Backup.Component.RestoreTenantCard.RestoreTargetInformation">恢复目标信息</UI-TERM>**。

   * 租户恢复

      |  参数   |              说明               |
      |-------|-------------------------------|
      | 目标集群   | 请选择目标集群。 |
      | 目标租户   | 请选择目标租户。                    |
      | 各 Zone 的 Unit 数量   | Zone 中最少 OBServer 数决定 Unit 可设最大个数。                    |

   * 库恢复

      <main id="notice" type='explain'>
      <h4>说明</h4>
      <p>库表恢复过程中需要在目标集群中创建辅助租户，建议辅助租户规格与源租户保持一致并确保目标集群中具有充足的 CPU/Memory/磁盘资源，资源不足可能造成恢复缓慢或者恢复失败。库表恢复完成后系统会默认删除辅助租户。</p>
      </main>

      |  参数   |              说明               |
      |-------|-------------------------------|
      | 目标集群   | 请选择目标集群。 |
      | 目标租户   | 请选择目标租户。                    |
      | 各 Zone 的 Unit 数量   | Zone 中最少 OBServer 数决定 Unit 可设最大个数。                    |

   * 表恢复

      <main id="notice" type='explain'>
      <h4>说明</h4>
      <p>库表恢复过程中需要在目标集群中创建辅助租户，建议辅助租户规格与源租户保持一致并确保目标集群中具有充足的 CPU/Memory/磁盘资源，资源不足可能造成恢复缓慢或者恢复失败。库表恢复完成后系统会默认删除辅助租户。</p>
      </main>

      |  参数   |              说明               |
      |-------|-------------------------------|
      | 目标集群   | 请选择目标集群。 |
      | 目标租户   | 请选择目标租户。                    |
      | 各 Zone 的 Unit 数量   | Zone 中最少 OBServer 数决定 Unit 可设最大个数。                    |

7. 填写如下参数配置 Zone ，并对 Zone 进行优先级排序。

   |   参数    |说明   |
   |---------|---|
   | 副本类型    | 取值范围： <ul><li>全能型副本：目前支持的普通副本，拥有事务日志、MemTable 和 SSTable 等全部完整的数据和功能。它可以随时快速切换为 Leader 以对外提供服务。</li><li> 日志型副本：只包含日志的副本，没有 MemTable 和 SSTable。它参与日志投票并对外提供日志服务，可以参与其他副本的恢复，但自己不能变为主提供数据库服务。   </li><li> 只读型副本：包含完整的日志、MemTable 和 SSTable 等。建议在业务对读取数据的一致性要求不高时选择。 </li></ul>   |
   | Unit 规格 | 该副本所占用的资源规格。 <ul><li>可选择已有规格。</li><li> 也可根据实际需要新建规格后再选择。 </li></ul>  |
   | Unit 数量 | 该副本所占用的资源数量。<blockquote>**<UI-TERM key="ocp-v2.src.constant.alarm.Small">注意</UI-TERM>**</br>当所选恢复目标集群为 V4.0 及以上版本时，不支持配置单个 Zone 的 Unit 数量，您在此填写的 Unit 数量将适用于新建恢复租户下的所有 Zone。</blockquote>|

8. 单击 **<UI-TERM key="ocp-v2.Alarm.Template.Copy">复制</UI-TERM>** 。
