# 查看备份任务

本节为您介绍如何根据时间筛选查看普通备份的数据备份任务列表、日志备份任务列表、备份清理列表，并对任务进行启停等管理操作。

您可通过如下三个入口进行备份数据查看：

* **入口一**：登录 OCP，进入 **备份恢复 > 备份** ，在 **<UI-TERM key="ocp-v2.Backup.Overview.Task.BackupTask">备份任务</UI-TERM>** 页签下，查看备份相关信息。

* **入口二**：登录 OCP，进入集群 **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概览</UI-TERM>** 页面，在左侧导航栏选择 **<UI-TERM key="ocp-v2.Backup.BackupStrategy.Edit.BackupAndRestoration">备份恢复</UI-TERM>**，下翻找到 **<UI-TERM key="ocp-v2.Backup.Overview.Task.BackupTask">备份任务</UI-TERM>** 页签，查看集群的备份相关信息。

* **入口三**：登录 OCP，进入租户 **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概览</UI-TERM>** 页面，在左侧导航栏选择 **<UI-TERM key="ocp-v2.Backup.BackupStrategy.Edit.BackupAndRestoration">备份恢复</UI-TERM>**，下翻找到 **<UI-TERM key="ocp-v2.Backup.Overview.Task.BackupTask">备份任务</UI-TERM>** 页签，查看租户的备份相关信息。

## 前提条件

在 **<UI-TERM key="ocp-v2.Backup.Overview.Task.BackupTask">备份任务</UI-TERM>** 页面，针对不同的操作，要求用户需具备的权限有所不同：

* **查看任务信息**

  * 通过 **入口一** 查看备份任务信息时，请确保当前登录 OCP 的用户具备如下权限：

    * **集群只读** 或 **租户只读** 资源权限。
    * 备份恢复 **<UI-TERM key="ocp-v2.Component.AddBackupStrategy.Backup">备份</UI-TERM>** 菜单权限。

  * 通过 **入口二** 查看备份任务信息时，请确保当前登录 OCP 的用户具备如下权限：

    * **集群只读** 资源权限。
    * 集群 **<UI-TERM key="ocp-v2.Backup.Guide.BackupAndRestoration">备份恢复</UI-TERM>** 菜单权限。

  * 通过 **入口三** 查看备份任务信息时，请确保当前登录 OCP 的用户具备如下权限：

    * **集群只读** 或 **租户只读** 资源权限。
    * 租户 **<UI-TERM key="ocp-v2.Detail.Backup.BackupAndRestoration">备份恢复</UI-TERM>** 菜单权限。

* **停止备份任务** 或 **启动备份任务**

  * 通过 **入口一** 停止备份任务或启动备份任务时，请确保当前登录 OCP 的用户具备如下权限：

    * **集群维护** 或 **租户维护** 资源权限。
    * 备份恢复 **<UI-TERM key="ocp-v2.Component.AddBackupStrategy.Backup">备份</UI-TERM>** 菜单权限。

  * 通过 **入口二** 停止备份任务或启动备份任务时，请确保当前登录 OCP 的用户具备如下权限：

    * **集群维护** 资源权限。
    * 集群 **<UI-TERM key="ocp-v2.src.constant.compute.BackupAndRestoration">备份恢复</UI-TERM>** 菜单权限。

  * 通过 **入口三** 停止备份任务或启动备份任务时，请确保当前登录 OCP 的用户具备如下权限：

    * **集群维护** 或 **租户维护** 资源权限。
    * 租户 **<UI-TERM key="ocp-v2.Backup.Guide.BackupAndRestoration">备份恢复</UI-TERM>** 菜单权限。

## 操作步骤

以下步骤以 **入口一** 为例。

1. 登录 OCP。

2. 单击左导航栏 **备份恢复 > 备份** ，默认进入 **<UI-TERM key="ocp-v2.Backup.Overview.Task.BackupTask">备份任务</UI-TERM>** 页签中。

3. 查看数据备份任务。

    您可在 **<UI-TERM key="ocp-v2.Backup.Overview.Task.DataBackup">数据备份</UI-TERM>** 页签查看数据的 **ID**、**<UI-TERM key="ocp-v2.Detail.Component.DeleteTenantModal.BelongsCluster">所属集群</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.plan.Tenant">租户</UI-TERM>**、**<UI-TERM key="ocp-v2.Backup.Backup.Data.DataBackupMethod">数据备份方式</UI-TERM>**、**<UI-TERM key="ocp-v2.Backup.SecondaryBackup.Data.BackupSetId">备份集 ID</UI-TERM>**、**<UI-TERM key="ocp-v2.Trace.Visualizer.StartTime">开始时间</UI-TERM>**、**<UI-TERM key="ocp-v2.TraceDetail.TraceContent.EndTime">结束时间</UI-TERM>**、**<UI-TERM key="ocp-v2.Backup.Backup.Data.RecoverablePointInTime">可恢复时间点</UI-TERM>**、**<UI-TERM key="ocp-v2.Backup.Backup.Data.WhetherDoneSecondaryBackup">是否做过二次备份</UI-TERM>**、**<UI-TERM key="ocp-v2.Host.Detail.OCPAgent.State">状态</UI-TERM>** 和 **<UI-TERM key="ocp-v2.Backup.Service.Operation">操作</UI-TERM>**，并根据不同的状态对备份任务进行查看。详情请参见下表。

    您可通过右上方的时间选项选择 **<UI-TERM key="ocp-v2.Information.Detail.CreateCollectDrawer.NearlyHour">近 1 小时</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.backup.NearlyHours">近 24 小时</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.log.LastDays">近 7 天</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.backup.NearlyDays">近 30 天</UI-TERM>** 或 **<UI-TERM key="ocp-v2.component.RangeTimeDropdown.CustomTime">自定义时间</UI-TERM>** ，根据时间对数据备份任务进行筛选。

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/backup/%E6%95%B0%E6%8D%AE%E5%A4%87%E4%BB%BD-1.png)

    | **<UI-TERM key="ocp-v2.component.ParameterTemplate.Parameter">参数</UI-TERM>** | **<UI-TERM key="ocp-v2.page.Settings.Profile.Description">说明</UI-TERM>** |
    | --- | --- |
    | ID | 单击 ID 左侧的 **+** 按钮，可展开查看 **<UI-TERM key="ocp-v2.Component.BackupStrategyDetail.BackupMethod">备份方式</UI-TERM>**、**<UI-TERM key="ocp-v2.Backup.Backup.Data.BackupDuration">备份时长</UI-TERM>**、**<UI-TERM key="ocp-v2.Backup.Backup.Data.DataVersion">数据版本</UI-TERM>** 及 **<UI-TERM key="ocp-v2.src.component.ArchiveForm.StorageDirectory">存储目录</UI-TERM>**。 |
    | 所属集群 | 单击 **<UI-TERM key="ocp-v2.Component.AddZoneDrawer.BelongsCluster">所属集群</UI-TERM>**，会进入该集群 **<UI-TERM key="ocp-v2.Backup.Component.RestoreNow.BackupAndRestoration">备份恢复</UI-TERM>** 页面。 |
    | 租户 | 单击 **<UI-TERM key="ocp-v2.alarm.FormListWithExclude.TenantWithExclude.Tenant">租户</UI-TERM>**，会进入该租户 **<UI-TERM key="ocp-v2.src.util.menu.BackupAndRestoration">备份恢复</UI-TERM>** 页面。 |
    | 数据备份方式 | 包括 **<UI-TERM key="ocp-v2.src.constant.backup.Total">全量</UI-TERM>** 和 **<UI-TERM key="ocp-v2.src.constant.backup.Incremental">增量</UI-TERM>**。 |
    | 备份集 ID | 用于标记物理备份中全量数据备份与增量数据备份的关系，ID 相同的全量备份与增量备份是对应的。 |
    | 开始时间 | 备份开始时间点。 |
    | 结束时间 | 备份结束时间点。 |
    | 可恢复时间点 | 备份恢复可选择的时间点。 |

    | 状态 | 数据备份状态。支持对备份状态进行筛选。<blockquote>**<UI-TERM key="ocp-v2.page.MultiCluster.Parameter.Description">说明</UI-TERM>**</br>当 OceanBase 为 V2.2.77 以上、V4.0 以下版本时，支持查看任务进度百分比。</blockquote> |

4. 查看日志备份任务。

    您可在 **<UI-TERM key="ocp-v2.Component.AddBackupStrategy.LogBackup">日志备份</UI-TERM>** 页签查看数据的 **所属集群、租户、备份方式、服务所属的主机 IP、最新备份时间点、延时（s）、存储目录、开始时间、状态** 和 **<UI-TERM key="ocp-v2.Settings.Credential.Host.Operation">操作</UI-TERM>**，并根据不同的状态对备份任务进行查看。详情请参见下表。

    您可通过右上方的时间选项选择 **近 1 小时、近 24 小时、近 7 天、近 30 天** 或 **<UI-TERM key="ocp-v2.component.RangeTimeDropdown.CustomTime">自定义时间</UI-TERM>** ，根据时间对日志备份任务进行筛选。

    | **<UI-TERM key="ocp-performance-report.ReportTables.ParameterStatInfo.TenantParamInfoTable.Parameter">参数</UI-TERM>** | **<UI-TERM key="ocp-v2.Inspection.Item.ConfigItem.Description">说明</UI-TERM>** |
    | --- | --- |
    | 所属集群 | 单击 **<UI-TERM key="ocp-v2.Component.OBServerList.OBServerModal.BelongsCluster">所属集群</UI-TERM>**，会进入该集群 **<UI-TERM key="ocp-v2.Backup.BackupStrategy.Edit.BackupAndRestoration">备份恢复</UI-TERM>** 页面。 |
    | 租户 | 单击 **<UI-TERM key="ocp-v2.Alarm.Event.Detail.Tenant">租户</UI-TERM>**，会进入该租户 **<UI-TERM key="ocp-v2.Backup.Component.RestoreNow.BackupAndRestoration">备份恢复</UI-TERM>** 页面。 |
    | 备份方式 | 该集群的备份方式，包括 **<UI-TERM key="ocp-v2.Backup.Component.BackupNowDrawer.LogicalBackup">逻辑备份</UI-TERM>** 和 **<UI-TERM key="ocp-v2.Component.AddBackupStrategy.PhysicalBackup">物理备份</UI-TERM>**。 |

    | 存储目录 | 备份存储目录。 |
    | 开始时间 | 备份开始时间点。 |

5. 查看备份清理任务。

   <main id="notice" type='explain'>
     <h4>说明</h4>
     <p>备份清理仅支持逻辑备份。支持逻辑备份的版本为 OceanBase 2.2.60 以下版本。</p>
   </main>

    您可在 **<UI-TERM key="ocp-v2.Backup.Overview.Task.BackupCleanup">备份清理</UI-TERM>** 页签查看数据的     **ID**、**所属集群、开始时间、结束时间** 和 **<UI-TERM key="ocp-v2.page.Host.State">状态</UI-TERM>**，并根据不同的状态对备份任务进行查看。

    您可通过右上方的时间选项选择 **近 1 小时、近 24 小时、近 7 天、近 30 天** 或 **<UI-TERM key="ocp-v2.component.OCPRangePicker.CustomTime">自定义时间</UI-TERM>** ，根据时间对备份清理任务进行筛选。
