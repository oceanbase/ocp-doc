# 新建告警推送

通过新建告警推送，系统会将平台产生的告警消息通过指定的告警通道通知用户。

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **集群维护**、**租户维护**、**OBProxy 维护**、**仲裁服务维护**、**Binlog 服务维护** 或 **主机维护** 任一资源权限。
  * 告警中心 **<UI-TERM key="ocp-v2.Detail.Component.RestartModal.All">全部</UI-TERM>** 菜单权限。

* 已 [新建告警规则](../300.manage-alert-rules/100.create-an-alert-rule.md) 。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏中单击 **<UI-TERM key="ocp-v2.page.Alarm.Alarm">告警中心</UI-TERM>**。

3. 单击 **<UI-TERM key="ocp-v2.Alarm.Subscriptions.New.AlertPush">告警推送</UI-TERM>** 页签。

4. 在告警推送页签中，单击 **<UI-TERM key="ocp-v2.Alarm.Subscriptions.CreatePushConfiguration">新建推送配置</UI-TERM>** 按钮。

5. 进入 **<UI-TERM key="ocp-v2.Alarm.Subscriptions.New.CreatePush">新建推送</UI-TERM>** 页面，在 **<UI-TERM key="ocp-v2.Alarm.Subscriptions.New.PushConfiguration">推送配置</UI-TERM>** 模块选择推送类型。

   系统支持 **<UI-TERM key="ocp-v2.src.constant.alarm.AlarmClassification">告警分类</UI-TERM>** 推送和 **<UI-TERM key="ocp-v2.Alarm.Template.Detail.AlertTemplate">告警模板</UI-TERM>** 两种推送模式。

   * **<UI-TERM key="ocp-v2.src.constant.alarm.AlarmClassification">告警分类</UI-TERM>**

      当选择 **<UI-TERM key="ocp-v2.Alarm.Rule.New.AlarmClassification">告警分类</UI-TERM>** 推送时，您可选择将告警消息推送至指定对象。若您不设置指定对象，系统将根据分组配置规则及告警对象配置推送告警消息。

      <main id="explain" type='alert'>
      <h4>说明</h4>
      <p><ul><li>需要为应用至少选择一个对象范围。</li><li>OCP 应用中，当对象范围选择 <b>服务</b> 及 <b>备份恢复</b> 时，无需配置指定对象。</li><li>OMS 应用中，当对象范围选择 <b>服务</b> 时，无需配置指定对象。</li></ul></p>
      </main>

      ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/421/alarm/%E6%96%B0%E5%BB%BA%E6%8E%A8%E9%80%81%E9%85%8D%E7%BD%AE-1.png)

   * **<UI-TERM key="ocp-v2.page.Alarm.AlertTemplate">告警模板</UI-TERM>**

      当选择 **<UI-TERM key="ocp-v2.Alarm.Subscriptions.Detail.AlertTemplate">告警模板</UI-TERM>** 推送时，页签下方将展示系统中所有的告警模板，勾选需要推送消息的模板，告警消息将推送至该模板中的所有对象。

      <main id="notice" type='explain'>
      <h4>说明</h4>
      <p>当告警模板未设置告警对象时，该模板将置灰无法进行勾选。您可参考 <a href="../400.manage-alert-templates/200.set-alert-objects.md">设置告警对象</a> 为告警模板添加告警对象。</p>
      </main>

      ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/421/alarm/%E6%96%B0%E5%BB%BA%E6%8E%A8%E9%80%81%E9%85%8D%E7%BD%AE-2.png)

6. 在 **<UI-TERM key="ocp-v2.Alarm.Subscriptions.New.PushMessageConfiguration">推送消息配置</UI-TERM>** 模块配置以下内容：

   1. 选择推送消息语言，支持 **<UI-TERM key="ocp-v2.Alarm.Channel.New.SimplifiedChinese">简体中文</UI-TERM>**、**<UI-TERM key="ocp-v2.Alarm.Channel.Detail.TraditionalChinese">繁体中文</UI-TERM>** 和 **<UI-TERM key="ocp-v2.Alarm.Subscriptions.Detail.English">英文</UI-TERM>**。

   2. 配置告警方式，包括 **<UI-TERM key="ocp-v2.page.Overview.AlarmLevel">告警等级</UI-TERM>**、**<UI-TERM key="ocp-v2.Alarm.Event.Detail.AlertChannel">告警通道</UI-TERM>** 和 **<UI-TERM key="ocp-v2.Alarm.Subscriptions.New.NotificationPeriod">通知时段</UI-TERM>**。

      若您不想在某个时间段接收告警推送消息，可设置指定时间推送，不设置则表示全天接收告警消息通知。

      <main id="notice" type='explain'>
      <h4>说明</h4>
      <p>您需至少为一个告警等级配置告警通道。</p>
      </main>

      ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/%E5%91%8A%E8%AD%A6%E6%B6%88%E6%81%AF%E6%8E%A8%E9%80%81.png)

   3. 选择是否开启 **<UI-TERM key="ocp-v2.Alarm.Subscriptions.Detail.AlarmMessageReceivingLimit">告警消息接收限制</UI-TERM>**。

      开启后可以限定告警通道发送消息的数量，当超过告警接收限制，告警通道将不再推送告警消息。

      ![4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E5%91%8A%E8%AD%A6%E6%B6%88%E6%81%AF%E6%8E%A5%E6%94%B6%E9%99%90%E5%88%B61.png)

   4. 选择是否开启 **<UI-TERM key="ocp-v2.Alarm.Subscriptions.Detail.RecoveryNotification">恢复通知</UI-TERM>**。

      开启后，当告警事件变更为已恢复状态时，会发送告警恢复通知消息。

   5. 选择是否 **<UI-TERM key="ocp-v2.Alarm.Subscriptions.Detail.EnablePush">启用推送</UI-TERM>**。

      对于创建后暂时不再使用的告警推送，您后续可在此处对其进行禁用。

7. 单击 **<UI-TERM key="ocp-v2.Template.Component.AddTargetDrawer.Submit">提交</UI-TERM>**。
