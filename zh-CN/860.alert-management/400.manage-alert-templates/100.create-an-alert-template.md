# 新建告警模板

OCP 系统内置了部分通用的告警模板，满足您对业务的日常监控需求，除此以外您还可参考本节定制您业务所需的告警模板，为业务对象统一设置告警规则。

相比较 [新建告警规则](../300.manage-alert-rules/100.create-an-alert-rule.md)，新建告警模板可以更快速地为业务对象批量设置告警规则。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **集群维护**、**租户维护**、**OBProxy 维护**、**仲裁服务维护**、**Binlog 服务维护** 或 **主机维护** 任一资源权限。
* 告警中心 **<UI-TERM key="ocp-v2.component.alarm.AlarmTargetLabel.All">全部</UI-TERM>** 菜单权限。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏中单击 **<UI-TERM key="ocp-v2.page.Alarm.Alarm">告警中心</UI-TERM>**。

3. 单击 **<UI-TERM key="ocp-v2.Alarm.Subscriptions.Detail.AlertTemplate">告警模板</UI-TERM>** 页签。

4. 在告警模板页签下，将光标悬停于右上角的 **<UI-TERM key="ocp-v2.Alarm.Template.CreateAnAlertTemplate">新建告警模板</UI-TERM>**，在菜单栏中选择模板类型。

5. 配置告警模板的 **<UI-TERM key="ocp-performance-report.pages.AWR.BasicInformation">基本信息</UI-TERM>**。

      输入 **<UI-TERM key="ocp-v2.component.ParameterTemplate.DetailDrawer.TemplateName">模板名</UI-TERM>** 及 **<UI-TERM key="ocp-v2.Alarm.Template.Detail.Description">说明</UI-TERM>**，并选择是否 **<UI-TERM key="ocp-v2.Alarm.Template.New.EnableTemplate">启用模板</UI-TERM>**。

      ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E6%A8%A1%E6%9D%BF%E5%9F%BA%E7%A1%80%E4%BF%A1%E6%81%AF1.png)

      对于系统内置告警模板及创建后暂时不再使用的告警模板，您后续可在此处对其进行禁用。

6. 配置告警规则信息。

   1. 选择告警规则类型。

      依据实际需要，切换告警规则类型页签。页签的显示根据模板类型的选择而有所不同。

      |  模板类型  |  告警规则类型   |
      |--------|---------|
      | OceanBase 模板    | <ul><li>集群告警</li> <li>租户告警</li><li>OBServer 告警</li></ul> |
      | OBProxy 模板   | <ul><li>OceanBase 集群告警</li> <li>OBProxy 集群告警</li></ul>   |
      | OCP 模板   |  <ul><li>备份恢复告警</li> <li>服务告警</li><li>主机告警</li></ul> |
      | 日志模板   | <ul><li>OceanBase 告警</li> <li>OBProxy 告警</li><li>主机告警</li> </ul> |

   2. 单击 **<UI-TERM key="ocp-v2.Alarm.Template.New.AddRule">添加规则</UI-TERM>** 按钮，在弹出的菜单栏中选择需要添加的规则。

      ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E6%B7%BB%E5%8A%A0%E8%A7%84%E5%88%991.png)

   3. 配置告警规则的 **<UI-TERM key="ocp-v2.Alarm.Rule.TriggerCondition">触发条件</UI-TERM>** 和 **<UI-TERM key="ocp-v2.Alarm.Rule.New.AlarmCycle">告警周期</UI-TERM>** 等信息。

   4. 单击左侧 **<UI-TERM key="ocp-v2.Alarm.Template.Detail.Rules">规则</UI-TERM>** 列表的 **<UI-TERM key="ocp-v2.Alarm.Template.New.AddRule">添加规则</UI-TERM>** ，为告警对象设置多个告警规则。

      告警规则设置可参考 [新建告警规则](../300.manage-alert-rules/100.create-an-alert-rule.md) 中的相关说明。

7. 单击 **<UI-TERM key="ocp-v2.Oracle.Component.AddOracleUserOrRoleDrawer.Submitted">提交</UI-TERM>** 。

   在提交结果页面中，可选择 **<UI-TERM key="ocp-v2.Template.Component.Result.ReturnToTemplateList">返回模板列表</UI-TERM>** 或对模板 **<UI-TERM key="ocp-v2.Alarm.Template.Detail.SetAlertObjects">设置告警对象</UI-TERM>** 。
