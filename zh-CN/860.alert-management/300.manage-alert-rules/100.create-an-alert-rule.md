# 新建告警规则

OCP 系统内置了部分告警规则满足您对业务的日常监控需求，除此以外您还可参考本节定制您业务所需的告警规则。相比较 [新建告警模板](../400.manage-alert-templates/100.create-an-alert-template.md)，新建告警规则可以更灵活地为每个规则都指定告警对象。

关于各内置告警规则的详细信息您可参考 [告警参考](../../1900.reference-guide/100.alarm-reference/100.alert-reference-overview.md)。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **集群维护**、**租户维护**、**OBProxy 维护**、**仲裁服务维护**、**Binlog 服务维护** 或 **主机维护** 任一资源权限。
* 告警中心 **<UI-TERM key="ocp-v2.page.Task.All">全部</UI-TERM>** 菜单权限。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏中单击 **<UI-TERM key="ocp-v2.src.hook.useMenu.AlarmCenter">告警中心</UI-TERM>**。

3. 进入 **<UI-TERM key="ocp-v2.Alarm.Event.Detail.AlertRules">告警规则</UI-TERM>** 页签，单击 **<UI-TERM key="ocp-v2.Alarm.Rule.CreateAlertRule">新建告警规则</UI-TERM>** 。

4. 进入 **新建告警规则** 页面，参考如下步骤配置告警规则相关信息。

### 步骤一：配置基本信息

1. 设置 **<UI-TERM key="ocp-v2.Alarm.Rule.New.AlertRuleName">告警规则名</UI-TERM>** 。  

   第三方应用通过 **<UI-TERM key="ocp-v2.Alarm.Rule.Detail.AlertRuleName">告警规则名</UI-TERM>** 对接 OCP 中的告警。仅支持字母、数字和下划线，建议遵循如下命名规则：

   * OceanBase 集群相关的告警，以 `ob_cluster_` 为前缀。
   * OceanBase 租户相关的告警，以 `ob_tenant_` 为前缀。
   * OceanBase 服务器相关的告警，以 `ob_host_` 为前缀。
   * OCP 服务器相关的告警，以 `host_` 为前缀。
   * OCP 服务相关的告警，以 `ocp_service_` 为前缀。
   * OBProxy 集群相关的告警，以 `obproxy_cluster_` 为前缀。
   * OBProxy 服务器相关的告警，以 `obproxy_host_` 为前缀。

2. 设置 **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.Description">说明</UI-TERM>**，需能够简要表明该告警规则的作用。

3. 设置 **<UI-TERM key="ocp-v2.Alarm.Event.AlarmClassification">告警分类</UI-TERM>**，将该告警规则加入到已有的告警分组中。

4. 选择是否 **<UI-TERM key="ocp-v2.Alarm.Rule.New.EnableAlerts">启用告警</UI-TERM>**，对于系统内置告警规则及创建后暂时不再使用的告警规则，您后续可在此处对其进行禁用。

![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/%E5%9F%BA%E6%9C%AC%E9%85%8D%E7%BD%AE.png)

### 步骤二：配置告警规则

针对不同的应用类型，告警规则的配置会有所不同。您可根据业务需求配置不同的运算规则，系统将根据您配置的告警规则，上报不同级别的告警。

下面将为您介绍如何新建非日志型告警规则，以及如何新建日志型告警规则。

#### 新建非日志型告警规则

1. 设置告警对象。

   |  告警对象  |  配置说明   |
   |--------|---------|
   | 应用     | 告警来源，请选择 OceanBase、OBProxy、OCP、OMS、OBLB、OBDNS 或 Binlog。  |
   | 告警对象类型   | 依据实际需要，选择告警规则的对象类型。选项的显示根据 **<UI-TERM key="ocp-v2.Alarm.Subscriptions.Application">应用</UI-TERM>** 的选择而有不同。   |
   | 集群   | 依据实际需要，选择具体的告警对象。当对象选择 **<UI-TERM key="ocp-v2.component.HostSelect.All">全部</UI-TERM>** 时，告警对象将包含当前告警对象类型下的已有对象和未来新增对象，您可通过勾选右侧的 **<UI-TERM key="ocp-v2.alarm.FormListWithExclude.ObproxyClusterWithExclude.ExcludeObjects">排除对象</UI-TERM>**，对不需要使用该告警规则的对象进行排除。  |

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/%E5%91%8A%E8%AD%A6%E5%AF%B9%E8%B1%A1.png)

2. 设置告警规则。

   * **单指标**

      为告警上报配置单一化的运算规则。多个规则之间不能存在相同的阈值和级别，最多只能配置 5 个规则。

      |  参数  |  说明   |
      |--------|---------|
      | 指标     | 在 **<UI-TERM key="ocp-v2.component.alarm.RuleDetail.Metric">指标</UI-TERM>** 下拉框中选择，具体指标含义可在 [告警参考](../../1900.reference-guide/100.alarm-reference/100.alert-reference-overview.md) 中搜索对应的指标了解。</br> 单击 **<UI-TERM key="ocp-v2.Alarm.Rule.New.Indicators">指标</UI-TERM>** 下拉框中的 **<UI-TERM key="ocp-v2.Alarm.Rule.New.AddMetric">添加指标</UI-TERM>** 按钮，您可进行自定义告警指标，请参见 [自定义告警可选监控指标](../1000.monitoring-metrics-for-customizable-alarm.md)。|
      | 运算符   | 配置指标的运算规则符号。   |
      | 阈值     | 配置指标的告警阈值。   |
      | 持续时长（秒） | 配置告警持续时间，为 0 时表示符合运算规则立即触发。   |
      | 告警等级 | 配置告警的等级。 |

      ![Image 98](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E5%8D%95%E6%8C%87%E6%A0%87%E5%91%8A%E8%AD%A6%E8%A7%84%E5%88%991.png)

   * **多指标**

      多指标适用于更复杂的告警场景，支持对告警规则配置多层级的 **AND** 或 **OR** 的指标关系。

      |  参数  |  说明   |
      |--------|---------|
      | 指标关系 | 为多个指标选择运算方式。可选择 **AND** 或 **OR**，**AND** 为同时满足，**OR** 为满足任一即可。 |
      | 指标     | 在 **<UI-TERM key="ocp-v2.Alarm.Template.Detail.Indicators">指标</UI-TERM>** 下拉框中选择，具体指标含义可在 [告警参考](../../1900.reference-guide/100.alarm-reference/100.alert-reference-overview.md) 中搜索对应的指标了解。</br> 单击 **<UI-TERM key="ocp-v2.Alarm.Rule.New.Indicators">指标</UI-TERM>** 下拉框中的 **<UI-TERM key="ocp-v2.Alarm.Rule.New.AddMetric">添加指标</UI-TERM>** 按钮，您可进行自定义告警指标，请参见 [自定义告警可选监控指标](../1000.monitoring-metrics-for-customizable-alarm.md)。|
      | 添加规则   | 可为指标添加多个规则，系统将根据所选的指标关系对规则进行运算。   |
      | 添加规则组 | 规则组即为多个指标的运算合集，需要在规则组中对多个指标配置指标关系。 |
      | 持续时间   | 配置告警持续时间，为 0 时表示符合运算规则立即触发。   |
      | 告警等级   | 配置告警的等级。 |

      以下图多指标配置为例，当一台服务器的资源指标达到如下条件之一，并且持续 2 分钟后触发严重告警：

      * 内存使用率超过 95%。
      * NTP 时钟偏移超过 100ms。
      * CPU 使用率超过 95% 且平均 load1 超过 2。

      ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E5%A4%9A%E6%8C%87%E6%A0%87%E8%BF%90%E7%AE%97%E8%A7%84%E5%88%991.png)

3. 设置 **<UI-TERM key="ocp-v2.Alarm.Template.Detail.AlarmCycle">告警周期</UI-TERM>** 。

   即设置告警的检测周期、是否自动消除即消除周期。

   * 检测周期：即告警的指标检测周期，系统会在每个检测周期检查告警是否满足触发条件，检测周期默认为 60 秒。
     * 上报告警前，每 60 秒检测一次触发条件是否达到，达到则上报告警。
     * 上报告警后，每个 **<UI-TERM key="ocp-v2.Alarm.Template.Detail.DetectionCycle">检测周期</UI-TERM>** 检查告警是否依然还满足触发条件，满足则持续上报。

   * 自动消除：选择系统是否自动消除告警。关闭自动消除后，告警消息会保留在 **<UI-TERM key="ocp-v2.page.Alarm.AlarmEvent">告警事件</UI-TERM>** 列表中不会消除，您可在列表中确认该告警的影响范围，并选择是否手动消除该条告警；开启自动消除后，系统将按照 **<UI-TERM key="ocp-v2.Alarm.Rule.Detail.EliminationCycle">消除周期</UI-TERM>** 对告警进行消除。

   * 消除周期：仅 **自动消除** 开启时可配置，即设置告警上报的持续时间。消除周期设置完成后，系统会在所设置的时间周期后对该告警进行消除。消除周期默认为 5 分钟。

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/%E5%91%8A%E8%AD%A6%E5%91%A8%E6%9C%9F.png)

#### 新建日志型告警规则

1. 设置告警对象。

   |  告警对象  |  配置说明   |
   |--------|---------|
   | 应用     | 告警来源，请选择 **日志**。  |
   | 告警对象类型   | 依据实际需要，选择告警规则的对象类型，可选 OceanBase 日志、OBProxy 日志或主机日志。   |
   | OBServer   | 依据实际需要，选择具体的告警对象。当对象选择 **<UI-TERM key="ocp-v2.component.HostSelect.All">全部</UI-TERM>** 时，告警对象将包含当前告警对象类型下的已有对象和未来新增对象，您可通过勾选右侧的 **<UI-TERM key="ocp-v2.alarm.FormListWithExclude.ObproxyClusterWithExclude.ExcludeObjects">排除对象</UI-TERM>**，对不需要使用该告警规则的对象进行排除。  |

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/%E5%91%8A%E8%AD%A6%E5%AF%B9%E8%B1%A1.png)

2. 设置告警规则。

   |  参数          |  说明   |
   |----------------|---------|
   | 指标           | 在 **<UI-TERM key="ocp-v2.component.alarm.RuleDetail.Metric">指标</UI-TERM>** 下拉框中选择，具体指标含义可在 [告警参考](../../1900.reference-guide/100.alarm-reference/100.alert-reference-overview.md) 中搜索对应的指标了解。</br> 单击 **<UI-TERM key="ocp-v2.Alarm.Rule.New.Indicators">指标</UI-TERM>** 下拉框中的 **<UI-TERM key="ocp-v2.Alarm.Rule.New.AddMetric">添加指标</UI-TERM>** 按钮，您可进行自定义告警指标，请参见 [自定义告警可选监控指标](../1000.monitoring-metrics-for-customizable-alarm.md)。|
   | 日志级别       | 当 **告警对象类型** 为 OceanBase 日志或 OBProxy 日志时，需选择日志内容的日志级别，当指定日志类型无日志级别配置时则置空。当日志内容为所指定的日志级别时，将产生告警。<li>OceanBase 日志：可选择 **ERROR**、**WARN**、**INFO**、**WDIAG**、**EDIAG**、**TRACE**，支持多选。</li><li>OBProxy 日志：可选择 **ERROR**、**WARN**、**INFO**，支持多选。</li>   |
   | 关键字         | 指定日志告警的关键字，当日志中记录中存在指定关键字时将触发告警。支持输入多个关键字，若置空则对对应日志级别的所有日志内容产生告警。<li>**任意关键字**：当日志记录中存在所指定的任意一个关键字时，即会触发告警。</li><li>**全部关键字**：当日志记录中存在所指定的全部关键字时，才会触发告警。</li>  |
   | 持续时长（秒） | 配置告警的持续时间，为 0 时表示符合运算规则立即触发。   |
   | 告警等级       | 配置告警的等级，包括 **停服**、**严重**、**警告**、**注意** 和 **提醒** 5 种等级。 |
   | 过滤关键字     | 指定过滤告警的关键字，支持输入多个。设置后，当日志记录中存在指定关键字时将不触发告警。<li>**任意关键字**：当日志记录中存在所指定的任意一个关键字时，将不会触发告警。</li><li>**全部关键字**：当日志记录中存在所指定的全部关键字时，才不会触发告警。</li>  |

   以下图为例， 当 `rootservice_log` 满足如下条件时，将立即触发告警：

   * 日志级别为 **ERROR** 或 **WARNING**、日志记录中存在 `observice start\(\) has failure`、`ret=-4393`、`observice init\(\) has failure`、`observer init\(\) has failure` 任一关键字，告警等级为 **停服**。
   * 当日志级别为 **ERROR**、日志记录中存在 `ret=-4394` 关键字，告警等级为 **严重**。
   * 当日志级别为 **WARNING**、日志记录中存在 `ret=-4165`、`errcode=-4165`、`ret=-41652`、`errcode=-41652` 任一关键字，告警等级为 **提醒**。

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/436/06271540.png)

3. 设置 **<UI-TERM key="ocp-v2.Alarm.Template.Detail.AlarmCycle">告警周期</UI-TERM>**。

   即设置告警的消除周期及是否自动消除。

   * 自动消除：选择系统是否自动消除告警。关闭自动消除后，告警消息会保留在 **<UI-TERM key="ocp-v2.page.Alarm.AlarmEvent">告警事件</UI-TERM>** 列表中不会消除，您可在列表中确认该告警的影响范围，并选择是否手动消除该条告警；开启自动消除后，系统将按照 **<UI-TERM key="ocp-v2.Alarm.Rule.Detail.EliminationCycle">消除周期</UI-TERM>** 对告警进行消除。

   * 消除周期：仅 **自动消除** 开启时可配置，即设置告警上报的持续时间。消除周期设置完成后，系统会在所设置的时间周期后对该告警进行消除。消除周期默认为 5 分钟。

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/%E5%91%8A%E8%AD%A6%E5%91%A8%E6%9C%9F.png)

### 步骤四：配置告警详情

   可通过 `${}` 引用变量。告警详情模板会在告警事件中显示，并且对应变量 ${alarm_description}，这个变量可以在告警消息的模板中被引用。

   ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E5%91%8A%E8%AD%A6%E8%AF%A6%E6%83%85%E9%85%8D%E7%BD%AE1.png)

### 步骤五：提交任务

单击 **<UI-TERM key="ocp-v2.Alarm.Channel.New.Submit">提交</UI-TERM>**。
