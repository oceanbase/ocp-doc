# 查看告警事件

本章节为您介绍如何查看告警事件详情和如何短暂屏蔽该告警事件。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **集群只读**、**租户只读**、**OBProxy 只读**、**仲裁服务只读**、**Binlog 服务只读** 或 **主机只读** 任一资源权限。
* 告警中心 **<UI-TERM key="ocp-v2.Detail.Component.RestartModal.All">全部</UI-TERM>** 菜单权限。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏中单击 **<UI-TERM key="ocp-v2.src.hook.useMenu.AlarmCenter">告警中心</UI-TERM>** 。

3. 系统默认进入 **<UI-TERM key="ocp-v2.page.Alarm.AlarmEvent">告警事件</UI-TERM>** 页签中。

4. 在查询框中设置查询条件，**<UI-TERM key="ocp-v2.page.Alarm.AlarmEvent">告警事件</UI-TERM>** 列表中将返回所有符合查询条件的告警事件。

    * 支持对告警事件根据 **<UI-TERM key="ocp-v2.Alarm.Rule.AddAlarmMetricModal.Application">应用</UI-TERM>**、**<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.ObjectType">对象类型</UI-TERM>**、**<UI-TERM key="ocp-v2.page.Overview.AlarmLevel">告警等级</UI-TERM>**、**<UI-TERM key="ocp-v2.Alarm.Template.Keywords">关键词</UI-TERM>**、**<UI-TERM key="ocp-v2.page.Task.StartTime">开始时间</UI-TERM>**、**<UI-TERM key="ocp-v2.TraceContent.PlanOperation.EndTime">结束时间</UI-TERM>** 等条件进行精确查找。

    * 可以通过单击 **<UI-TERM key="ocp-v2.Alarm.Event.ActiveAlert">活跃告警</UI-TERM>** 和 **<UI-TERM key="ocp-v2.Backup.Component.BackupAlarm.HistoricalAlerts">历史告警</UI-TERM>** 切换告警列表。

    * 单击 **<UI-TERM key="ocp-v2.Alarm.Event.ExportAlarmEvent">导出告警事件</UI-TERM>**，可将所有符合查询条件的告警事件导出至本地。

    * 若告警事件配置了消息推送，您可单击 **<UI-TERM key="ocp-v2.Alarm.Event.MessagePush">消息推送</UI-TERM>** 列的 **未成功** 查看告警事件详情。

    * 若告警事件未配置消息推送，您可单击 **<UI-TERM key="ocp-v2.Alarm.Event.MessagePush">消息推送</UI-TERM>** 列的 **未配置消息推送** 对其进行告警推送配置，详情可参考 [新建告警推送](600.manage-alert-push/100.create-an-alert-push.md)。

    * 针对 **<UI-TERM key="ocp-v2.src.constant.alarm.Log">日志</UI-TERM>** 告警类型且告警仅出现一次、需要手动确认的活跃告警事件，支持对告警事件进行 **<UI-TERM key="ocp-v2.Alarm.Event.Solution">解决</UI-TERM>** 和 **<UI-TERM key="ocp-v2.Alarm.Event.Shield">屏蔽</UI-TERM>** 操作。

      * 若告警事件已被解决，您可单击 **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.Operation">操作</UI-TERM>** 列的 **<UI-TERM key="ocp-v2.Alarm.Event.Solution">解决</UI-TERM>** 按钮消除此条告警。消除告警后，将不能对该告警进行任何操作。

      * 若告警事件无需关注，您可单击 **<UI-TERM key="ocp-v2.Alarm.Template.Operation">操作</UI-TERM>** 列的 **<UI-TERM key="ocp-v2.Alarm.Event.Shield">屏蔽</UI-TERM>** 对告警消息进行快速屏蔽。屏蔽告警后，在设置的结束时间前，该告警不会在屏蔽时间段内进行上报。具体配置说明可参考 [新建屏蔽条件](800.manage-blocking-conditions/100.create-a-blocking-condition.md)。

    ![Image 3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/%E5%91%8A%E8%AD%A6%E4%BA%8B%E4%BB%B6%E5%88%97%E8%A1%A81.png)

5. 选择需要查看的告警事件，单击告警说明，进入告警事件 **<UI-TERM key="ocp-v2.Alarm.Event.Detail.Details">详情</UI-TERM>** 页。

   1. 在告警 **<UI-TERM key="ocp-performance-report.pages.Report.Content.BasicInformation">基本信息</UI-TERM>** 模块查看告警事件的基本信息。

       * 单击 **<UI-TERM key="ocp-v2.Alarm.Event.Detail.AlertObject">告警对象</UI-TERM>** 名称，可查看告警对象的详细信息。
       * 单击 **<UI-TERM key="ocp-v2.Alarm.Rule.AlertRules">告警规则</UI-TERM>** 名称，可查看该告警规则的详细信息。若需要修改告警规则，可单击规则详情页的 **<UI-TERM key="ocp-v2.Alarm.Rule.New.EditAlertRules">编辑告警规则</UI-TERM>** 按钮进行调整，详情可参考 [修改告警规则](300.manage-alert-rules/400.edit-an-alert-rule.md)。
       * 单击 **<UI-TERM key="ocp-v2.Alarm.Event.Detail.ViewAlertHandlingSuggestions">查看告警处理建议</UI-TERM>** ，您可查看对于该类告警的相关处理建议。

        ![Image 4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/%E5%91%8A%E8%AD%A6%E6%B6%88%E6%81%AF%E4%BF%A1%E6%81%AF.png)

   2. 在 **<UI-TERM key="ocp-v2.Alarm.Event.Detail.AlarmEventHistory">告警事件历史</UI-TERM>** 模块查看告警事件历史及相关信息，包括 **告警时间**、**<UI-TERM key="ocp-v2.page.Overview.AlarmLevel">告警等级</UI-TERM>** 和 **<UI-TERM key="ocp-v2.component.alarm.RuleDetail.AlertStatus">告警状态</UI-TERM>**。

       ![5](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/%E5%91%8A%E8%AD%A6%E4%BA%8B%E4%BB%B6%E5%8E%86%E5%8F%B2.png)

   3. 在 **<UI-TERM key="ocp-v2.Alarm.Event.Detail.AlertMessage">告警消息</UI-TERM>** 列表中查看告警消息通知记录。

       ![6](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/%E5%91%8A%E8%AD%A6%E6%B6%88%E6%81%AF.png)

   4. 在告警事件详情页中单击右上角 **<UI-TERM key="ocp-v2.Alarm.Event.Detail.MaskAlarm">屏蔽告警</UI-TERM>** ，对告警消息进行快速屏蔽。

      屏蔽告警后，在设置的结束时间前，该告警不会在屏蔽时间段内进行上报。

   5. 在告警事件详情页中单击右上角 **<UI-TERM key="ocp-v2.Alarm.Event.Detail.AlarmAnalysisData">告警分析数据</UI-TERM>**，下载告警分析涉及的相关日志。

6. 当收到的告警事件过多时，您可按需对告警进行清理。

     1. 在左侧导航栏中单击 **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">系统管理</UI-TERM>** **\>** **<UI-TERM key="ocp-v2.Detail.Parameter.ParameterManagement">参数管理</UI-TERM>** 。
     2. 在参数列表中搜索 `ocp.alarm.notification.expired-days` 参数，配置告警归档天数。

          参数配置后，超过归档天数的告警消息、告警事件历史记录将被删除，主要包括以下过期数据：

        * `ocp2_alarm_notification`
        * `ocp_alarm_event_notification`
        * `ocp2_alarm_event_history`
        * `ocp_alarm_event_record`
        * `ocp2_alarm_filter` （清理的数据写入   `ocp2_alarm_filter_history`， 规则信息不会很多，历史表无需清理）。

     <main id="notice" type='notice'>
     <h4>注意</h4>
     <p><ul><li>告警清理周期一般不建议配置的过短，可设置几个月清理一次。</li><li>告警不应长时间未恢复而不处理，需注意为用户配置告警推送，用户在收到告警信息后，建议及时进行响应。</li><ul></p>
     </main>
