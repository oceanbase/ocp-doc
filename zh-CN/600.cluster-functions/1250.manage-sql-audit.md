# 管理 SQL Audit

SQL Audit 管理功能支持将数据库审计日志无缝传输至外部存储系统（如 ElasticSearch、SLS），显著提升数据库操作可见性与安全性。通过高效的日志管理和深度分析能力，助力企业实现精细化运营和风险管控，有效保障数据安全、业务连续性及合规要求。

本文为您介绍关于 SQL Audit 管理的操作步骤。

### 前提条件

* 请修改集群参数：enable_sql_audit 为 true 开启全局 SQL 审计功能。
* 请确保外部存储数据源 ElasticSearch 或 SLS 已配置。详见 [SQL Audit 对接 ElasticSearch](../1600.system-management-features/450.manage-external-integration/300.manage-sql-audit/300.manage-es.md) 或  [SQL Audit 对接 SLS](../1600.system-management-features/450.manage-external-integration/300.manage-sql-audit/200.manage-sls.md)。

### 操作步骤

1. 登录 OCP 。

2. 在左侧导航栏单击 **集群** ，系统默认进入 **集群列表** 页面。

3. 在 **集群列表** 中选择待操作的集群，单击其集群名，进入集群 **概览** 页面。

4. 在显示的页面左侧导航栏上，单击 **SQL Audit 管理**。

5. 在 **基本信息** 区域，单击 **配置** ，在对话框中选择租户。

   <main id="notice" type='notice'>
   <h4>注意</h4>
   <ul><li>选中租户的 SQL Audit 数据将被传输至如下外部储存。当存在新增/删除租户时，为避免 SQL Audit 数据未同步/租户名称重复，系统将自动更新 OCP Agent 参数。</li><li>若选择 <strong>全部</strong>，当前全部租户及未来新建租户的 SQL Audit 数据将被传输至后续配置的外部存储。可通过 <strong>排除对象</strong> 进行筛选。</li></ul>
</main>

6. 选择外部存储。

7. 配置 **日志库**，即 SLS 服务 logstore 名称。

8. 单击 **保存**。

9. 在确认框中，单击 **确定**。

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/440/sql-audit-manage.png)

## 相关操作

* **编辑 SQL Audit**：在 **<UI-TERM>基本信息</UI-TERM>** 区域右上角，单击 **<UI-TERM>编辑</UI-TERM>**。在弹出的对话框中修改相关信息，然后单击 **<UI-TERM>保存</UI-TERM>**。

* **删除 SQL Audit**：在 **<UI-TERM>基本信息</UI-TERM>** 区域，关闭 **<UI-TERM>启用状态</UI-TERM>** 开关。在弹出的对话框中单击 **<UI-TERM>禁用</UI-TERM>**。然后在 **<UI-TERM>基本信息</UI-TERM>** 区域右上角，单击 **<UI-TERM>删除</UI-TERM>**。最后在确认框中，单击 **<UI-TERM>确定</UI-TERM>**。

* **查看 SQL Audit**：在 **<UI-TERM>基本信息</UI-TERM>** 区域下方，可以查看 **<UI-TERM>写入对象存储条数</UI-TERM>**。可以在右上角时间筛选框中自定义时间。
