# 重启仲裁服务

本节为您介绍如何重启仲裁服务。

<main id="notice" type='notice'>
<h4>功能适用性</h4>
<p>该内容仅适用于 OCP 企业版，OCP 社区版不支持此功能。</p>
</main>

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **仲裁服务维护** 资源权限。
  * 集群 **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概览</UI-TERM>** 菜单权限。

* 仲裁服务需处于 **<UI-TERM key="ocp-v2.src.constant.binlog.Stopped.3">已停止</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.backup.NormalOperation">正常运行</UI-TERM>** 或 **<UI-TERM key="ocp-v2.page.Overview.Unavailable">不可用</UI-TERM>** 状态。
* 仲裁服务关联的租户中未存在日志流降级。

## 操作步骤

1. 登录 OCP 。

2. 在左导航栏单击 **<UI-TERM key="ocp-v2.src.constant.inspection.Cluster">集群</UI-TERM>** ，系统默认进入 **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">集群列表</UI-TERM>** 页签。

3. 单击 **<UI-TERM key="ocp-v2.Cluster.Component.RepalceDrawer.ArbitrationService">仲裁服务</UI-TERM>** 页签，进入 **<UI-TERM key="ocp-v2.Auth.Org.ResourceConfigDrawer.ArbitrationService">仲裁服务</UI-TERM>** 列表页面。

4. 选择需要重启的仲裁服务，在操作列中选择 **<UI-TERM key="ocp-v2.Component.AddSamplingInspectStrategy.More">更多</UI-TERM>** > **<UI-TERM key="ocp-v2.src.constant.oceanbase.RestartTheService">重启服务</UI-TERM>** 。

5. 在弹窗中单击 **<UI-TERM key="ocp-v2.Plan.Component.UpdateDrawer.Confirm">确认</UI-TERM>** 。

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>重启过程中，仲裁服务所关联的集群和租户将无法使用该仲裁服务，请谨慎操作。</p>
    </main>
