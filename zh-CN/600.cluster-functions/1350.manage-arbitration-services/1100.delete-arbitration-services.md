# 删除仲裁服务

本节为您介绍如何从主机上删除仲裁服务，该操作会删除仲裁服务的服务进程和相关数据。

<main id="notice" type='notice'>
<h4>功能适用性</h4>
<p>该内容仅适用于 OCP 企业版，OCP 社区版不支持此功能。</p>
</main>

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **<UI-TERM key="ocp-v2.Cluster.Arbitration.ArbitrationServiceManagement">仲裁服务管理</UI-TERM>** 资源权限。
  * 集群 **<UI-TERM key="ocp-v2.page.Overview.Overview">概览</UI-TERM>** 菜单权限。

* 仲裁服务需处于 **<UI-TERM key="ocp-v2.src.constant.obproxy.NormalOperation">正常运行</UI-TERM>** 状态。
* 当存在 OceanBase 集群正在使用该仲裁服务，则不允许删除。

## 操作步骤

1. 登录 OCP 。

2. 在左导航栏单击 **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.Cluster">集群</UI-TERM>** ，系统默认进入 **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">集群列表</UI-TERM>** 页签。

3. 单击 **<UI-TERM key="ocp-v2.Cluster.Arbitration.ArbitrationService">仲裁服务</UI-TERM>** 页签，进入 **<UI-TERM key="ocp-v2.Cluster.New.ArbitrationService">仲裁服务</UI-TERM>** 列表页面。

4. 选择需要删除的仲裁服务，在操作列中选择 **<UI-TERM key="ocp-v2.src.util.component.More">更多</UI-TERM>** > **<UI-TERM key="ocp-v2.src.constant.oceanbase.DeleteAService">删除服务</UI-TERM>** 。

5. 在弹窗中单击 **<UI-TERM key="ocp-v2.User.Component.DeleteUserModal.Delete">删除</UI-TERM>** 。
