# 关联新集群

您可参考本节为仲裁服务关联新集群，支持为仲裁服务关联一个或者多个集群。在关联新集群前，请合理评估仲裁服务的资源配置（CPU/内存/磁盘空间），避免异常场景下单个仲裁服务无法支持业务负载。

<main id="notice" type='notice'>
<h4>功能适用性</h4>
<p>该内容仅适用于 OCP 企业版，OCP 社区版不支持此功能。</p>
</main>

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **仲裁服务维护** 资源权限。
  * 集群 **<UI-TERM key="ocp-v2.page.Overview.Overview">概览</UI-TERM>** 菜单权限。

* 仲裁服务需处于 **<UI-TERM key="ocp-v2.src.constant.backup.NormalOperation">正常运行</UI-TERM>** 状态。
* 待关联的 OceanBase 集群与仲裁服务的一级版本号和二级版本号需保持一致，例如 OceanBase 集群版本、仲裁服务版本均为 V4.2.x.x。

## 操作步骤

1. 登录 OCP 。

2. 在左导航栏单击 **<UI-TERM key="ocp-performance-report.ReportTables.SqlInfo.SQLInfoTable.Cluster">集群</UI-TERM>** ，系统默认进入 **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">集群列表</UI-TERM>** 页签。

3. 单击 **<UI-TERM key="ocp-v2.page.Cluster.ArbitrationService">仲裁服务</UI-TERM>** 页签，进入 **<UI-TERM key="ocp-v2.src.constant.information.ArbitrationService">仲裁服务</UI-TERM>** 列表页面。

4. 选择需要关联集群的仲裁服务，在操作列中选择 **<UI-TERM key="ocp-v2.Component.AddSamplingInspectStrategy.More">更多</UI-TERM>** > **<UI-TERM key="ocp-v2.Cluster.Component.AssociateNewClusterDrawer.AssociateANewCluster">关联新集群</UI-TERM>** 。

5. 在弹出的面板中选择待关联的 OceanBase 集群；并选择是否开启 4F/2F 类型租户的仲裁服务，开启后，集群下的租户将同步开启租户仲裁服务。

6. 单击 **<UI-TERM key="ocp-v2.Cluster.Component.AssociateNewClusterDrawer.Association">关联</UI-TERM>**。
