# 解除关联

您可参考本节为仲裁服务解除所关联的集群。解除关联仲裁服务后，集群和租户将无法使用该仲裁服务，请谨慎操作。

<main id="notice" type='notice'>
<h4>功能适用性</h4>
<p>该内容仅适用于 OCP 企业版，OCP 社区版不支持此功能。</p>
</main>

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **仲裁服务维护** 资源权限。
  * 集群 **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概览</UI-TERM>** 菜单权限。

* 仲裁服务需处于 **<UI-TERM key="ocp-v2.src.constant.oceanbase.NormalOperation">正常运行</UI-TERM>** 状态。

* 仲裁服务已关联 OceanBase 集群。

## 操作步骤

1. 登录 OCP 。

2. 在左导航栏单击 **<UI-TERM key="ocp-v2.src.constant.monitor.Cluster">集群</UI-TERM>** ，系统默认进入 **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">集群列表</UI-TERM>** 页签。

3. 单击 **<UI-TERM key="ocp-v2.Component.OCPObjscope.ArbitrationService">仲裁服务</UI-TERM>** 页签，进入 **<UI-TERM key="ocp-v2.Auth.Org.ResourceConfigDrawer.ArbitrationService">仲裁服务</UI-TERM>** 列表页面。

4. 选择需要解除关联的仲裁服务，在操作列中选择 **<UI-TERM key="ocp-v2.src.util.component.More">更多</UI-TERM>** > **<UI-TERM key="ocp-v2.src.constant.oceanbase.Disassociate">解除关联</UI-TERM>** 。

5. 在弹出的面板中选择需解除关联的集群，支持选择多个集群。

6. 单击 **<UI-TERM key="ocp-v2.Cluster.Component.DisassociationDrawer.Release">解除</UI-TERM>**。
