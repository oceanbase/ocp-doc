# 迁出仲裁服务

本节为您介绍如何迁出仲裁服务。若您不想在 OCP 中继续管理该仲裁服务时，可参考本节内容进行迁出。

<main id="notice" type='notice'>
<h4>功能适用性</h4>
<p>该内容仅适用于 OCP 企业版，OCP 社区版不支持此功能。</p>
</main>

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **<UI-TERM key="ocp-v2.Cluster.Arbitration.ArbitrationServiceManagement">仲裁服务管理</UI-TERM>** 资源权限。
  * 集群 **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概览</UI-TERM>** 菜单权限。

* 仲裁服务需处于 **<UI-TERM key="ocp-v2.page.Overview.Stopped">已停止</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.tenant.NormalOperation">正常运行</UI-TERM>** 或 **<UI-TERM key="ocp-v2.page.Overview.Unavailable">不可用</UI-TERM>** 状态。

## 操作步骤

1. 登录 OCP 。

2. 在左导航栏单击 **<UI-TERM key="ocp-v2.Detail.Component.RestartModal.Cluster">集群</UI-TERM>** ，系统默认进入 **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">集群列表</UI-TERM>** 页签。

3. 单击 **<UI-TERM key="ocp-v2.Cluster.Component.RepalceDrawer.ArbitrationService">仲裁服务</UI-TERM>** 页签，进入 **<UI-TERM key="ocp-v2.Plan.Component.PlanTemplateTable.ArbitrationService">仲裁服务</UI-TERM>** 列表页面。

4. 选择需要迁出的仲裁服务，在操作列中选择 **<UI-TERM key="ocp-v2.src.util.component.More">更多</UI-TERM>** > **<UI-TERM key="ocp-v2.src.constant.oceanbase.RelocationService">迁出服务</UI-TERM>** 。

5. 在弹窗中单击 **<UI-TERM key="ocp-v2.Cluster.Arbitration.MoveOut">迁出</UI-TERM>** 。

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>迁出仲裁服务仅解除仲裁服务与 OCP 的关联关系，不影响仲裁服务的自身状态。</p>
    </main>

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E8%BF%81%E5%87%BA%E4%BB%B2%E8%A3%81%E6%9C%8D%E5%8A%A11.png)

6. 迁出仲裁服务后，仲裁服务所关联的租户可在租户 **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概览</UI-TERM>** 页面白屏关闭仲裁服务。
