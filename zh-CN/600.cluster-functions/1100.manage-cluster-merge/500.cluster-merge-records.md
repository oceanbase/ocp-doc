# 查看合并记录

您可以查看集群近 3 天的合并记录。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **集群只读** 资源权限。
* 集群 **<UI-TERM key="ocp-v2.src.util.menu.MergeManagement">合并管理</UI-TERM>** 菜单权限。

## 操作步骤

1. 登录 OCP 。

2. 在左侧导航栏单击 **<UI-TERM key="ocp-v2.src.constant.monitor.Cluster">集群</UI-TERM>** ，系统默认进入 **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">集群列表</UI-TERM>** 页签。

3. 在 **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">集群列表</UI-TERM>** 中选择待操作的集群并单击其集群名，进入集群 **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概览</UI-TERM>** 页面。

4. 在显示的页面的左侧导航栏上，单击 **<UI-TERM key="ocp-v2.Detail.Compaction.MergeManagement">合并管理</UI-TERM>** 。

5. 在 **<UI-TERM key="ocp-v2.Detail.Compaction.MergeDetails">合并详情</UI-TERM>** 或 **<UI-TERM key="ocp-v2.Detail.Compaction.MergeConfiguration">合并配置</UI-TERM>** 页签的右上角，单击 **<UI-TERM key="ocp-v2.Detail.Compaction.ViewMergeRecords">查看合并记录</UI-TERM>**，即可查看该集群在最近 3 天的所有合并记录，记录的信息包括租户名/ID、开始时间、结束时间、总耗时、版本号、合并状态等。
