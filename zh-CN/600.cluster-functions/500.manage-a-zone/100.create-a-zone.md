# 新增 Zone

您可以向您管理的集群中添加新的 Zone。

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **集群维护** 资源权限。
  * 集群 **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概览</UI-TERM>** 菜单权限。

* 您的 OceanBase 集群在当前 OCP 中管理。

  若不在当前 OCP 中管理，您可参考 [接管集群](../300.manage-a-cluster/400.take-over-a-cluster.md) 将您的 OceanBase 集群接管到当前 OCP 中。

* **<UI-TERM key="ocp-v2.Cluster.New.SingleCentralized">单机集中式</UI-TERM>** 数据库不支持新增 Zone。

## 注意事项

当集群已开启 Cgroup 时，若新增的 Zone 中存在操作系统版本低于 5.1.0 的主机时，建议关闭集群 Cgroup，否则可能会引起系统性能下降或者不稳定。
  
## 操作步骤

1. 登录 OCP 。

2. 在左侧导航栏单击 **<UI-TERM key="ocp-performance-report.pages.AWR.Cluster">集群</UI-TERM>** ，系统默认进入 **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">集群列表</UI-TERM>** 页签。

3. 在 **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">集群列表</UI-TERM>** 中选择待操作的集群并单击其集群名。

4. 进入集群 **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概览</UI-TERM>** 页面，单击右上角 **<UI-TERM key="ocp-v2.Topo.TopoGraph.NewZone">新增 Zone</UI-TERM>** 。

5. 在弹出的对话框中，设置 Zone 信息。

   默认是添加一个 Zone 信息，如果您需要添加多个 Zone ，可以在下方单击 **<UI-TERM key="ocp-v2.Cluster.Detail.NewZone">新增 Zone</UI-TERM>** 按钮，添加多个 Zone 的信息。

   需要设置的 Zone 信息如下表所示。

   | **配置**  |  **<UI-TERM key="ocp-v2.Auth.Role.Detail.Description">描述</UI-TERM>**   |
   |-----------|-----------------|
   | Zone 名称 | 自定义 Zone 名称。      |
   | 机房      | Zone 所在的机房。    |
   | 机型      | 可选项。 如果选择了机型，后面主机列表会根据机型进行过滤。 |
   | CPU 架构  | 您可以选择 Zone 的 CPU 架构（ARM 或 X86）。<main id="notice" type='explain'><h4>说明</h4><p>只有存在对应架构的 OceanBase RPM 包时才可以选择对应的 CPU 架构。</p></main>    |
   | 主机      | 您可以选择多个 IP。生产环境下，OceanBase 数据库建议日志盘空间为主机内存空间的三倍以及以上；同时，为了避免出现性能问题，不建议数据目录和日志目录挂载在同一块磁盘上。 |
   | 租户配置  | 您可批量为当前集群下的租户配置副本相关信息，无需为各个租户单独新增副本。<ul><li>待配置的副本信息包括：副本类型、Unit 规格及 Unit 数量。</li><li>每行仅支持添加一个租户，当需要配置多个租户时，请单击 **<UI-TERM key="ocp-v2.component.ZoneFormCardList.AddTenants">新增租户</UI-TERM>** 添加多行。</li><li>Unit 个数将根据所选租户自动填入，不支持编辑。</li></ul>   |
   | 自定义设置  | 配置 OBServer 节点的操作系统所属主用户、路径及端口，详情可参考 [新建分布式集群](../200.create-a-cluster/100.create-a-distributed-cluster.md) 中关于 **自定义配置** 的相关说明。    |
   | 参数设置  | 设置 Zone 下所有 OBServer 的启动参数，参数详情说明可参见 [OceanBase 配置项](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000000218691)。<br>如果未设置 OBServer 启动参数，则默认使用创建集群时的启动参数。    |

   ![09161742](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/435/01251411.png)

6. 完成后，单击 **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.Ok">确定</UI-TERM>** 。

   您可通过弹出框中的 **<UI-TERM key="ocp-v2.Plan.Component.PlanExecuteTable.ViewTasks">查看任务</UI-TERM>** 按钮，查看新建进度；也可在 **<UI-TERM key="ocp-v2.Layout.BasicLayout.TaskCenter">任务中心</UI-TERM>** 中查看该任务的进度。

   当该任务状态为 **<UI-TERM key="ocp-v2.Detail.Log.TaskGraph.Complete">完成</UI-TERM>** ，且集群 **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概览</UI-TERM>** 页的 **<UI-TERM key="ocp-v2.Component.ZoneList.ZoneList">Zone 列表</UI-TERM>** 中，该 Zone 的状态为 **<UI-TERM key="ocp-v2.src.constant.tenant.Running">运行中</UI-TERM>** 时，则新建成功。
