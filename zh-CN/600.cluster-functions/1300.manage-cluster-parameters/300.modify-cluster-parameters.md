# 修改参数

您可以根据需要修改集群或租户参数的值及生效范围。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **集群维护** 资源权限。
* 集群 **<UI-TERM key="ocp-v2.page.Iframe.ParameterManagement">参数管理</UI-TERM>** 菜单权限。

## 操作步骤

1. 登录 OCP 。

2. 在左侧导航栏单击 **<UI-TERM key="ocp-v2.Cluster.Import.Cluster">集群</UI-TERM>** ，系统默认进入 **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">集群列表</UI-TERM>** 页签。

3. 在 **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">集群列表</UI-TERM>** 中选择待操作的集群并单击其集群名，进入集群 **<UI-TERM key="ocp-v2.page.Overview.Overview">概览</UI-TERM>** 页面。

4. 在显示的页面的左侧导航栏上，单击 **<UI-TERM key="ocp-v2.component.OperationConfig.ParameterManagement">参数管理</UI-TERM>** 。

5. （可选）在 **<UI-TERM key="ocp-v2.page.MultiCluster.Parameter.ParameterList">参数列表</UI-TERM>** 页面上方的搜索框中，输入参数名相关信息进行模糊搜索。

   ![Image 107](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E5%8F%82%E6%95%B0%E5%88%97%E8%A1%A81.png)

6. 找到待修改的参数，在对应的 **<UI-TERM key="ocp-v2.User.MySQL.Operation">操作</UI-TERM>** 列中，单击 **<UI-TERM key="ocp-v2.component.OperationConfig.List.ModifyValue">修改值</UI-TERM>** 。

7. 在弹出的对话框中，修改参数的值、生效范围及生效对象，单击 **<UI-TERM key="ocp-v2.Detail.Component.FailoverStandbyTenantModal.Ok">确定</UI-TERM>** 。下图以修改集群范围的参数为示例。

   ![Image 108](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5895199461/p429966.png)

   不同参数的生效范围不同，故在修改值时请根据业务需要选择生效范围。

   * 当生效范围为 **<UI-TERM key="ocp-v2.Detail.Parameter.List.ClusterScope">集群范围</UI-TERM>** 或 **<UI-TERM key="ocp-v2.Detail.Parameter.List.CustomRange">自定义范围</UI-TERM>** 时，默认生效范围是 **<UI-TERM key="ocp-performance-report.ReportTables.SqlInfo.SQLInfoTable.Cluster">集群</UI-TERM>** 。如果需要调整到 Zone 或 OBServer 节点的生效范围，则可以在 **<UI-TERM key="ocp-v2.component.ModifyClusterParameterDrawer.EffectiveRange">生效范围</UI-TERM>** 下拉列表中选择 **Zone** 或 **OBServer** 。选择生效范围后继续选择生效对象，则该修改值会在所选生效对象范围内生效。

   * 当生效范围为 **<UI-TERM key="ocp-v2.Detail.Parameter.List.TenantScope">租户范围</UI-TERM>** 时，可在 **<UI-TERM key="ocp-v2.component.ModifyClusterParameterDrawer.EffectiveObject">生效对象</UI-TERM>** 下拉列表中选择具体租户，或单击列表中的 **<UI-TERM key="ocp-v2.Component.ScheduleModeAndDayList.SelectAll">全选</UI-TERM>** 按钮选择全部租户，则该修改值会在所选生效对象范围内生效。

   如果需要修改参数的值同时在不同的范围生效，例如，修改 **backup_concurrency** 在 **Zone 1** 为 **10** ；在 **Zone 2** 为 **12** ；在 **Server 1** 上为 20，则可以单击 **<UI-TERM key="ocp-v2.component.ModifyClusterParameterDrawer.AddValue">添加值</UI-TERM>** 新增 3 行记录，每行记录可以选中对应的生效范围。

    <main id="notice" type='explain'>
    <h4>说明</h4>
    <p><ul><li>如果单击 <strong>添加值</strong> 后出现多行修改值时，对集群的参数修改顺序是从第一行往下依次执行，并且每次执行成功后，会在 <strong>修改历史</strong> 页签中产生一条历史记录。</li><li>配置容量类参数需带单位，否则将配置失败。</li></ul></p>
    </main>
