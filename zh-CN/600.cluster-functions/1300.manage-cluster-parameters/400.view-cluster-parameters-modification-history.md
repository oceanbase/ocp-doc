# 查看参数修改历史

您可以在修改历史页面查看用户通过 OCP 对当前集群发起的所有参数修改的历史记录，包括每次参数修改的参数名称、变更前后的参数值、修改时间和操作用户。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **集群只读** 资源权限。
* 集群 **<UI-TERM key="ocp-v2.src.util.menu.ParameterManagement">参数管理</UI-TERM>** 菜单权限。

## 操作步骤

1. 登录 OCP 。

2. 在左侧导航栏单击 **<UI-TERM key="ocp-v2.Component.UpgradeDrawer.Cluster">集群</UI-TERM>** ，系统默认进入 **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">集群列表</UI-TERM>** 页签。

3. 在 **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">集群列表</UI-TERM>** 中选择待操作的集群并单击其集群名，进入集群 **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概览</UI-TERM>** 页面。

4. 在显示的页面的左侧导航栏上，单击 **<UI-TERM key="ocp-v2.Detail.Parameter.ParameterManagement">参数管理</UI-TERM>** 。

5. 单击 **<UI-TERM key="ocp-v2.Detail.Parameter.ModifyHistory">修改历史</UI-TERM>** 页签。

6. 通过 **<UI-TERM key="ocp-v2.component.OperationConfig.History.ModifiedDate">修改日期</UI-TERM>** 或 **<UI-TERM key="ocp-v2.Detail.Parameter.History.Parameter.1">参数名称</UI-TERM>** 进行过滤查询。

   其中， **<UI-TERM key="ocp-v2.Detail.Parameter.History.Parameter.1">参数名称</UI-TERM>** 支持模糊查询。

   ![查看参数](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E4%BF%AE%E6%94%B9%E5%8E%86%E5%8F%B21.png)

7. 在查询结果中，查看参数的历史修改信息。
