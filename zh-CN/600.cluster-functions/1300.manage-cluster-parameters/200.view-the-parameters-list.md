# 查看参数列表

通过参数列表，您可以查看当前集群所有参数的名称、类别、取值类型、取值范围、默认值、当前值、说明、是否重启生效及是否只读等。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **集群只读** 资源权限。
* 集群 **<UI-TERM key="ocp-v2.page.Iframe.ParameterManagement">参数管理</UI-TERM>** 菜单权限。

## 操作步骤

1. 登录 OCP 。

2. 在左侧导航栏单击 **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.Cluster">集群</UI-TERM>** ，系统默认进入 **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">集群列表</UI-TERM>** 页签。

3. 在 **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">集群列表</UI-TERM>** 中选择待操作的集群并单击其集群名，进入集群 **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概览</UI-TERM>** 页面。

4. 在显示的页面的左侧导航栏上，单击 **<UI-TERM key="ocp-v2.src.util.menu.ParameterManagement">参数管理</UI-TERM>** 。

   系统默认进入 **<UI-TERM key="ocp-v2.MultiAzone.Parameter.ParameterList">参数列表</UI-TERM>** 页面，您可在 **<UI-TERM key="ocp-v2.page.MultiAzone.ParameterList">参数列表</UI-TERM>** 中查看当前集群所有参数的信息。勾选右上角 **<UI-TERM key="ocp-v2.component.OperationConfig.List.ViewOnlyModifiedParameters">只查看已修改参数</UI-TERM>** ，您可查看 OCP 中已修改过的参数列表。
