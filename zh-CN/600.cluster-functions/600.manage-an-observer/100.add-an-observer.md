# 添加 OBServer 节点

您可以向您管理的集群中添加 OBServer 节点，从而实现为集群扩容的目的。

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **集群维护** 资源权限。
  * 集群 **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概览</UI-TERM>** 菜单权限。

* 您的 OceanBase 集群在当前 OCP 中管理。

  若不在当前 OCP 中管理，您可参考 [接管集群](../300.manage-a-cluster/400.take-over-a-cluster.md) 将您的 OceanBase 集群接管到当前 OCP 中。

* **<UI-TERM key="ocp-v2.Cluster.New.SingleCentralized">单机集中式</UI-TERM>** 数据库不支持添加 OBServer 节点。
  
## 向集群中添加 OBServer 节点

适用于同时向多个 Zone 中添加 OBServer 节点。

1. 登录 OCP 。

2. 在左侧导航栏单击 **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.Cluster">集群</UI-TERM>** ，系统默认进入 **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">集群列表</UI-TERM>** 页签。

3. 在 **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">集群列表</UI-TERM>** 中选择待操作的集群并单击其集群名。

4. 进入集群 **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概览</UI-TERM>** 页面，单击右上角 **<UI-TERM key="ocp-v2.Cluster.Detail.AddObserver">添加 OBServer</UI-TERM>** 。

5. 在 **<UI-TERM key="ocp-v2.Component.ZoneList.AddOBServerDrawer.AddObserver.1">添加 OBServer</UI-TERM>** 面板中，配置如下信息。

   |  参数  |  说明  |
   |--------|--------|
   | 软件包类型  |  默认与当前 OceanBase 集群的软件安装包类型保持一致。当系统无法识别当前 OceanBase 集群的软件包类型时，需要您根据操作系统版本手动选择合适的软件包。  |
   | OBServer 信息 |  指定待添加的 OBServer 节点的机型和 OBServer 节点所在的主机（可多选）。 <br>若并非所有 Zone 都有添加 OBServer 节点的需要，可单击 Zone 行尾的删除符号，删除该 Zone 行。  |
   | 自定义设置  | 用来设置 OBServer 节点的操作系统所属主用户、路径及端口，详情可参考 [新建分布式集群](../200.create-a-cluster/100.create-a-distributed-cluster.md) 中关于 **自定义配置** 的相关说明。 |
   | 参数设置 | 配置 OBServer 的启动参数，详情可参见 [OceanBase 配置项](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000000218691)。 |

   <main id="notice" type='notice'>
    <h4>注意</h4>
    <p><ul><li>仅可选择匹配当前集群硬件架构的主机。</li><li>生产环境下，OceanBase 数据库建议 OBServer 的日志盘空间为主机内存空间的三倍以及以上；同时，为了避免出现性能问题，不建议数据目录和日志目录挂载在同一块磁盘上。</li></ul></p>
    </main>

    ![11181812](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/432/%E6%B7%BB%E5%8A%A0observer.png)

6. 完成后，单击 **<UI-TERM key="ocp-v2.component.Compaction.MergePolicyDrawer.Ok">确定</UI-TERM>** 。

   您可通过弹出框中的 **<UI-TERM key="ocp-v2.src.component.TaskLabel.ViewTasks">查看任务</UI-TERM>** 按钮，查看任务进度；也可在 **<UI-TERM key="ocp-v2.Layout.BasicLayout.TaskCenter">任务中心</UI-TERM>** 中查看该任务的进度。

   当该任务状态为 **<UI-TERM key="ocp-v2.Detail.Log.TaskGraph.Complete">完成</UI-TERM>** ，且集群 **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概览</UI-TERM>** 页的 **<UI-TERM key="ocp-v2.Component.OBServerList.ObserverList">OBServer 列表</UI-TERM>** 中相应 OBServer 节点的状态都为 **<UI-TERM key="ocp-v2.Detail.Statistics.utils.Running">运行中</UI-TERM>** ，则任务成功。

## 向指定的 Zone 当中添加 OBServer 节点

适用于仅有单个 Zone 需要添加 OBServer 节点。

1. 登录 OCP 。

2. 在左侧导航栏单击 **<UI-TERM key="ocp-v2.component.CardAbnormalTable.Cluster">集群</UI-TERM>** ，系统默认进入 **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">集群列表</UI-TERM>** 页签。

3. 在 **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">集群列表</UI-TERM>** 中选择待操作的集群并单击其集群名。

4. 进入集群 **<UI-TERM key="ocp-v2.page.Overview.Overview">概览</UI-TERM>** 页面的 **<UI-TERM key="ocp-v2.Component.ZoneList.ZoneList">Zone 列表</UI-TERM>** 区域，选择一个需要添加 OBServer 节点的 Zone，在对应的 **<UI-TERM key="ocp-v2.page.Host.Operation">操作</UI-TERM>** 列中，单击 **<UI-TERM key="ocp-v2.Component.AddOBServerDrawer.AddObserver">添加 OBServer</UI-TERM>** 。

5. 在 **<UI-TERM key="ocp-v2.Component.UpgradeDistributedClusterDrawer.AddObserver">新增 OBServer</UI-TERM>** 面板中，配置如下信息。

   |  参数  |  说明  |
   |--------|--------|
   | 软件包类型  |  默认与当前 OceanBase 集群的软件安装包类型保持一致。当系统无法识别当前 OceanBase 集群的软件包类型时，需要您根据操作系统版本手动选择合适的软件包。  |
   | OBServer 信息 |  指定待添加的 OBServer 节点的机型和 OBServer 节点所在的主机（可多选）。 <br>默认只添加一个 OBServer 节点，如果需要添加多个 OBServer 节点，您可以在下方单击 **<UI-TERM key="ocp-v2.Component.UpgradeDistributedClusterDrawer.AddObserver">新增 OBServer</UI-TERM>** 按钮。  |
   | 自定义设置  | 用来设置 OBServer 节点的操作系统所属主用户、路径及端口，详情可参考 [新建分布式集群](../200.create-a-cluster/100.create-a-distributed-cluster.md) 中关于 **自定义配置** 的相关说明。 |
   | 参数设置 | 配置 OBServer 的启动参数，详情可参见 [OceanBase 配置项](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000000218691)。 |

   <main id="notice" type='notice'>
    <h4>注意</h4>
    <p><ul><li>仅可选择匹配当前集群硬件架构的主机。</li><li>生产环境下，OceanBase 数据库建议 OBServer 的日志盘空间为主机内存空间的三倍以及以上；同时，为了避免出现性能问题，不建议数据目录和日志目录挂载在同一块磁盘上。</li></ul></p>
   </main>

   ![09161748](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/432/%E6%96%B0%E5%A2%9Eobserver.png)

6. 完成后，单击 **<UI-TERM key="ocp-v2.Statistics.components.EditAutoBasicInfoDrawer.Ok">确定</UI-TERM>** 。
