# 重装 OBServer 节点

本页面为您介绍重装 OBServer 节点的操作。重装 OBServer 节点会在当前主机上删除 OBServer 节点并进行重新安装，帮助您快速重建有问题的 OBServer 节点。

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **集群维护** 资源权限。
  * 集群 **<UI-TERM key="ocp-v2.page.Overview.Overview">概览</UI-TERM>** 菜单权限。

* 您的 OceanBase 集群在当前 OCP 中管理。

  若不在当前 OCP 中管理，您可参考 [接管集群](../300.manage-a-cluster/400.take-over-a-cluster.md) 将您的 OceanBase 集群接管到当前 OCP 中。

* 被操作的主机处于在线状态。

* **<UI-TERM key="ocp-v2.Cluster.New.SingleCentralized">单机集中式</UI-TERM>** 数据库不支持重装 OBServer 节点。

## 操作步骤

1. 登录 OCP 。

2. 在左侧导航栏单击 **<UI-TERM key="ocp-v2.Cluster.New.Cluster">集群</UI-TERM>** ，系统默认进入 **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">集群列表</UI-TERM>** 页签。

3. 在 **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">集群列表</UI-TERM>** 中选择待操作的集群并单击其集群名，进入集群 **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概览</UI-TERM>** 页面。

4. 在 **<UI-TERM key="ocp-v2.Component.OBServerList.ObserverList">OBServer 列表</UI-TERM>** 区域，选择需要重装的 OBServer 节点，单击操作列的 **<UI-TERM key="ocp-v2.src.util.component.More">更多</UI-TERM>** > **<UI-TERM key="ocp-v2.page.Host.Reload">重装</UI-TERM>** 。

   ![09161858](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E9%87%8D%E8%A3%851.png)

5. 在弹出框中输入 **reinstall** 并单击 **<UI-TERM key="ocp-v2.src.constant.oceanbase.Reload">重装</UI-TERM>** 。

   <main id="notice" type='explain'>
    <h4>说明</h4>
    <ul>
    <li>在确认重装前，您需确认需要重装的 OBServer 节点信息，包括：主机 IP、所属集群、所属 zone 及 CPU 架构。</li>
    <li>重装将清理掉此 OBServer 节点下所有数据，请谨慎操作。</li>
    </ul>
   </main>

    ![09161858](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E9%87%8D%E8%A3%85observer1.png)

6. 单击 **<UI-TERM key="ocp-v2.Binlog.Component.StopBinlogModal.Ok">确定</UI-TERM>** 对重装操作进行二次确认。

7. 您可通过单击弹出框中的任务 ID 查看重装进度；也可在 **<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">任务中心</UI-TERM>** 中查看该任务的进度。

   当该任务状态为 **<UI-TERM key="ocp-v2.Detail.Log.TaskGraph.Complete">完成</UI-TERM>** ，且集群 **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概览</UI-TERM>** 页的 **<UI-TERM key="ocp-v2.Component.OBServerList.ObserverList">OBServer 列表</UI-TERM>** 中无此 OBServer 节点时，则删除成功。
