# 添加仲裁服务

本节为您介绍如何为集群添加仲裁服务。

<main id="notice" type='notice'>
<h4>功能适用性</h4>
<p>该内容仅适用于 OCP 企业版，OCP 社区版不支持此功能。</p>
</main>

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **仲裁服务维护** 资源权限。
  * 集群 **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概览</UI-TERM>** 菜单权限。

* OceanBase 集群为 V4.1.0 及以上版本。
* OceanBase 集群与仲裁服务的一级版本号和二级版本号均一致，例如 OceanBase 集群版本、仲裁服务版本均为 V4.2.x.x。
* OceanBase 集群处于 **<UI-TERM key="ocp-v2.src.constant.compute.NormalOperation">正常运行</UI-TERM>** 状态。
* 每个集群仅能添加一个仲裁服务。

## 操作步骤

1. 登录 OCP 。

2. 在左侧导航栏单击 **<UI-TERM key="ocp-v2.Arbitration.ArbitrationGroup.UpgradeArbitrationGroup.Cluster">集群</UI-TERM>** ，系统默认进入 **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">集群列表</UI-TERM>** 页签。

3. 在 **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">集群列表</UI-TERM>** 中选择待操作的集群并单击其集群名。

4. 在集群 **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概览</UI-TERM>** 页面，您可以通过以下 2 种方式为集群添加仲裁服务。

   * 单击右上角 **...** 图标，选择 **<UI-TERM key="ocp-v2.Cluster.New.AddArbitrationService">添加仲裁服务</UI-TERM>** 。
   * 在 **<UI-TERM key="ocp-v2.Component.ArbitrationServerList.ArbitrationServiceList">仲裁服务列表</UI-TERM>** 模块，选择 **<UI-TERM key="ocp-v2.Detail.LoadBalance.AddObproxyLoadBalanceAppDrawer.Add">添加</UI-TERM>** > **<UI-TERM key="ocp-v2.Component.OCPObjscope.ArbitrationService">仲裁服务</UI-TERM>** 。

5. 在 **<UI-TERM key="ocp-v2.Detail.Overview.AddArbitrationService">添加仲裁服务</UI-TERM>** 面板中，为集群选择仲裁服务地址；也可以在列表下方单击 **<UI-TERM key="ocp-v2.Cluster.New.CreateAService">新建服务</UI-TERM>**，创建新的仲裁服务，详情可参考 [新建仲裁服务](../../1350.manage-arbitration-services/200.create-arbitration-services.md)。

6. 单击 **<UI-TERM key="ocp-v2.component.OperationConfig.ModifyParameterDrawer.Submit">提交</UI-TERM>**。
