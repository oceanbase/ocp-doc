# 添加服务组

本节为您介绍如何为集群添加仲裁服务组。

<main id="notice" type='notice'>
<h4>功能适用性</h4>
<p>该内容仅适用于 OCP 企业版，OCP 社区版不支持此功能。</p>
</main>

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **集群维护** 资源权限。
  * 集群 **概览** 菜单权限。

* OceanBase 集群与服务组均处于 **正常运行** 状态。
* OceanBase 集群与服务组的一级版本号和二级版本号需保持一致，例如 OceanBase 集群版本、仲裁服务版本均为 V4.2.x.x。
* 每个集群仅能添加一个服务组。

## 操作步骤

1. 登录 OCP 。

2. 在左侧导航栏单击 **集群** ，系统默认进入 **集群列表** 页签。

3. 在 **集群列表** 中选择待操作的集群并单击其集群名。

4. 在集群 **概览** 页面，您可以通过以下 2 种方式为集群添加仲裁服务组。

   * 单击右上角 **...** 图标，选择 **添加仲裁服务** 。
   * 在 **仲裁服务列表** 模块，选择 **添加** > **仲裁服务** 。

5. 在弹出的面板中，为集群选择服务组相关信息。

    |  参数         |   说明   |
    |---------------|----------|
    | 服务组        | 支持选择已有的服务组；也可以在列表下方单击 **新建服务组**，为集群新建服务组，详情可参考 [新建服务组](../../1370.manage-service-groups/200.create-a-service-group.md)。  |
    | 仲裁服务地址  | 可以从列表中选择已有的仲裁服务地址；也可以在列表下方单击 **新建仲裁服务**，创建所需版本的仲裁服务，详情可参加 [新建仲裁服务](../../1350.manage-arbitration-services/200.create-arbitration-services.md)。  |
    | 开启 4F/2F 类型租户的仲裁服务      | 勾选后，集群下的租户将同步开启租户仲裁服务。  |

6. 单击 **添加**。
