# 替换仲裁服务

当仲裁服务所在的机器故障时，您可参考本节在新的机器上部署仲裁服务后替换故障的仲裁服务。

<main id="notice" type='notice'>
<h4>功能适用性</h4>
<p>该内容仅适用于 OCP 企业版，OCP 社区版不支持此功能。</p>
</main>

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **集群维护** 资源权限。
  * 集群 **<UI-TERM key="ocp-v2.page.Overview.Overview">概览</UI-TERM>** 菜单权限。

* 仲裁服务需处于 **<UI-TERM key="ocp-v2.src.constant.obproxy.NormalOperation">正常运行</UI-TERM>** 状态。
* 仲裁服务关联的租户中未存在日志流降级。
* OceanBase 集群与新替换的仲裁服务的一级版本号和二级版本号需保持一致，例如 OceanBase 集群版本、新替换的仲裁服务版本均为 V4.2.x.x。

## 操作步骤

1. 登录 OCP 。

2. 在左侧导航栏单击 **<UI-TERM key="ocp-performance-report.ReportTables.LockStatInfo.LatchStatTable.Cluster">集群</UI-TERM>** ，系统默认进入 **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">集群列表</UI-TERM>** 页签。

3. 在 **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">集群列表</UI-TERM>** 中选择待操作的集群并单击其集群名。

4. 在集群 **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概览</UI-TERM>** 页面的 **<UI-TERM key="ocp-v2.Component.ArbitrationServerList.ArbitrationServiceList">仲裁服务列表</UI-TERM>** 模块，选择需要替换服务的集群，单击操作列的 **<UI-TERM key="ocp-v2.src.constant.oceanbase.ReplacementService">替换服务</UI-TERM>** 。

5. 在弹出的面板中选择已有的仲裁服务；也可以在列表下方单击 **<UI-TERM key="ocp-v2.Cluster.New.CreateAService">新建服务</UI-TERM>**，为集群新建仲裁服务，详情可参考 [新建仲裁服务](../../1350.manage-arbitration-services/200.create-arbitration-services.md)。

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>替换过程中仲裁服务无法提供服务，可能会影响租户副本的高可用安全。</p>
    </main>

6. 单击 **<UI-TERM key="ocp-v2.Detail.Parameter.List.Submitted">提交</UI-TERM>**。
