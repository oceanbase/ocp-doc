# 管理 CPU 绑核配置

CPU 绑核是一种将特定进程或线程绑定到特定 CPU 核心上的技术，通过将关键任务绑定到固定的 CPU 核心上，可以避免任务在不同核心之间频繁切换，从而减少上下文切换开销，提高系统整体性能。

同时您需注意：过度使用 CPU 绑核可能会导致某些核心负载过高、其他核心处于空闲状态，影响系统的资源利用率。在实际应用中，需要根据具体情况谨慎选择是否使用 CPU 绑核，并合理调整绑核策略，以达到最佳的性能和资源利用效果。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **集群维护** 资源权限。
* 集群 **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概览</UI-TERM>** 菜单权限。

## 配置 CPU 绑定范围

1. 登录 OCP。

2. 在左侧导航栏单击 **<UI-TERM key="ocp-v2.Detail.Overview.Cluster.1">集群</UI-TERM>**，系统默认进入 **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">集群列表</UI-TERM>** 页签。

3. 在集群列表中选择待操作的集群，单击集群名。

4. 进入集群 **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概览</UI-TERM>** 页面，单击右上角 **...** 图标，选择 **<UI-TERM key="ocp-v2.Detail.Overview.CpuCoreBindingConfiguration">CPU 绑核配置</UI-TERM>**。

5. 单击 **<UI-TERM key="ocp-v2.component.CPUBindCoreConfigDrawer.ConfigureCpuBindingRange">配置 CPU 绑定范围</UI-TERM>**，您可选择为多个 Zone 配置相同的 CPU 绑定范围，或为不同 Zone 配置不同的 CPU 绑定范围。

   * **为多个 Zone 配置相同的 CPU 绑定范围**

     * 选择绑定对象：支持选择多个 Zone 作为绑定对象，系统默认选择该集群下全部 Zone。当选择了需要绑核的 Zone 后，系统会对这些 Zone 的 OBServer 进程进行 CPU 绑核配置。

     * 输入 CPU 绑定范围：单击下图 ① 处的 **<UI-TERM key="ocp-v2.component.CreateTagDrawer.Add">添加</UI-TERM>**，支持为 Zone 配置多个 CPU 绑定范围。

   * **为不同 Zone 配置不同的 CPU 绑定范围**

     单击下图 ② 处的 **<UI-TERM key="ocp-v2.Alarm.Rule.New.Add">添加</UI-TERM>**，支持添加多组 Zone CPU 绑核信息，绑定对象的 Zone 具有唯一性，不支持重复选择。

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/432/%E7%BB%91%E6%A0%B8.png)

6. 配置完成后单击 **<UI-TERM key="ocp-v2.TrendAndOutline.SQLHistory.Ok">确定</UI-TERM>**。

7. 您可在对话框中单击任务 ID 查看任务进度。当任务状态为 **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.SuccessfulExecution">执行成功</UI-TERM>**，且集群状态为 **<UI-TERM key="ocp-v2.src.constant.backup.NormalOperation">正常运行</UI-TERM>** 时，表示该集群 CPU 绑核配置成功。

## 停用/启用 CPU 绑定配置

1. 登录 OCP。

2. 在左侧导航栏单击 **<UI-TERM key="ocp-v2.component.ModifyClusterParameterDrawer.Cluster">集群</UI-TERM>**，系统默认进入 **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">集群列表</UI-TERM>** 页签。

3. 在集群列表中选择待操作的集群，单击集群名。

4. 进入集群 **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概览</UI-TERM>** 界面，单击右上角 **...** 图标，选择 **<UI-TERM key="ocp-v2.Detail.Overview.CpuCoreBindingConfiguration">CPU 绑核配置</UI-TERM>**。

5. 选择需要操作的 CPU 绑核配置，进行启用或停用动作。

6. 在弹出的对话框中单击 **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.Determine">确定</UI-TERM>**。
