# 配置 OCP Agent 资源

您可以在 **OCP Agent 资源配置** 页签中对集群下的所有 OCP Agent 统一进行资源配置。若您需要为特定主机单独修改 OCP Agent 规格，可参考 [查看主机详情](../../../850.host-features/150.view-a-host-overview.md) 中关于 **<UI-TERM key="ocp-v2.Host.Detail.OCPAgent.ChangeSpecifications">变更规格</UI-TERM>** 的内容进行操作。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **集群维护** 资源权限。
* 集群 **<UI-TERM key="ocp-v2.page.Overview.Overview">概览</UI-TERM>** 菜单权限。

## 操作步骤

1. 登录 OCP 。

2. 在左侧导航栏单击 **<UI-TERM key="ocp-v2.Detail.Component.RestartModal.Cluster">集群</UI-TERM>** ，系统默认进入 **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">集群列表</UI-TERM>** 页签。

3. 在 **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">集群列表</UI-TERM>** 中选择待操作的集群并单击其集群名。

4. 在集群 **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概览</UI-TERM>** 页面，单击右上角 **...** 图标，选择 **<UI-TERM key="ocp-v2.component.OperationConfig.OMConfiguration">运维配置</UI-TERM>**，默认进入 **<UI-TERM key="ocp-v2.Detail.Parameter.ParameterManagement">参数管理</UI-TERM>** 页签。

5. 单击 **OCP Agent 资源配置** 页签，页面中展示了当前集群下所有主机的主机 IP、主机名、Zone、进程及规格信息。

6. 单击右上角 **<UI-TERM key="ocp-v2.component.OperationConfig.ChangeSpecifications">变更规格</UI-TERM>**，在变更 **OCP Agent 规格** 面板中统一调整集群下全部 OCP Agent 的 CPU 和内存规格。

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <p><ul><li>建议最大规格为 6C/12GiB。</li><li>建议 ocp_monagent 的内存配置低于集群内各主机的可用物理内存大小，否则可能造成资源配置失败。主机的可用物理内存大小可通过 <b>性能监控</b> > <b>主机性能</b> > <b>主机维度</b> > <b>内存</b> 进行查看。</li><li>执行该操作后，系统会默认变更本集群下全部 OCP Agent 规格，请确保主机 CPU 和内存资源充足，否则可能造成系统性能降低。</li><li>变更 OCP Agent 规格需 <a href="../../../850.host-features/400.restart-the-ocp-agent.md">重启 OCP Agent</a>，重启期间 OCP 无法执行运维操作且会丢失部分监控数据，您需谨慎操作。</li></ul></p>
    </main>
