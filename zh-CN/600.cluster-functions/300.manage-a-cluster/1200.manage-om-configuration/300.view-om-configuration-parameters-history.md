# 查看参数修改历史

您可以在 **<UI-TERM key="ocp-v2.component.OperationConfig.Parameter.ModifyHistory">修改历史</UI-TERM>** 页签中查看当前集群发起的所有运维配置参数的历史修改记录，包括每次参数修改的参数名称、变更前后的参数值、修改时间、参数类型和操作用户。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **集群只读** 资源权限。
* 集群 **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概览</UI-TERM>** 菜单权限。

## 操作步骤

1. 登录 OCP 。

2. 在左侧导航栏单击 **<UI-TERM key="ocp-v2.component.CardAbnormalTable.Cluster">集群</UI-TERM>** ，系统默认进入 **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">集群列表</UI-TERM>** 页签。

3. 在 **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">集群列表</UI-TERM>** 中选择待操作的集群并单击其集群名。

4. 在集群 **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概览</UI-TERM>** 页面，单击右上角 **...** 图标，选择 **<UI-TERM key="ocp-v2.Detail.Overview.OMConfiguration">运维配置</UI-TERM>**，默认进入 **<UI-TERM key="ocp-v2.src.util.menu.ParameterManagement">参数管理</UI-TERM>** 页签。

5. 单击 **<UI-TERM key="ocp-v2.Detail.Parameter.ModificationHistory">修改历史</UI-TERM>** 页签。

6. 通过 **<UI-TERM key="ocp-v2.component.OperationConfig.History.ModifiedDate">修改日期</UI-TERM>** 或 **<UI-TERM key="ocp-v2.page.MultiCluster.Parameter.Parameter">参数名称</UI-TERM>** 进行过滤查询。其中，**<UI-TERM key="ocp-v2.page.MultiCluster.Parameter.Parameter">参数名称</UI-TERM>** 支持模糊查询。

7. 在查询结果中，查看参数的历史修改信息。
