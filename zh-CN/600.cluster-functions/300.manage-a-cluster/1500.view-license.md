# 查看 License

<main id="notice" type='notice'>
<h4>功能适用性</h4>
<p>该内容仅适用于 OCP 企业版，OCP 社区版不支持此功能。</p>
</main>

您可通过查看 License 了解当前单机的 License 状态与相关信息。

## 前提条件

* 请确保当前 OceanBase 为单机。

* 已 [导入 License](1400.import-license.md)。

* 请确保当前登录 OCP 的用户具备如下权限：

  * **集群维护** 资源权限。
  * 集群 **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概览</UI-TERM>** 菜单权限。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏单击 **<UI-TERM key="ocp-v2.Detail.Overview.Cluster.1">集群</UI-TERM>**，系统默认进入 **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">集群列表</UI-TERM>** 页签。

3. 在集群列表中选择待操作的集群，单击集群名。

4. 进入集群 **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概览</UI-TERM>** 页面，单击右上角 **...** 图标，选择 **查看 License**。

5. 在弹窗中查看 License 信息，字段详细说明如下。

   | 字段  |  说明   |
   |-------|---------|
   | 集群 ID   | OceanBase 在 OCP 端的集群 ID，由集群启动时自动生成。    |
   | 授权用户名  | 授权用户名。  |
   | License ID  | License 的 ID，由 OceanBase 生成。  |
   | License 编码 | License 的编码，由合同号组成。  |
   | License 类型 | License 的类型，分为如下两种：<ul><li>Commercial：商业版</li><li>Trial：试用版</li></ul>   |
   | 产品类型   | 分为如下两种：<ul><li>SE：单机企业版</li><li>DE：分布式企业版</li></ul>   |
   | License 颁发时间   | License 的颁发时间。    |
   | License 激活时间   | License 的激活时间。    |
   | License 过期时间   | License 的过期时间。    |
   | License 选件   | License 中所包含的功能选件，包含如下几种：<ul><li>EE：OceanBase 单机企业版基础功能</li><li>PS：OceanBase 单机集群间复制选件</li><li>MT：OceanBase 单机多租户选件</li><li>AP：OceanBase 单机 OLAP 选件</li><li></li></ul>    |
   | 授权节点数   | 授权节点数，单机为 1。    |
