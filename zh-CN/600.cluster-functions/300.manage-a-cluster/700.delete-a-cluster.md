# 删除集群

您可以根据业务需要，删除您不需要的 OceanBase 集群。集群删除后将会释放该 OceanBase 集群所占用的所有主机，并将业务从主机上清除，请谨慎操作。

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **集群管理** 资源权限。
  * 集群 **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概览</UI-TERM>** 菜单权限。

* 您的 OceanBase 集群在当前 OCP 中管理。若不在当前 OCP 中管理，您可参考 [接管集群](../300.manage-a-cluster/400.take-over-a-cluster.md) 将您的 OceanBase 集群接管到当前 OCP 中。
  
* 待删除 OceanBase 集群处于 **已停止**、**不可用**、**已废弃** 或 **已迁出** 状态。
* 删除主 OceanBase 集群时，请确保其备集群已删除。

## 操作步骤

1. 登录 OCP 。

2. 在左侧导航栏单击 **<UI-TERM key="ocp-v2.Detail.Component.RestartModal.Cluster">集群</UI-TERM>** ，系统默认进入 **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">集群列表</UI-TERM>** 页签。

3. 在 **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">集群列表</UI-TERM>** 中选择待操作的集群并单击其集群名。

4. 在集群 **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概览</UI-TERM>** 页面，单击右上角 **...** 图标，选择 **<UI-TERM key="ocp-v2.Cluster.Detail.DeleteACluster">删除集群</UI-TERM>** 。

5. 在弹出的 **<UI-TERM key="ocp-v2.Detail.Component.DeleteModal.DeleteACluster">删除集群</UI-TERM>** 对话框中，输入 delete。

6. 单击 **<UI-TERM key="ocp-v2.Host.Detail.Delete">删除</UI-TERM>** 。

   您可通过弹出框中的 **<UI-TERM key="ocp-v2.page.Welcome.ViewTasks">查看任务</UI-TERM>** 按钮，查看进度或失败原因。

   您也可在 **<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">任务中心</UI-TERM>** 中查看该任务的进度。

   当该任务状态为 **<UI-TERM key="ocp-v2.Detail.Log.TaskGraph.Complete">完成</UI-TERM>** ，且 **<UI-TERM key="ocp-v2.Detail.Component.RestartModal.Cluster">集群</UI-TERM>** 页的 **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">集群列表</UI-TERM>** 中无该 OceanBase 集群，则删除成功。
