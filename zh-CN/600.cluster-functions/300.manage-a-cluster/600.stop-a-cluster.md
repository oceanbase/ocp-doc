# 停止集群

您可以根据业务需要停止集群，停止集群将会停止集群中所有节点上运行的 observer 进程，请谨慎操作。

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **集群维护** 资源权限。
  * 集群 **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概览</UI-TERM>** 菜单权限。

* 选择该 OceanBase 集群业务量少的时间段进行 **<UI-TERM key="ocp-v2.Topo.TopoGraph.StopTheCluster">停止集群</UI-TERM>** 的操作。

  停止集群会停止业务，且目前无法规避停集群带来的影响，请谨慎操作。目前仅当该集群不再使用时才建议使用该功能。
  
## 操作步骤

1. 登录 OCP 。

2. 在左侧导航栏单击 **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.Cluster">集群</UI-TERM>** ，系统默认进入 **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">集群列表</UI-TERM>** 页签。

3. 在 **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">集群列表</UI-TERM>** 中选择待操作的集群并单击其集群名。

4. 在集群 **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概览</UI-TERM>** 页面，单击右上角 **...** 图标，选择 **<UI-TERM key="ocp-v2.Cluster.Detail.StopTheCluster">停止集群</UI-TERM>** 。

5. 在对话框中，选择是否在停止进程前执行转储操作（默认执行），并单击 **<UI-TERM key="ocp-v2.src.constant.oceanbase.Stop.4">停止</UI-TERM>** 。

   执行转储动作会延长停止进程的响应时间，但可以显著缩短 OBServer 恢复时间。

   ![11161438](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/421/%E5%81%9C%E6%AD%A2%E9%9B%86%E7%BE%A4.png)

6. 停止集群任务提交后，您可通过弹出框中的 **<UI-TERM key="ocp-v2.src.component.TaskLabel.ViewTasks">查看任务</UI-TERM>** ，查看停止进度。

   您也可在 **<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">任务中心</UI-TERM>** 中查看该任务的停止进度。

   当该任务状态为 **<UI-TERM key="ocp-v2.Detail.Log.TaskGraph.Complete">完成</UI-TERM>** ，且 **<UI-TERM key="ocp-v2.Arbitration.ArbitrationGroup.UpgradeArbitrationGroup.Cluster">集群</UI-TERM>** 页的 **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">集群列表</UI-TERM>** 中，该集群的状态为 **<UI-TERM key="ocp-v2.src.constant.binlog.Stopped.3">已停止</UI-TERM>** 时，则集群停止成功。

7. 启动集群。

   集群停止后，如您想再次启用该 OceanBase 集群，可通过集群 **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概览</UI-TERM>** 页右上角的 **<UI-TERM key="ocp-v2.Cluster.Detail.StartTheCluster">启动集群</UI-TERM>** ，再次启用该集群。
