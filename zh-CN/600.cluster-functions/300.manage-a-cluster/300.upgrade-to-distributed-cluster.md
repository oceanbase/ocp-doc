# 扩展分布式集群

本节将为您介绍如何将单机在线扩展为分布式集群。

## 背景信息

* 当将集群拓展为单 Zone 多主机模式时，仅会扩展 OceanBase 服务的计算能力，不具备多副本高可用能力，适用于开发测试环境。
* 当将集群拓展为偶数 Zone 的模式时，将无法满足数据高可用的要求，存在数据安全风险。建议您调整配置，保持奇数的可用区配置或者为集群/租户开启仲裁服务。

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **集群维护** 资源权限。
  * 集群 **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概览</UI-TERM>** 菜单权限。

* 待扩展的单机为 **正常运行** 状态。

* 在执行扩展操作前，请确保已上传符合如下条件的分布式 OceanBase 软件包：

  * 软件包包名不包含 `standalone` 标识。
  * 软件包版本与单机的前四级版本号均一致，例如单机、分布式 OceanBase 均为 V4.2.5.4。
  * 软件包系统架构与单机一致。

## 注意事项

* 将单机系统扩展为分布式集群操作风险较高且会中断业务访问，建议在 OceanBase 技术人员支持下进行。
* 操作前请务必仔细阅读官网文档 [单机集群扩展为分布式集群注意事项](https://www.oceanbase.com/docs/common-oceanbase-database-standalone-1000000003360376)，确认当前数据库版本是否支持分布式集群扩展，贸然操作可能导致集群不可用。

## 注意事项

当集群已开启 Cgroup 时，若扩展时所选择主机的操作系统内核版本低于 5.1.0 时，建议关闭集群 Cgroup，否则可能会引起系统性能下降或者不稳定。

## 操作步骤

1. 登录 OCP 。

2. 在左侧导航栏选择 **<UI-TERM key="ocp-v2.component.MonitorSearch.Cluster">集群</UI-TERM>** ，系统默认进入 **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">集群列表</UI-TERM>** 页签。

3. 在 **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">集群列表</UI-TERM>** 中选择待操作的集群并单击其集群名。

4. 进入集群 **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概览</UI-TERM>** 页面，单击 **扩展分布式集群** 。

5. 在对话框中了解操作风险，若仍需操作，单击 **扩展**。

6. 在右侧弹出的面板中，设置如下信息。

    * 选择软件包类型，默认与单机的软件安装包类型保持一致。当系统无法识别单机的软件包类型时，需要您根据操作系统版本手动选择合适的软件包。

    * 配置扩展相关信息。

      系统默认以 **<UI-TERM key="ocp-v2.Component.AddZoneDrawer.NewZone">新增 Zone</UI-TERM>** 的方式进行扩展，您可单击 **<UI-TERM key="ocp-v2.Component.UpgradeDistributedClusterDrawer.AddObserver">新增 OBServer</UI-TERM>** 页签选择将集群扩展为单 Zone 多主机模式。**<UI-TERM key="ocp-v2.Topo.TopoGraph.NewZone">新增 Zone</UI-TERM>** 模式下，如果您需要添加多个 Zone ，可以在下方单击 **<UI-TERM key="ocp-v2.Component.AddZoneDrawer.NewZone">新增 Zone</UI-TERM>** 按钮，添加多个 Zone 的信息。

      | **配置**  |   **<UI-TERM key="ocp-v2.Auth.Role.Detail.Description">描述</UI-TERM>**    |
      |---------|-------|
      | Zone 名称 | 自定义 Zone 名称。当以 **新增 OBServer** 的方式进行扩展时，Zone 名称不支持编辑。    |
      | 机房      | Zone 所在的机房。当以 **新增 OBServer** 的方式进行扩展时，机房不支持编辑。     |
      | 机型      | 可选项。如果选择了机型，后面主机列表会根据机型进行过滤。   |
      | CPU 架构  | Zone 中的 CPU 架构需与集群的 CPU 架构保持一致。<ul><li>当以 **新增 OBServer** 的方式进行扩展时，CPU 架构不支持编辑。</li><li>当以 **新增 Zone** 的方式进行扩展时，选择指定架构后，系统会检查是否存在符合单机 CPU 架构的安装包。若缺少指定架构的安装包，将无法新增 Zone。</li></ul>   |
      | 主机      | 当以 **<UI-TERM key="ocp-v2.Topo.TopoGraph.NewZone">新增 Zone</UI-TERM>** 的方式进行扩展时，仅可选择一台主机作为 OBServer & rootserver；以 **<UI-TERM key="ocp-v2.Component.UpgradeDistributedClusterDrawer.AddObserver">新增 OBServer</UI-TERM>** 方式进行扩展时，可选择多个主机。<ul><li>当下拉列表中无可选主机时，可进行 [添加主机](../../850.host-features/100.manage-a-host/200.add-a-host.md) 的操作。</li><li>生产环境下，OceanBase 数据库建议日志盘空间为主机内存空间的三倍以及以上；同时，为了避免出现性能问题，不建议数据目录和日志目录挂载在同一块磁盘上。</li></ul> |
      | 租户配置  | 当以 **<UI-TERM key="ocp-v2.Topo.TopoGraph.NewZone">新增 Zone</UI-TERM>** 的方式进行扩展时，您可批量为当前集群下的租户配置副本相关信息，无需为各个租户单独新增副本。<ul><li>待配置的副本信息包括：副本类型、Unit 规格及 Unit 数量。</li><li>一行配置仅支持添加一个租户，当需要配置多个租户时，请单击 **<UI-TERM key="ocp-v2.component.ZoneFormCardList.AddTenants">新增租户</UI-TERM>** 添加多行。</li><li>Unit 个数将根据所选租户自动填入，不支持编辑。</li></ul>   |

    * 进行自定义设置，用于配置 OBServer 节点的操作系统所属主用户、路径及端口，详情可参考 [新建分布式集群](../200.create-a-cluster/100.create-a-distributed-cluster.md) 中 **自定义配置** 的相关说明。

    * 配置 OBServer 启动参数，参数详情说明可参见 [OceanBase 配置项](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000000218691)。

   ![09161742](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/435/01251426.png)

7. 完成后，单击 **<UI-TERM key="ocp-v2.component.FilterDropdown.Determine">确定</UI-TERM>** 。

   您可通过弹出框中的 **<UI-TERM key="ocp-v2.src.constant.ViewTasks">查看任务</UI-TERM>** 按钮，查看新建进度；您也可在 **<UI-TERM key="ocp-v2.Layout.BasicLayout.TaskCenter">任务中心</UI-TERM>** 中查看该任务的进度。
