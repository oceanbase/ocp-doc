在单机中，您需将 License 授权文件上传至 OCP 平台，确保能够根据授权激活对应的功能组件。

## 适用场景

* 单机默认自带一个有效期 180 天的试用 License，当试用 License 即将过期或已过期时，需及时导入正式版 License。
* 正式版 License 即将过期或已过期，需导入最新获取的 License。
* 变更 License 中的功能组件后，需重新导入 License。

## 前提条件

* 请确保当前 OceanBase 为单机。

* 已获取 License 授权文件。

* 请确保当前登录 OCP 的用户具备如下权限：

  * **集群维护** 资源权限。
  * 集群 **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概览</UI-TERM>** 菜单权限。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏单击 **<UI-TERM key="ocp-v2.Detail.Overview.Cluster.1">集群</UI-TERM>**，系统默认进入 **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">集群列表</UI-TERM>** 页签。

3. 在集群列表中选择待操作的集群，单击集群名。

4. 进入集群 **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概览</UI-TERM>** 页面，单击右上角 **...** 图标，选择 **导入 License**。

5. 选择已下载至本地的 License 文件，完成上传。

    * 一次仅允许上传一个 License 文件。
    * 若上传成功后再次上传，新 License 文件将替换旧 License 文件。
