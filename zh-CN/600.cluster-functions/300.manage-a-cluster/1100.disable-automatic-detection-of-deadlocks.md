# 关闭死锁自动检测

您可根据您的业务需求，关闭死锁自动检测。

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **集群维护** 资源权限。
  * 集群 **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概览</UI-TERM>** 菜单权限。

* 当前集群版本为 V3.2.0 及以上。

* 集群已开启死锁自动检测功能。

## 操作步骤

1. 登录 OCP 。

2. 在左侧导航栏单击 **<UI-TERM key="ocp-performance-report.ReportTables.SqlInfo.SQLInfoTable.Cluster">集群</UI-TERM>** ，系统默认进入 **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">集群列表</UI-TERM>** 页签。

3. 在 **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">集群列表</UI-TERM>** 中选择待操作的集群并单击其集群名。

4. 在集群 **<UI-TERM key="ocp-v2.page.Overview.Overview">概览</UI-TERM>** 页面，单击右上角 **...** 图标，选择 **<UI-TERM key="ocp-v2.Topo.TopoGraph.DisableAutomaticDeadlockDetection">关闭死锁自动检测</UI-TERM>** 。

5. 在对话框中单击 **<UI-TERM key="ocp-v2.page.Inspection.Ok">确定</UI-TERM>** ，即可关闭死锁自动检测功能。
