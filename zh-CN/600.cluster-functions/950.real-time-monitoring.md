# 查看实时监控

实时监控通过全局视角展示集群资源的分布和关联，帮助您了解系统情况、进行业务监控及故障快速定位，方便更好地管理和优化系统性能，提高系统的稳定性和可靠性。

## 背景信息

为应对分布式数据库环境下全链路性能监控与故障定位的复杂性，OCP 推出全链路实时监控解决方案，构建覆盖 OBProxy——OceanBase 集群——租户——主机——Unit 的五级监控体系，通过三大核心能力重塑运维体验：

* **3D 拓扑可视化，透视架构全貌**

采用动态 3D 可视化引擎，立体呈现 OBProxy 与集群、集群与主机、租户与 OBServer 间的逻辑关系与物理部署。支持拓扑层级钻取，从全局架构到单个 Unit 的逐层下钻，直观展现资源分布与依赖关系，让分布式架构的 “黑盒” 运行状态透明化。

* **全维度指标监控，秒级定位异常**

实时汇聚 QPS、TPS、RT、连接数、CPU/内存使用率等 10+ 核心性能指标，结合性能监控趋势对比分析，精准识别性能拐点。支持在拓扑图上直接查看关联告警数量并跳转至告警中心，实现从指标异常到故障根源的一键追溯，提升故障定位效率。

* **双模数据呈现，满足多维运维场景**

提供结构化表格数据视图，通过图形化与数字化的信息互补，既满足管理者全局态势感知需求，又为技术人员提供深度分析的数据支撑，有效降低分布式系统的认知与管理门槛。

## 前提条件

* 仅 OceanBase V4.x 及以上版本支持查看实时监控。
* 3D 视图最多支持展示 30 个主机。当主机数量超过限制时，仅支持以表格视图进行展示。

## 注意事项

* 建议您开启监控的异步计算功能（可通过 `ocp.metric.async-compute.enabled` 参数控制），若不开启则有可能影响接口响应速度。
* 当您的集群包含大量主机、租户和 Unit 资源时，实时监控可能会遇到性能限制，建议切换到表格视图查看各项监控指标。
* 由于部分监控对象的指标采集时间存在差异，可能会导致数据在时序上出现不一致的现象。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏单击 **集群**，系统默认进入 **集群列表** 页签。

3. 在 **集群列表** 中选择待操作的集群并单击其集群名，进入集群 **概览** 页面。

4. 单击左侧导航栏的 **实时监控**。

### 通过 3D 视图查看实时监控数据

系统默认以 3D 视图展示实时监控数据。在 3D 视图画布中，实时监控数据将通过左侧数据面板和右侧拓扑图两个模块进行信息的动态展示。

**查看总览数据**

* 左侧数据面板展示当前集群的资源对象概览和告警统计概览。

* 右侧拓扑图展示当前集群所关联服务的资源信息，您可直观地查看 OBProxy 集群——OceanBase 集群——Zone 之间的拓扑关系及总体概况。

  * 支持展示所关联服务的所有资源对象，包括所有 OBProxy Server 资源、所有租户资源及所有主机资源。

  * 支持通过不同颜色展示资源对象的健康程度。不同颜色代表资源对象存在不同等级的告警信息，其中：紫色为停服告警，红色为严重告警，橙色为警告告警，绿色为无告警。

  | OBProxy 集群 | 集群名称、状态、QPS、TPS、RT、请求失败次数、客户端连接数、客户端连接使用率、进程内存使用率。  |

  | OceanBase 集群 | 集群名称、状态、QPS、TPS、会话数、活跃会话数、leader 副本数、RT。   |
  | 租户  | 租户名称、状态、QPS、TPS、RT、会话数、活跃会话数、线程使用率、CPU 消耗、leader 副本数、请求等待队列耗时、请求等待队列大小及租户的所有 Unit 信息。<br><ul>其中：<li>Unit 指标信息包括所属 OBServer、规格、QPS、TPS、RT、会话数、活跃会话数、线程使用率、CPU 消耗、leader 副本数、请求等待队列大小、请求等待队列耗时。Unit 默认展示所有监控项，若您无需关注某项监控，可以单击筛选按钮，在面板中取消勾选该监控项。</li><li>单击或将光标悬停于所属 OBServer 的 IP，可查看该 IP 的 OBServer 和主机的指标信息。</li></ul> |
  | OBServer | IP、状态、QPS、TPS、会话数、活跃会话数、leader 副本数及对应 Unit 信息。<br><ul>其中：<li>Unit 指标信息包括所属租户、规格、QPS、TPS、RT、会话数、活跃会话数、线程使用率、CPU 消耗、leader 副本数、请求等待队列大小、请求等待队列耗时。Unit 默认展示所有监控项，若您无需关注某项监控，可以单击筛选按钮，在面板中取消勾选该监控项。</li><li>单击或将光标悬停于所属租户，可查看该租户的指标信息。</li></ul>  |
  | 主机  | IP、状态、CPU 使用率、内存使用率、磁盘 IO 使用率、TCP 重传率、磁盘使用率、NTP 时钟偏移、网络吞吐率（send）、网络吞吐率（receive）。 |

### 通过表格视图查看实时监控数据

单击右上角 **表格** 按钮，切换为表格视图，系统将以表格形式展示不同资源对象的结构化数据。

* **OBProxy 集群** 列表支持展示集群、OBProxy Server、主机的实时监控数据，以及集群的告警概览数据。

  |  对象类型   |  指标信息   |
  |-------------|-------------|
  | OBProxy 集群 | <ul><li>集群：集群名称、状态、QPS、TPS、RT、请求失败次数、客户端连接数、客户端连接使用率、进程内存使用率。</li><li>OBProxy Server：IP、状态、QPS、TPS、RT、请求失败次数、客户端连接数、客户端连接使用率、进程内存使用率。</li></ul>  |
  | 主机  | 告警概览、IP、状态、OBProxy 集群、CPU 使用率、内存使用率、磁盘 IO 使用率、TCP 重传率、磁盘使用率、NTP 时钟偏移、网络吞吐率（send）、网络吞吐率（receive）。 |

* **OceanBase 集群** 列表支持展示集群、OBServer、主机、租户实时监控数据，以及集群的告警概览数据。

  |  对象类型   |  指标信息   |
  |-------------|-------------|
  | OceanBase 集群 | <ul><li>集群：集群名称、状态、QPS、TPS、会话数、活跃会话数、leader 副本数、RT。</li><li>OBServer：IP、Zone、状态、QPS、TPS、会话数、活跃会话数、leader 副本数。</li></ul>   |
  | 主机  | 告警概览、IP、Zone、状态、CPU 使用率、内存使用率、磁盘 IO 使用率、TCP 重传率、磁盘使用率、NTP 时钟偏移、网络吞吐率（send）、网络吞吐率（receive）。 |
  | 租户  | <ul><li>租户：租户名称、状态、QPS、TPS、RT、会话数、活跃会话数、线程使用率、CPU 消耗、leader 副本数、请求等待队列耗时、请求等待队列大小。</li><li>Unit：规格、所属 OBServer、QPS、TPS、RT、会话数、活跃会话数、线程使用率、CPU 消耗、leader 副本数、请求等待队列大小、请求等待队列耗时。</li></ul> |

## 相关操作

* **修改自动刷新频率**：系统默认每 30s 刷新一次监控数据，可根据实际情况修改为 **10 秒**、**20 秒**、**1 分钟**、**2 分钟** 或 **5 分钟**。修改后，系统将按照所选择的频率自动刷新监控数据。
* **查看告警详情**：若监控对象存在告警，单击对应告警等级，可跳转至告警页面查看告警详情。
* **调整拓扑图**：
  * 通过鼠标在空白处拖拽，可自由移动拓扑图。
  * 单击![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/440/09181117.png)，可调整拓扑图为全屏模式。
  * 单击放大/缩小图标或上下滑动鼠标滚轮，可对拓扑图进行放大或缩小操作。
  * 单击![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/440/09151453.png)，可将拓扑图快速调整为原始比例。
  * 单击![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/440/09151456.png)，可调整拓扑图动态适应画布大小。
