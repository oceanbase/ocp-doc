# 升级服务组

本节为您介绍如何升级仲裁服务组。升级过程中仲裁将停止服务，若强制运行，可能会影响关联集群高可用安全，您需谨慎操作。

<main id="notice" type='notice'>
<h4>功能适用性</h4>
<p>该内容仅适用于 OCP 企业版，OCP 社区版不支持此功能。</p>
</main>

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **仲裁服务维护** 资源权限。
  * 集群 **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概览</UI-TERM>** 菜单权限。

* 服务组需处于 **<UI-TERM key="ocp-v2.page.Overview.Content.NormalOperation">正常运行</UI-TERM>** 状态。
* 服务组关联的租户中未存在日志流降级。
* 当服务组已关联 OceanBase 集群时，升级后的服务组需与 OceanBase 集群的一级版本号和二级版本号保持一致，例如 OceanBase 集群版本、仲裁服务版本均为 V4.2.x.x，否则将导致升级失败。

## 操作步骤

1. 登录 OCP 。

2. 在左导航栏单击 **<UI-TERM key="ocp-v2.component.alarm.Search.Cluster">集群</UI-TERM>** ，并进入 **<UI-TERM key="ocp-v2.Auth.Org.ResourceConfigDrawer.ArbitrationService">仲裁服务</UI-TERM>** 页签。

3. 单击 **<UI-TERM key="ocp-v2.Arbitration.ArbitrationGroup.CreateArbitrationGroup.ServiceGroup">服务组</UI-TERM>** 页签，进入 **<UI-TERM key="ocp-v2.Detail.Component.AddArbitrationGroupDrawer.ServiceGroup">服务组</UI-TERM>** 列表页面。

4. 选择需要升级的服务组，在操作列中选择 **<UI-TERM key="ocp-v2.Detail.Component.UpgradeModal.Upgrade">升级</UI-TERM>** 。

5. 在弹窗中确认服务组的升级信息，并选择所升级版本的软件包。若无可选版本，单击 **<UI-TERM key="ocp-v2.src.component.PackageSelect.UploadASoftwarePackage">上传软件包</UI-TERM>** ，可在弹出框中上传所需版本的软件包。

6. 单击 **<UI-TERM key="ocp-v2.Arbitration.ArbitrationGroup.UpgradeArbitrationGroup.Upgrade">升级</UI-TERM>** 。

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>仅可选择高于当前版本的软件包版本，且软件包的 CPU 架构需与当前服务组的硬件架构保持一致。</p>
    </main>
