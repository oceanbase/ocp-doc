# 新增服务组

本节为您介绍如何新建仲裁服务组。当仲裁服务进程崩溃、OceanBase 与仲裁服务不通以及仲裁服所在主机宕机等场景下，系统依据优先配置实现秒级替换集群的仲裁服务地址，实现仲裁服务的高可用。

在新增服务组前，您需合理评估仲裁服务的资源配置（CPU/内存/磁盘空间），避免异常场景下单个仲裁服务无法支持仲裁服务组内的全部业务负载。

<main id="notice" type='notice'>
<h4>功能适用性</h4>
<p>该内容仅适用于 OCP 企业版，OCP 社区版不支持此功能。</p>
</main>

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **仲裁服务维护** 资源权限。
  * 集群 **概览** 菜单权限。

* 新建仲裁服务时，所选主机不能为已部署 OceanBase 集群的主机。

## 操作步骤

1. 登录 OCP 。

2. 在左导航栏单击 **集群** ，并进入 **仲裁服务** 页签。

3. 单击 **服务组** 页签，进入 **服务组** 列表页面。

4. 单击右上角 **新建服组** 。

5. 在 **新建服务组** 面板中，设置仲裁服务组的基础信息。

    |  参数         |   说明   |
    |---------------|----------|
    | 服务组名称    | 支持以英文字母开头、英文或数字结尾，可包含英文、数字和下划线，且长度为 2 ~ 32 个字符。   |
    | 仲裁服务地址  | 可以从列表中选择已有的仲裁服务地址，所选仲裁服务的版本必须保持一致，且建议至少选择 2 个或多个地址；也可以在列表下方单击 **新建仲裁服务**，创建所需版本的仲裁服务。  |
    | 替换优先级    | 默认设置最高优先级为 1，当本组内其他仲裁服务出现异常时，系统默认使用优先级为 1 的仲裁服务地址进行替换，仅当优先级为 1 的仲裁服务不可用或资源不足时，系统将使用优先级为 2 的仲裁服务地址，以此类推进行仲裁服务替换。<br>系统默认根据添加 **仲裁服务地址** 时的先后顺序进行优先级排序，如需调整优先级，可在优先级列表中通过拖拽调整顺序。   |
    | 异常替换条件  | 用于配置单个 OceanBase 集群自动切换仲裁服务的触发条件，具体包括如下 3 种：<ul><li>默认触发条件：适用于租户（2F1A/4F1A）半数副本与仲裁服务无法连接的场景，此时可以通过配置 **异常持续时长** 来触发系统仲裁服务地址自动替换。**异常持续时长** 默认值为 10 秒，最大值可配置为 3600 秒，为 0 时表示符合 Unit 个数或者百分比规则立即触发。</li><li>Unit 失连个数触发条件：适用于当 OceanBase 集群中存在指定个数的 Unit Server 与仲裁服务失连的场景，默认当 1 个 Unit 失连且 **异常持续时长** 超过 10 秒时触发系统仲裁服务地址自动替换。</li><li>Unit 失连百分比触发条件：适用于当 OceanBase 集群中存在指定百分比的 Unit Server 与仲裁服务失连的场景，默认当 50% 及以上 Unit 失连且 **异常持续时长** 超过 10 秒时触发系统仲裁服务地址自动替换。</li></ul> |
    | 备注          | 选填内容，为仲裁服务组补充相关说明。   |
    | 自动执行      | 选择是否允许自动执行仲裁服务地址替换。  |

6. 单击 **确定**。
