# 上传软件包

本页面为您介绍上传软件包的操作步骤。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **集群维护**、**租户维护**、**OBProxy 维护**、**仲裁服务维护**、**Binlog 服务维护** 或 **主机维护** 任一资源权限。
* 系统管理 **<UI-TERM key="ocp-v2.src.hook.useMenu.SoftwarePackageManagement">软件包管理</UI-TERM>** 菜单权限。

## 操作步骤

1. 在左侧导航栏单击 **系统管理** > **软件包管理** ，进入软件包页面。

2. 单击 **<UI-TERM key="ocp-v2.Component.UpgradeDrawer.Upload">上传</UI-TERM>** ，在弹出框中单击 **<UI-TERM key="ocp-v2.Dashboard.component.ImportDashboardModal.SelectFile">选择软件包</UI-TERM>** ，选择本地要上传的软件包并单击 **<UI-TERM key="ocp-v2.Auth.Org.CreateOrg.Ok">上传</UI-TERM>** 。

   支持的安装包类型包括 OceanBase、Binlog、OCP Agent、OBProxy、备份恢复及其他。

   <main id="notice" type='notice'>
    <h4>注意</h4>
    <p><ul><li>支持批量上传多个 <code>.rpm</code> 或 <code>tar.gz</code> 格式的安装包，上限为 10 个。</li><li>若您的系统版本为 <code>debian</code>，且需要自定义 OCP Agent 安装目录，建议您使用 <code>tar.gz</code> 后缀的 OCP Agent 安装包，并通过 <code>ocp.agent.home.path.prefix</code> 系统参数自定义安装目录。</li><li>若所上传的软件包为非正式包，则会存在一定风险，建议不要部署在正式集群环境。</li><li>企业版 OCP 会对所上传的软件包进行签名验证，若验证失败，将无法上传软件包，建议您选择其他软件包重新上传。</li></ul></p>
   </main>

3. 上传完成后，可在软件包列表中查看软件包信息。

## 相关操作

您可在软件包列表中查看软件包信息，包括 **软件包名**、**类型**、**版本**、**系统**、**硬件架构**、**大小（MiB）** 和 **上传时间**。

* 可根据 **类型**、**版本**、**系统** 和 **硬件架构** 对软件包进行筛选。

* 可根据 **软件包名** 和 **<UI-TERM key="ocp-v2.page.Package.UploadTime">上传时间</UI-TERM>** 对软件包进行排序。
