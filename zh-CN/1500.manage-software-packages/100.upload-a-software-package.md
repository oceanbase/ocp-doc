# 上传软件包

本页面为您介绍上传软件包的操作步骤。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **集群维护**、**租户维护**、**OBProxy 维护**、**仲裁服务维护**、**Binlog 服务维护** 或 **主机维护** 任一资源权限。
* 系统管理 **<UI-TERM key="ocp-v2.src.hook.useMenu.SoftwarePackageManagement">软件包管理</UI-TERM>** 菜单权限。

## 操作步骤

1. 在左侧导航栏单击 **系统管理 > 软件包管理** ，进入软件包页面。

2. 单击 **<UI-TERM key="ocp-v2.Component.UpgradeDrawer.Upload">上传</UI-TERM>** ，在弹出框中单击 **<UI-TERM key="ocp-v2.Dashboard.component.ImportDashboardModal.SelectFile">选择文件</UI-TERM>** ，选择本地要上传的软件包并单击 **<UI-TERM key="ocp-v2.Auth.Org.CreateOrg.Ok">确定</UI-TERM>** 。

   上传文件为 OceanBase 安装包、Binlog 服务安装包、OCP Agent 安装包、Proxy 安装包、备份恢复安装包及其他 `.rpm` 格式的安装包。

   <main id="notice" type='notice'>
    <h4>注意</h4>
    <p><ul><li>支持批量上传多个 <code>.rpm</code> 包，上限为 10 个。</li><li>若所上传的软件包为非正式包，则会存在一定风险，建议不要部署在正式集群环境。</li><li>企业版 OCP 会对所上传的软件包进行签名验证，若验证失败，将无法上传软件包，建议您选择其他软件包重新上传。</li></ul></p>
   </main>

3. 上传完成后，可在软件包列表中查看软件包信息。
