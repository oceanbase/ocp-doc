# 查询日志

通过日志查询功能，您可基于对象范围、日志类型、日志级别和时间范围查看 OBServer 节点、仲裁服务、OBProxy、Binlog Server、Binlog 实例、主机和 OCP Agent 的日志。同时，OCP 支持根据指定的文本，对日志关键字进行普通匹配和正则匹配。

您可通过日志分析，查看所选对象的报错日志、状态异常组件，并支持进行具体分析。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **集群只读**、**租户只读**、**OBProxy 只读**、**仲裁服务只读**、**Binlog 服务只读** 或 **主机只读** 任一资源权限。
* 日志服务 **<UI-TERM key="ocp-v2.component.HostSelect.All">全部</UI-TERM>** 菜单权限。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏中选择 **系统管理 \> 日志服务** 。

   系统默认进入 **<UI-TERM key="ocp-v2.page.QueryLog.LogQuery">日志查询</UI-TERM>** 界面。除此之外，通过如下入口您也可以进入该界面。

    <main id="notice" type='explain'>
    <h4>说明</h4>
    <p>通过如下方式进入到 <strong>日志查询</strong> 页面的，系统将会根据入口自动填充查询条件的 <strong>对象范围</strong> 和 <strong>日志类型</strong> 。</p>
    </main>

   * 在集群 **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概览</UI-TERM>** 页的右上角，单击 **...** 并选择 **<UI-TERM key="ocp-v2.page.QueryLog.DownloadAllLogs">下载日志</UI-TERM>** 。

   * 在集群 **<UI-TERM key="ocp-v2.page.Overview.Overview">概览</UI-TERM>** 页的 **<UI-TERM key="ocp-v2.Component.OBServerList.ObserverList">OBServer 列表</UI-TERM>** 中，单击 **...** 并选择 **<UI-TERM key="ocp-v2.src.constant.task.DownloadLogs">下载日志</UI-TERM>** 。

   * 单击左侧导航栏 **<UI-TERM key="ocp-v2.src.component.ModifyTagResourceDrawer.Host">主机</UI-TERM>** ，在主机列表中勾选多个 **<UI-TERM key="ocp-v2.Scan.ReportTable.ServerInfoTable.IpAddress">IP 地址</UI-TERM>** ，单击页面右下方将出现 **<UI-TERM key="ocp-v2.page.Host.BatchDownloadLogs">批量下载日志</UI-TERM>** 按钮。

   * 在 OBProxy 集群 **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概览</UI-TERM>** 页的右上角，单击 **...** 并选择 **<UI-TERM key="ocp-v2.Detail.Overview.DownloadAllLogs">下载全部日志</UI-TERM>** 。

   * 在 OBProxy 集群 **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概览</UI-TERM>** 页的 **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.ObproxyList">OBProxy 列表</UI-TERM>** 中，单击 **<UI-TERM key="ocp-v2.component.CardAbnormalTable.Operation">操作</UI-TERM>** 列的 **<UI-TERM key="ocp-v2.Component.OBServerList.DownloadLogs">下载日志</UI-TERM>** 按钮。

3. 在 **<UI-TERM key="ocp-v2.page.QueryLog.LogQuery">日志查询</UI-TERM>** 界面中设置查询条件。

   ![1216](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/403-cn/%E6%97%A5%E5%BF%97%E6%9F%A5%E8%AF%A2.png)

   | 条件类别  |设置说明 |
   |-------|-------|
   | 对象范围  | 必填项，选择要日志查询的范围。 <ul><li> 前框选择日志查询的对象，可选 **<UI-TERM key="ocp-v2.src.constant.inspection.OceanbaseCluster">OceanBase 集群</UI-TERM>**、**<UI-TERM key="ocp-v2.page.Cluster.ArbitrationService">仲裁服务</UI-TERM>**、**<UI-TERM key="ocp-v2.Alarm.Event.ObproxyCluster">OBProxy 集群</UI-TERM>**、**Binlog Server**、**<UI-TERM key="ocp-v2.Task.TaskObjectAndType.BinlogInstance">Binlog 实例</UI-TERM>**、**<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.Host">主机</UI-TERM>**。 </li>  <li> 后框选择该对象的具体服务器，可多选。当日志查询对象为 **<UI-TERM key="ocp-v2.src.component.ModifyTagResourceDrawer.Host">主机</UI-TERM>** 时，被选择的服务器支持以集群维度进行展示。</li></ul> |
   | 日志类型  | 必填项，关于日志类型您可参考下方的 **日志类型说明**。  <ul><li>  前框选择日志大类，可选 **<UI-TERM key="ocp-v2.src.constant.log.ObLog">OB 日志</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.log.ArbitrationServiceLog">仲裁服务日志</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.alarm.ObproxyLogs">OBProxy 日志</UI-TERM>**、**Binlog Server 日志**、**<UI-TERM key="ocp-v2.src.constant.log.BinlogInstanceLogs">Binlog 实例日志</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.compute.HostLogs">主机日志</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.compute.OcpAgentLog">OCP Agent 日志</UI-TERM>**。 </li>  <li>  后框选择需查看的该类日志下的具体日志文件，可多选。</li>   </ul>   |
   | 日志级别  | 选择要查看的日志级别，您可选择：ERROR、WARN、INFO、WDIAG、EDIAG、TRACE、DEBUG，可多选。 |
   | 时间范围  | 默认为近一个小时。您可通过左边框快速定义范围为近 5/10/15/30 分钟、近 1/3/6/12/24 小时或近 7 天，也可通过右边时间起始框自定义时间范围。 |
   | 关键字   | 日志查询时会筛选出含该关键字的日志。支持对多个关键字进行正则匹配和普通匹配。 |
   | 排除关键字 | 日志查询时会过滤含该关键字的日志。支持对多个关键字进行排除。  |

4. 单击 **<UI-TERM key="ocp-v2.Detail.SQLDiagnosis.Query">查询</UI-TERM>** 按钮。

   界面下方展示符合查询条件的日志记录。

   ![18](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/403-cn/%E6%97%A5%E5%BF%97%E8%AF%A6%E6%83%85.png)

   * 您可通过 ① 处，切换服务器，查看不同服务器上的日志详情。

   * 您可通过 ② 处，切换日志文件。

5. 单击 ③ 处 **<UI-TERM key="ocp-v2.Detail.Log.LogCard.DownloadLogs">下载日志</UI-TERM>** 按钮。

   可下载此服务器上满足选择（填入）条件的全部日志。

## 日志类型说明

日志类型信息如下：

|     日志类型       |  说明  |
|--------------------|--------|
| OB 日志            | `OceanBase 集群安装路径/log/` 目录下所有的日志，细分为 `observer`、`rootservice`、`election`、`alert` 4 类。   |
| 仲裁服务日志       | `仲裁服务安装路径/log/` 目录下所有的日志，细分为 `arbitration_observer`、`arbitration_rootservice`、`arbitration_election` 3 类。 |
| OBProxy 日志       | `/home/admin/logs/obproxy/log/` 目录下所有的日志，细分为 `obproxy`、`obproxy_digest`、`obproxy_stat`、`obproxy_slow`、`obproxy_limit`、`obproxy_diagnosis`、`obproxy_xflush`、`obproxy_error` 8 类。  |
| Binlog Server 日志 | `Binlog 集群安装路径/log/` 目录下的所有日志，细分为 `binlog_server_deploy`、`binlog_server_logproxy`、`binlog_server_out` 3 类。  |
| Binlog 实例日志    | `Binlog 集群安装路径/run/实例名/log` 目录下的所有日志，细分为 `binlog_service_instance`、`binlog_service_init`、`binlog_service_libobcdc`、`binlog_service_libobcdc_stderr` 4 类。 |
| 主机日志           | `/var/log` 路径下的 **message-日期** 文件。  |
| OCP Agent 日志     | `/home/admin/ocp_agent/log/` 目录下所有的日志，细分为 `mgragent`、`monagent`、`agentctl`、`agentd` 4 类。|
