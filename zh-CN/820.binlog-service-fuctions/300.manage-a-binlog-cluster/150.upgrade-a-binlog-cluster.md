# 升级版本

您可以根据业务需要对 Binlog 集群进行版本升级。在升级过程中，若集群下的 Binlog 实例为单副本模式，对于下游业务可能存在分钟级延迟；若集群下的 Binlog 实例为多副本模式，系统默认进行切主，对于下游业务可能存在秒级延迟，请谨慎操作。

在 OCP 中，升级 Binlog 集群有如下两种方式：

* **方式一**：在 **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">集群列表</UI-TERM>** 中，单击操作列的 **<UI-TERM key="ocp-v2.Detail.Component.UpgradeModal.UpgradedVersion">升级版本</UI-TERM>**。
* **方式二**：在 **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog 集群概览</UI-TERM>** 页面，单击右上角 **<UI-TERM key="ocp-v2.Detail.Component.UpgradeObproxiesModal.UpgradedVersion">升级版本</UI-TERM>**。

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **Binlog 服务维护** 资源权限。
  * Binlog 服务 **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog 集群概览</UI-TERM>** 菜单权限。

* 待升级的 Binlog 集群以及集群下的 Binlog 实例均处于 **<UI-TERM key="ocp-v2.src.constant.obproxy.NormalOperation">正常运行</UI-TERM>** 状态。
* 仅支持升级到 V4.2.0.0 及以上版本。

## 操作步骤

以下操作步骤以 **方式二** 为例。

1. 登录 OCP 。

2. 在左侧导航栏单击 **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogService">Binlog 服务</UI-TERM>** ，系统默认进入 Binlog 的 **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">集群列表</UI-TERM>** 页面。

3. 在 **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">集群列表</UI-TERM>** 中选择待操作的 Binlog 集群并单击其集群名。

4. 在集群 **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog 集群概览</UI-TERM>** 页面，单击右上角 **<UI-TERM key="ocp-v2.Detail.Component.UpgradeModal.UpgradedVersion">升级版本</UI-TERM>** 。

5. 在对话框中选择升级版本软件包，单击 **<UI-TERM key="ocp-v2.Arbitration.ArbitrationGroup.UpgradeArbitrationGroup.Upgrade">升级</UI-TERM>**。

   如果没有对应的软件包，您可以单击 **<UI-TERM key="ocp-v2.src.component.PackageSelect.UploadASoftwarePackage">上传软件包</UI-TERM>** ，上传所需的软件包版本。

6. 您可在 **<UI-TERM key="ocp-v2.Layout.BasicLayout.TaskCenter">任务中心</UI-TERM>** 中查看任务执行进度，当任务状态为 **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.SuccessfulExecution">执行成功</UI-TERM>** ，且该集群的状态为 **<UI-TERM key="ocp-v2.src.constant.oceanbase.NormalOperation">正常运行</UI-TERM>** 时，集群升级成功。
