# 停止/启动 Binlog 集群

您可以根据业务需要停止或开启 Binlog 集群。停止 Binlog 集群仅对集群管控生效，不会影响 Binlog 实例正常运行，也不会影响业务对 Binlog 数据的连接消费。

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **Binlog 服务维护** 资源权限。
  * Binlog 服务 **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog 集群概览</UI-TERM>** 菜单权限。

* 进行停止操作时，待停止的 Binlog 集群处于 **<UI-TERM key="ocp-v2.src.constant.oceanbase.NormalOperation">正常运行</UI-TERM>** 状态。
* 进行启动操作时，待启动的 Binlog 集群处于 **<UI-TERM key="ocp-v2.src.constant.binlog.Stopped.3">已停止</UI-TERM>** 状态。

## 操作步骤

1. 登录 OCP 。

2. 在左侧导航栏单击 **<UI-TERM key="ocp-v2.Detail.Overview.BinlogService">Binlog 服务</UI-TERM>** ，系统默认进入 Binlog 的 **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">集群列表</UI-TERM>** 页面。

3. 在 **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">集群列表</UI-TERM>** 中选择待操作的 Binlog 集群并单击其集群名。

4. 在集群 **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog 集群概览</UI-TERM>** 页面，单击右上角 **...** 图标，选择 **<UI-TERM key="ocp-v2.Detail.Overview.StopBinlogCluster">停止 Binlog 集群</UI-TERM>** 。

5. 在对话框中单击 **<UI-TERM key="ocp-v2.Component.BinlogServerList.Stop">停止</UI-TERM>** 。

   您可在 **<UI-TERM key="ocp-v2.Layout.BasicLayout.TaskCenter">任务中心</UI-TERM>** 中查看任务执行进度，当任务状态为 **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.SuccessfulExecution">执行成功</UI-TERM>** ，且该集群的状态为 **<UI-TERM key="ocp-v2.src.constant.oceanbase.Stopped">已停止</UI-TERM>** 时，则集群停止成功。

6. 启动集群。

   集群停止后，可通过集群 **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概览</UI-TERM>** 页右上角的 **<UI-TERM key="ocp-v2.Detail.Overview.StartTheBinlogCluster">启动 Binlog 集群</UI-TERM>** ，再次启用该 Binlog 集群。
