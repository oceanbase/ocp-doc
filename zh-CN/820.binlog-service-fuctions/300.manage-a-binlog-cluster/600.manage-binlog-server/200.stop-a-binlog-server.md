# 停止/启动 Binlog Server

本节为您介绍停止和启动 Binlog Server 的操作。

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **Binlog 服务维护** 资源权限。
  * Binlog 服务 **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlog 集群概览</UI-TERM>** 菜单权限。

* 进行停止操作时，待停止的 Binlog Server 及所属 Binlog 集群均处于 **<UI-TERM key="ocp-v2.src.constant.tenant.NormalOperation">正常运行</UI-TERM>** 状态。
* 进行启动操作时，待启动的 Binlog Server 处于 **<UI-TERM key="ocp-v2.src.constant.oceanbase.Stopped">已停止</UI-TERM>** 状态，且所属 Binlog 集群处于 **<UI-TERM key="ocp-v2.page.Overview.Content.NormalOperation">正常运行</UI-TERM>** 或 **<UI-TERM key="ocp-v2.src.constant.oceanbase.Stopped">已停止</UI-TERM>** 状态。

## 操作步骤

1. 登录 OCP 。

2. 在左侧导航栏单击 **<UI-TERM key="ocp-v2.Detail.Overview.BinlogService">Binlog 服务</UI-TERM>** ，系统默认进入 Binlog 的 **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">集群列表</UI-TERM>** 页面。

3. 在 **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">集群列表</UI-TERM>** 中选择待操作的 Binlog 集群并单击其集群名，进入 **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog 集群概览</UI-TERM>** 页面。

4. 在 **Binlog Server 列表** 模块，选择需要停止的节点，单击操作列的 **<UI-TERM key="ocp-v2.src.constant.obproxy.Stop">停止</UI-TERM>** 。

5. 在对话框中，单击 **<UI-TERM key="ocp-v2.Component.BinlogServerList.Stop">停止</UI-TERM>**。

   您可在 **<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">任务中心</UI-TERM>** 中查看任务进度。当该任务状态为 **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.SuccessfulExecution">执行成功</UI-TERM>** ，且 **Binlog Server 列表** 中相应 OBServer 节点的状态为 **<UI-TERM key="ocp-v2.src.constant.binlog.Stopped.3">已停止</UI-TERM>** ，则任务成功。

6. 启动 Binlog Server。

   Binlog Server 停止后，可单击 **Binlog Server 列表** 中操作列的 **<UI-TERM key="ocp-v2.Restore.SamplingStrategy.Start">启动</UI-TERM>**，再次启用该 Binlog Server。
