# 删除 Binlog Server

本节为您介绍如何删除 Binlog 集群中的 Binlog Server。

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **Binlog 服务维护** 资源权限。
  * Binlog 服务 **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlog 集群概览</UI-TERM>** 菜单权限。

* 待删除的 Binlog Server 所属的 Binlog 集群处于 **<UI-TERM key="ocp-v2.src.constant.backup.NormalOperation">正常运行</UI-TERM>** 或 **<UI-TERM key="ocp-v2.src.constant.backup.Stopped">已停止</UI-TERM>** 状态。
* 当 Binlog 集群下仅存在一个 Binlog Server 时，若想删除该集群下的 Binlog Server，需删除此 Binlog 集群。

## 操作步骤

1. 登录 OCP 。

2. 在左侧导航栏单击 **<UI-TERM key="ocp-v2.Detail.Overview.BinlogService">Binlog 服务</UI-TERM>** ，系统默认进入 Binlog 的 **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">集群列表</UI-TERM>** 页面。

3. 在 **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">集群列表</UI-TERM>** 中选择待操作的 Binlog 集群并单击其集群名，进入 **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlog 集群概览</UI-TERM>** 页面。

4. 在 **Binlog Server 列表** 模块，选择需要删除的节点，单击操作列的 **<UI-TERM key="ocp-v2.src.constant.compute.Delete">删除</UI-TERM>** 。

5. 在对话框中，输入 **delete** ，并单击 **<UI-TERM key="ocp-v2.src.constant.iam.Delete">删除</UI-TERM>**。

   您可在 **<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">任务中心</UI-TERM>** 中查看任务进度。当该任务状态为 **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.SuccessfulExecution">执行成功</UI-TERM>** ，且 **Binlog Server 列表** 中无该 Binlog Server 时，表示删除成功。

## 相关操作

删除 Binlog Server 后，节点上的 Binlog 实例需要您手动按需处理，详情可参考 [清理主机 Binlog 实例](400.clean-binlog-instance-on-a-host.md)。
