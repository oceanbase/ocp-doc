# 查看 Binlog 集群概览

进入具体的集群页面，您可查看当前 Binlog 集群的基本信息、Binlog 实例信息和 Binlog Server 信息，并支持对集群进行日常运维操作。

## 前提条件

当前登录 OCP 的用户具备如下权限时，才能查看 Binlog 集群概览数据。

* **Binlog 服务只读** 资源权限。
* Binlog 服务 **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog 集群概览</UI-TERM>** 菜单权限。

## 集群基本信息

您可在 **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlog 集群概览</UI-TERM>** 页面查看集群基础信息，包括 **<UI-TERM key="ocp-v2.Binlog.Component.UpgradeBinlogModal.BinlogClusterName">Binlog 集群名</UI-TERM>** 、**<UI-TERM key="ocp-v2.Host.Detail.Basic.State">状态</UI-TERM>** 、**<UI-TERM key="ocp-v2.Binlog.Component.UpgradeBinlogModal.VersionNumber">版本号</UI-TERM>** 、**<UI-TERM key="ocp-v2.Detail.Overview.CdcVersion">CDC 版本</UI-TERM>** 、**<UI-TERM key="ocp-v2.page.External.CreationTime">创建时间</UI-TERM>** 、**<UI-TERM key="ocp-performance-report.ReportTables.ParameterStatInfo.ZoneParamInfoTable.ModificationTime">修改时间</UI-TERM>** 、**<UI-TERM key="ocp-v2.Detail.Overview.MetadbInformation">MetaDB 信息</UI-TERM>** 、**<UI-TERM key="ocp-v2.Detail.Overview.SoftwareInstallationDirectory">软件安装目录</UI-TERM>** 及 **Binlog 文件生成目录** 信息。

| 参数          |  说明  |
|---------------|--------|
| Binlog 集群名 |   |
| 状态          | 集群当前的运行状态，包括 **<UI-TERM key="ocp-v2.Detail.Statistics.utils.Running">运行中</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.obproxy.Creating">创建中</UI-TERM>** 、**<UI-TERM key="ocp-v2.src.constant.binlog.OM">运维中</UI-TERM>** 、**<UI-TERM key="ocp-v2.Topo.TopoGraph.Deleting">删除中</UI-TERM>** 、**<UI-TERM key="ocp-v2.src.constant.backup.Starting">启动中</UI-TERM>** 、**<UI-TERM key="ocp-v2.src.constant.compute.Restarting">重启中</UI-TERM>** 、**<UI-TERM key="ocp-v2.src.constant.compute.Stopping">停止中</UI-TERM>** 和 **<UI-TERM key="ocp-v2.src.constant.binlog.Stopped.3">已停止</UI-TERM>** 。  |
| 版本号        | 当前 Binlog 集群的版本号。   |
| CDC 版本      | 当前集群的 OceanBase CDC 版本号。    |
| 创建时间      | 当前集群的创建时间。   |
| 修改时间      | 当前集群的最后一次修改时间。   |
| MetaDB 信息   | 单击 **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.View">查看</UI-TERM>** ，在弹窗中查看当前 Binlog 集群所使用的 MetaDB 配置信息。   |
| 软件安装目录  | Binlog 的安装路径，此处展示您 [创建 Binlog 集群](../200.create-a-binlog-cluster.md) 时填写的路径。   |
| Binlog 文件生成目录   |  Binlog 的数据存储路径，默认值为 `软件安装目录/run`。  |

## 查看 Binlog 实例列表

**<UI-TERM key="ocp-v2.Component.BinlogInstanceList.BinlogInstanceList">Binlog 实例列表</UI-TERM>** 中列举了 Binlog 集群下所有的实例信息，您可查看不同业务租户下的 Binlog 实例信息，包括 **<UI-TERM key="ocp-v2.Component.BinlogInstanceList.BinlogInstanceName">Binlog 实例名称</UI-TERM>** 、**<UI-TERM key="ocp-v2.Component.BinlogInstanceList.NodeIp">节点 IP</UI-TERM>** 、**转换延迟** 、**转化 RPS** 、**订阅连接数** 和 **<UI-TERM key="ocp-v2.component.TaskBubble.State">状态</UI-TERM>** 信息，并支持对 Binlog 实例进行 **<UI-TERM key="ocp-v2.src.constant.binlog.ConfigureThrottling">配置限流</UI-TERM>**、**<UI-TERM key="ocp-v2.Cluster.Arbitration.Stop">停止</UI-TERM>** 、**<UI-TERM key="ocp-v2.src.constant.binlog.Start">启动</UI-TERM>** 和 **<UI-TERM key="ocp-v2.src.constant.backup.Restart">重启</UI-TERM>** 操作，详情可参见 [管理 Binlog 实例](500.manage-binlog-instance/100.binlog-instance-overview.md)。

![Binlog Server 实例](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/435/06261430.png)

## 查看 Binlog Server 列表

您可在 **Binlog Server 列表** 中查看 Binlog Server 的 **IP** 、**<UI-TERM key="ocp-v2.Detail.Component.AddUserDrawer.Hostname">主机名</UI-TERM>** 、**<UI-TERM key="ocp-v2.Detail.Component.WaterLevel.ResourceWaterLevel">资源水位</UI-TERM>** 、**<UI-TERM key="ocp-v2.src.component.AddHostDrawer.HostType">主机类型</UI-TERM>** 、**<UI-TERM key="ocp-v2.OBProxy.New.ModelOptional">机型</UI-TERM>** 、**<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.ComputerRoom">机房</UI-TERM>** 、**<UI-TERM key="ocp-v2.Component.BackupStrategyDetail.Region">地域</UI-TERM>** 和 **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.State">状态</UI-TERM>** 信息，并可在对 Binlog Server 进行 **<UI-TERM key="ocp-v2.Component.BinlogServerList.Stop">停止</UI-TERM>** 、**<UI-TERM key="ocp-v2.Component.BinlogInstanceList.Start">启动</UI-TERM>** 和 **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.Delete">删除</UI-TERM>** 等运维操作，详情可参见 [管理 Binlog Server](600.manage-binlog-server/100.add-a-binlog-server.md)。

![Binlog Server 列表](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/431/binlogserver%E5%88%97%E8%A1%A8.png)

## 集群管理操作

您在 **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog 集群概览</UI-TERM>** 页面还可对集群进行其它基础管理操作，详情参见 [升级版本](150.upgrade-a-binlog-cluster.md)、[新增节点](600.manage-binlog-server/100.add-a-binlog-server.md)、[停止/启动 Binlog 集群](200.stop-and-start-a-binlog-cluster.md)、[重启 Binlog 集群](300.restart-a-binlog-cluster.md)、[删除 Binlog 集群](400.delete-a-binlog-cluster.md)、[查看日志](../../1300.log-service/100.log-query.md)。

同时，您也可根据左侧导航栏对集群进行日常运维操作，详情参见 [管理 Binlog 集群参数](../400.manage-binlog-cluster-parameters.md)。

## 切换 Binlog 集群

如需查看其它 Binlog 集群的概览信息，您可在 **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog 集群概览</UI-TERM>** 页面左上角的 Binlog 集群名称处选择您想查看的集群，则当前概览页会切换为您所查看的 Binlog 集群的概览页。

![切换 Binlog 集群](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/431/binlog%E9%9B%86%E7%BE%A4%E5%88%87%E6%8D%A2.png)
