# 新增实例副本

本节为您介绍如何为业务租户新增实例副本，您可通过 “一主多备” 模式保障主备实例之间的数据同步，进一步提升 Binlog 服务的高可用能力。建议单个 Binlog Server 仅承载业务租户的 1 个 Binlog 实例副本，同时单个业务租户最大支持 5 个实例副本。

## 前提条件

* 业务租户已开启 Binlog 服务，详情可参考 [管理租户 Binlog 服务](../../700.tenant-functions/600.manage-a-tenant/700.manage-binlog-service-of-a-tenant.md)。

* 请确保当前登录 OCP 的用户具备如下权限：

  * **Binlog 服务维护** 资源权限。
  * Binlog 服务 **Binlog 集群概览** 菜单权限。

## 操作步骤

1. 登录 OCP 。

2. 在左侧导航栏单击 **Binlog 服务** ，系统默认进入 Binlog 的 **集群列表** 页面。

3. 在 **集群列表** 中选择待操作的 Binlog 集群并单击其集群名。

4. 在 **Binlog 集群概览** 页面，单击右上角 **新增实例副本** 。

5. 在 **新增实例副本** 对话框中，指定待添加实例副本的业务租户，并为其配置副本数量和主机信息。

    最多支持再新增 4 个实例副本。您可将所有实例副本部署在同一台主机上，也可单击 **添加实例副本** 按钮，将实例副本部署于不同主机。

6. 单击 **新增**，提交任务。

   您可在 **任务中心** 中查看任务进度。当任务状态为 **执行成功** 时，表示新增节点成功。
