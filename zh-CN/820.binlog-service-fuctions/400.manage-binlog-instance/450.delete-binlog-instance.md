# 删除 Binlog 实例

本页面为您介绍删除备 Binlog 实例的步骤。

在 OCP 中，切换主备实例有如下两种方式：

* **方式一**：进入 **Binlog 集群概览** 页面，在 **Binlog 实例列表** 中选择待删除的备实例，单击操作列的 **... > 删除 Binlog 实例**。
* **方式二**：进入备实例的 **Binlog 实例概览** 页面，单击右上角 **... > 删除 Binlog 实例**。

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **Binlog 服务维护** 资源权限。
  * Binlog 服务 **Binlog 集群概览** 菜单权限。

* 待删除的 Binlog 实例为备实例，且实例对应的 Binlog Server 及 Binlog 集群为 **正常运行** 状态。

## 操作步骤

以下操作步骤以 **方式二** 为例。

1. 登录 OCP 。

2. 在左侧导航栏单击 **Binlog 服务** ，系统默认进入 Binlog 服务的 **集群列表** 页面。

3. 在 **集群列表** 中选择待操作的 Binlog 集群并单击其集群名，进入 **Binlog 集群概览** 页面。

4. 在 **Binlog 实例列表** 区域，选择待删除的 Binlog 备实例，单击实例名。

5. 进入其 **Binlog 实例概览** 页面，单击右上角 **... > 删除 Binlog 实例**。

6. 在对话框中单击 **删除** 。
