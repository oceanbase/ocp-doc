# 新增 Binlog Server

您可根据业务需要，参考本节内容向您管理的 Binlog 集群中添加 Binlog 节点，从而实现为集群扩容的目的。

在 OCP 中，为集群添加 Binlog Server 有如下两种方式：

* **方式一**：在 **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">集群列表</UI-TERM>** 中，单击操作列的 **<UI-TERM key="ocp-v2.Binlog.Component.AddBinlogNodeModal.AddNode">新增节点</UI-TERM>**。
* **方式二**：在 **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog 集群概览</UI-TERM>** 页面，单击右上角 **<UI-TERM key="ocp-v2.Binlog.Component.AddBinlogNodeModal.AddNode">新增 Binlog Server</UI-TERM>**。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **Binlog 服务维护** 资源权限。
* Binlog 服务 **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlog 集群概览</UI-TERM>** 菜单权限。

## 操作步骤

以下操作步骤以 **方式二** 为例。

1. 登录 OCP 。

2. 在左侧导航栏单击 **<UI-TERM key="ocp-v2.page.Binlog.BinlogService">Binlog 服务</UI-TERM>** ，系统默认进入 Binlog 的 **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">集群列表</UI-TERM>** 页面。

3. 在 **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">集群列表</UI-TERM>** 中选择待操作的 Binlog 集群并单击其集群名。

4. 在 **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlog 集群概览</UI-TERM>** 页面，单击右上角 **<UI-TERM key="ocp-v2.src.constant.binlog.AddNode">新增 Binlog Server</UI-TERM>** 。

5. 在 **<UI-TERM key="ocp-v2.src.constant.binlog.AddNode">新增 Binlog Server</UI-TERM>** 对话框中，指定待添加的 Binlog 节点的机房、机型和 Binlog 节点所在的主机（可多选）。

    默认只添加一个 Binlog 节点，如果需要添加多个 Binlog 节点，您可以在下方单击 **添加 Binlog Server** 按钮。

6. 单击 **<UI-TERM key="ocp-v2.Detail.Component.DailyChangeTenantModal.Ok">确定</UI-TERM>**，提交新增节点的任务。

   您可在 **<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">任务中心</UI-TERM>** 中查看任务进度。当任务状态为 **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.SuccessfulExecution">执行成功</UI-TERM>** ，且集群概览页面的 **Binlog Server 列表** 中相应 OBServer 节点的状态都为 **<UI-TERM key="ocp-v2.src.constant.obproxy.NormalOperation">正常运行</UI-TERM>** 时，表示新增节点成功。
