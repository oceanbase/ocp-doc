# 重启 OCP Agent

本页面为您介绍重启 OCP Agent 的操作步骤。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **主机维护** 资源权限。
* 主机 **<UI-TERM key="ocp-v2.Auth.Role.Detail.All">全部</UI-TERM>** 菜单权限。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏中单击 **<UI-TERM key="ocp-v2.Component.ZoneList.AddOBServerDrawer.Host">主机</UI-TERM>**。

3. 在 **主机** 页签中，选择需要重启 OCP Agent 的主机，单击操作列的 **... > <UI-TERM key="ocp-v2.Host.Detail.OCPAgent.RestartOcpAgent">重启 OCP Agent</UI-TERM>** 。

   系统弹出确认重启的操作提示。

4. 在弹出框中单击 **<UI-TERM key="ocp-v2.Detail.Component.UpgradeModal.Determine">确定</UI-TERM>** ，重启 OCP Agent。

5. 重启 OCP Agent 任务提交后，您可在主机列表中单击 **<UI-TERM key="ocp-v2.Plan.Component.PlanExecuteTable.ViewTasks">查看任务</UI-TERM>** 查看任务详情。
