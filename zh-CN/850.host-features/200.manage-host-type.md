# 管理机型

机型是用户为配置相同的主机指定的一个标签，建议您指定有意义的名称，便于更好地管理主机。

## 新增机型

本小节将为您介绍如何新增机型。

### 前提条件

* 当前登录 OCP 的用户为 **ADMIN** 角色或 **ORG_ADMIN** 角色。
* 机型名称具有全局唯一性。

### 操作步骤

1. 登录 OCP。

2. 在左侧导航栏中单击 **主机**。

3. 进入 **机型** 页签，单击右上角 **新增机型**。

4. 在对话框中输入机型名称与说明，单击 **新增**。

## 修改机型说明

本小节将为您介绍如何修改机型的说明信息。

### 前提条件

请确保当前登录 OCP 的用户至少具备如下权限：

* **主机维护** 资源权限。
* 主机 **<UI-TERM key="ocp-v2.component.common.ServerDropdown.All">全部</UI-TERM>** 菜单权限。

### 操作步骤

1. 登录 OCP。

2. 在左侧导航栏中单击 **主机**。

3. 进入 **机型** 页签，选择需要修改的机型，单击说明列的编辑按钮。

4. 在对话框中修改说明信息，单击 **确定**。

## 删除机型

本小节将为您介绍如何删除机型。

### 前提条件

* 请确保当前登录 OCP 的用户至少具备如下权限：

  * **主机维护** 资源权限。
  * 主机 **<UI-TERM key="ocp-v2.component.common.ServerDropdown.All">全部</UI-TERM>** 菜单权限。

* 当机型存在关联主机时，不支持删除。

### 操作步骤

1. 登录 OCP。

2. 在左侧导航栏中单击 **主机**。

3. 进入 **机型** 页签，选择需要删除的机型，单击操作列的 **删除**。

4. 在对话框中确认主机信息，确认无误后单击 **删除**。
