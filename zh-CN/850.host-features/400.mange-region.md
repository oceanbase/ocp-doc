# 管理区域

区域用于表示主机所处的地理区域，一个物理区域下可以存在一个或多个物理机房。区域和机房是 OceanBase 负载均衡和 SQL 语句路由策略的参考项，请按照实际情况填写。

## 新增区域

本小节将为您介绍如何新增区域。

### 前提条件

* 当前登录 OCP 的用户为 **ADMIN** 角色或 **ORG_ADMIN** 角色。
* 区域名称具有全局唯一性。

### 操作步骤

1. 登录 OCP。

2. 在左侧导航栏中单击 **主机**。

3. 进入 **区域** 页签，单击右上角 **新增区域**。

4. 在对话框中输入区域与说明，单击 **新增**。

## 修改区域说明

本小节将为您介绍如何修改区域的说明信息。

### 前提条件

请确保当前登录 OCP 的用户至少具备如下权限：

* **主机维护** 资源权限。
* 主机 **<UI-TERM key="ocp-v2.component.common.ServerDropdown.All">全部</UI-TERM>** 菜单权限。

### 操作步骤

1. 登录 OCP。

2. 在左侧导航栏中单击 **主机**。

3. 进入 **区域** 页签，选择需要修改的区域，单击说明列的编辑按钮。

4. 在对话框中修改说明信息，单击 **确定**。

## 删除区域

本小节将为您介绍如何删除区域。

### 前提条件

* 请确保当前登录 OCP 的用户至少具备如下权限：

  * **主机维护** 资源权限。
  * 主机 **<UI-TERM key="ocp-v2.component.common.ServerDropdown.All">全部</UI-TERM>** 菜单权限。

* 当区域存在关联机房时，不支持删除。

### 操作步骤

1. 登录 OCP。

2. 在左侧导航栏中单击 **主机**。

3. 进入 **区域** 页签，选择需要删除的区域，单击操作列的 **删除**。

4. 在对话框中确认信息，确认无误后单击 **删除**。
