# 管理机房

您可参考如下内容对机房进行管理。

<main id="notice" type='explain'>
<h4>说明</h4>
<p>OCP V3.1.1 版本开始支持多可用区模式，新增机房时，将在当前 OCP 所在的可用区中创建新的机房。</p>
</main>

## 新增机房

本小节将为您介绍如何新增机房。

### 前提条件

* 当前登录 OCP 的用户为 **ADMIN** 角色或 **ORG_ADMIN** 角色。
* 机房名称具有全局唯一性。

### 操作步骤

1. 登录 OCP。

2. 在左侧导航栏中单击 **主机**。

3. 进入 **机房** 页签，单击右上角 **新增机房**。

4. 在对话框中输入机房、区域与说明，单击 **新增**。

## 修改机房说明

本小节将为您介绍如何修改机房的说明信息。

### 前提条件

请确保当前登录 OCP 的用户至少具备如下权限：

* **主机维护** 资源权限。
* 主机 **<UI-TERM key="ocp-v2.component.common.ServerDropdown.All">全部</UI-TERM>** 菜单权限。

### 操作步骤

1. 登录 OCP。

2. 在左侧导航栏中单击 **主机**。

3. 进入 **机房** 页签，选择需要修改的机房，单击说明列的编辑按钮。

4. 在对话框中修改说明信息，单击 **确定**。

## 删除机房

本小节将为您介绍如何删除机房。

### 前提条件

* 请确保当前登录 OCP 的用户至少具备如下权限：

  * **主机维护** 资源权限。
  * 主机 **<UI-TERM key="ocp-v2.component.common.ServerDropdown.All">全部</UI-TERM>** 菜单权限。

* 当机房存在关联主机时，不支持删除。

### 操作步骤

1. 登录 OCP。

2. 在左侧导航栏中单击 **主机**。

3. 进入 **机房** 页签，选择需要删除的机房，单击操作列的 **删除**。

4. 在对话框中确认信息，确认无误后单击 **删除**。
