# 管理主机操作列表

拥有系统管理员、主机管理员（HOST_MANAGER）角色和主机只读角色（HOST_VIEWER）的用户，可以单击页面左部导航中的 **<UI-TERM key="ocp-v2.Arbitration.ArbitrationGroup.Host">主机</UI-TERM>** 进入 **<UI-TERM key="ocp-v2.alarm.FormListWithExclude.HostWithExclude.Host">主机</UI-TERM>** 页面。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **集群只读**、**租户只读** 或 **主机只读** 任一资源权限。
* 主机 **<UI-TERM key="ocp-v2.alarm.FormListWithExclude.ObproxyClusterAndHostWithExclude.All">全部</UI-TERM>** 菜单权限。

## 查看主机列表

**<UI-TERM key="ocp-v2.page.Host.HostList">主机列表</UI-TERM>** 展示了当前所有主机信息，包括 **<UI-TERM key="ocp-v2.Cluster.New.IpAddress">IP 地址</UI-TERM>**、**<UI-TERM key="ocp-v2.page.Host.Hostname">主机名</UI-TERM>**、**<UI-TERM key="ocp-v2.Host.Detail.Basic.Label">标签</UI-TERM>**、**<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.HostType">主机类型</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Resource.Unit.Models">机型</UI-TERM>**、**<UI-TERM key="ocp-v2.src.component.AddHostDrawer.ComputerRoom">机房</UI-TERM>**、**<UI-TERM key="ocp-v2.Component.BackupStrategyDetail.Region">地域</UI-TERM>**、**<UI-TERM key="ocp-v2.Tenant.Detail.BelongsCluster">所属集群</UI-TERM>**、**<UI-TERM key="ocp-v2.Host.Detail.Basic.Service">所属服务</UI-TERM>** 和 **<UI-TERM key="ocp-v2.Host.Detail.Basic.State">状态</UI-TERM>**。

* 支持进行分页查询，以及按照 IP 地址、主机名和所属集群进行搜索。其中，支持对主机 IP 进行批量查询，各地址 IP 之间使用空格间隔。
* 将光标悬停于主机标签上，可查看该主机的所有标签信息。支持单击编辑图标对标签进行管理，操作详情可参见 [管理标签](../1600.system-management-features/300.manage-tags/100.tags-overview.md)。
* 支持对 **<UI-TERM key="ocp-v2.component.TagLabel.Label">标签</UI-TERM>**、**<UI-TERM key="ocp-v2.src.component.AddHostDrawer.HostType">主机类型</UI-TERM>**、**<UI-TERM key="ocp-v2.Cluster.New.Models">机型</UI-TERM>**、**<UI-TERM key="ocp-v2.page.Host.DataCenter">机房</UI-TERM>**、**<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.Region">地域</UI-TERM>**、**<UI-TERM key="ocp-v2.Backup.Backup.Log.Cluster">所属集群</UI-TERM>**、**<UI-TERM key="ocp-v2.Host.Detail.Basic.Service">所属服务</UI-TERM>** 和 **<UI-TERM key="ocp-v2.Statistics.components.StatTable.Status">状态</UI-TERM>** 进行筛选。
* 当主机处于 **<UI-TERM key="ocp-v2.src.constant.binlog.OM">运维中</UI-TERM>** 状态时，单击 **操作列** 的 **<UI-TERM key="ocp-v2.page.Welcome.ViewTasks">查看任务</UI-TERM>** 按钮，可以跳转至集群运维的任务详情页面。在任务详情页面，您可进行查看日志、回滚和重试等操作，详情参见 [管理任务](../1600.system-management-features/600.manage-tasks.md)。
* 单击主机 IP 地址，可查看主机基本信息、OCP Agent 信息和主机监控数据，详情参见 [查看主机详情](150.view-a-host-overview.md)。
* 单击集群名称，可跳转至集群 **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概览</UI-TERM>** 页面查看集群详情。

![1223](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/%E4%B8%BB%E6%9C%BA%E5%88%97%E8%A1%A8.png)

展开折叠页面，还可以查看 **<UI-TERM key="ocp-v2.page.Host.HostId">主机 ID</UI-TERM>**、**<UI-TERM key="ocp-v2.page.Host.MappingPort">映射端口</UI-TERM>**、**<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.SshPort">SSH 端口</UI-TERM>**、**<UI-TERM key="ocp-v2.Host.Component.ReinstallModal.OcpAgentVersion">OCP Agent 版本</UI-TERM>**、**<UI-TERM key="ocp-v2.page.Host.OperatingSystem">操作系统</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Component.UpgradeObproxiesModal.CpuArchitecture">CPU 架构</UI-TERM>**、**<UI-TERM key="ocp-v2.page.Host.CpuModel">CPU 型号</UI-TERM>**、**<UI-TERM key="ocp-v2.Host.Detail.Basic.CpuCores">CPU 核数</UI-TERM>**、**<UI-TERM key="ocp-v2.page.Host.TotalMemory">总内存</UI-TERM>** 和 **<UI-TERM key="ocp-v2.Detail.Component.ModifyParameterDrawer.Description">说明</UI-TERM>** 。

|   参数   |     说明        |
|--------|-----------|
| 所属集群   | 显示主机所在的集群，包括 OceanBase 集群和 OBProxy 集群。单击集群名称，可跳转至对应集群的概览页面。      |
| 主机类型   | 当前版本支持物理主机、容器和 ECS 三类主机：<li>单台物理主机混合部署多种服务，但是相同类型的服务只能部署一个，避免同类服务产生冲突。</li><li> 单台容器主机，仅支持部署一种服务；根据 OceanBase 集群部署要求，不推荐部署 OceanBase 集群到容器类型主机。 </li>  |
| 状态     | 包括新提交、空闲、在线、离线、删除中、Agent 重装中和 Agent 重启中。    |
| 映射端口 | ocp-agent 与宿主机、ocp export 与宿主机 一共 2 组的映射关系，对应的格式为：`<主机端口>:<docker 中 ocp-agent 端口>, <主机端口>:<docker 中 ocp-exporter 端口 1>`。       |
