# 查看主机详情

在主机详情页面，您可查看主机的基本信息、OCP Agent 信息和主机监控数据。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **集群只读**、**租户只读** 或 **主机只读** 任一资源权限。
* 主机 **<UI-TERM key="ocp-v2.alarm.FormListWithExclude.ObproxyClusterAndHostWithExclude.All">全部</UI-TERM>** 菜单权限。

## 查看主机基本信息

您可在 **<UI-TERM key="ocp-v2.TraceDetail.TraceContent.BasicInformation">基本信息</UI-TERM>** 页签查看主机详情和磁盘使用情况，并支持进行标签管理操作。

* **<UI-TERM key="ocp-v2.Alarm.Event.Detail.Details">详情</UI-TERM>** 中支持查看主机状态、主机名、主机别名、SSH 端口、机房、机型、主机类型、地域、磁盘使用、所属服务、时钟偏移、当前时间、时区、操作系统、CPU 架构、CPU 型号、CPU 核数、标签、总内存和说明等信息。

    将光标悬停于主机群标签上，可查看该主机的所有标签信息。单击编辑图标对标签进行管理，操作详情可参见 [管理标签](../1600.system-management-features/300.manage-tags/100.tags-overview.md)。

* **<UI-TERM key="ocp-v2.Host.Detail.Basic.DiskUsage">磁盘使用</UI-TERM>** 中支持查看各路径所占用的分区磁盘使用量、磁盘已使用量、可用磁盘大小、使用率及挂载目录等信息。

![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/%E4%B8%BB%E6%9C%BA%E8%AF%A6%E6%83%85.png)

## 查看 OCP Agent 信息

您可在 **OCP Agent** 页签查看 OCP Agent 详情和进程列表。

* **<UI-TERM key="ocp-v2.Alarm.Event.Detail.Details">详情</UI-TERM>** 中支持查看 OCP Agent 状态、安装目录、安装时间、版本、日志目录和最近可用时间。

* **<UI-TERM key="ocp-v2.Host.Detail.OCPAgent.Processes">进程列表</UI-TERM>** 支持查看详细的进程信息，包括进程 ID、名称、启动命令、操作系统用户、端口号、规格、已运行时间、最近可用时间、状态等。

  * 单击操作列的 **<UI-TERM key="ocp-v2.Host.Detail.OCPAgent.DownloadLogs">下载日志</UI-TERM>**，可下载当前进程的日志信息。

  * 单击 `ocp_monagent` 进程操作列的 **<UI-TERM key="ocp-v2.Host.Detail.OCPAgent.ChangeSpecifications">变更规格</UI-TERM>**，可为当前主机变更 OCP Agent 规格。

     <main id="notice" type='notice'>
     <h4>注意</h4>
     <p><ul><li>建议最大规格为 6C/12GiB。</li><li>建议 ocp_monagent 的内存配置低于集群内各主机的可用物理内存大小，否则可能造成资源配置失败。主机的可用物理内存大小可通过 <b>性能监控</b> > <b>主机性能</b> > <b>主机维度</b> > <b>内存</b> 进行查看。</li><li>变更 OCP Agent 规格需 <a href="400.restart-the-ocp-agent.md">重启 OCP Agent</a>，重启期间 OCP 无法执行运维操作且会丢失部分监控数据，您需谨慎操作。</li><li>若您需要为集群下的所有 OCP Agent 修改资源规格，可参考 <a href="../600.cluster-functions/300.manage-a-cluster/1200.manage-om-configuration/400.configuring-ocp-agent-resources.md">配置 OCP Agent 资源</a> 进行操作。</li></ul></p>
     </main>

## 查看监控信息

您可在 **<UI-TERM key="ocp-v2.src.hook.useMenu.Monitoring">监控</UI-TERM>** 页签查看 **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.HostPerformance">主机性能</UI-TERM>**、**<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.HostResources">主机资源</UI-TERM>** 和 **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.HostProcess">主机进程</UI-TERM>** 的监控数据，详情参见 [查看主机性能](../880.manage-performance-monitoring/100.performance-monitoring-overview/300.view-host-performance.md)、[查看主机资源](../880.manage-performance-monitoring/100.performance-monitoring-overview/700.view-host-resources.md)、[查看主机进程](../880.manage-performance-monitoring/100.performance-monitoring-overview/750.view-host-process.md)。
