# 检查主机标准化

数据库集群作为数据的基石，性能及稳定性对生产环境极为重要，为了确保数据库集群能发挥最大的价值，建议上线前对主机环境进行标准化检查，并对其中可能存在的风险进行修复。

本节为您介绍如何进行检查主机标准化操作。具体主机检查项可参见 [主机标准化检查项](../850.host-features/700.host-standardized-inspection-scope.md)。

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **主机维护** 资源权限。
  * 主机 **<UI-TERM key="ocp-v2.component.HostSelect.All">全部</UI-TERM>** 菜单权限。

* 主机处于 **<UI-TERM key="ocp-v2.src.constant.oceanbase.Idle">空闲</UI-TERM>** 状态。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏中单击 **<UI-TERM key="ocp-v2.Service.Component.ServiceModal.Host">主机</UI-TERM>**。

3. 进入主机列表页面，根据实际业务场景，找到主机标准化的入口。

   * 当新主机处于 **<UI-TERM key="ocp-v2.src.constant.compute.Idle">空闲</UI-TERM>** 状态，且已知晓或已完成主机标准化时，您可单击操作列的 **...**，选择 **<UI-TERM key="ocp-v2.page.Host.HostStandardization">主机标准化</UI-TERM>**。

        ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E4%B8%BB%E6%9C%BA%E6%A0%87%E5%87%86%E5%8C%96%E8%B7%AF%E5%BE%84.png)

   * 当新主机处于 **<UI-TERM key="ocp-v2.src.constant.oceanbase.Idle">空闲</UI-TERM>** 状态且未进行标准化操作时，将光标悬停于主机 ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E7%A9%BA%E9%97%B2%E5%9B%BE%E6%A0%87.png) 图标上，在弹出的提示中单机 **<UI-TERM key="ocp-v2.page.Host.HostStandardization">主机标准化</UI-TERM>** 。

        ![09162134](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E4%B8%BB%E6%9C%BA%E6%A0%87%E5%87%86%E5%8C%96.png)

4. 在面板中选择主机标准化的执行操作类型及产品类型。具体说明如下：

   |  参数  |  说明 |
   |--------|-------|
   | 执行操作  | 分为 **<UI-TERM key="ocp-v2.page.Host.CheckAndRepairAutomatically">检查并自动修复</UI-TERM>** 和 **<UI-TERM key="ocp-v2.page.Host.CheckOnly">仅检查</UI-TERM>** 两种类型。<ul><li>检查并自动修复：系统将对主机进行检查，并自动修复检查过程中所发现的风险。</li><li>仅检查：系统将只对主机进行检查操作，而不会自动修复检查过程中发现的风险。</li></ul>   |
   | 产品类型  | 分为 **OceanBase** 和 **OBProxy** 两种类型，支持多选。系统将针对不同的产品类型，执行其依赖的主机标准化检查项。  |

5. 检查任务结束后，若主机中存在风险，您可单击 **<UI-TERM key="ocp-v2.page.Host.ViewInspectionReports">查看检查报告</UI-TERM>** 查看详细的检查结果。

   * 针对执行 **<UI-TERM key="ocp-v2.page.Host.CheckOnly">仅检查</UI-TERM>** 生成的检查报告，若检查报告中有可自动修复的风险，单击 **<UI-TERM key="ocp-v2.page.Host.AutomaticRepair.1">自动修复</UI-TERM>** 按钮，系统将对风险项进行自动修复。
   * 若检查报告中不可自动修复的风险，您需根据报告中的信息进行手动修复。
   * 待风险修复后，可单击报告中的 **<UI-TERM key="ocp-v2.Detail.TakeOver.ReCheck">重新检查</UI-TERM>** ，重新对主机发起一个检查任务。
