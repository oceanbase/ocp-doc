# 管理 SSL 链路加密

<main id="notice" type='notice'>
<h4>功能适用性</h4>
<p>该内容仅适用于 OCP 企业版，OCP 社区版不提供此功能。</p>
</main>

为了提高链路安全性，OceanBase 数据库连接支持开启 SSL（Secure Sockets Layer）链路加密，通过在传输层对网络连接进行加密，确保各个节点之间的通信流量不会被监听或篡改，从而提升通信数据的安全性。SSL 链路加密可作用于 OceanBase 之间 RPC 通信、OBProxy 与 OceanBase 通信、业务应用与 OBProxy 通信，在开启 SSL 连接之后，支持设置要求客户端也必须使用 SSL 连接访问。

本页面为您介绍关于 SSL 链路加密的操作步骤。

## 开启 SSL 链路加密<a id="parameter"></a>

开启 SSL 链路加密后，集群性能将有轻微下降（传输数据加解密需要消耗一定的计算资源），建议仅在有外网连接或者有传输加密需求时开启集群 SSL 链路加密。

### 前提条件

* 请确保当前登录 OCP 的用户为 **ADMIN** 角色或 **ORG_ADMIN** 角色。

* SSL 链路加密功能对直连地址不生效。

### 操作步骤

1. 登录 OCP 。

2. 在左侧导航栏单击 **OBProxy** 。

3. 在集群列表中选择需要操作的 OBProxy 集群，进入 OBProxy 集群 **概览** 页面。

4. 单击左侧导航栏的 **安全配置** ，默认进入 **SSL 链路加密** 页签。

5. 单击 **开启** ，在对话框中选择 SSL Server 证书名，单击 **开启** 。

   如下拉列表中缺少所需证书，您可单击 [上传证书](../../1600.system-management-features/150.manage-certificates/200.upload-certificates.md) 来进行添加。

## 关闭 SSL 链路加密

本节为您介绍如何关闭 SSL 链路加密。关闭 SSL 链路加密为分钟级别操作，请您耐心等待。

### 前提条件

* 请确保当前登录 OCP 的用户为 **ADMIN** 角色或 **ORG_ADMIN** 角色。

* 已 [开启 SSL 链路加密](#paremeter)。

* SSL Server 证书未过期。

### 操作步骤

1. 登录 OCP 。

2. 在左侧导航栏单击 **OBProxy** 。

3. 在集群列表中选择需要操作的 OBProxy 集群，进入 OBProxy 集群 **概览** 页面。

4. 单击左侧导航栏的 **安全配置** ，默认进入 **SSL 链路加密** 页签。

5. 单击右上角 **关闭加密** ，在对话框中单击 **关闭** 。

## 更新 SSL Server 证书

当 SSL Server 即将过期或已过期时，您可在线更新 SSL Server 证书。重新生成加密证书后，历史创建的 SSL 链接将继续生效，新链接将会失败，您需注意相关变化。

### 前提条件

* 请确保当前登录 OCP 的用户为 **ADMIN** 角色或 **ORG_ADMIN** 角色。

* 已 [开启 SSL 链路加密](#paremeter)。

### 操作步骤

1. 登录 OCP 。

2. 在左侧导航栏单击 **OBProxy** 。

3. 在集群列表中选择需要操作的 OBProxy 集群，进入 OBProxy 集群 **概览** 页面。

4. 单击左侧导航栏的 **安全配置** ，默认进入 **SSL 链路加密** 页签。

5. 单击右上角 **更新 SSL Server 证书** ，在对话框中选择 SSL Server 证书名，单击 **更新** 。

   如下拉列表中缺少所需证书，您可单击 [上传证书](../../1600.system-management-features/150.manage-certificates/200.upload-certificates.md) 来进行添加。

## 下载 CA 证书

支持将 CA 证书以压缩包的形式下载至本地保存，压缩包内包含如下三个文件：

* `p7b` 文件：用于 Windows 系统中导入 CA 证书。

* `pem` 文件：用于其他系统或应用中导入 CA 证书。

* `jks` 文件：Java 中的 truststore 证书存储文件，密码统一为 OceanBase，用于 Java 程序中导入 CA 证书链。

### 前提条件

* 请确保当前登录 OCP 的用户为 **ADMIN** 角色或 **ORG_ADMIN** 角色。

* 已 [开启 SSL 链路加密](#paremeter)。

* SSL Server 证书未过期。

### 操作步骤

1. 登录 OCP 。

2. 在左侧导航栏单击 **OBProxy** 。

3. 在集群列表中选择需要操作的 OBProxy 集群，进入 OBProxy 集群 **概览** 页面。

4. 单击左侧导航栏的 **安全配置** ，默认进入 **SSL 链路加密** 页签。

5. 单击 **下载 CA 证书** 。
