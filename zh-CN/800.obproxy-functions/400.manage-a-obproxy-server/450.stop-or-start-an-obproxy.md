# 停止/启动 OBProxy

本页面为您介绍停止/启动 OBProxy 的操作。停止 OBProxy 会造成业务中断，请谨慎操作。

停止 OBProxy 后，可通过 **<UI-TERM key="ocp-v2.src.constant.backup.Start">启动</UI-TERM>** 来重新启动该 OBProxy。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **OBProxy 维护** 资源权限。
* OBProxy **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概览</UI-TERM>** 菜单权限。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏单击 **OBProxy** 。

3. 在集群列表中选择需要操作的 OBProxy 集群，进入 OBProxy 集群 **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概览</UI-TERM>** 页面。

4. 在 OBProxy 列表中选择需要停止的 OBProxy，在 **<UI-TERM key="ocp-v2.Instance.Overview.Operation">操作</UI-TERM>** 列中选择 **更多 > 停止** 。

   ![1116](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E5%81%9C%E6%AD%A2obproxy.png)

   您也可以勾选多个 OBProxy 并单击 **<UI-TERM key="ocp-v2.src.constant.obproxy.BatchStop">批量停止</UI-TERM>** 。

   ![1114](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E6%89%B9%E9%87%8F%E5%81%9C%E6%AD%A2obproxy.png)

   如需停止 OBProxy 集群中所有 OBProxy，可通过 [停止/启动 OBProxy 集群](../300.manage-a-obproxy-cluster/700.restarts-all-obproxy-nodes-in-the-obproxy-cluster.md) 实现。

5. 在弹出框中单击 **<UI-TERM key="ocp-v2.Instance.Overview.Ok">确定</UI-TERM>**。

6. 任务提交后，您可通过弹出框中的 **<UI-TERM key="ocp-v2.src.constant.ViewTasks">查看任务</UI-TERM>** 按钮，查看停止进度。

   当该任务状态为 **<UI-TERM key="ocp-v2.Detail.Log.TaskGraph.Complete">完成</UI-TERM>** ，且集群 **<UI-TERM key="ocp-v2.Detail.Monitor.Monitor.Overview">总览</UI-TERM>** 页的 **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.ObproxyList">OBProxy 列表</UI-TERM>** 中该 OBProxy 的状态为 **<UI-TERM key="ocp-v2.src.constant.backup.Stopped">已停止</UI-TERM>** 时，则任务执行成功。

7. 启动 OBProxy 。

    OBProxy 停止后，如您想再次启用该 OBProxy，可在 OBProxy 列表中单击 **<UI-TERM key="ocp-v2.Detail.Backup.Start">启动</UI-TERM>**，再次启用该 OBProxy。您也可以勾选多个 OBProxy 进行 **<UI-TERM key="ocp-v2.src.constant.obproxy.BatchStart">批量启动</UI-TERM>** 。

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E5%90%AF%E5%8A%A8obproxy.png)
