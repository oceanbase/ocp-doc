# 删除 OBProxy

本页面为您介绍删除 OBProxy 的操作。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>当 OBProxy 集群下有主机处于离线状态，系统会无法执行清理主机操作，删除 OBProxy 集群时将跳过此步骤，建议您手动清理主机环境。</p>
</main>

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **OBProxy 维护** 资源权限。
  * OBProxy **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概览</UI-TERM>** 菜单权限。

* 请确保该 OBProxy 的删除不影响业务。

  * 该 OBProxy 所在集群无可连接的 OceanBase 集群，或该 OceanBase 集群也弃用了。

  * 当前 OBProxy 的集群中除了这个待删除的 OBProxy 之外，其他 OBProxy 均可正常使用。并且您已通过配置负载均衡管理，将业务请求转发到其他可用 OBProxy 上。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏单击 **OBProxy** 。

3. 在集群列表中选择需要操作的 OBProxy 集群，进入 OBProxy 集群 **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概览</UI-TERM>** 页面。

4. 在 OBProxy 列表中选择需要删除的 OBProxy，单击 **<UI-TERM key="ocp-v2.page.Task.Operation">操作</UI-TERM>** 列的 **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.Delete">删除</UI-TERM>** 。

   ![1634](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E5%88%A0%E9%99%A4obproxy.png)

   您也可勾选多个 OBProxy，在 **<UI-TERM key="ocp-v2.Component.AddSamplingInspectStrategy.More">更多</UI-TERM>** 中单击 **<UI-TERM key="ocp-v2.Component.OBServerList.BatchDelete">批量删除</UI-TERM>** 。

   ![1636](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E6%89%B9%E9%87%8F%E5%88%A0%E9%99%A4obproxy.png)

   如需删除 OBProxy 集群中所有 OBProxy，您可通过 [删除 OBProxy 集群](../300.manage-a-obproxy-cluster/500.delete-an-obproxy-cluster.md) 实现。

5. 在弹出的对话框中输入 **delete**，并单击 **<UI-TERM key="ocp-v2.Detail.LoadBalance.Delete">删除</UI-TERM>** 。

6. 任务提交后，您可通过弹出框中的 **<UI-TERM key="ocp-v2.src.constant.ViewTasks">查看任务</UI-TERM>** 按钮，查看删除进度。

   当该任务状态为 **<UI-TERM key="ocp-v2.Detail.Log.TaskGraph.Complete">完成</UI-TERM>** ，且集群 **<UI-TERM key="ocp-v2.Detail.Monitor.Monitor.Overview">总览</UI-TERM>** 页的 **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.ObproxyList">OBProxy 列表</UI-TERM>** 中不再有该 OBProxy 时，则删除成功。

   <main id="notice" type='alert'>
   <h4>注意</h4>
   <p><ul><li>若所删除的 OBProxy 为 OBProxy 集群的最后一个 OBProxy，删除后会导致应用无法连接对应数据库。请谨慎操作。</li><li>删除 OBProxy 后，OBProxy 将从负载均衡策略配置中移除，会对所在的应用产生影响。</li></p>
   </main>
