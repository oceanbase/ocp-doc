# 添加 OBProxy

本页面为您介绍添加 OBProxy 的操作。

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **OBProxy 维护** 资源权限。
  * OBProxy **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概览</UI-TERM>** 菜单权限。

* 当 OBProxy 集群为 V4.0 及以上版本时，仅支持选择 V4.0.0 及以上版本的 OBProxy 软件包；当 OBProxy 集群为 V3.x 及以下版本时，仅支持选择 V1.8.0 及以上、V4.0.0 以下版本的 OBProxy 软件包。
* 仅可添加集群中已有版本的 OBProxy 软件包，建议软件包架构与当前 OBProxy 集群节点的硬件架构保持一致。
* 仅支持 V4.3.0 及以上版本的 OBProxy 配置 RPC 端口。

## 操作步骤

添加 OBProxy 有如下两个入口：

* **入口一**：在 OBProxy 的 **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">集群列表</UI-TERM>** 中找到待添加 OBProxy 的集群，并单击对应操作列的 **<UI-TERM key="ocp-v2.OBProxy.New.DeployMode.AddObproxy">添加 OBProxy</UI-TERM>** 。
* **入口二**：在 **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">集群列表</UI-TERM>** 中单击待添加 OBProxy 的集群的集群名，进入该 OBProxy 集群 **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概览</UI-TERM>** 页面，单击 **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概览</UI-TERM>** 页右上角的 **<UI-TERM key="ocp-v2.Detail.Overview.AddObproxy">添加 OBProxy</UI-TERM>** 。

以下操作步骤以 **入口二** 为例：

1. 登录 OCP。

2. 在左侧导航栏单击 **OBProxy** 。

3. 在集群列表中选择需要操作的 OBProxy 集群，进入 OBProxy 集群 **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概览</UI-TERM>** 页面。

4. 单击 **<UI-TERM key="ocp-v2.Detail.Component.AddOBProxyDrawer.AddObproxy">添加 OBProxy</UI-TERM>** 。

   ![09162140](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/421/%E6%B7%BB%E5%8A%A0obproxy.png)

5. 在弹出框中选择 OBProxy 软件包，并配置 **<UI-TERM key="ocp-v2.Cluster.New.SqlPort">SQL 端口</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.ExporterPort">Exporter 端口</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.RpcPort">RPC 端口</UI-TERM>**、**<UI-TERM key="ocp-v2.OBProxy.New.DeployMode.ComputerRoom">机房</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.TakeOver.Models">机型</UI-TERM>**、**<UI-TERM key="ocp-v2.Task.TaskObjectAndType.Host">主机</UI-TERM>** 等信息，详情参见 [创建 OBProxy 集群](../../500.quickstart/800.quickstart-create-an-obproxy-cluster.md)。

   ![1122](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/432/%E6%B7%BB%E5%8A%A0obproxy.png)

   <main id="explain" type='explain'>
   <h4>说明</h4>
   <p>当 OBProxy 集群中未创建或接管 OBProxy 时，添加 OBProxy 时可自定义 SQL 端口、Exporter 端口和 RPC 端口；当 OBProxy 集群中已存在 OBProxy 时，SQL 端口、Exporter 端口和 RPC 端口默认继承 <a href="../../500.quickstart/800.quickstart-create-an-obproxy-cluster.md">创建 OBProxy 集群</a> 中部署 OBProxy 时配置的端口号，不支持自定义。</p>
   </main>

6. 单击 **<UI-TERM key="ocp-v2.Report.Component.GenerateReportModal.Determine">确定</UI-TERM>** 。
