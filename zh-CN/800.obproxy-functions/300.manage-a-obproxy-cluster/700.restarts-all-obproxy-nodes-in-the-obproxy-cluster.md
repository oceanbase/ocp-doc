# 重启 OBProxy 集群

本页面为您介绍重启 OBProxy 集群下全部 OBProxy 的操作，重启集群会同时重启 OBProxy 集群中所有 OBProxy。

如当前 OBProxy 集群已承载业务，建议根据您当前配置的负载均衡，通过 [重启 OBProxy](../400.manage-a-obproxy-server/400.restart-an-obproxy.md) 的方式分批重启集群中的 OBProxy。

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **OBProxy 维护** 资源权限。
  * OBProxy **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概览</UI-TERM>** 菜单权限。

* 当 OBProxy 为 V3.2.1 以下版本时，仅支持强制重启；当 OBProxy 为 V3.2.1 及以上版本时，支持 **<UI-TERM key="ocp-v2.Detail.Component.RestartModal.ForceRestart">强制重启</UI-TERM>** 和 **<UI-TERM key="ocp-v2.src.constant.backup.Restart">重启</UI-TERM>** 两种模式。

* 仅 OBProxy 集群下所有的 OBProxy 状态为 **<UI-TERM key="ocp-v2.src.constant.compute.Running">运行中</UI-TERM>** 时支持进行 **<UI-TERM key="ocp-v2.src.constant.oceanbase.Restart.4">重启</UI-TERM>**；否则仅支持 **<UI-TERM key="ocp-v2.Component.CgroupEditModal.ForceRestart">强制重启</UI-TERM>**。

* **<UI-TERM key="ocp-v2.Detail.Component.RestartModal.ForceRestart">强制重启</UI-TERM>** 过程中会停止所有 OBProxy，建议在业务量少的时间段执行。

## 操作步骤

重启 OBProxy 集群有如下两个入口：

* **入口一**：进入 **OBProxy** 页面，在集群列表中选择需要操作的 OBProxy 集群，单击 **更多 > 全部重启**。
* **入口二**：进入 OBProxy 集群 **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概览</UI-TERM>** 页面，单击 **<UI-TERM key="ocp-v2.page.OBProxy.RestartAll">全部重启</UI-TERM>**。

以下操作步骤以 **入口二** 为例：

1. 登录 OCP。

2. 在左侧导航栏单击 **OBProxy** 。

3. 在集群列表中选择需要操作的 OBProxy 集群，进入 OBProxy 集群 **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概览</UI-TERM>** 页面。

4. 单击 **<UI-TERM key="ocp-v2.Detail.Overview.RestartAll">全部重启</UI-TERM>** 。

   ![09162146](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E5%85%A8%E9%83%A8%E9%87%8D%E5%90%AF.png)

5. 在弹出框中选择重启模式，包括 **<UI-TERM key="ocp-v2.src.constant.compute.Restart">重启</UI-TERM>** 和 **<UI-TERM key="ocp-v2.Component.CgroupEditModal.ForceRestart">强制重启</UI-TERM>**。

   * **<UI-TERM key="ocp-v2.Component.ZoneList.Restart">重启</UI-TERM>**（推荐）：默认情况下，重启不会中断业务对数据库的访问。如果您的业务存在长事务，建议设置合适的 `hot_upgrade_exit_timeout` 参数值，或应用连接具备重试机制。
   * **<UI-TERM key="ocp-v2.Detail.Component.RestartModal.ForceRestart">强制重启</UI-TERM>**：通过本 OBproxy 连接的客户端将被终止，造成部分业务中断。

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/421/%E9%87%8D%E5%90%AFobproxy%E9%9B%86%E7%BE%A4.png)

6. 任务提交后，您可通过弹出框中的 **<UI-TERM key="ocp-v2.src.constant.ViewTasks">查看任务</UI-TERM>** 按钮，查看重启进度。

   当该任务状态为 **<UI-TERM key="ocp-v2.Detail.Log.TaskGraph.Complete">完成</UI-TERM>** ，且集群 **<UI-TERM key="ocp-v2.Detail.Monitor.Monitor.Overview">总览</UI-TERM>** 页的 **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.ObproxyList">OBProxy 列表</UI-TERM>** 中，所有 OBProxy 的状态为 **<UI-TERM key="ocp-v2.page.Information.Running">运行中</UI-TERM>** 时，则重启成功。
