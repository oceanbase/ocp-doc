# 管理 OBProxy 集群参数

您可在 **<UI-TERM key="ocp-v2.page.Iframe.ParameterManagement">参数管理</UI-TERM>** 页面，查看 OBProxy 集群的 **<UI-TERM key="ocp-v2.component.OperationConfig.Parameter.ParameterList">参数列表</UI-TERM>** 和 **<UI-TERM key="ocp-v2.component.OperationConfig.Parameter.ModifyHistory">修改历史</UI-TERM>** 。

## 前提条件

* 查看 OBProxy 集群参数信息及参数修改历史时，请确保当前登录 OCP 的用户具备如下权限：

  * **OBProxy 只读** 资源权限。
  * OBProxy **<UI-TERM key="ocp-v2.component.OperationConfig.ParameterManagement">参数管理</UI-TERM>** 菜单权限。

* 修改 OBProxy 集群参数时，请确保当前登录 OCP 的用户具备如下权限：

  * **OBProxy 维护** 资源权限。
  * OBProxy **<UI-TERM key="ocp-v2.page.Iframe.ParameterManagement">参数管理</UI-TERM>** 菜单权限。

## 查看/修改参数

1. 登录 OCP。

2. 在左侧导航栏单击 **OBProxy** 。

3. 在集群列表中选择需要操作的 OBProxy 集群，进入 OBProxy 集群 **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概览</UI-TERM>** 页面。

4. 单击左侧导航栏的 **<UI-TERM key="ocp-v2.component.OperationConfig.ParameterManagement">参数管理</UI-TERM>** ，默认进入 **<UI-TERM key="ocp-v2.page.MultiCluster.Parameter.ParameterList">参数列表</UI-TERM>** 页签。

   ![1122](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/403-cn/obproxy%E5%8F%82%E6%95%B0%E7%AE%A1%E7%90%86.png)

   在该页中，您可：
   * 查看参数：在搜索框中输出参数名，单击搜索按钮，查看指定参数，支持模糊查询。

   * 修改参数：

     1. 单击指定参数 **<UI-TERM key="ocp-v2.Component.BinlogService.Operation">操作</UI-TERM>** 列的 **<UI-TERM key="ocp-v2.component.OperationConfig.List.ModifyValue">修改值</UI-TERM>** 按钮。

     2. 填写 **<UI-TERM key="ocp-v2.Component.SQLCondition.Value">值</UI-TERM>** ，随后单击 **<UI-TERM key="ocp-v2.Detail.Component.Event.Determine">确定</UI-TERM>** 。

     3. 目标参数的值都修改完毕后，单击 **<UI-TERM key="ocp-v2.Detail.Parameter.SubmitModification">提交修改</UI-TERM>**。

        ![11221625](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/403-cn/%E4%BF%AE%E6%94%B9%E5%8F%82%E6%95%B0.png)

     4. 在弹出的面板中确认修改信息，单击 **<UI-TERM key="ocp-v2.Detail.Component.ModifyParameterDrawer.ConfirmModification">确认修改</UI-TERM>** 。等待修改任务执行完成，则修改成功。

     5. 参数修改完成后，您需查看参数的 **<UI-TERM key="ocp-v2.Detail.Parameter.List.WhetherTheRestartTakesEffect">是否重启生效</UI-TERM>** 信息，以确定参数如何生效：

        * 无需重启生效的参数：参数修改成功后约 3 分钟即可生效。
        * 需要重启生效的参数：重启 OBProxy 后才可生效。

      <main id="notice" type='explain'>
      <h4>说明</h4>
      <p><b>只读</b> 参数不支持修改参数值。</p>
      </main>

## 查看参数修改历史

1. 登录 OCP。

2. 在左侧导航栏单击 **OBProxy** 。

3. 在集群列表中选择需要操作的 OBProxy 集群，进入 OBProxy 集群 **<UI-TERM key="ocp-v2.Detail.Monitor.Monitor.Overview">总览</UI-TERM>** 页面。

4. 单击左侧导航栏的 **<UI-TERM key="ocp-v2.src.util.menu.ParameterManagement">参数管理</UI-TERM>** ，默认进入 **<UI-TERM key="ocp-v2.page.MultiAzone.ParameterList">参数列表</UI-TERM>** 页签。

5. 选择 **<UI-TERM key="ocp-v2.Detail.Parameter.ModifyHistory">修改历史</UI-TERM>** 页签。

   输入 **<UI-TERM key="ocp-v2.component.OperationConfig.History.ModifiedDate">修改日期</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Parameter.History.Parameter.1">参数名称</UI-TERM>** 信息，单击 **<UI-TERM key="ocp-v2.Detail.SQLDiagnosis.Query">查询</UI-TERM>** ，对参数进行筛选，查看对应参数的信息。您可在参数列表中查看 **<UI-TERM key="ocp-v2.Detail.Component.ModifyParameterDrawer.Parameter">参数名</UI-TERM>** 、 **<UI-TERM key="ocp-v2.Detail.Parameter.History.ValueBeforeChange">值-变更前</UI-TERM>** （变更前的参数值）、 **<UI-TERM key="ocp-v2.Detail.Parameter.History.ValueAfterChange">值-变更后</UI-TERM>** （变更后的参数值）、 **<UI-TERM key="ocp-v2.Detail.Overview.ModificationTime">修改时间</UI-TERM>** 和 **<UI-TERM key="ocp-v2.Detail.Parameter.History.OperationUser">操作用户</UI-TERM>** 。

   ![11221628](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/403-cn/%E5%8F%82%E6%95%B0%E4%BF%AE%E6%94%B9%E5%8E%86%E5%8F%B2.png)
